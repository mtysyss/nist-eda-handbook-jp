# 6.2.7. スキップロット抜取とは

#### スキップロット抜取り
スキップロット抜取りとは、提出されたロットの一部のみを検査することを意味する。
この抜取り方法は、時間と労力の面でコスト削減につながる。
ただし、スキップロット抜取りは、提出された製品の品質が極めて良好であることが実証されている場合にのみ使用すべきである。

#### スキップロット抜取計画の実施
スキップロット抜取計画は、以下に従い実施される。

1. アルファ・リスク、ベータ・リスク、および 消費者／生産者のリスクを指定し、[1回抜取計画を策定する](pmc23.md)。
この計画は「基準抜取計画」と呼ばれる。
2. まず、基準計画を用いて、通常のロットごとの検査を開始する。
3. あらかじめ指定された数 $`i`$ の連続したロットが合格した時点で、ロットの $`f`$ 分の1のみを検査するように切り替える。
その $`f`$ 分の1に含まれるロットの選定は無作為に行われる。
4. ロットが不合格となった場合は、通常の検査に戻す。

#### $` f `$ および *i* 係数
母数 $`f`$ および $`i`$ は、スキップロット抜取計画における受入確率を計算する上で不可欠である。
この方式において、<u>クリアランス数</u> と呼ばれる $`i`$ は、正の整数であり、抜取率 $`f`$は $`0 < f < 1`$ を満たす。
したがって、$`f=1`$の場合、スキップロット抜取りは成立しなくなる。
スキップロット抜取り計画の合格確率の計算は、次の式を用いて行われる

$$ P_a(f,i) = \frac{fP + (1-f)P^i}{f + (1-f)P^i} \, $$

ここで、*P* は、1回抜取計画の [OC曲線](pmc22.md#Operating%20Characteristic%20528OC%29)から、所定の不良品率 $`p`$ を持つロットを合格させる確率である。

以下の関係が成り立つ。

$$ \begin{align}
\text{与えられた } i \text{ に対して、} & f \text{ が小さいほど } P_a \text{ は大きくなり、} \\
\text{与えられた } f \text{ に対して、} & i \text{ が小さいほど } P_a \text{は大きくなる。}
\end{align} $$

#### スキップロット抜取計画のASN
スキップロット抜取計画の重要な特性の一つは、平均検査数（[ASN](pmc22.md#平均検査数)）である。
スキップロット抜取計画のASNは、次式で表される。

$$ \text{ASN}_{skip-lot} = (F)(\text{ASN}_{reference}) \, , $$

ここで、$`F`$は次に定義される。

$$ F = \frac{f}{(1-f)P_i + f} \, .$$ 

したがって、$`0 < F < 1`$ であるため、スキップロット抜取計画のASNは、基準抜取計画のASNよりも小さくなる。

要約すると、スキップロット抜取りは、提出されるロットの品質が極めて高く、かつ供給業者が確かな実績を証明できる場合に適している。
