# 6.2.3.1. 抜取計画の選定：MIL規格105D

#### AQL（許容品質水準）は、基本要件です。
抜取り計画は通常、合格品質水準（[AQL](pmc22.md#Acceptable％20Quality%20Level)）を基準として策定されます。
AQLとは、製造業者の製品の品質に対する基本要件のことである。
生産者は、[OC曲線](pmc22.md#Operating%20Characteristic%20%28OC%29)がAQLにおいて高い受入確率を示すような抜取計画を策定したいと考えている。
一方、OC曲線の反対側では、消費者は生産者からの品質不良品の受入から身を守りたいと望んでいる。
そこで消費者は、基準として<u>ロット許容不良率</u> [LTPD](pmc22.htm#Lot%20Tolerance%20Percent%20Defective) を設定する。
ここでの考え方は、品質不良品が受入される確率を極めて低く抑えることである。
Mil. Std. 計画は、これらの目標を達成するために 50年以上にわたり使用されてきた。

**米国国防省規格 105E**

#### Mil規格 105Eに基づく抜取り計画
属性検査のための標準的な軍用サンプリング手順は、第二次世界大戦中に策定された。
陸軍兵器局の表および手順は1940年代初頭に作成され、これらは後に陸軍補給部隊の表へと発展した。
戦争終結時には、海軍も一連の表の作成に取り組んだ。
その間、コロンビア大学の統計研究グループは調査を行い、計数抜取計画に関して多くの優れた成果を挙げた。

これら3つの流れは1950年に統合され、Mil.Std. 105Aという規格となった。
それ以来、随時改訂が加えられ、105B、105C、105Dとして発行されてきた。
Mil. Std. 105Dは1963年に米国政府によって発行された。
1971年には米国国家規格協会（ANSI）によって ANSI規格 Z1.4 として採用され、1974年には（若干の変更を加えて）国際標準化機構（ISO）によってISO規格 2859として採用された。
最新の改訂版は Mil. Std. 105E であり、1989年に発行された。

これら3つの類似した規格は継続的に更新・改訂されているが、基本的な表は変わらない。
したがって、以下で述べるM il. Std. 105E の関連事項に関する説明は、他の2つの規格にも当てはまる。 

**Mil規格 105D の記述**

#### Mil規格 105D に基づく抜取り計画
本書は、本質的には、抜取り手法の体系に基づいて整理された一連の個別計画である。
抜取り手法は、通常の抜取計画、厳格化された抜取計画、および縮小抜取計画の組合せと、これらを切り替えるための規則から構成される。

#### 規格の基礎であるAQL
この規格の基礎となるのは、合格品質水準 AQL である。
以下のシナリオでは、ある軍事機関（以下、消費者と呼ぶ）が、ある特定の製品をある供給業者（以下、生産者と呼ぶ）から購入しようとしている。

Mil. Std. 105D を適用するにあたっては、特定の製品特性に対する AQL が何であるかについて、生産者と消費者の間で完全な合意が得られていることが前提となる。
両当事者は、生産者が、通常、消費者が指定した品質水準を満たす複数のロットを検査に提出することを相互に理解している。
品質の継続性は、特定の抜取り計画に従ってロットを合格または不合格とすることで確保されるほか、生産者の製品が合意された AQL を満たしていないという証拠がある場合には、より厳格な別の抜取り計画へ移行する措置を講じることで確保される。 

#### 3種の抜取り計画を提供する規格
Mil. Std. 105E では、3種類の抜取り計画（1回、2回、および多回計画）が規定されている。
その選択は、一般的に検査員の裁量に委ねられている。

3つの選択肢があるため、この規格では標本規模を規定するのではなく、標本符号文字を規定している。
これと計画の種類の決定を組み合わせることで、使用する具体的な抜取り計画が決定される。 

#### 検査水準
AQLに関する初期決定に加え、「検査レベル」を決定することも必要である。
これにより、ロット規模と標本規模の関係が決まる。
この規格では、3つの一般的な水準と4つの特別な水準が規定されている。

#### 規格における手順
本規格の使用手順は、次のように要約できる。

1. AQLを決定する。
2. 検査水準を決定する。
3. ロット規模を決定する。
4. 表を参照して、標本規模の符号文字を確認する。
5. 使用する抜取り方式を決定する。
6. 適切な表を参照し、適用する検査計画を特定する。
7. 通常の検査を開始し、切り替え規則および検査中止の規則（必要な場合）に従う。
