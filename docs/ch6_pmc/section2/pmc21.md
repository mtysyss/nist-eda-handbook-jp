# 6.2.1. 合否判定抜取とは

#### 合否判定抜取における Dodge と Roming の貢献
受入検査は統計的品質管理における重要な分野であり、Dodge と Roming によって広められ、もともとは第二次世界大戦中に米軍が弾丸の検査に適用したものである。
もしすべての弾丸を事前に検査していたら出荷できる弾丸が一つも残らなくなってしまう。
一方で、一切検査しなければ戦場で故障が発生し壊滅的な結果を招く恐れがあった。

#### ロット合否判定抜取の定義
Dodge は、ロットから無作為に標本を抽出するべきであり、標本から得られた情報に基づいて、ロットの処理に関する決定を行うべきであると論じた。
一般的に決定はロットを合格とするか不合格とするかのいずれかである。
この工程は<u>ロット合否判定抜取</u>あるいは単に<u>合否判定抜取</u>とも呼ばれる。

#### 「計数」（すなわち、欠陥の計数）の仮定
合否判定抜取は、無検査と100％検査の中間的な手法である。
合否判定抜取検査計画には、<u>計数</u>（合格・不合格）によるものと<u>計量</u>によるものの2つの主要な分類がある。
計数による場合は受入検査において最も一般的であり、本節の残りの部分ではこれを前提とする。

#### 重要なポイント
覚えておくべき点は、合否判定抜取の主な目的は、そのロットが合格基準を満たす可能性が高いかを判断することであり、ロットの品質を推定することではないということである。

#### 合否判定抜取のシナリオ
合否判定抜取は、以下の条件のうち1つまたは複数が当てはまる場合に採用される。

* 検査が破壊的である場合
* 100％検査のコストが非常に高い
* 100％検査に時間が掛かり過ぎる

#### 受入品質管理と合否判定抜取
1969年、Harold Dodge は、受入品質管理（AQC）が合否判定抜取とは異なるものであることを指摘した。
後者は特定の抜取計画に依存しており、その計画が実施されると、検査対象となっている当該ロットの合格または不合格の条件が示される。
前者は、合格管理図の形で実施されることがある。
合格管理図の管理限界は、仕様限界値と、監視対象の標準偏差を用いて計算される（詳細については [Ryan, 2000](../section7/pmc7.md#Ryan,)を参照）。

#### Harold Dodgeによる所見
1942年、Dodge は次のように述べた。  

「……基本的に、開発された『受入品質管理』システムは、消費者が許容できない欠陥製品から消費者を保護し、生産者が工程品質管理を活用するよう奨励することを目的としている。
具体的には、検査対象の特性の重要度と直接的に比例し、かつそれらの検査によって示される品質水準の良さに反比例するように、受入検査の数量と厳格度を調整することである。」

これら2つの手法の違いを改めて述べると、合否判定抜取計画は一回限りの措置であり、本質的には短期的な効果を検証するものである。
一方、品質管理は長期的なものであり、ロットの受入に関する適切に設計されたシステムの一部である。 

#### Ed Schilling による所見
Schilling（1989）は次のように述べている。  

「個別の抜取計画は、まるで単独の狙撃兵のような効果しか持たないが、抜取計画の体系は、品質改善という戦いの場で一斉射撃のような効果をもたらすことができる。」 

#### 受入管理図を用いた製品品質の管理
受入管理図に関するISO規格[（ISO 7966、1993年）](../section7/pmc7.md)によれば、受入管理図は、管理上の意味合いへの配慮と合否判定抜取の要素を組み合わせたものである。
これは、工程の受入に関する意思決定を行う上で役立つ適切なツールである。
受入抽出検査の手法と受入管理図との違いは、製品の処分決定ではなく、工程の受入可能性に重点が置かれている点にある。
