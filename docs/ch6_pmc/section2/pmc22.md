# 6.2.2. ロット受入れ抜取検査計画（LASPs）の種類

#### LASP：抜取方式および一連の規則
ロット受入れ検査計画（LASP）とは、抜取り手法および意思決定のための一連の規則のことである。
標本中の不良品数を数えた結果に基づくこの決定は、ロットを受入、ロットを不適合とする、あるいは、複数回または連続抜取り方式の場合は、別の標本を採取して決定工程を繰り返す、といったものになる。

#### 選択可能な受入計画の種類
LASPs は以下の区分に分類される。

* **1回抜取計画：** 1ロット標本を無作為に抽出し、その結果得られた情報に基づいてロットの処分を決定する。
これらの計画は通常、標本規模 *n* に対する (*n*,*c*) 計画として表され、欠陥品が *c* 個以上ある場合にロットが不適合と判定される。
これらは最も一般的（かつ最も簡単）な計画であるが、必要な平均標本数という点では最も効率的とは言えない。

* **2回抜取計画：** 最初の標本を検査した後は、以下の3つの可能性がある。
    1. ロットを合格とする  
    2. ロットを不適合とする  
    3. 判定なし
  結果が（3）の場合、2番目の標本が採取されるが、その手順では両方の標本結果を統合し、その情報に基づいて最終的な判定を下す。

* **多回抜取計画：** これは2回抜取計画の拡張であり、結論を導き出すために 2つ以上の標本が必要である。
多回抜取りの利点は、標本規模が小さくなることである。

* **逐次抜取計画：** これは多回抜取の究極の拡張であり、ロットから1品目づつ選定し、各品目の検査後にロットを合格不合格の判定を行うか、あるいは別の単位を選定するを決める。

* **スキップロット抜取計画：**  スキップロット抜取とは、提出されたロットのうちごく一部のみを検査することを意味する。 

#### 受入検査の基本用語の定義
上記区分のいずれかに基づく計画の策定については以下のページで説明する。
すべての策定方法は、計画に求める特性によって異なる。
これらを以下の用語を用いて説明する。

* **合格品質水準（AQL）**：AQLとは、製造業者の製品の品質に対する基本要件となる不良率（百分率）のことである。
製造業者は、欠陥率が AQL以下であるロットを<u>高い確率で合格</u>と判定できるような抜取計画を策定したいと考えている。

* **ロット許容不良率（LTPD）**：LTPDとは、消費者が受け入れられないと指定した高い不良率のことである。
消費者は、不良率が LTPDと同じくらい高いロットを<u>受入する確率が低い</u> 抜取計画を望んでいる。

* **第1種の過誤（生産者のリスク）**：これは、与えられた (*n*, *c*) 抽出計画において、欠陥水準が AQLに等しいロットを不適合と判定してしまう確率である。
これが発生すると、許容可能な品質のロットが不適合と判定されてしまうため、生産者は不利益を被ることになる。
第1種の過誤には通常、記号 *α* が用いられ、*α* の典型的な値は 0.2 から 0.01 の範囲にある。

* **第2種の過誤（消費者のリスク）**： これは、与えられた  (*n*, *c*) 抽出計画において、欠陥水準が LTPDに等しいロットを受け入れてしまう確率である。
これが発生すると、許容できない品質のロットが受け入れられてしまうため、消費者は不利益を被る。
第2種の誤差には通常、記号 *β* が用いられ、典型的な値の範囲は 0.2 から 0.01 である。

* **検査特性（OC）曲線**：この曲線は、ロットを受け入れる確率（Y軸）と、ロット内の不良品率または不良品割合（X軸）をプロットしたものである。
<u>OC曲線は、LASPの特性を表示・調査するための主要なツールであry</u>。

* **平均出荷品質（AOQ）**： 抜取および試験が非破壊検査である場合、一般的な手順として、不合格ロットを100％検査し、すべての不良品を良品と交換する。
この場合、不適合と判定されたロットはすべて完全な状態となり、残るのは合格したロット内の欠陥のみとなる。
AOQ とは、このLASPと不適合ロットの 100％検査を組み合わせた工程における長期的な欠陥水準を指す。
すべてのロットの欠陥率が正確に *p* であり、選択された (*n*, *c*) LASP のOC曲線がそのようなロットを合格とする確率 *p*<sub>*a*</sub> を示している場合、長期的には AOQ は次のように簡単に導き出される。

$` \text{AOQ} = \frac{p_a p (N - n)}{N} \quad ,`$  

ここで、*N* はロット規模である。

* **平均出検品質水準（AOQL）**： AOQ（Y軸）対入荷ロットの欠陥率 *p*（X軸）のグラフは、$` p=0 `$ の時点で 0 から始まり、$` p = 1 `$ （すべてのロットが 100% 検査され、是正される場合）で再び 0 に戻る。
その間、曲線は最大値まで上昇する。
この最大値は、長期的に考えられる最悪の AOQであり、AOQLと呼ばれる。

* **平均総検査数（ATI）**： 不適合ロットが 100％検査される場合、ロットの欠陥水準が常に　*p* であるならば、ATIを容易に計算できる。
欠陥率 *p* のロットを受け入れる確率が *p*<sub>*a*</sub>　である LASP (*n*, *c*) については、次のように表される。

$` \text{ATI} = n + (1-p_a)(N-n) \quad , `$

ここで、*N*　はロット規模である。

* **平均検査数 (ASN)**： 1回抜取り LASP (*n*, *c*)の場合、すべてのロットが欠陥率 *p* で入荷すると仮定すれば、各ロットの標本数が *n* であることが計算できる。
ASNと入荷欠陥率 *p* の関係を示すグラフは、特定の LASP関係の抜取り効率を表している。 

#### 最終選択は妥協点
許容可能な特性を備えた1回抜取計画と多回抜取計画のうち、最終的にどちらを選択するかは、さまざまな多回抜取計画によって得られる平均的な抽出コストの削減効果が、これらの計画に伴う追加的な複雑さや、日ごとにどの程度の抜取りや検査が行われるかが不明確であるという不確かさを正当化するかを判断することにかかっている。
