# 6.2.3. 1回抜取計画の選定

#### 1回抜取計画を選択するための2つの方法
[前述のように定義された](pmc22.md#Single%20sampling)1回抜取計画は数値の組 (*n*, *c*) によって規定される。
標本規模は *n* であり、標本中に *c* 個を超える不良品が含まれている場合はロットは不合格となり、そうでない場合はロットは合格となる。

(*n*,*c*) を選択する際、広く用いられている方法は2つある。

1. [AQL](pmc22.md#Acceptable％20Quality％20Level)または[LTPD](pmc22.md#Lot%20Tolerance%20Percent%20Defective)のいずれかを目標値とする表（[MIL STD 105D](pmc231.md)など）を使用する方法。

2. [OC曲線](pmc22.md#Operating%20Characteristic%20%28OC%29)上の [2つの目標点を指定](pmc232.md)し、それらの点を通るOC曲線を一意に決定する (*n*,*c* )を求める。 

次の2ページではこれらの方法について詳しく説明する。
