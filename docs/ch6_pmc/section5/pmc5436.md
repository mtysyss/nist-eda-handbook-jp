# 6.5.4.3.6. 多変量グラフの作成

#### 統計ソフトウェアでは一般的に利用できない多変量管理図
管理図はもともと手作業で作成、管理されていたが、6.5.4.3.1節から6.5.4.3.4節で示された図の作成手順を用いてそれを実行しようとすると、極めて非現実的である。
残念ながら、よく知られている統計ソフト・ウェアパッケージには、先に概説した4つの手順を実行する機能が備わっていない。
しかし、このe-ハンドブック全体を通じて事例研究やチュートリアルに使用されている[Dataplot](http://www.itl.nist.gov/div898/handbook/dataplot.htm)には、その機能が備わっている。
