# 6.5.4.3.5. 多変量変動を管理するための管理図

#### 多変量変動を示す適切な図表はない
残念ながら、部分群または個別観測値のいずれかを対象とした多変量変動を管理するための図表のうち、単純で理解しやすく、実施しやすく、かつ統計的に正当化できるものはない。
部分群データに対しては、一般化分散に基づく手法が提案されているが、こうした手法は[Ryan (2000, 第9.4節)](../section7/pmc7.md#Ryan,)およびそこで引用されている一部の文献によって批判されている。
個別観測値については、単変量の移動範囲管理図の多変量版が、フェーズⅠにおける分散共分散行列の推定量として考えられるかもしれないが、その推定量の分布は不明である。
