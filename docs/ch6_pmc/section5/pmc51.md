# 6.5.1. 「正規」データとは

#### 正規分布モデル
「正規」データとは、正規分布に従う母集団から抽出された（由来する）データのことである。
この分布は、統計学の理論と応用の両面において、間違いなく最も重要かつ最も頻繁に使用される分布である。
*X* が正規確率変数である場合、*X* の確率分布は以下となる。

#### 正規確率分布

$$ f(x) = \frac{1}{\sigma \sqrt{2 \pi}} e^{ -\frac{1}{2} \left(\frac{x - \mu}{\sigma} \right)^2 } -\infty < x < \infty  .$$

#### 正規分布の母数
正規分布の母数は、平均 *μ* と標準偏差 *σ*（あるいは分散 *σ*<sup>2</sup>）である。
*X* がこれらの母数を持つ正規分布に従うことを示すために、次の特別な表記が用いられる。
すなわち

$$ X \sim N(\mu, \sigma) \text{ または }  X \sim N(\mu, \sigma^2)  . $$

#### 対称の単峰型である形状
正規分布の形状は対称で、単峰型である。
これはその発見者である Gauss にちなんで、<u>ベル型</u>分布または<u>ウス分布</u>と呼ばれている（ただし、De Moivre の功績も評価されるべきである）。

外観を以下に示す。

![Sample plot of the normal distribution](https://www.itl.nist.gov/div898/handbook/pmc/section5/gifs/normal.gif)

#### 曲線下の面積が1に等しくなる確率分布の性質
確率分布と呼ばれる、非負関数の特別な類の性質として、曲線下の面積が 1に等しくなることが挙げられる。
曲線の任意の部分の下側の面積は、指定された区間においてその分布を積分することで求めることができる。
正規分布のベル型曲線の下の面積は 1に等しいことが示せるため、正規分布は確率分布である。

#### *σ* の解釈
*σ* には簡単な解釈がある。

母集団の 68.27 % が $`\mu \pm 1 \sigma`$ の範囲内に収まる。
母集団の 95.45 % が $`\mu \pm 2 \sigma`$ の範囲内に収まる。
母集団の 99.73 % が $`\mu \pm 3 \sigma`$ の範囲内に収まる。 

#### 累積正規分布
累積正規分布は、正規変数がある値 *v* 以下となる確率として定義され、すなわち

$$ P(X \le v) = F(v) = \int_{-\infty}^v\frac{1}{\sigma\sqrt{2\pi}} e^{ -\frac{1}{2} \left( \frac{x-\mu}{\sigma} \right)^2 } dx  . $$

残念ながら、この積分は閉形式では評価できず、数値計算に頼らざるを得ない。
しかし、それでもなお、考えられるすべての *μ* および *σ* の値に対する表が必要である。
変数変換を行うことでこの状況を打開できる。

$$ z = \frac{x - \mu}{\sigma}  . $$ 

これで、*μ* や *σ* に依存せずに評価を行うことができる。
すなわち、

$$ P(X \le v) = P \left(z \le \frac{v-\mu}{\sigma} \right) = \Phi \left( \frac{v-\mu}{\sigma} \right)  , $$

ここで、$`\Phi(.)`$ は<u>標準正規分布</u> $`(\mu=0,  \sigma=1)`$ の累積分布関数である。

$$ \phi(z) = \frac{1}{\sqrt{2 \pi}} e^{\frac{-z^2}{2}} $$ 

#### 累積標準正規分布の表
累積標準正規分布の表は、あらゆる統計学の教科書や[ハンドブック](../../ch1_eda/section3/eda3671.md)に掲載されている。
また、数値計算法に関する文献には、多種多様な近似法が掲載されている。

例えば、$`\mu = 0`$ かつ $`\sigma = 1`$ の場合、$`\mu - 1\sigma`$ から $`\mu + 1\sigma`$ までの曲線下の面積は、0 から 1 までの範囲の面積に等しく、これは 0.6827 となる。
ほとんどの標準正規分布表は、検索値の左側の面積を示しているため、$`z = 1`$ に対する面積は 0.8413、$`z = -1`$ に対する面積は 0.1587 となる。
これらを差し引くと、-1 から +1 までの間の面積は0.8413 - 0.1587 = 0.6826 となる。
