# 6.4.4.6. Box-Jenkins モデルの同定

#### 定常性と季節性
Box-Jenkinsモデルを構築する最初の手順では、その時系列が[定常的](pmc442.md)であるか、またモデル化すべき有意な[季節性](pmc443.md)があるかを判断する。

#### 定常性の検出
定常性は、[実行シーケンス・プロット](../../ch1_eda/section3/eda33p.md)から評価することができる。
実行シーケンス・プロットでは、位置と尺度が一定であることが示されるべきである。
また、[自己相関プロット](../../ch1_eda/section3/eda331.md)からも定常性を検出することができる。
具体的には、自己相関プロットにおいて減衰が非常に緩やかな場合、非定常性が示唆されることがよくある。

#### 季節性の検出
季節性（または周期性）は、通常、[自己相関プロット](../../ch1_eda/section3/eda331.md)、[季節別副系列プロット](pmc4431.md)、あるいは[スペクトル図](../../ch1_eda/section3/eda33r.md)から評価する。

#### 定常性を確保するための差分処理
BoxとJenkinsは、定常性を達成するために差分処理の手法を推奨している。
しかし、Box-Jenkinsモデルの文脈においても、曲線を推定し、その推定値を元のデータから差し引く手法を用いる。

#### 季節調整
モデル同定の段階では、季節性がある場合はそれを検出し、季節性自己回帰項および季節性移動平均項の次数を特定することを目標とする。
多くの時系列では、周期が既知であるため、単一の季節性項で十分である。
例えば、月次データの場合、通常は季節性AR 12項または季節性MA 12項のいずれかを含めることになる。
Box-Jenkinsモデルでは、モデルを推定する前に季節性を明示的に除去することはない。
その代わりに、ARIMA推定ソフトウェアへのモデル指定において、季節項の次数を明記する。
ただし、データに季節差分処理を適用し、自己相関および偏自己相関プロットを再作成すると、役立つ場合がある。
これにより、モデルの非季節的成分のモデル同定が容易になる可能性がある。
場合によっては、季節差分処理によって季節性の影響の大部分またはすべてが除去されることもある。

#### *p* と *q* の同定
定常性と季節性を処理したら、次の手順では、自己回帰項と移動平均項の次数（すなわち、$`p`$と $`q`$）を同定する。

#### 自己相関および偏自己相関のプロット
これを行うための主なツールは、[自己相関プロット](../../ch1_eda/section3/eda331.md)および[偏自己相関プロット](pmc4463.md)である。
標本自己相関プロットと標本偏自己相関プロットを次数が既知の場合におけるこれらのプロットの理論的な挙動と比較する。

#### 自己回帰過程の次数 *p*
具体的には、AR(1)過程の場合、標本自己相関関数は指数関数的に減少する傾向を示すはずである。
しかし、高次AR過程は、多くの場合、指数関数的に減少する成分と減衰した正弦波成分が混在している。

高次自己回帰過程については、標本自己相関に加え、偏自己相関プロットも併せて検討する必要がある。
AR(*p*)過程の偏自己相関は、ラグ $`p + 1`$ 以降でゼロとなるため、標本偏自己相関を関数を調べ、ゼロからの逸脱の兆候があるかを確認する。
これは通常、標本偏自己相関プロット上に95％信頼区間を描画することで判断される（標本自己相関プロットを作成するほとんどのソフトウェア・プログラムは、この信頼区間も同時にプロットする）。
ソフトウェアが信頼区間を出力しない場合、その幅はおおよそ $`\pm 2/\sqrt{N}`$ となり、ここで *N* は標本規模を表す。 

#### 移動平均処理の次数 (*q*)
MA(*q*)過程の自己相関関数は、ラグ $`q + 1`$ 以降でゼロとなるため、標本自己相関関数を調べ、それが実質的にゼロになる箇所を確認する。
これを行うには、標本自己相関関数の 95％信頼区間を、標本自己相関プロット上にプロットする。
自己相関プロットを作成できるソフトウェアのほとんどは、この信頼区間も出力できる。
標本偏自己相関関数は、一般的に、移動平均過程の次数を特定する上で有用ではない。 

#### 自己相関関数の形状
以下の表は、モデル同定における標本自己相関関数の使用方法をまとめたものである。

| 形状 | 示唆されるモデル |  
| :---- | :--------- |  
| 指数関数型（ゼロへ減衰）| 自己回帰モデル。偏自己相関プロットを用いて、自己回帰モデルの次数を特定する。 |  
| 正と負が交互に現れ、ゼロに向かって減衰する | 自己回帰モデル。 偏自己相関プロットを用いて次数の特定に役立てる。 |  
| 1つ以上のスパイクがあり、残りは実質的にゼロ。 | 移動平均モデル。プロットがゼロになる点によって次数が特定される。 |  
| 数ラグ後に減衰が始まる | 自己回帰モデルと移動平均モデルの混合モデル。 |  
| すべてゼロ、またはゼロに近い | データは実質的に無作為である。 |  
| 一定の間隔で高い値が現れる | 季節性自己回帰項を含める。 |  
| ゼロへの減衰がない | 時系列は定常的ではない。 |    

#### 識別が困難な混合モデル
実際には、標本自己相関関数および偏自己相関関数は確率変数であり、理論的な関数とは同じ傾向を示さない。
このため、モデルの同定はより困難になる。
特に、混合モデルの同定は極めて困難となる場合がある。

経験は役立つが、これらの標本プロットを用いて優れたモデルを構築するには、多くの試行錯誤を要する場合がある。
このため、近年では FPE（最終予測誤差）や AIC（赤池情報量基準）などの情報量に基づく基準が好まれ、広く用いられている。
これらの手法は、モデル同定過程の自動化に役立つ。
これらの手法を利用するにはコンピュータ・ソフトウェアが必要である。
幸いなことに、これらの手法は、ARIMAモデル化機能を備えた多くの市販統計ソフトウェア・プログラムで利用可能である。

これらの技法に関する詳細については、[Brockwell and Davis (1987,2002)](../section7/pmc7.md#Brockwell1)を参照のこと。
