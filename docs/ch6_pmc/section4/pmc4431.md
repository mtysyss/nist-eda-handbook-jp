# 6.4.4.3.1. 季節別副系列プロット

#### 目的
季節別副系列プロット（[Cleveland1993](eda43.md#Cleveland2)）は、時系列データにおける季節性を検出するための手法である。

このプロットは季節性の周期が既に判っている場合にのみ有用である。
多くの場合、実際には周期は判っている。
例えば、月次データの周期は通常12である。

周期が不明な場合は、[自己相関プロット](../../ch1_eda/section3/eda331.md)や[スペクトル図](../../ch1_eda/section3/eda33r.md)を用いてそれを特定する。 

#### プロットの例

![Sample seasonal subseries plot](https://www.itl.nist.gov/div898/handbook/pmc/section4/gifs/co2seas.gif)

CO<sub>2</sub>濃度の月別データを含む季節別副系列プロットは、顕著な季節変動パターンを示している。
CO<sub>2</sub>濃度は5月にピークを迎え、9月にかけて着実に減少し、その後、5月のピークまで再び上昇し始める。

このプロットを用いて、群間および群内の両方のパターンを検出する。

観測値の数が多ければ、[箱ひげ図](../../ch1_eda/section3/eda337.md)の方が適している場合がある。 

#### 定義
季節季節別副系列プロットは、以下の要素によって構成する。

縦軸：応答変数
横軸：季節別に並べ替えた時間。
例えば、月次データの場合、1月のすべての値が（時系列順に）プロットされ、次に2月のすべての値が、というように続く。

さらに、群の平均値に基準線を引く。

このプロットを作成する前に、利用者は季節パターンの長さを指定する必要がある。
ほとんどの場合、分析者は問題の背景やデータ収集の状況からこれを把握している。
場合によっては、CO<sub>2</sub>データの場合のように、プロットを生成する前に時系列データからトレンドを除去する必要がある。 

#### 論点
季節別副系列プロットは、以下の問いに対する答えを示す。

1. データには季節的なパターンが見られるか。
2. 季節性の性質はどのようなものか。
3. 群内パターンはあるか（例：1月と7月は同様のパターンを示すか）
4. 季節性を考慮した後に、外れ値はあるか。

#### 重要性
時系列データを分析する際には、有意な季節性効果があるかを把握することが重要である。
季節別副系列プロットは、季節パターンがあるかを判断するための優れたツールである。

#### ソフトウェア
季節別副系列プロットは、いくつかの汎用統計ソフトウェアで利用可能である。
このプロットを直接提供していないほとんどの統計ソフトウェアでも、マクロを作成することで、このプロットを生成できる可能性がある。
季節別副系列プロットは、[Dataplotコード](https://www.itl.nist.gov/div898/handbook/pmc/section4/pmc4431.dp)および[Rコード](https://www.itl.nist.gov/div898/handbook/pmc/section4/pmc4431.r)の両方を使用して作成できる。
読者は、データを[テキストファイル](https://www.itl.nist.gov/div898/handbook/datasets/MLCO2MON.DAT)としてダウンロードすることができる。
