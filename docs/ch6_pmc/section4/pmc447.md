# 6.4.4.7. Box-Jenkinsモデルの推定

#### ソフトウェアを使用する
Box-Jenkins モデルの係数推定はかなり複雑な非線形推定問題である。
このため、係数推定は、Box-Jenkins モデルを推定できる高品質なソフトウェアに任せるべきである。
幸いなことに、現在では多くの市販の統計ソフトウェアが Box-Jenkins モデルの推定に対応している。

#### 手法
Box-Jenkins モデルの推定における主な手法は、[非線形最小二乗法](../../ch4_pmd/section1/pmd142.md)と最尤推定である。

一般に、最尤推定が推奨される技法である。
完全な Box-Jenkins モデルの尤度式は複雑であるため、ここでは記載しない。
数学的な詳細については、([Brockwelland Davis, 1991](../section7/pmc7.md#Brockwell)) を参照のこと。 

#### モデル推定の例
[Negizの事例研究](../section6/pmc62.md)は、Box-Jenkins モデルによる推定の例を示している。
