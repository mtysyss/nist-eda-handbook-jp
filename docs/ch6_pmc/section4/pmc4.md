# 6.4. 時系列解析入門

#### データに潜在する時系列分析手法
内部構造を考慮に入れる時系列データは、産業工程の監視や企業の業績指標の追跡を行う際にしばしば発生する。
時系列手法によるデータのモデル化と、本章の前半で説明した工程監視手法との本質的な違いは、以下の通り。 

<u>時系列分析は、時間の経過とともに取得されたデータ点に、考慮すべき内部構造（自己相関、トレンド、季節変動など）が存在し得るという事実を反映している。</u>

この節では、豊富で急速に発展している時系列モデル化および分析の分野において、広く利用されている手法のいくつかを簡単に概説する。
