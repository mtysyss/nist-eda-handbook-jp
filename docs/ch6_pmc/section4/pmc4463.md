# 6.4.4.6.3. 偏自己相関プロット

#### 目的：Box-Jenkins モデルのモデル同定
偏自己相関プロット（[Box and Jenkins,pp. 64-65, 1970](../section7/pmc7.md#BoxJenkins)）は、Box-Jenkinsモデルにおけるモデル同定に広く用いられている手法である。

ラグ *k* における偏自己相関は、ラグ 1 から *k*-1 まででは説明できない、$`X_t`$ と $`X_{t-k}`$ との間の自己相関である。

ここでは詳述しないが、標本自己相関に基づいて偏自己相関を計算するアルゴリズムがある。
数学的な詳細については、([Box, Jenkins,and Reinsel 1970](../section7/pmc7.md#Box, G.E.P.; G.M.)) または([Brockwell, 1991](../section7/pmc7.md#Brockwell)) を参照のこと。

具体的には、偏自己相関は、[自己回帰モデル](pmc444.md#AR)の次数の特定に有用である。
AR(*p*)工程の偏自己相関は、ラグ $`p+1`$ 以上でゼロとなる。
もし標本自己相関プロットから ARモデルが適切である可能性が示唆される場合、標本偏自己相関プロットを検証して次数を特定する。
実質的に偏自己相関がゼロになる場所を点をプロット上から求める。
この目的のためには、統計的有意性に関する 95%の信頼区間を設定することが有用である。

偏自己相関の近似的な 95％信頼区間は、$`\pm 2/\sqrt{N}`$となる。 

#### プロットの例

![Partial autocorrelation plot of southern oscillations data](https://www.itl.nist.gov/div898/handbook/pmc/section4/gifs/oscpart.gif)

この偏自己相関プロットは、[南方振動](pmc4412.md)データ集合について、ラグ1 およびラグ2 において明確な統計的有意性を示している（ラグ0は常に1である）。
続く数個のラグについては、統計的有意の境界にある。
もし、この自己相関プロットから ARモデルが適切であると判断されるならば、我々はAR(2)モデルからモデル化を開始する。
また、これをAR(3)モデルと比較してみることも考えられる。 

#### 定義
偏自己相関プロットは、以下の条件で作成する。

縦軸：ラグ *h* における偏自己相関係数
横軸：時間ラグ $`h  (h=0, 1, 2, 3, \ldots)`$

さらに、通常、95 %信頼区間の帯をプロット上に示す。

#### 論点

偏自己相関プロットは、以下の論点に対する答えを見つけるのに役立つ。

1. ARモデルは当該データに適しているか。
2. ARモデルが適切である場合、どの次数を用いるべきか。
