# 6.4.4.8.1. Box-Ljung 検定

#### 適合性の欠如の検定
Box-Ljung 検定（[1978](../section7/pmc7.md#Ljung,)）は、時系列モデルの不適合を検定するために用いられる診断手法である。

この検定は、データに ARMA(*p*,*q*)モデルを適合させた後の時系列の残差に対して適用する。
この検定は、残差の *m* 自己相関を検証する。
もし自己相関が極めて小さい場合、モデルには有意な不適合は見られないと結論付ける。

[6.4.4.10](pmc44a.md)節には、残差時系列を用いて Box-Ljung検定を実施した例を掲載している。 

#### 定義
一般に、Box-Ljung 検定はのように定義される。

| | |  
| :--- | :------ |  
| *H*<sub>0</sub>: | モデルに不適合は見られない。 |  
| *H*<sub>a</sub>: | モデルに不適合が見られる。 |  
| 検定統計量： | 長さ *n* の時系列 *Y* に対し、検定統計量は次のように定義される。<br><br>$` Q = n(n+2)\sum_{k=1}^m \frac{\hat{r}^2_k}{n-k} `$ <br><br>ここで、$`\hat{r}_k`$ はラグ *k* における時系列の推定自己相関であり、*m* は検定対象となるラグの数である。 |  
| 有意水準： | *α* |  
| 棄却域： | Box-Ljung検定では、以下の条件を満たす場合、帰無仮説を棄却する（これは、モデルに有意な適合不良があることを示す）。<br><br>$` Q > \chi_{1-\alpha, h}^2 `$ <br><br> ここで、$`\chi_{1-\alpha, h}^2`$ は、自由度 *h*、有意水準 *α* におけるカイ二乗分布の表値である。<br><br>この検定は残差に対して適用されるため、自由度は推定されたモデル母数を考慮に入れる必要があり、$`h = m-p-q`$ となる。ここで、*p* および *q* は、データへの ARMA(*p*,*q*)モデルに適合した係数数を表す。 |
