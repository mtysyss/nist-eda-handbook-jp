# 6.4.4.8. Box-Jenkinsモデルの診断

#### 安定な単変量過程に関する仮定
Box-Jenkins モデルのモデル診断は、[非線形最小二乗法による適合](../../ch4_pmd/section1/pmd142.md)におけるモデル検証と類似している。

すなわち、誤差項 $`A_t`$は、[定常な単変量工程の仮定](../../ch1_eda/section2/eda21.md)に従うとする。
残差は、平均と分散が一定である固定分布から抽出された白色雑音（あるいは、分布が正規分布である場合は独立）であるべきである。
もしBox-Jenkinsモデルがデータに対して適切なモデルであるならば、残差はこれらの仮定を満たすはずである。

これらの仮定が満たされない場合は、より適切なモデルを推定する必要がある。
つまり、モデル同定の段階に戻り、より優れたモデルの構築を試みる。
うまくいけば、残差の分析から、より適切なモデルに関する手がかりが得られる。 

#### 残差の4-プロット
EDAの章で述べたように、Box-Jenkinsモデルの残差が仮定を満たしているかを評価する方法の一つは、残差の[4プロット](../../ch1_eda/section3/eda33w.md)と残差の[自己相関プロット](../../ch1_eda/section3/eda331.md)を作成することである。
また、Box-Ljung ([1978](../section7/pmc7.md#Ljung,)) 統計量値を確認する。

Box-Jenkinsモデルの残差を分析する例は、[Negizデータの事例研究](../section6/pmc62.md)で示されている。
