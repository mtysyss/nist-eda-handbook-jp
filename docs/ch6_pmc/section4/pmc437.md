# 6.4.3.7. 指数平滑法の概要
**概要**

#### 有用な手法であると実証されている指数平滑法
指数平滑法は、長年にわたり、多くの予測する状況において非常に有用であることが実証されてきた。
この手法は1957年に C.C.Holt によって初めて提案され、当初はトレンドを示さない非季節的な時系列データへの適用を目的としていた。
その後、彼はトレンドを扱う手順を提案した（1958年）。
Winters（1965年）はこの手法を一般化し、季節性を考慮するようにしたため、「Holt-Winters 法」と呼ばれるようになった。

#### Holt-Winters の3つの更新式
Holt-Winters 法には3つの更新式があり、それぞれに 0から 1の範囲の定数が用いられている。
これらの方程式は、最近の観測値により大きな重みを与え、過去の観測値にはより小さな重みを与えるように設計されている。

これらの重みは、一定の比率で幾何級数的に減少していく。

HWの手順は、使いやすいソフトウェアによって完全に自動化することができる。
