# 6.4.4.9. 単変量Box-Jenkins分析の例

#### F系列
[Box、Jenkins、および Reinsel（1994）](../section7/pmc7.md#Box,%20G.E.P.;%20G.M.)に掲載されている[系列Fのデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/F_SERIES.DAT)を分析する。
70個の生データ点のグラフを以下に示す。

![Plot of Series F Data](https://www.itl.nist.gov/div898/handbook/pmc/section4/pmc449_r01.gif)

このデータには季節的成分や顕著な傾向は見られない。
（この時系列の定常性は、データと時間の関係に直線で適合することで検証された。
その傾きは、ゼロと有意な差がないことが確認された（*p* 値 = 0.2）。）

ACF値はラグ2以降、符号と減衰に関して速やかに交互に変化し、AR(2)モデルがデータに適していることを示している。

#### モデル適合
データにAR(2)モデルを適合させる。

$$ X_t = \delta + \phi_1 X_{t-1} + \phi_2 X_{t-2} + A_t $$

モデル適合の結果を以下に示す。

```
Source  Estimate  Standard Error
------  --------  --------------
φ1       -0.3198      0.1202
φ2        0.1797      0.1202

δ = 51.1286 
Residual standard deviation = 10.9599

Test randomness of residuals:
Standardized Runs Statistic Z = 0.4887, p-value = 0.625
```
