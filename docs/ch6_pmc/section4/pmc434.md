# 6.4.3.4. 二重指数平滑法（LASP）を用いた予測

#### 予測式
1期間先の予測は、次式での表される。

$$ F_{t+1} = S_t + b_t  . $$ 

*m* 期間先の予測は、次式で表される。

$$ F_{t+m} = S_t + m b_t  . $$ 

**例**

#### 例
もう一度、以下のデータ集合を考える。

　6.4, 5.6, 7.8, 8.8, 11, 11.6,16.7, 15.3,  
　21.6, 22.4

ここで、$`\alpha = 0.3623`$ および $`\gamma = 1.0`$ を用いた二重平滑化モデルで適合をする。
これらは、元の時系列と 1期間先までの予測値を比較したときに、MSEが最小となる推定値である（この形式の二重指数平滑化では、現在の時系列値を用いて平滑化値を計算するため、平滑化された時系列を用いて MSE が最小となる *α* を決定することはできない）。
選択された初期値は以下となる。

$$ S_1 = y_1 = 6.4$$ 
および 
$$b_1 = ((y_2 - y_1) + (y_3 - y_2) + (y_4 - y_3))/3 = 0.8$$

比較のために、$`\alpha = 0.977`$ を用いた単平滑化モデルも適合させた（これにより、単指数平滑化において最小の MSE が得られる）。

二重平滑化のMSEは 3.7024 である。  
単平滑化のMSEは 8.8867である。

#### 単指数平滑法と二重指数平滑法による予測を比較したグラフ
これらの結果（予測された二重平滑化値を用いたもの）をグラフに表すと、非常に参考になる。

![Plot showing single and double exponential smoothing Forecasts](https://www.itl.nist.gov/div898/handbook/pmc/section4/gifs/tseries4.gif)

このグラフは、二重平滑化が単平滑化よりもはるかにデータに忠実に追従していることを示している。
さらに、予測においては、単平滑化では水平な直線を投影する以上の成果は得られず、これは現実にはほとんど起こり得ない。
したがって、この事例では二重平滑化が推奨される。 

#### 二重指数平滑法と回帰分析による予測値を比較したグラフ
最後に、二重平滑化と線形回帰を比較してみる。

![Plot showing raw data with double exponential smoothing and regression Forecasts](https://www.itl.nist.gov/div898/handbook/pmc/section4/gifs/tseries5.gif)

これは興味深い図である。
どちらの手法もデータに似た形で沿っているが、回帰直線の方がより保守的である。
つまり、回帰直線では二重平滑化に比べて増加のペースが緩やかである。 

#### 予報者に拠る手法の選択
手法の選択は予測者次第である。
もし増加過程をより力強い形で表現したい場合は、二重平滑化を選択する。
そうでない場合は、回帰分析が適しているかもしれない。
なお、線形回帰では「時間」が独立変数として機能することに留意すべきである。
[4章](../../ch4_pmd/pmd.md)では、線形回帰の[基礎](../../ch4_pmd/section1/pmd141.md)と、回帰[推定](../../ch4_pmd/section4/pmd431.md)の詳細について解説する。
