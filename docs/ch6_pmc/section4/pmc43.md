# 6.4.3. 指数平滑法とは

#### 指数関数的に減少する重みを用いて過去の観測値に重み付けする指数平滑法
これは、平滑化された時系列を作成するための非常に一般的な手法である。
単純移動平均では過去の観測値に均等な重みが付与されるのに対し、指数平滑化では観測値が古いものになるにつれて<u>指数関数的に減少する重み</u>が割り当てられる。

言い換えれば、<u>予測において、古い観測値よりも最近の観測値に相対的に大きな重みが与えられる</u>。

移動平均の場合、観測値に割り当てられる重みはすべて同じで、1/*N* となる。
一方、指数平滑化では、決定（または推定）すべき 1つ以上の<u>平滑化係数</u>があり、これらの選択によって観測値に割り当てられる重みが決まる。

本節では、[単一](pmc431.md)、[二重](pmc433.md)、および[三重](pmc435.md)指数平滑化について解説する。
