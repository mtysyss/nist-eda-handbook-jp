# 6.4.2.1. 単純移動平均

#### 平滑化工程：移動平均の算出
過去データを要約する別の方法として、過去データで順次小さくなる一連の数値集合の平均を次のように計算する方法がある。

無作為に選ばれた[12供給業者](pmc42.md#12)の金額である、9、8、9、12、9、12、11、7、13、9、11、10という数値の集合を思い出す。
「より小さな集合」の規模 *M* を 3 に設定する。
すると、最初の 数値3つの平均は次のようになる。
(9 + 8 + 9) / 3 = 8.667。

これは「平滑化」（すなわち、ある種の平均化）と呼ばれる。
この平滑化処理は、1期間分先へ進み、最初の数値を除外して次の数値3つの平均を計算することで継続する。

#### 移動平均の例
次の表は、<u>移動平均</u>と呼ばれるこの工程をまとめたものである。
移動平均の一般式は次のとおり。

$$ M_t = \frac{X_t + X_{t-1} + \cdots + X_{t-N+1}}{N}  . $$
