# 6.4.1. 定義、応用、および手法

#### 定義

**時系列の定義**： <u>等時間間隔で測定された変数値の順序付き列</u>。

#### 産業データを分析するときに頻繁に出現する時系列データ

**応用**： 時系列モデルの用途は2つある。

* 観測データを生成した根本的な要因や構造を理解する。
* モデルを推定し、予測、監視、さらには  フィードバック制御やフィードフォワード制御を行う。

時系列分析は、以下のような多くの用途に利用されている。

* 経済予測
* 売上予測
* 予算分析
* 株式市場分析
* 収量予測
* 工程および品質管理
* 在庫調査
* 業務量の予測
* 公益事業調査
* 国勢調査の分析

その他、数え切れないほど多くの項目がある。

#### 時系列のモデル化や予測にはさまざまな手法が用いられる

**技法**： 時系列モデルの推定は、非常に野心的作業となる場合がある。
モデル推定には、以下を含む多くの手法がある。

* [Box-Jenkins ARIMAモデル](../section4/pmc44.md)
* [Box-Jenkins 多変量モデル](../section4/pmc45.md)
* [Holt-Winters 指数平滑化（1次、2次、3次）](../section4/pmc43.md)

適切な手法の選択は利用者の用途や好みに左右される。
これらすべての技法を網羅することは本ハンドブックの著者の範囲および意図を超えている。
ここで紹介する概要では、いくつかの基本的な平滑化手法について見ていく。

* 平均化法
* 指数平滑化の手法

この節の後半では、Box-Jenkins のモデル化手法と多変量時系列について論じる。
