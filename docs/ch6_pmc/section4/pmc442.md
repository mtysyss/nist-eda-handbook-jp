# 6.4.4.2. 定常性

#### 定常性

多くの時系列解析手法において、データが定常的であるという仮定が一般的に用いられる。
定常過程とは、平均、分散、および自己相関構造が時間の経過とともに変化しないという性質を持つものである。
定常性は厳密な数学的用語で定義することもできますが、ここでは、トレンドがなく、時系列が平坦に見え、分散が時間とともに一定であり、自己相関構造が時間とともに一定で、周期的な変動（[季節性](https://www.itl.nist.gov/div898/handbook/pmc/section4/pmc443.md)）がないことを指する。

実用上、定常性は通常、[ランシーケンス](../section3/eda33p.md)プロットから判断することができます。 

#### 定常性を達成するための変換
時系列が定常でない場合、多くの場合、以下の手法のいずれかを用いて定常な時系列に変換することができます。

1. データに差分処理を施すことができます。
すなわち、時系列 $`Z_t`$ に対して、新しい時系列 <br><br>
$$ Y_i = Z_i - Z_{i-1}  . $$<br><br>
差分処理されたデータには、元のデータよりも1つ少ないデータ点が含まれます。
差分処理を複数回行うことも可能ですが、通常は1回の差分処理で十分である。

2. データにトレンドが含まれている場合は、何らかの曲線をデータにフィットさせ、そのフィット結果からの残差をモデル化することができます。
フィットの目的は単に長期的なトレンドを除去することであるため、通常は直線などの単純なフィットが用いられます。

3. 分散が一定でない場合、時系列の対数や平方根を取ることで、分散を安定させることができる。
負のデータについては、変換を適用する前に、すべてのデータが正になるよう適切な定数を加えることができます。
その後、この定数をモデルから差し引くことで、予測値（すなわち、推定値）や将来の時点に対する予測値を得ることができます。

上記の手法は、位置とスケールが一定な時系列を生成することを目的としている。
季節性によって定常性が損なわれることもありますが、これは通常、時系列モデルに明示的に組み込まれます。

#### 実行シーケンス・プロット

![Run sequence plot of CO2 data set indicates a simple linear fit should be sufficient to remove trend](https://www.itl.nist.gov/div898/handbook/pmc/section4/gifs/co2runsq.gif) 

データの初期実行シーケンス・プロットからは、上昇傾向が示されている。

また、このプロットには周期的な挙動も見られる。
これについては次節で論じる。 

#### 線形トレンドの除去

![Run sequence plot of CO2 data with linear trend removed](https://www.itl.nist.gov/div898/handbook/pmc/section4/gifs/co2res.gif)

このプロットには、元のデータに対して線形回帰を行った際の残差が示されている。
線形トレンドを除去した後、実行シーケンス・プロットを見ると、データの位置と分散は一定であることが判るが、残差のパターンからは、データが体系的な方法でモデルから逸脱していることが判る。
