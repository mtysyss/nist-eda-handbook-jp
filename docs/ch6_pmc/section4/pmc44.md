# 6.4.4. 単変量時系列モデル

#### 単変量時系列
「単変量時系列」という用語は、等間隔の時間単位で順次記録された単一の（スカラー）観測値から構成される時系列を指す。
例としては、[月ごとのCO2濃度](pmc4411.md)や、[エルニーニョ現象の影響を予測するための南方振動](pmc4412.md)などが挙げられる。

単変量時系列のデータ集合は通常、1つの数値列として与えられるが、実際には時間は時系列における暗黙の変数である。
データが等間隔で記録されている場合、時間変数（または指標）を明示的に指定する必要はない。
時間変数は、時系列をプロットするときに明示的に使用されることがある。
しかし、時系列モデル自体では使用されない。

等間隔でデータが収集されていない時系列の分析については、本ハンドブックの範囲外とする。
