# 6.3.4.2. 主成分管理図

#### *T*<sup>2</sup> 座標系に関する問題
*T*<sup>2</sup> 管理図は、多変量工程データを扱う上で最も普及しており、使いやすく解釈も容易な手法であり、品質技術者や作業員の間でも広く受け入れられつつあるが、万能の解決策というわけではない。
第一に、単変量の場合とは異なり、管理図上に表示される値の目盛りは、監視対象の変数のいずれの目盛りとも関連していない。
第二に、*T*<sup>2</sup> 統計量が上側管理限界（*UCL*）を超えた場合、利用者はどの特定変数が管理外れ信号を引き起こしたのかを知ることができない。

#### 多変量分析のグラフと単変量分析グラフの作成
尺度調整に関しては、多変量管理図と併せて個別の単変量管理図も作成することを強く勧める。
これにより、その信号の原因となった可能性のある要因を特定しやすくなる。
しかし、個別の単変量管理図だけでは、変数間の共分散や相関に起因する状況を説明することはできない。
そのため、散布図も併せて使用する必要がある。

#### 多変量データを監視するもう一つの方法：主成分分析管理図
データを分析するもう一つの方法は、<u>主成分</u>を用いることである。
各多変量測定値（または観測値）について、主成分は、標準化された *p* 個の変数の線形結合である（標準化するには、それぞれの目標値からその値を引いて、標準偏差で割る）。
主成分には2つの重要な利点がある。

1. 新しい変数同士は相関がない（あるいはほぼ相関がない）
2. 多くの場合、ごく少数の（時には1つや2つの）主成分だけでデータ変動の大部分を説明できるため、管理のために *p* 個の主成分すべてを使用する必要がなくなる。

#### 固有値
残念ながら、1つ大きな欠点がある。
それは、元の変数の性質が失われてしまうことであり。
しかし、場合によっては、[固有値](../section5/pmc532.md#eigenvalues)が最大の主成分に対応する特定の線形結合が、意味のある測定単位を与えることもある。
管理図で使用されているのは、<u>主因子</u>である。

<u>主因子とは、主成分をその固有値の平方根で割ったものである</u>。
