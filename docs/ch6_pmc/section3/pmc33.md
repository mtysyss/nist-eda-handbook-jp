# 6.3.3. 計数管理図とは

#### 観測値の分類や計数を行うときの計数データ
Shewhart 管理図は、測定可能で数値で表すことができる品質特性をプロットしたものである。
重量、高さ、位置、厚さなどを測定する。
特定の品質特性を数値で表すことができない場合、あるいはそれが現実的でないとき、多くの場合、品質特性を用いて検査対象の品目を2つの「区分」のいずれかに仕分けたり分類したりする。

一般的な品質特性の分類例としては、製品を「適合品」または「不適合品」に指定することが挙げられる。
別の品質特性の基準としては、製品を「欠陥なし」と「欠陥あり」の区分に分類することがある。
この種の品質特性は<u>計数</u>と呼ばれる。

なお、「技術仕様に不適合」と「欠陥あり」には違いがあることに注意する。
不適合製品でも、正常に機能し、実際には全く欠陥がない場合もある。
一方で、部品が「仕様内」であっても、期待通りに機能しない（すなわち、欠陥がある）場合もある。
計数である品質特性の例としては、生産ロットにおける故障件数、ロット内の不具合のあるウェハの割合、ある特定日に社員食堂で食事をする人数、などが挙げられる。 

#### 属性管理図の種類
<u>欠陥</u>や<u>不適合</u>数を扱う管理図は、[*c*管理図（countの頭文字）](pmc331.md)と呼ばれる。
不良品の<u>割合</u>や<u>比率</u>を扱う管理図は、[*p*管理図（proportionの頭文字）](pmc332.md)と呼ばれる。

また、<u>単位あたりの欠陥数</u>を扱う別の管理図として、*u*管理図（unitの頭文字）がある。
これは、製品1単位あたりの不適合平均数を分析したい場合に適用される。

参考文献として、[Woodall(1997)](../section7/pmc7.md#Woodall,%20W.H.) を参照のこと。
同書では、計数管理図の例を示す論文を総説しており、欠陥の空間的依存性を調査したものなど、半導体製造からの例も含まれている。
