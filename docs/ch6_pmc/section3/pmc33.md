# 6.3.3. 計数管理図とは

#### 観測値の分類や計数を行う際に、属性データが生じます
Shewhart の管理図は、測定可能で数値で表すことができる品質特性をプロットしたものである。
重量、高さ、位置、厚さなどを測定する。
特定の品質特性を数値で表すことができない場合、あるいはそれが現実的でない場合は、多くの場合、品質特性を用いて、検査対象の品目を2つの「区分」のいずれかに仕分けたり分類したりすることになる。
一般的な品質特性の分類例としては、製品を「適合品」または「不適合品」に指定することが挙げられます。
別の品質特性の基準としては、製品を「欠陥なし」と「欠陥あり」のカテゴリーに分類することがある。
この種の品質特性は*「属性」*と呼ばれます。
なお、「技術仕様に不適合」と「欠陥あり」には違いがあることに注意してください。
不適合な製品でも、正常に機能し、実際には全く欠陥がない場合もある。
一方で、部品が「仕様内」であっても、期待通りに機能しない（すなわち、欠陥がある）場合もある。
属性である品質特性の例としては、生産ロットにおける故障件数、ロット内の不具合のあるウェーハの割合、ある特定の日に社員食堂で食事をする人の数、などが挙げられます。 

#### 属性管理図の種類
*欠陥*数や*不適合数を*扱う管理図は、[*c*管理図（countの頭文字）](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc331.md)と呼ばれます。
不良品の割合や*比率*を扱う管理図は、[*p*管理図（proportionの頭文字）](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc332.md)と呼ばれます。
また、*単位あたりの欠陥数を*扱う別の管理図として、u管理図（unitの頭文字）がある。
これは、製品1単位あたりの不適合の平均数を分析したい場合に適用されます。
参考文献としては、[Woodall(1997)](https://www.itl.nist.gov/div898/handbook/pmc/section7/pmc7.md#Woodall, W.H.) を参照のこと。
同書では、属性管理図の例を示す論文を総説しており、欠陥の空間的依存性を調査したものなど、半導体製造からの例も含まれている。
