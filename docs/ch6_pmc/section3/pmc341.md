# 6.3.4.1. Hotelling 管理図

#### Hotelling の *T*<sup>2</sup>「距離」統計量の定義
Hotelling *T*<sup>2</sup> 距離は、多変量正規分布の共分散構造を考慮に入れた距離の尺度である。
これは1947年に Harold Hotellingによって提案され、Hotelling *T*<sup>2</sup> と呼ばれている。
これは、スチューデントの t 統計量の多変量版と考えることができる。
 
*T*<sup>2</sup> 距離は、定数に二次形式を乗じたものである。
この二次形式は、以下の3つの量を乗算することで得られる。

1. 観測値と平均 $` \bf{m} `$ との偏差のベクトル（$`(\bf{X-m})'`$ で表される）
2. 共分散行列の逆行列 $`\bf{S}^{-1}`$
3. 偏差ベクトル $`(\bf{X-m})`$

なお、独立変数の場合、共分散行列は対角行列となり、*T*<sup>2</sup> は標準化された変数の平方和に比例することになる。

一般に、*T*<sup>2</sup> 値が大きいほど、観測値は平均から遠く離れていることになる。
*T*<sup>2</sup> を計算する式は次の通り。

$$ T^2 = c( \bf{X-m'} ) \bf{S}^{-1} ( \bf{X-m} )  . $$

定数 *c* は、共分散行列が推定された標本規模である。 

#### 簡単にグラフ化できる*T*<sup>2</sup>
*T*<sup>2</sup> 距離はグラフ表示に適しおり、その結果、*T*<sup>2</sup> 管理図は多変量管理図の中で最も広く利用されている。

**平均と共分散行列の推定**

#### 平均と共分散行列
$` \bf{X}_1,  \bf{X}_2,  \ldots,  \bf{X}_n `$ を $` N_p(\bf{m}, \bf{\Sigma}) `$ から独立に抽出された *n* *p* 次元の観測ベクトルとし、ここで $`p < n-1`$ であり、$`\bf{\Sigma}`$ は $`\bf{X}`$ の共分散行列であるとする。
観測された平均ベクトル $`\bf{\bar{X}}`$ および標本分散行列 

$$ \bf{S} = \frac{1}{n-1} \sum_{i=1}^n (\bf{X}_i - \bf{\bar{X}})(\bf{X}_i - \bf{\bar{X}})' $$

は、それぞれ $`\bf{m}`$ および $`\bf{\Sigma}`$ の不偏推定量である。
