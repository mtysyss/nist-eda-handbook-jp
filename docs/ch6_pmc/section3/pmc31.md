# 6.3.1. 管理図とは

#### 単変量と多変量の管理データの比較
管理図は品質を日常的に監視するために用いられる。
監視対象である工程特性数に応じて、管理図には2つの基本的な種類がある。
1つ目は、単変量管理図と呼ばれ、<u>1つの</u>品質特性をグラフ（図表）で表示したものである。
2つ目は、多変量管理図と呼ばれ、<u>複数の</u>品質特性を要約または表す統計量をグラフ化したものである。

#### 管理図の特徴
ある品質特性について標本から測定や計算された場合、管理図にはその品質特性の値と標本番号、あるいは時間の関係が示される。
一般的に管理図には管理下にある工程の平均値を表す中心線が引かれている。
また、上側管理限界（*UCL*）および下側管理限界（*LCL*）と呼ばれる2本の水平線も管理図上に示される。
これらの管理限界は、工程が管理状態にある限り、ほぼすべてのデータ点がこれらの限界内に収まるように設定されている。

#### 管理図が「機能する」理由
グラフに示されている管理限界は、0.001 *確率*限界のことがある。
もしそうであり、且つ偶然要因のみが存在する場合、データ点が上限を超える確率は千分の1となり、同様にデータ点が下限を下回る確率も千分の1となる。
もしデータ点がこれらの限界値の外側に位置する場合、我々は特定可能な原因を探さなければならない。
これらの限界値をどこに設定するかによって、実際には変動の特定可能な原因が存在しないにもかかわらず、そのような原因の探索を行うリスクが決まることになる。

千分の二というリスクは非常に小さいため、0.001 という限界値は、ある点がこれらの限界値の外側に位置する場合、そのばらつきが特定可能な原因によるものであるという実質的な保証を与えると言える。
なお、千分の二という数値は純粋に恣意的なものであることに留意しなければならない。
これを100分の1、あるいはそれ以上に設定しても何ら問題はない。
その決定は、品質管理施策の運営者がどの程度のリスクを許容するかに依存する。
一般に（品質管理の世界では）、0.002 という基準に近似した限界値を用いるのが通例である。
 
*X* を工程特性値とすると、偶然要因により系が *X* のばらつきを正規分布に従う形で生じさせる場合、0.001 の確率限界は 3σ限界値に非常に近くなる。
正規分布の表から、一方向の 3σは 0.00135、両方向では 0.0027であることが解る。
したがって、正規分布においては、3σ限界値は 0.001の確率限界値と実質的に同等である。 

#### 通常用いられる±「3シグマ」範囲
米国では、<u>*Xが*正規分布に従うか否かにかかわらず</u>、管理限界を標準偏差の倍数に基づいて設定することが一般的な慣行となっている。
通常、この倍率は 3であり、したがってこれらの限界は 3シグマ限界と呼ばれる。
この用語は、標準偏差が母集団の母数であるか、その推定値であるか、あるいは単に管理図作成のための「標準値」であるかにかかわらず使用される。
どの標準偏差が対象であるかは、文脈から推察すべきである。（なお英国では、統計学者は一般的に確率限界に従うことを好むことに留意されたい。）

もし基礎となる分布が、例えば正の方向に偏っている場合、3シグマの上限は 0.001の上限を下回り、3シグマの下限は 0.001限界を下回ることになる。
この状況は、実際には存在しない正のばらつきの帰属可能な原因を探してしまうリスクが、1,000分の1を超えることを意味する。
しかし、実際には存在しない負のばらつきの帰属可能な原因を探してしまうリスクは低減される。
そしてその結果として、管理限界を超えた偶然のばらつきのリスクは増加することになる。
このリスクがどの程度増加するかは、歪度の程度に依存する。

例えば、品質ばらつきが Poisson分布に従う場合、*np* = 0.8 であれば、3シグマ限界を使用することで、偶然に上限を超えるリスクは 0.001 から 0.009 に上昇し、下限は 0.001から 0.000に低下する。
Poisson分布では、平均と分散はいずれも *np* に等しくなる。
したがって、3シグマの上限は 0.8 + 3 *sqrt*(0.8) = 3.48 となり、下限は 0となる（ここで *sqrt*は「平方根」を表す）。
したがって、*np* = 0.8 の場合、3回以上の成功が得られる確率は 0.009 となる。 

#### 管理外れ所見に対処するための戦略
あるデータ点が管理限界の外側にある場合、その工程は管理外れの可能性が高いとみなされ、原因を特定して排除するための調査が必要であるとされます。

では、すべてのデータ点が管理限界内に収まっている場合、その工程は管理下にあるということになるか。
必ずしもそうとは限らない。
プロットが非無作為に見える場合、つまりデータ点に何らかの系統的な傾向が見られる場合は、依然として何か問題があることになる。
例えば、30個のデータ点のうち最初の 25個が中心線より上にあり、最後の 5個が中心線より下にある場合、なぜそうなるのかを知りたいと思うだろう。
連続したデータや非無作為なパターンを検出するための統計的手法は、管理図の解釈にも適用できる。
確かに、「管理下にある」とは、すべてのデータ点が管理限界の間にあり、かつ無作為なパターンを形成していることを意味する。
