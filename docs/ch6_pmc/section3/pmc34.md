# 6.3.4. 多変量管理図とは

#### 多変量管理図とHotelling の *T*<sup>2</sup> 統計量
ほとんどのデータは本来、多変量であるというのが現実である。
1947年、Hotelling は、多変量観測値のプロットに特に適した統計量を導入した。
この統計量は、その名もふさわしくHotelling の *T*<sup>2</sup> と呼ばれ、複数の変数の分散と平均からの情報を統合したスカラー量である。
計算に手間がかかり、非常に複雑で、行列代数の知識をある程度必要とするという事実から、産業界における多変量管理図の受入れは遅々として進まず、躊躇する傾向にあった。

#### 利用しやすくなった多変量管理図
今日では、コンピュータ全般、とりわけPCの普及により、複雑な計算が容易に行えるようになり、この10年間で多変量管理図がより注目されるようになった。
実際、Hotelling の *T*<sup>2</sup> 統計量を表示する多変量管理図は、非常に普及し、時にはシューハート管理図とも呼ばれることがある（例：Crosier, 1988）。
ただし、Shewhart 自身はこれらとは何の関係もなかった。

#### 平均値と分散の両方に関するHotelling 管理図
単変量の場合と同様に、データが群分けされている場合、*T*<sup>2</sup> 管理図は、分析対象のすべての特性について、各副群内変動の度合いを示す図と組み合わせる。
したがって、組み合わせた *T*<sup>2</sup> および $`T_d^2`$（分散）の組合せ管理図は、単変量解析における $`\bar{X}`$ および *S*（あるいは $`\bar{X}`$ および *R*）管理図の多変量版にあたる。

#### Hotelling 管理図例の解釈
各グラフは、4変数の平均値に関する 14回の連続測定結果を表している。
平均値の *T*<sup>2</sup> 管理図は、群1、2、および 9～11が管理外れ状態にあることを示している。
分散の $`T_d^2`$ 管理図は、群10、13、14も管理外れであることを示している。
このことから、多変量系に問題がある可能性が疑われる。
特定可能な原因を突き止めるには、個々の単変量管理図、あるいはこの多変量管理図と併せて用いるべき他の単変量手法に頼らなければならない。
