# 6.1.1. 統計的品質管理の始まり

#### 歴史的視点
品質管理は古くから存在している。
どれほど昔からか。
製造が始まり、それに伴い競争が生まれた時点で、消費者は製品を比較し、最も魅力的な製品を選ぶようになった（もちろん独占状態を除いて）と言っても過言ではない。
もし、メーカーA がメーカーB の利益が急増していることを発見したとき、前者は、おそらく製品の品質を向上させたり、値下げしたりすることで、自社の製品を改善しようと努めた。
品質の向上は必ずしも製品そのものに留まらず、製品を製造するための<u>工程</u>も含まれていた。

この過程は中世のギルドが示すように高く評価されていた。
これらのギルドは見習いに対して長期間の訓練を義務付け、熟練職人を目指す者は自らの能力の証明を示さなければならなかった。
このような手順は、一般的に、工程品質の維持および向上を目的としていた。

現代においては、食品医薬品局（FDA）や工場検査などの政府規制機関など、消費者に販売される製品の品質保証を目的とした専門団体がある。
<u>品質管理</u>はこのように長い歴史がある。

#### 比較的最近確立された統計学
一方、<u>統計的</u>品質管理は比較的新しい。
統計学そのものの歴史はわずか2～3世紀に過ぎない。
そして、その最大の進展は20世紀に起こった。
初期の応用は、天文学や物理学、そして生物科学や社会科学の分野で行われた。
1920年代になって初めて、標本抽出理論の発展に伴い、統計理論が品質管理に効果的に適用され始めた。

#### Walter Shewhart によって初めて提唱された製造における品質管理の概念
新たに発見された統計的手法を品質管理の問題に初めて応用したのは、ベル電話研究所の Walter A. Shewhart であった。
彼は1924年5月16日に、現代的な管理図のスケッチを掲載した覚書を発表した。

Shewhart はこの手法の改良と研究を続け、1931年には統計的品質管理に関する著書『製造製品の品質の経済的管理（*Economic Control of Quality of Manufactured Product*）』を、ニューヨークのヴァン・ノストランド社から出版した。
この著書は、その後の工程管理への統計的手法の応用の方向性を決定づけるものとなった。 

#### Dodge と Roming による抜取検査への貢献
ベル研究所の他の2人の統計学者、H.F. Dodge と H.G. Romig は、統計理論を抜き取り検査に応用する取組みを主導した。
これら3人の先駆者による研究は、今日の統計的品質管理理論の大部分を構成している。
統計的品質管理の歴史についてはまだまだ語るべきことが多くあるが、関心のある読者には、参考文献の1つまたは複数を一読いただきたい。
SQCの歴史的背景に関する非常に優れた要約は、Acheson J. Duncan著[『*Quality Control and IndustrialStatistics*』](../section7/pmc7.md#Duncan)の第1章に掲載されている。
また、[Juran（1997）](../section7/pmc7.md#Juran,%20J.)も参照のこと。
