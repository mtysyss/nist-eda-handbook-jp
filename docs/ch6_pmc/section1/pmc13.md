# 6.1.3. 工程管理とは

#### 介入の2つのタイプ――技術的判断に基づくものと自動化されたもの
工程管理とは、工程の監視結果に基づいて、工程を能動的に変更することである。
工程監視ツールが管理外れ状態を検知すると、工程担当者は工程を再び管理下に戻すための変更を行う。

1. <u>管理外れ対応計画</u>（OCAPS）は、管理外れ状態が検出されたときに講じるべき措置を詳細に定めたものである。
各工程ごとに、工程技術者が是正手順を順を追って実行できるよう具体的なフローチャートが用意される場合がある。

2. <u>高度な工程管理ループとは</u>、管理外れとなった測定値の大きさに応じて補正を行う、プログラムされた工程への自動的変更のことである。
