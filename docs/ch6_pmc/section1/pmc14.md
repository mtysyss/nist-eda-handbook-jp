# 6.1.4. 工程が「管理外れ」になった場合の対処法

#### 管理外れ状況に対する反応
工程が管理外となった場合、工程技術者は、管理図に関連付けられた管理外対応計画（OCAP）に従って、特定可能な原因を探す。
管理外れとは、現在のデータが、初期の管理図限界値を作成するために使用したデータと同じ母集団に由来するという仮定を棄却することを指す。

従来の Shewhart 管理図では、ウェスタン・エレクトリックの規則[（WECOルール）](../section3/pmc32.md#WECO%20rules)と呼ばれる一連の規則や、一連の[傾向規則](../section3/pmc32.md#Trend)が、管理外を判定するためによく用いられる。
