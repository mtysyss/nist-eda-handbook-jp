# 6.1.2. 工程管理技術とは

#### 代表的な工程管理技術
工程管理を実現する方法は数多くある。
主要な監視および調査ツールには、次のようなものがある。

* [ヒストグラム](../../ch1_eda/section3/eda33e.md)
* チェックシート
* パレート図
* 特製要因図
* 欠陥集中図
* [散布図](../../ch1_eda/section3/eda33q.md)
* [管理図](../section3/pmc3.md)

これらはすべて、Montgomery (2000) に解説されている。
本章では、（[第3節](../section3/pmc3.md)）管理図の手法、具体的には以下の点に焦点を当てる。

* [古典的シューハート管理図](../section3/pmc321.md)
* [累積和（CUSUM）管理図](../section3/pmc323.md)
* [指数加重移動平均（EWMA）管理図](../section3/pmc324.md)
* [多変量管理図](../section3/pmc34.md)

#### 基礎となる概念
統計的工程管理の背景にある概念は、現在の状況と過去の状況を比較することに基づいている。
工程の典型的な挙動をある特定時点の状態として捉えるか、あるいは工程がどのように動作すると予想されるかのモデルを構築し、工程の出力に対する期待値の測定値について管理限界を計算する。
その後、工程からデータを収集し、そのデータを管理限界と比較する。
測定値の大部分は管理限界内に収まるはずである。
管理限界の外側にある測定値については、それらが初期の特定時点の状態やモデルと同じ母集団に属するかどうかを調べる。
言い換えれば、過去のデータを用いて初期の管理限界を計算する。
その後、データをこれらの初期の管理限界と比較する。
管理限界の外側にあるデータ点は調査され、場合によっては後で除外されることもある。
その場合、管理限界が再計算され、この過程を繰り返す。
これをフェーズI と呼ぶ。
フェーズI の終了時に計算された管理限界を用いた即時工程監視がフェーズⅡである。

**統計的品質管理（SQC）**

#### 統計的品質管理ツール
すべての処理が完了した後、製品に欠陥や不良品がないかを調査するために、いくつかの手法を用いる。
SQC（[2節で説明](../section2/pmc2.md)）の代表的な手法には、次がある。

* ロット合否判定抜取計画
* スキップロット抜取計画
* 軍事（MIL）規格に基づく抜取計画

#### 統計的品質管理の基本概念
統計的品質管理の目的は、経費効率の良い方法で、顧客に出荷される製品がその仕様を満たしていることを保証することである。
すべての製品を検査することは経費がかかり非効率であるが、不適合製品を出荷した場合、顧客不満という点で重大な結果を招く可能性がある。
統計的品質管理とは、所定のロットから十分な数の製品を抜取検査し、確率的に所定の品質水準を保証する工程である。
