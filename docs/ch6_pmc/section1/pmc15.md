# 6.1.5. 「管理下」にあるが許容できない場合の対処法

#### 工程が予測可能であることを意味する管理下
「管理下にある」とは、その工程が統計的な意味で予測可能であることを意味するだけである。
もし、その工程が「管理下にある」にもかかわらず、平均水準が高すぎたり低すぎたり、あるいはばらつきが許容範囲を超えている場合は、どう対処すればよいか。

#### 工程改善技法
次のような工程改善技法

* [実験](../../ch5_pri/pri.md)  
* [校正](../../ch2_mpc/section3/mpc3.md)
* 履歴データベースの再分析

といった工程改善技法を導入し、目標値に工程を合わせたり、ばらつきを低減したりする。

#### 工程の安定
工程が安定して初めて、目標値を中心に調整したり、全体的なばらつきを低減したりすることが可能になることに留意する。
