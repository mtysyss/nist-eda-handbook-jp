#### 解釈
これらのデータの部分群分けのうち、どれが正しいか。
見て判る通り、部分群分けごとに異なるグラフを作成する。
答えの一部は、この工程の製造要求事項にある。
また、統計的に特定できるもう一つの側面は、各変動因子の大きさである。
データの構造や、各因子がどの程度のばらつきに寄与しているかを理解するためには、分散成分分析を行う必要がある。
このデータ集合に対する分散成分分析の結果を以下に示す。

| 成分 | 分散成分推定 |  
| :---: | :---: |  
| --- | --- |  
| カセット | 0.2645 |  
| ウェハ | 0.0500 |  
| 測定場所 | 0.1755 |  
{: .no-border-table} 


#### 分散成分の推定
利用するソフトウェアが分散成分を直接作成しない場合は、標準的な分散分析の出力結果から、[平均平方（MS）を期待平均平方（EMS）と等しく](../../ch7_prc/section4/prc44.md)することで、それらを計算する。

枝分れの無作為効果モデルにおける平方和および平均平方は、以下に示す通り。

```
                      Degrees of    Sum of
Source                 Freedom      Squares   Mean Squares
--------------------  ----------  ---------   ------------
Cassette                  29      127.40293      4.3932 
Wafer(Cassette)           60       25.52089      0.4253
Site(Cassette, Wafer)    360       63.17865      0.1755
```

カセット、カセット内のウェハ、カセットおよびウェーハ内の測定場所に対する期待平均平方値と、それらが対応する平均平方値は以下の通り。 

```
4.3932 = (3*5)*Var(cassettes) + 5*Var(wafer) + Var(site)
0.4253 = 5*Var(wafer) + Var(site)
0.1755 = Var(site)
```

これらの方程式を解くと、カセット、ウェハ、および測定場所について、それぞれ 0.2645、0.04997、0.1755 という分散成分の推定値が得られる。

本節の分析はすべて、[Rコード](https://www.itl.nist.gov/div898/handbook/pmc/section6/pmc613.r)を使用して実行可能である。
読者はデータを[テキストファイル](https://www.itl.nist.gov/div898/handbook/datasets/LITHOGRA.DAT)としてダウンロードできる。
