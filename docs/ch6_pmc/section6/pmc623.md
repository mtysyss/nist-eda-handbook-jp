# 6.6.2.3. モデルの推定

#### AR(2)モデルの係数推定値
差分データに基づき、AR(2)モデルについて以下の母数推定値を計算した。

```
             Parameter  Standard    95 % Confidence
Source        Estimate    Error         Interval
------       ---------  --------   ----------------
Intercept     -0.0050     0.0119 
AR1           -0.4064     0.0419   (-0.4884, -0.3243)
AR2           -0.1649     0.0419   (-0.2469, -0.0829) 

Number of Observations:                 558
Degrees of Freedom:           558 - 3 = 555  
Residual Standard Deviation:         0.4423
```

信頼区間にゼロが含まれていないことから、両方のAR係数は有意である。 

差分データ $` Y_t `$ に対するモデルは AR(2) モデルであり、

$$ Y_t = -0.4064 Y_{t-1} - 0.1649 Y_{t-2} - 0.0050  , $$

ここで、$` \sigma = 0.4423 `$ である。

多くの場合、差分データではなく、元のデータ $`X_t`$ を用いてモデルを表現するほうが便利である。
差分の定義 $`Y_t = X_t - X_{t-1}`$ から、上記の式に適切な置換を行うと、

$$ X_t - X_{t-1} = -0.4064 (X_{t-1} - X_{t-2}) - 0.1649 (X_{t-2} - X_{t-3}) - 0.0050  , $$

となり、元の時系列を用いた次式のモデルが得られる。

$$ X_t = 0.5936 X_{t-1} + 0.2415 X_{t-2} + 0.1649 X_{t-3} - 0.0050  . $$ 

#### MA(1)モデルの係数推定値
対照として、差分データに基づくMA(1)モデルの係数推定値は以下の通りである。
 
```
             Parameter  Standard    95 % Confidence
Source        Estimate    Error         Interval
------       ---------  --------   ----------------
Intercept     -0.0051     0.0114 
MA1           -0.3921     0.0366   (-0.4638, -0.3205)
 
Number of Observations:                 558
Degrees of Freedom:           558 - 2 = 556  
Residual Standard Deviation:         0.4434
```

差分データ $`Y_t`$ に対するモデルは、ARIMA(0,1,1) モデルであり、

$$ Y_t = a_t - 0.3921 a_{t-1} - 0.0051  , $$

ここで、$`\sigma = 0.4434`$ である。

多くの場合、差分データではなく、元のデータ $`X_t`$ を用いてモデルを表現するほうが便利である。
上記の式に適切な置換を行うと、

$$ X_t - X_{t-1} = a_{t} - 0.3921 a_{t-1} - 0.0051  , $$

となり、元の時系列を用いたモデルは次式となる。

$$ X_{t} = X_{t-1} + a_{t} - 0.3921 a_{t-1} - 0.0051  . $$
