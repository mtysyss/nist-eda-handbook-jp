# 6.6.2.2. モデルの同定

#### 定常性、外れ値、季節性の確認
分析の最初の手順では、応答変数の[実行シーケンス・プロット](../../ch1_eda/section3/eda33p.md)を作成する。
実行シーケンス・プロットから、[定常性](../section4/pmc442.md)（すなわち、位置と幅が一定であること）、外れ値の有無、および季節的なパターンが判る。

非定常性は、多くの場合、データに差分処理を施すか、何らかのトレンド曲線を当てはめることで除去できる。
その後、差分処理したデータ、あるいはトレンド曲線を当てはめた後の残差に対して、Box-Jenkinsモデルを当てはめることを試みる。

Box-Jenkinsモデルでは季節成分を推定できるが、分析者は季節周期を指定する必要がある（例えば、月次データの場合は12）。
季節成分は経済時系列ではよく見られるが、工学や科学のデータではあまり一般的ではない。 

#### 実行シーケンス・プロット

![Run sequenc plot of particle size](https://www.itl.nist.gov/div898/handbook/pmc/section6/negiz4/gif/runseqpl.gif)

#### 実行シーケンス・プロットの解釈
実行シーケンス・プロットから、以下の結論を導き出せる。

1. データには強い正の自己相関が見られる。

2. データには有意な傾向や明らかな季節的パターンは見られないようである。 

次の手順として、[自己相関プロット](../../ch1_eda/section3/eda331.md)を用いて標本の自己相関を調べる。

#### 自己相関プロット

![Autocorelation plot of the particel size data](https://www.itl.nist.gov/div898/handbook/pmc/section6/negiz4/gif/autocopl.gif)

#### 自己相関プロットの解釈
自己相関プロットには[95%信頼区間](../../ch1_eda/section3/eda331.md)が表示されており、これは、この工程が移動平均工程であるという仮定に基づいて作成されている。
自己相関プロットは、標本自己相関が非常に強い正の値を示し、その減衰が極めて緩やかであることが判る。

自己相関プロットは、この工程が非定常であることを示しており、ARIMAモデルの適用が示唆される。
次の手順ではデータに差分処理を施す。 

#### 差分データの実行シーケンス・プロット

![Run sequence plot of particle size after differencing](https://www.itl.nist.gov/div898/handbook/pmc/section6/negiz4/gif/runseqp2.gif)

#### 実行シーケンス・プロットの解釈
差分データの実行シーケンス・プロットを見ると、差分データの平均値はゼロ付近にあり、差分データは元のデータよりも自己相関が小さいことが判る。

次の手順として、差分データの標本自己相関を検証する。 

#### 差分データの自己相関プロット

![Autocorelation plot of the particle size data after differencing](https://www.itl.nist.gov/div898/handbook/pmc/section6/negiz4/gif/autocop2.gif)

#### 差分データの自己相関プロットの解釈
95%信頼区間を示した差分データの自己相関プロットは、ラグ1 における自己相関のみが有意であることが示されている。
自己相関プロットと差分データの実行シーケンスを併せて見ると、差分データは定常的であることが示唆される。
この自己相関プロットに基づき、差分データにはMA(1)モデルが示唆される。

他の可能性のあるモデルを検討するため、差分データの偏自己相関プロットを作成する。 

#### 差分データの偏自己相関プロット

![Partial autocorrelation plot of the particle size data after differencing](https://www.itl.nist.gov/div898/handbook/pmc/section6/negiz4/gif/partaupl.gif)

#### 差分データ偏自己相関プロットの解釈
差分データの偏自己相関プロットに 95%信頼区間を示すと、1次および2次ラグの偏自己相関のみが有意であることが判る。
これは、差分データに対してAR(2)モデルが適用可能であることを示唆している。

#### 赤池情報量基準（AIC および AICC）
AIC や AICC などの情報に基づく基準（[Brockwell and Davis (2002)、pp. 171-174](../section7/pmc7.md#Brockwell2)参照）を用いることで、適切なモデルの選択を自動化することができる。
時系列解析用の多くのソフトウェア・プログラムは、幅広いモデルについてAICやAICCを計算する。

モデル同定にどのような手法を用いるにせよ、選択されたモデルに対してはモデル診断を行うべきである。
本節の図に基づいて、ARIMA(2,1,0) および ARIMA(0,1,1) モデルについて詳細に検討する。
