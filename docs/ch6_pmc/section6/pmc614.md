# 6.6.1.4. Shewhart 管理図

#### 工程を監視するための適切な管理図の選定
このデータにおけるばらつきの最大の因子は、ロット間のばらつきである。
したがって、従来の Shewhart 法を用いる場合、部分群をロット以外のもので指定すると、既知のロット間のばらつきを無視することになり、すでに既知の特定可能な原因（データが異なるロットに由来すること）を持つ管理外れ点が検出される可能性がある。
しかし、リソグラフィ工程において最も関心のある測定値は、ロット平均ではなく測定場所水準の測定値である。
この一見矛盾しているように見える問題を、どのように解決すればよいか。

#### 変動因子を個別にグラフ化
一つの解決策は、重要なばらつきの因子を個別にグラフ化することである。
そうすれば、工程のばらつきを監視し、ばらつきの原因がどこにあるのか、またそれが変化しているかを真に理解できるようになる。
対象データ集合の場合、この手法では 2組の管理図が必要である。
1つは個別測定値用、もう1つはロット平均値用である。
これにより、この工程に必要な管理図の数が 2倍になる（線幅の管理図が 2枚ではなく 4枚になる）。

#### 変動因子の中で最も重要なもののみをグラフに示す
別の解決策としては、変動の最大因子について 1管理図を作成する方法である。
これは、ロット間の変動を監視するための管理図を 1組用意することを意味する。
製造の観点からは、これは受け入れがたいだろう。

#### 箱ひげ図の使用
個々のデータ値すべてをプロットし、ロットごとに[箱ひげ図](../../ch1_eda/section3/eda337.md)形式でグループ化する、非標準のグラフを作成することも可能である。
管理限界は、個々のデータ値を監視するために設定し、ロット間のばらつきについては、グループ化のパターンによって監視する。
ただし、ほとんどの現場管理システムにおいて、このような非標準的な管理図を導入するには、特別なプログラミングと管理部門の介入が必要となる。

#### 平均管理図の別形式
一般的に採用される解決策として、最初の選択肢、つまりこの工程について複数の管理図を作成する。
ロット平均の管理限界を設定する際には、ロット内の変動ではなく、ロット間の変動を使用するよう注意を払う必要がある。
その結果得られる管理図は、（前述の）標準個体値／移動範囲管理図と、以前のロット平均値管理図とは異なるロット平均値の管理図である。
この新しい管理図では、ロット内平均標準偏差の代わりに、ロット間のばらつきを用いて管理限界を計算する。
付随する標準偏差管理図は、前述のものと同じである。
