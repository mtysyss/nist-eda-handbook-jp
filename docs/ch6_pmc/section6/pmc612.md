# 6.6.1.2. データのグラフ表示

データ分析の最初の手順として、応答と、応答と多種の因子対の簡単ないくつかのプロットの作成を行う。

#### データの4-プロット

![4-plot of the response variable](https://www.itl.nist.gov/div898/handbook/pmc/section6/lithogra/gif/4plot.gif)

#### 通訳
この[4プロット](../../ch1_eda/section3/eda33w.md)は以下のことを示している。

1. [実行シーケンス・プロット](../../ch1_eda/section3/eda33p.md)（左上）は、位置と尺度が時間の経過とともに一定ではないことを示している。
これは、3つの因子が実際に何らかの影響を及ぼしていることを示唆している。

2. [遅延プロット](../../ch1_eda/section3/eda33f.md)（右上）は、データに軽度の自己相関が存在することを示している。
これは、データが3つの因子の論理的な順序（つまり、無作為ではない）でグループ化されており、実行シーケンス・プロットが因子の影響があることを示していることから、予想外のことではない。

3. [ヒストグラム](../../ch1_eda/section3/eda33e.md)（左下）からは、データの大部分が 1から 5の間に分布しており、データの中心が約2.2にあることが判る。

4. データの位置と尺度が一定ではなく、また自己相関が存在するため、[正規確率プロット](../../ch1_eda/section3/eda33l.md)（右下）に基づく分布の推論は意味をなさない。
 
実行シーケンス・プロットは、より詳細を示すために原寸大で表示されている。
さらに、データの数値的要約も作成している。

#### データの実行シーケンスプロット

![Run sequence plot of the response variable](https://www.itl.nist.gov/div898/handbook/pmc/section6/lithogra/gif/runseqpl.gif)

#### 数値要約

```
      標本規模       = 450
      平均          =   2.53228  
      中央          =   2.45334  
      最小          =   0.74655
      最大          =   5.16867
      範囲          =   4.42212
      標準偏差       =   0.69376  
      自己相関       =   0.60726
```

主に平均値と標準偏差に関心がある。
要約表から、平均値は 2.53、標準偏差は 0.69であることが判る。

#### 個々の因子に対する応答をプロットする
次の手順は、各因子ごとに応答値をプロットすることである。
比較のために、データの[散布図](../../ch1_eda/section3/eda33q.md)と[箱ひげ図](../../ch1_eda/section3/eda337.md)の両方を作成する。
散布図の方がより詳細な情報が得られる。
しかし、特にデータ点やグループ数が増えるにつれて、箱ひげ図の方が比較が分かりやすくなるのが一般的である。

#### 幅対カセットの散布図

![Plot of width versus cassette](https://www.itl.nist.gov/div898/handbook/pmc/section6/lithogra/gif/scatcass.gif)

#### 幅対カセットの箱ひげ図

![Box plot of width versus cassette](https://www.itl.nist.gov/div898/handbook/pmc/section6/lithogra/gif/boxpcass.gif)

#### 通訳
上記の散布図および箱ひげ図に基づいて、以下の結論を導き出せる。

1. 各種カセットの設置場所にはかなりのばらつきが見られる。
中央値は約1.7から4の範囲で変動している。
2. 尺度にも多少のばらつきが見られる。
3. 外れ値がいくつか見られる。

#### 幅対ウェハの散布図

![Scatter plot of width versus wafer](https://www.itl.nist.gov/div898/handbook/pmc/section6/lithogra/gif/scatwafe.gif)

#### 幅対ウェハの箱ひげ図

![Box plot of width versus wafer](https://www.itl.nist.gov/div898/handbook/pmc/section6/lithogra/gif/boxpwafe.gif)

#### 解釈
上記の散布図および箱ひげ図に基づいて、以下の結論を導き出せる。

1. 3枚のウェハの位置は比較的安定している。
2. 3枚のウェハの尺度は比較的安定している。
3. 高値側にいくつかの外れ値が見られる。
4. ウェハ因子を均質とみなすことは妥当である。

#### 幅対場所の散布図

![Scatter plot of width versus site](https://www.itl.nist.gov/div898/handbook/pmc/section6/lithogra/gif/scatsite.gif)

#### 幅対場所の箱ひげ図

![Box plot of width versus site](https://www.itl.nist.gov/div898/handbook/pmc/section6/lithogra/gif/boxpsite.gif)

#### 解釈
上記の散布図および箱ひげ図に基づいて、以下の結論を導き出せる。

1. 測定場所によって位置に多少のばらつきが見られる。
特に中央の測定点では、中央値が低い。
2. 各測定場所間で尺度は比較的一定である。
3. いくつかの外れ値が見られる。

#### DOE平均および標準偏差のプロット
[DOE平均プロット](../../ch1_eda/section3/eda33c.md)と[DOE標準偏差プロット](../../ch1_eda/section3/eda33d.md)を使用することで、因子の平均と標準偏差を併せて表示し、より的確に比較することができます。

#### DOE平均プロット

![DOE mean plot of response against 3 factor variables](https://www.itl.nist.gov/div898/handbook/pmc/section6/lithogra/gif/dexmean.gif)

#### DOE sd プロット

![DOE SD plot of response variable against 3 factor variables](https://www.itl.nist.gov/div898/handbook/pmc/section6/lithogra/gif/dexsd.gif)

#### まとめ
上記のグラフから、ロット間および測定場所間に差異があることが判る。
このデータ集合の部分群を作成するには、さまざまな方法がある。
各ロットを部分群とすることも、各ウェハを部分群とすることも、あるいは測定された各測定場所を部分群とすることもできる（各部分群にはデータ値が1つだけ含まれる）。

従来の Shewhart 平均管理図では、部分群内の平均標準偏差を用いて、平均管理図の管理限界を計算することを思い出す。
しかし、平均管理図では、部分群間の平均値間の変動を監視することになる。
連続処理の状況であれば問題はないが、バッチ処理環境で運用している場合にはこれが問題となる。

[6.6.1.3.節](../section6/pmc613.md)では、異なる部分群分けに基づいたさまざまな管理図について検討する。
