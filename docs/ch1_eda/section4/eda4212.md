# 1.4.2.1.2. グラフ出力と解釈

#### 目標
この分析の目的は、以下の3点である。  

1. 単変量モデル、  
<br>$$Y_{i} = C + E_{i}$$  
<br>が適切かつ妥当であるかを判断する。  
2. 「管理下にある」測定工程において、典型的な基礎となる仮定が有効であるかを判断する。
これらの仮定は次の通り。
    1. 無作為性  
    2. 固定された分布  
    3. 固定された位置をもつ分布  
    4. 固定された尺度の分布  
3. 信頼区間  
<br>$$\bar{Y} \pm 2s/\sqrt{N}$$  
<br>が適切かつ有効であるかを判断する。
ここで、$`s`$ $`は`$  元のデータの標準偏差である。 

#### データの4-プロット
![4-Plot of the Data](https://www.itl.nist.gov/div898/handbook/eda/section4/randn4p/gif/4plot.gif)  

#### 通訳
上記の図で、仮定が扱われる。  

1. [実行順序プロット](eda33p.md)（左上）は、データに時間の経過に伴う位置や尺度の有意な偏位がないことを示している。
また、実行順序プロットには明らかな外れ値は観られない。  
2. [遅延プロット](eda33f.md)（右上）からは、データに非無作為なパターンは認められない。  
3. [ヒストグラム](eda33l.md)（左下）は、データが適度に対称的であり、分布の端に著しい外れ値は観られず、       データが近似的に正規分布に従うと仮定することが妥当であることを示している。
4. [正規確率プロット](normprpl.md)（右下）は、正規性の仮定が実際に妥当であることを裏付けている。

上記のプロットから、基礎となる仮定は有効であり、データはほぼ正規分布に従うと結論付ける。
したがって、先に示した信頼区間の形式は、母平均の不確かさを定量化するのに適切である。
このモデルの数値結果は、「[定量出力と解釈](eda4213.md#モデル)」の節に記載されている。
