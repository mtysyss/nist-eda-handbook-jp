# 1.4.2.5.2. 基礎となる仮定の検定

#### 目的
この分析の目的は、以下の3点である。  

1. 単変量モデル、  
<br>$$Y_{i} = C + E_{i}$$  
<br>が適切かつ妥当であるかを判断する。  
2. 「管理下にある」測定工程において、典型的な基礎となる仮定が有効であるかを判断する。
これらの仮定は次の通り。
    1. 無作為性  
    2. 固定された分布  
    3. 固定された位置をもつ分布  
    4. 固定された尺度の分布  
3. 信頼区間  
<br>$$\bar{Y} \pm 2s/\sqrt{N}$$  
<br>が適切かつ有効であるかを判断する。
ここで、$`s`$ は 元のデータの標準偏差である。 

#### データの 4-プロット
![4-plot of data](https://www.itl.nist.gov/div898/handbook/eda/section4/lew/gif/4plot.gif)  

#### 解釈
上記の図で、仮定が扱われる。  

1. [実行順序プロット](../section3/eda33p.md)（左上）は、データが時間の経過とともに位置やスケールにおいて顕著な変化を示していないことを示している。
2. [遅延プロット](../section3/eda33f.md)（右上）は、データが無作為ではないことを示している。
また、遅延プロットからは、いくつかの外れ値が存在することも示唆されている。
3. このように無作為性の仮定に著しく違反している場合、データの分布を決定する時にはデータが無作為である場合のみに意味があるため、[ヒストグラム](../section3/eda33e.md)（左下）および[正規確率プロット](../section3/eda33l.md)（右下）は考慮しない。

上記のプロットから、基礎となる無作為性の仮定は成立しないという結論が導かれる。
したがって、モデル、

$$Y_i=C+E_i$$  

は適切ではない。

より適切なモデルを構築する必要がある。
非無作為なデータは、[時系列](/pmc/section4/pmc4.md)の方法論を用いてモデル化できる場合が多い。
具体的には、遅延プロットに見られる円形のパターンは、正弦波モデルが適切である可能性を示唆している。
正弦波モデルについては、次節で詳述する。 

#### 個々のプロット
より詳細な情報を得るために、各プロットを個別に作成する。
この場合、分布のプロットは意味をなさないため、実行順序プロットと遅延プロットのみを描画する。

#### 実行順序プロット
![run sequence plot](https://www.itl.nist.gov/div898/handbook/eda/section4/lew/gif/runseq.gif)  

#### 遅延プロット
![lag plot](https://www.itl.nist.gov/div898/handbook/eda/section4/lew/gif/lagplot.gif)  

外れ値を明確に区別するために、プロット上に線と四角形を描いた。
遅延プロットによると、以下のデータ点が外れ値に見える。

```
INDEX         Y(i-1)           Y(i)   

  158        -506.00         300.00
  157         300.00         201.00
    3         -15.00         -35.00
    5         115.00         141.00
```

つまり、3番目、5番目、157番目、および158番目の点が外れ値に見える。 

#### 自己相関プロット
遅延プロットで有意な非無作為性が示された場合、[自己相関プロット](../section3/eda331.md)を確認するのが良い。  

![autocorrelation plot](https://www.itl.nist.gov/div898/handbook/eda/section4/lew/gif/autocorr.gif)  
 
この自己相関プロットには、明確な周期的なパターンが見られる。
遅延プロットと同様に、これは正弦波モデルを示唆している。 

#### スペクトル図
非無作為データにおいて、もう1つ有用なプロットとして[スペクトル図](../section3/eda33r.md)がある。

![spectral plot ](https://www.itl.nist.gov/div898/handbook/eda/section4/lew/gif/spectrum.gif)  

このスペクトル図では、周波数 0.3 に単一の主ピークが確認できる。
この周波数 0.3 は、次節で正弦波モデルを適合させるときに利用する。 

#### 定量的結果
遅延プロット、自己相関プロット、およびスペクトル図は、無作為性仮定に違反していることを明確に示しているが、これらのグラフに加え、いくつかの定量的指標も示す。

#### 要約統計量
分析の第一段階として、データから記述統計量を計算した。

```
      Sample size  =  200
      Mean         = -177.4350
      Median       = -162.0000  
      Minimum      = -579.0000  
      Maximum      =  300.0000 
      Range        =  879.0000
      Stan. Dev.   =  277.3322
```

#### 位置
時間の経過に伴う位置の変化を定量化する一つの方法は、観測値数 N を表すインデックス変数 $`X = 1, 2, ..., N`$ を用いて、データ集合に[直線近似](../../pmd/section1/pmd141.md)することである。
位置に有意な偏位がない場合、傾き母数はゼロとなるはずである。

```
      Coefficient     Estimate     Stan. Error   t-Value
          A0          -178.175         39.47      -4.514
          A1         0.7366E-02         0.34       0.022
 
      Residual Standard Deviation = 278.0313
      Residual Degrees of Freedom = 198
```

傾き母数 A1 の傾き母数の[$`t`$ 値](../pmd/section4/pmd43.md)は 0.022 であり、これは統計的に有意ではない。
これは、傾きが実際にはゼロと見なせることを示している。

#### ばらつき
ばらつきの変化を検出する簡単な方法の一つは、データ集合をいくつかの等しい大きさの区間に分割した後、[Bartlett 検定](../section3/eda357.md)を行うことである。
しかし、このデータの非無作為性から正規性を仮定できないため、代わりに[Levene 検定](../section3/eda358.md)を使用する。
具体的には、平均値ではなく中央値に基づくLevene 検定を使用する。
区間の数はある程度恣意的に決めることができるが、4 または 8 が妥当な値である。

```
      H0:  σ12 = σ22 = σ32 = σ42 
      Ha:  At least one σi2 is not equal to the others.

      Test statistic:  W = 0.09378
      Degrees of freedom:  k - 1 = 3
      Sample size:  N = 200
      Significance level:  α = 0.05
      Critical value:  Fα,k-1,N-k = 2.651
      Critical region:  Reject H0 if W > 2.651
```

この事例では、Levene 検定の結果、検定統計量 0.9378 が境界値 2.651 を下回っていることから、4区間における分散に有意な差はないことを示している。

#### 無作為性
[連検定](../section3/eda35d.md)は、データの無作為性を検証するために用いられる。

```
      H0:  the sequence was produced in a random manner
      Ha:  the sequence was not produced in a random manner  

      Test statistic:  Z = 2.6938
      Significance level:  α = 0.05
      Critical value:  Z1-α/2 = 1.96 
      Critical region:  Reject H0 if |Z| > 1.96
```

検定統計量の絶対値は、5％有意水準における棄却値よりも大きいため、データは無作為ではないと結論付ける。

#### 分布の仮定
定量的検定の結果、一定尺度および非無作為性の仮定が満たされないことが示されたため、分布の指標は意味をなさない。
したがって、これらの定量検定は省略する。
