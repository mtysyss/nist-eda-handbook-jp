# 1.4.2.10.4. 試験所効果の分析

#### 箱ひげ図
次に、試験所効果の有無を確認する。
まず、試験所ごとのセラミック強度について箱ひげ図を作成する。

![Box Plot](https://www.itl.nist.gov/div898/handbook/eda/section4/jahanmi2/gif/boxplotl.gif)  

この[箱ひげ図](../section3/eda337.md)は、以下のことを示している。

1. 8つの試験所の中央値には、わずかなばらつきが観られる。
2. 各試験所の測定基準は比較的安定している。
3. 2つの試験所（3番と5番）には、低い側に外れ値が観られる。 

#### バッチ1 の箱ひげ図
前項で明確なバッチ効果が確認されたことを踏まえ、次の手順として、2つのバッチそれぞれ個別に箱ひげ図を作成する。

![Box Plot for Batch 1](https://www.itl.nist.gov/div898/handbook/eda/section4/jahanmi2/gif/boxpltl1.gif)  

この[箱ひげ図](../section3/eda337.md)は、以下のことを示している。

1. 各試験所の中央値は 650 から 700 の範囲にある。  
2. 各試験所間で変動幅は比較的一定である。  
3. 各試験所には、低い側に少なくとも1つの外れ値がある。  

#### バッチ2 の箱ひげ図
![Box Plot for Batch 2](https://www.itl.nist.gov/div898/handbook/eda/section4/jahanmi2/gif/boxpltl2.gif)  

この[箱ひげ図](../section3/eda337.md)は、以下のことを示している。

1. 中央値は 550 から 600 の範囲にある。
2. バッチ1 と比較して、バッチ2 の方が研究所間でばらつきがやや大きくなっている。
3. 8つの試験所のうち6つで、高い側に外れ値が観られる。
また、3つの試験所で低い側に外れ値が観られる。 

#### 結論
上記の箱ひげ図から、試験所効果の可能性について以下の結論を導き出すことができる。

1. 測定地点におけるバッチ効果（約75～100単位）が、いかなる検査室効果よりも支配的である。  
2. 各試験所を等価であるとみなすことは妥当である。
