# 1.4.2.10.2. 応答変数の分析

#### 数値要約
分析の第一段階として、応答変数について一般的な要約統計量を計算する。

```
      Sample size  =   480
      Mean         =   650.0773
      Median       =   646.6275  
      Minimum      =   345.2940  
      Maximum      =   821.6540  
      Range        =   476.3600  
      Stan. Dev.   =    74.6383
```

#### 4-プロット
次の手順は、応答変数の[4-プロット](../section3/eda33w.md)の作成である。

![4-plot of the response variable](https://www.itl.nist.gov/div898/handbook/eda/section4/jahanmi2/gif/4plot.gif)  

この[4-プロット](../section3/eda33w.md)からは以下のことが判る。

1. [実行順序プロット](../section3/eda33p.md)（左上隅）は位置と尺度が比較的一定であることを示している。
また、低値側にいくつかの外れ値が観られる。
ほとんどのデータ点は 500 から 750 の範囲にある。
しかし、300 から 450 の範囲に、特に注意を要する約6つのデータ点がある。
<br>
実行順序プロットは、時間効果を明らかにできるという点で、実験計画において有用である。
通常、時間は妨害因子である。
つまり、実験の実施順序が応答に有意な影響を与えてはいけない。
もし時間効果が存在するように見える場合、これは実験に潜在的なバイアスが存在することを意味し、調査して解決する必要がある。
2. [遅延プロット](../section3/eda33f.md)（右上隅）には、有意な構造は観られない。
これは、時間効果の可能性を検出するためのもう一つのツールである。
3. [ヒストグラム](../section3/eda33e.md)（左下隅）を見ると、応答は概ね対称的であるが、二峰性分布を示している。
4. [正規確率プロット](../section3/eda33l.md)（右下隅）にはある程度の曲率が示されており、正規分布以外の分布の方がより良い適合を示す可能性があることを示唆している。
