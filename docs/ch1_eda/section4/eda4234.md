# 1.4.2.3.4. 新しいモデルの検証

#### 元データと予測値のプロット
[モデルを検証](../pmd/section4/pmd44.md)する最初の手順は、推定結果と元データをプロットすることである。  

![plot of predicted values with the original data](https://www.itl.nist.gov/div898/handbook/eda/section4/randwalk/gif/plotpred.gif) 
 
このプロットは、妥当な良い適合を示している。 

#### 残差での基礎となる仮定の検証
予測値のプロットに加え、推定値からの残差の標準偏差もこのモデルの大きな改善を示している。
次の手順は、このモデルにおける誤差成分、すなわち[残差](../pmd/section4/pmd44.md)に関する基礎となる仮定を検証することである。

#### 残差の4-プロット
![4-Plot of residuals](https://www.itl.nist.gov/div898/handbook/eda/section4/randwalk/gif/4plotres.gif)  

#### 解釈
上記の図で、仮定が扱われる。

1. [実行順序プロット](../section3/eda33p.md)（左上）は、時間の経過に伴う位置や尺度の有意な変化がないことを示している。
2. [遅延プロット](../section3/eda33f.md)（右上）は無作為な外観を示している。
3. [ヒストグラム](../section3/eda33l.md)は比較的平坦な形状を示している。
これは、誤差成分（または残差）に対して、一様確率分布が適切なモデルとなり得ることを示唆している。
4. [正規確率](../section3/eda33l.md)プロットからは、正規分布が誤差成分の適切なモデルではないことが明確に示されている。

一様確率プロットを使用し、一様分布が誤差成分の適切なモデルとなり得るかをさらに検証する。

#### 残差の一様確率プロット
![uniform probability plot of residuals](https://www.itl.nist.gov/div898/handbook/eda/section4/randwalk/gif/unifprpl.gif)  

[一様確率プロット](../section3/eda33m.md)が直線近いことから、一様分布が誤差成分の適切なモデルであることを裏付けている。 

#### 結論
我々のモデルの残差は基礎となる仮定を満たしているため、次のように結論付ける。

$$Y_{i} = 0.0502 + 0.987*Y_{i-1} + E_{i}$$

ここで、$`E_i`$ は一様分布がこのデータ集合に対する適切なモデルであると結論付ける。

このモデルは次式に簡略化できる。

$$Y_{i} = 1.0*Y_{i-1} + E_{i}$$

これには単純さという利点がある（現在の点は単に前の点に一様分布に従う誤差項を加えたものである）。

#### 科学および工学の知識の活用
この事例では、ランダム・ウォークの定義に基づくと、上記のモデルは妥当である。
すなわち、ランダム・ウォークとは、一様分布に従うデータ点の累積和である。
現在の点を前の点に一様分布に従う誤差項を加えたものとしてモデル化することが、現時点で可能な最善の方法であるというのは理にかなっている。
この事例では、データの構築方法が分かっているという点でやや人為的ではあるが、データ生成過程に関する科学的・工学的知見をデータのモデル化や検証に活用することは、一般的かつ望ましいことである。
多くの場合、対立する複数のモデルからほぼ同等の数学的結果を得ることがある。
この場合、その過程に対する科学的理解に最もよく近似するモデルを選択することが、合理的な選択である。

#### 時系列モデル
このモデルは時系列モデルの例である。
時系列に関するより詳細な説明は、[プロセス監視](../../pmc/section4/pmc4.md)の章に記載されている。
