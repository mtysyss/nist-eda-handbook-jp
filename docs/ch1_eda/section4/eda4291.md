# 1.4.2.9.1. 背景とデータ

#### 作成
このデータ集合は、[BirnbaumとSaunders（1958）](eda43.md#Birnbaum)が報告した、最大応力 21,000 psi（ポンド毎平方インチ）の周期的な荷重を受けた 6061-T6 アルミニウム板の矩形試験片の疲労寿命（破断までのサイクル数：千サイクル単位）の測定値で構成されている。

#### 分析の目的
本事例研究の目的は、いくつかの妥当な選択肢の中から、得られた耐用年数の測定値のばらつきを記述するための確率モデルを選択することである。

統計的信頼性解析の分野における当初の研究は、時間的に変動する荷重を受ける材料の破損時期の予測を扱っていた。
特定の静的荷重に耐えるよう設計された構造物であっても、動的荷重下では予想よりも早く破損する可能性があることはよく知られていた。

耐用年数の確率分布に関する現実的なモデルが見つかれば、それを用いて、使用中に故障確率が許容可能な最大値（例えば0.1％）を超えないようにするために、部品や構造物をいつ交換する必要があるかを推定することができる。

本eハンドブックの[製品信頼性評価](../../apr/apr.md)の章には、信頼性解析で使用される統計的方法に関する追加資料を収録している。
この事例研究は、そのような解析モデル選択段階におけるグラフやその他の技法の使用例を示すことで、当該章を補完することを目的としている。

特定のモデルを採用する説得力のある理由がない場合、あるいは検討中のどのモデルも目的に適していないと思われる場合、許容限界や信頼区間を計算するなど、ノンパラメトリックな統計的方法を選択することがある。

ノンパラメトリック法は、いくつかの調整可能な母数の値まで完全に指定された特定の確率分布からのデータ標本であるという仮定に依存しない。
例えば、ガウス確率分布は、2つの調整可能な母数を持つパラメトリック・モデルである。

ノンパラメトリック法を使用する際の代償は、効率性の低下である。
つまり、適用可能な場合、パラメトリック法に比べて、統計的推論のためにより多くのデータが必要になる可能性がある。
例えば、モデル母数に対するノンパラメトリックによる信頼区間は、基礎となる分布が正しく特定できた場合に必要となる信頼区間よりも、かなり広くなることがある。
そのような特定こそが、この事例研究で我々が試みるものである。

なお、この事例研究後の展開で強調することになるが、モデルを選択するという行為そのものが、選択が行われた後に導き出される結論の不確かさにしばしば大きく寄与している点に留意すべきである。
