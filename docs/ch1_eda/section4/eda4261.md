# 1.4.2.6.1. 背景とデータ

#### 作成
このデータ集合は、1970年代にNISTの化学者 Radu Mavrodineaunu が、フィルター透過率実験用の自動データ収集システムから収集したものである。
応答変数は透過率である。

このデータ集合を研究する動機は、比較的小さなデータ集合に潜む自己相関構造が、いかにして科学者が自身の自動データ収集システムの問題を検出するのに役立ったかを示すことである。 

#### ソフトウェア
本事例研究で使用された分析は、[Dataplotコード](https://www.itl.nist.gov/div898/handbook/eda/section4/eda4263.dp)と[Rコード](https://www.itl.nist.gov/div898/handbook/eda/section4/eda4263.r)の両方を使用して出力する 。
読者は、[データをテキスト・ファイルとして](https://www.itl.nist.gov/div898/handbook/datasets/MAVRO.DAT)ダウンロードできる。
