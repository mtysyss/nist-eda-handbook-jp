# 1.4.2.3.3. より優れたモデルの構築

#### 遅延プロットによるより優れたモデルの示唆
基礎となる仮定が成り立たなかったため、より優れたモデルを構築する必要がある。

遅延プロットには明確な線形パターンが観られた。
遅延プロットの定義、$`Y_i`$ 対 $`Y_{i-1}`$ から、有力なモデル候補は以下の形式である。
$$Y_{i}=A_0+A_1*Y_{i-1}+E_{i}$$  

#### 出力の近似
このモデルの[線形近似](../ch4_pmd/section1/pmd141.md)の結果、以下の結果が得られた。

```
    Coefficient    Estimate     Stan. Error   t-Value
        A0         0.050165      0.024171       2.075
        A1         0.987087      0.006313     156.350 
 
    Residual Standard Deviation = 0.2931      
    Residual Degrees of Freedom = 497
```

傾き母数 $`A_1`$ の[t 値](../ch4_pmd/section4/pmd43.md)は 156.350 であり、統計的に有意である。
また、残差の標準偏差は 0.2931 である。
これを[要約表に示されている](eda4232.md#要約統計量)標準偏差 2.078675 と比較する。
つまり、自己回帰モデルへの適合により、変動が 7分の1 に減少したことになる。 

#### 時系列モデル
このモデルは時系列モデルの例である。
時系列に関するより詳細な説明は、[工程監視](../../pmc/section4/pmc4.md)の章に記載されている。
