# 1.4.2.9.2. グラフ出力と解釈

#### 目的
本解析の目的は、[[1.4.2.9.1]](eda4291.md)に記載されているアルミニウム合金試験片疲労寿命の測定値ばらつきを記述するために、確率モデルをいくつかの妥当な候補の中から選定することである。

#### データの初期プロット
単純な図表は、データの位置や広がりに関する情報を提供し、異常値や特定のパターン（例えば塊）を検出するのに非常に有用である。
これには、ドット・チャート、箱ひげ図、ヒストグラムなどが含まれる。
効果的なヒストグラムを作成するには区間幅の選択が必要であり、この選択が結果に大きな影響を与える可能性があり、基礎となる確率密度のノンパラメトリック推定値を検証することが望ましいことがある。

![initial plots](https://www.itl.nist.gov/div898/handbook/eda/section4/eda4292_r01.gif)  

これらいくつかのプロットは、測定値が 350,000 をわずかに上回る値から 2,500,000 サイクルをわずかに下回る範囲にあることを様々な形で示している。
箱ひげ図からは、最大測定値が外れ値である可能性を示唆している。

推奨される最初の手順は、データとそのデータが特定の確率分布からの標本である場合に予想される結果との整合性を確認することである。
材料の基礎的な特性や関連する工業工程に関する知識は、通常、検討すべきモデルに関する手がかりを提供する。
この探索段階では、図診断技法が非常に有用である。
単変量データにおいて、これらの中でも最も重要なのが、分位数-分位数プロット、すなわちQQプロットである（[Wilk and Gnanadesikan, 1968](eda43.md#Wilk)）。

QQプロットでは、各データ点が1つの点として表される。
これら各点の縦軸はデータ値の一つである。
もしこのデータ値が標本中の *k* 番目の順位統計量（すなわち、*k* 番目に大きい値）である場合、対応する横軸は、特定の分布から抽出された、当該データと同じ規模の標本において、*k* 番目に大きい値が持つべき「典型」値である。
*F* を累積確率分布関数とし、標本が *n* 個の値から成る場合、$`F^{-1} [(k-1/2)/(n+1/2)]`$ はその「典型」値として妥当な選択となる。
なぜなら、これはこの分布から得られた標本規模 *n* の標本における *k* 番目の順序統計量中央値の近似値だからである。

次の図は、ガウス（もしくは、正規）確率分布に対する本データの QQプロットを示している。
もしデータが期待値と完全に一致していれば、すべての点は直線上に並ぶことになる。

![normal probability plot](https://www.itl.nist.gov/div898/handbook/eda/section4/eda4292_r02.gif)  

実際には、このような完全な一致からの逸脱が、標本抽出に伴う自然なばらつきの範囲内にあるかを判断する必要がある。
これは、対象分布から抽出した各標本のQQプロットがいかに変動し得るかを検討することで容易に判断できる。

次の図は、データの QQプロットに重ねて、データと同じ規模で、データと同じ平均値と標準偏差を持つガウス分布から抽出した 標本 99個の QQプロットを示している。

![plot of samples from data](https://www.itl.nist.gov/div898/handbook/eda/section4/eda4292_r03.gif)  

ガウス分布から得られた標本 99個に対応する QQプロットの群が、データの QQプロットを事実上覆っているという事実は、データがガウス・モデルと一致しない確率が 100分の1 より小さいことを示唆している。

もちろん、どんなに稀な事象であっても起こり得るからこれは何も証明するものではない。
しかし、一般的な目的においては、これが許容できる適合度を示すものと一般的に受け止められている。
いずれにせよ、別のモデルの方がさらに良い適合度を示すのではないか、と自然に疑問に思うかもしれない。

データの出所、すなわちそれらが材料の強度を表していることを踏まえ、信頼性に関する多くの研究においてガウス・モデルよりも非ガウスモデルの方がより適切である傾向があるため、代替モデルを検討すべきであるという強い示唆が得られる。
 

#### 分布候補
このデータのモデル候補として、合理的に考えられる確率分布は数多くある。
しかし、信頼性研究において有用であることが実証されていることから、以下の分布に限定して検討する。

* [正規分布](../section3/eda3661.md)  
* [ガンマ分布](../section3/eda366b.md)
* Birnbaum-Saunders 分布
* [3母数 Weibull 分布](../section3/eda3668.md)

#### 手法
非常に単純な手法としては、検討対象となっているモデル候補のデータの QQプロットを比較する方法が挙げられる。
これには通常、まずデータにモデルを適合させる作業が含まれる。
例えば、最尤法[[1.3.6.5.2]](../section3/eda3652.md)を用いることが挙げられる。

最尤推定量は以下の通り。

* ガウス分布：平均 1401、標準偏差 389  
* ガンマ分布：形状 11.85、比率 0.00846  
* Birnbaum-Saunders 分布：形状 0.310、尺度 1337  
* 3母数 Weibull分布：位置 181、形状 3.43、尺度 1357  

次の図は、4つの分布の最適適合確率密度が、ノンパラメトリックな確率密度推定値をどの程度近似しているか（あるいは離れているか）を示している。
ただし、この比較では、標本規模がかなり小さい（測定値 101個）という事実も、適合モデル自体が、ノンパラメトリック推定値が導出されたのと同じデータから推定されているという事実も考慮されていない。

![density curves](https://www.itl.nist.gov/div898/handbook/eda/section4/eda4292_r04.gif)  

こうした制約はあるものの、以下に示す対応する QQプロットを検討する価値はある。
これによると、ガウス分布と3母数 Weibull 分布が最適なモデルであることが示唆される。

![QQ-plots](https://www.itl.nist.gov/div898/handbook/eda/section4/eda4292_r05.gif)  

#### モデルの選択
代替モデルの利点をより慎重に比較するにあたって、3母数 Weibull モデルが（まさに 3つの母数を持つがゆえに）、調整可能な母数が 2つしかない他のモデルよりも、本質的に柔軟性が高い可能性があるという事実を考慮に入れる必要がある。

形式的な比較に 2つの基準を用いることができる。
すなわち、赤池情報量基準（AIC）とベイズ情報量基準（BIC）である（[Hastie et al., 2001](eda43.md#Hastie)）。
いずれのモデル選択基準の値も小さいほど、そのモデルは優れている。 

```
      AIC  BIC
 GAU 1495 1501
 GAM 1499 1504
 BS  1507 1512
 WEI 1498 1505
```

この基準に基づき（かつAICとBICの両方に従えば）、ガウス・モデルを他の 3つのいずれかに置き換える説得力のある理由は見当たらない。
BICの値は、データが各モデルをどの程度強く支持しているかという問いに対する近似的な答えを導き出すのにも利用できる。
これを行うには、ベイズ統計手法の適用が必要となる[[8.1.10]](../../apr/section1/apr1a.md)。

まず、4つのモデルすべてに等しい確率を *事前の* 割当てとして設定するが、これは当初の段階ではいずれかのモデルを他より優先する理由がないことを示しており、その後、測定された寿命の値に基づいてこれらの確率を更新する。
4つのモデルの更新された、*事後確率* と呼ばれる確率は、おおよそ $`exp(-BIC(GAU)/2)`$、$`exp(-BIC(GAM)/2)`$、$`exp(-BIC(BS)/2)`$、および $`exp(-BIC(WEI)/2)`$ に比例する。
その値は、GAUが 76％、GAMが 16％、BSが 0.27％、WEIが 7.4％である。

選択されたモデルの1つの用途に、故障確率が許容可能な最大値、例えば 0.1% を超えないことを保証するために、部品や構造物を交換すべき稼働年数を求めることが挙げられる。
この問いに対する答えは、推定分布の 0.1 百分位数、すなわち $`G^{-1}(0.001) = 198,000`$ サイクルとなり、ここで、この事例では $`G^{-1}~$ は推定されたガウス確率分布の逆関数を表す。

この推定値の不確かさを評価するために、統計的ブートストラップ法[[1.3.3.4]](../section3/eda334.md)を用いる。
この事例では、データから十分多くのブートストラップ標本を抽出し、それぞれに対して前述のモデル適合およびモデル選択の手順を適用し、最終的に最良モデル（これは標本ごとに異なる可能性がある）について $`G^{-1}(0.001)`$ を計算する。

ブートストラップ標本規模はデータと同じとし、各標本はデータから *置換* ありで一様無作為抽出されるべきである。
5,000個のブートストラップ標本に基づくこの処理により、0.1百分位数に対する 95％信頼区間は 4万～ 36万6千サイクルという範囲となった。
測定値がわずか 101個しか含まれていないサンプルに基づいて、99.9％の確率で超えられる最大値を推定しようとしていることを考えれば、この大きな不確かさは驚くべきことではない。 

#### 予測区間
この解析におけるもう一つの用途は、アルミニウム合金試験片の疲労寿命に関する予測区間を評価することである。
例えば、同じ工程を用いて 3つの新しい試験片を試験する場合、これら 3つの試験片について（ 95％の信頼度で）最小サイクル数を把握したいと考える。
つまり、将来、3つの試験片すべての疲労寿命を 95％の信頼度で包含する統計的区間 $`[L, ∞]`$ を求めなければならない。
ここで、*L* は将来の 3つの試験片すべての疲労寿命を 95％の信頼度で包含する統計的区間である。
求める区間は、片側下限 95％予測区間である。
*L* を構築するための係数の表は正規分布モデルについて広く入手可能であり、ここでは説明のために正規分布モデルに対応する結果を用いる。
具体的には、*L* は次式で計算される。

$$L = \bar{x} + r s$$  

$$L = 1400.91 - 2.16 * 391.32 = 555.66 \text{サイクル} × 1000$$  

ここで、係数 *r* は[Hahn and Meeker (1991)](eda43.md#Hahn)の表 A.14 に与えられた値か、[R プログラム](https://www.itl.nist.gov/div898/handbook/eda/section4/eda4292_rcode.r)から求めることができる。
