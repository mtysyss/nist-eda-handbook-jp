# 1.4.2.2.3. 定量出力と解釈

#### 要約統計量
分析の第一段階として、データから一般的な要約統計量を計算する。

```
    Sample size  = 500      
    Mean         =   0.5078304      
    Median       =   0.5183650      
    Minimum      =   0.0024900        
    Maximum      =   0.9970800        
    Range        =   0.9945900      
    Stan. Dev.   =   0.2943252
```

データのグラフから、データが正規分布に従っていない可能性があることが示唆されるため、データに対してさらに2つの統計量、すなわち正規PPCCと一様PPCCも計算する。

```
    Normal PPCC  =   0.9771602       
    Uniform PPCC =   0.9995682
```

一様[確率プロット相関係数](../section3/eda33n.md)（PPCC）の値は、正規PPCC値よりも大きくなっている。
これは、一様分布が正規分布よりもこれらのデータによく適合していることを示している。

#### 位置
時間の経過に伴う位置の変化を定量化する一つの方法は、回帰分析においてインデックス変数を独立変数として用いて、データを[直線近似](../pmd/section1/pmd141.md)することである。
本データについては、データが連続した実行順序で記録されており、等間隔の時間間隔で収集されたものと仮定する。
回帰分析では、インデックス変数 X = 1, 2, ..., N を使用する。
ここで N は観測値の数である。
時間の経過に伴う位置の有意な偏位がない場合、傾きの母数はゼロとなるはずである。

```
    Coefficient     Estimate     Stan. Error   t-Value   
          B0        0.522923        0.2638E-01    19.82
          B1       -0.602478E-04    0.9125E-04    -0.66

      Residual Standard Deviation = 0.2944917
      Residual Degrees of Freedom = 498
```

傾き母数の[$`t`$-値](../pmd/section4/pmd43.md) -0.66 は、境界値 $`t_{0.975,498}=1.96`$ より小さい。
したがって、有意水準 0.05 において、傾きはゼロと異なるものではないと結論付ける。

#### ばらつき
ばらつきの変化を検出する簡単な方法の一つは、データ集合をいくつかの等しい大きさの区間に分割した後、[Bartlett 検定](../section3/eda357.md)を行うことである。
しかし、バートレット検定は非正規性に対して頑健ではない。
このデータ集合は正規分布でうまく近似できないことがわかっているため、代わりに[Levene 検定](../section3/eda35a.md)を使用する。
具体的には、平均値ではなく中央値に基づく Levene 検定を用いる。
区間の数はある程度恣意的に決めることができるが、4つまたは 8つが妥当な値である。
ここでは、データを 4つの区間に分割する。

```
    H0:  σ12 = σ22 = σ32 = σ42
    Ha:  At least one σi2 is not equal to the others.

    Test statistic:  W = 0.07983
    Degrees of freedom:  k - 1 = 3
    Significance level:  α = 0.05
    Critical value:  Fα,k-1,N-k = 2.623
    Critical region:  Reject H0 if W > 2.623
```

この場合、Levene 検定の結果、4つの区分における分散に有意な差はないことが示された。

#### 無作為性
データが非無作為となる要因は数多くある。
しかし、最も一般的な非無作為性は、前ページに示した[遅延プロット](eda4222.md#遅延プロット)を含む、いくつかの簡単な検定によって検出する。

もう一つの確認方法として、様々なラグに対する自己相関を示す[自己相関プロット](../section3/eda331.md)がある。
信頼区間は、95％ および 99％ の信頼水準でプロットする。
この帯区間外にある点は、統計的に有意な値を示している（ラグ 0 は常に 1 である）。

![ autocorrelation plot](https://www.itl.nist.gov/div898/handbook/eda/section4/randu4p/gif/autocorr.gif)  
 
一般的に最も注目されるラグ1 の[自己相関](../section3/eda35c.md)は 0.03である。
5% 有意水準における境界値は -0.087 および 0.087 である。
これは、ラグ1 の自己相関は統計的に有意ではなく、非無作為性の証拠はない。
無作為性の一般的な検定として、[連検定](../section3/eda35d.md)がある。

```
    H0:  the sequence was produced in a random manner
    Ha:  the sequence was not produced in a random manner  

    Test statistic:  Z = 0.2686
    Significance level:  α = 0.05
    Critical value:  Z1-α/2 = 1.96
    Critical region:  Reject H0 if |Z| > 1.96
```

連検定の結果、データが無作為に生成されたという帰無仮説を棄却することはできなかった。 

#### 分布分析
[確率プロット](../section3/eda33m.md)は、特定の分布がデータ集合に適切に適合しているかを評価するためのグラフを用いた検定である。  

確率プロットの定量的補完として、確率プロット上の点間の相関係数（PPCC）がある。
このデータ集合について、正規分布に基づくPPCCは 0.977 である。
PPCCは境界値 0.987（これは[表の値](../section3/eda3676.md)である）を下回っているため、正規性の仮定は棄却される。  

[カイ二乗検定](../section3/eda35f.md)および [Kolmogorov-Smirnov](../section3/eda35g.md) 適合度検定は、分布の妥当性を評価するための代替手法である。
[Wilk-Shapiro](../../prc/section2/prc213.md) 検定および [Anderson-Darling](../section3/eda35e.md) 検定は、正規性の検定に使用する。
Anderson-Darling 検定の結果は以下の通りである。

```
    H0:  the data are normally distributed      
    Ha:  the data are not normally distributed      
    
    Adjusted test statistic:  A2 = 5.765      
    Significance level:  α = 0.05      
    Critical value:  0.787      
    Critical region:  Reject H0 if A2 > 0.787
```

Anderson-Darling 検定では、検定統計量の値 5.765 が、有意水準 0.05 における境界値 0.787 を上回っているため、正規性の仮定が棄却される。 

#### モデル
グラフおよび定量分析に基づき、以下のモデルを用いる。

$$Y_i=C+E_i$$  

ここで、$`C`$ は範囲の中間値によって推定され、$`C`$ の不確かさ区間は[ブートストラップ](eda4222.md#ブートストラッププロット)解析に基づいて計算する。
具体的には、

$$C=0.499$$
$$C \text{の95%信頼区間} = (0.497, 0.503)$$
