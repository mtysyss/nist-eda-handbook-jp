# 1.4.2.6.2. グラフ出力と解釈

#### 目的
この分析の目的は、以下の3点である。  

1. 単変量モデル、  
<br>$$Y_{i} = C + E_{i}$$  
<br>が適切かつ妥当であるかを判断する。  
2. 「管理下にある」測定工程において、典型的な基礎となる仮定が有効であるかを判断する。
これらの仮定は次の通り。
    1. 無作為性  
    2. 固定された分布  
    3. 固定された位置をもつ分布  
    4. 固定された尺度の分布  
3. 信頼区間  
<br>$$\bar{Y} \pm 2s/\sqrt{N}$$  
<br>が適切かつ有効であるかを判断する。
ここで、$`s`$ は元のデータの標準偏差である。 

#### データの 4-プロット
![4-plot of data](https://www.itl.nist.gov/div898/handbook/eda/section4/mavro/gif/4plot.gif)  

#### 解釈
上記の図で、仮定が扱われる。

1. [実行順序プロット](../section3/eda33p.md)（左上）は、$`x=35`$ 付近で位置に有意な偏位を示している。
2. [遅延プロット](../section3/eda33f.md)（右上）に見られる直線的外観は、データの非無作為なパターンを示している。
3. 遅延プロットが有意な非無作為性を示しているため、[ヒストグラム](../section3/eda33e.md)（左下）や[正規確率プロット](../section3/eda33l.md)（右下）については、解釈をしない。

非無作為性の仮定に著しく違反していることから、単変量モデル

$$Y_{i} = C + E_{i}$$  

は成立しない。
遅延プロットの直線的外観を考慮し、最初の手順として、次式のモデルを検討する。

$$Y_{i} = A_0 + A_1\*Y_{i-1} + E_{i}$$  

しかし、この事例では研究者と話し合った結果、非無作為性は全く予期していなかったことが判明した。
実験の工程を検討したところ、自動データ収集システムの標本化率が速すぎると判明した。
つまり、次の標本抽出が始まる前に機器がリセットされるのに十分な時間がなく、その結果、現在の測定値が前の測定値の影響を受けていたのである。
解決策は、標本抽出間隔を長くして実験をやり直すことだった。

単純な図表現技法は、データ内の予期せぬ結果を明らかにする上で非常に有効である。
このような事態が発生した際、その予期せぬ結果が実験やデータ収集上の問題に起因するものか、あるいはデータに潜む予期せぬ構造を示唆するものかを調査することが重要である。
この判断は統計のみに基づいて行うことはできない。
グラフ分析および統計分析の役割は、データ内の問題や予期せぬ結果を検出することにある。
問題を解決するには、科学者や技術者の知識が必要である。 

#### 個々のプロット
通常は必要ないが、より詳細な情報を得るために、各プロットを作成する。
遅延プロットから有意な非無作為性が示されているため、分布プロットは省略する。
