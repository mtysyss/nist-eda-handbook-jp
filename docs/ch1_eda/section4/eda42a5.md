# 1.4.2.10.5. 主因子の分析

#### 主効果
主因子を分析する最初の手順は、どの因子が最も有意かを特定することである。
[DOE散布図](../section3/eda33b.md)、[DOE平均プロット](../section3/eda33c.md)、および [DOE標準偏差プロット](../section3/eda33d.md)が主なツールである。
ここで「DOE」は「実験計画法（Design of Experiments）」の略称である。

前のページでバッチ効果は有意である一方、試験所効果はごくわずかであることが示されたため、バッチ1 とバッチ2 について別々のプロットを作成する。
ただし、試験所については同等として扱う。 

#### バッチ1 のDOE散布図
![DOE Scatter Plot for Batch 1](https://www.itl.nist.gov/div898/handbook/eda/section4/eda42a5_r01.gif)  

このDOE散布図は、バッチ1 について以下のことを示している。

1. データのほとんどは 500 から 800 の間にある。  
2. 300 から 500 の間には 10個ほどのデータ点がある。  
3. 低い側の外れ値（すなわち、300 から 500 の間の点）を除けば、主因子3つについて、点の分布は位置や広がりの点でほぼ同等である。   

#### バッチ1 のDOE平均プロット
![DOE Mean Plot for Batch 1](https://www.itl.nist.gov/div898/handbook/eda/section4/eda42a5_r02.gif)   

このDOE平均プロットは、バッチ1 について以下のことを示している。

1. テーブル速度係数（X1）が最も有意な因子であり、2つの点間の差は約35単位である。  
2. 砥石粒度（X3）は、次に有意な因子であり、その影響は約10単位である。  
3. 送り速度因子（X2）の影響はごくわずかである。  
 
#### バッチ1 のDOE SDプロット
![DOE SD Plot for Batch 1](https://www.itl.nist.gov/div898/handbook/eda/section4/eda42a5_r03.gif)  

このDOE標準偏差プロットは、バッチ1 について以下のことを示している。

1. テーブル速度因子（X1）については、因子の各水準間でばらつきに有意な差が認められる。
その差は約20単位である。  
2. 砥石の粒度因子（X3）および送り速度因子（X2）のばらつきには、ほとんど差がない。   

#### バッチ2 のDOE散布図
![DOE Scatter Plot for Batch 2](https://www.itl.nist.gov/div898/handbook/eda/section4/eda42a5_r04.gif)  

このDOE散布図は、バッチ2 について以下のことを示している。

1. ほとんどのデータ点は 450 から 750 の間にある。  
2. 低値側と高値側の両方に、いくつかの外れ値がある。  
3. 外れ値（すなわち、450未満または 750 を超える点）を除けば、主因子 3つについて、点の分布は位置および広がりの点で同等である。 

#### バッチ2 のDOE平均プロット
![DOE Scatter Plot for Batch 2](https://www.itl.nist.gov/div898/handbook/eda/section4/eda42a5_r05.gif)  

このDOE平均プロットは、バッチ2 について以下のことを示している。

1. 送り速度（X2）と砥石の粒度（X3）の因子は、それぞれ約15～20単位で、ほぼ同等の影響を与えている。  
2. テーブル速度（X1）の因子の影響はごくわずかである。  

#### バッチ2 のDOE SDプロット
![DOE SD Plot for Batch 2](https://www.itl.nist.gov/div898/handbook/eda/section4/eda42a5_r06.gif)  

このDOE標準偏差プロットは、バッチ2 について以下のことを示している。

1. 3つの因子における標準偏差の差は、おおむね同程度である（送り速度の因子についてはわずかに小さい）。 

#### 交互作用
上記複数の図は主効果を視覚的に示している。
さらに注目すべき点は、有意な交互作用効果があるかである。

主効果および2項交互作用については、[工程改善](../../pri/pri.md)の章で解説している。

以下の[DOE交互作用プロット](../section3/eda33c.md) [^1]において、プロット上の表示に変数と推定された効果が示されている。
例えば、因子1 はテーブル速度であり、その推定効果は 30.77 である（方向を考慮すると実際には -30.77 となる）。 

#### バッチ1 のDOE交互作用プロット
![DOE Interaction Plot for Batch 1](https://www.itl.nist.gov/div898/handbook/eda/section4/eda42a5_r07.gif)  

バッチ1 の因子の順位付けリストは以下の通り。

1. テーブル速度（X1）、推定効果 -30.77。
2. テーブル速度（X1）と砥石粒度（X3）の交互作用推定効果は -20.25。
3. テーブル速度（X1）と送り速度（X2）の交互作用、推定効果は 9.7。
4. 砥石粒度（X3）：推定効果 -7.18。
5. 下送り（X2）および下送りと砥石粒度（X3）との交互作用は、実質的にゼロである。 

#### バッチ2 のDOE交互作用プロット
![DOE Interaction Plot for Batch 2](https://www.itl.nist.gov/div898/handbook/eda/section4/eda42a5_r08.gif)  

第2バッチの因子の順位付けリストは以下の通り。

1. 送り速度（X2）で、推定効果は 18.22  
2. テーブル速度（X1）とホイール粒度（X3）の交互作用推定効果は -16.71。
3. 砥石の粒度（X3）、推定効果は -14.71 
4. 残りの主効果および 2因子交互作用効果は実質的にゼロである。 

#### 結論
上記のグラフから、以下の全体的な結論を導き出すことができる。

1. バッチ効果（約75単位）が主要な支配因子である。  
2. 最も重要な因子はロットごとに異なる。
推定された効果を伴う因子の順位リストについては、上記の本文を参照のこと。
