# 1.4.2.7.2. グラフ出力と解釈

#### 目的
この分析の目的は、以下の3点である。  

1. 単変量モデル、  
<br>$$Y_{i} = C + E_{i}$$  
<br>が適切かつ妥当であるかを判断する。  
2. 「管理下にある」測定工程において、典型的な基礎となる仮定が有効であるかを判断する。
これらの仮定は次の通り。
    1. 無作為性  
    2. 固定された分布  
    3. 固定された位置をもつ分布  
    4. 固定された尺度の分布  
3. 信頼区間  
<br>$$\bar{Y} \pm 2s/\sqrt{N}$$  
<br>が適切かつ有効であるかを判断する。
ここで、$`s`$ は 元のデータの標準偏差である。 

#### データの 4-プロット
![4-plot of data](https://www.itl.nist.gov/div898/handbook/eda/section4/resistor/gif/4plot.gif)  

#### 解釈
上記の図で、仮定が扱われる。

1. [実行順序プロット](../section3/eda33p.md)（左上）は、位置とばらつきの両方に有意な偏位を示している。
具体的には、位置は時間の経過とともに増加している。
ばらつきは、データの中央の 3分の1 に比べ、最初の 3分の1 と最後の 3分の1 はより大きく観える。
2. [遅延プロット](../section3/eda33f.md)（右上）は、データの有意な非無作為なパターンを示している。
具体的には、このプロットに観られる強い直線的外観は、$`Y_t`$ を $`Y_{t-1}`$ に関連付けるモデルを示唆している。
3. 分布プロットである[ヒストグラム](../section3/eda33e.md)（左下）と[正規確率プロット](../section3/eda33l.md)（右下）については、無作為性の仮定に明らかに違反しているため、解釈は行わない。

非無作為性の仮定に著しく違反していることは、単変量モデル

$$Y_{i} = C + E_{i}$$  

は成立しない。
遅延プロットの直線的な外観を考慮し、最初の手順として、次式のモデルを検討する。

$$Y_{i} = A_0 + A_1\*Y_{i-1} + E_{i}$$

しかし、当該の科学者との議論により、以下のことが明らかになった。

1. 位置の偏位は予想されていた。
2. ばらつきが一定でないことは予想されていなかった。

研究者はデータ収集装置を調査し、変動が一定でないのは季節的な影響であると判断した。
ばらつきの大きい最初の 3分の1 と最後の 3分の1 のデータは冬に収集されたのに対し、より安定した中央の 3分の1 は夏に収集されていた。
この季節的な影響は、測定機器に影響を与える湿度の量によって引き起こされていると判断された。
この事例での解決策は、環境要因の影響を受けにくいよう試験装置を改良することだった。

単純な図表現技法は、データ内の予期せぬ結果を明らかにする上で非常に有効である。
このような場合、その予期せぬ結果が実験やデータ収集上の問題によるものなのか、それとも実際にはデータに潜む予期せぬ構造を示唆しているのかを調査することが重要である。
この判断は統計のみに基づいて行うことはできない。
グラフと統計解析の役割は、データ内の問題や予期せぬ結果を検出することにある。
これらの問題を解決するには、科学者や技術者の知識が必要である。 

#### 個々のプロット
通常は必要ないが、より詳細な情報を得るために、各プロットを作成する。
遅延プロットから有意な非無作為性が示されているため、分布プロットは省略する。
