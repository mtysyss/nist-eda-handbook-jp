# 1.4.2.4.3. 定量出力と解釈

#### 要約統計量
分析の第一段階として、データから一般的な要約統計量を算出した。

```    Sample size  = 700      
Mean         =   2898.562      
Median       =   2899.000        
Minimum      =   2895.000        
Maximum      =   2902.000        
Range        =      7.000        
Stan. Dev.   =      1.305
```

データが離散的であるため、正規化されたPPCCも算出した。

```
    Normal PPCC = 0.97484
```

#### 位置
時間の経過に伴う位置の変化を定量化する一つの方法は、回帰分析においてインデックス変数を独立変数として用いて、データを[直線近似](../pmd/section1/pmd141.md)することである。
本データについては、データが実行順であり、等間隔で収集されたことを仮定する。
回帰分析では、インデックス変数 $`X = 1, 2, ..., N`$ を用いる（ここで N は観測値の数である）。
時間の経過に伴う位置偏位がない場合、傾きの母数はゼロとなるはずである。

```    
Coefficient     Estimate     Stan. Error      t-Value    
      B0         2.898E+03       9.745E-02    29739.288            
      B1         1.071E-03       2.409e-04        4.445       
      
      Residual Standard Deviation = 1.288      
      Residual Degrees of Freedom = 698
```

傾き母数 B1の[*t* 値](../pmd/section4/pmd43.md)は 4.445 であり、これは統計的に有意である（境界値は 1.96）。
 しかし、傾きの値は 1.071E-03 である。
傾きがほぼゼロであることを考慮すると、統計的に有意であるとはいえ、位置が一定であるという仮定は著しく違反しているわけではない。

#### ばらつき
ばらつきの変化を検出する簡単な方法の一つは、データ集合をいくつかの等しい大きさの区間に分割した後、[Bartlett 検定](../section3/eda357.md)を行うことである。
しかし、Bartlett 検定は非正規性に対して頑健ではない。
データの性質上（少数の離散点が何度も繰り返されている）、正規性の仮定が疑わしいため、代わりに[Levene 検定](../section3/eda35a.md)を使用する。
具体的には、平均値ではなく中央値に基づく Levene 検定を用いる。
区間の数はある程度恣意的に決めることができるが、4 または 8 が妥当な値である。
ここではデータを 4つの区間に分割する。

```
    H0:  σ12 = σ22 = σ32 = σ42       
    Ha:  At least one σi2 is not equal to the others.      

    Test statistic:  W = 1.43      
    Degrees of freedom:  k - 1 = 3      
    Significance level:  α = 0.05      
    Critical value:  Fα,k-1,N-k = 2.618      
    Critical region:  Reject H0 if W > 2.618
```

Levene 検定の検定統計量 1.43 は、95 %の境界値 2.618 より小さいため、4つの区間における分散に有意な差はないと結論付ける。

#### 無作為性
データが非無作為となる要因は数多くある。
しかし、最も一般的な非無作為性は、いくつかの簡単な検定によって検出する。
[前節の遅延プロット](eda4242.md#遅延プロット)は、その代表的な図表現技法の一つである。

もう一つの確認方法として、様々なラグに対する自己相関を示す[自己相関プロット](../section3/eda331.md)がある。
信頼区間は、95％ および 99％ の信頼水準でプロットする。
この帯区間外にある点は、統計的に有意な値を示している（ラグ 0 は常に 1 である）。

![autocorrelation plot](https://www.itl.nist.gov/div898/handbook/eda/section4/soulen/gif/autocorr.gif)  

 一般的に最も注目されるラグ1 の自己相関は、0.31 である。
5％ 有意水準における境界値は -0.087 および 0.087 である。
これは、ラグ1 の自己相関が統計的に有意であることを示しており、非無作為性の証拠がいくつかある。

無作為性の一般的な検定として、[連検定](../section3/eda35d.md)がある。

```
    H0:  the sequence was produced in a random manner      
    Ha:  the sequence was not produced in a random manner  

      Test statistic:  Z = -13.4162      
      Significance level:  α = 0.05      
      Critical value:  Z1-α/2 = 1.96       
      Critical region:  Reject H0 if |Z| > 1.96
```

連検定の結果は、非無作為性を示している。

連検定とラグ1 の自己相関は、いくつか軽微な非無作為性を示しているが、$`Y_i = C + E_i`$ モデルを棄却するには不十分である。
この非無作為性の少なくとも一部は、データの離散的な性質によって説明できる。 

#### 分布分析
確率プロットは、特定の分布がデータ集合に適切に適合しているかを評価するためのグラフを用いた検定である。
 確率プロットを定量的に補完する指標として、確率プロット上の点間の相関係数（PPCC）が挙げられる。
このデータ集合の正規分布に基づくPPCCは 0.975 である。
PPCCは境界値 0.987（これは[表の値](../section3/eda3676.md)である）を下回っているため、正規性の仮定は棄却される。  

[カイ二乗検定](../section3/eda35f.md)および [Kolmogorov-Smirnov](../section3/eda35g.md) 適合度検定は、分布の妥当性を評価するための代替手法である。
[Wilk-Shapiro](../../prc/section2/prc213.md) 検定および [Anderson-Darling](../section3/eda35e.md) 検定は、正規性の検定に使用する。
Anderson-Darling 検定の結果は以下の通りである。

```
    H0:  the data are normally distributed      
    Ha:  the data are not normally distributed      
    Adjusted test statistic:  A2 = 16.858      
    Significance level:  α = 0.05      
    Critical value:  0.787      
    Critical region:  Reject H0 if A2 > 0.787
```

Anderson-Darling 検定では、検定統計量 16.858 が 95%境界値 0.787 を上回っているため、正規性の仮定が棄却される。

データは厳密には正規ではないが、正規性の仮定の違反は、$`Y_i = C + E_i`$というモデルが妥当でないと結論付けるほど深刻ではない。
非正規性の少なくとも一部は、データの離散的な性質によって説明できる。 

#### 外れ値分析
外れ値の検定は、[Grubbs 検定](../section3/eda35h.md)である。

```
    H0:  there are no outliers in the data      
    Ha:  the maximum value is an outlier      
    Test statistic:  G = 2.729201      
    Significance level:  α = 0.05      
    Critical value for a one-tailed test:  3.950619      
    Critical region:  Reject H0 if G > 3.950619
```

このデータ集合について、Grubbs 検定では、有意水準 0.05 では外れ値は検出されなかった。

#### モデル
無作為性および正規性の仮定はわずかに満たされていなかったが、このデータに対する妥当なモデルは以下の通りであると結論付ける。

$$ Y_{i} = 2898.7 + E_{i}$$  

さらに、平均値の 95％信頼区間は $`(2898.515, 2898.928)`$ である。
