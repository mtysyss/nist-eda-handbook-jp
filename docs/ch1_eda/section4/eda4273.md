# 1.4.2.7.3. 定量出力と解釈

#### 要約統計量
分析の第一段階として、データから一般的な要約統計量を計算した。

```
      Sample size  = 1000
      Mean         =   28.01634  
      Median       =   28.02910
      Minimum      =   27.82800
      Maximum      =   28.11850    
      Range        =    0.29050
      Stan. Dev.   =    0.06349
```

#### 位置
時間の経過に伴う位置の変化を定量化する一つの方法は、回帰分析においてインデックス変数を独立変数として用いて、データを[直線近似](../ch4_pmd/section1/pmd141.md)することである。
本データについては、データが実行順であり、等間隔で収集されたことを仮定する。
回帰分析では、インデックス変数 $`X = 1, 2, ..., N`$ を用いる（ここで N は観測値の数である）。
時間の経過に伴う位置偏位がない場合、傾きの母数はゼロとなるはずである。

```
      Coefficient     Estimate     Stan. Error      t-Value
          B0           27.9114      0.1209E-02     0.2309E+05
          B1        0.20967E-03     0.2092E-05        100.2
 
      Residual Standard Deviation = 0.1909796E-01
      Residual Degrees of Freedom = 998
```

傾き母数 $`B_1`$ の[*t* 値](../ch4_pmd/section4/pmd43.md)は 100.2 であり、これは統計的に有意である。
傾き母数の推定値は 0.00021 である。
この数値はほぼゼロであるが、データの元の尺度が 約27.8 から 28.2 であることを考慮する必要がある。
この場合、位置は偏位していると結論付ける。

#### ばらつき
ばらつきの変化を検出する簡単な方法の一つは、データ集合をいくつかの等しい大きさの区間に分割した後、[Bartlett 検定](../section3/eda357.md)を行うことである。
しかし、Bartlett 検定は非正規性に対して頑健ではない。
これらデータの正規性の仮定が疑わしいため、代わりに[Levene 検定](../section3/eda358.md)を使用する。
具体的には、平均値ではなく中央値に基づく Levene 検定を用いる。
区間の数はある程度恣意的に決めることができるが、4 または 8 が妥当な値である。
ここではデータを 4つの区間に分割する。

```
      H0:  σ12 = σ22 = σ32 = σ42  
      Ha:  At least one σi2 is not equal to the others.

      Test statistic:  W = 140.85
      Degrees of freedom:  k - 1 = 3
      Significance level:  α = 0.05
      Critical value:  Fα,k-1,N-k = 2.614
      Critical region:  Reject H0 if W > 2.614
```

この事例では、Levene 検定の検定統計量 140.85 は、5%有意水準の棄却値 2.614 よりも大きいため、ばらつきは一定ではないという有意な証拠があると結論付ける。

#### 無作為性
データが非無作為となる要因は数多くある。
しかし、最も一般的な非無作為性の形態は、いくつかの簡単な検定によって検出することができます。
前節の4つのプロットのうちの「遅延プロット」は、そのための簡単なグラフ的手法の一つである。

一つの確認として、さまざまなラグに対する[自己相関](../section3/eda35c.md)を示す自己相関プロットがある。
信頼区間は、95％ および 99％ の信頼水準でプロットする。
この区間外にある点は、統計的に有意な値を示している（ラグ 0 は常に 1 である）。

![autocorrelation plot](https://www.itl.nist.gov/div898/handbook/eda/section4/resistor/gif/autocorr.gif)  

一般的に最も注目されるラグ1 の自己相関は 0.97 である。
5％の有意水準における境界値は -0.062 および 0.062 である。
これは、ラグ1 の自己相関が統計的に有意であることを示しており、非無作為性の強い証拠となる。

無作為性の一般的な検定は、[連検定](../section3/eda35d.md)である。

```
      H0:  the sequence was produced in a random manner
      Ha:  the sequence was not produced in a random manner  

      Test statistic:  Z = -30.5629
      Significance level:  α = 0.05
      Critical value:  Z1-α/2 = 1.96 
      Critical region:  Reject H0 if |Z| > 1.96
```

検定統計量が棄却域の外にあるため、帰無仮説を棄却し、データは無作為ではないと結論付ける。 

#### 分布分析
無作為性の仮定を棄却したため、分布の検定は意味をなさない。
したがって、これらの定量的検定は省略する。
外れ値に対するGrubbs 検定もデータの近似的な正規性を仮定しているため、Grubbs 検定も同様に省略する。
