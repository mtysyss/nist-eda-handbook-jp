# 1.4.2.2.2. グラフ出力と解釈

#### 目的
この分析の目的は、以下の3点である。  

1. 単変量モデル、  
<br>$$Y_{i} = C + E_{i}$$  
<br>が適切かつ妥当であるかを判断する。  
2. 「管理下にある」測定工程において、典型的な基礎となる仮定が有効であるかを判断する。
これらの仮定は次の通り。
    1. 無作為性  
    2. 固定された分布  
    3. 固定された位置をもつ分布  
    4. 固定された尺度の分布  
3. 信頼区間  
<br>$$\bar{Y} \pm 2s/\sqrt{N}$$  
<br>が適切かつ有効であるかを判断する。
ここで、$`s`$ は元のデータの標準偏差である。 

#### データの4-プロット
![4-Plot of the Data](https://www.itl.nist.gov/div898/handbook/eda/section4/randu4p/gif/4plot.gif)  

#### 解釈
上記の図で、仮定が扱われる。  

1. [実行順序プロット](../section3/eda33p.md)（左上）は、データに時間の経過に伴う位置や尺度の有意な偏位がないことを示している。  
2. [遅延プロット](../section3/eda33f.md)（右上）からは、データに非無作為なパターンは認められない。  
3. [ヒストグラム](../section3/eda33e.md)は、データの範囲全体を通じて頻度が比較的平坦であることを示している。
これは、正規分布よりも一様分布の方が、より良い分布として適合する可能性があることを示唆している。
4. [正規確率プロット](../section3/eda33l.md)は、正規性の仮定が妥当ではないことを裏付けている。
この場合、4-プロットに続いて一様確率プロットを作成し、それがデータにより良く適合するかを判断する必要がある。
以下に示す。

上記のプロットから、基礎となる仮定は有効であると結論づけられる。
したがって、モデル $`Y_i=C+E_i`$ は有効である。
しかし、データは正規分布ではないため、C の推定値として平均を用いて不確かさを定量化するために、前述の信頼区間を用いることは、有効でも適切でもない。

#### 個々のプロット
通常は必要ないが、より詳細な情報を得るために、各プロットを作成する。

#### 実行順序プロット

#### 遅延プロット
 ![lag plot](https://www.itl.nist.gov/div898/handbook/eda/section4/randu4p/gif/lagplot.gif)   

#### ヒストグラム（正規分布の確率密度関数を重ねたもの）
 ![histogram with normal pdf](https://www.itl.nist.gov/div898/handbook/eda/section4/randu4p/gif/histnorm.gif)  

このグラフから、正規分布ではうまく説明できないことが判る。
ヒストグラムの平坦さから、一様分布の方がより適切である可能性がある。 

#### ヒストグラム（一様確率密度関数を重ね合わせたもの）
![histogram with uniform pdf](https://www.itl.nist.gov/div898/handbook/eda/section4/randu4p/gif/histunif.gif) 
 
4-プロットのヒストグラムから、一様分布が適切である可能性が示唆されたため、ヒストグラムの上に一様分布を重ねた。
その結果、正規分布よりもはるかに適合度が高いことが示された。 

#### 正規確率プロット
 ![normal probability plot](https://www.itl.nist.gov/div898/handbook/eda/section4/randu4p/gif/normprpl.gif)   

ヒストグラムと同様、正規確率プロットからも、正規分布はこれらのデータにうまく適合していないことがわかる。 

#### 一様確率プロット
![uniform probability plot](https://www.itl.nist.gov/div898/handbook/eda/section4/randu4p/gif/unifprpl.gif)  

上記のプロットから、一様分布が適切である可能性が示唆されたため、一様確率プロットを作成する。
このプロットは、一様分布がデータに非常に良く適合していることを示している。 

#### より良いモデル
データは基本的な仮定に従っているものの、正規分布ではなく一様分布に従っているため、$`C`$ を典型値にプラスマイナスの信頼区間として特徴づけたい。
この場合、ばらつきが最小となる[位置推定量](../section3/eda351.md)を見つけたい。  

この目的には、[ブートストラップ・プロット](../section3/eda334.md)が理想的なツールである。
以下のプロットは、平均値、中央値、中点値、および 中央絶対偏差に対するブートストラップ・プロットと、それに対応するヒストグラムを示している。 

#### ブートストラッププロット
![bootstrap plots](https://www.itl.nist.gov/div898/handbook/eda/section4/randu4p/gif/bootstra.gif)  

#### 中点値が最適
上記のヒストグラムから、このデータにおいては、位置の推定値として、中点値が平均値や中央値よりもはるかに優れていることは明らかである。

平均値を用いた場合、位置の推定値は 0.507 となり、平均値の 95%信頼区間は $`(0.482,0.534)`$ となる。
中点値を用いた場合、位置の推定値は 0.499 となり、中点値の 95%信頼区間は $`(0.497,0.503)`$ となる。
 
位置の推定値は類似しているもが、不確かさの区間の差はかなり大きい。

一様分布の場合、理論的には中点値が位置の最良の線形不偏推定量であることが知られている。
しかし、多くの応用例では、最も適切な推定量が不明であったり、有効な信頼区間を決定することが数学的に困難であったりする。
ブートストラップ法は、こうした場合に信頼区間を決定（および比較）する手法を提供する。
