# 1.4.2.5.4. 新しいモデルの検証

#### 残差の 4-プロット
[適合度を評価](../../pmd/section4/pmd44.md)する最初の手順は、残差の[4-プロット](../section3/eda33w.md)を作成することである。

![4-plot of residuals](https://www.itl.nist.gov/div898/handbook/eda/section4/lew/gif/4plotres.gif)  

#### 解釈
上記の図で、仮定が扱われる。

1. [実行順序プロット](../section3/eda33p.md)（左上）は、データに位置の有意な偏位がないことを示している。
尺度には若干の偏位が観られる。
前の複素復調振幅プロットによって起動時の影響が検出されていた。
いくつかの外れ値があるように観える。
2. [遅延プロット](../section3/eda33f.md)（右上）は、データが無作為であることを示している。
外れ値は遅延プロットにも現れている。
3. [ヒストグラム](../section3/eda33l.md)（左下）および[正規確率プロット](../section3/eda33l.md)（右下）からは、残差に深刻な非正規性は認められない。
しかし、正規確率プロットの左側にある屈曲部分は、若干の懸念材料である。

4-プロットは、この適合がかなり良好であることを示している。
しかし、外れ値を除去することで、適合度をさらに向上させることを試みる。

#### 外れ値を除いた近似結果
3つの外れ値を除外し、以下の母数推定値が得られた。 

```
      Coefficient     Estimate     Stan. Error     t-Value
         C            -178.788        10.57         -16.91
         AMP          -361.759        25.45         -14.22
         FREQ         0.302597      0.1457E-03     2077.00
         PHASE         1.46533      0.4715E-01       31.08
 
      Residual Standard Deviation = 148.3398
      Residual Degrees of Freedom = 193
```

#### 編集済みデータへの新規近似
残差標準偏差が 155.84 であった元の推定式は、以下の通りであった。

$$\hat{Y}\_i = -178.786 - 361.766[2\pi(0.302596)T\_i + 1.46536]$$  

残差標準偏差が 148.34 である新しい推定式は以下の通り。

$$\hat{Y}\_i = -178.788 - 361.759[2\pi(0.302597)T\_i + 1.46533]$$  

母数推定値の変化はごくわずかで、残差標準偏差は約5％減少した。
この事例では、残差の除去が、モデルの変動性を低減するという点で、ある程度の効果をもたらす。

#### 新しい近似の4-プロット
![4-Plot for new fit](https://www.itl.nist.gov/div898/handbook/eda/section4/lew/gif/4plotre2.gif)  

このプロットは、基礎となる仮定が満たされていることを示しており、したがって、新しい近似はデータを適切に表している。

この事例では、外れ値を除去したモデルを使用するか、除去しないモデルを使用するかは、判断に委ねられる。
