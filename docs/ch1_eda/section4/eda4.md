# 1.4. EDAの事例研究

#### 概要
本節では、特定の問題でのEDA手法の適用例を示す一連の事例研究を紹介する。
いくつかの事例では、データに関するすべての情報を明らかするひとつのEDA技法に焦点を当てている。
それ以外の事例研究では、複数のEDA技法が必要であり、選択される技法はその解析過程の前の手順の結果によって決まる。
これら事例研究では、基礎となる仮定や一般的なEDAの原則に焦点を当て、どのように解析の流れが導かれているかに注目されたい。
