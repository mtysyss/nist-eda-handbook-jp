# 1.4.2.4.2. グラフ出力と解釈

#### 目的
この分析の目的は、以下の3点である。  

1. 単変量モデル、  
<br>$$Y_{i} = C + E_{i}$$  
<br>が適切かつ妥当であるかを判断する。  
2. 「管理下にある」測定工程において、典型的な基礎となる仮定が有効であるかを判断する。
これらの仮定は次の通り。
    1. 無作為性  
    2. 固定された分布  
    3. 固定された位置をもつ分布  
    4. 固定された尺度の分布  
3. 信頼区間  
<br>$$\bar{Y} \pm 2s/\sqrt{N}$$  
<br>が適切かつ有効であるかを判断する。
ここで、$`s`$ は 元のデータの標準偏差である。 

#### データの 4-プロット
![4-plot of data](https://www.itl.nist.gov/div898/handbook/eda/section4/soulen/gif/4plot.gif)  

#### 解釈
上記の図で、仮定が扱われる。  

1. [実行順序プロット](../section3/eda33p.md)（左上）は、データに時間の経過に伴う位置や尺度の有意な偏位がないことを示している。
2. [遅延プロット](../section3/eda33f.md)（右上）からは、データに非無作為なパターンは認められない。  
3. [ヒストグラム](../section3/eda33e.md)（左下）は、データが適度に 対称的であり、裾に顕著な外れ値は見られず、データが正規分布で近似できると仮定することが妥当であることを示している。
4. [正規確率プロット](../section3/eda33l.md)（右下）は、 異なる値がわずかしかなく、繰り返しが多いという事実により解釈が難しい。

異なる値がわずかしかなく、繰り返しが多数ある整数データが、いくつかのプロット（例えば、遅延プロットや正規確率プロット）の断続的な外観の原因となっている。
この場合、データの性質上、正規確率プロットの解釈は難しいが、特に各数値が何度も繰り返されていることによる。
しかし、ヒストグラムは、正規分布がデータに対して適切なモデルとなることを示唆している。

上のプロットから、基礎となる仮定は妥当であり、データは正規分布で合理的に近似できると結論づけられる。
したがって、一般的に用いられる不確かさの基準は有効かつ適切である。
このモデルの数値は、[定量出力と解釈(eda4253.md)」の節に記載されている。
