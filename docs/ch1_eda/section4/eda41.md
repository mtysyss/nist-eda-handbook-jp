# 1.4.1. 事例研究の導入

#### 目的
最初の8つの事例研究の目的は、科学的な工程から得られたデータに対する、EDA（探索的データ解析）のグラフや定量的指標、検定の適用方法を示し、典型的な測定工程の根底にある以下の仮定、すなわち、データが以下の振る舞いをするという仮定に基づいて、それらデータを論理的に解析検討することである。

* 無作為性を示し  
* 固定された分布から  
* 固定された位置を持ち  
* 固定された標準偏差を持つ  

事例研究 9 および 10 では、それぞれ分布モデル化と実験計画の分析におけるEDA技法の活用例を示す。  

#### ***$`Y_i = C + E_i`$***  
上記の仮定が満たされる場合、その工程は統計的に「管理下にある」と言われ、その中核的な特徴として「予測可能性」を持つ。
つまり、その工程について、過去だけでなく未来についても確率的な記述が可能となる。

「管理下にある」工程に対する適切なモデルは、次式で表される。  

$$Y_i=C+E_i$$  

ここで、$`C`$ は定数（「決定論的」もしくは「構造的」成分）であり、$`E_i`$ は誤差項（または「無作為」成分）である。  

定数 $`C`$ は工程の平均値であり、あらゆる報告書に記載される主要な要約値である。
$`C`$ は（仮定上）一定であるが未知であり、技術者の主な解析目的は、$`C`$ の推定値を導き出すことにある。  

この目標は、4つの子目標に分けられる。  

1. $`C`$ の最も一般的な推定量である $`\bar{Y}`$ は、$`C`$ の最良の推定量か。
ここで「最良」とは何を意味するのか？  
2. もし $`\bar{Y}`$ が最良であるならば、$`\bar{Y}`$ の不確かさ $`s_{\bar{Y}}`$ は何であるか。
特に、$`\bar{Y}`$ の不確かさに関する慣例の式、
<br>$$s_{\bar{Y}}=s/\sqrt{N}$$  
は成立するか。
ここで、$`s`$ はデータの標準偏差、$`N`$ は標本サイズである。  
3. もし $`\bar{Y}`$ が $`C`$ の最良推定量**でない**場合、$`C`$ のより良い推定量（例えば、中央値、範囲中央値、平均中央値）は何か。  
4. もし、より良い推定量 $`\hat{C}`$ が存在する場合、その不確かさはどの程度か。
すなわち、 $`s_{\hat{C}}`$ はどの程度か。  

EDAと、基礎となる仮定の定期的な検証は、上記のすべてについての洞察を与えてくれる。

1. [位置](eda351.md)および[ばらつき](eda356.md)の確認は、 $`C`$ が本当に定数であるかの情報を与える。  
2. 分布の確認は、 $`\bar{Y}`$ が最良の推定量であるかを示す。
解析確認の技法には、[ヒストグラム](eda33e.md)、[正規確率プロット](eda33l.md)、および、[確率プロット相関係数プロット](eda33n.md)が含まれる。
3. 無作為性は、 慣例である、  
<br>$$s_{\bar{Y}} = s\sqrt{N}$$  
<br>
の有効性を確認する。  
4. 分布の検定は、必要に応じて、より優れた推定量を決定するのに役立つ。  
5. シミュレーション・ツール（すなわち、[ブートストラップ法](eda334.md)）は、代替推定量の不確かさに関する値を与える。  

#### 満たされていない前提条件
上記の仮定のうち1つ以上が満たされない場合、データに適したモデルを見つけるために、EDA技法、あるいはEDAと従来の技法の組合せを用いる。
すなわち、  

$$Y_i=D+E_i$$  

ここで、$`D`$ は決定論的部分、$`E`$ は誤差成分である。  

データが無作為でない場合、データにいくつかの単純な時系列モデルを当てはめて検討することがある。
一定位置および一定尺度の仮定が破られている場合、説明となる要因がないか測定工程を調査する必要がある。  

誤差項に関する仮定は、適切なモデルにおいては誤差成分がその仮定に従うべきであるという意味で、依然として非常に重要である。
モデルの妥当性を検証したり、競合するモデルを比較したりするための基準は、これらの仮定に基づいて定式化される。 

#### 多変量データ
この章の事例研究では単変量データを使用しているが、上記の仮定は多変量データにも当てはまる。  

データが単変量でない場合、次のモデルを求めていることになる。  

$$Y_i=F(X_1, ...,X_k)+E_i$$  

ここで、$`F`$ は1つ以上の変数に基づく関数である。
単変量データ集合の良好なモデルの誤差成分は、上記の仮定を満たはずである。
モデルの妥当性を検証し、比較するための基準は、誤差成分がこれらの仮定をどの程度満たしているかに基づく。  

工程モデル化の章にある[ロードセルの校正](../../pmd/section6/pmd61.md)の事例研究は、回帰分析の文脈におけるこの例を示している。 

#### 既知特性データを使用した最初の3つの事例研究
最初の3つの事例研究では、以下の分布から無作為に出力されたデータを使用している。  

* 平均 0、標準偏差 1 の正規分布  
* 平均 0、標準偏差 $`\sqrt{1/12}`$ の一様分布（区間 $`(0,1)`$ 上で一様）  
* ランダム・ウォーク  

その他の単変量事例研究では、科学的な工程から得られたデータを利用する。
目的は、

$$Y_i=C+E_i$$  

が妥当なモデルであるかを判断することである。
これは、基礎となる仮定を検定することで行う。
仮定が満たされる場合、$`C`$ の推定値と $`C`$ の不確かさの推定値を計算する。
仮定が満たされない場合、誤差成分が基礎となる仮定を満たすモデルを見つけ出すことを試みる。

#### データに適用される図表現技法
これらの仮定を検証するために、各データ集合について、この目的に特に適した4つの図表現技法を用いて分析を行う。

1. [実行順序プロット](eda33p.md)、位置や尺度の偏位の検出に有用  
2. [遅延プロット](eda33f.md)、データの非無作為性の検出に有用  
3. [ヒストグラム](eda33e.md)、基礎となる分布の特定に有用  
4. [正規確率プロット](eda33l.md)、データが正規分布に従うかを判断する  

基礎となる仮定を検証するための技法は他にも数多くある。
しかし、上記の 4つのプロットを用いるのは、1ページの図表だけで全ての仮定を検証する最高の機会である。

特定の事例研究では、基礎となる仮定を満たす誤差成分を持つモデルを構築するために、図表現技法を追加して用いる。 

#### データに適用される定量的手法
正規分布および一様分布に従う乱数データ集合についても、以下の定量的技法を用いて解析を行う。
これらの手法については、前節でより詳しく説明している。  

1. 要約統計量には以下が含まれる。  
    * [平均](eda351.md)  
    * [標準偏差](eda356.md)  
    * [自己相関係数](eda35c.md)、無作為性検定  
    * [正規および一様分布の確率プロット相関係数](eda33n.md)（ppcc）、それぞれ正規分布または一様分布であるかの検定  
    * Wilk-Shapiro 検定、正規分布の検定  
2. 時間の関数としてのデータの線形近似によるドリフトの評価（固定位置の検定）  
3. 分散一定の[Bartlett 検定](eda357.md)  
4. 無作為性検定の[自己相関プロット](eda331.md)および係数  
5. 無作為性欠如の検定の[連検定](eda35d.md)  
6. 正規分布[Anderson-Darling 検定](eda35e.md)  
7. 外れ値の[Grubbs 検定](eda35h.md)、  
8. 報告書  

正規および一様分布の乱数に適用される図表現技法は、基礎となる仮定の妥当性を評価するには十分であるが、定量的技法は、図表現技法と定量手法の違いを示すために用いた。  

残りの事例研究では、必要に応じてこれらの定量技法を1つ以上分析に組み合わせている。
