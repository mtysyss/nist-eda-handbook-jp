# 1.4.2.1.3. 定量出力と解釈

#### 要約統計量
分析の第一段階として、データから一般的な要約統計量を計算する。

```
      Sample size  = 500
      Mean         =  -0.2935997E-02
      Median       =  -0.9300000E-01
      Minimum      =  -0.2647000E+01
      Maximum      =   0.3436000E+01
      Range        =   0.6083000E+01
      Stan. Dev.   =   0.1021041E+01
```

#### 位置
時間の経過に伴う位置の変化を定量化する一つの方法は、回帰分析においてインデックス変数を独立変数として用いて、データを[直線近似](../pmd/section1/pmd141.md)することである。
本データについては、データが時系列順に並んでいること、および等間隔で収集されたことを仮定する。
回帰分析では、インデックス変数 X = 1, 2, ..., N を用いる（ここで N は観測値の数である）。
時間の経過に伴う位置偏位がない場合、傾きの母数はゼロとなるはずである。

```
    Coefficient     Estimate      Stan. Error   t-Value  
        B0        0.699127E-02     0.9155E-01    0.0764  
        B1       -0.396298E-04     0.3167E-03   -0.1251
        
     Residual Standard Deviation = 1.02205
     Residual Degrees of Freedom = 498
```

傾き母数の [$`t`$　-値](../pmd/section4/pmd43.md)の絶対値は、$`t_0.975,498=1.96`$ の境界値よりも小さい。
したがって、有意水準 0.05 において、傾きはゼロと異なるものではないと結論付ける。

#### ばらつき
ばらつきの変化を検出する簡単な方法の一つは、データ集合をいくつかの等しい大きさの区間に分割した後、[Bartlett 検定](../section3/eda357.md)を行うことである。
区間の数はある程度恣意的に決めることができるが、4つまたは 8つが妥当な値である。
ここでは、データを 4つの区間に分割する。

```
    H0:  σ12 = σ22 = σ32 = σ42       
    Ha:  At least one σi2 is not equal to the others.      
    
    Test statistic:  T = 2.373660      
    Degrees of freedom:  k - 1 = 3      
    Significance level:  α = 0.05      
    Critical value:  Χ21-α,k-1 = 7.814728      
    Critical region:  Reject H0 if T > 7.814728
```

Bartlett 検定の結果、4つの区間における分散に有意な差はないことが示されている。

#### 無作為性
データが非無作為となる要因は数多くある。
しかし、最も一般的な非無作為性の形態は、前ページに示した[遅延プロット](eda4212.md#遅延プロット)を含む、いくつかの簡単な検定によって検出する。  

もう一つの確認方法として、様々なラグに対する自己相関を示す[自己相関プロット](../section3/eda331.md)がある。
信頼区間は、95％ および 99％ の信頼水準でプロットする。
この帯の外にある点は、統計的に有意な値を示している（ラグ 0 は常に 1 である）。

![ autocorrelation plot](https://www.itl.nist.gov/div898/handbook/eda/section4/randn4p/gif/autocorr.gif)  

一般的に最も注目されるラグ1 の[自己相関](../section3/eda35c.md)は 0.045 である。
5％ 有意水準における境界値は -0.087 および 0.087 である。
0.045 は棄却域内にあるため、ラグ1 の自己相関は統計的に有意ではなく、非無作為性の証拠はない。

無作為性の一般的な検定として、[連検定](../section3/eda35d.md)がある。

```  
      H0:  the sequence was produced in a random manner
      Ha:  the sequence was not produced in a random manner  

      Test statistic:  Z = -1.0744      
      Significance level:  α = 0.05      
      Critical value:  Z1-α/2 = 1.96       
      Critical region:  Reject H0 if |Z| > 1.96
```

連検定の結果、データが無作為に作成されたという帰無仮説を棄却できなかった。 

#### 分布分析
[確率プロット](../section3/eda33m.md)は、特定の分布がデータ集合に適切に適合しているかを評価するためのグラフを用いた検定である。  

確率プロットの定量的補完として、確率プロット上の点間の相関係数（PPCC）がある。
このデータ集合について、正規分布に基づく PPCC は 0.996 である。
PPCC は境界値 0.997（これは[表の値](../section3/eda3676.md)である）を下回っているため、正規性の仮定は棄却される。  

[カイ二乗検定](../section3/eda35f.md)および [Kolmogorov-Smirnov](../section3/eda35g.md) 適合度検定は、分布の妥当性を評価するための代替手法である。
[Wilk-Shapiro](../../prc/section2/prc213.md) 検定および [Anderson-Darling](../section3/eda35e.md) 検定は、正規性の検定に使用する。
Anderson-Darling 検定の結果は以下の通りである。

```
    H0:  the data are normally distributed
    Ha:  the data are not normally distributed
    
    Adjusted test statistic:  A2 = 1.0612      
    Significance level:  α = 0.05      
    Critical value:  0.787      
    Critical region:  Reject H0 if A2 > 0.787
```

Anderson-Darling 検定は、有意水準 0.05 において正規性の仮定を棄却する。 

#### 外れ値分析
外れ値の検定は、[Grubbs 検定](../section3/eda35h.md)である。

```
    H0:  there are no outliers in the data      
    Ha:  the maximum value is an outlier      

    Test statistic:  G = 3.368068      
    Significance level:  α = 0.05      
    Critical value for an upper one-tailed test:  3.863087               
    Critical region:  Reject H0 if G > 3.863087
```

このデータ集合に関して、Grubbs 検定では、有意水準 0.05 では外れ値は検出されなかった。

#### モデル
基礎となる仮定がグラフおよび解析で検証されたことから、このデータに対する妥当なモデルは以下の通りであると結論付ける。  

$$Y_i=C+E_i$$  

ここで、$`C`$ は推定された平均値である -0.00294 となる。
$`C`$ の不確かさは、[95% 信頼区間](../section3/eda352.md) $`(-0.09266, 0.08678)`$ として表す。
