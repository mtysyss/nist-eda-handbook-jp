# 1.4.2.3.2. 基礎となる仮定の検定

#### 目的
この分析の目的は、以下の3点である。  

1. 単変量モデル、  
<br>$$Y_{i} = C + E_{i}$$  
<br>が適切かつ妥当であるかを判断する。  
2. 「管理下にある」測定工程において、典型的な基礎となる仮定が有効であるかを判断する。
これらの仮定は次の通り。
    1. 無作為性  
    2. 固定された分布  
    3. 固定された位置をもつ分布  
    4. 固定された尺度の分布  
3. 信頼区間  
<br>$$\bar{Y} \pm 2s/\sqrt{N}$$  
<br>が適切かつ有効であるかを判断する。
ここで、$`s`$ は 元のデータの標準偏差である。 

#### データの4-プロット
![Random Walk: 4-Plot](https://www.itl.nist.gov/div898/handbook/eda/section4/randwalk/gif/randwa4p.gif)  

#### 解釈
上記の図で、仮定が扱われる。  

1. [実行順序プロット](../section3/eda33p.md)（左上）は、時間の経過に伴う位置の有意な偏位を示している。
2. [遅延プロット](../section3/eda33f.md)（右上）は、データに有意な非無作為性があることを示している。
3. 無作為性および一定の位置と尺度という仮定が満たされない場合、分布に関する仮定は意味をなさなくなる。
したがって、[ヒストグラム](../section3/eda33e.md)（左下）や[正規確率プロット](../section3/eda33l.md)（右下）について、いかなる解釈も行わない。

上記のプロットから、基礎となる仮定を著しく違反していると結論付ける。
したがって、$`Y_i=C+E_i`$ モデルは有効ではない。

無作為性の仮定に著しく違反している場合、[時系列](../../pmc/section4/pmc4.md)モデルが適切である可能性がある。
遅延プロットはしばしば妥当なモデルを示唆する。
例えば、この事例では遅延プロットが強く線形な外観を示していることから、 $`Y_i`$ 対 $`Y_{i-1}`$ を適合させるモデルが適切である可能性がある。
データが非無作為な場合、遅延プロットを[自己相関プロット](../section3/eda331.md)および[スペクトル図](../section3/eda33r.md)で補完することが有用である。
この事例では遅延プロットだけで適切なモデルを示唆するのに十分であるが、比較のために自己相関プロットとスペクトル図も示す。 

#### 自己相関プロット
遅延プロットで有意な非無作為性が示された場合、[自己相関プロット](../section3/eda331.md)を確認するのが良い。  

![autocorrelation plot](https://www.itl.nist.gov/div898/handbook/eda/section4/randwalk/gif/autocorr.gif)  

この自己相関プロットは、ラグ1 から 100 にかけて、線形に減少する形で有意な自己相関を示している。 

#### スペクトル図
非無作為データにおいて、もう1つ有用なプロットとして[スペクトル図](../section3/eda33r.md)がある。

![spectral plot](https://www.itl.nist.gov/div898/handbook/eda/section4/randwalk/gif/spectrum.gif)  

このスペクトル図には、単一の主低周波ピークが示されている。 

#### 定量出力
上記の 4-プロットからは仮定の違反がはっきりと示されているが、図による結果に加え、いくつかの定量的指標も示す。

#### 要約統計量
分析の第一段階として、データから一般的な要約統計量を計算した。

```
    Sample size  = 500      
    Mean         =   3.216681      
    Median       =   3.612030      
    Minimum      =  -1.638390      
    Maximum      =   7.415205      
    Range        =   9.053595      
    Stan. Dev.   =   2.078675
```

また、自己相関係数を計算すると 0.987 となり、これは非常に強い自己相関があることを示している。

#### 位置
時間の経過に伴う位置の変化を定量化する一つの方法は、回帰分析においてインデックス変数を独立変数として用いて、データを[直線近似](../pmd/section1/pmd141.md)することである。
本データについては、データが実行順であり、等間隔で収集されたことを仮定する。
回帰分析では、インデックス変数 $`X = 1, 2, ..., N`$ を用いる（ここで N は観測値の数である）。
時間の経過に伴う位置偏位がない場合、傾きの母数はゼロとなるはずである。

```
    Coefficient      Estimate     Stan. Error   t-Value   
          B0         1.83351         0.1721        10.650
          B1         0.552164E-02    0.5953E-03     9.275

    Residual Standard Deviation = 1.9214      
    Residual Degrees of Freedom = 498
```

傾き母数の[$`t`$ 値](../pmd/section4/pmd43.md) 9.275 は、境界値 $`t_{0.975,498}=1.96`$ よりも大きい。
したがって、有意水準 0.05 において、傾きはゼロとは異なると結論付ける。

#### ばらつき
ばらつきの変化を検出する簡単な方法の一つは、データ集合をいくつかの等しい大きさの区間に分割した後、[Bartlett 検定](../section3/eda357.md)を行うことである。
しかし、Bartlett 検定は非正規性に対して頑健ではない。
このデータ集合は正規分布による近似が適切でないことが判っていることから、代わりに[Levene 検定](../section3/eda35a.md)[^1]を用いる。
具体的には、平均値ではなく中央値に基づく Levene 検定を用いる。
区間の数はある程度恣意的に決めることができるが、4 または 8 が妥当な値である。
ここではデータを 4つの区間に分割する。

```
    H0:  σ12 = σ22 = σ32 = σ42  
    Ha:  At least one σi2 is not equal to the others.      

    Test statistic:  W = 10.459      
    Degrees of freedom:  k - 1 = 3      
    Significance level:  α = 0.05      
    Critical value:  Fα,k-1,N-k = 2.623      
    Critical region:  Reject H0 if W > 2.623
```

この事例では、Levene 検定の結果、検定統計量 10.459 が 95%棄却値 2.623 を上回っていることから、4区間における分散には有意な差があることが示された。
したがって、尺度は一定ではないと結論付ける。

#### 無作為性
上記ラグ1 の自己相関係数は明らかに非無作為性を示しているが、[連検定](../section3/eda35d.md)の結果も併せて示す。

```
    H0:  the sequence was produced in a random manner      
    Ha:  the sequence was not produced in a random manner  

    Test statistic:  Z = -20.3239      
    Significance level:  α = 0.05      
    Critical value:  Z1-α/2 = 1.96       
    Critical region:  Reject H0 if |Z| > 1.96
```

連検定の結果、データが無作為に生成されたという帰無仮説は、有意水準 0.05 で棄却された。

#### 分布の仮定
定量的検定の結果、無作為性と一定の位置および尺度の仮定が満たされていないことが示されているため、分布の測定値には意味がない。
したがって、これらの定量的検定は省略する。
