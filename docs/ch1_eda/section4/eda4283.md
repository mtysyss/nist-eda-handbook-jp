# 1.4.2.8.3. 定量出力と解釈

#### 要約統計量
分析の第一段階として、データから一般的な要約統計量を計算した。

```
      Sample size  = 195
      Mean         =   9.261460
      Median       =   9.261952  
      Minimum      =   9.196848
      Maximum      =   9.327973
      Range        =   0.131126  
      Stan. Dev.   =   0.022789
```

#### 位置
時間の経過に伴う位置の変化を定量化する一つの方法は、回帰分析においてインデックス変数を独立変数として用いて、データを[直線近似](../pmd/section1/pmd141.md)することである。
本データについては、データが実行順であり、等間隔で収集されたことを仮定する。
回帰分析では、インデックス変数 $`X = 1, 2, ..., N`$ を用いる（ここで N は観測値の数である）。
時間の経過に伴う位置偏位がない場合、傾きの母数はゼロとなるはずである。

```
      Coefficient     Estimate     Stan. Error      t-Value
          B0           9.26699      0.3253E-02     2849.
          B1        -0.56412E-04    0.2878E-04     -1.960

 
      Residual Standard Deviation = 0.2262372E-01
      Residual Degrees of Freedom = 193
```

傾き母数 $`B_1`$ の[*t* 値](../pmd/section4/pmd43.md)は -1.96 であり、これは 95% 信頼区間の基準値である -1.96 と実質的に等しいため、（わずかに）統計的に有意である。
しかし、傾き母数の推定値は -0.00056 であることに注意されたい。
この傾きは、統計的には有意であるものの、実質的にはゼロと見なすことができる。

#### ばらつき
ばらつきの変化を検出する簡単な方法の一つは、データ集合をいくつかの等しい大きさの区間に分割した後、[Bartlett 検定](../section3/eda357.md)を行うことである。
区間の数はある程度恣意的に決めることができるが、4 または 8 が妥当な値である。
ここではデータを 4つの区間に分割する。

```
      H0:  σ12 = σ22 = σ32 = σ42 
      Ha:  At least one σi2 is not equal to the others.

      Test statistic:  T = 3.147
      Degrees of freedom:  k - 1 = 3
      Significance level:  α = 0.05
      Critical value:  Χ 21-α,k-1 = 7.815
      Critical region:  Reject H0 if T > 7.815
```

この事例では、Bartlett 検定の検定統計量 3.147 は、5%有意水準における臨界値 7.815 よりも小さいため、4区間における分散に有意な差はないと結論づけられる。
つまり、一定尺度の仮定は成立している。

#### 無作為性
データが非無作為となる要因は数多くある。
しかし、最も一般的な非無作為性は、いくつかの簡単な検定によって検出する。
前節での遅延プロットは、その代表的な図表現技法の一つである。

一つの確認として、さまざまなラグに対する[自己相関](../section3/eda35c.md)を示す自己相関プロットがある。
信頼区間は、95％ および 99％ の信頼水準でプロットする。
この区間外にある点は、統計的に有意な値を示している（ラグ 0 は常に 1 である）。

![autocorrelation plot](https://www.itl.nist.gov/div898/handbook/eda/section4/zarr13/gif/autocorr.gif)  

一般的に最も注目されるラグ1 の自己相関は、0.281 である。
5％ 有意水準における境界値は -0.140 および 0.140 である。
これは、ラグ1 の自己相関が統計的に有意であることを示しており、非無作為性の証拠となる。

無作為性の一般的な検定は、[連検定](../section3/eda35d.md)である。

```
      H0:  the sequence was produced in a random manner
      Ha:  the sequence was not produced in a random manner  

      Test statistic:  Z = -3.2306
      Significance level:  α = 0.05
      Critical value:  Z1-α/2 = 1.96 
      Critical region:  Reject H0 if |Z| > 1.96
```

検定統計量の値は -1.96 より小さいため、0.05 の有意水準で帰無仮説を棄却し、データは無作為ではないと結論付ける。

自己相関プロットと連検定がある程度軽微な非無作為性を示しているが、無作為性仮定の違反は、より高度なモデルを構築するほど深刻ではない。
実務上、仮定の一部が軽微に違反することは珍しくなく、その違反がデータに対してより高度なモデルを構築するほど深刻であるかは、判断に委ねられる。 

#### 分布分析
[確率プロット](../section3/eda33n.md)は、特定の分布がデータ集合に適切に適合しているかどうかを評価するためのグラフによる検定である。

確率プロットを定量補完として、確率プロット上の点間の相関係数がある。
このデータ集合における相関係数は 0.996 である。
これは境界値である 0.987（これは[表の値](../section3/eda3676.md)である）より大きいため、正規性の仮定は棄却されない。

[カイ二乗検定](../section3/eda35f.md)および [Kolmogorov-Smirnov](../section3/eda35g.md) 適合度検定は、分布の妥当性を評価するための代替手法である。
[Wilk-Shapiro](../../prc/section2/prc213.md) 検定および [Anderson-Darling](../section3/eda35e.md) 検定は、正規性の検定に使用する。
Anderson-Darling 検定の結果は以下の通りである。

```
      H0:  the data are normally distributed
      Ha:  the data are not normally distributed

      Adjusted test statistic:  A 2 = 0.129
      Significance level:  α = 0.05
      Critical value:  0.787
      Critical region:  Reject H0 if A 2 > 0.787
```

Anderson-Darling 検定においても、検定統計量 0.129 が5％有意水準における棄却値 0.787 を下回っているため、正規性の仮定は棄却されない。 

#### 外れ値分析
外れ値の検定は、[Grubbs 検定](../section3/eda35h.md)である。

```
      H0:  there are no outliers in the data
      Ha:  the maximum value is an outlier

      Test statistic:  G = 2.918673
      Significance level:  α = 0.05
      Critical value for an upper one-tailed test:  3.597898
      Critical region:  Reject H0 if G > 3.597898
```

このデータ集合について、Grubbs 検定では、有意水準 0.05 では外れ値は検出されない。

#### モデル
基礎となる仮定は、無作為性に関する仮定に軽微な違反はあるものの、グラフおよび分析の両方で検証され、このデータに対する妥当なモデルは次式であると結論付ける。

$$Y_{i} = 9.26146 + E_{i}$$  

ここで 9.26146 と推定された $`C`$ の不確かさは、[95 %信頼区間](../section3/eda352.md)で、$`(9.258242,9.26479)`$ として表す。
