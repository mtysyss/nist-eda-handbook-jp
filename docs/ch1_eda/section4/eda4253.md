# 1.4.2.5.3. より優れたモデルの構築

#### 正弦波モデル
前節の遅延プロットと自己相関プロットは、正弦波モデルが適切である可能性を強く示唆していた。
基本的な正弦波モデルは以下の通り。  

$$Y_{i} = C + \alpha\sin{(2\pi\omega T_{i} + \phi)} + E_i$$

ここで、$`C`$ は平均レベルを定義する定数、$`α`$ は正弦関数の振幅、$`ω`$ は周波数、$`T_i`$ は時間変数、そして$`\phi`$ は位相である。
この正弦波モデルは、[非線形最小二乗法](../../pmd/section1/pmd142.md)を用いて推定することができる。

良好な適合を得るためには、正弦波モデルでは $`C`$および、振幅、周波数について適切な初期値が必要である。 

#### Cの適切な初期値
$`C`$ の適切な初期値は、データの平均を計算し取得する。
データに傾向が見られる場合、すなわち、位置一定の仮定が成り立たない場合は、$`C`$ を[線形または2次最小二乗法](../../pmd/section1/pmd141.md)による近似で置き換える。
つまり、モデルは次式となる。

$$Y_{i} = (B_0 + B_1\*T_{i}) + \alpha\sin{(2\pi\omega T_{i} + \phi)}+ E_i$$  

または

$$Y_{i} = (B_0 + B_1\*T_{i} + B_2\*T^{2}_{i}) + \alpha\sin{(2\pi\omegaT_{i} + \phi)} + E_i$$  

データに位置の有意な変化が見られないことから、$`C`$ を平均値として、より単純なモデルを適合させる。
前のページの要約出力によると、平均値は -177.44 である。

#### 周波数における適切な初期値
周波数の初期値は[スペクトル図](eda4252.md#ペクトル図)から求めることができ、それによると主周波数は 約0.3 を示している。

#### 複素復調位相プロット
[複素復調位相プロット](../section3/eda339.md)を使用することで、この周波数の初期推定値をさらに精緻化する。

複素復調位相プロットにおいて、線が左から右に向かって傾いている場合は、周波数を上げる必要がある。
線が右から左に向かって傾いている場合は、周波数を下げる必要がある。
比較的平坦な（すなわち、水平な）傾きは、適切な周波数であることを示している。
0.3 の復調位相プロットを作成し、試行錯誤を繰り返してより正確な周波数の推定値を求める。
これを簡略化するために、周波数 0.28 から始め、0.0025 刻みで増加させ、0.3175 で終了するように、1ページに16個のプロットを作成する。

![complex demodulation phase plots](https://www.itl.nist.gov/div898/handbook/eda/section4/lew/gif/compdeph.gif)  

#### 解釈
プロットは左から右へ傾く直線から始まるが、徐々に右から左へ傾くようになる。
比較的緩やかな傾きが見られるのは、周波数 0.3025（3行目、2列目）の場合である。
複素復調位相のプロットでは、範囲が $`\pi/2`$ から $`-\pi/2`$ に制限している。
これが、プロットにいくつかの切れ目が見える理由である。

#### 振幅の適切な初期値
[複素復調振幅プロット](../section3/eda338.md)は、振幅の適切な初期値を見つけるために用いる。
さらに、このプロットは、振幅がデータ範囲全体で一定であるか、あるいは変動するかを示する。
プロットが実質的に平坦、すなわち傾きがゼロである場合、非線形モデルにおいて振幅が一定であると仮定するのが妥当である。
しかし、プロットの範囲内で傾きが変化する場合は、モデルを次のように調整する必要がある。

$$Y_{i} = C + (B_0 + B_1\*T_{i})\sin{(2\pi\omega T_{i} +\phi)} + E_i$$  

つまり、$`α`$ を時間の関数で置き換える。
上記のモデルでは線形近似が指定されているが、必要に応じて、これより複雑な関数に置き換える。

#### 複素復調振幅プロット
![complex demodulation amplitude plot](https://www.itl.nist.gov/div898/handbook/eda/section4/lew/gif/compdeam.gif)  

このデータの複素復調振幅プロットからは、以下のことを示している。

1. 振幅は約 390 に固定されている。
2. 短い立ち上がり効果が認められる。
3. $`x=160`$ 付近で振幅の変化が見られ、外れ値の有無について調査すべきである。

非線形モデルに関して言えば、このプロットはデータ集合に対して、$`α`$ に単一の定数を当てはめることで十分であることを示唆している。 

#### 適合結果
周波数 0.3025、振幅 390、C値 -177.44 を初期推定値として、以下の母数が推定された。 

```
      Coefficient     Estimate     Stan. Error     t-Value
         C            -178.786        11.02         -16.22
         AMP          -361.766        26.19         -13.81
         FREQ         0.302596      0.1510E-03     2005.00
         PHASE         1.46536      0.4909E-01       29.85
 
      Residual Standard Deviation = 155.8484
      Residual Degrees of Freedom = 196
```
 
#### モデル
推定結果から、我々が提案するモデルは以下の通りである。

$$\hat{Y}_i = -178.786 - 361.766[2\pi(0.302596)T_i + 1.46536]$$
