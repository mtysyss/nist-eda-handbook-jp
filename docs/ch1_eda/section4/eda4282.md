# 1.4.2.8.2. グラフ出力と解釈

#### 目的
この分析の目的は、以下の3点である。  

1. 単変量モデル、  
<br>$$Y_{i} = C + E_{i}$$  
<br>が適切かつ妥当であるかを判断する。  
2. 「管理下にある」測定工程において、典型的な基礎となる仮定が有効であるかを判断する。
これらの仮定は次の通り。
    1. 無作為性  
    2. 固定された分布  
    3. 固定された位置をもつ分布  
    4. 固定された尺度の分布  
3. 信頼区間  
<br>$$\bar{Y} \pm 2s/\sqrt{N}$$  
<br>が適切かつ有効であるかを判断する。
ここで、$`s`$ は元のデータの標準偏差である。 

#### データの 4-プロット
![4-plot of data](https://www.itl.nist.gov/div898/handbook/eda/section4/zarr13/gif/4plot.gif)  

#### 解釈
上記の図で、仮定が扱われる。

1. [実行順序プロット](../section3/eda33p.md)（左上）は、データに時間の経過に伴う位置や尺度の有意な偏位がないことを示している。
2. [遅延プロット](../section3/eda33f.md)（右上）は、     データに非無作為なパターンがないことを示している。
3. [ヒストグラム](../section3/eda33e.md)（左下）は、       データが適度に対称的であり、裾部に著しい外れ値は観られず、データが近似的に正規分布に従うと仮定することは妥当であるように思われる。
4. [正規確率プロット](../section3/eda33l.md)（右下）は、正規性の仮定が実際に妥当であることを裏付けている。
