# 1.4.2.10.3. バッチ効果の分析

#### 局外因子 バッチ
この実験における2つの交絡因子は、ロット番号と試験所である。
ロットは2つ、試験所は8つある。
理想的には、これらの因子が応答変数に与える影響は最小限であるべきである。

まず、ロット要因について検討する。 

#### 対比ヒストグラム
![Bihistogram](https://www.itl.nist.gov/div898/handbook/eda/section4/jahanmi2/gif/bihistog.gif)  

この[対比ヒストグラム](../section3/eda332.md)は、以下のことを示している。

1. バッチ効果が観られる。  
2. バッチ1 の応答値は 700 を中心に分布しているのに対し、バッチ2 の応答値は 625 を中心に分布している。
つまり、バッチ効果はおよそ 75単位となる。
3. 2つのバッチ間のばらつきは同等である。
4. バッチ1 は下側の裾部に若干の偏りが観られる。
バッチ2 は分布の中央部に若干の偏りが観られるが、バッチ1 と比較して裾部での偏りはそれほど大きくない。
5. どちらのバッチにも、いくつかの低い値のデータ点が含まれている。

対比ヒストグラムだけで終わらせることも可能だが、比較のために、他に一般的に用いられる二標本用の図表現技法をいくつか示す。 

#### 分位数-分位数プロット

![Quantile-Quantile Plot](https://www.itl.nist.gov/div898/handbook/eda/section4/jahanmi2/gif/qqplot.gif)  

この[Q-Qプロット](../section3/eda33o.md)は、以下のことを示している。

1. 右側の裾部にあるいくつかの点を除き、バッチ1 の値はバッチ2 の値よりも高い分位数を持っている。
これは、バッチ1 がバッチ2 よりも位置の値が高いとを示唆している。
2. q-qプロットは直線的ではない。
これは、バッチ間の差が単に位置のずれだけで説明できるものではないことを示唆している。
つまり、ばらつきや歪度も変化している。
対比ヒストグラムから判断すると、q-qプロットの非直線性を説明する最も有力な要因は、バッチ2 の歪度であると考えられる。 

#### 箱ひげ図
![Box Plot](https://www.itl.nist.gov/div898/handbook/eda/section4/jahanmi2/gif/boxplot.gif)  

この[箱ひげ図](../section3/eda337.md)は、以下のことを示している。

1. バッチ1 の中央値は約700 であるのに対し、バッチ2 の中央値は約600 である。  
2. 両バッチのばらつきはほぼ同様であるが、バッチ1 の方がわずかに大きいかもしれない。  
3. どちらのバッチにも、低い外れ値がいくつか見られる。
バッチ2 には、高い外れ値もいくつかある。
箱ひげ図は、外れ値の有無を特定するのに特に有効な手法である。  

#### ブロック・プロット
8つの試験所それぞれについて、「1」と「2」がバッチ番号を表しているブロック・プロットを作成した。
最初のプロットには、主因子は一切含まれていない。
次の3つのブロック・プロットには、主因子のいずれかが含まれている。
なお、3つの主因子（テーブル速度＝X1、送り速度＝X2、ホイール砥粒サイズ＝X3）はそれぞれ 2水準あることに留意する。
試験所が8つあり、主因子の水準が2つあるため、これらのプロットには16個の独立したブロックが想定される。
一部のブロックが欠落しているという事実は、試験所と主因子の組み合わせの一部が空であることを示している。

![Block Plots](https://www.itl.nist.gov/div898/handbook/eda/section4/jahanmi2/gif/blockpl1.gif)  

これらの[ブロック・プロット](../section3/eda333.md)からは、以下のことを示している。

1. 上記の**すべての**条件において、バッチ1 の平均値はバッチ2 の平均値よりも大きい。
これは、バッチ効果があり、試験所や主要因子の組み合わせを問わず一貫して現れていることを強く示唆している。 

#### 定量技法
上記のグラフから導き出された結論の一部を定量技法を用いて裏付ける。
[*F*-検定](../section3/eda359.md)を用いて、2つのバッチの分散が等しいかどうかを検定し、[二標本*t*-検定](../section3/eda353.md)を用いて、2つのバッチの平均が等しいかどうかを検定する。
各バッチの要約統計量は以下の通り。 

```
Batch 1:
    NUMBER OF OBSERVATIONS =  240
    MEAN                   =  688.9987
    STANDARD DEVIATION     =   65.5491
    VARIANCE               = 4296.6845 
 
Batch 2:
    NUMBER OF OBSERVATIONS =  240
    MEAN                   =  611.1559
    STANDARD DEVIATION     =   61.8543
    VARIANCE               = 3825.9544
```

#### *F*-検定
両側 *F*-検定の結果、2つのバッチの分散には、5％水準で有意な差は認められない。 

```
H0:  σ12 = σ22 
Ha:  σ12 ≠ σ22

Test statistic:  F = 1.123 
Numerator degrees of freedom:  ν1 = 239
Denominator degrees of freedom:  ν2 = 239
Significance level:  α = 0.05
Critical values:  F1-α/2,ν1,ν2 = 0.845
                  Fα/2,ν1,ν2 = 1.289
Critical region:  Reject H0 if F < 0.845 or F > 1.289
```

#### 二標本*t*-検定
*F*-検定の結果、2つのバッチの分散は等しいと示されたため、両側二標本 *t*-検定で分散を組み入れ、バッチの平均値を比較する。 

```
H0:  μ1 = μ2
Ha:  μ1 ≠ μ2

Test statistic:  T = 13.3806 
Pooled standard deviation:  sp = 63.7285
Degrees of freedom:  ν = 478
Significance level:  α = 0.05
Critical value:  t1-α/2,ν = 1.965
Critical region: Reject H0 if |T| > 1.965
```

*t*-検定の結果、5％の有意水準において、バッチ1 の平均値がバッチ2 の平均値よりも大きいことが示された。 

#### 結論
上記の分析から、以下の結論が導き出される。

1. 実際には、有意なバッチ効果が存在する。
このバッチ効果は、各試験所および主因子の間で一貫している。
2. 差の大きさは 75 から 100 のオーダーである（バッチ2 はバッチ1 よりも小さい）。
標準偏差には有意な差は見られない。
3. 各バッチにはある程度の偏りが認められる。

このバッチ効果は、本研究の科学者たちにとって全く予期せぬものであった。

なお、定量技法は平均値の不等価と標準偏差の等価という結論を支持しているが、外れ値の存在やバッチ2 データの偏りなど、データのより微妙な特徴までは示していない。
