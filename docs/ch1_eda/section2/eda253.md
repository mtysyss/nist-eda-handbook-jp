# 1.2.5.3. 非固定ばらつきの母数の帰結

#### ばらつきの推定
ばらつきの一般的な推定値は標準偏差である。

$$s\_Y = \frac{1}{\sqrt{(N-1)}} \sqrt{\sum\_{i=1}^{N}{(Y\_i - \bar{Y})^2}}$$  

$N$ 個の測定値 $Y_1,Y_2, ..., Y_N$ から得られる。

#### 非固定ばらつきの帰結
実行順序プロットが固定されたばらつきの仮定を支持しない場合、

1. ばらつきが偏位している可能性がある。  
2. 単一のばらつき推定値は無意味となる可能性がある。（過程のばらつきが偏位している場合）。
3. ばらつきの推定推定値が不正確である可能性がある。  
4. ばらつきの推定値は偏っている可能性がある。
