# 1.2.5.4. 分布の仮定に関連する帰結

#### 分布分析
科学者や技術者は分布の「中間値」を推定するため、平均値(average)を日常的に用いる。
しかし平均値という位置推定量が持つばらつきやノイズは、データの基盤となる分布と本質的に結びついていることはあまり知られていない。
特定の分布では平均値は不適切な選択である。 
任意の分布に対して、最適な選択、すなわちばらつき／ノイズが最小の推定量が存在する。
この最適選択は、例えば中央値、算術平均、中間平均、平均、あるいは他の何かである。
この意味するところは、まず[分布を「推定」](../section3/eda365.md)し、その分布に基づいて最適な推定量を選択することである。
この手法に従わない場合と比較して、結果として得られる工学的母数推定量はばらつきが小さくなる。

#### 事例研究
[航空機のガラスの破損](../section4/eda429.md)事例研究は、適切な分布を決定し、その分布の母数を推定する例を示している。
[一様乱数](../section4/eda422.md)事例研究は、正規分布ではない分布に対してより適切な中心母数を決定する例を示している。

#### 分布
1. 分布は変化している可能性がある。  
2. 単一の分布推定は無意味となる可能性がある（過程の分布が変化している場合）。  
3. 分布が著しく非正規である可能性がある。  
4. 分布が未知である可能性がある。  
5. 誤差の真の確率分布は未知のままである可能性がある。  

#### モデル
1. モデルは変化している可能性がある。  
2. 単一モデルによる推定は無意味の可能性がある。  
3. 標準のモデル
       $$Y = 定数 + 誤差$$
が無効である可能性がある。
4. 標準モデルが不十分な場合、より優れたモデルに関する情報が検出されない可能性がある。  
5. 不十分な決定論的モデルに近似される可能性がある。  
6. 改良されたモデルに関する情報が検出されない可能性がある。  

#### 過程
1. 過程は管理外になる可能性がある。  
2. 過程は予測不可能である可能性がある。  
3. 過程はモデル化できない可能性がある。
