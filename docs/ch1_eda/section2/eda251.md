# 1.2.5.1. 非無作為性の帰結

#### 無作為性の仮定
4つの基本的な仮定がある：

1. 無作為性  
2. 固定された位置  
3. 固定されたばらつき  
4. 固定された分布  

無作為性の仮定が最も重要であるが、最も検定されていない。

#### 非無作為性の帰結
もし無作為性の仮定が成り立たないならば、

1. 通常の統計的検定はすべて無効となる。  
2. 一般的に用いられる統計量に対する計算された不確かさは意味をなさなくなる。  
3. 事前に指定された許容誤差に必要な最小標本数は意味をなさなくなる。  
4. 単純なモデル： $y = 定数 + 誤差$ は無効となる。  
5. 母数推定値は疑わしくなり、支持できなくなる。  

#### 自己相関による非無作為性
特定の非無作為性の共通の型として自己相関が挙げられる。
自己相関とは、$Y_t$と$Y_{t-k}$の間の相関を指し、ここで$k$は自己相関の遅延を定義する整数である。
すなわち自己相関は時間依存性の非無作為性である。
これは、 $k=1$ （または $k$ が1でない場合の $k$ 点前）の場合、現在の点の値が前の点に強く依存することを意味する。
自己相関は通常、[自己相関プロット](../section3/autocopl.md)または[ラグ・プロット](../section3/lagplot.md)によって検出される。
データが自己相関により非無作為である場合、

1. 隣接するデータ値は関連している可能性がある。  
2. 研究対象の現象について、 $n$ 個の独立したスナップ・ショットが存在しないことがある。  
3. 検出されていない「不要な」外れ値が存在することがある。  
4. 検出されていない「情報豊富な」外れ値が存在することがある。
