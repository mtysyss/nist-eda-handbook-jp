# 1.2.5.2. 非固定位置母数の帰結

#### 位置の推定
位置の通常の推定値は平均

$$\bar{Y} = \frac{1}{N} \sum\_{i=1}^{N}{Y\_i}$$

であり、 $N$ 個の測定値 $Y_1,Y_2, ... , Y_N$ から得られる。

#### 非固定位置の帰結
実行順序プロットが固定位置の仮定を支持しない場合、

1. 位置が偏位している可能性がある。  
2. 1つの位置推定値は意味をなさない可能性がある。(過程が偏位している場合）。
3. 位置推定量（例：標本平均）の選択は最適ではない可能性がある。  
4. 平均の不確かさに関する標準的な公式  

$$s(\bar{Y}) = \frac{1}{\sqrt{N(N-1)}} \sqrt{\sum\_{i=1}^{N}{(Y\_i - \bar{Y})^2}}$$  

は不適切であり、数値が楽観的に小さくなっている可能性がある。  
5. 位置推定値が不正確である可能性がある。  
6. 位置推定値は偏っている可能性がある。
