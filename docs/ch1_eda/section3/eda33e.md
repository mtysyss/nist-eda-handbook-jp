# 1.3.3.14. ヒストグラム

#### 目的：単変量データ集合を要約する
ヒストグラムの目的（[Chambers](../../section4/eda43.md)）は、単変量データ集合の分布を図示し、要約することである。 
ヒストグラムは以下の点を視覚的に示す。  

1. データの中心（位置）  
2. データの広がり（すなわち尺度）  
3. データの歪度  
4. 外れ値の存在  
5. データの複数の最頻値の存在  

これらの特徴はデータの適切な分布モデルを強く示唆する。
[確率プロット](eda33m.md)または[適合度](eda35e.md)検定を用いて分布モデルを検定できる。  

本節の[例](eda33e.md#examples)では、ヒストグラムによって明らかにされるいくつかの一般的な特徴の外観を示す。

#### 定義
一般的にヒストグラムは、データの範囲を等間隔の区間（階級と呼ばれる）に分割し作成する。
次に各区間について、データ集合からその区間に含まれるデータの個数を数える。
すなわち  

* 縦軸：頻度（各区間の頻度）  
* 横軸：応答変数  

階級は利用者が任意に定義するか、何らかの体系的な規則によって定義される。
スコット（[Scott 1992](../section4/eda43.md#Scott)）は理論的に導出された複数の規則を提案している。   

累積ヒストグラムはヒストグラムの変形であり、垂直軸は単一区間の頻度だけでなく、その区間と応答変数のより小さい値を持つ全区間の合計頻度を示す。   
ヒストグラムと累積ヒストグラムには、計数を正規化計数で置き換えた派生型がある。
これらの派生型の名称は相対ヒストグラムと相対累積ヒストグラムである。 

頻度を正規化する一般的な方法は2つある。  

1. 正規化カウントは、階級の頻度を観測値の総数で割った値である。
この場合、相対カウントは合計が1（百分率尺度使用時は100）となるよう正規化される。
これは直感的な例であり、ヒストグラム・バーの高さが各階級のデータ比率を表す。  
2. 正規化カウントは、階級内のカウントを観測値の数に階級幅を乗じた値で割ったものである。
この正規化では、ヒストグラムの下の面積（または積分）が1に等しくなる。
確率論的観点では、この正規化により確率密度関数に最も近い相対ヒストグラムと累積分布関数に最も近い相対累積ヒストグラムが得られる。
ヒストグラム上に確率密度関数や累積分布関数を重ねたい場合はこの正規化を使用する。 
この正規化は直感的ではない（相対頻度が1を超えることも許容される）が、ヒストグラムを用いて確率密度関数をモデル化する場合に適切な正規化である。 

#### 論点
ヒストグラムは、以下の質問に対する答えを与えることができる。  

1. データはどのような母集団分布からか。  
2. データの位置はどこか。  
3. データのばらつきはどの程度か。  
4. データは対称分布か、偏り分布か。  
5. データに外れ値はあるか。
