# 1.3.6.5.4. PPCCおよび確率プロット

#### PPCCおよび確率プロット
[PPCCプロット](eda33n.md)は、単一の形状係数を持つ分布の形状係数を推定するために利用する。
形状パ係数の最適値を特定した後、[確率プロット](eda33m.md)を用いて、確率分布の位置および尺度の母数を推定することができる。

#### 利点
この方法の利点は以下の通り。  

* よく理解されている2つの概念に基づいている。  
    1. 確率プロットの直線性（すなわち、直線として描かれる度合い）は、分布の適合度の良さを測る良い指標となる。
    2. 確率プロット上の点間の相関係数は、確率プロットの直線性を評価する良い指標となる。
* 単一の形状係数を持つ多種多様な分布に対して、容易に適用できる手法である。
基本的な要件は、確率プロットとPPCCプロットの両方の計算に必要な[パーセント点](eda362.md#PPF)関数を計算できることである。
* PPCCプロットは、形状係数の感度に関する洞察を提供する。
すなわち、PPCCプロットが形状係数の最適値付近で比較的平坦である場合、これは、適合モデルが形状係数の値におけるわずかな偏差、あるいは場合によっては大きな偏差に対しても敏感ではないことを強く示唆している。
* 最大相関係数は、分布間の比較を行う手段となるだけでなく、特定の分布における形状係数の最適値を特定する手段ともなる。
例えば、Weibull 分布、対数正規分布、およびその他のいくつかの分布について、PPCCおよび確率の適合結果を用いることができます。
各分布で得られた最大相関係数を比較することで、どの分布を使用するのが最適かを選択する際に役立つ。

#### 欠点
この手法の欠点は以下の通り。  

* 形状係数が1つの分布に限定される。
* PPCCプロットは、Dataplot以外の統計ソフトウェア・パッケージでは広く利用できない（Dataplotは40以上の分布についてPPCCプロットを提供している）。
確率プロットは一般的に利用可能である。
しかし、多くの統計ソフトウェア・パッケージでは、限られた数の分布についてのみ提供している。
* 相関係数の有意水準（すなわち、最大相関係数が所定の値を上回る場合、その分布は所定の信頼水準においてデータに適切に適合する）は、限られた数の分布についてのみ導出されている。

#### その他の図表現法
信頼性解析においては、[ハザード・プロット](../../apr/section2/apr222.md)と[Weibull プロット](eda33u.md)が、係数を推定するために一般的に用いられる代替的な可視化法である。
