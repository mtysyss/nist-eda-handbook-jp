# 1.3.1. はじめに  

#### 図表現技法と定量技法  
本節では、探索的および古典的なデータ分析で一般的に使用される多くの技法について説明する。
この一覧は決して網羅的なものではない。
追加の技法（図表現および定量的の両方）については他の章で論じられている。
具体的には、[製品比較](../../prc/prc.md)の章で多くの古典的な統計的技法についてより詳細な説明をしている。 

EDAは図表現技法を重視するのに対し、古典的技法は定量技法を重視する。
実際に分析者は通常、図表現技法と定量技法を組み合わせて使用する。
本節では、説明を「図表現技法」と「定量技法」に分類している。
これは構成上の明確化を目的としたものであり、データ分析において図表現技法と定量技法の双方を併用することを妨げる意図はない。   

#### 事例研究に示される技法の活用  
本節では、手法そのものに焦点を当てる。
グラフや検定の定義方法、公開された参考文献、およびサンプル出力について説明する。
技術的課題への応用例は[事例研究](../section4/eda4.md)節で示す。
事例研究ではすべての技法が紹介されるわけではない。

#### ソフトウェアにおける可用性  
本節のサンプル・プロットおよび出力は、[Dataplotソフトウェアプログラム](../../dataplot.md)を用いて作成されている。
その他の汎用統計データ解析プログラムでも、ここで論じたプロット、区間、検定の大半を生成可能であり、あるいはマクロを記述することで同様の結果を得られる。
