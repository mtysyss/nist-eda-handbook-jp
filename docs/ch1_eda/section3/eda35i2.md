# 1.3.5.18.2. 重要因子

#### 重要因子の特定
データを表現するのに最も適切なモデルを選択したい。
そのためには、以下の2つの目標の調整をとる必要がある。

1. モデルには、すべての重要な要因が含まれていることが望ましい。  
2. モデルは簡潔であるべきである。
つまり、モデルは可能な限り単純であるべきである。  

要するに、モデルにはすべての重要な要因と相互作用を含め、重要でない要因と相互作用は除外したい。  

重要な要因を定義するために7つの基準が用いられる。
これら7つの基準はすべて同等に重要というわけではなく、また、それらが同一の部分集合を導き出すわけでもない。
その場合は、合意された部分集合または重み付けされた合意された部分集合を抽出する必要がある。
実際には、これらの基準の一部はすべての状況に適用できるとは限らない。  

これらの基準は、[渦電流](../../pri/section6/pri611.md)データで検討されている。
最小二乗法を用いて計算された係数推定値は以下に示す通り。

 ```
     係数         推定値
     ---------    --------
     平均          2.65875
     X1            1.55125
     X2           -0.43375
     X1*X2         0.06375
     X3            0.10625
     X1*X3         0.12375
     X2*X3         0.14875
     X1*X2*X3      0.07125
```

実際には、すべての分析においてこれらの基準のすべてが使用されるわけではない（また、一部の分析者は追加の基準を持つ場合もあります）。
これらの基準は有用な指針として提示される。
ほとんどの分析者は、自分にとって最も有用だと考える基準に焦点を当てる。 

#### モデルに用語を含めるための基準　
モデルに因子を残すかの判断に利用できる7つの基準は、以下に要約できる。

1. [係数：工学的有意差](eda35i2.md#係数工学的有意差)  
2. [係数：桁数基準](eda35i2.md#係数桁数基準)  
3. [係数：統計的有意差](eda35i2.md#係数統計的有意差)  
4. [係数：確率プロット](eda35i2.md#係数の正規確率プロット)  
5. [効果：Youden プロット](eda35i2.md#効果推定値のYoudenプロット)  
6. [残差標準偏差：工学的有意差](eda35i2.md#残差標準偏差工学的有意差)  
7. [残差標準偏差：統計的有意差](eda35i2.md#残差標準偏差統計的有意差)  

最初の 4 基準は係数推定値に焦点を当て、そのうち 3つは数値基準、1つは図表現基準である。
5番目の基準は効果に焦点を当て、これは係数推定値の2倍に相当する。
最後の 2基準はモデルの残差標準偏差に焦点を当てている。
これら 7つの基準について、以下の各項目で詳細に説明する。

#### 係数：工学的有意差
工学的に有意最小差は、次式で定義される。

$$ |\hat{\beta\_{i}}| > \Delta $$

ここで、$`|\hat{\beta}_{i}|`$ は係数推定値の絶対値、Δ は工学的に有意な最小差である。  

すなわち、係数推定値があらかじめ定められた工学上の差よりも大きい場合、その因子を「重要」と宣言する。
これは、技術員が実際に最小差を決めていることを意味する。
多くの場合はそうしてない。
事前の閾値が存在しない場合、工学的に有意な最小差Δの適切な目安として、係数推定値が、例えば現在の生産平均の 10％を超える因子のみを残すという方法がある。
この場合、平均的な検出器の感度が 2.5Ωであると仮定する。
これにより、係数が 2.5Ωの 10％、 0.25Ω を超えるすべての因子を（工学的な観点から）有意であると宣言することになる。  

この工学的有意差の最小基準に基づき、X1 と X2 の2つの項を残すべきであると結論付ける。 

#### 係数：桁数基準
桁数の基準は次式で定義される。

$$ |\hat{\beta\_{i}}| < 0.10 \cdot \max |\hat{\beta\_{i}}| $$  

すなわち、最大係数値の 10％未満の因子を除外する。
残りの因子は、保持する場合もあれば、しない場合もある。
この基準は工学的なものでも統計的なものでもないが、数値的な洞察をある程度提供する。
この例では、最大の係数は X1（1.55125 Ω）からのものであり、その 10% は 0.155 Ωとなるため、係数が 0.155 Ωを超えるすべての因子を保持することが示唆される。  

桁数の基準に基づき、X1 と X2 の 2つの項を残すべきであると結論づる。
3番目の項である $`X2*X3(0.14875)`$ は、基準値をやや下回っているだけであるため、他の基準に基づいてこれを残すことも検討する。 

#### 係数：統計的有意差
統計的有意差は次式で定義される。

$$ |\hat{\beta\_i}| > 2 \cdot \mbox{s.e.}(\hat{\beta\_i}) $$  

すなわち、ある因子の係数が 0 から 2標準偏差以上離れている場合、その因子を重要であるとみなす（定義上、0 は「効果なし」を意味する）。
この「2」は正規分布の理論に由来する（より具体的には、1.96 の値を用いると 95％信頼区間が得られる）。
より正確な値は *t*-分布の理論から導かれる。

この方法の難点は、この基準を適用するために観測値の標準偏差 *σ* が必要になることが挙げられる。
これは以下の理由で問題となる。

1. 技術者が *σ* を知らない可能性がある。  
2. 実験に反復がない可能性があり、そのため *σ* のモデルを想定しない推定値が得られない。  
3. 3次以上の交互作用を無視する、時折用いられる仮定を用いて *σ* の推定値を求めることは、工学的な観点からは誤りであることがある。  

渦電流の例では、

1. 技術者は *σ* を知らなかった。  
2. 計画（$`2^3`$ の完全要因計画）には反復実験が含まれて**いなかった**。  
3. 3項以上の交互作用を無視し、単一の項、すなわち$`X1*X2*X3`$ の交互作用のみを除外した *σ* の推定値を導く。

渦電流の例において、3項の交互作用がゼロであると仮定し、したがってゼロを中心とする母集団からの単一の抽出を表すとすれば、係数の標準偏差の推定値は、単に3項の交互作用の推定値（0.07125）となる。
したがって、2標準偏差は 0.1425 となる。
この例では、ルールとしてすべての $` |\hat{\beta}_{i}| `$を残すことになる。  

これにより、X1 (1.55125)、X2 (-0.43375)、および $`X1*X2 (0.14875)`$ の3つの項が残ることになる。 

#### 係数：確率プロット
[確率プロット](eda33m.md)は、次の方法で用いる。  

1. 正規確率プロット：係数推定値の正規確率プロット上で、ある因子がゼロを通る直線から大きく外れている場合、その因子を「重要」とみなす。  
2. 半正規確率プロット：係数推定値の絶対値を用いた半正規確率プロットにおいて、因子がゼロ付近の直線から十分に外れている場合、その因子を「重要」とみなす。  

これら両方の方法は、2水準直交計画における係数の最小二乗推定値が、単に平均値の差の半分に過ぎないという事実に基づいており、したがって、中心極限定理を大まかに適用すると、（重要な要因がない場合）係数推定値は平均 0 の正規分布をほぼ示し、推定値の絶対値は半正規分布を示すべきであると示唆される。

半正規確率プロットは、符号付き係数（初期の因子符号化である +1 および -1 の割り当て方法の気まぐれな影響を受ける）とは対照的に、係数の大きさのみを扱うため、一部の研究者からは正規確率プロットよりも好まれている。 

#### 係数の正規確率プロット
以下の正規確率プロットは、渦電流データに対する係数推定値を示している。

![1.3.5.18.2.Important Factors fig1](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35i2_r01.gif)  

この例では、確率プロットにおいて 2つの因子（ X1 と X2 ）が直線から外れていることが明確に判る。
残りの 5つの係数はすべて、中心が 0 の正規分布から無作為に抽出されたような挙動を示し、したがって統計的に有意ではないとみなされる。
結論として、このルールにより、X1（1.55125）とX2（-0.43375）の2つの因子が保持される。 

#### 平均値：Youden プロット
[Youden プロット](eda33v.md)は次の方法で利用する。
高値・低値の平均値を示すYouden プロットにおいて、ある要因が中央値の「塊」から外れている場合、その要因を「重要」とみなす。
定義上、ある要因は、低値（-1）設定における平均応答が、高値（+1）設定における平均応答と有意に異なる場合に、重要であるとみなされる。 （なお、効果は係数推定値の2倍であることに注意。）
逆に、低値と高値の平均がほぼ同じである場合、どちらの設定を使用しても結果に差が生じず、そのような因子を重要とみなす理由はない。
この事実と、項目の対を比較する上で Youden プロットが持つ固有の利点を組み合せ、低値と高値の平均を用いた Youden プロットを作成する技法が導かれる。

#### 効果推定値のYoudenプロット
以下は、渦電流データの効果推定値の Youden プロットである。

![1.3.5.18.2.Important Factors fig2](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35i2_r02.gif)  

この例において、Youden プロットは、全体平均（2.65875）付近に点の群が集まっていることを明確に示し、その上（因子1）と下（因子2）に2つの外れた点が存在する。
Youden プロットに基づき、X1（1.55125）とX2（-0.43375）の2つの因子を保持すると結論付ける。 

#### 残差標準偏差：工学的有意差
この基準は次式で定義される。  

$$\text{残差標準偏差} > \text{閾値}$$  

すなわち、ある因子（およびそれより大きなすべての因子）を含む累積モデルが、事前の工学的基準で定められた最小残差標準偏差よりも小さい場合、その因子を「重要」と判定する。  

この基準は、モデルに焦点を当る点で他の基準とは異なる。
実際には、この基準は、最大の係数から始め、モデルに項を累積的に追加し続け、加算的に複雑になる各モデルの残差標準偏差がどのように小さくなっていくかを監視することを意味する。
ある時点で、累積モデルは十分に複雑かつ包括的になり、その結果として得られる残差標準偏差が、事前に規定された残差標準偏差の閾値を下回る。
その時点で項の追加を停止し、モデルに含まれるすべての項を「重要」と宣言し、モデルに含まれないものはすべて「重要でない」とみなす。  

この手順は、技術者が残差標準偏差の最小値がどの程度であるべきかを検討していることを意味する。
実質的に、これは典型的な残差（生データとモデルによる予測値との差）の大きさを、技術者がどの程度許容できるかに関わる。
言い換えれば、技術者が予測式にどの程度の精度を求めるかということになる。
残念ながら、この技術的仕様が常に策定されているとは限らず、そのため、この基準は意味をなさなくなる可能性がある。  

事前に定められた閾値がない場合、最小の工学的残差標準偏差に関する良い目安として、残差標準偏差が、例えば現在の生産平均の 5％をわずかに下回るまで項を追加し続けることが挙げられる。
渦電流データについて、平均的な検出器の感度が 2.5 Ωであると仮定する。
これにより、残差標準偏差が 2.5 Ωの 5% である 0.125 Ωを下回るまで、モデルに項を追加し続けることが示唆される。  

 ```
モデル                                                      残差標準偏差
-----------------------------------------------------      ---------
平均 + X1                                                    0.57272
平均 + X1 + X2                                               0.30429
平均 + X1 + X2 + X2*X3                                       0.26737
平均 + X1 + X2 + X2*X3 + X1*X3                               0.23341
平均 + X1 + X2 + X2*X3 + X1*X3 + X3                          0.19121
平均 + X1 + X2 + X2*X3 + X1*X3 + X3 + X1*X2*X3               0.18031
平均 + X1 + X2 + X2*X3 + X1*X3 + X3 + X1*X2*X3 + X1*X2            NA
```

最小残差標準偏差の基準に基づけば、残差標準偏差を 0.125未満にするために、**すべての**項を含めることになる。
繰り返しになるが、この 5％ルールは、工学や統計学に基づくものではなく、単なる「経験則」に過ぎない。
理想的には、技術者は実用上、式にどの程度の精度を求めるかに基づき、残差標準偏差に対するより適切な閾値を設定する。
もしその数値が利用可能であれば、この基準とデータ集合に対して、項の全集合よりも少ない数を選択することになる。 

#### 残差標準偏差：統計的有意差
この基準は次式で定義される。  

$$\text{残差の標準偏差} > σ$$  

ここで、*σ*は 反復条件下における観測値の標準偏差である。  

すなわち、その項を含む累積モデルの残差標準偏差が *σ* より小さくなるまで、その項を「重要」と宣言する。
本質的に、データを複製した場合に得られるものよりも優れたモデル適合を要求することはできないと認めている。
つまり、いかなる推定モデルからの残差標準偏差も、（理論的または実際の）複製標準偏差よりも小さくすることを要求することはできない。（項を追加することで）推定標準偏差を *σ* に近い値になるまで下げることはできるが、それ以上下げようとすることは、実質的にノイズを推定しようとしていることに等しい。  

実際には、以下の理由でこの基準の適用が難しい場合がある。  

1. 技術者が *σ* を知らない可能性がある。  
2. 実験に反復測定がない場合があり、そのためモデルを想定しない *σ* の推定値が得られない可能性がある。

今回の事例研究では、  
1. 技術者は *σ* を知らなかった。  
2. 実験計画（$`2^3`$ の完全実施要因計画）には反復が設定されていなかった。
このような計画において反復を設ける最も一般的な方法は、立方体の中心（$`(X1,X2,X3) = (0,0,0)`$）に反復された中心点を配置することである。  

したがって、今回の場合では、この基準を用いて「重要な」要因の部分集合を導き出すことは**できなかった**。

#### 結論
要約すると、「重要な」要因を特定するための 7つの基準を適用した結果、渦電流データについては以下の結果が得られた。   

1. 係数、工学的有意差：　　　　　X1, X2  
2. 係数、数値的有意差：　　　　　X1, X2  
3. 係数、統計的有意差：　　　　　X1、X2、X2×X3  
4. 係数、確率プロット：　　　　　X1、X2  
5. 効果、Youden プロット：　　　X1、X2  
6. 残差標準偏差、工学的有意差:　全7項  
7. 残差の標準偏差、統計的有意差:該当なし  

このような矛盾した結果はよくある。
議論の余地はあるものの、最も重要な 3つの基準（重要度の高い順に列挙）は以下の通り。　 

　4\. 係数、確率プロット：　　　　　X1、X2  
　1\. 係数、工学的有意差：　　　　　X1、X2  
　3\. 残差の標準偏差、工学的有意差：全7項  

以上の内容を検討した結果、渦電流データに関して以下の合意に達した。

1. 重要な要因：X1 および X2  
2. 簡潔な予測式：  

$$ \hat{Y} = 2.65875 + 1.55125 \cdot X\_1 - 0.43375 \cdot X\_2 $$  

（残差標準偏差：0.30429 Ω）

なお、これは初期のモデル選択であることに留意されたい。
残差分析を用いたモデル検証をまだ行う必要がある。
