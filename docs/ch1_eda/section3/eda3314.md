# 1.3.3.1.4. 自己相関プロット：正弦波モデル

#### 正弦波モデルの自己相関プロット
以下は、[LEW.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/LEW.DAT)の自己相関プロットのサンプルである。 
![1.3.3.1.4.Autocorrelation Plot: Sinusoidal Model](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/autocop4.gif)

#### 結論
上記のプロットから以下の結論が導き出せる。

1. データは正弦波モデルに基づいている。

#### 議論
プロットには正と負のスパイクが交互に現れる。
これらのスパイクはゼロに減衰しない。
このようなパターンは正弦波モデルの自己相関プロットの特徴である。
