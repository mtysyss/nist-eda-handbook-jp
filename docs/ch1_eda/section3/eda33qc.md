# 1.3.3.26.12. 条件付きプロット

#### 目的：第三の変数を条件として、二つの変数間の対関係の確認
コプロットまたは部分集合プロットとも呼ばれる条件付きプロットは、第三の変数（条件変数と呼ばれる）の値を条件として、二つの変数をプロットしたものである。
条件変数は、離散的な値をわずかしか取らない変数でも、限られた数の部分集合に分割された連続変数でもよい。  
 
[散布図行列](eda33qb.md)の制限の一つは、他の変数との相互作用効果を示せない点である。
これが条件付きプロットの強みである。
また、データの群ごとの散布図を表示するのにも有用である。
これらの群は異なるプロット記号を用いて単一のプロット上に描画することも可能であるが、条件付きプロットを用いることで視覚的に群を区別しやすくなる場合が多い。  

条件付けプロット行列の基本概念は単純だが、プロットの詳細には数多くの代替手法がある。  

1. 散布図に何らかの近似曲線を重ねることは有用である。
線形または二次近似も使用可能であるが、最も一般的な代替案は[lowess](../../ch4_pmd/section1/pmd144.md)曲線を重ねることである。  
2. ププロット数が膨大になる可能性があるため、軸ラベルを情報量豊富かつ視覚的に好ましい形で表示するのはやや難しいことがある。
効果的な代替案として、行と列を交互にラベル表示する方法がある。
具体的には、1行目では最初のプロットのみ左縦軸に目盛線と軸ラベルを表示し、2行目では最後のプロットの右縦軸にのみ目盛線と軸ラベルを表示する。
この交互パターンは残りの行でも行う。
列と横軸ラベルにも同様のパターンを適用する。
この手法は、すべてのプロットに対して軸の範囲が共通の値に固定されている場合にのみ機能することにを留意する。  

3. 散布図を余白無しで繋げるのを好む分析者もいれば、各プロット間にわずかな間隔を空けることを好む者もいる。
あるいは、繋げないプロットで独自のラベル付けを各プロットに付けることもできる。  

6. このプロット形式は散布図に最も頻繁に使用されるが、基本概念は単純かつ強力であり、他のプロット形式へも容易に拡張可能である。 

#### プロット例  
![1.3.3.26.12.Conditioning Plot](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/condplot.gif)  

[PR1.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/PR1.DAT)のこのプロットでは、温度は6つの異なる値を持っている。
これらの各温度について、トルクと時間を打点する。
この例は、[工程モデル化](../../ch4_pmd/section1/pmd11.md#例)の章でより詳細に議論する。 

#### 定義
変数$`X`$、$`Y`$、$`Z`$が与えられたとき、条件プロットの$`Z`$の値を$`k`$群に分割し作成する。
これらの群はいくつかの方法で作成可能である。
データの自然な群分け、等しい規模の複数群への分割、データ内の層別に基づく群分けなどが考えられる。
ページを$`nc≥k`$になりように、$`n`$行と$`c`$列に分割する。
各行と各列で一つの散布図を定義する。  
行 $`i`$ と列 $`j`$ の個別のプロットを以下の条件で定義する。  

* 縦軸：変数 $`Y`$  
* 横軸：変数 $`X`$  

ここで、$`i`$行と$`j`$列に対応する群内の点のみを使用する。 

#### 論点
条件付けプロットは、以下の質問に対する答えを与える。  

1. 二つの変数間に関係性はあるか。  
2. 関係性が存在するならば、その関係の性質は第三の変数の値に依存するか。  
3. データの群は類似しているか。  
4. データに外れ値はあるか。

#### ソフトウェア
条件付きプロットは、RやDataplotを含む汎用統計ソフトウェアでますます一般的になりつつある。
もしソフトウェアが条件付きプロットを出力しない場合でも、1ページに複数のプロットや散布図を出力できるなら、条件付きプロットを出力するマクロを作成することは可能である。
