# 1.3.3.26.10. 散布図：外れ値

#### 外れ値を示す散布図
![1.3.3.26.10.Scatter Plot: Outlier](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/scatploa.gif)  

#### 議論
この散布図は以下の点を明らかにしている。 

1. ほとんどのデータにおいて$`X`$と$`Y`$の間に基本的な直線関係が認められ  
2. ひとつの異常値（$`X=375`$）がある。  

外れ値は、他のデータとは異なるモデルから生じるデータ点として定義される。
ここでのデータは、特定の傾きとばらつきを持つ線形モデルからのように観えるが、外れ値は別のモデルから得られたように観える。

外れ値検出は、効果的なモデル化にとって重要である。
外れ値はそのようなモデル適合から除外すべきである。
もしここでのすべてのデータが線形回帰に含まれるならば、近似モデルは事実上どこでも不十分になる。
外れ値が近似過程から除外された場合、結果として得られる近似はほぼすべての場所で優れたものとなる（外側を除くすべての点）。
