# 1.3.3.15.2. 遅延プロット：中程度の自己相関

#### 遅延プロット
![1.3.3.15.2.Lag Plot: Moderate Autocorrelation](https://www.itl.nist.gov/div898/handbook/eda/gif/lagplot2.gif)  

#### 結論
上記の[FLICKER.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/FLICKER.DAT)のプロットに基づくと、以下の結論を導くことができる。  

1. データは中程度の正の自己相関を持つ自己回帰モデルから得られたものである。  
2. データに外れ値はない。  

#### 議論
上記のラグ＝1のプロットでは、点が対角線に沿って（ノイズはあるものの）集まる傾向に注目する。
このような密集は、中程度の自己相関の遅延プロットにおける特徴である。  

もし過程が完全に無作為であれば、現在の観測値（例えば $`Y_{i-1}= 0`$）の知識は次の観測値 $`Y_i`$ について
実質的に何の知見も与えない。
上記のように、過程に中程度の自己相関があり、かつ$`Y_{i-1}=0`$ の場合、$`Y_i`$ の取り得る値の範囲はより狭い範囲（-0.01から+0.01）に制限されることがわかる。
これは自己回帰モデルを用いた予測が可能であることを示唆している。 

#### 推奨される次の手順
自己回帰モデルの係数を推定する。  

$$Y_i=A_0+A_1*Y_{i-1}+E_i$$  

$`Y_i`$ と $`Y_{i-1}`$ は遅延プロットの軸そのものであるため、この推定は遅延プロットから直接行われる[線形回帰](../../pmd/section1/pmd141.md)である。  

自己回帰モデルの残差標準偏差は、以下の初期模型の残差標準偏差よりもはるかに小さくなる。

$$Y_i=A_0+E_i$$
