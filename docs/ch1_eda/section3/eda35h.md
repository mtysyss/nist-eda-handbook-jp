# 1.3.5.17. 外れ値の検出

#### はじめに
外れ値とは、標本内の他の観測値から著しく逸脱しているように見える観測値である。

外れ値の可能性の特定は、以下の理由から重要である。

1. 外れ値は、適切でないデータを示している可能性がある。
例えば、データの記録の誤りや実験が正しく行われていない可能性がある。
もし、その外れ値が実際に誤りであると判断できる場合は、その外れた値を分析から削除すべきである（もしくは、可能であれば修正すべきである）。  
2. 場合によっては、外れた値が不良データであるかを判断できないこともある。
外れ値は、無作為なばらつきによるものかもしれないし、科学的に興味深いことを示している可能性もある。
いずれにせよ、通常は外れた観測値を単純に削除することは望ましくない。
しかし、データに著しい外れ値が含まれている場合は、頑健な統計技法の使用を検討する必要がある。 

#### 表示、対応、識別
[IglewiczとHoaglin](../section4/eda43.md#Iglewicz) は、外れ値に関して以下の3つの問題を区別している。  

1. 外れ値の標識付け - さらなる調査のために潜在的な外れ値に印を付ける（すなわち、その外た可能性の値が誤ったデータであるか、不適切な分布モデルを示しているか、など）。  
2. 外れ値への対応 - 外れ値の影響を過度に受けない頑健な統計技法を用いる。
すなわち、潜在的な外れ値が誤った観測値であるかを判断できない場合、これらの観測値をより適切に考慮するために統計解析を修正する必要があるか。  
3. 外れ値の特定 - 観測値が外れ値であるかを正式に検定する。

本節では、標識付けと識別に関する問題に焦点を当てる。

#### 正規性の仮定
観測値を外れ値として特定するかは、データの基礎となる分布に依存する。
本節では、おおよそ正規分布に従うと仮定される一変量データ集合に限定して議論する。
検定対象のデータに対する正規性の仮定が成立しない場合、外れ値が存在するという判断は、実際には外れ値の存在ではなく、データの非正規性に起因している可能性がある。  

このため、外れ値検定を適用する前に、データの[正規確率プロット](eda33l.md)を作成することが推奨される。
正規性の正式な検定を行うことも可能だが、1つ以上の外れ値が存在すると、実際には外れ値検定を適用する上で妥当な仮定であるにもかかわらず、検定によって正規性が棄却されてしまうことがある。  

正規性の仮定を確認することに加え、正規確率プロットの下側および上側の裾は、潜在的な外れ値を特定するための有用な図表現技法である。
特に、このプロットは、単一の外れ値を確認すべきか、あるいは複数の外れ値を確認すべきかを判断するのに役立つ。  

[箱ひげ図](eda337.md)や[ヒストグラム](eda33e.md)も、正規性の仮定を確認し、潜在的な外れ値を特定する上で有用な視覚的ツールである。 

#### 単一と複数の外れ値
外れ値検定の中には、単一の外れ値の存在を検出するように設計されたものもあれば、複数の外れ値の存在を検出するように設計されたものもある。
複数の外れ値を検出するために、単一の外れ値用の検定を順次適用することは適切ではない。  

さらに、複数の外れ値を検出する検定には、疑わしい外れ値の数を正確に指定する必要があるものもある。 

#### 隠蔽と埋没
検定において少な過ぎる外れ値数を指定した場合、隠蔽（訳註：masking）が起きることがある。
例えば、実際には2つ（またはそれ以上）の外れ値が存在するにもかかわらず、1つの外れ値のみを検定対象とした場合、複数の外れ値が検定統計量の値に過剰な影響を与え、結果としてどの点も外れ値として判定されなくなる可能性がある。  

一方、検定で外れ値の指定が多過ぎると、埋没（訳註：swamping）が起きることがある。
例えば、実際には外れ値が1つのみであるにもかかわらず、2つ以上の外れ値があるかの検定を行うと、両方の点が外れ値として判定される可能性がある（多くの検定では、検定対象の点をすべて外れ値として判定するか、あるいはすべて外れ値として判定しないかのどちらかになる）。  

隠蔽や埋没の可能性があるため、形式的な外れ値検定を図表現の方法で補完することが有用である。
図は、隠蔽や埋没が問題となり得る場合を特定するのに役立つことが多い。
また、隠蔽と埋没は、多くの検定において検定対象となる外れ値の正確な数を指定する必要がある理由でもある。  

さらに、隠蔽は、単一の外れ値検定を順次適用しようとした場合に失敗する原因の一つでもある。
例えば、複数の外れ値が存在する場合、隠蔽によって、最初の外れ値に対する検定が外れ値なしという結論を返す可能性がある（その結果、それ以降の外れ値に対する検定が実行されない）。 

#### 標準化得点と修正標準化得点
観測値の標準化得点（訳註：Z-Score）は次式で定義される。

$$Z_i = \frac{Y_i - \bar{Y}} {s}$$  

ここで、$`\bar{Y}`$  および $`s`$ は、それぞれ標本平均と標本標準偏差を表す。
言い換えれば、データは平均から何標準偏差離れているかという単位で表される。

標準化得点を用いた外れ値候補の特定は一般的なやり方であるが、最大標準化得点は高々 $`(n-1)/\sqrt{n}`$ である事実により、（特に標本規模が小さい場合）誤解を招く恐れがある。  

[IglewiczとHoaglin](../section4/eda43.md#Iglewicz)は、以下の修正標準化得点の使用を推奨している。  

$$M_{i} = \frac{0.6745(x_{i} - \tilde{x})} {\mbox{MAD}}$$  

ここで、MADは[中央絶対偏差](../section3/eda356.md#MAD)であり、$`\tilde{x}`$ は中央値である。  

これらの著者は、絶対値が 3.5 を超える修正標準化得点を潜在的な外れ値として標識付けすることを推奨している。 

#### 正式な外れ値検定
文献では、多くの正式な外れ値検定が提案されている。
これらは、以下の特徴によって分類することができる。  

* データの分布モデルはなにか。ここでは、データが近似的に正規分布に従うことを仮定する検定に限定して議論する。  
* 検定は単一の外れ値を対象としているか、複数の外れ値を対象としているか。
* 検定が複数の外れ値を対象としている場合、外れ値の数を正確に指定する必要があるか、上限を指定するだけでよいか。  

以下は、正規分布に従うデータに対して一般的に使用される外れ値検定の例である。
この一覧は網羅的なものではない（文献では多数の外れ値検定が提案されている）。
ここで示す検定は、本質的に「平均からの距離」という基準に基づいている。
これは使用可能な唯一の基準ではない。
例えば、ここでは扱わない Dixon 検定は、その値が最も近い近傍の値と比較して大き過ぎる（または小さ過ぎる）という事実に基づいている。

1. [Grubbs 検定](eda35h1.md) - 単一の外れ値を検定する場合に推奨される検定である。  
2. [Tietjen-Moore 検定](eda35h2.md) - 1つ以上の外れ値がある場合の Grubbs 検定の一般化である。
外れ値の数を正確に指定しなければならないという制限がある。  
3. [一般化極値スチューデント化偏差(ESD) 検定](eda35h3.md) - 外れ値推定数の上限のみ必要であり、外れ値の正確な数が不明な場合に推奨される検定である。  

#### 対数正規分布
ここで取り上げる検定は、データが近似的に正規分布に従うという仮定に基づいている。
もしデータが近似的に[対数正規分布](eda3669.md)に従う場合は、データに対数変換を施して正規分布に近づけた上で、ここで取り上げる外れ値検定を適用する。

#### 追加情報
[IglewiczとHoaglin](../section4/eda43.md#Iglewicz) は、前述の外れ値検定（および前述されていないものも含む）について詳細に報告し、外れ値に関する優れた解説をしている。
[BarnettとLewis](https://www.itl.nist.gov/div898/handbook/eda/section4/eda43.md#Barnett)は、このテーマについて書籍一冊分の分量で扱っている。  

これらの文献では、近似的に正規分布に従うデータに対する追加の検定について論じているだけでなく、データが正規分布に従わない場合についても論じている。
