# 1.3.3.28. 標準偏差プロット

#### 目的：群間の尺度変化の検出
標準偏差プロットは、データの異なる群間で標準偏差が変動しているかを確認するために用いる。
群は分析者が決める。
多くの場合、データ自体が特定の群化変数を与える。
例えば、群は因子変数の水準のこともある。
以下のプロット例では、各年の月で群化されている。  

標準偏差プロットは、群化されていないデータに対しても使用でき、標準偏差が時間経過とともに変化しているかどうかを判断できます。
この場合は、データを任意の数の等しい規模の群に分割する。
例えば、400点のデータ系列であれば、各40点の10群に分割する。
これらの群を用いて平均プロットを作成し、平均が時間とともに増加しているか減少しているかを確認する。

標準偏差は尺度を測る最も一般的な指標だが、この概念は他の尺度測定にも適用される。
例えば、各群の標準偏差をプロットする代わりに、[中央絶対偏差](eda356.md#中央絶対偏差)や[平均絶対偏差](eda356.md#平均絶対偏差)をプロットすることある。
これはデータに顕著な外れ値が存在し、標準偏差よりも頑健な尺度測定が求められる場合に実施する。 

標準偏差プロットは通常、[平均プロット](eda33k.md)と組み合わせて用いる。
平均プロットは位置の偏りを確認するために用い、標準偏差プロットは尺度の偏りを確認するために用いる。 

#### プロット例  
![1.3.3.28.Standard Deviation Plot](https://www.itl.nist.gov/div898/handbook/eda/gif/sdplot.gif)  

[PBF11.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/PBF11.DAT)のこの標準偏差プロット例は、以下の点を示している。

1. ばらつきに偏位が生じている。  
2. ばらつきが最も大きいのは夏季である。  

#### 定義：群標準偏差 対 群ID
標準偏差プロットは以下の条件で作成する。  

* 縦軸：群の標準偏差  
* 横軸：群識別子  

基準線はは、全体の標準偏差の位置に引く。

#### 論点
標準偏差プロットは、以下の質問の答えを与える。  

1. ばらつきに偏位はあるか。  
2. ばらつきの偏位の大きさはどの程度か。  
3. ばらつきの偏位に明確なパターンがあるか。  

#### 重要：仮定の確認
1因子分析における一般的な仮定は、分散が等しいというものである。
すなわち、因子変数の異なる水準間で分散が同じであるという仮定である。
標準偏差プロットはこの仮定を視覚的に確認する手段である。
単変量データにおける一般的な仮定に、分散一定がある。
データを等間隔に群化することで、標準偏差プロットはこの仮定を視覚的に検定できる。

#### ソフトウェア
ほとんどの汎用統計ソフトウェアは標準偏差プロットを実装していない。
ただし、統計プログラムが群ごとの標準偏差を出力できるならば、このプロットを出力するマクロを作成することは可能だろう。
