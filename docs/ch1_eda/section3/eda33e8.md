# 1.3.3.14.8. ヒストグラムの解釈：外れ値を含む対称

#### 外れ値を含む対称ヒストグラム
![1.3.3.14.8.Histogram Interpretation: Symmetric with Outlier](https://www.itl.nist.gov/div898/handbook/eda/gif/histogr8.gif)  

#### 外れ値に関する議論
上のプロットは、[ZARR13.DATデータ](https://www.itl.nist.gov/div898/handbook/datasets/ZARR13.DAT)に9.45の値を4つ追加したヒストグラムである。  

対称分布とは、ヒストグラムの2つの「半分」が互いに鏡像のように見える分布である。
上記の例は、Y = 4.5付近の異常値を除けば対称的である。  

外れ値とは、データ全体と分布（位置、尺度、分布の形）が異なるデータ点である。
現実では、外れ値には単純なものから以下の様々な原因がある。    

1. 操作ミス  
2. 機器の故障  
3. 日々の影響  
4. ロット間の差異  
5. 異常な入力条件  
6. 暖機効果  

より小さな原因として以下などがある。  

1. 応答に影響を与える要因の設定変更（意図的・無意識を問わず）  
2. 自然は私たちに伝えようとしている何か。 

#### 異常値は調査すべき
すべての外れ値を真剣に受け止め、それを説明するために徹底的に調査すべきである。
自動的な外れ値除去機構（例えば標本平均から4標準偏差を超える全データを排除）は特に危険である。  

自動外れ値除去が自動情報除去へと変質した典型例が南極オゾン層破壊問題である。
南極上空のオゾン層破壊は、低オゾン値を記録した衛星データに外れ値除去コードが組み込まれておらず、分析前に「外れ値」（すなわち低オゾン値）が自動的に排除されなければ、数年早く検出されていたはずである。 
このような不注意（かつ誤った）排除が何年も続いた。
南極の地上観測で低オゾン値が検出され始めて初めて、衛星がなぜこの事実を捉えられなかったのか再確認する者が現れ、衛星は捉えていたが、除外されていたのだった。  

最善の姿勢は、外れ値を「友」と見なし、外れ値が何かを伝えようとしていると捉え、各外れ値の説明に納得できるまで調査を止めるべきではないという考え方である。 

#### 推奨される次の手順
ヒストグラムに外れ値が存在する場合に推奨される手順は次のとおり。  

1. [箱ひげ図](eda37.md)を作成し、（一般的に見られる通常の場合）外れ値を視覚的に確認する。
一般的に、箱ひげ図はヒストグラムよりも外れ値検出においてはるかに優れた可視化ツールである。  

2. 一般的に見られる通常の場合では、対象データが標本平均からどの程度、標準偏差離れているかを示す[Grubbs検定](eda35h.md)を実施し、外れ値を定量的に確認する。
大きな値は外れ値を示す。
