# 1.3.6.3. 分布族

#### 形状係数
多くの確率分布は単一の分布ではなく、実際には分布族を形成している。
これは、その分布が 1つ以上の形状係数を持つためである。  

形状係数により、分布は形状係数の値に応じて様々な形状をとることができる。
これらの分布は、多様なデータ集合をモデル化できるほど柔軟性が高いため、モデル化の応用において特に有用である。 

#### 例：Weibull 分布
[Weibull 分布](eda3668.md)は、形状係数を持つ分布の一例である。
次のグラフは、形状係数の値を 0.5、1.0、2.0、および 5.0 とした場合の Weibull 分布の確率密度関数をプロットしたものである。  

![sample Weibull distribution](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/weibshap.gif)  

上記の形状には、指数分布、右偏り分布、および比較的対称な分布が含まれる。  
 
Weibull 分布は比較的単純な分布形式を持っている。
しかし、形状係数によって、Weibull 分布は多種多様な形状をとることができます。
Weibull 分布のこの単純さと形状の柔軟性の組合せにより、信頼性解析の分野において有効な分布モデルとなっている。
比較的単純な分布形式を用いて多種多様な分布形状をモデル化できるこの能力は、他の多くの分布族においても同様に可能である。 

#### PPCCプロット
[PPCCプロット](eda33n.md)は、与えられたデータセットに最もよく適合する、単一の形状係数を持つ分布族から分布を選択するための、効果的な可視化ツールである。
