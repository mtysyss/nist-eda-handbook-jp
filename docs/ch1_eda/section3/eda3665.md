# 1.3.6.6.5. F分布

#### 確率密度関数
F 分布は、自由度をそれぞれ $`ν_1`$ および $`ν_2`$ とする二つの[カイ二乗](eda3666.md)分布の比であり、各カイ二乗分布はまずその自由度で除算される。
F 分布の[確率密度関数](eda362.md#確率密度関数)は次式である。  

$$f(x) = \frac{\Gamma(\frac{\nu_{1} + \nu_{2}} {2}) (\frac{\nu_{1}} {\nu_{2}})^{\frac{\nu_{1}} {2}} x^{\frac{\nu_{1}} {2} - 1 }} {\Gamma(\frac{\nu_{1}} {2}) \Gamma(\frac{\nu_{2}} {2}) (1 + \frac{\nu_{1}x} {\nu_{2}})^{\frac{\nu_{1} + \nu_{2}} {2}} } $$

ここで $`ν_1`$ と $`ν_2`$ は形状母数であり、$`Γ`$ はガンマ関数である。
ガンマ関数は次式である。  

$$\Gamma(a) = \int_{0}^{\infty} {t^{a-1}e^{-t}dt}$$

検定では、F 分布は「標準化分布」（すなわち、位置母数や尺度母数を持たない）として扱われる。
しかし、分布モデルの検討（他の確率分布と同様に）では、F 分布自体に[位置母数](eda364.md) *μ* と[尺度母数](eda364.md) *σ* を用いて変換することが可能である。

以下は、形状母数の4つの異なる値での F 確率密度関数のプロットである。  

![plot of the F probability density functionfor 4 different values of the shape parameters ](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/fpdf4.gif)  

#### 累積分布関数
F 分布の[累積分布関数](eda362.md#確率密度関数)は次式である。  

$$F(x) = 1 - I_{k}(\frac{\nu_{2}} {2},\frac{\nu_{1}} {2} )$$

ここで $`k=\nu_2/(\nu_2 + \nu_1 \cdot x)`$であり、$`I_k`$は不完全ベータ関数である。
不完全ベータ関数は次式である。 

$$I_{k}(x,\alpha,\beta) =\frac{\int_{0}^{x} {t^{\alpha-1}(1-t)^{\beta-1}dt}} {B(\alpha,\beta) }$$  


ここで $`B`$ は次式のベータ関数である。

$$B(\alpha,\beta) = \int_{0}^{1} {t^{\alpha-1}(1-t)^{\beta-1}dt}$$  

以下は。上記の確率密度関数プロットと同じ $`ν_1`$ および $`ν_2`$ の値を用いた F 累積分布関数のプロットである。

#### 他の確率関数
F 分布は仮説検定や信頼区間の構築に用いられることが多く、モデル化用途ではほとんど使用されないため、ハザード関数、累積ハザード関数、生存関数、逆生存確率関数に関する公式や図表は省略する。

#### 共通統計量 　
以下の式は、位置母数がゼロで尺度母数が1の場合のものである。

平均　　　　$`\frac {\nu_{2}} {(\nu_{2} - 2)} \qquad  \nu_{2} > 2`$  
最頻値　　　$`\frac {\nu_{2}(\nu_{1} - 2)} {\nu_{1}(\nu_{2} + 2)}\qquad  \nu_{1} > 2`$  
範囲　　　　0から$`\infty`$  
標準偏差　　$`\sqrt{\frac {2\nu_{2}^{2}(\nu_{1} + \nu_{2} - 2)}{\nu_{1}(\nu_{2} - 2)^{2}(\nu_{2} - 4)}} \qquad \nu_{2} > 4`$  
変動係数　　$`\sqrt{\frac{2(\nu_{1} + \nu_{2} - 2)} {\nu_{1}(\nu_{2} - 4)}}\qquad  \nu_{2} > 4`$  
歪度　　　　$`\frac {(2\nu_{1} + \nu_{2} - 2)\sqrt{8(\nu_{2} - 4)}}{\sqrt{\nu_{1}}(\nu_{2} - 6)\sqrt{(\nu_{1} + \nu_{2} - 2)}}\qquad  \nu_{2} > 6`$  

#### 母数推定
F 分布は仮説検定や信頼区間の構築に用いられることが多く、モデル化用途ではほとんど使用されないため、母数推定に関する議論は省略する。

#### 解説  
F 分布は、仮説検定における臨界領域や信頼区間の決定に多くの場合用いられる。
代表的な例として、[分散分析](../prc/section4/prc42.md)と二つの母集団の分散が等しいかを判定する[F 検定](eda359.md)が挙げられる。

#### ソフトウェア
ほとんどの汎用統計ソフトウェアは、F 分布の確率関数の一部を実装している。
