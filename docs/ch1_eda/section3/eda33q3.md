# 1.3.3.26.3. 散布図：強い線形（負の相関）関係

#### 強い負の相関を示す散布図
![1.3.3.26.3.Scatter Plot: Strong Linear (negative correlation) Relationship](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/scatplo3.gif)  

#### 議論
上記のプロットでは、直線がデータに直線がデータに問題なく適合している点に注目する。
したがって、線形関係が成立している。
直線からの散らばりが非常に小さいため、強い線形関係が存在する。
直線の傾きは負である（$`X`$の値が小さいと$`Y`$の値が大きく、$`X`$の値が大きいと$`Y`$の値が小さくなる）。
故に、$`X`$ と$`Y`$の間には負の相関（すなわち負の相関関係）が存在する。
