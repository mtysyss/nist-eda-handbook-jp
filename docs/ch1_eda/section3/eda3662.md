# 1.3.6.6.2. 一様分布

#### 確率密度関数
一様分布の[確率密度関数](eda36.md#確率密度関数)の一般式は次式である。  

$$f(x) = \frac{1} {B - A} \qquad \mbox{ただし} A \le x \le B$$  

ここで A は[位置母数](eda364.md)、(B - A) は[尺度母数](eda364.md)である。
A = 0 および B = 1 の場合を**標準一様分布**と呼ぶ。
標準一様分布の式は  

$$ f(x) = 1 \qquad \mbox{for} 0 \le x \le 1$$  

確率関数の一般形は[標準分布を用いて表現](eda364.md#標準形に基づく位置と尺度の公式)できるため、本節以降の式はすべて関数の標準形について示す。

#### 共通統計量 　
平均値　　　　　　$`(A + B)/2`$  
中央値　　　　　　$`(A + B)/2`$  
範囲　　　　　　　$`B - A`$  
標準偏差　　　　　$`\sqrt{\frac{(B - A)^{2}} {12}}`$  
変動係数　　　　　$`\frac{(B - A)} {\sqrt{3}(B + A)}`$  
歪度　　　　　　　0  
尖度　　　　　　　9/5  

#### 母数推定
AとBのモーメント推定量は以下の通り。  

$$\hat{A} = \bar{x} - \sqrt{3}s$$  
$$\hat{B} = \bar{x} + \sqrt{3}s$$  

最尤推定量は通常、母数 *a* と *h* を用いて次式で与えられる。  

$$A= a-h$$  
$$B= a+h$$  

*a* と *h* の最尤推定量は次式となる。  

$$\hat{a} = \mbox{中間値}(Y_{1}, Y_{2}, ... , Y_{n})$$  
$$\hat{h} = 0.5[\mbox{範囲}(Y_{1}, Y_{2}, ... , Y_{n})]$$  

これにより、A と B の最大尤度推定量は以下となる。  

$$\hat{A} = \mbox{中間値}(Y_{1}, Y_{2}, ... , Y_{n}) -0.5[\mbox{範囲}(Y_{1}, Y_{2}, ... , Y_{n})] = Y_{1}$$   
$$\hat{B} = \mbox{中間値}(Y_{1}, Y_{2}, ... , Y_{n}) +0.5[\mbox{範囲}(Y_{1}, Y_{2}, ... , Y_{n})] = Y_{n}$$   

#### 解説
一様分布は、連続分布において与えられた範囲内で等確率として定義する。
このため、基準分布として重要である。  

一様分布の最も重要な応用の一つは乱数生成である。
すなわち、ほぼ全ての乱数生成器は $`(0,1)`$ 区間上で乱数を生成する。
他の分布については、一様乱数に変換が適用される。
