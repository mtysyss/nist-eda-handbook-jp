# 1.3.6.5. 分布の母数推定

#### 確率分布を用いた単変量データ集合のモデル化
確率分布の一般的な応用の一つは、特定の確率分布を用いて単変量データをモデル化することである。
これには、以下の2つの手順が含まれる。

1. 「最も適合する」分布の決定  
2. その分布のパラメータ（形状、位置、尺度の母数）の推定  

#### 多様な方法
確率分布の母数を推定するための、数値的および図表現的な様々な方法がある。

1. [モーメント法](eda3651.md)  
2. [最尤法](eda3652.md)  
3. [最小二乗法](eda3653.md)  
4. [PPCCおよび確率プロット](eda3654.md)
