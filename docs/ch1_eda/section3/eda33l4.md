# 1.3.3.21.4. 正規確率プロット：データは右裾引き

#### 右裾引きデータの正規確率プロット
![1.3.3.21.4.Normal Probability Plot: Data are Skewed Right](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/normprp4.gif)  


#### 結論
[SUNSPOT.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/SUNSPOT.DAT)の上記プロットから、以下の結論を導くことができる。　　

1. 正規確率プロットは、強い非線形パターンを示している。
具体的には、最初の点と最後の点の間に引かれた基準線よりすべての点が下にある二次関数的なパターンを示している。  
2. 正規分布は、これらのデータに対する適切なモデルではない。  

#### 議論
正規確率プロットに見られるこの２次的なパターンは、データ集合が著しく右裾引きであることを示す特徴である。
同様に、正規確率プロット上のすべての点が、最初と最後の点を結ぶ基準線より上に位置する場合、それはデータ集合が著しく左裾引きであることを示す特徴的なパターンである。 
この場合、これらのデータを[ワイブル](eda3668.md)分布や[対数正規](eda3669.md)といった右に歪んだ分布でモデル化する必要があると、十分に合理的に結論付けることができる。
