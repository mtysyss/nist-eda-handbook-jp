# 1.3.3.23. 確率プロット 相関係数プロット

#### 目的：データ集合に最もよく適合する分布族の形状係数を求めるための図表現技法
確率プロット相関係数（PPCC）プロット（[Filliben 1975](../section4/eda43.md#確率プロット相関係数プロット)）は、データ集合を最もよく説明する分布族の[形状係数](eda363.md)を特定するための図表現技法である。
この技法は、単一の係数と[位置および尺度の母数](eda364.md)によって定義されるワイブルなどの分布族に適しているが、位置と尺度の母数のみで定義される正規分布などの分布には適していない。  

PPCCプロットは次の手順で作成する。一連の形状係数の値について、与えられた形状係数の値に対応する[確率プロット](eda33m.md)に対する相関係数を計算する。
これらの相関係数を対応する形状係数に対してプロットする。
最大相関係数が形状係数の最適値に対応する。
精度を高めるために、PPCCプロットを2回繰り返し作成する。
1回目は適切な近傍領域を見つけるため、2回目は推定値を微調整するためである。  

PPCCプロットは、まず形状係数の適切な値を見つけるために使用する。
その後、[確率プロット](eda33m.md)を作成し、位置と尺度の母数推定値を求め、その分布への適合度を視覚的に評価するためにも用いる。

#### 分布の比較
PPCCプロットは、特定の分布の形状係数を推定するための適切な選択肢を見つけるだけでなく、どの分布族が最も適切かを判断するときにも有用である。
例えば、信頼性データが与えられた場合、ワイブル、対数正布、ガンマ、逆ガウス、その他の分布について、1ページにまとめてPPCCプロットを作成する。 
この1ページにはいくつかの分布における形状係数の最適値が示され、どの分布族が最も適合しているか（最大確率プロット相関係数によって測定される）が示される。 
つまり、ワイブル分布のPPCCの最大値が0.99で、対数正規分布の最大値が0.94に過ぎない場合、ワイブル分布族の方がより適切な選択であると合理的に結論付けることができる。

#### 対称分布に対するTucky-Lambda PPCCプロット
形状係数 $`λ`$ を持つ[Tukey Lambda](eda366f.md) PPCC プロットは、対称的な分布に特に有用である。
これは、分布が短いもしくは長い裾かを示すだけでなく、いくつかの一般的な分布を特定することも可能である。
具体的には、  

1. $`λ=-1`$: 分布は近似的にコーシー分布  
2. $`λ=0`$: 分布は厳密にロジスティック分布  
3. $`λ=0.14`$: 分布は近似的に正規分布  
4. $`λ=0.5`$: 分布はU字型  
5. $`λ=1`$: 分布は厳密に一様分布  

Tukey Lambda PPCCプロットの最大値が0.14付近にある場合、正規分布がデータに対する適切なモデルであると合理的に結論付けることができる。
最大値が0.14未満の場合、二重指数やロジスティック分布などの裾の長い分布が良い選択である。
最大値が -1 付近にある場合、コーシー分布のような非常に長い裾を持つ分布の選択を示唆する。
最大値が0.14 より大きい場合、ベータや一様分布のような短い裾を持つ分布を示唆する。  

適切な分布を示すためにTukey-Lambda PPCCプロットを使用する。
そして、適切な候補の分布に関するPPCCプロットおよび確率プロットを作成すべきである。 

#### 適切な分布族を選択するときの判断
分布モデルを比較するときに、単にPPCC値が最大のものを選ぶべきではない。
多くの場合、複数の分布モデルが同程度のPPCC値を示すことがある。
例えば、対数正規分布とワイブル分布は、いずれも特定の信頼性データ集合に対して非常に良く適合する。 
一般的に分布の複雑さを考慮する。
つまり、PPCC値がわずかに小さいだけであっても、より単純な分布の方が、より複雑な分布よりも好まれることがある。
同様に、いくつかの場合には基礎となる科学的モデルという観点から、PPCC値がわずかに小さい分布を優先する方が、理論に正当なこともある。
他の場合では、分布モデルが最適であるかを知る必要はなく、単に目的のために適切であるかを知ればよい場合もある。
つまり、他の分布の方がデータに多少よく適合しても、正規分布データに設計された技法を用いることもできる。

#### プロットの例
以下は、[100個の正規乱数](https://www.itl.nist.gov/div898/handbook/datasets/NORMAL.DAT)のPPCCプロットである。
相関係数の最大値は、$`λ=0.099`$ のときに0.997となる。  

![1.3.3.23.Probability Plot Correlation Coefficient Plot](https://www.itl.nist.gov/div898/handbook/eda/gif/ppccplot.gif)  

このPPCCプロットは、以下の点を示している。  

1. 最良の近似となる対称分布はほぼ正規分布である。  
2. データは長い裾ではない。  
3. 標本平均は位置の適切な推定量と考えられる。  

このPPCCプロットに続いき正規確率プロットを作成し、データの正規性モデルを検証する。 

#### 定義：
PPCCプロットは、以下の条件で作成する。  

* 縦軸：確率プロット相関係数  
* 横軸：形状係数の値  

#### 論点  
PPCCプロットは、以下の質問に答える。  

1. 分布族においてどの分布が最善な適合を示すか。  
2. 最良の適合分布の適合は良いか（高い相関係数を持つ確率プロットを与えるという点）。  
3. この分布族は他の分布と比較して適合は良いか。  
4. 形状係数の選択はどの程度敏感か。  

#### 重要
多くの統計解析は、データを抽出した母集団に関する分布の仮定に基づいている。
しかし、分布族は形状係数の値によって形状が根本的に異なる場合がある。
したがって、形状係数の適切な値を見出すことは、解析において不可欠な手順である。
多くの解析において、データに適した分布モデルを見つけることが、解析の主な焦点である。
いずれの場合においても、PPCCプロットは有用なツールである。

#### ソフトウェア
現在の一般的な汎用統計ソフトウェアのほとんどでは、PPCCプロットは利用できない。
しかし、その基礎となる技法は確率プロットと相関係数に基づくため、これらの機能を実装している統計ソフトウェアであれば、PPCCプロット用のマクロを作成することは可能であろう。
DataplotはPPCCプロットに対応している。
