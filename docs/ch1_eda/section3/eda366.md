# 1.3.6.6. 分布のギャラリー

#### 一般的分布のギャラリー
最も一般的な分布のいくつかに関する詳細情報を以下に記載している。
統計的応用において用いられる多くの分布がある。
本ハンドブックの範囲では、そのうちの一部についてのみ論じるにとどめる。
多種多様な分布に関する詳細な情報の優れた参考文献の2つに、[Johnson、Kotz、およびBalakrishnan](../section4/eda43.md#Johnson)と、[Evans、Hastings、およびPeacock](../section4/eda43.md#Evans)を挙げる。
確率関数の式は、分布の[標準形](eda364.md#標準形)に記載されている。
分布の標準形を用いて[位置および幅の母数](eda364.md)を持つ関数を定義する[公式](eda364.md#標準形に基づく位置と幅の公式)がある。  

母数推定に関する節は、モーメント法と最尤法に限定している。
これは、[最小二乗](eda3653.md)や[PPCC法および確率プロット](eda3654.md)が汎用的な推定手順であることによる。
最大尤度方程式が連立方程式を解くことを含む場合を一覧に含めていない。
これは、これらの手法の解法には高度なコンピュータ・ソフトウェアを必要とする点にある。
最尤推定量が自明な場合を除き、その計算には統計ソフトウェア・プログラムを利用すべきである。
関心のある読者のために参考文献を記載している。  

出典によって、ここに示されているものとは異なる式が記載されている場合があることに留意されたい。
場合によっては、これらは単に数学的に等価な式のこともある。
また、異なる係数化が用いられている場合もある。
