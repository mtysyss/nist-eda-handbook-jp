# 1.3.3.17. 線形切片プロット

#### 目的：群間の線形切片における変化の検出
線形切片プロットは、群間で線形近似が一貫しているかを視覚的に評価するために用いる。
つまり、データに群があるときに、単一の近似をすべての群に適用できるか、それとも各群ごと個別に近似が必要かを知りたい場合がある。

線形切片プロットは、通常、[線形傾き](eda33i.md) と [線形残差標準偏差](eda33j.md) の各プロットと組み合わせて使用する。  

群がない場合もあるかもしれない。代わりに異なるデータ集合があり、単一の近似を各データ集合に適切に適用できるかを知りたいこともある。
この場合には、単純に異なるデータ集合を群として扱い、群ごとに線形切片プロットを適用する。

#### プロット例
![1.3.3.17.Linear Intercept Plot](https://www.itl.nist.gov/div898/handbook/eda/gif/linintpl.gif)  
[HSU12.DAT データ集合](https://www.itl.nist.gov/div898/handbook/datasets/HSU12.DAT)のこの線形切片プロットは、切片に偏位があることを示している。
最初の3つの切片は他の群よりも低い値になっている。
切片に小さな違いがあることに注目する。

#### 定義：群切片対群ID
線形切片プロットは、次の条件で作成する。  

* 縦軸軸：線形近似で得られた群ごとの切片  
* 横軸：群識別子  

基準線は、すべてのデータを使用した線形近似の切片でプロットする。

#### 論点
線形切片プロットは、以下の質問に対する答えを与えることができる。  

1. 線形近似の切片が群間で相対的に一定か。  
2. 切片が群間で変化する場合、パターンが識別できるか。  

#### 重要：群間の同質性の確認
群化されたデータでは、異なる群が同質（すなわち類似）か異質（すなわち相違）かを知ることが重要なときがある。
直線切片プロットは、線形近似の文脈においてこの質問に答えるのに役立つ。

#### ソフトウェア
ほとんどの汎用統計ソフトウェア・プログラムは、線形切片プロットを実装していない。
しかし、統計プログラムが群の線形近似が可能なら、このプロットを出力するマクロの作成は実現可能であろう。
