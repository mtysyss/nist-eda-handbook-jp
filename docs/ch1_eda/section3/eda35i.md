# 1.3.5.18. Yates アルゴリズム

#### 目的：2水準因子計画における因子効果の推定
[完全実施](../pri/section3/pri333.md)および[一部実施](../../pri/section3/pri334.md)要因計画は、工学や科学分野における[実験計画法](../pri/pri.md)で一般的に用いられる。  

これらの計画法では、各因子に2水準が割り当てられる。
これらは通常、低水準および高水準と呼ばれる。
計算上の便宜上、因子は正規化され、低水準には-1、高水準には+1の値が割り当てられる。
これらは一般的に「-」および「+」とも割り当てられる。

完全実施要因計画には、すべての因子について、低水準と高水準のすべての可能な組合せが含まれる。
一部実施要因計画には、これらの組合せの中から慎重に選ばれた部分集合が含まれる。
[部分集合の選択](../pri/section3/pri334.md)基準については、工程改善の章で詳しく説明する。  

Yates アルゴリズムは、これら計画の特殊な構造を利用し、すべての因子と関連するすべての交互作用について、因子効果の最小二乗推定値を与える。  

Yates アルゴリズムの数学的な詳細は、[Box、Hunter、およびHunter (1978)](../section4/eda43.md#BHH)の 10章に記載されている。
また、[Natrella (1963)](../section4/eda43.md#Natrella)は、効果推定値の有意性を検定するための手順も示している。  

効果推定値は通常、[DOE平均プロット](eda33c.md)や[DOE等高線プロット](eda33a1.md)（「DOE」は「実験計画法」を表す）といったいくつかの図表現技法によって補完される。
これらは[渦電流](../pri/section6/pri61.md)の事例研究で用いられている。 

#### Yates 順序
Yates アルゴリズムを実行する前に、データは「Yates 順序」に並べ替える必要がある。
つまり、*k* 個の要因がある場合、*k* 番目の列は、$`2^{k-1}`$ 個のマイナス符号（すなわち、その要因の低水準）と、それに続く$`2^{k-1}`$ 個のプラス符号（すなわち、その要因の高水準）で構成される。
例えば、3つの要因を持つ完全因子計画の場合、計画行列は  
 
　　- - -  
　　+ - -  
　　- + -  
　　+ + -  
　　- - +  
　　+ - +  
　　- + +  
　　+ + +  

一部実施要因計画での Yates 順序の決定には、その一部実施要因計画の[交絡構造](../../pri/section3/pri3343.md)に関する知識が必要である。 

#### Yates アルゴリズム
Yatesアルゴリズムを、[渦電流](../../pri/section6/pri611.md)データ集合に適用する。
このデータ集合には、3つの要因を持つ2水準の完全実施要因計画による 8つの測定値が含まれている。
この実験の目的は、渦電流測定値に最も大きな影響を与える要因を特定することである。  

「効果」列には、因子実験から得られた主効果と交互作用を標準順序で記載する。
「応答」列には、実験から得られた測定結果を Yates 順序で記載する。

```
効果       応答      列 1      列 2　   列 3     推定値  
------    --------  -----    -----    -----  --------  
平均        1.70      6.27    10.21    21.27   2.65875  
X1         4.57      3.94    11.06    12.41   1.55125  
X2         0.55      6.10     5.71    -3.47  -0.43375  
X1*X2      3.39      4.96     6.70     0.51   0.06375  
X3         1.51      2.87    -2.33     0.85   0.10625  
X1*X3      4.59      2.84    -1.14     0.99   0.12375  
X2*X3      0.67      3.08    -0.03     1.19   0.14875  
X1*X2*X3   4.29      3.62     0.54     0.57   0.07125  

応答の合計:      21.27  
応答の平方和:    77.7707  
列3 の平方和:   622.1656  
```

列1 の最初の 4つの値は、隣接する応答値のペアを足し合わせることで得られる。
例えば、$`4.57 + 1.70 = 6.27`$、$`3.39 + 0.55 = 3.94`$ などである。
列1 の 2番目の 4つの値は、同じ隣接する応答値のペアを差し引くことで得られる。
例えば、$`4.57 - 1.70 = 2.87`$、$`3.39 - 0.55 = 2.84`$ などである。
列2 の値は同様の方法で計算されるが、列1 の隣接する値を足し合わせたり引き算したりする点が異なる。
列3 は、列2 の隣接する値を用いて計算する。
最後に、列3 の値を回答総数である 8 で割ることで、「推定値」の列が得られる。  

計算が正しいかは、列3 の最初の値 $`(21.27)`$ が全回答の合計と一致するかを確認することで確認できる。
さらに、二乗和応答 $`(77.7707)`$ は、列3 の値の二乗和を 8 で割った値 $`(622.1656/8 = 77.7707)`$ と等しくなるはずである。 

#### 実務上の考慮事項
Yates アルゴリズムは、効果推定値を計算するための便利な方法である。
しかし、分散分析や回帰分析の手順を用いれば、統計ソフトウェアから同じ情報を容易に得ることができる。
実験計画のデータを分析する方法については、「[プロセス改善](../../pri/pri.md)」の章でより詳しく解説している。
