# 1.3.3.15. 遅延プロット

#### 目的：無作為性の確認
遅延プロットでは、データ集合や時系列が無作為かどうかを確認する。
無作為なデータは遅延プロットにおいて識別可能な構造を示さないはずである。
遅延プロットに非無作為な構造が認められる場合、元のデータが無作為でないことを示す。
以下に示す[例](eda33f.md#例)には、遅延プロットの代表的なパターンがいくつか含まれている。

#### プロット例
![1.3.3.15.Lag Plot](https://www.itl.nist.gov/div898/handbook/eda/gif/lagplot0.gif)  

[MAVRO.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/MAVRO.DAT)のこのサンプル遅延プロットは線形パターンを示している。
これはデータが強く非無作為であることを示し、さらに自己回帰モデルが適切である可能性を示唆している。 

#### 定義
ラグ(=遅延)とは固定された時間的ずれである。例えば、データ集合 $`Y_1, Y_2,..., Y_n`$ が与えられた場合、$`Y_2`$ と $`Y_7`$ はラグ5を持つ（7 - 2 = 5）。
遅延プロットは任意のラグで生成可能だが、最も一般的に使用されるラグは1である。  

ラグ1のプロットは、$`i = 2, 3, ..., n`$（$`n`$ は観測値の数）に対して、$`Y_i`$ の値と $`Y_{i-1}`$ の値をプロットしたものである。

* 縦軸：全 $`i`$ における $`Y_i`$  
* 横軸：全 $`i`$ における $`Y_{i-1}`$    

#### 論点
遅延プロットは、以下の質問に対する答えを与えることができる。

1. データは無作為か。  
2. データに連続的な相関はあるか。  
3. データに適したモデルは何か。  
4. データに外れ値はあるか。  

#### 重要
統計的推定および検定技法の大半において無作為性が基礎的な仮定である以上、遅延プロットは研究者にとって日常的に用いるべきツールである。

#### ソフトウェア
遅延プロットは、ほとんどの汎用統計ソフトウェアでは直接利用できない。
遅延プロットは本質的に、2つの変数を適切に遅延させた散布図であるため、ほとんどの統計プログラムで遅延プロット用のマクロを作成することは可能であろう。
