# 1.3.5.18.1. モデルと予測式の定義

#### 直交計画法では、項を追加しても係数の推定値は変わらない
最小二乗法による推定では、多くの場合、先に追加された項のモデル係数は、その後追加された項によって変化する。
例えば、X2 項がモデルに含まれているかどうかに応じ、X1 の係数が変化することがある。
しかし、$`2^3`$ の完全実施要因計画のように、計画が直交である場合には、このようなことは**起こらない**。 
直交計画の場合、追加項が加わっても、以前に含まれていた項の推定値は変化しない。
これは、係数推定値の順位付けられた項が、段階的に複雑になるモデルの最小二乗係数推定値であることを意味する。

#### 予測式の例
[渦電流](../../pri/section6/pri611.md)データ集合の最小二乗法解析から得られた係数推定値を用いて、予測式の例を作成する。

```
     係数          推定値
     ---------    --------
     平均          2.65875    
     X1            1.55125 
     X2           -0.43375
     X1*X2         0.06375  
     X3            0.10625    
     X1*X3         0.12375   
     X2*X3         0.14875
     X1*X2*X3      0.07125
```

予測式は、与えられた因子の値に対して応答変数の値を予測するものである。
選択する式には、上記のすべての因子を組み込むことも、因子の一部のみを組み込むこともできる。
例えば、X1 とX2 の 2つの因子のみを用いた予測式の一例は、以下の通りである。  

$$ \hat{Y} = 2.65875 + 1.55125 \cdot X_1 - 0.43375 \cdot X_2 $$  

予測式における最小二乗法による係数推定値は、因子値が 1単位変化したときの応答の変化を反映している。
因子の水準が -1 から +1 に変化した場合の「完全な」効果推定値（Yates 処理手順を用いて計算される）を得るには、効果推定値（切片を除く）に 2を乗算する。  

Yates 処理手順は単に効果を計算するためだけの便利な方法であることを覚えておく。
最小二乗回帰機能を備えた統計ソフトウェア・パッケージであれば、同じ効果を算出できるだけでなく、他にも多くの有用な分析を行うことができる。 

#### モデルの選択
以下の2つの目標の調整を取りながら、データに最も適したモデルを選択したい。

1. モデルには、すべての重要な要因を含めたい。  
2. モデルは簡潔であることが望ましい。
つまり、モデルは可能な限り単純であるべきである。  

残差の標準偏差だけでは、因子を追加すれば、残差の標準偏差は常に減少するため、最も適切なモデルを決定するには不十分であることに注意する。
次節では、モデルにどの因子（および交互作用）を含めるべきかを決定するためのいくつかの方法について説明する。
