# 1.3.3.1.2. 自己相関プロット：中程度の自己相関

#### 自己相関プロット
以下は、[FLICKER.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/FLICKER.DAT)の自己相関プロットのサンプルである。  
![1.3.3.3.1.2.Autocorrelation Plot: Moderate Autocorrelation](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/autocop2.gif)

#### 結論
このプロットから以下の結論を導き出せる。

1. データは、中程度の正の自己相関を持つ自己回帰を基礎としたモデルから得られたものである。

#### 議論
プロットはラグ1（約0.75）で中程度の高い自己相関から始まり、徐々に減少する。
減少する自己相関は概ね直線的だが、顕著なノイズを伴う。
このようなパターンは「中程度の自己相関」の自己相関プロットの特徴であり、適切にモデル化すれば中程度の予測可能性を提供する。

#### 推奨される次のステップ
次のステップは自己回帰モデルのパラメータを推定することである。  

$$Y_i = A_0 + A_1*Y_{i-1} + E_i$$  

この推定は、[最小二乗線形回帰](../../pmd/section1/pmd141.md)による、もしくは[ボックス・ジェンキンス](../../pmc/section4/pmc44.md)の自己回帰（AR）モデルを当てはめることで行うことができる。   

最小二乗法による近似の無作為性の仮定は、モデルの残差に適用する。
これは、元のデータに非無作為性が認められた場合でも、 **$`Y_i`$** を **$`Y_{i-1}`$** に対して適合した後の残差は、無作為な残差となるはずである。
提案されたモデルが実際に無作為性を十分に除去できたかを評価する方法については、「[工程の模型化」](../../pmd/section4/pmd44.md)の章で詳しく説明する。  

この自己回帰モデルの残差標準偏差は、デフォルト・モデルの残差標準偏差よりもはるかに小さくなる。
$$Y_i = A_0 + E_i$$
