# 1.3.3.26.4. 散布図：完全な線形（正の相関）関係

#### 完全な線形関係を示す散布図
![1.3.3.26.4.Scatter Plot: Exact Linear (positive correlation) Relationship](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/scatplo4.gif)  

#### 議論
上記のプロットでは、直線がデータに直線がデータに問題なく適合している点に注目する。
したがって、線形関係が成立している。
直線からの散らばりはゼロである（$`X`$と$`Y`$の間には完全な予測可能性が存在する）。
したがって、厳密な線形関係が成立している。 
直線の傾きは正である（$`X`$の値が小さいと$`Y`$の値も小さく、$`X`$の値が大きいと$`Y`$の値も大きい）。
故に、$`X`$と$`Y`$の間には正の相関（つまり正の相関関係）が存在する。
