# 1.3.3.27. スペクトル図

#### 目的：循環構造の検討
スペクトル図（[Jenkins and Watts 1968](../section4/eda43.md#Jenkins), 
[Bloomfield 1976](../section4/eda43.md#Bloomfield)）は、周波数領域での周期構造を調べるための図表現技法である。  

これは、自己共分散関数の平滑化されたフーリエ変換である。 
周波数は単位時間あたりのサイクル数で測定され、単位時間は 2 点間の距離として定義される。
周波数 0 は無限のサイクルに対応し、周波数 0.5 は 2 データ点のサイクルに対応する。
等間隔の時系列は、本質的に 0 から 0.5 の間の周波数の検出に制限される。

スペクトル図を適用する前に、時系列から変動の傾向を除去することが通常必要である。
変動の傾向は[実行順序プロット](../section3/eda33p.md)で検出可能である。
通常、時系列の差分や[直線による近似](../../ch4_pmd/section1/pmd141.md)（または他の多項式曲線）により変動の傾向を取り除き、残差に対してスペクトル解析を適用する。  

スペクトル図は、以下の式の正弦波モデルにおける周波数 $`\omega`$ 開始値を特定するためによく用いられる。  

$$Y_i=C+\alpha\sin{(2\pi\omega t_i+\phi)}+E_i$$  

この例については、[梁のたわみ事例研究](../section4/eda425.md)を参照のこと。 

#### プロット例
![1.3.3.27. Spectral Plot](https://www.itl.nist.gov/div898/handbook/eda/gif/spectrum.gif)  
[LEW.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/LEW.DAT)のスペクトル図は、観測ごとに約0.3サイクルという一つの支配的な周波数を示している。 

#### 定義：分散と頻度
スペクトル図は以下の条件で作成する。

* 縦軸：平滑化された分散（強度）  
* 横軸：周波数（観測あたりのサイクル数）  

平滑化された分散を生成するための計算は複雑であり、ここではこれ以上説明しない。
詳細についてはJenkinsとBloomfieldの参考文献、および時系列の周波数分析について論じている多くの文献を参照のこと。

#### 論点
スペクトル図は以下の質問に対する答えを与えることができる。  

1. 周期成分はいくつ存在するか。  
2. 支配的な周期周波数は存在するか。  
3. 支配的な周期周波数が存在するならば、それは何か。  

#### 重要：時系列の循環挙動の確認
スペクトル図は、周波数領域において単変量時系列の周期的性質を評価する主技法である。
これは時系列の周波数領域解析において、実行順序プロットに次いでほぼ常に作成される2つ目のプロットである。
