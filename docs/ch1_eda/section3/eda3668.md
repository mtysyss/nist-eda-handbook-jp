# 1.3.6.6.8.  Weibull 分布

#### 確率密度関数
一般 Weibull 分布の[確率密度関数](eda362.md#確率密度関数)の式は、以下の通りである。

$$f(x) = \frac{\gamma} {\alpha} (\frac{x-\mu}{\alpha})^{(\gamma - 1)}\exp{(-((x-\mu)/\alpha)^{\gamma})}\hspace{.3in} x \ge \mu; \gamma, \alpha > 0$$  

ここで、$`γ`$ は[形状母数](eda363.md)、$`μ`$ は[位置母数](eda364.md)、$`α`$ は[尺度母数](eda364.md)である。
$`μ=0`$ かつ $`α=1`$ の場合を**標準 Weibull 分布**と呼ぶ。
$`μ=0`$ の場合を 2係数 Weibull 分布と呼ぶ。
標準 Weibull 分布の式は次のように簡略化される 

$$f(x) = \gamma x^{(\gamma - 1)}\exp(-(x^{\gamma})) \hspace{.3in}x \ge 0; \gamma > 0$$   

確率関数の一般形は[標準分布を用いて表現](eda364.md#標準形に基づく位置と尺度の式)できるため、本節の以降のすべての式は、関数の標準形で示す。
以下は、 Weibull 確率密度関数のプロットである。

#### 累積分布関数
Weibull 分布の[累積分布関](eda362.md#累積分布関)の式は次式である。
 
$$F(x) = 1 - e^{-(x^{\gamma})} \hspace{.3in} x \ge 0; \gamma > 0$$   
 
以下は、上記の確率密度関数のプロットと同じ $`γ`$ の値を用いた、Weibull 累積分布関数のプロットである。
 
![plot of the Weibull cumulative distribution function with thesame values of gamma as the pdf plots above](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/weicdf4.gif)  

#### パーセント点関数
Weibull 分布の[パーセント点関数](eda362.md#パーセント点関数)の式は次式である。
 
$$G(p) = (-\ln(1 - p))^{1/\gamma} \hspace{.3in} 0 \le p < 1; \gamma > 0$$   
 
以下は、上記の確率密度関数（PDF）のグラフと同じ $`γ`$ の値を用いた Weibull 分布のパーセント点関数のプロットである。

![plot of the Weibull percent point function with the same values of gamma as the pdf plots above](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/weippf4.gif)  

#### ハザード関数
Weibull 分布の[ハザード関数](eda362.md#ハザード関数)の式は次式である。 
 
$$h(x) = \gamma x^{(\gamma - 1)} \hspace{.3in} x \ge 0; \gamma > 0$$   
 
以下は、上記の確率密度関数のグラフと同じ $`γ`$ の値を用いた Weibull ハザード関数のプロットである。

![plot of the Weibull hazard function with the same values of gamma as the pdf plots above](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/weihaz4.gif)  

#### 累積ハザード関数
Weibull 分布の[累積ハザード関数](eda362.md#累積ハザード関数)の式は次式である。
 
$$H(x) = x^{\gamma} \hspace{.3in} x \ge 0; \gamma > 0$$   
 
以下は、上記の確率密度関数のグラフと同じ $`γ`$ の値を用いた Weibull 分布の累積ハザード関数のプロットである。

#### 生存関数
Weibull 分布の[生存関数](eda362.md#生存関数)の式は次式である。
 
$$S(x) = \exp{-(x^{\gamma})} \hspace{.3in} x \ge 0; \gamma > 0$$   
  
以下は、上記の確率密度関数のプロットと同じ $`γ`$ の値を用いた Weibull 生存関数のプロットである。

![plot of the Weibull survival function with the same values of gamma as the pdf plots above](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/weisurv4.gif)  

#### 逆生存関数
Weibull 分布の[逆生存関数](eda362.md#逆生存関数)の式は次式である。

$$Z(p) = (-\ln(p))^{1/\gamma} \hspace{.3in} 0 \le p < 1; \gamma > 0$$   
 
以下は、上記の確率密度関数のプロットと同じ $`γ`$ の値を用いた Weibull 分布の逆生存関数のプロットである。

#### 共通統計量
以下の式は、位置母数が 0、尺度母数が 1 である。

平均値　　　$`\Gamma(\frac{\gamma + 1} {\gamma})`$ ここで、Γはガンマ関数である  $`\Gamma(a) = \int_{0}^{\infty} {t^{a-1}e^{-t}dt}`$   
中央値　　　$`\ln(2)^{1/\gamma}`$  
最頻値　　　$`(1 - \frac{1} {\gamma})^{1/\gamma} \hspace{.2in} \gamma > 1`$  
　　　　　　$`0 \hspace{1.05in} \gamma \le 1`$  
範囲　　　　0 から $`\infty`$  
標準偏差　　$`\sqrt{\Gamma(\frac{\gamma + 2} {\gamma}) -(\Gamma(\frac{\gamma + 1} {\gamma}))^{2}}`$  
変動係数　　$`\sqrt{\frac{\Gamma(\frac{\gamma + 2} {\gamma})}{(\Gamma(\frac{\gamma + 1} {\gamma}))^{2}} - 1}`$  

#### 母数推定
[Weibull 分布の最尤推定](../../apr/section4/apr413.md)については、[信頼性](../../apr/apr.md)の章（8章）で論じられている。
また、[Johnson、Kotz、および Balakrishnan](../section4/eda43.md#Johnson)の著書の第21章でも論じられている。

#### 解説
Weibull 分布は、[信頼性](../../apr/apr.md)解析において故障時間をモデル化するために広く用いられている。

#### ソフトウェア
一般的な統計ソフトウェア・プログラムの多くは、Weibull 分布の確率関数のうち、いくつかを実装している。
