# 1.3.3.14.4. ヒストグラムの解釈：対称かつ双峰性

#### 対称かつ双峰性ヒストグラム
![1.3.3.14.4.Histogram Interpretation: Symmetric and Bimodal](http://www.itl.nist.gov/div898/handbook/eda/gif/histogr4.gif)    

#### 双峰性の解説
上のプロットは[LEW.DATデータ](https://www.itl.nist.gov/div898/handbook/datasets/LEW.DAT)のヒストグラムである。
分布の最頻値とは、最も頻繁に出現する値、または出現確率が最も高い値である。
サンプルの最頻値はヒストグラムのピークで発生する。  

多くの現象において、応答値の分布が単一の最頻値（単峰性）を中心に集まり、その後、より低い頻度で裾部へ分布することがかなり一般的である。
正規分布は、単峰性分布の典型的な例である。

上記のヒストグラムは、双峰性（2ピーク）分布のデータを示している。
ヒストグラムは、双峰性などの問題を診断するためのツールとして機能する。
分布の非単峰性の根本的な理由に疑問を持つことは、研究対象となっている現象の洞察と決定論的モデリングの向上にしばしばつながる。
例えば、上記のデータについて、二峰性ヒストグラムはデータの正弦波性によって引き起こされる。

#### 推奨される次の手順
ヒストグラムが対称的で二峰分布を示す場合、推奨される手順は次のとおり。  

1. 正弦波を確認するために、[実行順序プロット](eda33p.md)または[散布図](eda33q.md)を作成する。  
2. [遅延プロット](eda33f.md)を作成し、正弦波性を確認する。遅延プロットが楕円である場合、データは正弦波である。  
3. データが正弦波である場合、[スペクトル図](eda33r.md)を作成し、背景にある正弦波周波数をグラフで推定する。  
4. データが正弦波でない場合、[Tukey Lambda PPCCプロット](eda33n.md)によりデータに最適な対称分布が決定される可能性がある。  
5. データは2つの分布の混合で適合する可能性がある。この場合の一般的な手順は、2つの[正規](eda3661.md)または[対数正規](eda3669.md)分布の混合を適合させることである。分布の混合を適合することに関するさらなる議論は、本ハンドブックの範囲を超えている。
