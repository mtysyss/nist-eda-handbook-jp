# 1.3.5.16. Kolmogorov-Smirnov 適合度検定

#### 目的：分布の妥当性の検定
Kolmogorov-Smirnov 検定（[Chakravart, Laha, and Roy, 1967](../section4//eda43.md#Chakravart)）は、標本が特定の分布を持つ母集団から抽出されたものかを判断するために用いられる。  

Kolmogorov-Smirnov（K-S）検定は、経験分布関数（ECDF）に基づく。
<u>順序付けられた</u> *N* 個のデータ点 $`Y_1, Y_2,...,Y_N`$ が与えられたとき、ECDF は次式で定義される。  

$$E_{N} = n(i)/N$$  

ここで $`n(i)`$は $`Y_i`$ 未満のデータ点の数であり、$`Y_i`$ は最小値から最大値へ順序付けられる。
これは各順序付けデータ点の値で $`1/N`$ ずつ増加する階段関数である。

下図は、[100個の正規乱数](https://www.itl.nist.gov/div898/handbook/datasets/NORMAL.DAT)の経験分布関数と正規累積分布関数のプロットである。
K-S検定は、これら二つの曲線間の最大距離に基づく。

![1.3.5.16.Kolmogorov-Smirnov Goodness-of-Fit Test](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/ecdf.gif)  

#### K-S検定の特徴と限界
この検定の魅力的な特徴は、K-S 検定統計量自体の分布が検定対象の基礎となる累積分布関数に依存しない点である。
もう一つの利点は、厳密な検定であることが挙げられる（カイ二乗適合度検定は近似が有効となる十分な標本規模に依存する）。
これらの利点にもかかわらず、K-S検定にはいくつかの重要な制限がある。  

1. 連続分布にのみ適用可能である。  
2. 分布の中心部では裾部よりも感度が高くなる傾向がある。  
3. おそらく最も大きな制限は、分布が完全に指定されてなければならない。
位置、尺度、形状の母数がデータから推定される場合、K-S 検定の棄却域はもはや有効でなくなる。
通常、シミュレーションによって決定する必要がある。

[Anderson-Darling](eda35e.md) 検定や Cramer Von-Mises 検定など、いくつかの適合度検定は、K-S 検定を改良したものである。
これらの改良された検定は、一般的に元の K-S 検定よりも強力であると考えられ、多くの分析者がそれらを好む。
また、K-S 検定の利点である、基礎となる分布から独立した棄却値を持つという利点は、一見したほど大きな利点ではない。
これは、上記の制限 3（すなわち、分布母数は通常、既知ではなく、データから推定しなければならない）によるものである。
したがって実際には、K-S 検定の棄却値は、 Anderson-Darling 検定や Cramer Von-Mises （および関連する）検定と同様に、シミュレーションによって決定する必要がある。  

K-S 検定は通常、打ち切りのない、かつ、群化されていないデータの連続分布の文脈で開発されているが、実際には、離散分布や打ち切りおよび群化データにも拡張されていることに留意されたい。
ここでは、それらの事例については議論しない。 

#### 定義
Kolmogorov-Smirnov 検定は以下で定義する。  

##### $`H_0`$:
データは指定された分布に従う。

##### $`H_a`$:
データは指定された分布に従わない。

##### 検定統計量:
Kolmogorov-Smirnov 検定統計量は次式で定義される。  

$$D = \max_{1 \le i \le N} \left( F(Y_{i}) -\frac{i-1} {N}, \frac{i}{N} - F(Y_{i}) \right)$$  

ここで、$`F`$ は検定対象の分布の理論的累積分布関数であり、連続分布（二項分布や Poisson 分布などの離散分布ではない）でなければならず、完全に指定されている必要がある（つまり、[位置、尺度](eda364.md)、[形状](eda363.md)の母数はデータから推定できない）。

##### 有意水準:
*α*

##### 棄却値:
検定統計量 $`D`$` が表から得られる棄却値より大きい場合、分布形状に関する仮説は棄却される。
文献には、K-S 検定統計量と棄却域の幅の設定が若干異なる複数の表の派生がある。
これらの代替形式は同じはずであるが、検定統計量の計算方法が棄却値の表作成方法と整合していることを確認する必要がある。

本ハンドブックでは K-S 検定表は提供していない。
K-S 検定を実行するソフトウェア・プログラムが関連する棄却値を提供している。 

#### 技術ノート
電子ハンドブックの過去の版では、Kolmogorov-Smirnov 適合度統計量の計算式として以下の式を示していた。  

$$D = \max_{1 \le i \le N}\left| F(Y_{i}) - \frac{i} {N} \right|$$  

この式は実際には正しくない。
この式は次のように書き換えられることに注意する。  

$$D = \max_{1 \le i \le N}(F(Y_{i}) - \frac{i} {N}, \frac{i}{N} - F(Y_{i}))$$  

この形式では、両式間の差の上限が $`i/N`$ であることが明確となる。
実際のデータでは、差は上限より小さくなる可能性が高い。

例えば、$`N=20`$の場合、これら二つの式間の差の上限は 0.05 である（5%の臨界値は 0.294 であることと比較）。
$`N=100`$ の場合、上限は 0.001 となる。
実際には、中規模から大規模な標本サイズ（例えば $`N≥50`$）では、これらの公式は本質的に同等である。 

#### Kolmogorov-Smirnov 検定の例
正規分布、二重指数分布、自由度 3 の *t* 分布、対数正規分布について、それぞれ 1,000個の乱数を作成した。
いずれの場合も、正規分布に Kolmogorov-Smirnov 検定を適用した。  

正規乱数は変数 Y1 に、二重指数乱数は変数 Y2 に、*t* 乱数は変数 Y3 に、対数正規乱数は変数 Y4 にそれぞれ格納した。

　　$`H_0`$:　　データは正規分布である。  
　　$`H_a`$:　　データは正規分布ではない。  

　　Y1 検定統計量:　　$`D = 0.0241492 `$  
　　Y2 検定統計量:　　$`D = 0.0514086`$  
　　Y3 検定統計量:　　$`D = 0.0514086`$  
　　Y4 検定統計量:　　$`D = 0.5354889`$  

　　有意水準:　$`α = 0.05`$  
　　棄却値:　　$`0.04301  `$     
　　棄却域:　　$`D > 0.04301`$　の場合に $`H_0`$ を棄却    

予想通り、正規分布データ集合では帰無仮説を棄却せず、3つの非正規データ集合では帰無仮説を棄却した。 

#### 論点
Kolmogorov-Smirnov 検定は、以下の種類の質問に答えるために使用できる：

* データは正規分布に従うか。  
* データは対数正規分布に従うか。  
* データは Weibull 分布に従うか。  
* データは指数分布に従うか。  
* データはロジスティック分布に従うか。  

#### 重要
多くの統計的検定や手順は特定の分布[仮定](../section2/eda2.md)に基づく。
正規性の仮定は古典的な統計的検定において特に一般的である。
信頼性モデル化の多くは、データが Weibull 分布に従うという仮定に基づいている。

強い分布の仮定に基づかないノンパラメトリックや頑健な技法は数多く存在する。
ノンパラメトリックとは、[符号検定](../../prc/section2/prc243.md)など特定の分布を仮定しない技法を指す。
頑健とは、幅広い分布仮定のもとで良好な性能を発揮する統計的技法を意味する。
しかしながら、特定の分布仮定に基づく技法は一般的に、これらのノンパラメトリックや頑健な技法よりも検出力が高い。
検出力とは、差異が実際に存在するときにそれを検出する能力を指す。
したがって、分布の仮定が確認できる場合、パラメトリック手法が一般的に推奨される。

正規性（またはその他の分布に関する）仮定を置く技法を用いる場合、この仮定が実際に正当化されることを確認することが重要である。
正当化される場合、より検出力の高いパラメトリック手法が使用できる。
分布に関する仮定が正当化されない場合、ノンパラメトリック手法または頑健な手法の使用が必要となることがある。
