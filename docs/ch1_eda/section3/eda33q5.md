# 1.3.3.26.5. 散布図：二次関係

#### 二次関係を示す散布図
![1.3.3.26.5.Scatter Plot: Quadratic Relationship](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/scatplo5.gif)  

#### 議論
上記プロットは、$`X`$ と $`Y`$ の関係を適切に表す想像でき得る単純な直線はなく、曲線（または曲線的、もしくは非線形）関数が必要であることに注目する。
最も単純な曲線関数は次式の二次モデルである。  

$$Y_i=A+BX_i+CX_i^2+E_i$$  

ここで、$`A`$、$`B`$、$`C`$は何らかの係数である。
他の多くの曲線関数が可能であるが、データ解析の簡潔の原則から、まず[二次関数](../../pmd/section1/pmd142.md)で近似することが妥当である。
