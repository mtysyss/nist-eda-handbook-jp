# 1.3.3.30. Weibull プロット

#### 目的：データがWeibull 分布で近似される母集団に従うかの視覚的な確認
Weibull プロット ([Nelson 1982](../section4/eda43.md#Nelson))は、データ集合が論理的に2係数Weibull 分布（位置母数はゼロと仮定）で近似される母集団から得られたかを判定する図表現技法である。  

Weibull プロットは特別な尺度が設定されており、データが実際にWeibull 分布に従う場合、点が直線状（または近似的に直線状）になるよう設計されている。
この直線に対する最小二乗法による近似は、Weibull 分布の形状および尺度の係数推定値を導出する（位置母数はゼロと仮定する）。  

具体的には、形状係数は近似直線の傾きの逆数であり、尺度係数は近似直線の切片の指数である。  

Weibull 分布には、形状係数の値に関わらず尺度係数が63.2%点に位置するという特性もある。
プロットにはこの63.2%点に水平線が表示され、水平線が最小二乗法で推定された直線と交わる点に垂直線が表示される。
この垂直線が尺度係数の値を示す。 

#### プロット例  
![1.3.3.30.Weibull Plot](https://www.itl.nist.gov/div898/handbook/eda/gif/weibullp.gif)  

[FULLER2.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/FULLER2.DAT)のこのWeibull プロットは以下の点をを示している。  

1. Weibull 分布の仮定は妥当であり、  
2. 尺度係数の推定値は33.32と算出され  
3. 形状係数の推定値は5.28と算出され  
4. 外れ値は存在しない。  

x軸上の値（「0」、「1」、「2」）は指数を表す。
これらは実際には$`10^0=1`$、$`10^1=10`$、$`10^2=100`$を意味する。 

#### 定義：Weibull 累積確率対対数（順序付き応答）
Weibull プロットは以下の条件で作成する。  

* 縦軸：百分率で表されたWeibull 累積確率  
* 横軸：順序付けられた故障時間（LOG10尺度）

縦軸の尺度は $`ln(-ln(1-p))`$ で、$`p=(i-0.3)/(n+0.4)`$、$`i`$は観測値の順位である。
この尺度をWeibull ・データに対する結果のプロットを線形化するために選択する。

#### 論点
Weibull プロットは、以下の質問に答えるために用いる。  

1. データは2係数Weibull 分布に従うか。  
2. 2係数Weibull 分布における形状係数の最良推定値は何か。  
3. 2係数Weibull 分布における尺度（＝ばらつき）係数の最良推定値は何か。  

#### 重要：分布の仮定の確認
多くの統計分析、特に信頼性分野における分析は、データがWeibull 分布に従うという仮定に基づいている。
分析がデータがWeibull 分布に従うと仮定する場合、この仮定を検定することが重要であり、仮定が成立すれば、Weibull 係数の適切な推定値を見つける必要がある。

Weibull 確率プロット（Weibull PPCCプロットと併用）、Weibull ・ハザード・プロットおよびWeibull プロットは、いずれもデータモデルとしてのWeibull 分布の妥当性を評価し、さらに形状、尺度または位置母数の推定を提供する類似の手法である。 
Weibull ・ハザード・プロットとWeibull プロットは打切りデータ（Weibull 確率プロットでは扱えない）を扱うように設計されている。

Weibull プロットは、信頼性データを分析するために設計された統計ソフトウェア・プログラムで一般的に利用可能である。
