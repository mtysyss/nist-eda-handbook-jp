# 1.3.5.3. 平均値が等しい二標本 *t*-検定

#### 目的：二つの母集団平均値の等しさの検定
二標本*t*検定（[Snedecor and Cochran, 1989](../section4/eda43.md#Snedecor)）は、二つの母集団の平均が等しいかどうかを判定するために用いる。
一般的な応用例として、新しい工程や処置が現行の工程や処置よりも優れているかを検定することが挙げられる。  

この検定にはいくつかの派生がある。  

1. データは対応ありと対応なしがある。
対応ありとは、二つの標本内の値が1対1で対応していることを意味する。
すなわち、$`X_1,X_2,...,X_n`$と$`Y_1,Y_2,...,Y_n`$が二つの標本であるならば、$`X_i`$は$`Y_i`$に対応する。 
対応のある標本では、通常$`X_i-Y_i`$ の差を計算する。
対応のない標本では、2つの標本の標本規模が等しくても等しくなくてもよい。
対応のあるデータの計算式は、対応のないデータの計算式よりもやや単純である。  
2. 二つの標本の分散は等しいと仮定することも、等しくないものと仮定することもできる。
分散が等しい場合、式はやや単純になるが、コンピュータが普及した現在では、これはもはや大きな問題ではない。  
3. いくつかの応用では、いくつかの閾値で現在の処置を上回る場合にのみ新しい工程や処置を採用したいことがある。
この場合、帰無仮説を「二つの母集団の平均値の差がある定数$`\mu_1-\mu_2=d_0`$に等しい」という形で設定する。
ここで定数は望ましい閾値である。 

#### 定義
対応のないデータに対する二標本*t*-検定は次のように定義する。  
##### $`H_0:`$
$`\mu_1=\mu_2`$  

##### $`H_a:`$
$`\mu_1 \neq \mu_2`$  

##### 検定統計量:
$`T=\frac{\bar{Y}_1-\bar{Y}_2}{\sqrt{s^2_1/N_1+s^2_2/N_2}}`$  
ここで、$`N_1`$および $`N_2`$は標本規模、$`\bar{Y}_1`$ および $`\bar{Y}_2`$ は標本平均、$`s^2_1`$ および $`s^2_2`$ は標本分散である。 
分散が等しいと仮定すると、この式は次の形に簡略化される。  
$$T=\frac{\bar{Y}_1-\bar{Y}_2} {s_p\sqrt{1/N_1+1/N_2}}$$  
ここで  
$$s_p^2=\frac{(N_1-1)s^2_1+(N_2-1)s^2_2}{N_1+N_2-2}$$  

##### 有意水準: 
$`α`$  

##### 棄却域: 
二つの平均が等しいという帰無仮説を棄却する条件は  
$$|T|>t_{1-α/2,ν}$$  
ここで $`t_{1-α/2,ν}`$は自由度 $`ν`$の [$`t`$-分布](eda3664.md)の[棄却値](eda3672.md)であり、  
$$\upsilon = \frac{(s^2_1/N_1+s^2_2/N_2)^2} {(s^2_1/N_1)^2/(N_1-1)+(s^2_2/N_2)^2/(N_2-1)}$$  
上記の自由度は[Welch-Satterthwaite](../section4/eda43.md#Welch1947)の式である。
Welch-Satterthwaiteの自由度は標本規模や分散が異なる場合に頑健である。
等分散を仮定し標本規模が類似している場合、次式の単純な自由度の式を使用できる：$`ν=N_1+N_2-2`$。

#### 二標本 *t*-検定の例
以下の二標本 *t*-検定は[AUTO83B.DAT](eda3531.md)データに対して出力された。
このデータ集合には米国車（標本1）と日本車（標本2）のマイル/ガロンの燃費が含まれ、各標本の要約統計量は以下の通り。

標本 1:  
　　観測数　　　　= 249  
　　平均　　　　　=  20.14458  
　　標準偏差　　　=   6.41470  
　　平均標準誤差　=   0.40652  
  
標本 2:  
　　観測数　　　　= 79  
　　平均　　　　　= 30.48101  
　　標準偏差　　　=  6.10771  
　　平均標準誤差　=  0.68717  

両標本の母平均が等しいという仮説を検定する。
両標本の分散が等しいと仮定する。 

$`H_0:　　μ_1=μ_2`$  
$`H_a:　　μ_1≠μ_2`$  
検定統計量:　　$`T = -12.62059`$  
併合標準偏差:　$`s_p = 6.34260`$  
自由度:　　　　$`ν = 326`$  
有意水準:	　　　$`α = 0.05`$  
棄却値 (上側):　$`t_{1-α/2,ν} = 1.9673`$  
棄却域:　　　　$`H_0`$の棄却　$`|T| > 1.9673`$  

本例における検定統計量の絶対値12.62059は、棄却値1.9673を上回っているため、帰無仮説を棄却し、0.05の有意水準で両母集団の平均が異なることを結論付ける。   

一般に、一標本*t*-検定では以下の3つの対立仮説と棄却領域が考えられる。   
| 対立仮説 | 棄却領域 |   
|:--- |:--- |  
| $`H_a: μ_1 ≠ μ_2`$ | $`\|T\|>t_{1-α/2,ν}`$ |  
| $`H_a: μ_1 > μ_2`$ | $`T > t_{1-α,ν}`$ |  
| $`H_a: μ_1 < μ_2`$ | $`T < t_{α,ν}`$ |  

両側*t*-検定の場合の棄却値は$`t_{1-α/2,ν}=1.9673`$（$`α=0.05`$、$`ν=326`$）となる。
一方、上側片側検定を行う場合の棄却値は$`t_{1-α,ν}=1.6495`$となる。

#### 論点
二標本*t*-検定は以下の質問の答えを与える。 

1. 工程1は工程2と同等か。  
2. 新しい工程は現行工程より優れているか。  
3. 新しい工程は、少なくとも事前に定められた閾値以上の差で現在の工程より優れているか。
