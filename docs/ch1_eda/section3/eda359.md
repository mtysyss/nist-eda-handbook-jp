# 1.3.5.9. 2つの分散の等しさの F-検定

#### 目的：2つの母集団の分散が等しいかの検定
*F*-検定（[Snedecor and Cochran,1983](../section4/eda43.md#Snedecor)）は、2つの母集団の分散が等しいかを検定するために用いられる。
この検定は、両側検定または片側検定のいずれかで行う。
両側検定では、分散が等しくないという対立仮説に対して検定を行う。
片側検定では、一方向のみを検定する。
すなわち、第1母集団の分散が第2母集団の分散より大きい、あるいは小さい（ただし、その両方でない）かを検定する。
どちらを選択するかは、問題によって決まる。
例えば、新しい工程を検定する場合、新しい工程のばらつきが古い工程よりも小さいかを知ることだけに興味があるかもしれない。

#### 定義
*F* 仮説検定は次のように定義する。  

##### $`H_0`$:
\( \sigma\_{1}^{2} \) = \( \sigma\_{2}^{2} \)

##### $`H_a`$:
$`\sigma\_{1}^{2} < \sigma\_{2}^{2}`$　下側片側検定の場合  
$`\sigma\_{1}^{2} > \sigma\_{2}^{2}`$　上側片側検定の場合  
$`\sigma\_{1}^{2} \ne \sigma\_{2}^{2}`$　両側検定の場合  

##### 検定統計量：
$`F=s^{2}\_{1}/s^{2}\_{2}`$  
ここで、$`s^{2}_{1}`$ および $`s^{2}\_{2}`$ は標本分散である。
この比が1から大きく外れるほど、母集団分散が等しくないという証拠が強くなる。 

##### 有意水準：
*α*

##### 棄却域：
以下の条件を満たす場合、2つの分散が等しいという仮説は棄却される。  
$`F > F\_{\alpha,N\_1 - 1,N\_2 - 1}`$　片側検定の上限  
$`F < F\_{1 - \alpha,N\_1 - 1,N\_2 - 1}`$　下側片側検定の場合  
$`F < F\_{1 - \alpha/2,N\_1 - 1,N\_2 - 1}`$　両側検定の場合  
または  
$`F > F\_{\alpha/2,N\_1 - 1,N\_2 - 1}`$  
ここで、$`F_{α,N_1-1,N_2-1}`$ は、自由度 $`N_1-1`$ および $`N_2-1`$、有意水準 *α* を持つ[$`F`$ 分布](eda3665.md)の[棄却値](eda3673.md)である。  

上記棄却域の式において、本ハンドブックでは、$`F_α`$ を *F* 分布の上側棄却値、$`F_{1-α}`$ を *F* 分布の下側棄却値とする慣例に従っている。
これは、一部の文献やソフトウェア・プログラムで使用されている表記法とは逆であることに注意されたい。 



#### F検定の例
[JAHANMI2.DAT](https://www.itl.nist.gov/div898/handbook/datasets/JAHANMI2.DAT)データに対して、以下の *F* 検定を出力した。
このデータ集合には、2ロットの材料に関する 480 件のセラミック強度測定値を含んでいる。
各ロットの要約統計量は以下の通り。  

バッチ 1:  
　　観測数　　　　　　=      240  
　　平均　　　　　　　=    688.9987  
　　標準偏差　　　　　=    65.54909  

バッチ 2:  
　　観測数　　　　　　=      240  
　　平均　　　　　　　=    611.1559  
　　標準偏差　　　　　=    61.85425  

2つのバッチの分散が等しいという帰無仮説を検定しています。

$`H_0`$:　$`σ_1^2 = σ_2^2`$  
$`H_a`$:　$`σ_1^2 \ne σ_2^2`$

検定統計量:　$`F = 1.123037`$  
分子自由度:　　　$`N_1-1 = 239`$  
分母自由度:　　　$`N_2-1 = 239`$  
有意水準:　　$`α = 0.05`$  
棄却値:　　　$`F_{1-α/2,N1-1,N2-1} = 0.7756`$  
　　　　　　$`F_{α/2,N1-1,N2-1} = 1.2894`$  
棄却域:　　　$`F < 0.7756`$ もしくは $`F > 1.2894`$　の場合に $`H_0`$ を棄却   

*F* 検定の結果、有意水準 0.05 において、2つのバッチの分散が等しいという帰無仮説を棄却するには十分な証拠がないことが示さる。

#### 論点
*F* 検定は、以下の質問の答えを与える。

1. 2 標本は、分散が等しい母集団から得られたものか。  
2. 新しい工程や、処置、試験は、現行工程のばらつきを低減させるか。
