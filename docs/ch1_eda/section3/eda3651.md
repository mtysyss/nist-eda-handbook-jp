# 1.3.6.5.1. モーメント法

#### モーメント法
モーメント法は、標本モーメントを母数推定値と等しくみなすものである。
モーメント法が利用可能な場合、その利点は単純さにある。
欠点は、利用できない場合が多く、また、最尤推定量や最小二乗推定量のような望ましい最適性を備えていないことである。  

モーメント推定量の主な用途は、より精度の高い[最尤法](eda3652.md)や[最小二乗法](eda3653.md)による推定量の初期値として用いることである。 

#### ソフトウェア
一般的な統計ソフトウェアの多くは、モーメント法による母数推定のコマンドを明示的に備えていない。
しかし、実際に利用する場合、モーメント法の数式は比較的単純であり、ほとんどの統計ソフトウェア・プログラムで容易に実装することができます。
