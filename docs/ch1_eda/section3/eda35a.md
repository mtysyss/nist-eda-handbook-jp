# 1.3.5.10. 分散の等しさの Levene 検定

#### 目的：分散の等分散性の検定
Levene 検定（[Levene 1960](../section4/eda43.md#Levene)）は、*k* 個の標本が等分散であるかを検定するために用いられる。
標本間で分散が等しい状態は等分散性と呼ばれる。
分散分析などの一部の統計的検定は、群または標本間で分散が等しいことを前提とする。
Levene 検定はこの前提を検定するために用いられる。 

Levene 検定は[Bartlett 検定](eda357.md)の代替法である。
Levene 検定は正規性からの逸脱に対して Bartlett 検定よりも感度が低い。
データが実際に正規分布もしくはほぼ正規分布に従うという強い証拠がある場合に Bartlett 検定の方がより優れた性能を発揮する。 

#### 定義
レベーン検定は次のように定義する。  
##### $`H_0`$:
$`\sigma\_{1}^{2} = \sigma\_{2}^{2} = \ldots = \sigma\_{k}^{2}`$  

##### $`H_a`$:
$`\sigma\_{i}^{2} \ne \sigma\_{j}^{2}`$　少なくとも一組の $`(i,j)`$ に対して

##### 検定統計量：
標本サイズ *N* の変数 *Y* を *k* 個の部分群に分割し、*i* 番目の部分群の標本規模を $`N_i`$ とすると、Levene 検定統計量は次に定義される。  

$$W = \frac{(N-k)} {(k-1)}\frac{\sum\_{i=1}^{k}N\_{i}(\bar{Z}\_{i.}-\bar{Z}\_{..})^{2} }{\sum\_{i=1}^{k}\sum\_{j=1}^{N\_i}(Z\_{ij}-\bar{Z}\_{i.})^{2} }$$  
ここで $`Z_{ij} は以下の3つの定義のいずれか。  

1. $`Z\_{ij} = |Y\_{ij} - \bar{Y}\_{i.}|`$  
ここで $`\bar{Y}\_{i.}`$ は *i* 番目の部分群の[平均値](eda351.md#位置の定義)である。 
2. $`Z\_{ij} = |Y\_{ij} - \tilde{Y}\_{i.}|`$  
ここで $`\tilde{Y}\_{i.}`$ は *i* 番目の部分群の[中央値](eda351.md#位置の定義) である。 
3. $`Z\_{ij} = |Y\_{ij} - \bar{Y}\_{i.}'|`$  
ここで $`\bar{Y}\_{i.}'`$ は *i* 番目の部分群 10%[刈込平均](eda351.md#位置の代替指標) である。

$`\bar{Z}\_{i.}`$ は $`Z_{ij}`$ の群平均であり、$`\bar{Z}\_{..}`$ は $`Z_{ij}`$ の総平均である。  

$`Z_{ij}`$ を定義する3つの選択肢が、Levene 検定の頑健性と検出力を決定する。
頑健性とは、基礎データが正規分布せず変数が実際に等しい場合に、検定が等しくない分散として誤って検出しない能力を意味する。
検出力とは、実際に分散が等しくないにもかかわらず、検定が等しくない分散として検出する能力を意味します。

[Brown and Forsythe （1974）](../section4/eda43.md#Brown)は Levene 検定を拡張し、平均値に加えて中央値または刈込平均の使用を可能にした。
彼らが実施したモンテカルロ研究によれば、基礎データが Cauchy 分布（すなわち重裾分布）に従う場合には刈込平均の使用が最も良好な結果を示した一方、母集団データがカイ二乗分布 $`\chi^{2}\_{4}`$ （すなわち歪みのある分布）に従う場合には中央値の使用が最良の結果を与えた。
平均値の使用は、対称的で中程度の裾を持つ分布において最高の検出力であった。  

最適な選択は基礎となる分布に依存するが、多くの非正規データに対して良好な頑健性を保ちつつ十分な検出力も維持する選択肢として、中央値に基づく定義が推奨される。
データの基礎となる分布が既知の場合、他の選択肢の採用が示唆される可能性がある。 

##### 有意水準:
*α*

##### 臨界領域:
Levene 検定は、以下の条件を満たす場合に分散が等しいという仮説を棄却する。  

$$W > F_{α, k-1, N-k}$$  

ここで $`F_{α, k-1,N-k}`$ は、有意水準 *α* における[$`F`$ 分布](eda3665.md) の自由度 $`k-1`$ および $`N-k`$ の[上側棄却値](/eda3673.md)である。  

上記の棄却域の式において、本ハンドブックでは $`F_α`$ が *F* 分布の上側棄却値、$`F_{1-α}`$ が下側棄却値であるという慣例に従っている。
これは一部の教科書やソフトウェア・プログラムとは逆であることに注意されたい。 

#### Levene 検定の例
[GEAR.DAT](eda3581.md)データに対して、中央値に基づくLevene 検定を実施した。
このデータ集合には、10バッチそれぞれについて歯車直径の測定値を10個ずつ含み、合計100個の測定値が記録されている。

$`H_0`$:　$`σ_1^2 = ... = σ_2^2`$  
$`H_a`$:　$`σ_1^2 \ne ... \ne σ_2^2`$

検定統計量:　$`W = 1.705910`$  
自由度:　　　$`k-1 = 10-1 = 9`$  
　　　　　　　$`N-k = 100-10 = 90`$  
有意水準:　　$`α = 0.05`$  
棄却値:　　　$`F_{α,k-1,N-k} = 1.9855`$  
棄却域:　　　$`F > 1.9855`$　の場合に $`H_0`$ を棄却   

群間の分散が等しいという仮説を検定している。
Levene 検定の検定統計量の値が棄却値を下回っているため、有意水準 0.05 において帰無仮説を棄却できない。
したがって、分散が等しくないとする主張には十分な証拠がないと結論付ける。
