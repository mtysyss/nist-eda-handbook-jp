# 1.3.3.13. DOE標準偏差プロット

#### 目的：規模に関する重要な因子を検出する
DOE標準偏差プロットは、因子が2つ以上あり、各水準で繰り返しがある重要な因子に関する実験計画のデータを分析するのに適している。
このプロットは、因子別にプロットされた各因子の2つ以上の水準の標準偏差値を示している。
単一因子の標準偏差は直線で結ばれる。
DOE標準偏差プロットは、実験計画の従来の[分散分析](../../ppc/section2/ppc23.md)を補完するものである。  

このプロットは通常、標準偏差に対して作成する。
しかし、範囲、絶対偏差の中央値、平均絶対偏差などの他の尺度統計量に対しても作成可能である。 

#### サンプルプロット
![sample DOE Standard Deviation Plot](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/eda_dexboxbike_r03.gif)  
[BOXBIKE2.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/BOXBIKE2.DAT)のこのDOE標準偏差プロットのサンプルは、以下のことを示している。

1. 因子1は因子水準間の標準偏差の差が最も大きい。  
2. 因子4の平均標準偏差は他の因子の平均標準偏差より著しく低い（ただし因子1の水準1標準偏差は因子4の水準1標準偏差とほぼ同等である）。  
3. すべての因子において、水準1の標準偏差は水準2の標準偏差よりも小さい。  

#### 定義：応答標準偏差と因子変数の関係
DOE標準偏差プロットは、以下の条件で作成する。  

* 縦軸：因子各水準における応答変数の標準偏差  
* 横軸：因子変数  

#### 論点
DOE標準偏差プロットは、以下の質問に対する答えを与えることができる。  

1. 因子間で標準偏差はどう変化するか。  
2. 因子内で標準偏差はどう変化するか。  
3. 尺度に関して最も重要な因子はどれか。  
4. 尺度に関して重要な因子の順位はどうか。

#### 重要：ばらつきの評価
多くの実験計画の目的は、どの因子が有意かを特定することである。
これは通常、因子水準の平均値から判断する（DOE平均プロットで表示可能）。
副次的な目的は、因子内および因子間の応答のばらつきを評価することである。
DOE標準偏差プロットはこれを実施する便利な方法である。

#### ソフトウェア
DOE標準偏差プロットは、ほとんどの汎用統計ソフトウェアでは利用できない。
直接実装していない統計ソフトウェアでも、マクロを記述することでDOE標準偏差プロットを作成できる可能性がある。
