# 1.3.5.1. 位置の指標

#### 場所
多くの統計分析における基本的な課題は、分布の位置パラメータを推定することである。
すなわち、データを最もよく表す典型的な値もしくは中心値を見つけることである。

#### 位置の定義
典型的な値を定義する最初の手順は、その意味を明確にすることである。
単変量データでは、主に三つの定義が用いられる。  
1. 平均値 - 平均値はデータ点の合計をデータ点の数で割った値である。
すなわち、  
$$\bar{Y}=\sum_{i=1}^N Y_i/N$$  
平均値(mean)は、一般的に「平均(average)」と呼ばれる値である。
用語「平均(average)」を平均値(mean)の同義語として用い、「典型値」を位置の指標を総称する用語として用いる。  
2. 中央値 - 中央値とは、その点より小さいデータが半数、その点より大きいデータが半数となるデータの値である。
すなわち、$`X_1,X_2,...,X_N`$ が最小値から最大値へ並べ替えられた無作為標本であるとき、中央値は次のように定義される。  
$$\tilde{Y}=Y_{(N+1)/2} \text{,   N が奇数の場合}$$   
$$\tilde{Y}=(Y_{N/2}+Y_{(N/2)+1})/2 \text{,   N が偶数の場合}$$  
* 最頻値 - 最頻値とは、無作為標本において  最も頻繁に現れる値である。
必ずしもひとつとは限らない。
最頻値は通常、定性的に用いられる。
例えば、データには単一の支配的な山が存在し、さらに二つ以上の小さな山が存在する可能性がある。
これは通常、データのヒストグラムから明らかとなる。  

連続母集団から標本抽出を行う場合、最頻値の定義には注意が必要である。
つまり、データが連続的であれば、特定の値が複数回出現することはありえない。
より厳密ではないが意味のある指標としては、最高峰を持つヒストグラムの階級区間の中点がある。

#### 異なる指標の理由
当然の疑問として、なぜ典型値の測定方法が複数存在するのかが挙げられる。
以下の例では、これらの代替の定義が有用かつ必要である理由を説明する。 
このプロットは、正規分布、指数分布、コーシー分布、対数正規分布に従う10,000個の乱数のヒストグラムを示している。  
![1.3.5.1.Measures of Location](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/location.gif)  

#### 正規分布
最初のヒストグラムは[正規分布](eda3661.md)からの例である。
平均は0.005、中央値は-0.010、最頻値は-0.144である（最頻値はヒストグラム区間の中で最も高いピークを持つ区間の中点として計算される）。 
 
正規分布は対称分布であり、分布の中心に単一のピークを持ち、裾部が良好な挙動を示す。
対称とは、分布を軸で折り畳むと両側が一致することを意味する。
つまり、ある中心点から左右で同じ挙動を示す。
正規分布では、平均、中央値、最頻値は実質的に同等である。
上記のヒストグラムは平均、中央値、最頻値について類似の推定値を与える。
したがって、データが正規分布でよく近似されることをヒストグラムや正規確率プロットが示している場合、位置推定量として平均を使用することは合理的である。 

#### 指数分布
2番目のヒストグラムは[指数分布](eda3667.md)からの例である。
平均は1.001、中央値は0.684、最頻値は0.254である（最頻値は、最も高いピークを持つヒストグラム区間の中点として計算される）。 

指数分布は偏った、すなわち非対称な分布である。
歪んだ分布では、平均と中央値は一致しない。
平均は歪みの方向にに偏る。
つまり、右裾が左裾より重い場合、平均は中央値より大きくなる。
同様に、左裾が右裾より重い場合、平均は中央値より小さくなる。  

歪んだ分布では、平均、中央値、最頻値のどれが典型的な値をより意味ある尺度として表すかは全く明らかではない。
この場合、三つの尺度全てが有用である。 

#### コーシー分布
3番目のヒストグラムは[コーシー分布](eda3663.md)からの例である。
平均は3.70、中央値は-0.016、最頻値は-0.362である（最頻値は、最も高いピークを持つヒストグラム区間の中点として計算される）。  

他のデータとの視覚的比較を容易にするため、コーシー分布のヒストグラムは-10から10の値に制限した。
実際のコーシー分布データの最小値は約-29,000、最大値は約89,000である。  

コーシー分布は対称分布であり、分布の中心に単一のピークを持ち、重い裾部を有する。
コーシー分布には興味深い性質があり、より多くのデータを収集しても平均の推定精度が向上しない。
すなわち、平均の標本分布は元のデータの標本分布と同等である。
これはコーシー分布において平均値が典型的な値の尺度として無意味であることを意味する。
このヒストグラムでは平均値3.7が大半のデータ値を大きく上回っている。
これは裾部におけるごく少数の極端な値に起因する。
しかし中央値は典型的な値の有用な指標を提供する。  

コーシー分布は極端な例ではあるが、平均値の測定における重裾分布の重要性を示している。
裾部の極端な値は平均値を歪める。
しかし、中央値は順位に基づくため、これらの極端な値によって歪められることはない。
一般に、裾部に極端な値を持つデータでは、平均値よりも中央値の方が位置のより良い推定値を与える。 

#### 対数正規分布
4番目のヒストグラムは[対数正規分布](eda3669.md)からの例である。
平均は1.677、中央値は0.989、最頻値は0.680である（最頻値は、最も高いピークを持つヒストグラム区間の中点として計算される）。　

対数正規分布もまた歪分布である。
したがって平均と中央値は位置の推定値として同等の情報を与えない。
指数分布の場合と同様に、どちらがより意味のある位置の指標であるかという問いに対する明確な答えは存在しない。 

#### 頑健性
位置を測定する手段として、平均値や中央値に代わる様々な選択肢が存在する。
平均値はデータが正規分布している場合にのみ最適な推定量となるため、代替手法はデータが正規分布していない場合に適用される。

[TukeyとMosteller](../section4/eda43.md#Mosteller)は頑健性の2種類を定義した。
頑健性とは非正規性の影響を受けにくい性質を指す。

1. 妥当性の頑健性とは、母集団位置の信頼区間が基礎となる分布がどのようなものであっても、95%の確率で母集団位置を包含することを意味する。  
2. 効率性の頑健性とは、非正規分布の裾部において高い有効性を示すことを指す。
すなわち、母位置の信頼区間は、分布の真の形状が分かっている場合に得られる最良の結果とほぼ同程度の狭さを示す傾向がある。  

平均は、母分布が正規分布である場合に最善の推定量となる例である。
しかし、妥当性の頑健性に欠ける。
つまり、母分布が実際には正規分布でない場合、平均に基づく信頼区間は精度が低い傾向にある。  

中央値は、妥当性の頑健性は持つが効率性の頑健性を持たない推定量の一例である。  

代替の位置の指標は、この二つの頑健性の概念の均衡を取ろうとする。
つまり、データが正規分布に従う場合の信頼区間は、平均に基づく信頼区間とほぼ同程度に狭いものであるべきである。
しかし、基礎となるデータが正規分布に従わない場合でも、その有効性を維持すべきである。
特に、これらの代替案は裾が重い分布の問題を取り扱う。 

#### 位置の代替指標
より一般的な代替位置指標には以下のもののがある。  
1. 中位平均 - 25分位点と75分位点の間のデータを用いて平均を算出する。  
2. 刈込平均 - 中位平均に類似するが、異なる百分位値を使用する。
一般的な選択は、下位裾部と上位裾部の両方でデータの5%を刈り込むこと、すなわち5分位点と95分位点間のデータで平均を計算することである。  
3. ウィンザー化平均 - 刈込み平均に類似している。
ただし、データを切り捨てる代わりに、最小値（または最大値）に設定する。
例えば、5分位点未満の全データは5分位点の値に、95分位点を超える全データは95分位点の値にそれぞれ設定される。  
4. 中位数 = (最小値 + 最大値) / 2  

上記で定義した最初の3つの代替位置推定量は、裾部の極端な値に過度に影響されないという点で中央値の利点を有する。
ただし、正規分布（またはそれに近い）データでは平均値に近い推定値を与える。  

中位範囲は両極端な点に基づくため頑健ではない。
その使用は通常、極端な点における挙動が関連する状況に限定される。
