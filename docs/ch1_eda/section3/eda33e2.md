# 1.3.3.14.2. ヒストグラムの解釈：対称、非正規分布、短い裾

#### 対称的で短い裾のヒストグラム
![1.3.3.14.2.Histogram Interpretation: Symmetric, Non-Normal, Short-Tailed](https://www.itl.nist.gov/div898/handbook/eda/gif/histogr2.gif)  


#### 薄短いの解説
上のプロットは、[TUKLAMB.DAT データ集合](https://www.itl.nist.gov/div898/handbook/datasets/TUKLAMB.DAT)の最初の100行のヒストグラムである。  

対称分布において、分布の「本体」は分布の「中心」、一般に確率の大部分が存在する分布領域、すなわち分布の「厚い」部分を指す。
分布の「裾」とは、分布の極端領域（左右両方）を指す。
分布の「裾の長さ」とは、これらの端がゼロに近づく速度を示す用語である。  

短い裾の分布では、裾はゼロに非常に速く近づく。
このような分布は、一般的に切り詰められた（「鋸で切り落とされた」）外観を持っている。
古典的な短い裾の分布は、確率が与えられた範囲で一定であり、他の領域ではゼロに低下する一様（長方形）分布であり、これを裾がない、あるいは極めて短い裾を持つと表す。  

中程度の裾の分布では、裾部が中程度にゼロに減少する。
古典的な中程度の裾の分布は正規分布（ガウス分布）である。  

長い裾の分布では、裾は非常にゆっくりとゼロに減少し、その結果、分布本体からかなり離れた確率が観測されが予想される。
古典的な長い裾の分布はコーシー分布である。  

裾の長さに関して、上記のヒストグラムは「短い裾」分布の特徴である。  

分布の中心の位置に関する最適（偏りのない、最も正確な）推定は、分布の裾の長さに大きく依存する。
N 個の観測値を取り、計算した標本平均を分布中心の最適な推定値として用いるという一般的な選択は、正規分布（中程度の裾の分布）では良い選択であり、一様分布（短い裾の分布）では不十分であり、コーシー分布（長い裾の分布）では不適切な選択である。
正規分布においては、標本平均が最も正確な推定量であが、一様分布とコーシー分布においては、標本平均が最良の推定量ではない。    

一様分布の場合、中点値  

$$中点値 = (最小 + 最大) / 2$$  

は位置の最良な見積りである。コーシー分布では、中央値が位置の最も優れた推定値である。

#### 推奨される次の手順
ヒストグラムが対称的で短い裾分布を示す場合、推奨される次の手順は[一様分布確率プロット](eda33m)を作成することである。
一様分布確率プロットが線形である場合、一様分布はデータに適したモデルである。
