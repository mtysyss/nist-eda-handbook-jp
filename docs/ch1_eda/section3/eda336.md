# 1.3.3.6. Box-Cox正規性プロット

#### 目的：データを正規化するための変換を見つける  
多くの統計検定や区間は、正規性の仮定に基づいている。
正規性の仮定は、正規性の仮定を行わない検定と比較して、しばしば単純で数学的に扱いやすく、かつ強力な検定へと導く。
残念ながら、多くの実データ集合は大概、実際には正規ではない。
しかし、データ集合の適切な変換を行うと、しばしば正規分布に近いデータ集合が得られることがある。
これにより、正規性の仮定に基づく統計的技法の適用性と有用性が高まる。  

Box-Cox変換は特に有用な変換族である。
以下の式で定義される。

$$T(Y)=(Y^λ - 1)/λ$$  

ここで、Y は応答変数、λ は変換係数である。
λ = 0 のとき、データの自然対数を取る代わりに、上記の式を使用する。  


上記で定義したBox‐Cox変換のような特定の変換が与えられたとき、結果として得られる変換の正規性の測度を定義することが有用である。
一つの測定手段は、[正規確率プロット](eda33l.htm)の相関係数を計算することである。
相関は確率プロットの垂直軸と横軸の変数間で計算され、確率プロットの線形性を測る便利な指標である（確率プロットがより線形であるほど、正規分布がデータに適合する）。  

Box-Cox正規性プロットは、さまざまな λ 値に対応する相関係数をプロットしたものである。
プロット上で最大相関係数に対応する λ 値が、データを正規分布に近づけるための最適な λ 値となる。

#### サンプル・プロット
![Box-Cox正規性プロット](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/boxcox.gif)  
上段左側のヒストグラムは、右寄きの歪みがある（正規分布に従わない）[データ集合（最初の列）](https://www.itl.nist.gov/div898/handbook/datasets/AUTO83B.DAT)を示している。
Box-Cox正規性プロットでは、最大相関係数が $`\lambda＝-0.3`$ であること示されている。
Box-Cox変換を $`\lambda＝-0.3`$ で適用した後のヒストグラムは、正規性の仮定が妥当なデータ集合を示している。
このことは、変換されたデータの正規性確率プロットで確認できる。

#### 定義
Box-Cox正規性プロットは、次の方法で作成する。  

* 垂直軸：Box-Cox変換を適用した正規確率プロットからの相関係数  
* 水平軸：$`\lambda`$ 値  

#### 論点
Box-Cox正規性プロットは、以下の質問に対する答えを与えることができる。

1. データを正規化するために変換する方法はあるか。  
2. 変換係数の最適な値は何か。  

#### 重要：正規化は検定の妥当性を改善する
正規性仮定は、多くの一変量区間や仮説検定に不可欠である。
データが実際には明らかに正規ではない場合、Box-Cox正規性プロットを使用して、ほぼ正規になるように変換できることがよくある。

#### ソフトウェア
Box-Cox線形性プロットは、多くの一般的な統計ソフトウェア・プログラムの標準的な機能ではない。
しかし、その基礎技法は、正規分布確率プロットと相関係数の計算に基づいている。
したがって、これらの機能が使える統計ソフトウェアであれば、Box-Coxの正規性プロット用のマクロを書くことは実現可能である。
