# 1.3.3.31. Youden プロット

#### 目的：試験所間比較
Youdenプロットは、各ラボが同一製品で2回の実験を行い、または異なる製品で1回の実験を行う場合の試験所間データを分析するための図表現技法である。  

Youdenプロットは、試験所内のばらつきと試験所間のばらつきの両方を比較する簡単だが効果的な方法である。

#### プロット例  
![1.3.3.31. Youden Plot](http://www.itl.nist.gov/div898/handbook/eda/gif/youdenpl.gif)  

[UGIANSKY.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/UGIANSKY.DAT)のこのYoudenプロットは、以下点を示している。  

1. すべての研究所が同等であるとはいえない。  
2. Lab 4は偏位が低い。  
3. Lab 3には、試験所内変動の問題がある。  
4. Lab 5には、外れ値のある実験がある。  

#### 定義：試験所で符号化した応答1と応答2の比較
Youden プロットは、以下の条件で作成する。  

- 縦軸：応答変数 1（つまり、実行1または製品1の応答値）  
- 横軸：応答変数 2（つまり、実行2または製品2の応答値）  

さらに、プロット記号はラボID（通常は1から$`k`$までの整数、$`k`$はラボの数）である。 
45度の基準線も描画される場合がある。
理想的には、同じ製品を2つの実行を行う試験所は、かなり類似した結果を与えるはずである。 
この基準線からの逸脱は、試験所の不一致を示す。
2つの異なる製品を試験している場合は、45度の直線は適切ではないこともある。 
しかし、複数の試験所が一貫している場合、点は近似した直線に近い位置に表示される。

#### 論点
Youden プロットは、次の質問の答えるを与える。  

1. すべての試験所は同等か。  
2. 試験所間で（再現性の）問題があるのはどこの試験所か。  
3. 試験所内で（反復性の）問題があるのはどこの試験所か。  
4. 外れ値なのはどこの試験所か。  

#### 重要
試験所間調査や同一試験所での二つの実行を比較する場合には、一貫した結果が得られるかを知ることが重要である。
Youdenプロットは、この種のデータを分析するための定型的プロットであるべきである。

#### DOE Youden プロット
[DOE Youden プロット](eda33v1.md) は、実験計画において用いられる特殊な Youden プロットである。
特に、[完全実施](../../pri/section3/pri333.md)や[一部実施](../../pri/section3/pri334.md)要因計画において有用である。
