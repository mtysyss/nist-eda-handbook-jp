# 1.3.5.8. 分散のカイ二乗検定

#### 目的：分散が指定された値と等しいかの検定
カイ二乗検定（[Snedecor and Cochran,1983](../section4/eda43.md#Snedecor)）は、母集団の分散が指定された値と等しいかを検定するために用いられる。
この検定は、両側検定もしくは片側検定のいずれかで行う。
両側検定では、真の分散が指定された値より小さいか、あるいは大きいという対立仮説を検定する。 
片側検定では、一方向のみを検定する。
両側検定か片側検定かの選択は、問題によって決まる。
例えば、新しい工程を検定する場合、そのばらつきが現在の工程のばらつきよりも大きいかにのみに関心があるかもしれない。

#### 定義
カイ二乗の仮説検定は次のように定義される。  

##### $`H_0`$:
$`\sigma^2 = \sigma_0^2`$  

##### $`H\_a`$:
$`\sigma^2 < \sigma_0^2`$　　下限の片側検定の場合  
$`\sigma^2 > \sigma_0^2`$　　上側片側検定の場合  
$`\sigma^2 \ne \sigma_0^2`$　　両側検定の場合  

##### 検定統計量：
$`T = (N-1)(s/\sigma\_0)^2`$

ここで、*N* は標本サイズ、*s* は標本標準偏差である。
この式の重要な要素は、$`s/σ_0`$ という比で、これは標本標準偏差と目標標準偏差の比を比較する。
この比が1から大きく外れるほど、帰無仮説を棄却する可能性が高くなる。  

##### 有意水準：
*α*

##### 棄却域：
分散が指定された値 $`σ_0^2`$ であるという帰無仮説を以下の場合に棄却する。  
$`T > \chi^2\_{1-\alpha, \, N-1}`$　上側対立仮説の場合  
$`T < \chi^2\_{\alpha, \, N-1}`$　下側対立仮説の場合  
$`T < \chi^2\_{\alpha/2, \, N-1}`$　両側対立仮説の場合  
または  
$`T > \chi^2\_{1-\alpha/2, \, N-1}`$  
ここで、$`\chi\_{., \, N-1}^2`$ は、自由度 $`N-1`$ の[カイ二乗分布](eda3666.md)の[棄却値](eda3674.md)である。  

この仮説検定の式は、分散の信頼区間推定式へと容易に変換できる。

$$\sqrt{\frac{(N-1)s^2}{\chi^2\_{1-\alpha/2, \, N-1}}} \le \sigma \le \sqrt{\frac{(N-1)s^2}{\chi^2\_{\alpha/2, \, N-1}}}$$  

標準偏差の信頼区間は、分散の信頼区間の上限と下限の平方根をとり計算する。 

#### カイ二乗検定の例
[GEAR.DAT](eda3581.md)データセットに対してカイ二乗検定を実施した。
歯車径の100回の測定値について、観測された分散は 0.00003969 である（標準偏差は 0.0063 ）。
真の分散が 0.01 に等しいという帰無仮説を検定する。

$`H_0`$:　$`σ_2=0.01`$  
$`H_a`$:　$`σ_2 \ne 0.01`$

検定統計量:　$`T = 0.3903`$  
自由度:　　　$`N - 1 = 99`$  
有意水準:　　$`α = 0.05`$  
棄却値:　　　$`Χ_{α/2,N-1}^2 = 73.361 `$  
　　　　　　$`Χ_{1-α/2,N-1}^2 = 128.422`$  
棄却域:　　　$`T < 73.361`$ もしくは $`T > 128.422`$　の場合に $`H_0`$ を棄却   

検定統計量の値 0.3903 は下限臨界値よりはるかに小さいため、帰無仮説を棄却し、分散は 0.01 に等しくないという結論を得る。

#### 論点
カイ二乗検定は、以下の質問に答えるを与える。  

1. 分散は、あらかじめ定められた閾値と等しいか。  
2. 分散は、あらかじめ定められた閾値よりも大きいか。  
3. 分散は、あるあらかじめ定められた閾値よりも小さいか。
