# 1.3.6. 多種の確率分布

#### 多種の確率分布
多種の確率分布は、統計学における考え方の基本である。
これらは理論的な側面と実践的な側面の両方で用いられる。  

確率分布の実用的な用途としては、次のようなものがある。

* 母数の信頼区間を算出すること、および、仮説検定の有意領域を算出すること。  
* 単変量データの場合、データに対して妥当な分布モデルを決定することがしばしば有用である。  
* 統計的信頼区間や仮説検定は、しばしば特定の分布の仮定に基づいている。
分布の仮定に基づいて信頼区間や検定を計算する前に、その仮定が与えられたデータ集合に対して妥当であるかを確認する必要がある。
この場合に分布はデータに最も適合する分布である必要はなく、統計技法が有効な結論を導き出せるだけの、十分に適切なモデルであればよい。
* 特定の確率分布を用いて生成された乱数を用いたシミュレーション研究が必要となる場合が多い。
