# 1.3.3.21.1. 正規確率プロット：正規分布に従うデータ

#### 正規確率プロット
以下の正規確率プロットは[熱流量計](../section4/eda428.md)のデータに基づいている。  

![1.3.3.21.1.Normal Probability Plot: Normally Distributed Data](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/normprp1.gif)  

#### 結論
上記のプロットから、以下の結論を導くことができる。  

1. 正規確率プロットは、強い直線的な傾向を示している。
確率プロット上の点に回帰した直線からの逸脱はごくわずかである。
2. 正規分布は、これらのデータに対して適切なモデルであると考えられる。

#### 議論
視覚的に見ると、確率プロットは極めて直線的なパターンを示している。
これは、確率プロットに適合させた直線の相関係数が0.9989であることから裏付けられる。
プロットの上端および下端にあるデータ点が、直線パターンから著しく逸脱していないという事実は、（正規分布と比較して）顕著な外れ値が存在しないことを示している。  

この場合、正規分布がデータに対して優れたモデルであると結論付けることは十分に妥当である。
回帰直線の切片と傾きは、適合した正規分布の位置及び尺度の母数推定値として、それぞれ9.26と0.023を与える。
