# 1.3. EDA技法  

#### 要約  
データ集合を収集した後、探索的データ解析をどのように行うか？
どのような技法を採用するか？
各種技法はどのような点に焦点を当てているか？
どのような結論が導き出せると期待できるか？   

本節では、EDA技法のギャラリーと各技法の詳細な説明を通じて、疑問に対する答えを提供する。手法は図表現技法と定量的技法に分類される。
探索的データ解析においては、主に図表現技法に重点が置かれる。
