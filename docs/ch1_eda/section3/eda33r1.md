# 1.3.3.27.1. スペクトル図：無作為データ

#### 200個の正規乱数のスペクトル図
![1.3.3.27.1. Spectral Plot: Random Data](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/spect1.gif)  

#### 結論
上記の[200の正規乱数](https://www.itl.nist.gov/div898/handbook/datasets/NORMAL2.DAT)プロットから、以下の結論を導き出せる。

1. 支配的なピークは存在しない。  
2. スペクトルに特定可能なパターンは見られない。  
3. データは無作為である。  

#### 議論
無作為データの場合、スペクトル図にはスペクトル内に支配的なピークや明確なパターンが
見られないはずである。
上記のサンプルプロットでは、明らかに支配的なピークは存在せず、ピークは無作為に変動しているように見える。
この種のスペクトル図の様相は、データ内に顕著な周期パターンが存在しないことを示している。
