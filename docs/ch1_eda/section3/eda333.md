# 1.3.3.3. ブロック・プロット

#### 目的：関心のある要因が、他のすべての要因に対して頑健な効果を持つかの判定
ブロックプロット（[Filliben 1993](../section4/eda43.md#Filliben)）は、関心のある因子（主因子）が応答変数に統計的に有意な影響を与えるか、またその主因子の効果に関する結論が実験内の他のすべての雑因子や副次因子に対して頑健に成立するかを評価するための探索的データ解析（EDA）ツールである。 
これは[分散分析検定](../../prc/section4/prc42.md)を、より仮定依存性の低い二項検定に置き換えるものであり、主因子が効果を持つかを頑健に判断しようとするときには常に日常的に使用すべきである。 

#### サンプル・プロット：溶接方法2は、12件中10件において溶接方法1よりも低い（より良い）
![1.3.3.3.Block Plot](https://www.itl.nist.gov/div898/handbook/eda/gif/blockplo.gif)  
[SHEESLE2.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/SHEESLE2.DAT)のこのブロック・プロットは、12事例（バー）のうち10事例において溶接方法2が溶接方法1より低い（優れている）ことを示している。
二項分布の観点から、溶接方法は統計的に有意である。 

#### 定義
ブロック・プロットは以下の条件で作成する。

* 縦軸：応答変数 Y  
* 横軸：すべての二次因子 X1, X2, ... の全水準の全組合せ  
* プロット特性：主因子の水準 XP  

#### 議論：主因子はプロット特性で示される：バー内プロット特性
1時間あたりの平均不良リード線数に関する以下の4要因の調査

1. 溶接方法（2水準）  
2. 工場（2水準）  
3. 速度（2水準）  
4. シフト（3水準）  

は上記のプロットに示されている。
溶接方法は主因子であり、他の3因子は妨害因子である。
横軸上の12の異なる位置は、3つの妨害因子の全可能な組合せに対応する。
すなわち、12 = 2工場 × 2速度 × 3シフトである。 
これら12条件は、主因子（溶接方法）の2水準に関する結論が真に「一般的な結論」と呼べるかを評価する枠組みを提供する。
もし、12の妨害因子の組合せの全てまたは大部分において、ある溶接方法の設定が他の溶接方法の設定よりも優れた結果（時間当たりの平均欠陥数が少ない）を示すことが確認されれば、その結論は実際に一般的かつ頑健であると言える。

#### 横軸に沿って順序付け
上記のグラフでは、横軸に沿った順序は次のとおり。

* 左側の6本の棒は工場1から、右側の6本の棒は工場2から取得したものであるす。
* 最初の3本の棒は速度1、次の3本は速度2、その次の3本は速度1、最後の3本は速度2に属する。
* 棒1、4、7、10は第1シフト分、棒2、5、8、11は第2シフト分、棒3、6、9、12は第3シフト分である。

#### 12件中10件において、設定2は設定1よりも優れている
最初の棒グラフ（プラント1、速度1、シフト1）のブロックプロットでは、溶接方法1は1時間あたり約28個の欠陥を生じ、溶接方法2は1時間あたり約22個の欠陥を生じる。
したがって、この組み合わせにおける差は約1時間あたり6個の欠陥であり、溶接方法2がより優れている（1時間あたりの欠陥数が少ない）と見なされる。  

「溶接方法2は溶接方法1より優れている」という結論は一般化できるか。  

2番目の棒（工場1、速度1、シフト2）では、溶接方法1は約37であるのに対し、溶接方法2は約18に過ぎない。
したがって、溶接方法2は、再び、溶接方法1より優れていると見なされる。
同様に、棒3（工場1、速度1、シフト3）では、溶接方法2が溶接方法1より小さいことが確認できる。
12本の棒すべてを概観すると、溶接方法2が溶接方法1より小さいことがわかる。
（工場1、速度1、シフト3）でも、溶接方法2が溶接方法1より小さい値を示している。
全12本の棒を調査すると、12件中10件で溶接方法2が溶接方法1より小さい値を示しており、これは溶接方法の効果が高い信頼性を持つことを強く示唆している。 

#### 発生確率がわずか2％の事象
12回中10回が偶然に起こる確率はどれくらいか。
これは確率論的に、コインを12回投げたときに10回表が出ることでそのコインに歪がないかを検定することに相当する。
歪みのないコインを12回投げたときに10回（あるいはより極端な11回、12回）表が出る確率（[二項分布から](eda366i.md)）は約2%である。 
このような低確率事象は通常、成立し得ないと却下され、実際には溶接方法に差異があると結論づけられる。

#### 利点：図表現と二項
ブロック・プロットの利点は以下の通りである。

* 定量手法（分散分析）が図表現手法に置き換えられる。
* F検定（分散分析）が二項検定に置き換えられ、より少ない仮定で済む。

#### 論点
ブロック・プロットは以下の質問に対する答えを与えることができる。  

1. 関心のある要因は有意か。
2. 関心のある要因は効果を持つか。
3. 主因子の水準間で位置は変化するか。
4. プロセスは改善されたか。
5. 主因子の最適な設定値（＝レベル）は何か。
6. この主要因子の最適設定により、平均でどの程度の改善が期待できるか。
7. 主因子の1つと1つ以上の妨害因子との間に相互作用は存在するか。
8. 主要因子の効果は、特定の妨害因子の設定によって変化するか。
9. 外れ値は存在するか。

#### 重要：関心のある因子の有意性を厳密に検定する
ブロック・プロットは、主因子の結論が実際に頑健に一般化可能かどうかを鋭く焦点化する図解技法である。
この問いは、分析者が「どの因子が重要でどの因子が重要でないか」（スクリーニング問題）と問う一般的な多因子実験の問いとは根本的に異なる。 
分散分析などの全体的なデータ解析技法は、この差異を活用する局所的・焦点化されたデータ解析手法によって改善の余地がある。

ブロックプロットは、[セラミック強度](../section4/eda42a.md)データの事例研究で使用されている。

#### ソフトウェア
ブロック・プロットは現在、ほとんどの汎用統計ソフトウェアでは利用できない。
ただし、Dataplotや、Rソフトウェアを使用してプログラミングをすれば作成することが可能である。
