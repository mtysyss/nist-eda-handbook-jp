# 1.3.6.7.5. $`t^*`$ 分布の境界値

#### 表の使い方
この表は、[校正区間内における3点校正標準の測定値](../../mpc/section3/mpc37.md)から、校正直線が統計的管理状態にあるか否かを判定するのに適した t\*分布の上限境界値である。
自由度 *ν* の[検定統計量](../../mpc/section3/mpc371.md)をこの境界値と比較する。
検定統計量の絶対値が表の値を超える場合に当該機器の校正は管理外れと判断される。
