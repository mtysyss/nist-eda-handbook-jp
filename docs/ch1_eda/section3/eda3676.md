# 1.3.6.7.6. 正規PPCC分布の境界値

#### この表の使い方
この表は、データ集合が近似的に[正規分布](eda3661.md)に従う母集団から得られたかどうかを判定するのに適切な、正規確率プロット相関係数（PPCC）分布の境界値を示している。
これは[正規確率プロット](eda33m.md)と組み合わせて用いる。
検定統計量は正規確率プロットを構成する点の相関係数である。
この検定統計量を下記の境界値と比較する。  

検定統計量が表の値より小さい場合、データが正規分布母集団から得られたという帰無仮説は棄却される。
例えば、50個のデータ点からなるデータ集合の相関係数が正規確率プロットから 0.985 であった場合、有意水準 5%における境界値は 0.9761 である。
0.985 は 0.9761 より大きいため、データが正規分布母集団から得られたという帰無仮説を棄却できない。  

完全な正規性は完全な相関（すなわち相関係数 1）を意味するため、我々が関心を持つのは相関係数が低すぎる場合の正規性の棄却のみである。
つまりこれは下側片側検定である。  

本表の数値は[Filliben](../section4/eda43.md#PPCC)と[Devaney](../section4/eda43.md#Devaney)によるシミュレーション研究から決定された。
