# 1.3.3.21. 正規確率プロット

#### 目的：データが正規分布に従っているかの確認
正規確率プロット（[Chambers et al., 1983](../section4/eda43.md#Chambers)）は、データ集合が概ね[正規](eda3661.md)分布であるかを評価するための視覚的技法である。  

データを理論正規分布に対してプロットし、点が近似的な直線になるように作成する。
この直線からの逸脱は、正規性からの逸脱を示している。

正規確率プロットは[確率プロット](eda33m.md)の特殊な例である。
正規確率プロットは、多くの応用において重要であるため、別途取り上げる。

#### プロット例
![1.3.3.21.Normal Probability Plot](https://www.itl.nist.gov/div898/handbook/eda/gif/normprpl.gif)  

[100個の正規乱数](https://www.itl.nist.gov/div898/handbook/datasets/NORMAL.DAT)に関する正規確率プロットの点は、近似的に直線的なパターンを形成しており、正規分布がこのデータ集合に対する適切なモデルであることを示している。 


#### 定義：順序付き応答値と正規順序統計量
正規確率プロットは、以下の条件で作成する。 

* 縦軸：順序付けされた応答値  
* 横軸：正規順統計の中央値  

次式で定義される正規順序統計の中央値に一致する関数で観測値をプロットする。

$$N_i=G(u_i)$$  

ここで、$`U_i`$ は（以下で定義）一様順序統計量の中央値であり、$`G`$ は正規分布の[パーセント点関数](eda362.md#パーセント点関数)である。
パーセント点関数は、[累積分布関数](eda362.md#累積分布関数)の逆関数（$`x`$ がある値以下である確率）である。
つまり、確率が与えられたとき、累積分布関数の対応する $`x`$ が必要である。  

一様順序統計量の中央値（[Filliben 1975](../section4/eda43.md#PPCC) を参照）は以下の式で近似できる。

$$U_i=1-U_n　i=1　の場合$$  
$$U_i=(i-0.3175)/(n+0.365)　i=2,3,...,n-1　の場合$$  
$$U_i=0.5(1/n)　i=n　の場合$$  

さらに、直線を点に合わせ、基準線として追加することもできる。
この線から点が大きく離れるほど、正規性からの逸脱の兆候が大きくなる。  

正規分布以外の分布に対する[確率プロット](eda33m.md)も、全く同じ方法で計算する。
正規分布のパーセント点関数（$`G`$）を単に目的の分布のパーセント点関数に置き換える。
つまり、パーセント点関数を持つ任意の分布に対して、確率プロットを簡単に作成することができる。  

この確率プロット計算方法の利点の一つは、適合した直線の切片および傾きの推定が、実際には分布の位置および尺度母数の推定であるということである。
正規分布においては、位置と尺度がそれぞれ平均と標準偏差で推定されるため、あまり重要ではないが、他の多くの分布にも有用である。

正規確率プロット上の点の相関係数は、データが正規分布に従うという形式的な仮説検定のために、[境界値の表](eda3676.md)と比較することができる。

#### 論点  
正規確率プロットは、以下の質問に対する答えを与えることができる。  

1. データは正規分布か。  
2. 正常性からの逸脱（データが歪んでいる、予想より短い裾、予想より長い裾）の性質は何か。  

#### 重要：正規性の仮定の確認
測定工程における基本的な前提は、データが次のように振る舞うべきということである。  

1. 無作為性  
2. 固定分布  
3. 固定位置  
4. 固定尺度  

確率プロットは、固定分布の仮定を評価するために用いる。
特に、多くの統計モデルは次の形をとる。

$$応答 = 決定論的 + 無作為$$  

決定論項が近似であり、無作為項が誤差である。
この誤差成分は、最も一般的な統計モデルにおいて、固定された位置と尺度を持つ正規分布を具体的に想定している。
これは正規確率プロットの最も多い応用である。
すなわち、モデルを近似し、適合したモデルの残差に対して正規確率プロットを作成する。
適合したモデルの残差が正規分布でない場合、モデルの主な仮定の一つに違反する。
