# 1.3.3.26.11. 散布図行列

#### 目的：変数間における対応のある関係の確認
変数$`X_1, X_2, ..., X_k`$ の集合が与えられたとき、散布図行列はそれら変数のすべての対応のある散布図を1ページ上に行列形式で表示する。
すなわち、変数が$`k`$個ある場合、散布図行列は$`k`$行$`k`$列となり、この行列の$`i`$行$`j`$列は$`X_i`$対$`X)_j`$の散布図である。  

散布図行列の基本概念は単純だが、プロットの詳細には数多くの代替案がある。  

1. 対角線プロットは$`X_i`$対$`X_{i\dot}で打点するため、単純に45度の直線である。
これは変数の単変量分布を示す点で一定の有用性はあるが、他の代替手法が一般的である。
対角線上に変数の表示を好む利用者もいる。
別の選択肢として、対角線上に単変量ヒストグラムをプロットする方法がある。
あるいは、対角線を空白のままにすることもある。   
2. $`X_i`$対$`X_j`$は軸を反転させた$`X_j`$対$`X_i`$と同等であるため、対角線下のプロットを省略する手法も好まれる。 
3. 散布図に何らかの近似曲線を重ねることは有用である。
線形または二次近似も使用可能であるが、最も一般的な代替案は[lowess](../../ch4_pmd/section1/pmd144.md)曲線を重ねることである。 
4. プロット数が膨大になる可能性があるため、軸ラベルを情報量豊富かつ視覚的に好ましい形で表示するのはやや難しいことがある。
効果的な代替案として、行と列を交互にラベル表示する方法がある。
具体的には、1行目では最初のプロットのみ左縦軸に目盛線と軸ラベルを表示し、2行目では最後のプロットの右縦軸にのみ目盛線と軸ラベルを表示する。
この交互パターンは残りの行でも行う。
列と横軸ラベルにも同様のパターンを適用する。
別の方法として、最小値と最大値を対角線上のプロットに変数名と共に配置する方法がある。 

5. 散布図を余白無しで繋げるのを好む分析者もいれば、各プロット間にわずかな間隔を空けることを好む者もいる。 
6. このプロット形式は散布図に最も頻繁に使用されるが、基本概念は単純かつ強力であり、[分位数-分位数プロット](eda33o.md)や[対比ヒストグラム](eda332.md)など対にしたプロットの他のプロット形式へも容易に拡張可能である。 

#### プロット例  
![1.3.3.26.11.Scatterplot Matrix](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/spmatr2.gif)  

NISTの化学者 Lloyd Currie が収集した[汚染データ](https://www.itl.nist.gov/div898/handbook/datasets/CURRIE.DAT)から作成されたプロット例である。  

このプロットを観る方法はいくつかある。
特定の変数に主に関心がある場合、その変数の行と列を眺める。
最も強い相関関係を見つけたい場合、すべてのプロットを眺め、どの変数が関連しているかを判断する。 

#### 定義
$`k`$個の変数が与えられたとき、散布図行列は$`k`$行$`k`$列で構成される。
各行と各列は単一の散布図を定義する。
行 $`i`$ と列 $`j`$ の個々のプロットは以下条件で定義する

* 縦軸：変数 $`X_i`$  
* 横軸：変数 $`X_j`$  

#### 論点
散布図マトリクスは、以下の質問に対する答えを与える。  

1. 変数間に対関係はあるか。  
2. 関係が存在するならば、それらの関係の性質は何か。  
3. データに外れ値はあるか。  
4. データに群ごとの集団があるか。  

#### 連動と絞込み
散布図行列は、連動と絞込の概念の基盤である。
連動とは、ある点または点の集合が各プロットでどのように振る舞うかを示すことを意味する。
これは、何らかの方法でこれらの点を強調表示することで実現する。
例えば、強調表示された点は塗りつぶされた円として描画され、残りの点は塗りつぶされていない円として描画されることがある。 
典型的な応用例として、外れ値が個々の対で打点したときにどのように現れるかを示すことが挙げられる。
絞込みはこの概念をさらに拡張する。
絞込みでは、強調表示する点をマウスでインタラクティブに選択し、散布図行列が動的に更新される（理想的にはリアルタイムで）。
つまり、あるプロット内の点群から矩形領域を選択し、その選択が他のプロットにどのように反映されるかを確認できる。
絞込みの詳細は、Becker, Cleveland, Wilks による論文「_Dynamic Graphics for Data Analysis_」([Cleveland and McGill, 1988](../../section4/eda43.md#Cleveland3)) で論じられている。

#### ソフトウェア
散布図行列は汎用統計ソフトウェアでますます一般的になりつつある。
ソフトウェアが散布図行列を出力しない場合でも、1ページに複数のプロットと散布図を作成可能なら、散布図行列を出力するマクロを作成できるはずである。
図表現手法を重視する一部の汎用統計ソフトウェアでは絞込み機能が利用可能である。
