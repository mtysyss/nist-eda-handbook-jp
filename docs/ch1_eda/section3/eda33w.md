# 1.3.3.32. 4-プロット

#### 目的：基本的な統計的仮定の確認
4-プロットは、4つの特定のEDA 図表現技法の集まりであり、多くの測定工程を裏付ける仮定の検定を目的とする。 
4-プロットは、次の4つのプロットで構成される。  

1. [実行順序プロット](eda33p.md)
2. [遅延プロット](eda33f.md)
3. [ヒストグラム](eda33e.md)
4. [正規確率プロット](eda33l.md)

典型的な測定工程の[4つの基本的な仮定](../section2/eda21.md)が成立するならば、上記4つのプロットは特徴的な外観を持ち（下の正規乱数の事例研究を参照）、いずれかの基本的仮定が満たされない場合、1つ以上のプロットに特異な外観が現れる。 
下の事例研究ではいくつか一般的な状況が示されている。  

4-プロットは、単変量データや時系列データでは明らかに役立ちますが、その有用性ははるかに広範囲に及ぶ。 
次式形式の多くの統計[モデル](../../pmd/pmd.md)は、誤差項に対し同じ基本的仮定をおいている。


つまり、機能的な適合がいかに複雑であっても、誤差項に関する基本的仮定は依然、同じである。 
4-プロットは、モデルが単純であろうと複雑であろうと、モデルに適合させる際には残差に対して定型的に適用するべきである。

#### プロット例：工程には固定位置、固定ばらつき、非無作為（振動）、非正規U字型の分布があり、3つの外れ値がある
![1.3.3.32. 4-Plot](https://www.itl.nist.gov/div898/handbook/eda/gif/4-plot.gif)  

[LEW.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/LEW.DAT)のこの4-プロットは、以下の点をを示している。  

1. 左上の実行順序プロットに示されるように、固定位置の仮定は正当化される。  
2. 左上の実行順序プロットで示されるように、固定ばらつきの仮定は正当化される。  
3. 無作為性の仮定は、右上の非無作為（振動）遅延プロットによって違反していることが示されている。  
4. 共通している正規分布の仮定は、左下のヒストグラムと右下の正規確率プロットによって違反していることが示されている。
分布は非正規でU字型である。    
5. 右上の遅延プロットでいくつかの外れ値が観られる。   

#### 定義：1. 実行順序プロット；2. 遅延プロット；3. ヒストグラム；4. 正規確率プロット
4-プロットは次の構成になっている。  

1. 固定位置とばらちきを検定するための実行順序プロット:  
    - 縦軸: $`Y_i`$  
    - 横軸: $`i`$  

2. 無作為性を検定するための遅延プロット:  
    - 縦軸: $`Y_i`$    
    - 横軸: $`Y_{i-1}`$  

3. （正規）分布を検定するためのヒストグラム:  
    - 縦軸: 頻度  
    - 横軸: $`Y`$  

4. 正規分布を検定するための正規確率プロット:  
    - 縦軸: 順序付き$`Y_i`$  
    - 横軸: 理論値から得られる正規分布$`N(0,1)`$からの順序付き$`Y_i`$  

#### 論点
4-プロットは以下の多くの質問に対する答えを与える。  

1. 工程が管理下にあり、安定し、予測可能か。  
2. 工程は位置に関して偏位しているか。  
3. 工程は変動に関して偏位しているか。  
4. データは無作為か。  
5. 観察値は隣接する観察値と関連しているか。  
6. 時間系列のデータは白色雑音か。  
7. 時間系列のデータが白色雑音ではなく、正弦波、自己回帰などか。  
8. データが無作為ではない場合、より良いモデルは何か。  
9. 工程は正規分布に従うか。  
10. 非正規の場合、工程はどの分布に従うか。  
11. 次のモデルは有効であり十分か。
  $$Y_i=A_0+E_i$$  
12. 初期モデルが不十分な場合、より良いモデルは何か。  
13. 次式は有効か。  
$$s_{\bar{Y}}=s/\sqrt{N}$$  
14. 工程の位置を推定するために標本平均は良い推定値か。  
15. そうでないならば、より良い推定値は何か。  
16. 外れ値はあるか。  

#### 重要：基盤となる仮定の検定は、最終的な科学的・工学的な結論の妥当性を確保するのに役立つ
すべての測定工程の背景には一般的に次の4つの仮定が含まれており、つまり、工程から得られたデータは、「以下の挙動」を示す。  

1. 無作為を描く  
2. 固定分布に従う  
3. その分布の位置は固定されている  
4. その分布のばらつきは固定されている  

予測可能性は科学と工学において重要な目標である。
上記の4つの仮定が成り立つならば、確率的な予測が可能となり、過去の工程だけでなく将来の工程についても確率的な主張ができる。
端的には、このような工程は「統計的に管理されている」と言われる。
4つの仮定が成り立たない場合、工程は偏位状態にあり（位置、ばらつき、分布に関して）、予測不可能で、制御不能である。
位置や、ばらつき、分布の「推定値」による単純な特徴付けは、楽観的で、著しく妥当性のない工学結論につながる。  

科学的、工学的結論の有効性は、これらの4つの基礎となる仮定の有効性に深く結びついており、これらの4つの仮定を定期的に検定する必要がある。
4-プロット（実行順序プロット、遅延プロット、ヒストグラム、正規確率プロット）は、この定期的な確認を行うための簡単で効率的かつ強力な方法として捉えられている。

#### 解釈：平坦、同じ幅、無作為、鐘型、線形
4つの基本的仮定について  

1. 固定位置の仮定が成り立つ場合、実行順序プロットは平坦で偏位していない。  
2. 固定ばらつきの仮定が成り立つ場合、実行順序プロットの縦軸のばらつきは約全体軸に沿って同じになる。  
3. 無作為性の仮定が成り立つ場合、遅延プロットは構造が無くで無作為になる。  
4. 固定分布の仮定が成り立つ場合（特に固定正規分布の仮定が成り立つ場合）、ヒストグラムは鐘形になり、正規確率プロットは近似的に直線になる。  

4つの仮定すべてが成り立つ場合、工程は「統計的に管理下にある」。
実際には多くの工程がこの理想から逸脱する。
