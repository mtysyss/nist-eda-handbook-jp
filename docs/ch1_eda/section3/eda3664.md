# 1.3.6.6.4. t 分布

#### 確率密度関数
*t*分布の[確率密度関数](eda362.md#確率密度関数)は次式である。 

$$f(x) = \frac{(1 + \frac{x^2}{\nu})^{\frac{-(\nu + 1)} {2}}}{B(0.5,0.5\nu)\sqrt{\nu}}$$   

ここで $`B`$ はベータ関数、*ν* は正の整数である形状母数である。
ベータ関数は次式である。  

$$B(\alpha,\beta) = \int_{0}^{1} {t^{\alpha-1}(1-t)^{\beta-1}dt}$$ 

検定の文脈では、*t*分布は「標準化分布」（すなわち位置母数や尺度母数を持たない）として扱われる。
しかし、分布モデルの検討（他の確率分布と同様に）では、*t*分布自体に[位置母数](eda364.md)*μ*と[尺度母数](eda364.md)*σ*を用いて変換することが可能である。  

以下は、4つの異なる形状母数値での*t*確率密度関数のプロットである。  
 
![plot of the t probability density function for 4 different values of the shape parameter ](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/tpdf4.gif)  

これらのプロットはすべて類似した形状を持つ。
差異は裾部の重さに現れる。
実際、*ν* が 1 に等しい *t* 分布は[Cauchy](eda3663.md) 分布である。
*t* 分布は *ν* が大きくなるにつれて[正規](eda3661.md)分布に近づく。
この近似は $`ν>30`$ の値において非常に良好である。 

#### 累積分布関数
*t* 分布の[累積分布関数](eda362.md#累積分布関数)の式は複雑であり、ここでは記載しない。
この式は、[Evans, Hastings, および Peacock](,,/section4/eda43.md#EVANS)の著書に記載されている。

#### 他の確率関数
*t* 分布は仮説検定や信頼区間の構築に用いられることが多く、モデル化用途では稀であるため、ハザード関数、累積ハザード関数、生存関数、逆生存確率関数に関する公式や図表は省略する。

#### 共通統計量 　
平均値　　　0 (*ν* が 1の場合、定義されない)  
中央値　　　0  
最頻値　　　0  
範囲　　　　$`-\infty \mbox{ から } \infty`$  
標準偏差　　$`\sqrt{\frac {\nu} {(\nu - 2)}}`$ *νが*1または2の場合、定義されない。  
変動係数　　未定義  
歪度　　　　0, *ν* が 3以下の場合、定義されない。ただし、*t* 分布はすべてのケースで対称である。  
尖度　　　　$`\frac {3(\nu-2)} {(\nu - 4)} `$ *ν* が 4以下の場合、定義されない。   

#### 母数推定
*t* 分布は仮説検定や信頼区間の構築に主に用いられ、モデル化用途ではほとんど使用されないため、母数推定に関する議論は省略する。

#### 解説  
*t* 分布は、仮説検定の限界領域や信頼区間の決定において多くの場合に使用される。
最も一般的な例は、[データが仮定された工程平均と整合しているかの検定](../prc/section2/prc22.md)である。

#### ソフトウェア
ほとんどの汎用統計ソフトウェアは、*t* 分布の確率関数の少なくとも一部を実装している。
