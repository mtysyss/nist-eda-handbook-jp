# 1.3.3.26.2. 散布図：強い線形（正の相関）関係

#### 強い正の線形相関を示す散布図
![1.3.3.26.2.Scatter Plot: Strong Linear (positive correlation) Relationship](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/scatplo2.gif)  

#### 議論
[LEW3.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/LEW3.DAT)の上記プロットにおいて、直線がデータに問題なく適合している点に注目する。
つまり、線形関係が存在する。
直線からの散らばりが非常に小さく、強い線形関係が認められる。 
直線の傾きは正である（$`X`$の値が小さいと$`Y`$の値も小さく、$`X`$の値が大きいと$`Y`$の値も大きい）。
故に、$`X`$と$`Y`$の間には正の相関（つまり正の相関関係）が存在する。
