# 1.3.6.6.9. 対数正規分布

#### 確率密度関数
変数 $`X`$ が対数正規分布に従うとは、$`Y = \ln(X)`$ が自然対数を表す「LN」の正規分布に従うことをいう。
対数正規分布の[確率密度関数](eda362.md#確率密度関数)の一般式は次式である。

$$f(x) = \frac{e^{-((\ln((x-\theta)/m))^{2}/(2\sigma^{2}))}}{(x-\theta)\sigma\sqrt{2\pi}} \hspace{.2in} x > \theta; m,\sigma > 0$$   

ここで、$`σ`$は[形状母数](eda363.md)（かつ分布の対数の標準偏差）、$`θ`$ は[位置母数](eda364.md)、$`m`$ は[尺度母数](eda364.md)（かつ分布の中央値）である。
$`x=θ`$ の場合、$`f(x)=0`$ となる。
$`θ=0`$ かつ $`m=1`$ の場合を**標準対数正規分布**と呼ぶ。
$`θ`$ が 0 に等しい場合を 2 母数対数正規分布と呼ぶ。

標準対数正規分布の式は次式である。 
 
$$f(x) = \frac{e^{-((\ln x)^{2}/2\sigma^{2})}}{x\sigma\sqrt{2\pi}} \hspace{.2in} x > 0; \sigma > 0$$   
 
確率関数の一般形は[標準分布を用いて表現](eda364.md#標準形に基づく)できるため、本節の以降のすべての式は、関数の標準形で示す。
 
 対数正規分布は通常、以下の母数で表されることに注意されたい。
 
$$\mu = \log(m)$$  

母数 $`μ`$ は、分布の対数の平均である。
この $`μ`$ による母数化を用いる場合、対数正規分布の確率密度関数は次式となる。 

$$f(x) = \frac{e^{-(\ln(x - \theta) - \mu)^2/(2\sigma^2)}}{(x - \theta)\sigma\sqrt{2\pi}} \hspace{.2in} x > \theta; \sigma > 0$$   

m は明示的な尺度母数であるため、我々は*m*を用いた母数化を好んで用いる。

以下は、$`σ`$ の4つの値に対する対数正規確率密度関数のプロットである。

![plot of the lognormal probability density function for four values of sigma](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/lgnpdf4.gif)
  
対数正規分布にはいくつかの一般的な母数化がある。
ここで示す式は[Evans、Hastings、および Peacock](../section4/eda43.md#Evans)によるものである。 

#### 累積分布関数
対数正規分布の累積分布関数の式は、次式である。   

$$F(x) = \Phi(\frac{\ln(x)} {\sigma}) \hspace{.2in} x \ge 0;\sigma > 0$$   

ここで、$`\Phi`$は[正規分布の累積分布関数](eda3661.md#累積分布関数)である。

以下は、上記の確率密度関数のプロットと同じ $`σ`$ の値を用いた対数正規分布の累積分布関数のプロットである。

![plot of the lognormal cumulative distribution function](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/lgncdf4.gif)  

#### パーセント点関数
対数正規分布の[パーセント点関数](eda362.md#パーセント点関数)の式は次式である。

$$G(p) = \exp(\sigma\Phi^{-1}(p)) \hspace{.2in} 0 \le p < 1;\sigma > 0$$   
 
ここで、$`\Phi^{-1}`$ は[正規分布のパーセント点関数](eda3661.md#パーセント点関数)である。
 
以下は、上記の確率密度関数のプロットと同じ $`σ`$ の値を用いた対数正規分布のパーセント点関数のプロットである。
 
![plot of the lognormal percent point function](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/lgnppf4.gif)  

#### ハザード関数
対数正規分布の[ハザード関数](eda362.md#ハザード関数)の式は、次式である。

$$h(x,\sigma) = \frac{(\frac{1} {x\sigma})\phi(\frac{\ln x} {\sigma})}{\Phi(\frac{-\ln x} {\sigma})} \hspace{.2in} x > 0; \sigma > 0$$   
 
ここで、$`\phi`$ は[正規分布の確率密度関数](eda3661.md#確率密度関数)、$`\Phi`$は[正規分布の累積分布関数](eda3661.md#累積分布関数)である。
 
以下は、上記の確率密度関数のプロットと同じ $`σ`$ の値を用いた対数正規ハザード関数のプロットである。
 
![plot of the lognormal hazard function](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/lgnhaz4.gif)  

#### 累積ハザード関数
対数正規分布の[累積ハザード関数](eda362.md#累積ハザード関数)の式は次式である。

$$H(x) = -\ln(1 - \Phi(\frac{\ln(x)} {\sigma})) \hspace{.2in}x \ge 0; \sigma > 0$$   
 
ここで、$`\Phi`$ は[正規分布の累積分布関数](eda3661.md#累積分布関数)である。
 
以下は、上記の確率密度関数のプロットと同じ $`σ`$ の値を用いた対数正規分布の累積ハザード関数のプロットである。
 
![plot of the lognormal cumulative hazard function ](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/lgncha4.gif)  

#### 生存関数
対数正規分布の[生存関数](eda362.md#生存関数)の式は次式である。

$$S(x) = 1 - \Phi(\frac{\ln(x)} {\sigma}) \hspace{.2in} x \ge 0;\sigma > 0$$   
 
ここで、$`\Phi`$ は[正規分布の累積分布関数](eda3661.md#累積分布関数)である。
 
 
 以下は、上記の確率密度関数のプロットと同じ $`σ`$ の値を用いた対数正規生存関数のプロットである。

#### 逆生存関数
対数正規分布の[逆生存関数](eda362.md#逆生存関数)の式は次式である。

$$Z(p) = \exp(\sigma\Phi^{-1}(1-p)) \hspace{.2in} 0 \le p < 1;\sigma > 0$$   

ここで、$`\Phi^{-1}`$は[正規分布のパーセント点関数](eda3661.md#パーセント点関数)である。

以下は、上記の確率密度関数のプロットと同じ $`σ`$ の値を用いた対数正規分布の逆生存関数のプロットである。

#### 共通統計量
以下の式は、位置母数が 0、尺度母数が 1 である。

平均値　　　　$`e^{0.5\sigma^{2}}`$  
中央値　　　　尺度母数 $`*m*`$（尺度母数が指定されていない場合は 1）  
最頻値　　　　$`\frac{1} {e^{\sigma^{2}}}`$  
範囲　　　　　0 から $`\infty`$  
標準偏差　　　$`\sqrt{e^{\sigma^{2}} (e^{\sigma^{2}} - 1)}`$  
歪度　　　　　$`(e^{\sigma^{2}}+2) \sqrt{e^{\sigma^{2}} - 1} `$  
尖度　　　　　$`(e^{\sigma^{2}})^{4} + 2(e^{\sigma^{2}})^{3} +3(e^{\sigma^{2}})^{2} - 3`$  
変動係数　　　$`\sqrt{e^{\sigma^{2}} - 1}`$  

#### 母数推定
尺度母数 $`m`$ および形状母数 $`σ`$ の最尤推定量は、以下となる。

$$\hat{m} = \exp{\hat{\mu}}$$  

および

$$\hat{\sigma} = \sqrt{\frac{\sum_{i=1}^{N}{(\ln{(X_{i})} -\hat{\mu})^{2}}} {N}}$$  

ここで

$$\hat{\mu}= \frac{\sum_{i=1}^{N}{\ln{X_i}}} {N}$$  

位置母数が既知である場合、形状母数および尺度母数の最尤推定値を計算する前に、元のデータ点からこれを差し引く。

#### 解説
対数正規分布は、[信頼性](../../apr/apr.md)解析において故障時間をモデル化するために広く用いられている。
対数正規分布と [Weibull](eda3668.md) 分布は、信頼性解析において最も一般的に用いられる分布である。

#### ソフトウェア
一般的な統計ソフトウェア・プログラムの多くは、対数正規分布に関する確率関数のうち、いくつかを実装している。
