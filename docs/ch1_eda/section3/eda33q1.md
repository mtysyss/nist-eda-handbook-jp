# 1.3.3.26.1. 散布図：関係性なし

#### 関係性のない散布図
![1.3.3.26.1.Scatter Plot: No Relationship](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/scatplo1.gif)  

#### 議論
上記のプロットで、$`X`$ の値（例えば $`X=0.5`$）に対し、$`Y`$ の対応する値が $`Y=-2`$ から $`Y=+2`$ までの範囲にあることに注目する。
$`X`$ の他の値についても同様である。
$`X`$ の与えられた値から $`Y`$ を決定する際の予測可能性の欠如と、散布図の纏まりがなく構造化されていない外観が、関係がないという結論となる。
