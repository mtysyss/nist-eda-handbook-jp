# 1.3.3.18. 線形傾きプロット

#### 目的：群間の線形傾きにおける変化の検出
線形傾きプロットは、線形近似が群間で一貫しているかを視覚的に評価するために用いる。
つまり、データに群がある場合、単一の近似を全群に適用できるか、それとも各群ごとに個別の近似が必要かを判断したいときがある。 

線形傾きプロットは通常、[線形切片](eda33h.md)および[線形残差標準偏差](eda33j.md)の各プロットと組み合わせて使用する。 

群がない場合もあるかもしれない。
代わりに異なるデータ集合があり、同じ近似が各データ集合に適切に適用できるかを知りたいときがある。
この場合、各データ集合を単純に群と考えし、群に線形傾きプロットを適用する。 

#### プロット例  
![1.3.3.18.Linear Slope Plot](https://www.itl.nist.gov/div898/handbook/eda/gif/linslopl.gif)  
[HSU12.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/HSU12.DAT)のこの線形傾きプロットは、全群において傾きが約0.174（±0.002）であることを示している。
傾きの変動に特定のパターンは観られない。
これは単一近似が適切であることを示唆している。 

#### 定義：群傾斜対群ID
線形勾配プロットは、以下の条件で作成する。  

* 縦軸：線形近似で得られた群ごとの傾き  
* 横軸：群識別子  

基準線は、すべてのデータを使用した線形近似の傾きでプロットする。

#### 論点
線形傾きプロットは、以下の質問に対する答えを与えることができる。  

1. 線形近似において、各群は同じ傾きか。  
2. 傾きが異なる場合、傾きに認識可能なパターンはあるか。  

#### 重要：群の同質性の確認
群化されたデータでは、異なる群が同質（すなわち類似）か異質（すなわち相違）かを知ることが重要なときがある。
直線傾きプロットは、線形近似の文脈においてこの質問に答えるのに役立つ。

#### 事例研究
線形傾きプロットは、[アラスカ・パイプライン](../../pmd/section6/pmd62.htm)データの事例研究で利用されている。

#### ソフトウェア
ほとんどの汎用統計ソフトウェア・プログラムは、線形傾きプロットを実装していない。
しかし、統計プログラムが群の線形近似が可能なら、このプロットを出力するマクロの作成は実現可能であろう。
