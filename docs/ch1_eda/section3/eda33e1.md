# 1.3.3.14.1. ヒストグラムの解釈：正規分布

#### 対称性のある中程度の裾を持つヒストグラム
![](https://www.itl.nist.gov/div898/handbook/eda/gif/histogr1.gif)  

上記は[ZARR13.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/ZARR13.DAT)のヒストグラムである。  
 
古典的な鐘形の対称ヒストグラムであることに注目する。
頻度カウントの大部分が中央に集まり、カウントは裾で消えている。
物理科学/工学の観点から見ると、正規分布とは自然界で最も頻繁に起こる分布（中心極限定理が一因）である。

#### 推奨される次の手順
ヒストグラムが対称的で中程度の裾の分布を示す場合、推奨される次の手順は、どの程度正規性か確認するために[正規確率プロット](eda33l.htm)を作成することである。
正規確率プロットが線形である場合、正規分布はデータの適切なモデルとなる。
