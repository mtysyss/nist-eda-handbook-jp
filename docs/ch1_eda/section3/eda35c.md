# 1.3.5.12. 自己相関

#### 目的：非無作為性の検出、時系列モデル化
自己相関（[Box and Jenkins, 1976](../section4/eda43.md#Box)）関数は、以下の 2 つの目的で用いられる。

1. データに非無作為性があるかを検出する　　
2. データが無作為でない場合に、適切な時系列モデルを特定する  　　

#### 定義
時刻 $`X_1,X_2,...,X_N`$ における観測値 $`Y_1,Y_2,...,Y_N`$ に対し、遅延 *k* の自己相関関数は次式で定義される。  

$$r_{k} = \frac{\sum_{i=1}^{N-k}(Y_{i} - \bar{Y})(Y_{i+k} -\bar{Y})} {\sum_{i=1}^{N}(Y_{i} - \bar{Y})^{2} }$$  

自己相関の式には時間変数 *X* は用いられていないが、観測値が等間隔であることが前提である。  

自己相関は相関係数である。
ただし、異なる二変数間の相関ではなく、時点 $`X_i`$ と $`X_{i+k}`$ における同一変数の 2 つの値の相関を表す。 

自己相関を用いて非無作為性を検出する場合、通常は最初の（ラグ1）自己相関のみが関心対象となる。
自己相関を用いて適切な時系列モデルを特定する場合、通常は多くのラグについて自己相関を[プロット](autocopl.md)する。

#### 論点
自己相関関数は、以下の質問の答えを与える。 　

1. このデータ例は無作為な過程から得られたものか。  
2. 単純な定数＋誤差モデルよりも、非線形や時系列モデルの方が、このデータに対してより適切なモデルか。  

#### 重要
単変量統計的工程が管理下にあるか否かを判断する上での主な[仮定](../section2/eda2.md)の一つが無作為性である。
一定位置と一定尺度、無作為性、固定分布という仮定が妥当であれば、単変量工程は次式にモデル化できる。  

$$Y_{i} = A_0 + E_{i}$$

ここで $`E_i`$ は誤差項である。 
無作為性の仮定が成立しない場合、違うモデルを採用する必要がある。
これは通常、[時系列モデル](../../pmc/section4/pmc4.md)もしくは[非線形モデル](../../ch4_pmd/section1/pmd142.md)（独立変数として時間を用いる）のいずれかとなる。
