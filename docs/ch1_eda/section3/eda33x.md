# 1.3.3.33. 6-プロット

#### 目的：図表現でのモデル検証
6-プロットは、Y対X 近似の妥当性を評価する目的である6つの特定の図表現技法の集まりである。
近似には、線形近似、非線形近似、LOWESS（局所加重最小二乗法）近似、区分多項式近似、または独立変数1つを利用するその他の近似などがある。  

6-プロットは次のとおり。  

1. [応答および予測値対独立変数の散布図](scatterp.md)  
2. [残差対独立変数の散布図](scatterp.md)  
3. [残差対予測値の散布図](scatterp.md)  
4. [残差の遅延プロット](eda33f.md)  
5. [残差のヒストグラム](eda33e.md)  
6. [残差の正規確率プロット](eda33l.md)  

#### プロット例  
![1.3.3.33. 6-Plot](http://www.itl.nist.gov/div898/handbook/eda/gif/6plot.gif)  

[PONTIUS.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/PONTIUS.DAT)のこの6-プロットは、線形近似を示しているが、線形モデルは適切ではない。
これは、二次モデルがより適したモデルであることを示唆している。

#### 定義：6要素のプロット
6-プロットは次プロットで構成される。  

1. 応答値と予測値  
    - 縦軸：応答変数、予測値  
    - 横軸：独立変数  
2. 残差値対独立変数  
    - 縦軸：残差値  
    - 横軸：独立変数  
3. 残差値対予測値  
    - 縦軸：残差値  
    - 横軸：予測値  
4. 残差の遅延プロット  
    - 縦軸：RES(I)  
    - 横軸：RES(I-1)  
5. 残差のヒストグラム  
    - 縦軸：頻度  
    - 横軸：残差値  
6. 残差の正規確率プロット  
    - 縦軸：順序付けられた残差値  
    - 横軸：順序付き残差の正規$`N(0,1)`$分布の理論値  

#### 論点
6-プロットは、以下の質問に対する答えを与える。  

1. 残差は、固定された位置と尺度を持つほぼ正規分布に従うか。  
2. 外れ値はあるか。  
3. 近似は十分か。  
4. 残差はより良い近似を示唆するか。  

#### 重要：モデルの検証
モデルが応答変数と1独立変数を含む場合は次式となる。

$$Y_i=f(X_i)+E_i$$  

ここで、Y は応答変数、X は独立変数、$`f`$ は線形または非線形の近似関数、E は無作為成分である。
良いモデルでは、誤差成分は次の特性を持つべきである。

1. 無作為性（つまり独立）  
2. 固定分布  
3. 固定位置  
4. 固定ばらつき  

さらに、近似モデルでは、固定分布が正規分布であり、固定位置がゼロであると通常仮定される。
良いモデルの固定変動は可能な限り小さい。
近似モデルの重要な要素は、誤差成分の仮定を検証し、ばらつきが十分に小さいかを評価することである。
誤差成分の仮定を検証するために、ヒストグラム、遅延プロット、正規確率プロットが使用される。
応答変数と予測値を独立変数でプロットすると、変動が十分に小さいかを評価できる。
残差を独立変数と予測値でプロットすると、独立性の仮定を評価できる。  

モデル適合の過程において、これらの仮定の妥当性と品質を評価することは非常に重要である。
適切なモデルの妥当性確認手順なしに近似を検討すべきではない。
