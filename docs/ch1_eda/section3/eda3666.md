# 1.3.6.6.6. カイ二乗分布

#### 確率密度関数
カイ二乗分布は、[標準正規](eda3661.md)分布に従う *ν* 個の独立変数を二乗し、それらを合計して得られる。
カイ二乗分布の[確率密度関数](eda362.md#確率密度関数)は次式である。  

$$f(x) = \frac{e^{\frac{-x} {2}}x^{\frac{\nu} {2} - 1}}{2^{\frac{\nu} {2}}\Gamma(\frac{\nu} {2}) } \qquad \mbox{ただし} \; x \ge 0$$  

ここで *ν* は形状母数、Γはガンマ関数である。
ガンマ関数の式は以下である。 

$$\Gamma(a) = \int\_{0}^{\infty} {t^{a-1}e^{-t}dt}$$  

検定において、カイ二乗分布は「標準化された分布」（すなわち、位置母数や尺度母数を持たない）として扱われる。
しかし、分布のモデル化検討（他の確率分布と同様に）では、カイ二乗分布自体を[位置母数](eda364.md) *μ* と[尺度母数](eda364.md) *σ* を用いて変換することが可能である。

#### 累積分布関数
カイ二乗分布の[累積分布関数](eda362.md#累積分布関数)は次式である。   

$$F(x) = \frac{\gamma(\frac{\nu} {2},\frac{x} {2})}{\Gamma(\frac{\nu} {2})} \qquad  \mbox{ただし} \; x \ge 0$$  

ここでΓは上記で定義したガンマ関数、*γ* は不完全ガンマ関数である。
不完全ガンマ関数の公式は次式である。   

$$\Gamma\_{x}(a) = \int_{0}^{x} {t^{a-1}e^{-t}dt}$$

#### その他の確率関数
カイ二乗分布は仮説検定や信頼区間の構築に用いられることが多く、モデル化用途では稀であるため、ハザード関数、累積ハザード関数、生存関数、逆生存確率関数に関する公式や図表は省略する。

#### 共通統計量 　
平均値　　　　$`ν`$  
中央値　　　　$`ν`$ が大きい場合、おおよそ $`ν- 2/3`$  
最頻値　　　　$`\nu - 2 \qquad  \mbox{ただし} \quad \nu > 2`$  
範囲　　　　　0から$`\infty`$  
標準偏差　　　$`\sqrt{2\nu}`$  
変動母数　　　$`\sqrt{\frac{2} {\nu}}`$  
歪度　　　　　$`\frac{2^{1.5} } {\sqrt{\nu}}`$  
尖度　　　　　$`3 + \frac{12} {\nu}`$  

#### 母数推定
カイ二乗分布は通常、仮説検定や信頼区間の構築に用いられ、モデル化用途にはほとんど使用されないため、母数推定に関する議論は省略する。

#### 解説  
カイ二乗分布は、仮説検定における棄却領域の決定や信頼区間の設定に広く用いられる。
代表的な例として、**R×C** の連関表における[独立性のカイ二乗検定](../prc/section4/prc45.md)と、母集団の標準偏差が事前指定値と等しいかを判定する[カイ二乗検定](eda358.md)が挙げられる。

#### ソフトウェア
ほとんどの汎用統計ソフトウェアは、カイ二乗分布の確率関数の少なくとも一部を実装している。
