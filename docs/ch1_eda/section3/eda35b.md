# 1.3.5.11. 歪度と尖度の指標

#### 歪度と尖度
多くの統計分析における基本的な作業は、データ集合の[位置](eda351.md)と[ばらつき](eda356.md)特徴づけることである。
データのさらなる特徴付けには、歪度と尖度が含まれる。  

歪度は対称性の指標、より正確には非対称性の指標である。
分布またはデータ集合は、中心点から左右対称に見える場合に「対称」である。  

尖度は、データが正規分布と比較して裾が重い分布か裾が軽い分布かを測る指標である。
つまり、尖度が高いデータ集合は裾が重い（外れ値が多い）傾向があり、尖度が低いデータ集合は裾が軽い（外れ値が少ない）傾向がある。
一様分布はその極端な例である。  

[ヒストグラム](eda33e.md)は、データ集合の歪度と尖度をともに示す効果的な図表現技法である。 

#### 歪度の定義
単変量データ $`Y_1, Y_2, ..,Y_N`$ に対する歪度の計算式は次の通り。  

$$g_{1} = \frac{\sum_{i=1}^{N}(Y_{i} - \bar{Y})^{3}/N} {s^{3}}$$  

ここで $`\bar{Y}`$ は平均、*s* は標準偏差、*N* はデータ点数である。
注意：歪度を計算する際、*s* は分母に *N* を用いて計算され、$`N-1`$ ではない。  
 
上記の歪度計算式は Fisher-Pearson 歪度係数と呼ばれる。
多くのソフトウェア・プログラムでは実際には調整済み Fisher-Pearson 歪度係数が計算される。 

$$G_{1} = \frac{\sqrt{N(N-1)}}{N-2} \frac{\sum_{i=1}^{N}(Y_{i} - \bar{Y})^{3}/N} {s^{3}}$$

これは標本規模に対する補正である。
補正係数は *N* が大きくなるにつれて1に近づく。
参考までに、補正係数は $`N=5`$ で 1.49、$`N=10`$ で 1.19、$`N=20`$ で 1.08、$`N=30`$ で 1.05、$`N=100`$ で 1.02 となる。  

[正規分布](eda3661.md)の歪度はゼロであり、対称的なデータでは歪度はゼロに近い値となる。
歪度の負の値は左に偏ったデータを示し、正の値は右に偏ったデータを示す。
左に偏るとは、右裾に比べて左裾が長いことを意味する。
同様に、右に偏るとは、左裾に比べて右裾が長いことを意味する。
データが多峰性を持つ場合、これは歪度の符号に影響を与える可能性がある。  

一部の測定値には下限値が存在し、右偏りを示す。
例えば信頼性研究では、故障時間は負の値を取ることができない。  

文献には歪度の代替定義があることに留意すべきである。
例えば、Galton 歪度（ Bowley の歪度とも呼ばれる）は以下のように定義される。

$$\mbox{Galton 歪度} =\frac{Q_{1} + Q_{3} -2 Q_{2}}{Q_{3} - Q_{1}}$$  
ここで $`Q_1`$ は下四分位数、$`Q_3`$は上四分位数、$`Q_2`$ は中央値である。 

ピアソン2の歪度係数は次のように定義される

$$S_{k_2} = 3 \frac{(\bar{Y} - \tilde{Y})}{s}$$
ここで  $` \tilde{Y} `$  は標本中央値である。 

歪度には他にも多くの定義があるが、ここでは扱わない。 

#### 尖度の定義
単変量データ $`Y_1,Y_2,...,Y_N`$ に対する尖度の式は次の通り。  

$$\mbox{尖度} = \frac{\sum_{i=1}^{N}(Y_{i} - \bar{Y})^{4}/N}{s^{4}}$$  
ここで $`\bar{Y}`$  は平均、*s* は標準偏差、*N* はデータ点数である。
注意：尖度を計算する際、分母では標準偏差を $`N-1`$ ではなく *N* で割る。

#### 尖度の代替定義
[標準正規分布](eda3661.md)の尖度は3である。
このため、一部の文献では以下の尖度の定義（しばしば「過剰尖度」と呼ばれる）を用いる。 

$$\mbox{尖度} = \frac{\sum_{i=1}^{N}(Y_{i} - \bar{Y})^{4}/N}{s^{4}} - 3$$  

この定義を用いることで、標準正規分布の尖度はゼロとなる。
さらに、第二の定義では、正の尖度は「裾が重い分布」を示し、負の尖度は「裾が軽い分布」を示す。  

尖度の定義の選択は慣習による（本ハンドブックでは元の定義を使用）。
ソフトウェアで標本尖度を計算する際は、どの慣習に従っているか注意が必要である。
多くの文献では「過剰尖度」を計算しながら「尖度」という用語を使用するため、必ずしも明確ではない場合がある。 

#### 例
以下の例は、正規分布、二重指数分布、Cauchy 分布、および Weibull 分布に従う 10,000個の乱数のヒストグラムを示している。 　

![1.3.5.11.Measures of Skewness and Kurtosis](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/skewness.gif)  

#### 正規分布
最初のヒストグラムは[正規分布](eda3661.md)の例である。
正規分布は対称分布であり、裾部が良好な振る舞いを見せる。
これは歪度が 0.03 であることから示される。
尖度は 2.96 であり、期待値 3 に近い。
ヒストグラムでは対称性を確認できる。

#### 二重指数分布
2番目のヒストグラムは[二重指数分布](eda366c.md)の例である。
二重指数分布は対称分布である。
正規分布と比較すると、より強いピーク、より急峻な減衰、より重い裾部を持つ。
すなわち、歪度はほぼゼロ、尖度は 3 より大きいと予想される。
歪度は 0.06、尖度は 5.9 である。

#### Cauchy 分布
3番目のヒストグラムは [Cauchy 分布](eda3663.md)の例である。 

他のデータ集合との視覚比較を容易にするため、Cauchy 分布のヒストグラムは -10 から 10 の値に制限した。
実際の Cauchy データの全データ集合では、最小値は約 -29,000、最大値は約 89,000 である。 

Cauchy 分布は対称分布であり、分布の中心に単一のピークを持ち、重い裾を持つ。
対称であるため、歪度はほぼゼロであると予想する。
重い裾を持つ性質から、尖度は正規分布よりも大きいと予想される。
実際、歪度は 69.99、尖度は 6,693 である。
これらの極端に高い値は重い裾によって説明できる。
平均や標準偏差が裾部の極端な値によって歪められるのと同様に、歪度や尖度といった指標も歪められる。 

#### Weibull 分布
4番目のヒストグラムは、形状係数 1.5 の [Weibull 分布](eda3668.md)の例である。
Weibull 分布は歪んだ分布であり、歪みの程度は形状係数の値に依存する。
中心から離れるにつれて減少する度合いも、形状係数の値に依存する。
このデータ集合では、歪度は 1.08、尖度は 4.46 であり、中程度の歪度と尖度を示している。

#### 歪度と尖度の取扱い
多くの古典的な統計検定や信頼区間は正規性の仮定に依存している。
顕著な歪度や尖度はデータが正規分布していないことを明確に示す。
ヒストグラムや数値的指標によって示されるように、データ集合に顕著な歪度や尖度が認められる場合、どのような対応が可能か。   

一つの方法は、データを変換して正規分布に近づけることである。
[Box-Cox変換](eda336.md)はデータ正規化に有用な手法である。
特に、中程度の右側歪みを持つデータでは対数変換や平方根変換が効果的である。 

別の手法は、正規分布以外の分布に基づく手法を用いることである。
例えば信頼性研究では、正規分布ではなく指数分布、Weibull 分布、対数正規分布がモデル化の基礎として一般的に用いられる。
[確率プロット相関係数プロット](eda33n.md)と[確率プロット](eda33m.md)は、データに適した分布モデルを決定する有用なツールである。 

#### ソフトウェア
歪度係数と尖度係数は、ほとんどの汎用統計ソフトウェア・プログラムで利用可能である。
