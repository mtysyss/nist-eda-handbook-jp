# 1.3.3.15.1. 遅延プロット：無作為データ

#### 遅延プロット
![1.3.3.15.1.Lag Plot: Random Data](https://www.itl.nist.gov/div898/handbook/eda/gif/lagplot1.gif)  

#### 結論
上記の[200個の正規乱数](https://www.itl.nist.gov/div898/handbook/datasets/NORMAL2.DAT)プロットに基づくと、以下の結論を導くことができる。  

1. データは無作為である。  
2. データに自己相関は見られない。  
3. データに外れ値はない。  

#### 議論
上記の遅延プロットはラグ = 1 の場合を示している。
構造が観られない点に注意されたい。
現在の値 $`Y_{i-1}`$ から次の値 $`Y_i`$ を推測することは不可能である。
したがって横軸上の既知値 $`Y_{i-1}`$ （例えば $`Y_{i-1}=+0.5`$ ）に対して、$`Y_i`$ 番目の値は事実上あらゆる値（$`Y_i=-2.5`$ から $`Y_i=+1.5`$ まで）となり得る。
このような非関連性が無作為性の本質である。
