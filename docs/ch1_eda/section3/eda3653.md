# 1.3.6.5.3. 最小二乗法

#### 最小二乗法
[非線形最小二乗法](../../ch4_pmd/section1/pmd142.md)は、最尤法に代わる手法である。

#### 利点
この手法の利点は以下の通り。  

* 最大尤度推定を実装していない多くの統計ソフトウェア・パッケージでも、非線形最小二乗法用のソフトウェアが利用可能である場合がある。
* 最大尤度法よりも広く適用できる。
つまり、使用しているソフトウェアが非線形近似機能を備え、対象とする確率関数を指定できる場合、その分布に対する最小二乗推定値を算出できる。
これにより、ソフトウェアが最大尤度推定値を提供していなくても、分布に対する妥当な推定値を得ることが可能になる。

#### 欠点
この手法の欠点は以下の通り。  

* 打ち切りデータには容易に適用できない。
* 一般に、最尤法に比べて最適性の特性が劣ると考えられている。
* 初期値の選択にかなり敏感である。

#### ソフトウェア
非線形最小二乗法による近似は、多くの汎用統計ソフトウェアで利用可能である。
