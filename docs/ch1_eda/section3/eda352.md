# 1.3.5.2. 平均値の信頼区間

#### 目的：平均値の区間推定
平均の信頼区間（[Snedecor andCochran, 1989](../section4/eda43.md#Snedecor)）は平均の区間推定値である。
平均の推定値は標本ごとに変動するため、区間推定が望まれることが多い。
平均の単一推定値ではなく、信頼区間は平均の下限と上限を与える。 
この区間推定は、真の平均値に対する推定値の不確かさの大きさを示す。
区間が狭いほど、推定値の精度が高い。   

信頼区間は信頼係数を用いて表現される。
信頼係数の選択はある程度任意であるが、実際には90％、95％、99％の区間がよく用いられ、中でも95％が最も一般的である。  

技術的な注記として、95%信頼区間が真の平均を含む確率が95%であることを意味する**わけではない**。
特定の標本から計算された区間は、真の平均を含むか含まないかのいずれかである。
むしろ、信頼水準は区間の計算方法に関連している。
信頼係数とは、単に真の平均を含むと予想される特定規模の標本の割合である。
つまり、95%信頼区間の場合、多くの標本を収集すれば、その区間が真の平均を含む可能性が高い。 
信頼係数とは、単に、ある規模の標本が真の平均値を含むと期待される割合である。
つまり、95%信頼区間の場合、多くの標本を収集し信頼区間を計算すると、長期的にはこれらの区間の約95%が真の平均値を含むこととなる。 

#### 定義：信頼区間
信頼区間は次のように定義する。  

$$\bar{Y} \pm t_{1 - \alpha/2, \, N-1} \,\, \frac{s}{\sqrt{N}}$$  

ここで$`\bar{Y}`$は標本平均、$`s`$は標本標準偏差、$`N`$は標本規模、$`α`$は望ましい有意水準、$`t_{1-\alpha/2,N-1}`$は自由度 $`N-1`$ の[t分布](eda3664.md)の $`100(1-α/2)`$ 分位数である。 
信頼係数は $`1-α`$であることに注意する。   

この式から、区間の幅は次のふたつの因子によって制御されることが明らかである。  

1. $`N`$が増加すると、$`\sqrt{N}`$項により区間幅は狭くなる。  
    つまり、平均値のより精密な推定を得る一つの方法は標本規模を増加させることである。  
2. 標本標準偏差が大きいほど、信頼区間は広くなる。
これは単に、ノイズの多いデータ（例えば、標準偏差が大きいデータ）は、標準偏差が小さいデータよりも広い区間を与えることを意味する。 

#### 定義：仮説検定
母平均が特定の値 $`\mu_0`$ を持つかを両側対立仮説としてその値を持たないことに対して検定するために、信頼区間は仮説検定の形式に変換する。
この検定は一標本*t*-検定であり、次のように定義する。 
 
$`H_0:`$  $`\mu=\mu_0`$  
$`H_a:`$  $`\mu \neq \mu_0`$  
検定統計量:  $`T=(\bar{Y}-\mu_0)/(s/\sqrt{N})`$  
	ここで$`\bar{Y}`$,$`N`$, および$`s`$は上記で定義される。  
有意水準:  $`α`$。$`α`$の最も一般的な値は0.05である。  
棄却域:  平均が指定値$`\mu_0`$であるという帰無仮説を棄却する。 
$`T<t_{\alpha/2,N-1}`$
または
$`T>t_{1-\alpha/2,N-1}`$  

#### 信頼区間の例
以下の情報に基づき、[ZARR13.DAT](../section4/eda4281.md)データの95％両側信頼区間を出力した。 

N数　　　　　　　　　= 195  
平均値　　　　　　　　=   9.261460  
標準偏差　　　　　　　=   0.022789  
$`t_{1-0.025,N-1}`$　　=   1.9723  

下側限界 $`= 9.261460 - 1.9723*0.022789/\sqrt{195}`$  
上側限界 $`= 9.261460 + 1.9723*0.022789/\sqrt{195}`$  

したがって、平均値の95%信頼区間は (9.258242, 9.264679) となる。 

#### t-検定の例
[ZARR13.DAT](https://www.itl.nist.gov/div898/handbook/eda/section4/eda4281.md)データを用いて両側一標本t-検定を実施し、母平均が5に等しいという帰無仮説を検定した。  

$`H_0　　μ = 5`$  
$`H_a　　μ ≠ 5`$  

検定統計量:　$`T=2611.284`$  
自由度:　　　$`ν=194`$  
有意水準:　　$`α=0.05`$  
棄却値:　　　$`t_{1-α/2,ν}=1.9723`$  
棄却域:　　　$`H_0`$の棄却　$`|T|>1.9723`$  


検定統計量の絶対値が棄却値を上回ったため、両側*t*-検定における帰無仮説を棄却する。
仮に上側の片側検定を実施した場合、棄却値は$`t_{1-α,ν}=1.6527`$となり、同様に帰無仮説を棄却する結果となる。  

信頼区間は仮説検定の代替手段を提供する。
信頼区間が5を含む場合、$`H_0`$は棄却できない。
本例では信頼区間(9.258242, 9.264679)は5を含まないため、有意水準0.05において母平均が5に等しくないことを示す。 

一般に、一標本*t*-検定には3つの対立仮説と棄却領域がある。  

| 対立仮説 | 帰無仮説 |  
|:--- |:--- |  
| $`H_a:μ≠μ_0`$ | $`\|T\|>t_{1-α/2,ν}`$ |  
| $`H_a:μ>μ_0`$ | $`T>t_{1-α,ν}`$ |  
| $`H_a:μ<μ_0`$ | $`T<t_{α,ν}`$ |

#### 論点
平均値の信頼区間は以下の質問の答えを与える。  

1. 平均値の妥当な推定値は。  
2. 平均値の推定値にはどの程度のばらつきがあるか。  
3. 与えられた目標値は信頼区間に収まるか。
