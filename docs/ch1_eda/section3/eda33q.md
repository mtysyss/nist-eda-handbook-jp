# 1.3.3.26. 散布図

#### 目的：関係性の確認
散布図（[Chambers 1983](../section4/eda43.md#Chambers)）は、2変数間の関係や関連性を明らかにする。
このような関係はプロットの非無作為な構造に現れる。
一般的なパターンの様々な[例](eda33q.md#例)を示している。 

#### プロット例：変数 $`Y`$ と $`X`$ 
![.3.3.26.Scatter Plot](https://www.itl.nist.gov/div898/handbook/eda/gif/scatterp.gif)  

この[アラスカ・パイプライン・データ](https://www.itl.nist.gov/div898/handbook/datasets/BERGER1.DAT)のプロット例は、2変数間に線形関係が存在することを示しており、[線形回帰モデル](../../ch4_pmd/section1/pmd141.md)が適切であること示唆している。 

#### 定義：$`Y`$ 対 $`X`$
散布図とは、$`Y`$ の値と対応する$`X`$ の値を打点したものである。  

* 縦軸：変数 $`Y`$ 通常、応答変数  
* 横軸：変数 $`X`$ 通常、応答変数と関連があると推測される変数  

#### 論点
散布図は、以下の質問に対する答えを与えることができる。

1. 変数 $`X`$ と $`Y`$ は関連しているか。  
2. 変数 $`X`$ と $`Y`$ は線形に関連しているか。  
3. 変数 $`X`$ と $`Y`$ は非線形に関連しているか。  
4. $`Y`$ の変化は $`X`$ に依存しているか。  
5. 外れ値はあるか。

#### 散布図の組合せ
1ページに複数の散布図を組み合わせることもでき、2つ以上の変数を持つデータ集合における上位の構造を理解するのに役立つ。  

[散布図行列](eda33qb.md)は全ての組合せの散布図を単一ページに作成する。
[条件付きプロット](eda33qc.md)（コプロットや部分集合プロットとも呼ばれる）は、第三変数の値に依存した $`Y`$ 対 $`X`$ の散布図を作成する。 

#### 相関関係から因果関係は証明されない
散布図はデータ内の関係を明らかにする。
「関係性」とは $`X`$ と $`Y`$ の間に何らかの構造的関連性（線形、二次など）が存在することを意味する。
ただし、因果関係が示唆される場合でも  

 因果関係は相関を意味するが   

 相関が因果関係を意味するわけではない。  
  
散布図は関連性を判断するための有用な診断ツールであるが、関連性が存在する場合にプロットが根本的な因果関係メカニズムを示唆しているかもしれないし、示唆しないかもしれない。
散布図では因果関係を「証明」することは決してできず、最終的には、研究者（基礎となる科学・工学に根拠）だけが因果関係が実際に存在すると結論付けることができる。

#### 外観
散布図の最も一般的な表現は  

1. データ点にプロット記号（例：X）を配置し、  
2. データ点を線で結ば**ない**。  

その他の散布図形式の派生には以下が含まれる。  
 
 1. データ点に任意のプロット記号（例：X）を表示し  
 2. データ点を実線で結ぶ。   

いずれの場合も結果のプロットは散布図と呼ばれるが、前者（離散的で接続されていない）はデータ以外に解釈を歪める補間による人工物を画面に表示しないのは、著者の個人的な好みである。
