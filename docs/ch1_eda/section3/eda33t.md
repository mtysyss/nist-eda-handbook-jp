# 1.3.3.29. 星図

#### 目的：多変量データの表示
星図([Chambers 1983](../section4/eda43.md#Chambers))は多変量データを表示する手法である。
各星は単一の観測値を表す。
通常、星図は、各ページに多数の星を表示するマルチ・プロット形式で作成され、各星が1つの観測値を表す。  

星図は、単一データ点の相対値を（例：点3は変数2と4では大きく、変数1、3、5、6では小さい）評価し、類似点や相違点を特定するために用いられる。 

#### プロット例  
下のプロットには[16車種](https://www.itl.nist.gov/div898/handbook/datasets/AUTO79.DAT)の星図を示している。
実際のデータ・ファイルには74台の車が含まれているが、1ページに合理的に表示できる範囲にプロットを制限している。
サンプルの星図の変数一覧は次のとおり。

1. 価格  
2. 走行距離（MPG）  
3. 1978年修理記録（1 = 最悪、5 = 最良）  
4. 1977年修理記録（1 = 最悪、5 = 最良）  
5. 頭上空間  
6. 後部座席空間  
7. トランク容量  
8. 重量  
9. 全長[1]  

![1.3.3.29.Star Plot](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/starplot.gif)  

これらのプロットを個別に確認することもできるし、類似した特徴を持つ車の分類を特定するために使用することもできる。
例えば、キャデラック・セビルの星図を見ると、最も高価な車の一つであり、燃費は平均以下（ただし最下位ではない）、修理記録は平均的、室内空間とサイズは平均からやや上であることがわかる。 
次にキャデラック・モデル（最後の3プロット）とAMCモデル（最初の3プロット）を比較することもできる。
この比較では明確なパターンが浮かび上がる。 
AMCモデルは低価格傾向にあり、燃費は平均以下、高さ・重量・室内空間のいずれも小型である。
一方キャデラック・モデルは高価で燃費は悪く、サイズと室内空間のいずれも大型である。 

#### 定義
星図は、複数の等角の放射状線（半径と呼ばれる）で構成され、各線は変数の1つを表す。
各線のデータ長は、全データ点における変数の最大値に対する、その変数データの大きさに比例している。 
各放射線のデータ値を結ぶ線を描く。
これによりプロットは星のような外観となり、このプロット名の由来となっている。

#### 論点
星図は、以下の質問の答えを与える。  

1. 特定の観測において支配的な変数は何か。  
2. どの観測値が最も類似しているか、すなわち観測値の集団は存在するか。  
3. 外れ値はあるか。  

#### 技術的な弱点
星図は小規模から中規模の多変量データ集合に有用である。
その主な欠点は、数百点未満のデータ集合にのみに有効であることである。
それ以上の規模では、情報量が多過ぎる。  

大規模データ集合に適した図表現技法に関しては、[Scott](../section4/eda43.md#SCOTT)で議論されている。 

#### 関連技法
多変量データをプロットする代替手法は、[Chambers](../section4/eda43.md#Chambers),[du Toit](../section4/eda43.md#du Toit), および[Everitt](../section4/eda43.md#Everitt) で議論されている。

#### ソフトウェア
一部の汎用統計ソフトウェア・プログラムでは、散布図が利用可能である。
