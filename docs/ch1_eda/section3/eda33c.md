# 1.3.3.12. DOE平均プロット

#### 目的：位置に関する重要な因子の検出
DOE平均プロットは、重要な因子について、各因子が2つ以上の水準を持つ実験計画のデータを分析するのに適している。
このプロットは、各因子の2つ以上の水準における平均値を因子ごとにプロットする。
単一因子の平均値が直線で結ばれる。  

DOE平均プロットは、実験計画おける従来の[分散分析](../../ppc/section2/ppc23.md)を補完するものである。 
このプロットは通常、平均値に対して作成する。ただし、中央値などの他の位置統計量に対しても作成しても良い。 

#### プロット例  因子4、2、1が最も重要な因子
![1.3.3.12.DOE Mean Plot](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/eda_dexboxbike_r02.gif)    
この[BOXBIKE2.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/BOXBIKE2.DAT)のDOE平均プロットのサンプルは、以下のことを示している。 

1. 因子4が最も重要である。  
2. 因子2が2番目に重要である。  
3. 因子1が3番目に重要である。  
4. 因子7が4番目に重要である。  
5. 因子6が5番目に重要である。  
6. 因子3と5は比較的重要度が低い。

要約すると、因子4、2、1は明らかに重要であり、因子3と5は明らかに重要性が低く、因子6と7は境界領域の因子であり、今後のモデルへの組み込みはさらなる分析によって決定される。 

#### 定義：平均応答値と因子変数の関係
DOE平均プロットは、以下の条件で作成する。  

* 縦軸：因子変数の各水準における応答変数の平均値  
* 横軸：因子変数  

#### 論点
DOE平均プロットは、以下の質問に対する答えを与えることができる。  

1. どの因子が重要か。
DOE平均プロットは、この質問に対する決定的な答えを与えないが、因子を「明らかに重要」「明らかに重要でない」「重要性の境界線上」に分類するのに役立つ。  
2. 重要な因子の順位はどうか。

#### 重要：重要な因子の特定
多くの実験計画の目的は、どの因子が有意であるかを特定することである。
また、重要な因子の順位付けリストもしばしば関心を集める。
DOE平均プロットはこうした質問に答えるのに理想的に適しており、実験計画の分析において日常的に使用することが推奨される。

#### 交互作用効果の拡張
[散布図行列](eda33qb.md)の概念を用いることで、DOE散布図は一次交互作用効果を表示するように拡張できる。   

具体的には、$`k`$ 個の因子がある場合、$`k`$ 行 $`k`$ 列のプロット行列を作成する。
対角線上のプロットは単一因子の DOE平均プロットそのものである。
対角外プロットでは、交互作用の各水準の測定値が水準に対してプロットされ、水準は $`X_i`$ 掛ける $`X_j`$ と $`X_i`$ は $`i`$ 番目の主効果水準の符号、$`X_j`$ は $`j`$ 番目の主効果の符号である。
一般的な2水準計画（例えば、各因子が2水準を持つ）では、値は通常-1と1で符号化されるため、乗算後の値も-1と1となる。
次に、この交互作用変数に対してDOE平均プロットを作成する。
この図はDOE交互作用効果図と呼ばれ、その例を以下に示す。

#### ソフトウェア
DOE平均プロットは、いくつかの汎用統計ソフトウェア・プログラムで利用可能であるが、プログラムにより形式が多少異なる場合がある。
このプロットを直接的に実装されていない統計ソフトウェアでも、DOE平均プロット用のマクロを作成することが可能な場合がある。
