# 1.3.6.6.7. 指数分布

#### 確率密度関数
指数分布の[確率密度関数](eda362.md#確率密度関数)の一般式は次式である。   

$$f(x) = \frac{1} {\beta} e^{-(x - \mu)/\beta} \hspace{.3in}x \ge \mu; \beta > 0$$   

ここで、$`μ`$ は[位置母数](eda364.md)、$`β`$ は[尺度母数](eda364.md)である（尺度母数はしばしば $`λ`$と呼ばれ、$`1/β`$ に等しい）。
$`μ=0`$、$`β=1`$ の場合を**標準指数分布**と呼ぶ。
標準指数分布は次式である。  

$$f(x) = e^{-x} \qquad  \mbox{ただし } x \ge 0$$   

確率関数の一般形は[標準分布を用いて表現](eda364.md#標準形に基づく位置と尺度の式)できる。
本節以降の公式は、1母数（すなわち尺度母数を持つ）形の関数について与えられる。

#### 累積分布関数
指数分布の[累積分布関数](eda362.md#累積分布関数)は次式である。  

$$F(x) = 1 - e^{-x/\beta} \hspace{.3in} x \ge 0; \beta > 0$$   

以下は、指数累積分布関数のグラフである。  

![plot of the exponential cumulative distribution](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/expcdf.gif)   

#### パーセント点関数
指数分布の[パーセント点関数](eda362.md#パーセント点関数)は次式である。  

$$G(p) = -\beta\ln(1 - p) \hspace{.3in} 0 \le p < 1; \beta > 0$$   

以下は、指数パーセント点関数のグラフである。  

![plot of the exponential percent point function](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/expppf.gif)  

#### ハザード関数
指数分布の[ハザード関数](eda362.md#ハザード関数)は次式である。  

$$h(x) = \frac{1} {\beta} \hspace{.3in} x \ge 0; \beta > 0$$   

以下は、指数ハザード関数のグラフである。  

![plot of the exponential hazard function](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/exphaz.gif)  

#### 累積ハザード関数
指数分布の[累積ハザード関数](eda362.md#累積ハザード関数)は次式である。  

$$H(x) = \frac{x} {\beta} \hspace{.3in} x \ge 0; \beta > 0$$   

以下は、指数累積ハザード関数のグラフである。  

![plot of the exponential cumulative hazard function](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/expcha.gif)  

#### 生存関数
指数分布の[生存関数](eda362.md#生存関数)は次式である。  

$$S(x) = e^{-x/\beta} \hspace{.3in} x \ge 0; \beta > 0$$   

以下は指数生存関数のグラフである。

#### 逆生存関数
指数分布の[逆生存関数](eda362.md#逆生存関数)は次式である。  

$$Z(p) = -\beta\ln(p) \hspace{.3in} 0 \le p < 1; \beta > 0$$

#### 共通統計量 　
平均値　　　　$`\mu + \beta`$  
中央値　　　　$`\mu + \beta\ln{2}`$  
最頻値　　　　$`μ`$  
範囲　　　　　$`μ*から $`\infty`$  
標準偏差　　　$`β`$  
変動係数　　　1  
歪度　　　　　2  
尖度　　　　　9  

#### 母数推定
全数標本の場合、尺度母数の最尤推定量は標本平均である。
[指数分布に対する最尤推定法](../../apr/section4/apr412.md)は信頼性に関する章（第8章）で論じられている。
また、[Johnson, Kotz, Balakrishnan](../section4/eda43.md#Johnson)著の第19章でも論じられている。

#### 解説  
指数分布は主に[信頼性](../../apr/apr.md)分野で用いられる。
指数分布は、一定の故障率を持つデータをモデル化するために用いられる（これはハザード・プロットが単に一定値に等しいことで示される）。

#### ソフトウェア
ほとんどの汎用統計ソフトウェアは、指数分布の確率関数の少なくとも一部を実装している。
