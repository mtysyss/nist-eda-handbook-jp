# 1.3.3.1. 自己相関プロット

#### 目的：無作為性の確認
自己相関プロット（[Box and Jenkins, pp. 28-32](../section4/eda43.md#Box)）は、データ集合の無作為性を確認するために一般的に使用されるツールである。
この無作為性は、さまざまな時間の遅れ（タイム・ラグ）に関するデータ値の自己相関を計算することで確認される。
無作為であるとき、このような自己相関はあらゆるタイム・ラグ間隔においてゼロに近い値となる。
無作為でない場合は、1つ以上の自己相関が明らかにゼロ以外の値となる。  

さらに、自己相関プロットは、[Box-Jenkins](../../pmc/section4/pmc4.md) 自己回帰、移動平均時系列モデルのモデル識別段階でも使用される。 

#### 自己相関は無作為性の指標の一つに過ぎない  
相関がないことは必ずしも無作為であることを意味しないことに注意する。
有意な自己相関を持つデータは無作為ではない。
しかし、有意な自己相関を示さないデータでも、他の方法で非無作為性を示す可能性がある。
自己相関は単なる無作為性の尺度の一つに過ぎない。
モデルの妥当性確認の文脈（本ハンドブックで主に扱う無作為性の主要な形態）においては、自己相関の有無を確認することは通常、無作為性の十分な検定となる。
なぜなら、適合度の低いモデルの残差は、明白な無作為性を示す傾向があるからである。
しかし、一部の応用分野ではより厳密な無作為性の判定が必要となる。
こうした事例では、データが様々な形で、しばしば微妙な方法で非無作為性を示す可能性があるため、自己相関のチェックを含む一連の検定が適用される。
より厳密な無作為性検定が必要な例としては、乱数生成器の検定が挙げられる。 

#### サンプル・プロット：無作為である場合、自己相関はほぼゼロであるべき。この例ではそうではないため、無作為性の仮定は成立しない  
![autocorrelation plot](https://www.itl.nist.gov/div898/handbook/eda/gif/autocop0.gif)  
 [FLICKER.DATデータ](https://www.itl.nist.gov/div898/handbook/datasets/FLICKER.DAT) の自己相関プロットのこのサンプルは、時系列が無作為ではなく、隣接および近接観測値間に高い自己相関を有していることを示している。 

#### 定義：$`r(h)`$ 対 $`h`$  
自己相関プロットは以下によって作成する

* 縦軸：自己相関係数  
	<br>$$R_h = C_h/C_0$$<br>  
	ここで $`C_h`$ は自己共分散関数である。  
	<br>$$C_h = \frac{1}{N}\sum_{t=1} ^{N-h}(Y_t - \bar{Y})(Y_{t+h} - \bar{Y})$$<br>  
	また $`C_0`$ は分散関数である  
	<br>$$C_0 = \frac{\sum_{t=1} ^{N}(Y_t - \bar{Y})^2}{N}$$<br>  
	**$`R_h`$** は-1から+1の間にあることに注意する。  
	なお、一部の文献では自己共分散関数として以下の式を用いる場合がある。  
	<br>$$C_h = \frac{1}{N-h}\sum_{t=1}^{N-h}(Y_t - \bar{Y})(Y_{t+h} - \bar{Y})$$<br>  
	この定義は偏差が少ないが、$`$(1/N)`$ 式は望ましい統計的性質を持ち、統計学文献で最も一般的に使用される形式である。詳細は[Chatfieldの20ページおよび49-50ページ](../section4/eda43.md#Chatfield)を参照のこと。 

* 横軸：時間遅れ $`h`$ $` (h = 1, 2, 3, ...)`$   

* 上記線には複数の水平基準線も含まれる。
    中央線はゼロ位置である。
    他の4本は95%および99%信頼区間線である。
    信頼区間線の作成には2種類の異なる式が用いられる点に留意されたい。  
    1. 自己相関プロットを無作為性（すなわちデータに時間依存性がない）の検定に使用する場合、以下の式が推奨される。  
    <br>$$\pm \frac{z_{1-\alpha/2}}{\sqrt{N}}$$<br>  
    ここで $`N`$ は標本規模、 $`z`$ は標準正規分布の累積分布関数、 $`\alpha`$ は有意水準である。
    この場合、信頼区間は標本規模に依存する固定幅を持つ。
    上記プロットの信頼区間作成に用いられた式がこれである。  	     
    2. 自己相関プロットは[ARIMAモデル](../../pmc/section4/pmc446.md)適合のためのモデル同定段階でも使用される。
    このとき、データに対して移動平均モデルが仮定され、以下の信頼区間とすべきである。  
    <br>$$\pm z_{1-\alpha/2} \sqrt{\frac{1}{N} (1 + 2 \sum_{i=1}^{k}{y_i^2})}$$<br>  
    ここで、 $`k`$ はラグ、 $`N`$ は標本規模、 $`z`$ は標準正規分布の累積分布関数、$`\alpha`$は有意水準である。
    この場合、信頼区間はラグが増加するにつれて拡大する。

#### 論点
自己相関プロットは、以下の質問に対する答えを与えることができる。

1. データは無作為か。  
2. 観測値は隣接する観測値と関連しているか。  
3. 観測値は2つの離れた観測値と関連しているか。  
4. 観測された時系列は白色雑音か。  
5. 観測された時系列は正弦波か。  
6. 観測された時系列は自己回帰的か。  
7. 観測された時系列に適したモデルは何か。  
8. モデル  
<br>$`Y = 定数項 + 誤差項`$<br>  
は有効かつ十分か。
9. 次の式は有効か。  
<br>$$s_{\bar{Y}} = s/\sqrt{N}$$<br>
                   

#### 重要：技術的結論の妥当性を確保する  
無作為性（固定モデル、固定変動、固定分布とともに）は、あらゆる測定過程に通常内在する4つの仮定の一つである。
無作為性の仮定は、以下の三つの理由から極めて重要である。

1. ほとんどの標準的な統計検定は無作為性に依存している。
   検定結論の妥当性は、無作為性仮定の妥当性に直接結びついている。 

2. 多くの一般的に使用される統計式は無作為性の仮定に依存しており、最も一般的な式は標本平均の標準偏差を求める式である。  
    <br>$$s\_{\bar{{Y}}} = s/\sqrt{N}$$<br>  
    ここで ***s*** はデータの標準偏差である。この公式は頻繁に使用されるが、無作為性の仮定が成立しない限り、その結果は全く意味を持たない。 

3. 単変量データの場合、デフォルトモデルは  
    <br>$$Y = 定数 + 誤差$$<br>  
    データが無作為でない場合、このモデルは誤りであり無効となる。
    パラメータ（定数など）の推定値は意味をなさず無効となる。

端的に言えば、分析者が無作為性を検定しない場合には、多くの統計的結論の妥当性は疑わしくなる。
自己相関プロットは、このような無作為性を検定する優れた方法である。
