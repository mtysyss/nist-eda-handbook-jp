# 1.3.3.1.1. 自己相関プロット：無作為データ

#### 自己相関プロット
以下は自己相関プロットのサンプルである。  
![1.3.3.3.1.1.Autocorrelation Plot: Random Data](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/autocop1.gif)

#### 結論
このプロットから以下の結論が導き出せる。

1. 有意な自己相関は見られない。  
2. データは無作為である。  

#### 議論
定義上、常に1となるラグ0を除き、ほぼ全ての自己相関が95%信頼区間に収まっていることに留意されたい。
さらに、明らかなパターン（例えば最初の25個が正で次の25個が負といった）は見られない。
これは、データが真に無作為である場合に期待される、パターンの欠如である。  

95%および99%信頼区間をわずかに超えるラグ値が必ずしも非無作為性を示すわけではない。
95%信頼区間では、無作為な変動により約20ラグに1つが統計的に有意となることが予想される。  

現在の値$`Y_i`$から次の値$`Y_{i+1}`$を推測する関連性は存在しない。
このような非関連性が無作為性の本質である。
端的に言えば、隣接する観測値は「相関しない」ため、これを「自己相関なし」の事例と呼ぶ。
