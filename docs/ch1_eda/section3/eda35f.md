# 1.3.5.15. カイ二乗適合度検定

#### 目的：分布の適合性の検定
カイ二乗検定（[Snedecor and Cochran, 1989](../section4/eda43.md#Snedecor)）は、データ標本が特定の分布を持つ母集団から抽出されたものかを検定するために用いられる。  

カイ二乗適合度検定の魅力的な特徴は、[累積分布関数](eda362.md#累積分布関数)を計算できるあらゆる単変量分布に適用できる点である。
カイ二乗適合度検定は区分化されたデータ（すなわち、階級に分類されたデータ）に適用される。
区分化されていないデータについては、カイ二乗検定を出力する前に、単にヒストグラムや頻度表を計算することで実際には制限にはならない。
しかし、カイ二乗検定統計量の値は、データがどう分類されているかに依存する。
カイ二乗検定のもう一つの欠点は、カイ二乗近似が有効であるためには、十分な標本規模が必要になる点である。  

カイ二乗検定は、[Anderson-Darling](eda35e.md) 検定および [Kolmogorov-Smirnov](eda35g.md) 適合度検定の代替である。
カイ二乗適合度検定は、[二項分布](eda366i.md)や [Poisson 分布](eda366j.md)などの離散分布に適用できる。
一方、Kolmogorov-Smirnov 検定および Anderson-Darling 検定は連続分布に限定される。
カイ二乗適合度検定に関する追加の説明は、[製品および工程の比較](../../prc/section2/prc211.md)の章（7章）に記載されている。 

#### 定義
カイ二乗検定は次の仮説に対して定義する。  

##### $`H_0`$:
データは指定された分布に従う。

##### $`H_a`$:
データは指定された分布に従わない。 

##### 検定統計量：
カイ二乗適合度検定で使用される検定統計量を計算するには、まず関心のある量 $`Y`$ の観測値の範囲を $`y_{1} < y_{2} < \dots < y_{k+1}`$ によって決定される $`k`$ 個の区間に分割する。
このとき、区間 $`i`$ の下端 $`y_{i}`$ および上端 $`y_{i+1}`$ は $`i=1,\dots,k`$ に対して定義する。
なお、$`y_{1}`$ は最小値であることに注意する。
ここで、区間 $`i`$ の下端点は $`y_{i}`$ 、上端点は $`y_{i+1}`$ であり（$`i=1,\dots,k`$ ）である。
なお、$`y_{1}`$ は $`-\infty`$ となり、$`y_{k+1}`$ は $`+\infty`$ となる。

検定統計量は以下のように定義される。  

$$\chi^{2} = \sum_{i=1}^{k} (O_{i}-E_{i})^{2}/E_{i}$$  

ここで、$`O_{i}`$ は区間 $`i`$ に分類される観測値の数を表す（連続する二つの区間の境界上に位置する観測値の計数方法に関する何らかの規約の下で、例えば、$`y_{i}`$ に等しい観測値は区間 $`i+1`$ に分類されるものとして計数される）。
また、$`E_{i}`$ は、検定対象の確率モデルに基づいてビン $`i`$ に分布すると期待される観測値の数を示す。
このモデルが[累積分布関数](eda362.md#累積分布関数)$`F_{\theta}`$ で指定されている場合、期待値は次のように計算される。  

$$E_{i} = N (F_{\theta}(y_{i+1})-F_{\theta}(y_{i}))$$  

ここで $`N`$ は標本規模を表し、$`F_{\theta}(-\infty) = 0`$ および$`F_{\theta}(+\infty) = 1`$ という規約の下で定義される。  

一般に、この累積分布関数はベクトルパラメータ $`\theta`$ に依存するため、前述の $`E_{i}`$ の式において $`F_{\theta}`$ と表記されることに留意されたい。
 例えば、確率モデルがガウス分布の場合、$`\theta = (\mu, \sigma)`$ となる。
ここで $`\mu`$ と $`\sigma`$ はガウス分布の平均と標準偏差を表す。
 一方、確率モデルがポアソン分布の場合、$`\theta`$ はスカラー量 $`\theta = \lambda`$ となり、対応する平均値となる。
いずれの場合も、$`E_{i}`$ を計算するには、まず $`\theta`$ を推定する必要がある。

カイ二乗検定は、$`\theta`$ の推定値が個々の観測値ではなく、観測されたビンカウントから導出された[最尤](../../apr/section4/apr412.md)推定値であると仮定する。
このような推定値（$`\widetilde{\theta}`$ と表記）は、対数尤度関数 $`\ell`$ を $`\theta`$ に関して数値的に最大化することで計算できる。  

$$\ell(\theta) = \sum_{i=1}^{k} O_{i} \log (F_{\theta}(y_{i+1})-F_{\theta}(y_{i}))$$  

期待値を持つビンのカウント数は 次式で計算される。  

$$E_{i} = N (F_{\widetilde{\theta}}(y_{i+1})-F_{\widetilde{\theta}}(y_{i})) \qquad i=1,\dots,k$$  


##### 有意水準: 
*α*

##### 臨界領域:
検定統計量は、近似的にカイ二乗分布に従う。
自由度は $`(k-c)`$ であり、ここで *k*は空でないセルの数、*c*は分布の推定母数（[位置および尺度の母数](eda364.md)、[形状係数](eda363.md)を含む）+ 1 である。
例えば、3 係数の Weibull 分布の場合、$`c=4`$ となる。  

したがって、データが指定された分布を持つ母集団からのものであるという仮説は、以下の場合に棄却される。  
$$\chi^2 > \chi_{1-\alpha, k-c}^2$$  
ここで $`\chi_{1-\alpha, k-c}^2 `$ は自由度 $`k-c`$ 、有意水準 *α* におけるカイ二乗の棄却値である。 


#### カイ二乗検定の例
正規分布、二重指数分布、自由度3の*t分布*、対数正規分布について、それぞれ 1,000 個の乱数を作成した。
全ての事例において、正規分布データの検定に $`k=32`$ 区分のカイ二乗検定を適用した。
正規分布は2つのパラメータを持つため、$`c=2+1=3`$ である。 

正規乱数は変数Y1に、二重指数乱数は変数Y2に、*t*乱数は変数Y3に、対数正規乱数は変数Y4に格納した。

　　$`H_0`$:　　データは正規分布である。  
　　$`H_a`$:　　データは正規分布ではない。  

　　Y1 調整済み検定統計量:　　$`\chi^2 =   32.256`$  
　　Y2 調整済み検定統計量:　　$`\chi^2 =   91.776`$  
　　Y3 調整済み検定統計量:　　$`\chi^2 =  101.488`$  
　　Y4 調整済み検定統計量:　　$`\chi^2 = 1085.10435`$  

　　有意水準:　$`α = 0.05`$  
　　自由度:　　$`k - c = 32 - 3 = 29`$  
　　棄却値:　　$`\chi_{1-α, k-c}^2 = 42.557`$     
　　棄却域:　　$`\chi^2 > 42.557`$　の場合に $`H_0`$ を棄却    

期待通り、カイ二乗検定は正規分布データ集合では帰無仮説を棄却せず、3つの非正規データ集合では帰無仮説を棄却した。 

#### 応用例
この例では、[アルミニウム合金試験片の疲労寿命](../section4/eda429.md)で説明されているデータを使用し、破断まで周期的な荷重が加えられたアルミニウム板の矩形試験編の疲労寿命（破断までのサイクル数、単位：千サイクル） 101 の測定値である。
これらのデータが 3-係数の Weibull 確率分布モデルと一致するかを検定するために、カイ二乗適合度検定を適用し、測定値を$`k=10`$ 個の区間に分類し、各区間には約 10 個の観測値が含まれるように選択する。
区間のカウント数に基づく Weibull 係数の最大尤度推定値は、個々の観測値に基づく推定値とはわずかに異なる。
[検定統計量に対する $`p`$-値](../../prc/section1/prc131.md)は 0.15 であり、したがって、データに対する確率モデルとして 3 係数 Weibull 分布の妥当性に疑問を呈するものではない。
下記の[Rコード](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35f.r)には、上述した検定の実装が含まれている。

#### 論点
カイ二乗検定は、以下の種類の質問に答える。  

* データは正規分布に従うか。  
* データは対数正規分布に従うか。  
* データは Weibull 分布に従うか。  
* データは指数分布に従うか。  
* データはロジスティック分布に従うか。  
* データは二項分布に従うか。  

#### 重要
多くの統計的検定や手順は特定の分布の[仮定](../section2/eda2.md)に基づく。
正規性の仮定は古典的な統計検定において特に一般的である。
信頼性モデル化の多くは、データの分布が Weibull 分布に従うという仮定に基づいている。

強い分布を仮定しないノンパラメトリックや頑健な技法も多数存在する。
ノンパラメトリックとは、符号検定のように特定の分布仮定を必要としない技法を指す。
頑健とは、幅広い分布仮定のもとで良好な性能を発揮する統計的技法を意味する。
しかしながら、特定の分布仮定に基づく技法は一般的に、これらのノンパラメトリックや頑健な技法よりも検出力が高い。
ここで「検出力」とは、差異が実際に存在する際にそれを検出する能力を指す。
したがって、分布仮定が確認できる場合、パラメトリック技法が一般的に優先される。  

正規性（またはその他の分布に関する）仮定を置く技法を使用する場合、この仮定が実際に正当化されることを確認することが重要である。
正当化される場合、より検出力の高いパラメトリック技法が使用できる。
分布に関する仮定が正当化されない場合、ノンパラメトリックもしくは頑健な技法が必要となることがある。
