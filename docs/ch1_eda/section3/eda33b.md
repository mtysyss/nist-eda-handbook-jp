# 1.3.3.11. DOE 散布図

#### 目的：散布図と尺度に関する重要な因子の特定
DOE散布図は、各因子（すなわち独立）変数の各水準に対する応答値を示す。
因子変数内および異なる因子変数間での位置と尺度の変化の状況を可視化している。
これは、重要な因子がどれかを可視化し、実験計画において重要な因子の順位付けリストを得るのに役立つ。
DOE散布図は、実験計画における従来の分散分析を補完するものである。  
 
DOE散布図は通常、[DOE平均プロット](eda33c.md)および[DOE標準偏差プロット](eda33d.md)と組み合わせて用いられる。
DOE平均プロットは生の応答値を平均応答値で置き換え、DOE標準偏差プロットは生の応答値を応答値の標準偏差で置き換える。
これら3つのプロット全てを作成することには価値がある。 
DOE平均プロットと標準偏差プロットは、位置と広がりに関する要約統計量が際立つ点で有用である（生データプロットでは見落とされる場合がある）。
しかし、生データ点は、外れ値の存在など、要約統計で失われる可能性のある微妙な点を明らかにすることがある。 

#### プロット例  因子4、2、3、7が重要な因子
![1.3.3.11.DOE Scatter Plot](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/eda_dexboxbike_r01.gif)

#### プロットの解説
この[BOXBIKE2.DAT データ集合](https://www.itl.nist.gov/div898/handbook/datasets/BOXBIKE2.DAT)のサンプル・プロットでは、7つの因子があり、各因子は2つの水準を持つ。
各因子について、その水準ごとに異なるx座標が定義されている。
例えば因子1では、水準1は0.8、水準2は1.2と符号化されている。
$`y`$ 座標は単に応答変数の値である。
実線の水平線は応答変数の全体平均値の位置に引かれている。
明瞭化のため点線の垂直線が追加されている。  

因子ごとに任意の水準数でプロットを描くことは可能だが、実質的に有用なのは因子が2～3水準の場合に限られる。 

#### 結論
このDOE散布図のサンプルは以下のことを示している。

1. 外れ値は存在しない。
2. 因子2と因子4の水準には明確な位置の差が見られる。
3. 因子1の水準には明確な尺度の違いが見られる。

#### 定義：応答変数と因子変数の対応
DOE散布図は、以下の条件で作成する。  

* 縦軸：応答変数の値  
* 横軸：因子変数（わずかに補正された $`x`$ 座標で因子の各水準を符号化）

#### 論点
DOE散布図は、以下の質問に対する答えを与えることができる。

1. 位置と尺度に関して重要な因子は何か。  
2. 外れ値は存在するか。  

#### 重要：散布図と尺度に関する重要な因子の特定
多くの実験計画の目的は、位置と尺度に関して重要な要因を特定することである。
重要な因子の順位付けリストもしばしば関心の対象となる。
DOE散布図、平均、標準偏差プロットはこれをグラフで示す。
DOE散布図は、外れ値が結果を歪めている可能性があるかも示している。

DOE散布図は主に実験計画を分析するために設計された。
しかしながら、これらは、実験計画から得られたデータかにかかわらず、2つ以上の異なる水準を持つ2つ以上の因子変数を持つ応答変数など、あらゆる種類の多因子データに対して有用である。

#### 相互作用効果の拡張
[散布図行列](eda33qb.md)の概念を用いることで、DOE散布図は一次相互作用効果を表示するように拡張できる。  

具体的には、$`k`$ 個の因子がある場合、$`k`$ 行 $`k`$ 列のプロット行列を作成する。
対角線上のプロットは単一因子の DOE 散布図そのものである。
非対角線上のプロットでは、$`X_i`$ と $`X_j`$ の値を乗算する。 
一般的な2水準計画（例えば、各因子が2水準を持つ）では、値は通常-1と1で符号化されるため、乗算後の値も-1と1となる。
次に、この交互作用変数に対してDOE散布図を作成する。
この図はDOE交互作用効果図と呼ばれ、その例を以下に示す。  
![sample DOE interaction effects plot](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/dexscat1.gif)

#### DOE相互作用効果プロットの解釈
まず主効果の対角要素を評価する。
これらの対角プロットは、3因子すべての水準間で大きな重複を示している。
これは位置効果と尺度効果が比較的小さいことを示唆する。 
次に、一次相互作用効果の対角線外プロットを評価する。
例えば、1行目2列目のプロットは因子X1とX2の相互作用を示す。
主効果プロットと同様に、明確なパターンは認められない。

#### ソフトウェア
DOE散布図は、いくつかの汎用統計ソフトウェア・プログラムで利用可能であるが、プログラムにより形式が多少異なる場合がある。
これらは本質的に、X変数が特定の方法で定義された散布図に過ぎないため、ほとんどの統計ソフトウェア・プログラムでDOE散布図用のマクロを作成することは可能であろう。
