# 1.3.3.7. 箱ひげ図

#### 目的：位置とばらつき偏位の確認  
箱ひげ図([Chambers 1983](../section4/eda43.md#Chambers))は、データ集合の位置とばらつきに関する情報を伝える優れたツールであり、特に異なる群のデータ間の位置とばらつきの変化を検出して示すのに役立つ。

#### サンプル・プロット：この箱ひげ図は、機械が位置および場合によってはばらつきがエネルギーに大きな影響を与えることを示している  
![1.3.3.7. Box Plot](https://www.itl.nist.gov/div898/handbook/eda/gif/boxplot0.gif)  
この箱ひげ図は、[4台の機械のエネルギー出力](http://www.itl.nist.gov/div898/handbook/datasets/SPLETT2.DAT)を比較し、機械が位置とばらつきの両方がエネルギーに対して有意な影響を与えることを示している。
機械3はエネルギー応答が最も高く（約72.5）である。
機械4はエネルギー応答のばらつきが最も少なく、測定値の約50%が1エネルギー単位以内である。

#### 定義  
箱ひげ図は、次の条件で作成する。  

* 縦軸：応答変数
* 横軸：興味のある要因


以下により具体的に示す。  

1. [中央値](eda351.md)と[四分位数](eda356.md)を計算する（第1四分位数は25パーセンタイルであり、第3四分位数は75パーセンタイルである）。  
2. 中央値に記号をプロット（または線を引く）し、下四分位と上四分位の間に箱（故に箱ひげ図という）を描画する。
この箱はデータの中間の50%、すなわちデータの「本体」を表す。  
3. 下四分位から最小点までの線と、上位四分位から最大点までのもう一本の線を描く。
通常、記号はこれら最小点と最大点で描画するが、任意である。

したがって、箱ひげ図はデータの中央50％、中央値、極端な点を識別する。

#### 単一または複数の箱ひげ図が描画できる  
単一の箱ひげ図は、明確な群を持たない1つのデータ集合の1つのバッチに対して描く。
一方で、複数の箱ひげ図を一緒にプロットして複数のデータ集合を比較したり、1つのデータ集合内の群を比較したりすることができる。
単一の箱ひげ図の場合は箱の幅は任意である。
複数の箱ひげ図の場合は、箱ひげ図の幅を群またはサンプル内の点の数比に比例して設定する（一部のソフトウェアでの実行すると、箱ひげ図を同じ幅に単純に設定される）。

#### 境界線のある箱ひげ図 
箱ひげ図には、外れ値をより具体的に特定する有用な派生型がある。
この種類は以下の手順で作成する。  

1. [中央値](eda351.md)と[下四分位および上四分位](eda356.md)を計算する。  
2. 中央値に記号をプロットし、下四分位と上四分位の間に箱を描く。  
3. 四分位範囲（上位四分位と下位四分位の差）を計算し、IQ と名付ける。    
4. 以下の点を計算する。  

$$L1 = 下位四分位 - 1.5 \* IQ$$  
$$L2 = 下位四分位 - 3.0 \* IQ$$  
$$U1 = 上位四分位 + 1.5 \* IQ$$  
$$U2 = 上位四分位 + 3.0 \* IQ$$  

5. 下位四分位から最小点までの直線を下位四分位から L1 より大きい最小点まで引く。
次に、上位四分位から最大までの直線を U1 より小さい最大点まで引く。
6. L1 と L2 の間、または U1 と U2 の間の点は小さな円として描く。
L2未満またはU2より大きい点は大きな円として描く。

#### 論点
箱ひげ図は、以下の質問に対する答えを与えることができる。

1. 要因は有意か。
2. 標本群間で位置が異なるか。
3. 標本群間でばらつきが異なるか。
4. 外れ値があるか。

#### 重要：著しい要因を確認する
箱ひげ図は、要因が位置またはばらつきのいずれかに関して応答に有意な影響を与えるかを判断するための重要なEDAツールである。  

箱ひげ図は、大量の情報を要約するための効果的なツールでもある。
