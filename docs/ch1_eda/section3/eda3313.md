# 1.3.3.1.3. 自己相関プロット：強い自己相関と自己回帰モデル

#### 強い自己相関のための自己相関プロット
以下は、[ランダム・ウォークのデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/RANDWALK.DAT)の自己相関プロットのサンプルである。  
![1.3.3.1.3.Autocorrelation Plot: Strong Autocorrelation and Autoregressive Model](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/autocop3.gif)

#### 結論
上記のプロットから以下の結論を導き出せる。

1. データは強い正の自己相関を持つ自己回帰を基礎としたモデルから得られたものである。

#### 議論
プロットは、ラグ1で高い自己相関（1よりわずかに低い値）から始まり、徐々に低下する。
その後も減少を続け、負の値となった後、負の自己相関が増加し始める。
自己相関の減少は概ね直線的で、ノイズは少ない。
このようなパターンは「強い自己相関」の自己相関プロットの特徴であり、適切にモデル化すれば高い予測可能性を提供する。

#### 推奨される次の手順
次の手順は以下の式、自己回帰モデルの係数を推定することである。  

$$Y_i = A_0 + A_1*Y_{i-1} + E_i$$  

この推定は、[最小二乗線形回帰](../../pmd/section1/pmd141.md)による、もしくは[ボックス・ジェンキンス](../../pmc/section4/pmc44.md)の自己回帰（AR）モデルを当てはめることで行うことができる。   

最小二乗法による近似の無作為性の仮定は、モデルの残差に適用する。
これは、元のデータに非無作為性が認められた場合でも、 **$`Y_i`$** を **$`Y_{i-1}`$** に対して適合した後の残差は、無作為な残差となるはずである。
提案されたモデルが実際に無作為性を十分に除去できたかを評価する方法については、「[工程の模型化](../../pmd/section4/pmd44.md)」の章で詳しく説明する。  

この自己回帰モデルの残差標準偏差は、以下の初期モデルの残差標準偏差よりもはるかに小さくなる。  

$$Y_i = A_0 + E_i$$
