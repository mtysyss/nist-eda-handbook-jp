# 1.3.3.14.6. ヒストグラムの解釈：右裾引き（非対称）

#### 右に歪んだヒストグラム
![右傾斜したヒストグラムの画像](http://www.itl.nist.gov/div898/handbook/eda/gif/histogr6.gif)  

#### 歪度の議論
上のプロットは、[SUNSPOT.DAT データ](https://www.itl.nist.gov/div898/handbook/datasets/SUNSPOT.DAT)のヒストグラムである。  

対称分布とは、ヒストグラムの2つの「半分」が互いに鏡像として現れる分布である。
歪んだ（非対称）分布とは、そのような鏡像が存在しない分布である。

歪んだ分布では、分布の一方の裾がもう一方の裾に比べてかなり長く、または引き伸ばされていることがかなり一般的である。
「右裾引き」分布とは、裾が右側にある分布である。
「左裾引き」分布とは、裾が左側にある分布のことである。
上記のヒストグラムは、右に歪んだ分布を示している。  

歪んだ分布は、分布の「典型的な値」を推定する過程そのものに、ある種の哲学的複雑さをもたらす。
具体的には、分析者が分布から無作為に抽出された100個の値の系を持ち、これらの100件の観測結果を「典型的な値」で要約したいとする。
典型的な価値とは何か。分布が対称であるとき典型的な値は明確であり、それは分布の明確に定義された中心である。
例えば、鐘形対称分布の場合、中心点は分布の頂点におけるその値と同一である。  

しかし、歪んだ分布においては、通常の意味で「中心」は存在しない。
そうであるとしても、いくつかの「典型的な値」指標は、歪んだ分布にしばしば使用される。
最初の指標は分布の[最頻値](eda351.md#最頻値)である。
残念ながら、著しく歪んだ分布では、最頻値がデータの左端または右端付近にあることがあり、そのため分布の中心をうまく表すものとは思えない。
第二の選択肢として、平均（分布が均衡を取る水平軸上の点）が典型的な値として十分に機能すると概念的に主張することができる。
第三の選択肢として、他の人々は、水平軸上でデータの正確に50%が左側（右側にも）にあるという中央値が、典型的な良い値として機能すると主張するかもしれない。  

対称分布の場合、母集団において最頻、平均、中央値が同一であるため、本質的な問題は消える。
しかし、歪んだ分布の場合、これら3つの指標は著しく異なる。
実際には、歪んだ分布において最も一般的に報告される典型的な値は平均値であり、次に多いのは中央値、最も一般的でない値は最頻値である。
これら3つの指標はそれぞれ異なる「中心」の側面を反映しているため、データ集合を要約し特徴付けるときに、分析者は少なくとも2つ（平均と中央値）を報告し、できれば3つ（平均、中央値、最頻値）すべてを報告することが推奨される。  

#### 歪んだデータのいくつかの原因
歪められたデータは、データの下限または上限が原因でしばしば発生する。
つまり、下限を持つデータは右に傾くことが多く、上限を持つデータは左に傾くことが多い。
歪みは開始時効果によっても生じることがある。
例えば、信頼性用途では、一部の過程が多数の初期故障が発生し、左裾引きを引き起こす可能性がある。
一方で、信頼性の過程は、失敗が稀であるような長い起動期間を持ち、その結果、データが右に歪むことがある。
科学および工学の分野で収集されたデータは、しばしば下限がゼロである。
例えば、故障データは非負である必要がある。
多くの測定工程は、正のデータしか与えない。
出現までの時間と規模をゼロ未満にできない一般的な測定値である。

#### 推奨される次の手順
ヒストグラムが右に歪んだデータ集合を示す場合、推奨される手順は次のとおり。  

1. 標本平均、標本中央値、標本最頻値を計算し、報告することで、データを定量的に要約する。    
2. 最適適合分布（右裾引き）を決定する。  
    - [ワイブル族](eda3668.md) (最大値に対して)
    - [ガンマ族](eda366b.md)
    - [カイ二乗族](eda3666.md)
    - [対数正規族](eda3669.md)
    - [冪乗対数正規族](eda366e.md)
3. [Box-Cox変換](eda336.md)のような正規化変換を検討する。
