# 1.3.3.5. Box-Cox線形性プロット

#### 目的：YとXの変数との相関関係を最大化するX変数の変換を見つける  
Xに対するYを線形で近似するとき、Xの適切な変換がしばしば適合を著しく改善する。
Box-Cox変換（[Box-Cox,1964]）は、特に有用な変換族である。
次のように定義される。

$$T(X)=\frac{(X^{\lambda} - 1)}{\lambda}$$  

ここで、X は変換される変数であり、λ は変換係数である。
$`λ=0`$ の場合、自然対数を使用する代わりに上記の式を使用する。  

Box-Cox線形性プロットは、与えられた値 λ に対して Y と変換された X との相関を示すプロットである。
すなわち、プロットの λ は水平軸変数の座標であり、Y と変換された X との相関の値は垂直軸の座標である。
プロット上の最大相関（負の相関の最小）に対応する λ 値が、λ の最適な選択となる。  

X の変換は適合を改善するために使用される。
Y へのBox-Cox変換は、ここで議論されていない[誤差の仮定](../../ch4_pmd/section2/pmd21.md)を満たすための基礎として使用することができる。
この事例はここでは扱わない。
詳細については、([Draper と Smith, 1981](../section4/eda43.htm#Draper))の 225ページ または ([Ryan, 1997](../section4/eda43.htm#Ryan)）の 77ページを参照のこと。

#### プロット例
![](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/boxcoxli.gif)

線形フィットから予測された値を含む[元データ](https://www.itl.nist.gov/div898/handbook/datasets/JONES.DAT)のプロットは、二次近似の方が好ましい可能性があることを示している。Box-Cox線形性プロットは $`λ=2.0`$ を示している。
予測値の変換されたデータのプロットは、変換されたデータの線形適合からより優れた適合を示している（残差標準偏差の有意な減少により検証される）。

#### 定義
Box-Cox線形性プロットは、以下の条件で作成する。  

* 縦軸：変換された X と Y の相関係数  
* 横軸：λ 値

#### 論点
Box-Cox線形性プロットは、以下の質問に対する答えを与えることができる。

1. 適切な変換で近似が改善されるか。  
2. 変換係数の最適な値は何か。  

#### 重要：適切な変換を見つける
変換で、しばしば著しい適合の改善ができる。
Box-Cox線形性プロットは、試行錯誤の近似を多く行わずに、適切な変換を見つける便利な方法である。

#### 事例研究
[アラスカ・パイプライン](../../ch4_pmd/section6/pmd62.htm)データの事例研究でBox-Cox線形性プロットを利用している。

#### ソフトウェア
Box-Cox線形性プロットは、多くの一般的な統計ソフトウェア・プログラムの標準的な機能ではない。
しかし、その基礎となる技法は変換に基づいており、相関係数を求めることと関連している。
したがって、これらの機能が使える統計ソフトウェアであれば、Box-Cox線形性プロット用のマクロを書くことは実現可能である。
