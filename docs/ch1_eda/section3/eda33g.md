# 1.3.3.16. 線形相関プロット

#### 目的：群間の相関における変化の検出
線形相関プロットは、相関が群間で一貫しているかを評価するために用いる。
つまり、データが群化されているとき、単一の相関をすべての群に適用できるか、それとも各群ごとに個別の相関が必要かを判断したい場合がある。  

線形相関プロットは、[線形傾き](eda33i.md)、[線形切片](eda33h.md)、[線形残差標準偏差](eda33j.md)の各プロットと組み合わせて使用されることが多い。 
線形相関プロットを初期的に作成し、線形近似が有益な方向になるかを確認する。
相関が高い場合、これは線形勾配、切片、残差標準偏差プロットを使うことに価値があることを意味する。
相関が弱い場合は、別のモデルを採用する必要がある。  

場合によっては、群がないことがある。
代わりに異なるデータ集合があり、同じ相関を各データ集合に十分に適用できるかを知りたい場合がある。
この場合には、各異なるデータ集合を群として考え、線形勾配プロットを群に適用する。

#### プロット例
![1.3.3.16.Linear Correlation Plot](https://www.itl.nist.gov/div898/handbook/eda/gif/lincorrp.gif)  
この[HSU12.DAT データ集合](https://www.itl.nist.gov/div898/handbook/datasets/HSU12.DAT)の線形相関プロットは、すべての群で相関が高いことを示している。
これは、線形近似がこれらの各群に対して良いモデルをであることを示唆している。

#### 定義：群相関対群ID
線形相関プロットは以下の条件で作成する。  

* 縦軸：群の相関  
* 横軸：群識別子  

基準線は、全データ集合の相関でプロットする。

#### 論点
線形相関プロットは、以下の質問に対する答えを与えることができる。

1. 群間に線形関係はあるか。  
2. 線形関係の強さは、群間で相対的に一定か。  

#### 重要：群の同質性の確認
群化されたデータでは、異なる群が同質（すなわち類似）か異質（すなわち相違）かを知ることが重要なときがある。
線形相関プロットは、線形近似の文脈においてこの質問に答えるのに役立つ。

#### 事例研究
線形相関プロットは、[アラスカ・パイプライン](../../pmd/section6/pmd62.htm)データの事例研究で利用されている。

#### ソフトウェア
ほとんどの汎用統計ソフトウェア・プログラムは、線形相関プロットを実装していない。
しかし、統計プログラムが群間の相関を作成できるなら、このプロットを出力するマクロの作成は実現可能であろう。
