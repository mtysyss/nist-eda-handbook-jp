# 1.3.3.25. 実行順序プロット

#### 目的：位置と尺度の偏位、および外れ値の確認
実行順序プロット([Chambers 1983](../section4/eda43.md#Chambers))は、単変量データ集合を図表現で要約する簡単な方法である。
単変量データ集合の一般的な仮定として、次の挙動を示すことが挙げられる。  

1. 無作為性を描き  
2. 固定された分布から  
3. 共通の位置を持ち  
4. 共通の尺度を持つ  

実行順序プロットでは、位置や尺度の偏位が通常非常に顕著となる。
また、外れ値も容易に検出できる。

#### プロット例  最後3分の1データの位置の偏位
![1.3.3.25.Run-Sequence Plot](https://www.itl.nist.gov/div898/handbook/eda/section3/gif/runseq.gif)  

[MAVRO.DATデータ集合](https://www.itl.nist.gov/div898/handbook/datasets/MAVRO.DAT)のこのサンプルの実行順序プロットは、データの最後の3分の1において位置が上方へ偏位していることが判る。 

#### 定義：$`y(i)`$ 対 $`i`$  
実行順序プロットは、以下の条件で作成する。  

* 縦軸：応答変数 $`Y_i`$   
* 横軸：インデックス $`i(i= 1, 2, 3, ... ) `$  

#### 論点  
実行順序プロットは、以下の質問に対する答えを与える。  

1. 位置に偏位はあるか。  
2. ばらつきに偏位はあるか。  
3. 外れ値はあるか。  

実行順序プロットは、分析者にデータに対する優れた感覚を与えることもできる。

#### 重要：単変量仮定の確認
単変量データに対する初期モデルは次式となる。  

$$Y = 定数 + 誤差$$  

ここで、誤差項は無作為であり、一定の分布に従いかつ位置と尺度が一定であると仮定される。
このモデルの妥当性は、これらの仮定の妥当性に依存する。
実行順序プロットは、位置と尺度が一定であるかを確認するのに有用である。 

より複雑なモデルであっても、誤差項に関する仮定は多くの場合に同じである。
つまり、残差の実行順序プロット（たとえ非常に複雑なモデルからであっても）は、外れ値の確認や位置および尺度の偏位の検出において、依然として不可欠である。
