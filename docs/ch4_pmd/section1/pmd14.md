# 4.1.4. モデル構築に用いられる統計手法

#### 適切な統計手法の選択：一般的なケース
多くの種類のデータ分析問題において、解決に向けた道筋として検討すべき一般的な取組みは、せいぜい2、3つに過ぎない。
例えば、正規分布からのノイズを含むデータに適した高効率な手法と、他種のノイズを含むデータ向けのより汎用的な手法との間には、しばしば二分法が存在する。
特定の問題種に対する異なる取組みの中でも、適切な解を得るために使用できる選択可能な統計的手法は、通常、せいぜい数種類に過ぎない。
ほとんどのデータ解析問題において重要な点は、問題を解決するための最適な統計手法の選択が、主に分析の目的とデータの性質によって決定されるということである。

#### 適切な統計手法の選択：モデル化
しかし、モデル構築は、手法選択という点において、統計学の他のほとんどの分野とは異なる。
モデル構築には、問題の他のほとんどの種類よりも、より一般的な取組み方や、より選択可能な技法が数多く存在する。
特定のモデル化用途に対し、効果的に適用できる統計手法が複数あることもよくある。
モデル化問題に適用可能な手法の選択肢が豊富であるということは、効果的かつ効率的な解決策を得る機会が増える一方で、様々な分析を行い、異なる解決策を比較し、さまざまな道具の使い方を習得するために時間を費やす可能性も高まることを意味する。
本節の残りの部分では、さまざまなモデル構築の状況において有用な、最も一般的で定評のある統計技法のいくつかを紹介し、簡単に解説する。
