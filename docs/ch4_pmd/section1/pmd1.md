# 4.1. 工程のモデル化入門

#### 第4.1節の概要
この節の目的は、関数に基づく工程モデル化の全体像を把握することにある。
これには、工程のモデル化とは何か、工程モデル化の目的、およびモデル構築に使用されるさまざまな統計的手法の比較についての解説を含む。
データの収集方法、適切なモデルの構築、出力の解釈、工程モデルの活用方法に関する詳細な情報は、以降の節で取り上げる。
本章の最後の節では、科学および工学の様々な応用分野からのデータを用いて、最初の5つの節で提示した一般的な情報を具体例で示す事例研究を掲載している。
