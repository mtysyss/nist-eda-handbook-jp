# 4.1.2. 工程モデルを説明するときに統計学者が用いる用語

#### モデルの構成要素
すべての工程モデルには、主に3つの部分がある。
それらは次の通り。

1. 応答変数、通常 $`y`$ で表記される
2. 数学関数、通常 $`f(\vec{x};\vec{\beta})`$ と表記される
3. 偶然誤差、通常 $`\varepsilon`$  と表記される

#### モデルの形
モデルの一般的な形は次式である。

$$y = f(\vec{x};\vec{\beta}) + \varepsilon$$

本章で取り上げるすべての工程モデルはこの一般的な形をとる。
[前述](../section1/pmd11.md#例)したように、モデルに含まれる偶然誤差により、応答変数と説明変数との関係は、完全な決定論的な関係ではなく、「統計的」な関係となる。
これは、応答変数と説明変数との間の関数的な関係が、個々のデータ点ごとに成立するのではなく、平均にのみ成立するためである。

モデルの異なる側面に関する詳細をもでるの異なる成分に対する代替用語に沿って、以下で議論している。

#### 応答変数
応答変数 $`y`$ は、モデル化の過程を通して要約し活用できると期待される変動を示す量である。
一般に、モデル化工程を開始する前から、応答変数の変動は1つまたは複数の他の変数の値と系統的に関連していることが知られているが、この依存関係の有無や性質を検証することは、モデル化工程そのものの一部である。

#### 数学関数
この数学関数は2つの部分から構成されている。
これらの部分は、予測変数 $`x_1, x_2, \ldots \, `$ と、母数 $`\beta_0, \beta_1, \ldots `$ である。
予測変数は、応答変数とともに観測される。
これらは、前ページで数学的関数 $`f(\vec{x};\vec{\beta})`$への入力として説明された量である。
すべての説明変数の集合は、略して$`\vec{x}`$と表記される。

$$\vec{x} \equiv (x_1, x_2, \ldots)$$

母数とは、モデル化の過程で推定される量のことである。
その真の値は、シミュレーション実験を除いて、未知であり、知ることもできない。
予測変数と同様に、すべての母数の集合は、略して $`\vec{\beta}`$ と表記される。

$$\vec{\beta} \equiv (\beta_0, \beta_1, \ldots)$$

母数と予測変数を異なる形で組み合わせ、応答変数で決定論的変動を説明するために用いられる関数を作る。
例えば、未知の切片と傾きの直線は、2つの母数と1つの説明変数として次式で表される。

$$f(x;\vec{\beta}) = \beta_0 + \beta_1x.$$

切片は未知であるが、既知の傾き 1 を持つ直線の場合は、1母数だけになる。

$$f(x;\vec{\beta}) = \beta_0 + x$$

予測変数2つを持つ2次曲面の完全なモデルでは母数は6つある。

$$f(\vec{x};\vec{\beta}) = \beta_0 + \beta_1x_1 + \beta_2x_2 + \beta_{12}x_1x_2 + \beta_{11}x_1^2 + \beta_{22}x_2^2$$

#### 偶然誤差
数学関数の母数と同様に、偶然誤差は未知である。
これらは単に、データと数学関数との差である。
これらは特定の確率分布に従うと仮定されるが、その分布を用いて全体的な挙動が記述する。
誤差を記述する確率分布は、平均がゼロであり、$`\sigma`$ で表される未知の標準偏差を持ち、標準偏差は、$`\beta`$ と同様に、モデルのもう一つの母数である。

#### 代替用語
残念ながら、[前述](pmd12.htm#bfm)のモデル各部分について、完全に標準化された名称は存在しない。
他の文献やソフトウェアでは、異なる用語が使われている場合がある。
例えば、応答変数の別の一般的な名称として「従属変数」がある。
応答変数は、略して単に「応答」とも呼ばれる。
予測変数の他の名称としては、「説明変数」、「独立変数」、「予測子」、「回帰子」などがある。
応答変数の決定論的ばらつきを記述するために用いられる数学的関数は、「回帰関数」、「回帰方程式」、「平滑化関数」、あるいは「平滑」と呼ばれることもある。

#### 「モデル」の適用範囲
「モデル」という用語を正しく用いる場合、それは[上記](pmd12.md#bfm)の方程式を指すとともに、偶然誤差のばらつきを記述するために用いられる確率分布の背景となる仮定も含む。
しかし、多くの場合、「モデル」という用語を、データの決定論的なばらつきを記述する数学関数を具体的に指す場合にも用いることがある。
この関数はモデルの一部であるため、限定的な用法は間違いではないが、「モデル」という用語が単なる数学関数以上のものを指し得ることを覚えておくことが重要である。
