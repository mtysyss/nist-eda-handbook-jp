# 4.1.3.2. 予測

#### 予測に関する詳細
[前述](pmd13.md)したように、予測の目的は予測変数値の特定の組合せに対応する応答変数の将来値を決定することである。
[推定](pmd131.md)と同様に、予測値は、データから未知の[母数](pmd12.md#mf)を推定した後、予測変数値を回帰式に代入することで計算する。
推定と予測の違いは、不確かさの計算においてのみ生じる。
これらの違いは、以下に示す[圧力/温度の例](pmd11.md#pt.r1)を用いて、[推定を説明した例](pmd131.md#ex)と並行して説明する。

#### 例
この場合、対象とする予測変数の値が 47度であると仮定する。
次式を用いて予測値を計算すると

$$\hat{P} = 7.749695 + 3.930123T$$

予測圧力は 192.4655 となる。

![](https://www.itl.nist.gov/div898/handbook/pmd/section1/plots/pred1.r.gif)

もちろん、圧力/温度実験が繰り返す場合、データから得られる回帰関数の母数推定値は、データの無作為性と限定されたデータの標本採取数の必要性から、毎回微妙に異なるだろう。
異なる母数の推定は、結果として異なる推定値が得られる。
以下のプロットは、繰り返し実験で起こり得るわずかなばらつきの種類を示している。

#### 予測の不確かさ
予測において極めて重要なのは、データのノイズによって予測値がどの程度ばらつくかを評価することである。
その情報なしでは、予測値を目標値や他の予測値と比較する根拠が得られない。
その結果、予測に用いる手法には、予測値の不確かさの評価を含める必要がある。
幸いなことに、多くの場合、工程にモデルをあてはめるために使用されたデータは、そのモデルから得られた予測の不確かさを計算するためにも利用できる。
圧力／温度の例では、47度における回帰関数値の予測区間をモデル適合に使用したデータから計算することができる。
以下の図は、元のデータを用いて計算した 99％予測区間を示している。
この区間は、母数の推定値とデータに含まれるノイズに基づいて、47度で観測される将来の単一圧力測定値について、あり得る値の範囲を示している。

#### 信頼区間の長さ
予測区間は工程からの単一の新たな測定値に対する区間であるため、その不確かさには回帰母数の推定値に内在するノイズおよび新たな測定値の不確かさが含まれる。
つまり、新たな測定値に対するこの区間は、回帰関数値に対する信頼区間よりも広くなる。
これらの区間は、信頼区間ではなく予測区間と呼ばれる。
なぜなら、信頼区間は母数を対象とするものであり、新たな測定値は母数ではなく確率変数であるからである。

#### 信頼区間
予測区間と同様に、許容区間はモデル化対象の工程から得られる新たな測定値の妥当な値の範囲を囲む。
ただし、単一測定値や固定数の測定値の範囲を囲むのではなく、許容区間は特定の予測変数値の組合せについて、将来のすべての測定値のうち指定された割合の範囲を囲む。
例えば、47度における将来の圧力測定値について、極端な値（低値または高値）を監視するには、将来の全測定値の 98％を高い信頼度で包含する許容区間を使用する。
もし将来の値がこの区間の外側に外れた場合、システムを点検し、すべてが正常に機能していることを確認する。
47度における将来のすべての圧力測定値の 98％を網羅する 99％の許容区間は、192.4655 ± 14.5810 となる。
この区間は、単一測定値に対する予測区間よりも幅が広い。
これは、将来の測定値全体のより大きな割合を網羅するように設計されているためである。
許容区間に関する説明は、区間の記述に 2つの百分率が使用されているため、誤解を招きやすい。
99％の場合の一方は、その区間が捕捉すべき量を確実に捕捉できるという確信度を表している。
もう一方の98％は、対象となる量が何であるかを表しており、この場合は T=47度における将来の全測定値の 98％を指する。

予測区間および許容区間の解釈と計算に関する詳細については、[5.1節](../section5/pmd51.md)を参照のこと。
