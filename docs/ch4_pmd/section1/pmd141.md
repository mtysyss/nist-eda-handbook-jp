# 4.1.4.1. 線形最小二乗回帰

#### モデル化の主力
線形最小二乗回帰は、断然最も広く用いられているモデル化方法である。
多くの人が、データにモデルを適合させるために「回帰」、「線形回帰」、あるいは「最小二乗法」を使用したと述べるとき、通常はこの手法を指している。
線形最小二乗回帰は、最も広く用いられているモデル化方法であるだけでなく、その直接的な適用範囲外の幅広い状況にも応用されてきた。
この節で取り上げる他の手法、[非線形最小二乗回帰](pmd142.md)、[加重最小二乗回帰](pmd143.md)、[LOESS](pmd144.md)などを含め、多くのモデル化手法における基礎となる重要な役割を果たしている。

#### 線形最小二乗モデルの定義
[適切なデータ集合](../section3/pmd32.md)を用いて直接適用すれば、線形最小二乗回帰を用いて、以下の形式の任意の関数でデータを当てはめることができる。

$$f(\vec{x};\vec{\beta}) = \beta_0 + \beta_1x_1 + \beta_2x_2 + \ldots $$

ここで、

1. 関数の各説明変数は未知の母数で乗算され
2. 対応する説明変数を持たない未知の母数は最大で1つあり
3. 個々の項をすべて合計し、最終的な関数値を得る。

統計学的には、これらの基準を満たす関数はすべて「線形関数」と呼ばれる。
関数が直線ではない場合でも「線形」という用語が用いられるのは、未知の母数を変数と見なし、説明変数をそれらの「変数」に対応する既知の係数と見なせば、問題は（通常は過剰決定となる）線形方程式系となり、未知母数の値を求めることができるためである。
「線形」という言葉の様々な意味を区別するために、ここで論じている線形モデルは、しばしば「母数に関して線形」もしくは「統計的に線形」であると言われる。

#### 「最小二乗法」である理由
線形最小二乗回帰もまた、未知の母数推定値が計算される方法に由来してその名が付けられている。
母数の推定値を得るために用いられる「最小二乗法」は、1700年代後半から1800年代初頭にかけて、以下の数学者たちによって独立して開発された。
Karl Friedrich Gauss、Adrien Marie Legendre、そして（おそらく）Robert Adrain、[[Stigler (1978)]](../section7/pmd7.md#Stigler,%20S.M.%20%281978%29)、[[Harter (1983)]](../section7/pmd7.md#Harter,%20H.L.%20%281983%29)、[[Stigler (1986)]](../section7/pmd7.md#Stigler,%20S.M.%20%281986%29)によって、それぞれドイツ、フランス、アメリカで独立して開発された。
最小二乗法では、データとモデルとの間の偏差の平方和を最小化することで、未知の母数を推定する。
この最小化工程により、データによって構成される過剰決定方程式系が、$`p`$ 個の未知数を持つ $`p`$ 個の方程式からなる合理的な方程式系（ここで $`p`$ はモデルの関数部分における母数の数）へと簡約される。
次に、この新しい連立方程式を解くことで、母数の推定値が得られる。
最小二乗法を用いた母数推定方法の詳細については、[4.4.3.1節](../section4/pmd431.md)を参照のこと。

#### 線形関数の例
前述したように、線形モデルは直線や平面に限定されず、非常に幅広い形状を含む。
例えば、単純な二次曲線、

$$f(x;\vec{\beta}) = \beta_0 + \beta_1x + \beta_{11}x^2$$

は、統計的な意味において線形である。
$`\log(x)`$ における直線モデル、

$$f(x;\vec{\beta}) = \beta_0 + \beta_1\ln(x)$$

あるいは、$`\sin(x)`$ に関する多項式、

$$f(x;\vec{\beta}) = \beta_0 + \beta_1\sin(x) + \beta_2\sin(2x) + \beta_3\sin(3x)$$

も、観測された説明変数 $`x`$ に関しては線形ではないが、母数に関しては線形であるため、統計的な意味でも線形である。

#### 非線形モデルの例
統計的な意味で線形であるモデルが、説明変数に関して必ずしも線形である必要がないのと同様に、非線形モデルであっても、説明変数に関しては線形であっても、母数に関しては線形でない場合がある。
例えば、

$$f(x;\vec{\beta}) = \beta_0 + \beta_0\beta_1x $$

は $`x`$ に関して線形であるが、[上述](pmd141.md#def)した線形モデルの一般的な形式で表すことはできない。
これは、この直線の傾きが2つの母数の積として表されるためである。
その結果、このモデルには非線形最小二乗回帰を用いて推定することはできるが、線形最小二乗法は用いることができない。
非線形モデルに関するさらなる例や考察については、次の節である[4.1.4.2節](pmd142.md)を参照のこと。

#### 線形最小二乗法の利点
線形最小二乗回帰は、その有効性と網羅性から、工程のモデル化における主要な手法としての地位を確立している。

母数が非線形である関数により適切に記述されるデータの種類はあるが、科学や工学の多くの過程は線形モデルでうまく記述される。
これは、過程が本質的に線形であるか、小さな範囲において任意の過程が線形モデルによって十分に近似できるためである。

線形最小二乗回帰から得られる未知母数の推定値は、工程モデル化で一般的に用いられる前提条件の下で、想定される母数推定の広範な集合論からの最適推定値である。
実務的に言えば、線形最小二乗回帰はデータを非常に効率的に利用する。
比較的少数のデータ集合でも良好な結果が得られる。

最後に、線形回帰に関連する理論は十分に理解されており、予測、校正、最適化のために、容易に解釈できるさまざまな統計区間を構築することを可能にする。
これらの統計区間は、科学および工学に関する質問に対して明確な回答を提供するために利用できる。

#### 線形最小二乗法の欠点
線形最小二乗法の主な欠点は、広い範囲に渡って線形モデルがとれる形状に制限があること、外挿特性が不十分である可能性があること、外れ値に対する感受性が高いことが挙げられる。

予測変数に非線形項を含む線形モデルは比較的遅い曲線を描くため、本質的に非線形な過程においては、データの範囲が拡大するにつれて、データに適合する線形モデルを見つけることがますます困難になる。
説明変数が極端になると、線形モデルの出力も常により極端になる。
これは、対象領域でデータを収集できない過程の結果を外挿するために、線形モデルが効果的でない可能性があることを意味する。
もちろん、外挿はモデルの種類に関係なく潜在的に危険である。

最後に、最小二乗法はしばしば未知母数の最適な推定値を与えるが、モデルに適合させるために使用されるデータに異常なデータ点が存在することに非常に敏感である。
1つまたは2つの外れ値が、時に最小二乗解析の結果を深刻に歪めることがある。
これにより、[特に外れ値に関する](../section4/pmd445.md#nppi)、[モデル検証](../section4/pmd44.md)は、モデル構築の動機となる質問に対する妥当な回答を得る上で極めて重要である。
