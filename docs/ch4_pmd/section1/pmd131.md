# 4.1.3.1. 推定

#### 推定に関する詳細
前のページで述べたように、推定の主な目的は、特定の予測変数値の組合せに対応する[回帰関数](pmd12.md#at)の値を決定することである。
推定値は、データから未知の[母数](pmd12.md#mf)を推定した後、予測変数の値を[回帰式](pmd12.md#at)に代入し計算する。
この工程を、数ページ前に紹介した[圧力/温度の例](pmd11.md#pt.r1)を用いて以下に示す。

#### 例
この場合、対象とする予測変数値が 47度であると仮定する。
以下の式をを用いて回帰関数の推定値を計算すると、

$$\hat{P} = 7.749695 + 3.930123T$$

推定平均圧力は 192.4655 となる。

![](https://www.itl.nist.gov/div898/handbook/pmd/section1/plots/pred1.r.gif)

もちろん、圧力/温度実験が繰り返す場合、データから得られる回帰関数の母数推定値は、データの無作為性と限定されたデータの標本採取数の必要性から、毎回微妙に異なるだろう。
異なる母数の推定は、結果として異なる推定値が得られる。
以下のプロットは、繰り返し実験で起こり得るわずかなばらつきの種類を示している。

#### 推定値の不確かさ
推定における極めて重要な部分は、データに含まれるノイズによって推定値がどの程度ばらつくかを評価することである。
その情報なしでは、推定値を目標値や他の推定値と比較する根拠が得られない。
推定に用いるいかなる手法であっても、推定値の不確かさの評価を含める必要がある。
幸いなことに、多くの場合、工程にモデルを当てはめるために使用されたデータは、モデルから得られた推定値の不確かさを計算するためにも使用できる。
圧力/温度の例では、47度における回帰関数の値の信頼区間をモデル適合に使用したデータから計算することができる。
以下の図は、元のデータを用いて計算した 99％信頼区間を示している。
この区間は、母数の推定値とデータに含まれるノイズに基づいて、47度における平均圧力の妥当な値の範囲を示している。

#### 信頼区間の長さ
信頼区間は回帰関数の値に関する区間であるため、その不確かさには回帰母数の推定値に内在するノイズのみが含まれる。
推定値の不確かさは、未知の母数を推定するために使用されるデータが、各母数の推定値を決定するために（使用される統計的手法に応じて）本質的に平均化されるため、工程からの単一測定値の不確かさよりも小さくなる可能性がある。
このデータの「平均化」により、個々の観測データ点に内在する誤差が無効化される傾向がある。
この種の結果に含まれるノイズは、一般的に、[1つまたは複数の将来の測定値の予測](pmd132.md)に含まれるノイズよりも小さく、推定された母数の不確かさと、新たな測定値の不確かさの両方を考慮に入れなければならない。
