# 4.1.3. 工程モデルの使用目的

#### 3つの主な目的
工程モデルは、主に以下の4つの目的で用いられる。

1. 推定  
2. 予測  
3. 校正  
4. 最適化  

このページの残りの部分では、工程モデルのさまざまな用途について簡潔に説明する。
工程モデルの用途に関するより詳細な説明は、このページの下部に記載されている本節の各小見出しで解説されている。

#### 推定
推定の目的は、予測変数の値の特定の組合せについて、[回帰関数](pmd12.md#at)の値（すなわち、応答変数の平均値）を求めることである。
回帰関数の値は、予測変数の値のあらゆる組合せについて推定することができ、これにはデータが測定または観測されていない値も含まれる。
予測変数の値の観測範囲内の点について推定された関数値は、内挿と呼ばれることがある。
予測変数の値の観測範囲外の点について回帰関数値を推定することを外挿と呼ぶが、これは必要となる場合もあるが、注意が必要である。

#### 予測
予測の目的は、予測変数値の特定の組合せに対し、以下のいずれかを特定することである。

1. 応答変数の新たな観測値
2. 応答変数の将来の観測値全体のうち、特定の割合を占める観測値

予測は、予測変数値のあらゆる組合せについて行うことができ、これにはデータが測定または観測されていない値も含まれる。
推定の場合と同様に、予測変数値の観測範囲外で行われる予測も時には必要となるが、注意が必要である。

#### 校正
校正の目的は、ある測定システムを用いて行われた測定値を別の測定システムによる測定値と定量的に関連付けることである。
これは、測定値を共通の単位で比較できるようにするため、あるいは相対的な測定法による結果を絶対単位に結びつけるために行われる。

#### 最適化
最適化は、所望の工程出力を得るために用いるべき工程入力の値を決定するために行う。
典型的な最適化の目標は、工程の歩留まりを最大化すること、製品の製造に必要な処理時間を最小化すること、あるいは、指定された公差を維持するために、ばらつきを最小限に抑えつつ目標となる製品仕様を達成することが挙げられる。
