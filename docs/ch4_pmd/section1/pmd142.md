# 4.1.4.2. 非線形最小二乗回帰

#### 線形最小二乗回帰の拡張
非線形最小二乗回帰は、はるかに大規模かつ一般的な関数の集合に適用するために、線形最小二乗回帰を拡張したものである。
閉形式で表すことができるほぼすべての関数を非線形回帰モデルに組み込むことができる。
線形回帰とは異なり、非線形回帰モデルの関数部分において、母数の使用方法に制限はほとんどない。
ただし、関数内の未知母数の推定方法は、概念的には線形最小二乗回帰の場合と同じである。

#### 非線形回帰モデルの定義
その名前が示す通り、非線形モデルとは、以下の[基本形](pmd12.md#bfm)を持つモデルを指し、

$$y = f(\vec{x};\vec{\beta}) + \varepsilon$$

ここで

1. モデルの関数部分は、未知の母数 $`\beta_0, \beta_1, \ldots`$ に対して*[線形](pmd141.md#def)ではなく*
2. 未知母数の値を推定するために[最小二乗法](../section4/pmd431.md)が用いられる。

しかしながら、関数の未知母数が通常推定される方法であるが、以下の2つの追加条件を満たすモデルを使用する方がしばしばはるかに容易である。

3. 関数は未知の母数に関して滑らかであり、
4. 母数推定値を得るために使用される[最小二乗法の基準](../section4/pmd431.md)は、唯一の解を有している。

これら最後の2つの基準は、非線形最小二乗モデルの定義において必須の部分ではないが、実務上重要である。

#### 非線形モデルの例
非線形モデルの例としては、次のようなものがある。

$$f(x;\vec{\beta}) = \frac{\beta_0 + \beta_1x}{1+\beta_2x}$$

$$f(x;\vec{\beta}) = \beta_1x^{\beta_2}$$

$$f(x;\vec{\beta}) = \beta_0 + \beta_1\exp(-\beta_2x)$$

$$f(\vec{x};\vec{\beta}) = \beta_1\sin(\beta_2 + \beta_3x_1) + \beta_4\cos(\beta_5 + \beta_6x_2)$$

#### 非線形最小二乗法の利点
非線形最小二乗回帰が他の多くの技法に比べて持つ最大の利点は、適合させることができる関数の範囲が広いことである。
多くの科学や工学上の過程は、線形モデルやその他の比較的単純な種類のモデルを用いてよく記述できるが、本質的に非線形である過程も数多く存在する。
例えば、コンクリートが硬化するにつれて強度が向上する過程は、非線形な過程である。
コンクリート強度に関する研究によると、強度は当初急速に増加するが、その後、時間の経過とともに横ばいとなり、数学的に言えば漸近線に近づく。
すべての線形関数において、説明変数が極値に近づくにつれて、関数値が増加または減少する速度が低下することはあり得ないため、線形モデルは漸近線を示す過程をうまく記述できない。
一方、過程の漸近的な挙動をうまく記述できる非線形モデルは数多く存在する。
一部の過程の漸近的挙動と同様に、物理的過程の他の特徴も、より単純なモデル種を用いるよりも、非線形モデルを用いる方が表現しやすい場合がしばしばある。
 
「最小二乗」の手順である非線形最小二乗法は、他の手法に比べて線形最小二乗回帰と同様の利点（および欠点）を有している。
共通の利点の一つは、データの効率的な活用である。
非線形回帰は、比較的小さなデータ集合を持つモデルにおいて、未知母数の優れた推定値を生み出すことができる。
非線形最小二乗法が線形最小二乗法と共有するもう一つの利点は、信頼、予測、校正区間を計算する科学的および工学的課題に答えるための、非常に高度に発達した理論であることが挙げられる。
ほとんどの場合、非線形回帰によって与えられる区間の確率的解釈は概ね正しいが、これらの区間は実際には非常にうまく機能する。

#### 非線形最小二乗法の欠点
線形最小二乗法のような単純なモデル化技法から非線形最小二乗回帰に移行するときの主なコストは、母数推定値を計算するために反復最適化手順を使用する必要がある点である。
母数に対して線形な関数の場合、母数の最小二乗推定値は常に解析的に求めることができるが、非線形モデルでは一般的にそうではない。
反復法を使用する場合、ソフトウェアが最適化を開始する前に、利用者が未知母数の初期値を指定する必要がある。
初期値は、まだ未知の母数推定値に妥当な程度に近くなければならず、そうでないと最適化手順が収束しない可能性がある。
また、不適切な初期値は、ソフトウェアが最小二乗推定値を定義する大域最小値ではなく、局所最小値に収束してしまう原因にもなり得る。

線形最小二乗法に共通する欠点には、外れ値に対する強い感受性が含まれる。
線形最小二乗解析と同様に、データに1つまたは2つの外れ値が存在すると、非線形解析の結果に深刻な影響を及ぼす可能性がある。
さらに、残念ながら、非線形回帰における外れ値検出のためのモデル検証のためのツールは、線形回帰に比べて少ない。
