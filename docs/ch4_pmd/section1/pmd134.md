# 4.1.3.4. 最適化

#### 最適化に関する詳細
[前述](pmd13.md)したように、最適化の目的は、所望の出力を得るために必要な工程入力値を決定することである。
校正と同様に、最適化においても、応答変数として出力値を代入し、それに関連する予測変数の値を求める。
ここでも、工程モデルは入力と出力を結びつける。
しかし、校正や予測とは異なり、最適化を成功させるには、予測変数と応答変数の間に因果関係が存在する必要がある。
工程モデルが変数間の因果関係を正しく確実に表すためには、無作為順で実施される実験計画を用いなければならない。
最適化を行うには、通常、二次モデルが用いられ、最小値や最大値を求めるための標準的な微積分技法を併用する。
ただし、他の技法も使用可能である。
以下で説明する例には、最適化工程の図解が含まれている。

#### 例
化学反応を利用する製造工程において、その工程が実施される温度や圧力は、反応時間に影響を及ぼす可能性がある。
この工程のスループットを最大化するため、最適と思われる条件の近傍において、13回の実行からなる[中心複合計画](../../ch5_pri/section3/pri3361.md)を用いた最適化実験が実施された。
微積分を用いて、回帰関数における局所極値に関連する入力値を決定した。
以下の図は、データに適合させた二次曲面と、最大スループットに関連する入力値が概念的にどのように求められるかを示している。

![](https://www.itl.nist.gov/div898/handbook/pmd/section1/plots/opt1_r.gif)

予測と校正と同様、データの無作為性と工程からのデータ採取の必要性は結果に影響を与える。
最適化実験が理想的な条件下で再度実行された場合、モデルを用いて計算された最適入力値は微妙に異なる。
故に、結果を正しく解釈するために、結果における無作為変動の程度を理解することが重要である。

#### 最適化における不確かさ
予測や校正と同様に、スループットを最大化すると推定される入力値の不確かさも、モデルを適合させるために使用されたデータから計算することができる。
しかし、予測や校正とは異なり、最適化ではほとんどの場合、複数の量、すなわち工程入力の値を同時に推定することになる。
その結果、各入力ごとに個別の不確かさ区間を計算するのではなく、すべての入力値に対して同時に信頼領域を計算することになる。
この信頼領域には、高い確率でスループットを最大化する真の工程入力の完全な集合が含まれる。
下の図は、考えられるさまざまな入力値の組合せを示す図で、スループットが等しい等高線を示している。
実線の等高線はスループットを示しており、中央の破線の等高線は、最適な結果をもたらす妥当な入力値の組合せを囲んでいる。
「+」は推定された最適値を示している。
破線で囲まれた領域は、2つの工程入力に対する 95％の同時信頼領域である。
この領域内では、工程のスループットはおよそ 217単位/時間である。
