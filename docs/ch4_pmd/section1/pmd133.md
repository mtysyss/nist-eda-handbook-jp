# 4.1.3.3. 校正

#### 校正に関する詳細
[工程モデルのさまざまな用途を紹介するページ](pmd13.md)で述べたように、校正の目的は、2つの測定尺度のうち一方で行われた測定値をもう一方の測定尺度に定量的に変換することである。
一般的に、これら尺度2つの重要度は等しくないため、変換は一方向のみで行われる。
一次測定尺度は通常、科学的に関連性のある尺度であり、この尺度で直接行われた測定は、二次尺度での測定よりも（相対的に）精度が高いことがよくある。
2つの測定尺度間の関係を記述する工程モデルが、この変換手段を提供する。
主に校正を目的として構築された工程モデルは、しばしば「校正曲線」と呼ばれる。

#### 例
熱電対は温度測定装置として広く用いられており、温度評価において、多くの場合、温度計よりも実用的である。
ただし、熱電対は温度を温度尺度で直接示すのではなく、電圧として測定する。
さらに、特定の熱電対の応答特性は、構成に用いられる金属の正確な組成に依存するため、同一の測定条件下であっても、2つの熱電対の応答には多少の違いが生じる。
その結果、熱電対は解釈可能な測定情報を得るために、熱電対を校正する必要がある。
熱電対の校正曲線は、多くの場合、熱電対の出力を比較的精度の高い温度計のデータと比較し作成する。
そして、その熱電対で新しい温度を測定したとき、観測された電圧を回帰式に代入し、温度を計算することで、電圧を温度値に変換する。
（読者は、熱電対のデータを[テキストファイル](https://www.itl.nist.gov/div898/handbook/datasets/CLB1.DAT)としてダウンロードできる。）

以下のプロットは、[LOESS](pmd144.md)と呼ばれる方法を用いた局所二次モデルで熱電対を当てはめた校正曲線を示している。
従来、複雑で高次多項式モデルが熱電対校正に用いられてきたが、計算がより安定性し、より柔軟性の高い局所直線もしくは二次モデルが提案されている。
局所二次モデルを用いた温度の回帰式の解は解析ではなく数値で行われ、この種のモデルが用いる校正の概念には同一である。
二次測定尺度で行われる熱電対の測定は、応答変数として扱われ、より精度の高い温度計の結果として一次尺度は分析の[背景にある前提条件](../section2/pmd216.md)をもっとも満たすことから、予測変数として扱われることに留意する。

#### 校正の不確かさ
ここでも、予測の場合と同様に、工程モデルの当てはめに用いられたデータは、校正の不確かさを決定するためにも使用できる。
推定されたモデル母数のばらつきと、新たな電圧観測値のばらつきの両方を考慮に入れる必要がある。
これは、新たな測定値の予測における不確かさと同様である。
実際、校正区間は、予測区間の端点を求める式において、予測変数の値を解くことで計算する。
下の図は、このページの最初の図で使用された元の校正データに対する 99％校正区間を示している。
図中の関心のある領域は、区間の端点を視覚的に区別できるよう拡大表示している。
校正区間は摂氏 387.3748 ± 0.307 度である。

![](https://www.itl.nist.gov/div898/handbook/pmd/section1/plots/clb3.r.gif)

ほとんど全ての校正の適用では、対象である最終的な量は二次尺度での測定に関係する一次尺度測定方法の真の値である。
結果として、校正においては予測区間と許容区間の類似性はない。
