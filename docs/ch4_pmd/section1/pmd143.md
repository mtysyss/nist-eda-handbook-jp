# 4.1.4.3. 加重最小二乗回帰

#### データ品質にばらつきがある場合の対応
線形および非線形最小二乗回帰を含む、共通した[ほとんどの工程モデル化手法の根底にある仮定](../section2/pmd21.md)の一つは、各データ点が、[工程変動全体のうち決定論的部分](pmd11.md#def)について、等しく正確な情報を提供しているという点である。
言い換えれば、誤差項の標準偏差は、予測変数や説明変数のすべての値にわたって一定である。
しかし、この仮定は、あらゆるモデル化の適用例において、たとえ近似的にであっても明らかに成り立たない。
例えば、半導体フォトマスクの配線間隔のデータでは、配線間隔が広くなるにつれて、配線間隔の測定精度が低下しているように見える。
このように、すべての観測値を等しく扱うという仮定が妥当でない場合、加重最小二乗法を用いることで、母数推定の効率を最大化できることがよくある。
これは、母数推定値に対して適切な影響量を各データ点に与える試みで行われる。
すべてのデータを等しく扱う手順では、測定精度が低いデータ点に対して本来あるべき以上の影響を与え、極めて高精度なデータ点に対しては影響をほとんど与えない。

#### モデルの種類と加重最小二乗法
線形および非線形の最小二乗回帰とは異なり、加重最小二乗回帰は、工程変数間の関係を記述するために使用される関数の特定種類とは関連していない。
代わりに、加重最小二乗法はモデル内の偶然誤差の挙動を反映し、母数が[線形](pmd141.md#def)、[非線形](pmd142.md#def)の関数でも使用できる。
それは、各データ点に関連付けられた非負定数（または重み）を適合基準に追加して組み込むことで機能する。
重みの大きさは、関連する観測に含まれる情報の精度を示す。
重み付け適合基準を最適化して母数推定値を求めることで、重みは各観測が最終的な母数推定値に与える寄与を決定できる。
各観測の重みは他の観測の重みに対して相対的に与えられることに留意することが重要であり、絶対重みの異なる集合は同一の効果を持ち得る。

#### 加重最小二乗法の利点
これまでに議論されたすべての最小二乗法と同様に、加重最小二乗法は小規模なデータ集合を有効に活用する効率的な手法である。
また、推定、予測、校正、最適化のために、容易に解釈できるさまざまな統計区間を提供する能力も共有している。
さらに、上記で述べたように、加重最小二乗法が他の手法に比べて有する主な利点は、データ点の品質が異なる回帰状況に対応できる点にある。
データにおける偶然誤差の標準偏差が説明変数のすべての水準で一定でない場合、説明変数の各水準における分散に反比例する重みを持つ加重最小二乗値を用いることで、可能な限り最も正確な母数推定が得られる。

#### 加重最小二乗法の欠点
加重最小二乗法の最大の欠点は、多くの人が認識していない点であり、おそらくこの手法の背後にある理論が、重みが正確に既知であるという前提に基づいているという事実である。
実際の適用ではほとんど当てははまらないため、代わりに推定重みを使用しなければならない。
推定重みの使用による効果は評価が困難であるが、経験上、推定による重みのわずかな変動は回帰分析やその解釈にあまり影響しないことが示されている。
しかし、少数の再現された観測から重みが推定される場合、分析結果は非常に深刻かつ予測できない影響を及ぼす可能性がある。
これは、予測変数や説明変数の極端な値に対する重みが、わずかな観測だけで推定される場合に特に当てはまる。
この潜在的な問題を認識し続けることが重要であり、重みが互いに正確に推定できる場合にのみ、加重最小二乗法を使用することが重要である [[Carroll and Ruppert (1988), Ryan (1997)]](../section7/pmd7.md#Carroll,%20R.J.%20and%20Ruppert,%20D.%20%281988%29)

加重最小二乗回帰は、他の最小二乗法と同様に、外れ値の影響にも敏感である。
潜在的な外れ値を適切に調査し対処しない場合、母数推定や加重最小二乗法分析の他の側面に負の影響を及ぼす可能性がある。
加重最小二乗回帰が実際に外れ値の影響を高めてしまう場合、分析結果は非加重最小二乗分析に比べてはるかに劣る可能性がある。
