# 4.1.1. 工程のモデル化とは

#### 基本的定義
工程のモデル化とは、ある量 *y* の全変動を以下の成分に分割し簡潔に記述すしたものである。

1. 1つまたは複数の他の量 $`x_1, x_2, \ldots`$ の数学関数によって与えられる決定論的成分
2. 特定の確率分布に従う無作為成分

#### 例
例えば、タンク内の一定量の気体について測定された圧力の総変動は、その変動性を気体温度の関数である決定論的部分と、残された偶然誤差とに分けて記述することができる。
シャルルの法則によれば、ここで述べた条件下において気体の圧力はその温度に比例し、この場合変動の大部分は決定論的である。
しかし、圧力計の測定誤差により、この関係は純粋に決定論的とはならない。
偶然誤差は個別に特徴づけることはできないが、異なる大きさの誤差の相対的な発生頻度を表す何らかの確率分布に従うことになる。
（読者は、圧力・温度データを[テキストファイル](https://www.itl.nist.gov/div898/handbook/datasets/MODEL-4_4_4.DAT)としてダウンロードできる。）
