# 4.6.2. アラスカ・パイプライン

#### 不均質分散
この例では、アラスカのパイプラインの超音波校正データに対する線形回帰モデルの構築について説明する。
この事例研究では、偶然誤差の[標準偏差一定](../section2/pmd213.md)であるという仮定の違反に対処するための変形や加重回帰を用いる方法を示している。
この仮定は、誤差の等質分散であるとも呼ばれます。
