# 4.6.1.4. 残差のグラフ解析 - 初期モデル

#### 誤解を招く恐れのあるプロット
データに直線を当てはめた後、多くの人は、推定された回帰関数を重ね合わせたプロットを用いて、適合度を確認することを好む。
以下のプロットは、ロードセル・データについてこれを示したものである。
このプロットに基づくと、モデルに不備があるという明確な証拠はない。

![potentially misleading plot showing fitted line on data](https://www.itl.nist.gov/div898/handbook/pmd/section6/ldcll/plots/gra1a.r.gif)

#### 罠の避け方
この種の重合せプロットは、データと回帰関数による予測値との関係を示すのに有用であるが、モデルに関する重要な詳細が見えにくくなる可能性がある。
一方、残差のプロットはこうした詳細を明確に示し、適合度の良否を確認するために活用すべきである。
残差のグラフ分析は、モデル改良の必要性を判断したり、分析の基礎となる仮定が満たされていることを確認したりするための、最も重要な技法である。
 
このモデルでの関心事である残差プロットは以下を含む。

2. [残差と回帰関数値](../section4/pmd444.md)

次に、残差と負荷のプロットを示す。

#### 明らかになった隠れた構造
![a plot of residuals versus load revealing hidden structure](https://www.itl.nist.gov/div898/handbook/pmd/section6/ldcll/plots/gra1b.gif)

#### 凡例の尺度
残差と負荷量との関係に見られる構造は、モデルの関数部分が誤指定されていることを明確に示している。
データのプロットではこの問題を示さなかったのに対し、残差プロットではこの問題を明確に示したのは、両者のプロット間の尺度の違いによるものである。
応答の曲率は、線形トレンドよりもはるかに小さい。
したがって、データの尺度でプロットを表示すると曲率は隠れてしまう。
しかし、残差プロットのように線形トレンドを差し引くと、曲率が際立つようになる。

残差と予測された撓み値のプロットは、残差と負荷の最後のプロットと本質的に同じ構造を示す。
しかし、より複雑なモデルの場合、このプロットは、残差と予測変数のプロットだけでは明らかでない問題を明らかにすることがある。

#### 類似した残差構造
![plot of residuals vs. predicted deflection showing essentially the samestructure](https://www.itl.nist.gov/div898/handbook/pmd/section6/ldcll/plots/gra1c_f.gif)

#### 他の診断プロット
以下に、その他の残差診断プロットを示す。
これらのプロットには、実行順序プロット、遅延プロット、ヒストグラム、および正規確率プロットが含まれる。
このような 2×2の配列で示されたプロットは、データの 4-プロットから構成され、モデルの基礎となる仮定を確認する上で非常に有用である。

#### 4-プロット
![4-plot showing run order plot, lag plot, histogram, and normalprobability plot](https://www.itl.nist.gov/div898/handbook/pmd/section6/ldcll/plots/gra1d.gif)

#### プロットの解釈
これら残差プロットに見られる構造は、モデルのさまざまな側面における潜在的な問題も示唆する。
理想的な状況下では、上段のプロットには残差に系統的構造は現れないはずである。
ヒストグラムは対称的なベル型となり、正規確率プロットは直線となるはずである。
一見したところ、ここで見られる構造は、データに時間依存する傾向があり、測定値の自己相関があり、そして残差分布が正規分布ではないことを示唆している。

しかしながら、荷重と撓みの系統的関係を表す関数が修正されれば、これらのプロットは問題なく見える可能性が高い。
回帰モデルのひとつの側面に関する問題は、しばしば複数の種類の残差プロットに見られる。
したがって、現時点で、適切なモデルの残差分布が非正規、もしくは、工程の自己相関があるなどの明確な証拠は 4-プロットにはない。
しかしながら、モデルの関数部分を修正した後でも 4-プロットがこれらの問題を示すのであれば、問題が実在する可能性に対処する必要がある。
