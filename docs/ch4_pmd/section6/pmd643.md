# 4.6.4.3. データの初期プロット

#### データのプロット
非線形関数に当てはめる最初の手順として単にデータをプロットする。

![plot of original data shows initially step slope that levels off](https://www.itl.nist.gov/div898/handbook/pmd/section6/copper/plots/plot1_f.gif) 

このプロットでは、初期はかなり急な傾きが見られるが、その後、より緩やかな傾きになっていく。
この種の曲線は、多くの場合、有理関数モデルで近似することができる。

また、このプロットは、このデータに外れ値がある様には見えないことも示している。
