# 4.6.4.5. 3次/3次有理関数モデル

#### C/C言語の有理関数モデル
Q/Qモデルではデータを十分に説明できなかったため、次に、3次/3次（C/C）有理関数モデルを当てはめた。

[4.6.4.2](pmd642.md#StartingValues)で説明した手順に基づき、以下のモデルを当てはめた。

$$y = A_0 + A_1 x + A_2 x^2 + A_3 x^3 - B_1 x - B_2 x^2 - B_3 x^3 + \varepsilon $$

以下の代表点7つを用い、C/C有理関数の初期値を作成した。

```
 TEMP        THERMEXP
 ----        --------
  10             0
  30             2
  40             3
  50             5
 120            12
 200            15
 800            20
```

7点に対する事前線形適合から、係数は以下の通り。

```
A0 = -2.323648e+00  
A1 =  3.530298e-01
A2 = -1.383334e-02  
A3 =  1.766845e-04 
B1 = -3.395949e-02 
B2 =  1.100686e-04  
B3 =  7.910518e-06
```

#### 非線形適合の出力
C/Cモデルを当てはめた結果は以下の通り。

```
Parameter        Estimate    Stan. Dev    t Value
A0           1.07913        0.1710            6.3
A1          -0.122801       0.1203E-01      -10.2
A2           0.408837E-02   0.2252E-03       18.2
A3          -0.142848E-05   0.2610E-06       -5.5
B1          -0.576111E-02   0.2468E-03      -23.3
B2           0.240629E-03   0.1060E-04       23.0
B3          -0.123254E-06   0.1217E-07      -10.1

Residual standard deviation = 0.0818
Residual degrees of freedom = 229
```

回帰分析から、以下の推定モデルが得られた。

$$\hat{y} = \frac{1.079 - 0.122x + 0.004097x^{2} - 0.00000143x^{3}} {1 - 0.00576x + 0.000241x^{2} - 0.000000123x^{3}} $$

#### C/C 有理関数適合のプロット
生データを用いて、適合させた有理関数モデルのプロットを作成する。
![plot of C/C model appears to be a good fit](https://www.itl.nist.gov/div898/handbook/pmd/section6/copper/plots/ccfit_f.gif) 

生データを用いた適合関数は、妥当な適合を示しているように見える。 

#### モデルの妥当性確認の 6-プロット
生データを用いた適合関数のプロットは妥当な適合を示しているように見えるが、[モデルの仮定](../section2/pmd21.md)を検証する必要がある。
この目的には、[6-プロット](../../ch1_eda/section3/eda33x.md)が有効なツールである。

![6-plot of C/C model indicates no significant violation of assumptions](https://www.itl.nist.gov/div898/handbook/pmd/section6/copper/plots/cc6plo_f.gif) 

6-プロットには、モデルの仮定に対する重大な違反は見られない。
すなわち、誤差は位置と広がりが一定であるように見え（1行目2列目の残差プロットより）、無作為であるように（2行1列目の遅延プロットより）、かつ正規分布によく近似されている（2行2列目および3列目のヒストグラムと正規確率プロットより）ことが示唆されている。 

#### 残差プロット
より詳細を示すために、フルサイズの残差プロットを作成する。

![full-sized residual plot shows the pattern in the residuals more clearly](https://www.itl.nist.gov/div898/handbook/pmd/section6/copper/plots/ccres1_f.gif) 

フルサイズの残差プロットから、誤差の位置と広がりが一定という仮定が成り立っていることを示唆している。
残差に明確なパターンの証拠はない。 

#### 結論
3次／3次有理関数モデルが、実際にこのデータ集合に対して満足のいくモデルを与えると結論づける。
