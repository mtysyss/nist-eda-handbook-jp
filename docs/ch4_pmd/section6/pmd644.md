# 4.6.4.4. 2次／2次有理関数モデル

#### Q/Q 有理関数モデルの初期値
[4.6.4.2](pmd642.md#StartingValues)に記載された手順に基づき、以下のモデルを当てはめた。

$$y = A_0 + A_1 x + A_2 x^2 - B_1 x y - B_2 x^2 y + \varepsilon$$

以下の5つの代表点を用い、Q/Q有理関数の初期値を作成した。

```
Temp        THERMEXP
----        --------
 10             0
 50             5
120            12
200            15
800            20
```

5つの点に対する初期の線形近似から得られた係数は以下の通り。

```
A0 = -3.005450  
A1 =  0.368829 
A2 = -0.006828 
B1 = -0.011234 
B2 = -0.000306
```

#### 非線形適合の結果
非線形フィットの結果は以下の通り。

```
Parameter        Estimate    Stan. Dev      t Value
A0             -8.028e+00    3.988e-01       -20.13   
A1              5.083e-01    1.930e-02        26.33   
A2             -7.307e-03    2.463e-04       -29.67   
B1             -7.040e-03    5.235e-04       -13.45   
B2             -3.288e-04    1.242e-05       -26.47   

Residual standard deviation = 0.5501
Residual degrees of freedom = 231
```

この回帰分析から以下の推定モデルが得られた。

$$\hat{y} = \frac{-8.028 + 0.508x - 0.007307x^{2}} {1 - 0.00704x - 0.0003288x^{2}} $$

#### Q/Q 有利関数適合のプロット
生データを用いて、適合させた有理関数モデルのプロットを作成する。

![plot of Q/Q model appears to be a good fit](https://www.itl.nist.gov/div898/handbook/pmd/section6/copper/plots/qqfit_f.gif) 

生データを用いた推定関数を見ると、妥当な適合を示しているように見える。 

#### モデルの妥当性確認の 6-プロット
生データを用いた適合関数のプロットは一見すると妥当な適合を示しているように見えるが、[モデルの仮定](../section2/pmd21.md)の妥当性を確認する必要がある。
この目的には、[6-プロット](../../ch1_eda/section3/eda33x.md)が有効なツールである。

![6-plot of Q/Q model shows distinctive pattern in the residuals](https://www.itl.nist.gov/div898/handbook/pmd/section6/copper/plots/qq6plo_f.gif) 

残差と予測変数である温度とのプロット（行1、列2）および残差と予測値とのプロット（行1、列3）は、残差に明確なパターンがあることを示している。
これは、誤差が無作為であるという仮定に著しく違反していることを示唆している。 

#### 残差プロット
より詳細を示すためにフルサイズの残差プロットを作成する。

![full-sized residual plot shows the pattern in the residuals more clearly](https://www.itl.nist.gov/div898/handbook/pmd/section6/copper/plots/qqres1_f.gif) 

フルサイズの残差プロットは、残差に明確なパターンがあることをはっきりと示している。。
残差が明確にパターンを示す場合、対応する誤差はおそらく無作為ではない。
