# 4.6.2.3. 初期の線形近似

#### 線形近似の結果
データの初期プロットに基づき、まずデータに直線モデルを当てはめた。

 ```
Parameter     Estimate    Stan. Dev    t Value
B0             4.99368      1.12566       4.44
B1             0.73111      0.02455      29.78  
Residual standard deviation = 6.08092
Residual degrees of freedom = 105

Lack-of-fit F statistic              = 0.9857
Lack-of-fit critical value, F0.05,76,29 = 1.73
```

切片係数は 4.99368、傾き係数は 0.73111 と推定された。 
両方の係数は統計的に有意である。 

#### モデル妥当性確認の6-プロット
独立変数が1つの場合、[6-plot](../../ch1_eda/section3/eda33x.md)は初期モデルの妥当性の確認を行う上で便利な手法である。

![6-plot shows 6 different model validation plots](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/6plot1_f.gif)

回帰モデルの基本的な仮定は、誤差が、平均がゼロで標準偏差（または分散）が一定である正規分布に従う無作為な観測値である、というものである。

1行目のプロットは、独立変数（lab）の値が大きくなるにつれ、残差の分散が増加していることを示している。
これは、標準偏差が一定であるという仮定、均質分散性の仮定が満たされていないことを示している。

これをより明確に確認するために、データと残差を独立変数に対してプロットした予測値のフルサイズのプロットを作成する。 

#### 元データを載せた予測値のプロット

![plot of predicted values with raw data indicates problem with homogeneous variance assumption](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/fit1_f.gif) 

このグラフは、誤差分散の等分散の仮定に違反していることをより明確に示している。 

#### 独立変数に対する残差値のプロット

![plot of residuals versus independent variable shows non-homogeneous variances more clearly](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/res1_f.gif) 

このプロットも、均質分散性の仮定に違反していることをより明確に示している。
この仮定は、位置一定という仮定とともに、通常、このプロット上で最も確認しやすいものである。 

#### 不均質な分散
最後の図から、分散の差がわずか以上であることが判るため、この問題に対処するために、データを変換するか、重み付き最小二乗法を用いることにする。
