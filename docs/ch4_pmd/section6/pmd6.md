# 4.6. 工程モデル化の事例研究

#### 現実的な詳細例
本節では、物理科学および工学分野の応用でのデータを用いて、最初の5つの節で述べた一般的な要点を解説する。
各例は本文中で段階的に説明され、多くの場合、分析全般について解説している当該章の関連節と相互参照されている。
また、各解析は、適切な Dataplotマクロにリンクされたワークシートを使用し再現することも可能である。
このワークシートは、参照しやすいように本文で解説されている段階的な解析手順にもリンクされている。
