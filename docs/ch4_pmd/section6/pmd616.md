# 4.6.1.6. モデルの精緻化

これらのデータに対して直線モデルを除外した後、次の課題はデータの系統的な変動をより適切に記述できる関数を決定することである。

残差とすべての予測変数候補のプロットを比較検討することで、新しいモデルの選択に関する洞察を得ることができ、データのプロットが初期モデルの選択に役立つのと同様である。
このように選択された一連のモデルを繰り返すことで、データをよく記述する関数を導く。


#### 2次関数を示唆する残留構造
![residual structure that indicates perhaps a quadratic fit](https://www.itl.nist.gov/div898/handbook/pmd/section6/ldcll/plots/gra1b.gif)

残差と負荷のプロットにおける馬蹄形構造は、2次多項式がデータにうまく適合する可能性があることを示唆している。
それも最も単純な多項式モデルであるため、直線の次に考慮すべき関数である。
