# 4.6.2.2. バッチ効果の確認

#### 生データのプロット
他の回帰問題と同様、はじめに生データをプロットするのは常に良い方法である。
以下は、生データの[散布図](../../ch1_eda/section3/eda33q.md)である。

![scatter plot indicates a linear fit might be appropriate](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/plot1_f.gif) 

この散布図から、これらのデータに対して、直線近似が初期モデル候補として適していることを示している。 

#### バッチごとのプロット
これらのデータは、6つの異なるバッチに分けて収集された。
分析の最初の手順は、バッチ効果の有無の判断である。

この事例では、研究者は本来、バッチ自体には関心がなかった。
つまり、バッチは妨害要因であり、妥当であれば、データが単一バッチから得られたかのように分析したい。
しかし、これが実際に妥当な仮定であるかを確認する必要がある。 

#### 条件付きプロット
まず、バッチを条件とした[条件付きプロット](../../ch1_eda/section3/eda33qc.md)を作成する。
![conditional plot (on batch) does not show a batch effect](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/batch1_f.gif) 

この条件付きプロットは、1ページに6つのバッチの散布図それぞれを表示したものである。
これらのプロットはそれぞれ、似たパターンを示している。 

#### 線形相関と関連プロット
条件付きプロットに続いて、[線形相関プロット](../../ch1_eda/section3/eda33g.md)、[線形切片プロット](../../ch1_eda/section3/eda33h.md)、[線形傾きプロット](../../ch1_eda/section3/eda33i.md)、および[線形残差標準偏差プロット](../../ch1_eda/section3/eda33j.md)を作成する。
これら4つのプロットは、各バッチに適用された線形適合の相関、切片および傾き、残差標準偏差を示している。
これらのプロットは、6つのバッチ全体における線形近似の性能を示している。

![linear correlation, intercept, slope and ressd plots do not show any significant batch effect](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/batch2_f.gif)

現場と実験室での欠陥サイズの相関をバッチごとに示した線形相関プロット（左上）は、バッチ6において、他のバッチに比べて測定値間の線形関係がやや強いことを示している。
これは、残差標準偏差プロット（右下）に示されている、バッチ6の残差標準偏差が著しく低いことにも反映されており、このプロットは残差標準偏差とバッチの関係を示している。
線形傾きプロット（左下）では、すべての傾きが 0.6～0.9 の範囲内にあり、線形切片プロット（右上）では、すべての切片が 2～8 の範囲内にある。 

#### 均質とみなすバッチ
これらの要約プロットは、前述の条件付きプロットと併せて見ると、データを単一バッチとして扱うことが妥当な仮定であることを示している。
どのバッチも他のバッチと比べて著しく異常な挙動を示すことはなく、また、他のバッチとは著しく異なる適合を必要とするバッチもない。

これら2つのプロットは互いに補完し合う良い組合せである。
適合統計量のプロットは、全体的な適合度を迅速かつ手軽に比較することを可能にする。
しかし、条件付きプロットは、要約プロットでは見落とされがちな詳細を明らかにすることができる。
例えば、点のまとまりや外れ値の存在、データの曲率、および他の類似した特徴をより容易に特定することができる。

これらのプロットに基づき、残りの分析ではバッチ変数を無視することにする。
