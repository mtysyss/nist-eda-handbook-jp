# 4.6.1.5. 数値出力の解釈 - 初期モデル

#### 不適合度統計量の解釈
残差プロットが、データの系統的変動を表す関数の仕様には明らかに問題があることを示していることは、この適合から得られた数値結果の大部分を検討してもほとんど無意味であることを意味する。
しかし、データには繰り返し測定が含まれているため、不適合検定をモデル検証の一環として利用することもできる。
以下に、適合の数値結果を示する。

#### 回帰の結果
```
Parameter       Estimate    Stan. Dev    t Value
B0          0.614969E-02   0.7132E-03        8.6
B1          0.722103E-06   0.3969E-09   0.18E+04

Residual standard deviation = 0.0021712694
Residual degrees of freedom = 38

Lack-of-fit F statistic              = 214.7464 
Lack-of-fit critical value, F0.05,18,20 = 2.15
```

#### 関数の不具合
不適合検定の検定統計量 214.7464 は、モデルの関数部分が適切ではないことを明確に示している。
有意水準 0.05 の検定における境界値は 2.15 である。
この値が臨界値を上回る場合、このデータに対する直線モデル仮説は棄却されるべきであることを示している。
