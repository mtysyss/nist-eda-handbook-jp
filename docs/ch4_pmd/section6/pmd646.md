# 4.6.4.6. 自分で解いてみる

#### このケーススタディのデータプロットマクロを表示する
このページでは、前のページの事例研究の説明で概説された分析を、[Dataplot](https://www.itl.nist.gov/div898/software/dataplot/homepage.md) を使用して再現することができます。
ただし、[Dataplot を](https://www.itl.nist.gov/div898/software/dataplot/ftp/homepage.md)[ダウンロードして](https://www.itl.nist.gov/div898/software/dataplot/ftp/homepage.md)インストール済みである必要がある。
以下の各分析手順からの出力結果は、1つまたは複数の Dataplot ウィンドウに表示されます。
主なウィンドウは、「出力ウィンドウ」、「グラフィックスウィンドウ」、「コマンド履歴ウィンドウ」、および「データシートウィンドウ」の4つである。
各メインウィンドウの上部には、Dataplotのコマンドを実行するためのメニューがある。
下部には、コマンドを入力できるコマンド入力ウィンドウがある。

#### 以下のリンクをクリックして、
Dataplot を起動し、この事例研究を実際に実行してください。
各手順では、前の手順の結果が使用される場合がありますので、しばらくお待ちください。
ソフトウェアが現在の手順が完了したことを確認するまで待ってから、次の手順をクリックしてください。
*この欄のリンク* *をクリックすると、事例研究の説明にある各分析手順に関するより詳細な情報をご覧いただけます。
