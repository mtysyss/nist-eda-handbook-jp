# 4.6.3.4. 適合を改善するための重み付け

#### 重み付け
誤差分散一定という仮定が成り立たないときの別の方法として、[加重適合](../section1/pmd143.md)を行う。
加重適合では、モデル内の未知係数を推定するときに、精度の低い測定値には低い重みを、精度の高い測定値には高い重みを割り当てる。

#### 適切な重み関数の選定
適切な重み関数を決定するための技法については、[4.4.5.2節](../section4/pmd452.md)で詳細に議論した。

この場合、データには反復が含まれているため、[冪乗モデル](../section4/pmd452.md#pfm)
 
$$\begin{eqnarray}
\ln{(\hat{\sigma}_i^2)} & = & \ln{(\gamma_1x_i^{\gamma_2})} \\
& = & \ln{(\gamma_1)} + \gamma_2\ln{(x_i)}
\end{eqnarray} $$

をデータ内の各反復集合の分散に当てはめ、重みとして次を用いる。

$$w_i = \frac{1}{x^{\hat{\gamma}_2}_i} $$

#### 重み推定の適合
反復群について、ln(分散)をln(平均)に対してプロットし、以下の結果が得られた。

```
Parameter       Estimate    Stan. Dev    t Value
γ0                2.5369       0.1919       13.1
γ1               -1.1128       0.1741       -6.4

Residual standard deviation = 0.6099
Residual degrees of freedom = 20
```

![plot of replicated variance against relicated means with fit](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/wtfunc_f.gif) 

反復分散と反復平均のプロットおよび適合の出力から、線形適合が妥当な適合を示しており、推定傾きは -1.1128 である。

この適合に基づき、加重関数の指数として -1.0 の推定値を用いた。 

#### 重み関数の残差プロット
![plot of residual values from fit for estimating weights reveals no obvious problems](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/wtres_f.gif) 

適切な加重関数を決定するための適合の残差プロットには明らかな問題は見られない。 

#### 加重適合の数値結果
加重適合の結果は以下の通り。

```
Parameter       Estimate    Stan. Dev    t Value
b1              0.146999   0.1505E-01        9.8
b2              0.005280   0.4021E-03       13.1
b3              0.012388   0.7362E-03       16.8

Residual standard deviation = 4.11
Residual degrees of freedom = 211
```

#### 予測値のプロット
加重適合の品質を評価するために、まず予測直線と元データのプロットを作成する。

![plot of predicted values with raw data indicates a good fit](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/fit3_f.gif) 

予測値とデータのプロットは良好な適合を示している。
加重適合のモデルは次式である。

$$\hat{y} = \frac{\exp(-0.147x)}{0.00528 + 0.0124x} $$ 

#### 適合の 6-プロット
![6-plot indicates regression assumptions satisfied](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/6plot3_f.gif) 

加重モデルが回帰の仮定に違反していないことを確認する必要がある。
6-プロットは回帰の仮定が満たされていることを示している。 

#### 残差のプロット
![plot of residuals versus predictor variable shows homogeneous variances for residuals](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/res3_f.gif) 

等誤差分散の仮定をより詳細に確認するために、残差と予測変数をフルサイズ版で作成した。
このプロットは、残差のばらつきがほぼ等しくなっていることを示唆している。
