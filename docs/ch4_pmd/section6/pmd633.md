# 4.6.3.3. 適合を改善するための変換

#### 変換
不均質分散の問題に対する一つの方法はデータに変換を適用することである。

#### 均質な分散を得るための一般的変換のプロット
最初の手順として、応答変数に対し、均質分散になる変換を試みる。
実際には、平方根、ln、および逆数への変換がこの目的にはよく機能する。
まずはこれらを試してみる。

![plot of transformations indicates square root transformation is best](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/transf1_f.gif) 

これらプロット4つの検討では、金属距離の値に渡り、超音波応答のばらつきが最も一定であるプロットを探す。
これらプロットの尺度は大きく異なり、比較が困難に見えるが、ここではプロット間のばらつきの絶対水準を比較しているわけではない。
その代わり、これらプロット4つにおいて、各プロット内の変動がいかに一定であるかだけを比較する。
変動が最も一定であるプロットが、どの変換が最適かを示す。

残差変動の一定性に基づくと、このデータには平方根変換が最も適していると考えられる。 

#### 予測変数に対する一般的変換のプロット
応答変数を変換した後、予測変数も同様に変換しておくと役立つことがよくある。
実際には、平方根と、ln、逆数への変換が、この目的にはよく機能する。
まずはこれらを試してみる。

![plot of transformations indicates transformations do not improve the situation](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/transf2_f.gif) 

このプロットは、提案された変換のいずれも、生の予測変数を用いる場合に比べて改善が見られないことを示している。 

#### 平方根適合
上記のプロットに基づき、応答変数には平方根変換を適用し、予測変数には変換を適用しないモデルを選択する。

```
Parameter     Estimate    Stan. Dev    t Value
b1          -0.0154326   0.8593E-02       -1.8
b2           0.0806714   0.1524E-02       53.6
b3           0.0638590   0.2900E-02       22.2
  
Residual standard deviation = 0.29715
Residual degrees of freedom = 211
```

残差の標準偏差は元の適合よりも小さくなっているが、当てはめが異なる尺度で行ったため、これらを直接比較することはできない。

#### 予測値のプロット
![plot of predicted values with raw data](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/fit2_f.gif) 

変換されたデータを用いた予測値のプロットは良好な適合を示している。
適合されたモデルは次式である。

$$\widehat{\sqrt{y}} = \frac{\exp(-0.015x)} {0.0807 + 0.0639x} $$ 

#### 適合の6-プロット
![6-plot indicates fit assumptions satisfied](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/6plot2_f.gif)

データを変換したため、回帰分析の仮定がすべて依然として成立しているかを確認する必要がある。

このモデルを用いたデータの 6-プロットからは仮定に対する明らかな違反は見られない。 

#### 残差のプロット
![plot of residuals versus predictor variable shows homogeneous variances for residuals](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/res2_f.gif) 

より詳細を確認するために、残差と予測変数のプロットをフルサイズで作成する。
このプロットは、今度は、誤差がの均質分散性の仮定を満たしていることが示唆される。
