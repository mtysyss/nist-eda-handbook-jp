# 4.6.2.1. 背景とデータ

#### データ収集に関する説明
アラスカ・パイプラインのデータは、アラスカ・パイプラインの欠陥深さを現場で超音波により測定したものである。
その後、欠陥の深さは実験室で再測定された。
これらの測定は、6つの異なるバッチで行われた。

このデータを用いて、実験室での測定値に対する現場測定値の偏りを校正するための解析が行われた。
この解析において、現場測定値は応答変数であり、実験室測定値は予測変数である。

これらのデータは、当時、NISTの材料研究研究所（現・材料科学・工学研究所）所長室に所属していた Harry Berger から提供された。
これらのデータは、米国運輸省材料輸送局のために実施された研究に使用された。

#### ソフトウェア
本事例研究で使用された分析は、[Dataplotコード](https://www.itl.nist.gov/div898/handbook/pmd/section6/pmd621.dp)および[Rコード](https://www.itl.nist.gov/div898/handbook/pmd/section6/pmd621.r)の両方を使用して再現することができる。
読者は、データを[テキストファイル](https://www.itl.nist.gov/div898/handbook/datasets/BERGER1.DAT)としてダウンロードすることができる。
