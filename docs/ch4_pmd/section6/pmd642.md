# 4.6.4.2. 有理関数モデル

事例研究に入る前に、有理関数モデルの説明がいくつか必要である。

#### 多項式関数
多項式関数とは次の形をもつ関数のことである。

$$f(x) = a_{n}x^{n} + a_{n-1}x^{n-1} + ... + a_{2}x^{2} + a_{1}x + a_{0}$$

ここで、$`n`$ は多項式の<u>次数</u>を決める非負の整数を表す。
次数が 0 の多項式は単に定数であり、次数が 1 のものは直線、次数が 2 のものは1次関数、次数が 3 のものは3次関数というように続く。

#### 有理関数
有理関数とは単に2つの多項式関数の比であり、

$$f(x) = \frac{a_{n}x^{n} + a_{n-1}x^{n-1} + ... + a_{2}x^{2} + a_{1}x + a_{0}} {b_{m}x^{m} + b_{m-1}x^{m-1}+ ... + b_{2}x^{2} + b_{1}x + b_{0}}$$

ここで、$`n`$ は分子の次数を決める非負の整数であり、$`m`$ は分母の次数を決める非負の整数である。
有理関数モデルを適合する場合、分母の定数項を通常 1 に設定する。

有理関数は通常、分子と分母の次数によって識別される。
例えば、分子が2次、分母が3次である場合は、2次／3次有理関数として識別される。
[一般的な有理関数のグラフのいくつか](../section8/pmd8.md)を付録に示している。 

#### 多項式モデル
歴史的には、多項式モデルは関数の適合に最も頻繁に用いられてきた経験的モデルの一つである。
これらのモデルが広く用いられているのは以下の理由に拠る。

1. 多項式モデルは形式が単純である。
2. 多項式モデルは、性質がよく知られ、理解されている。
3. 多項式モデルは、形状の柔軟性が適度にある。
4. 多項式モデルは閉じた族である。
生データの位置や広がりの変化がある場合、ある多項式モデルから別の多項式モデルに写像される。
つまり、多項式モデルは基礎となる計量に依存しない。
5. 多項式モデルは計算処理が容易である。

しかし、多項式モデルには以下の制限もある。

1. 多項式モデルは補間特性に乏しい。
高次多項式は、正確に適合した値の間で振動が生じやすいことで悪名高い。
2. 多項式モデルは外挿特性に乏しい。
多項式はデータの範囲内では良好な適合を示す場合があるが、データの範囲外では適合度が急速に低下することが多い。
3. 多項式モデルは、漸近的な性質が劣る。
その性質上、多項式は有限の $`x`$ 値に対しては有限の応答を示し、$`x`$ 値が無限大である場合にのみ無限の応答を示す。
したがって、多項式では 漸近的な現象を十分にモデル化できない場合がある。
4. 多項式モデルには、形状と次数の妥協点がある。
複雑な構造を持つデータをモデル化するためには、モデルの次数を高くする必要があり、推定すべき係数の数も多くなる。
その結果、非常に不安定なモデルに繋がることがある。

#### 有理関数モデル
有理関数モデルは多項式モデルの一般化である。
有理関数モデルには、多項式モデルが部分集合として含まれる（すなわち、分母が定数である場合）。

上記制限のいずれかにより、多項式モデルによるモデル化が不十分な場合は、有理関数モデルを検討すべきである。 

#### 利点
有理関数モデルには以下の利点がある。

1. 有理関数モデルは適度に単純な形式を持っている。
2. 有理関数モデルは閉じた族である。
これは多項式モデルと同様に、有理関数モデルが基礎となる計量に依存しないことを意味する。
3. 有理関数モデルは極めて幅広い形状をとることができ、多項式族よりもはるかに広い範囲の形状に対応できる。
4. 有理関数モデルは、多項式モデルよりも優れた補間特性を有する。
有理関数は通常、多項式モデルよりも滑らかで振動が少ない。
5. 有理関数は優れた外挿能力を持っている。
有理関数は通常、データの定義域内だけでなく、関心のある定義域の外側における理論的／漸近的な挙動にも一致するように、関数をモデル化できるように調整可能である。
6. 有理関数モデルは優れた漸近的性質を持っている。
有理関数は、有限の $`x`$ 値に対しては有限または無限となり、無限の $`x`$ 値に対しては有限または無限となる場合がある。
したがって、有理関数は容易に有理関数モデルに組み込むことができます。
7. 有理関数モデルは、多くの場合、分子と分母の両方で比較的低い次数で複雑な構造をモデル化するために使用できる。
これはひいては、多項式モデルと比較し、必要な係数の数が少なくて済むことを意味する。
8. 有理関数モデルは計算処理の面で比較的扱いやすい。
非線形モデルではあるが、有理関数モデルは特に適合が容易な非線形モデルの一つである。

#### 欠点
有理関数モデルには以下の欠点がある。

1. 有理関数族の性質は、多項式族の性質ほど、技術者や科学者によく知られていない。
また、有理関数族に関する文献も限られている。
この族の性質は十分に理解されていないことが多く、以下のモデル化に関する質問に答えるのは難しい場合がある。
    データが特定の形状を示している場合、分子の次数と分母の次数にはどのような値を選択すべきか？ 
2. 制約のない有理関数による適合では、分母多項式の根に起因した望ましくない（垂直な）不都合な漸近線が得られることがある。
関数の「発散」する影響を受ける $`x`$ の範囲は極めて狭い場合もあるが、それが発生すると、漸近点近傍での局所的な補間において障害となる。
これらの漸近線は、データ範囲全体に渡り適合関数を単純にプロットすることで容易に検出できる。
このような漸近線があっても、経験的モデル化の選択肢として有理関数モデルを検討することをためらう必要はない。
こうした厄介な漸近線は時折、予測不能に発生するが、形状の柔軟性が向上する利点がそれらが発生するリスクを十分に上回る価値がある。

#### 有理関数モデルの初期値
非線形モデルの当てはめにおいて適切な初期値を見つけることは、よく見られる難点の一つである。
有理関数モデルの大きな利点は、線形最小二乗法を用いて初期値を計算できることである。

これを行うには、データ集合から $`p`$ 個の点を選ぶが、$`p`$ は有理モデルの母数の数を表す。
例えば、次の線形/二次モデルが与えられた場合、

$$\frac{A_0 + A_1x} {1 + B_1x + B_2x^{2}}$$

4つの代表的な点を選択する必要がある。

次に、以下のモデルに対して線形近似を行う。

$$y = A_0 + A_1x + ... + A_{p_n}x^{p_n} - B_1xy - ... - B_{p_d}x^{p_d}y + \varepsilon$$

ここで、$`p_n`$ および $`p_d`$ はそれぞれ分子と分母の次数であり、$`x`$ および $`y`$ にはデータ集合全体ではなく、点の部分集合が含まれる。
この線形適合から推定された係数は、データ集合全体に対する非線形モデルの当てはめを行うときの初期値として用いる。

**注：**応答変数が関数の両側に現れるこの種の適合は、非線形適合の初期値を得るために**のみ**使用すべきである。
このような適合の統計的性質については、十分に解明されていない。

点の部分集合はデータの範囲内で選択する必要がある。
どの点を選択するかはそれほど重要ではないが、明らかな外れ値は避けるようにする。
