# 4.6.2.4. 適合を改善し、分散を均一化するための変換

#### 変換
回帰のモデル化では、以下の2つの目的を達成するためにしばしば変形を適用する。

1. 誤差項に対する均質分散性の仮定を満たす
2. 可能な限り、推定結果を線形化する

これら2つの目標は相反する可能性があるため、ある程度の注意と判断が求められる。
一般的には、まず均質分散性を満たすことを優先し、その後で推定の線形化に取り組む。

#### 均質な分散を得るための一般的変換のプロット
まず、応答変数を変換して、分散を均質化する変換を見つけることから始める。
実際には、平方根、ln、および逆数による変換がこの目的でよく機能する。
まずはこれらを試してみよう。

![plot of transformations indicates ln transformation is best](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/transf1_f.gif) 

これらのプロットを検証するとき、プロットの水平方向の範囲全体に渡りばらつきが最も一定であるプロットを探す。

このプロットは、分散を最も均一にするために、ln変換が有力なモデル候補であることを示している。 

#### 適合の線形化のための一般的変換のプロット
上記の変換を適用する問題の一つは、直線の当てはめがもはやデータに対する適切なモデルではないことがプロットに示されている点である。
この問題に対処するため、最も線形適合が得られるような予測変数の変換を見つけることを試みる。
実際には、平方根、ln、および逆変換がこの目的にはしばしば有効である。
まずこれらを試す。

![plot of transformations indicates ln transformation is best](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/transf2_f.gif) 

このプロットは予測変数のln変換が有力なモデル候補であることを示している。 

#### Box-Cox線形プロット
前の手順は、[Box-Cox線形](../../ch1_eda/section3/eda335.md)プロットを用いて、より形式的に検討する。
y軸上の最大相関係数に対応する x軸上の α 値は、最も直線的な適合が得られる冪乗変換を示している。

![Box-Cox plot shows a value of approximately -0.1 achieves the most linear fit](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/transf3_f.gif) 

このプロットによると、-0.1 という値で最も直線的な適合が得られることを示している。

実際には、解釈を容易にするため、数学的な最大値を与える値ではなく、lnや平方根といった一般的な変換を用いることが好まれることが多い。
しかし、Box-Cox線形プロットは、その選択が妥当であるかを依然として示している。
つまり、より単純なモデルに当てはめるために、適合の直線性をわずかに犠牲にすることもある。

この場合、値が 0.0 であれば ln変換が示唆される。
プロットから得られる最適値は -0.1 であるが、プロットから -0.2 から 0.2 までの間のどの値でも、ほぼ同様の結果が得られることが示されている。
そのため、ここでは一般的な ln 変換を採用することにする。 

#### ln-ln 適合
上記のプロットに基づき、ln-lnモデルを適合させることにした。

```
Parameter     Estimate    Stan. Dev    t Value
B0            0.281384      0.08093       3.48
B1            0.885175      0.02302      38.46
  
Residual standard deviation = 0.168260
Residual degrees of freedom = 105

Lack-of-fit F statistic              = 1.7032
Lack-of-fit critical value, F0.05,76,29 = 1.73
```

なお、残差の標準偏差は元の適合結果に比べて有意に小さいが、適合が異なる尺度で行われたため、これらを直接比較することはできない。

#### 予測値のプロット
![plot of predicted values with raw data](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/fit2_f.gif) 

変換されたデータを用いた予測値のプロットは良好な適合を示している。
さらに、プロットの水平範囲にわたるデータのばらつきは比較的一定であるように見える。

![6-plot indicates regression assumptions satisfied](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/6plot2_f.gif)

残差の6-プロットを見ると、すべての回帰の仮定が満たされていることが判る。
