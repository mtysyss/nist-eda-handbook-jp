# 4.6.1.2. 初期モデルの選定

#### シンプルに始める
データを分析す最初の手順は、候補となるモデルの選択である。
このような測定システムの場合、荷重とロードセルの応答との関係は比較的単純な関数で記述できるはずである。
効果的な測定システムの特徴の一つとして、計測器の応答と定量化される特性との間に明確な関連性がある。

#### データのプロット
データをプロットすると、荷重と撓みの間に仮定された単純な関係が妥当であることが示唆される。
以下のプロットはそのデータを示している。
このプロットから直線モデルがデータに適合する可能性が高いことが示唆される。
また、外れ値の存在や応答の標準偏差が一定でないといった、その他の問題は見られない。
