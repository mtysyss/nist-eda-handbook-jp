# 4.6.2.6. 適合の比較

#### 適合3つの比較
3つの当てはめの結果を比較してみると興味深い。

1. 非加重適合
2. 変換適合
3. 加重適合

#### データと適合のプロット
![weighted and transformed fits smaller predicted values for lower values of defect size, larger predicted values for larger values of defect size](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/comp_f.gif) 

このプロットは、元の適合と比較し、変換および加重適合では、実験室での欠陥サイズが小さい場合には予測値が小さくなり、実験室での欠陥サイズが大きい場合には予測値が大きくなることを示している。
実験室での欠陥サイズが中程度の値については、3つの適合の結果はかなりよく一致している。
変換および加重適合は、実験室での欠陥サイズが小さい値の範囲では一致する傾向がある。
しかし、実験室での欠陥サイズが大きい値の範囲では、加重適合は変換後の適合に比べ、予測値が高くなる傾向がある。 

#### 結論
当初の当てはめは悪くなかったが、誤差項の均質分散性の仮定に違反していた。
変換したデータの推定と加重推定のいずれも、他の回帰の仮定に違反することなく、この問題をうまく解決している。
