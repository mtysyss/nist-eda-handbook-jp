# 4.6.3.2. 初期の非線形適合

#### データのプロット
非線形関数に当てはめる最初の手順は、単にデータをプロットすることである。

![plot of original data shows an exponentially decaying pattern](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/plot1_f.gif) 

このプロットはデータが指数関数的に減少する傾向を示している。
これは、何らかの指数関数がデータの適切なモデルとなり得ることを示唆している。 

#### 初期モデル選択
非線形モデルを当てはめる初期モデル選択において、対処すべき課題が2つある。

1. モデルに適した関数形を決定する必要がある。
2. モデル係数の推定に適切な初期値を決定する必要がある。

#### モデルに適切な関数形の決定
非線形モデルに使用できる関数の候補は非常に多いため、適切なモデルを決定することは必ずしも明確ではない。
いくつかの[適切なモデル選択の指針](../section4/pmd42.md)を分析の章で紹介している。

データのプロットから、よく知られた関数が示唆されることはよくある。
さらに、適切なモデルの決定には、科学と工学の知識を活用することもよくある。
科学的研究では、理論的なモデルをデータに当てはめることに関心があることが頻繁にある。
また、過去における同様のデータにうまく適合した関数の既存研究（自身のデータまたは公表された研究）から得た過去の知見を持っていることもよくある。
理論的モデルや過去のデータ集合に関する経験がない場合、適切な関数を選択するにはしばしばある程度の試行錯誤が必要である。

モデル選択において科学的知識を活用するかに関わらず、選択したモデルが適切であるかを判断するには、[モデルの妥当性確認](../section4/pmd44.md)は依然として不可欠である。 

#### 適切な初期値の決定
非線形モデルは反復法て当てはめられるが、これには初期値が必要である。
場合によっては、不適切な初期値を設定すると、推定された係数が大域の最小値や最大値ではなく、局所的な最小値や最大値に収束してしまうことがある。
モデルによっては、初期値の選択に対して比較的鈍感なものもあれば、極めて敏感なものもある。

類似のモデルに適合した過去データ集合があれば、それらを適切な初期値を決めるための指針として利用できることが多い。
また、モデルの関数形から、経験に基づいた推測を行うこともできる。
モデルによっては、初期値を決定するための特定の方法が存在することがある。
例えば、時系列分析で一般的に使用される正弦波モデルは、適切な初期値に対して非常に敏感である。
[梁の撓み事例研究](eda425.md)では、正弦波モデルの初期値を求める例が示されている。

適切な初期値が何であるかが分からない場合、一つの方法として、モデルの各係数値の格子を作成し、その格子上の各点で残差標準偏差などの適合度の指標を計算する方法がある。
その考え方は、係数の妥当な値を含む広い格子を作成することである。
ただし、計算負荷を抑えるため（特にモデル内の係数数が増えるにつれて）、各係数の格子点数は比較的少なく抑えるのが一般的である。
ここでの考え方は、最適な適合を見つけることではなく、適切な近傍に収めることである。
そこで、初期値として残差標準偏差が最小となる格子点を選択する。 

#### 理論モデルへのデータの適合
この特定のデータ集合について、科学者は以下の理論モデルに適合させようとしていた。

$$y = \frac{\exp(-b_1 x)} {b_2 + b_3 x} + \varepsilon $$

理論モデルがあるため、これを初期モデルとして用いる。
3つの係数すべてについて、初期値を 0.1 に設定する。

#### 非線形適合の結果
非線形適合の結果は以下の通り。

```
Parameter     Estimate    Stan. Dev    t Value
b1            0.190279   0.2194E-01        8.6
b2            0.006131   0.3450E-03       17.8
b3            0.010531   0.7928E-03       13.3
  
Residual standard deviation  = 3.362
Residual degrees of freedom  = 211
```

#### 予測値と元データのプロット
![plot of predicted values with raw data](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/fit1_f.gif) 

このプロットは、かなり良好な適合を示している。
このプロットからは適合の仮定に違反する点を見つけるのは難しい。
推定されたモデルは次式である。
 
$$\hat{y} = \frac{\exp(-0.190x)} {0.00613 + 0.0105x} $$ 

#### モデルの妥当性確認のための6-プロット
独立変数が1つの場合、[6-プロット](../../ch1_eda/section3/eda33x.md)は、初期モデルの妥当性を確認するために便利な手法である。

![6-plot shows 6 different model validation plots, residuals do not show constant variance](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/6plot1_f.gif) 

回帰モデルの基本的な仮定は、誤差が、平均がゼロで標準偏差（または分散）が一定である正規分布に従う無作為な観測値である、というものである。

これらのプロットからは、誤差分散が一定ではないことが示唆される。

これをより明確に確認するために、モデルから予測された値のフルサイズのプロットを作成し、データを重ね合わせ、残差を独立変数である金属距離に対してプロットする。 

#### 独立変数に対する残差値のプロット
![plot of residuals versus independent variable shows non-homogeneous](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/res1_f.gif) 

このグラフからは、金属距離が 1未満の値において、誤差分散が他の範囲よりも大きいことが示唆される。
つまり、均質分散性の仮定が成り立っていないようである。 

#### 不均質分散
ただし、金属距離が1以下の場合を除き、誤差分散に違いがあるという確固たる証拠はない。
とはいえ、この問題を解消できるかを確認するために、変換や加重適合を試みる。
