# 4.6.3.5. 適合の比較

#### 適合3つの比較
適合の結果3つを比較してみると興味深い。

1. 非加重適合
2. 変換適合
3. 加重適合

#### データと適合のプロット
適合比較における最初の手順として、予測値3つの集合すべてを（元の単位で）、生データと同じプロット上にプロットする。

![all three fits are similar](https://www.itl.nist.gov/div898/handbook/pmd/section6/ultrason/plots/comp_f.gif) 

このプロットは適合3つすべてが同程度の予測値を出力していることを示している。
また、適合の残差標準偏差（RESSD）を比較する。
変換済みデータの RESSD は、予測値を元尺度に戻し計算する。

```
RESSD From Unweighted Fit  = 3.361673
RESSD From Transformed Fit = 3.306732
RESSD From Weighted Fit    = 3.392797
```

この場合、3つの適合すべてにおいて RESSDは非常に近い値である（これはプロットから予想される）。 

#### 結論
変換および加重適合は、元の適合に非常に近い予測値を出力していることから、なぜわざわざ手間をかけて変換や加重適合を行う必要があるか？
そうするのは、非線形モデルを推定するための[モデルの仮定](../section2/pmd21.md)を満たすモデルを構築するためである。
これにより、そのモデルに基づく結論や分析が正当かつ適切であるという確信をより強めることができる。
