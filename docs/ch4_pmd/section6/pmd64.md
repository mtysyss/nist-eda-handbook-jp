# 4.6.4. 銅の熱膨張の事例研究

#### 有理関数モデル
この事例研究では、有理関数モデルと呼ばれる一種の非線形モデルの活用を示している。
使用したデータ集合は、温度に関連した銅の熱膨張に関するものである。

このデータ集合は、NISTの科学者 Thomas Hahn から提供されたものである。
