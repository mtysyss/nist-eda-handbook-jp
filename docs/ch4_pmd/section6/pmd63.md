# 4.6.3. 超音波参照ブロックの研究

#### 不均質分散の非線形近似
この例では、超音波校正データに対する非線形回帰モデルの構築について解説する。
この事例研究では、非線形モデルの当てはめ、および誤差の[標準偏差一定](../section2/pmd213.md)の仮定に対する違反に対処する、変換と加重当てはめの利用について解説する。
この仮定は、誤差の等質分散性とも呼ばれる。
