# 4.6.2.5. 適合を向上させるための重み付け

#### 重み付け
誤差の標準偏差一定の仮定（すなわち、等質分散性）に違反しているときの別の方法として、[加重適合](../section1/pmd143.md)を行う。
加重推定では、モデル内の未知係数を推定するときに、精度の低い測定値には低い重みを、精度の高い測定値には高い重みを割り当てる。

#### 重さ推定の当てはめ
パイプラインのデータについては、各群に4つの観測値を含むよう（最後のグループのみ3つ）に[近似的反復群](../section4/pmd452.md#arg)を選択した。
これを行うには、まず予測変数でデータを並べ替え、次に4つの点を連続して抽出し、各反復群を作成した。

重み推定にデータを用いた[冪乗関数モデル](../section4/pmd452.md#pfm)を適用し、反復群について ln(分散)対 ln(平均)の適合に関して以下の結果を得た。

```
Parameter     Estimate    Stan. Dev    t Value
B0            -3.18451       0.8265       -3.9
B1             1.69001       0.2344        7.2

Residual standard deviation = 0.85612
Residual degrees of freedom = 25
```

![plot of replicated variance against relicated means with fit](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/wtfunc_f.gif)

数値適合結果および反復分散と反復平均のプロットから、線形適合が妥当な適合を示し、推定傾きは 1.69 が得られた。

重み付け関数の指数は推定値 1.5 を用いた。 

#### 重み関数の残差プロット
![plot of residual values from fit for estimating weights reveals no obvious problems](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/wtres_f.gif) 

適切な重み付け関数を決定するための適合の残差プロットには、明らかな問題は見られない。 

#### 重み付き適合の数値結果
現場測定値と実験室測定値を関連付けるモデルの加重適合は、以下の通り。

```
Parameter     Estimate    Stan. Dev    t Value
B0             2.35234      0.54312        4.3
B1             0.80636      0.02265       35.6

Residual standard deviation = 0.36459
Residual degrees of freedom = 105
```

結果として得られた傾きと切片は、それぞれ 0.81 および 2.35 である。
これらを[元のモデル](../section6/pmd623.md)における傾き 0.73 および切片 4.99 と比較する。

#### 予測値のプロット
![plot of predicted values with raw data indicates a good fit](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/fit3_f.gif) 

予測値とデータのプロットから良好な一致が示されている。 

#### 重み付き残差の診断プロット
![6plot indicates regression assumptions satisfied](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/6plot3_f.gif) 

重み付けによって、その他の回帰の仮定に違反していないことを確認する必要がある。
残差に重み付けを行った後の 6-plotは、回帰の仮定が満たされていることを示している。 

#### 加重残差とラボ欠陥サイズの関係図
![plot of weighted residuals versus predictor variable shows homogeneous variances for residuals](https://www.itl.nist.gov/div898/handbook/pmd/section6/pipeline/plots/res3_f.gif) 

誤差の等質分散性の仮定をより詳細に確認するため、重み付き残差と予測変数をプロットしたフルサイズのプロットを作成した。
このプロットから、誤差は等質分散性であることが示唆される。
