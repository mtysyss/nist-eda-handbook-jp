# 4.4.4.5. 偶然誤差の正規分布検定

#### 正規性確認に用いられるヒストグラムと正規確率プロット
[ヒストグラム](../../ch1_eda/section3/eda33e.md)および[正規確率プロット](../../ch1_eda/section3/eda33l.md)は、工程に内在する偶然誤差が正規分布に従うと仮定することが妥当かどうかを検証するために用いられる。
この[正規性の仮定](../section2/pmd214.md)は、工程に関する意思決定を行うときに許容できる誤り率を定めるために必要となる。
もし偶然誤差が正規分布に従わない場合、推論において規定された信頼水準が示す頻度よりも多かれ少なかれ、誤った決定が下されることになる。

#### 正規確率プロット
正規確率プロットは、残差の値を並べ替えて、標準正規分布に基づく対応する理論値に対してプロットし作成する。
しかし、ほとんどの残差散布図とは異なり、この場合、点の無作為な散らばりは、確認する仮定が満たされていることを示すものではない。
その代わりに、もし偶然誤差が正規分布に従っているならば、プロットされた点は直線に近い位置に分布することになる。
明らかな曲率や直線からの他の著しい逸脱は、偶然誤差が正規分布に従っていない可能性を示唆している。
直線から大きく外れた点がいくつかある場合は、データに外れ値が含まれていることを示唆している。

[圧力・温度の例](../section1/pmd11.md#pt.r1)、[熱電対校正の例](../section1/pmd133.md#tc.r1)、および[ポリマーの緩和の例](pmd422.md#pr.r1)における正規確率プロットを以下に示す。
これら3つの例の正規確率プロットは、工程における偶然誤差がおおよそ正規分布に従うと仮定することが妥当であることを示している。
いずれの場合も、残差と標準正規分布からの理論値との間に強い線形関係が認められる。
もちろん、プロットからは、関係が完全に決定論的ではないこと（そして、決してそうなることはないこと）が示されているが、直線的な関係は依然として明らかである。
これらのプロット上のどの点も、残差によって定義される線形関係から大きく逸脱していないため、これらのデータ集合のいずれにも外れ値が存在しないという結論も妥当である。

#### ヒストグラム
正規確率プロットは、統計的工程における偶然誤差が正規分布から抽出されたものと仮定することが妥当かを判断するのに役立つ。
正規確率プロットの利点は、直線からの逸脱に対して人間の目が非常に敏感であり、誤差が非正規分布に従っている可能性を示唆している場合がある点にある。
しかし、正規確率プロットが正規性の仮定が妥当ではない可能性を示唆している場合でも、その分布が実際にどのような形状をしているかについては、あまり明確な手がかりを与えてはくれない。
一方、推定値からの残差のヒストグラムは、分布の形状についてより明確な情報を提供できる。
ヒストグラムが正規確率プロットよりも一般的な分布情報を提供するという事実は、正規性からの逸脱を識別することが、より具体的に焦点を当てた正規確率プロットを用いる場合よりも難しいことを示唆している。

#### 重要な注意事項
正規確率プロットおよびヒストグラムについて留意すべき重要な点は、以下の場合に工程から生じる偶然誤差の分布に関する情報を提供するということである。

1. モデルの関数部分が正しく指定され
2. データ全体で標準偏差が一定で
3. 工程に偏位がなく
4. 偶然誤差が実行ごとに独立している場合に偶然誤差は独立している。

他の残差プロットがモデルの問題を示している場合、正規確率プロットやヒストグラムは容易に解釈できなくなる。
