# 4.4.5.1. 残差プロットに基づく関数の更新

#### 残留プロットによるモデル精緻化の指針
[モデル関数部分の妥当性の確認](pmd441.md)をするために用いた残差プロットが問題を示した場合、モデル関数部分をどのように改善すべきかを判断するために、プロットに現れた構造を活用する。
例えば、[熱電対の校正](../section1/pmd133.md#tc.r1)データに適合させた[初期モデル](pmd422.md#tc.r1)が二次多項式であったと仮定する。
残差と温度の散布図は、このモデルを用いるとデータに構造が残ることを示していた。

#### 残差対温度：2次モデル
![residual plot from quadratic model](https://www.itl.nist.gov/div898/handbook/pmd/section4/plots/mvtc2_f.gif)

三次多項式に見える残差プロットの形は、多項式に他の項の追加することで、二次モデルではデータに残る構造を説明できる可能性を示唆している。
三次多項式に当てはめた後、残差の大きさは約30倍程度低減され、モデルに大きな改善が見られる。

#### 残差と温度の関係：3次モデル
![residual plot from cubic model](https://www.itl.nist.gov/div898/handbook/pmd/section4/plots/mitc1_f.gif)

#### 残差の複雑性の増加が示唆するLOESSモデル
モデルは改善されたが、残差には依然として構造が見られる。
この構造を基にすると、より高次の多項式の方がデータに適合しそうに見える。
しかし、このような数回の反復により次数が大きい多項式になり、残差の構造は多項式では実際にはデータを十分に説明できていないことを示唆している。
その結果、非線形モデルやLOESSモデルなど、別の種類のモデルの方がこのデータにはより適していると考えられる。
データを記述するために必要なモデルの種類は、各手順における残差の構造を用いて体系的に導き出すことができる。
