# 4.4.3. 未知母数の推定値取得方法

#### 母数推定の概論
モデルの関数部分の基礎形式を選択した後、モデル構築過程の次の手順は、その関数に含まれる未知母数の推定である。
一般に、これは最適化問題を解くことによって行われ、目的関数（最小化または最大化される関数）が、応答変数と未知の母数を含むモデルの関数部分を結びつけ、真の未知母数値に近い母数推定値を導き出すように構成されている。
大まかに言えば、未知母数は最適化において求解すべき変数として扱われ、このモデル化過程の段階では、データが目的関数の既知の係数として機能する。

理論上、係数を推定する方法は、最小化または最大化すべき目的関数の数だけ多く存在する。
しかし、優れた統計的特性を持つ係数推定量を与えるいくつかの原則が支配的である。
工程モデルにおける係数推定の主な2つの手法は、最尤法と最小二乗法である。
これら両方の方法は、多くの優れた特性を持つ係数推定を提供する。
しかし、最尤度と最小二乗はどちらも外れ値に敏感である。
頑健な手法と呼ばれる、係数推定の新しい手法も多数あり、最小二乗法と最大尤法の効率と望ましい特性を外れ値に対する低い感度で調整する。

#### 4.3節の概要
頑健な技法は有用であるものの、より伝統的な手法ほどには十分に開発されておらず、多くの場合、容易に入手できない専用のソフトウェアを必要とする。
また、最尤法も一般的には専用のアルゴリズムを必要とするが、そのような要件を必要としない重要な特例もある。
例えば、偶然誤差が正規分布に従うデータの場合、最小二乗法と最尤法の母数推定量は同一となる。
こうしたソフトウェアや開発上の問題と、多くの応用分野において最尤法と最小二乗法が一致するという事実を踏まえ、本節では現時点では最小二乗法による母数推定のみに焦点を当てる。
本節の残りの部分では、最小二乗法がどのように機能するかについて直感的な理解を提供し、この手法の有効性を示す。
