# 4.4.4.4. 各観測値間の偶然誤差の独立性評価

#### 残差間の依存関係を示す遅延プロット
残差の[遅延プロット](../../ch1_eda/section3/eda33f.md)は、もう一つの特殊な散布図の一種であり、誤差が独立しているかを示す。
もし誤差が独立していない場合、誤差の標準偏差推定値は偏り、工程に関する不適切な推論につながる可能性がある。
遅延プロットは、各残差値をそれに続く残差値（観測の時間順）とプロットすることで機能する。
最初の残差を 2番目の残差に対して、2番目の残差を 3番目の残差に対して、というようにプロットする。
残差を対にする方法のため、このプロットには、他のほとんどの種類の残差プロットよりも点数が1つ少なくなる。

#### 解釈
誤差が互いに独立している場合、遅延プロットにはパターンや構造は見られないはずである。
この場合、データ点はプロット上に散らばるように、無作為に散乱しているように見える。
しかし、誤差間に有意な依存関係がある場合、決定論的な何らかのパターンが明らかになることが多くある。

#### 例
[圧力・温度の例](../section1/pmd11.md#pt.r1)、[熱電対校正の例](../section1/pmd133.md#tc.r1)、および[高分子の緩和の例](pmd422.md#pr.r1)における遅延プロットを以下に示す。
これら3つの例の遅延プロットからは、各当てはめによる誤差が独立していることが示唆される。
いずれの場合も、残差は原点周辺に無作為に散らばっており、明らかな構造は見られない。
最後のプロットであるポリマー緩和のデータでは、残差と遅延残差の間にわずかな相関が見られるが、経験上、これは単に偶然誤差によるものであり、実際の問題とは考えにくい。
実際に遅延プロットは外れ値を強調してしまうこともあり、（絶対値で）大きな残差がいくつかある場合、それらが不必要に目を引いている可能性がある。
外れ値の特定にも有効な正規確率プロットについては、[次](pmd445.md)で説明し、データ集合内の異常な点についてさらに詳しく明らかにする。

#### 次の手順
誤差が独立していない場合に残差に見られることがあるさまざまなパターンの一部を遅延プロットに関する[一般的な解説](../../ch1_eda/section3/eda33f.md#examples)に示している。
残差が無作為でない場合、データを完全にモデル化するには、時系列解析手法が必要となることがある。
時系列分析の基礎については、[工程のモデル化](../../ch6_pmc/pmc.md)」の章の[4節](../../ch6_pmc/section4/pmc4.md)で解説している。
ただし、時系列分析手法の必要性について早計な判断する前に、実行順序プロットにデータの傾向や他の構造が示されていないことを必ず確認する。
実行順序プロットに傾向が見られる場合、それが偏位によるものであれ、誤った関数形の使用によるものであれ、実行順序プロットに示される構造の原因は、遅延プロットにも構造を持ち込む。
このように遅延プロットに生じた構造は、必ずしも連続する偶然誤差間の依存性を示すものではない。
遅延プロットは、実行順序プロットに存在する構造をすべて考慮した上で初めて、明確に解釈することができる。
