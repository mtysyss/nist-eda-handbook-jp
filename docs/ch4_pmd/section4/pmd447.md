# 4.4.4.7. モデル関数部分における必要項の検定

#### 推論に影響を与えるモデルの不要項
形式的には概ね正しいものの、余分な不要な項が含まれているモデルは、データに対して「過学習」していると言われる。
過学習という用語がこの問題を指すのは、モデル内の余分な項によってモデルが本来あるべき以上に柔軟になり、データに含まれる無作為変動の一部をあたかもそれが決定論的構造であるかのように説明してしまうためである。
モデル内の不要項の係数は通常、推定値がゼロに近い値となるため、それらをモデルに残しておいても何の問題もないように思えるかもしれない。
実際、モデルに1つや2つの余分な項が含まれていても、通常はそれほど大きな悪影響はない。
しかし、モデルに余分な項が必要以上に多く残されている場合、その影響は深刻になり得る。
とりわけ、モデルに不要な項を含めると、データから推定される不確かさが必要以上に大きくなり、データの分析から導き出される科学的もしくは工学的結論に影響を及ぼす可能性がある。

#### データの過学習を起こしやすい経験的モデルと局所モデル
過学習は、データの総変動のうち、どの程度が系統的であり、どの程度が無作為であるかについて参考になる知識がない場合、工程に対する純粋に経験的なモデル開発時に発生しやすい。
また、データの構造を記述するために明示的に指定された関数を使用するのではなく、[局所的](../section1/pmd144.md)にデータを適合させる回帰法を用いるときにも、過学習はより頻繁に発生する。
明示的な関数は通常、比較的単純で項の数も少ない。
一方、ノイズは一般的に明確な構造を示さないため、データのノイズに適合する明示的な関数をどのように指定すべきかを見極めるのは、一般的に困難である。
これが、この種のモデルで普通は過学習が問題にならない理由である。
一方、局所モデルは、非常に複雑なパターンに容易に適合させることができ、注意を払わないと工程ノイズの中に構造らしきものを見出してしまう可能性がある。

#### 過学習に対する統計検定
統計検定は、モデルの関数部分で重要な項が欠落しているか、あるいは誤って指定されているかを確認するために使用できるのと同様に、不要な項が含まれていないかを判断するためにも使用できる。
実際、データの過学習の有無の確認は、統計的検定が残差プロットよりも有効である分野の一つである。
ただし、過学習の有無を検定するときには、モデル内の各係数の重要性を個別に検定する手法が用いられ、モデル内の[項の欠落もしくは誤った指定](pmd446.md)を検定する場合のように、単一の検定を行う方法とは異なる。

#### 個々係数の検定
回帰分析ソフトウェアの出力のほとんどには、各係数がゼロであるという仮説と、ゼロではないという対立仮説を比較する個別の統計検定も含まれる。
これらの検定は、ほとんどのコンピュータ出力に自動的に含まれており、反復測定を必要とせず、モデル内の各係数に関する具体的な情報を提供するため、非常に便利である。
しかし、モデルに含まれる異なる予測変数の値が相関している場合、これらの検定結果を解釈するのは非常に困難になることもある。
これは、これらの検定が実際には**、他のすべての予測変数がモデルに含まれているという条件下で**、各係数がゼロであるかを検定しているためである。

#### スチューデントのt分布に基づく検定統計量
各係数がゼロであるかを検定するための検定統計量は、通常、スチューデントの*t*分布に基づいている。
モデル内の各係数推定値は、仮説上の値であるゼロから何標準偏差離れているかという観点で測定される。
係数推定値が仮説上の値に十分に近く、その偏差がすべて偶然誤差に起因するとみなせる場合、係数の真値がゼロであるという仮説は棄却されない。
一方、係数推定値が仮説値から著しく離れて、その偏差を偶然誤差によって合理的に説明できない場合、係数の真値がゼロであるという仮説は棄却される。

各係数がゼロであると仮定された値から、これら検定それぞれの検定統計量は、単純にその推定標準偏差で推定係数値を割ったものとなり、

$$T = \frac{(\hat{\beta}_i-0)}{\hat{\sigma}_{\hat{\beta}_i}} = \frac{\hat{\beta}_i}{\hat{\sigma}_{\hat{\beta}_i}}$$
 
係数の推定値と仮説標準偏差間の距離の測度である。
偶然誤差が正規分布であり、係数の真値がゼロ（として仮説設定する）であると仮定すると、検定統計量は自由度 $`n-p`$ の[Studentのt分布](../../ch1_eda/section3/eda3664.md)に従う。
したがって、*t*分布の切捨て値は、各係数推定値が仮定値から過度に離れ、偏差が偶然誤差に帰属するように、検定統計量がどの程度極端であるかを判定するために使用する。
これらの検定は、係数値がゼロより大きいか未満かを同時に検定するために一般的に使用され、各検定は切捨て値と$`\alpha /2`$ の有意水準を設定して使用すべきである。
これにより、各係数がゼロであるという仮説が確率 $`\alpha`$ で偶然に却下されることが保証される。
t 分布の対称性のため、上限値または下限値のいずれか一方の切捨て値のみを決定すれば、もう一方は負となる。
同様に、多くの人は単に検定統計量の絶対値を上限の切捨て値と比較する。


#### 圧力・温度の例に関する係数検定
モデル内の各係数に対する有意差検定の使用例を示すため、[圧力・温度](../section1/pmd11.md#pt.r1)の例に関する回帰分析の結果を以下に示す。
この事例では、データに直線モデルを適合したため、出力には切片および傾きの有意差検定が含まれている。
切片と傾きの推定値は、それぞれ 7.74899 および 3.93014 である。
それらの推定標準偏差は次の列に示され、その後に各係数がゼロであるかを判定するための検定統計量が記載されている。
推定残差標準偏差 $`\hat{\sigma}`$ およびその自由度も記載されている。

```
係数   　推定  　　標準偏差　　 t 値
B0     7.74899    2.3538     3.292
B1     3.93014    0.0507    77.515

残差標準偏差 = 4.299098
残差の自由度 = 38
```

*t* 分布表から切捨て値を有意水準 $`\alpha = 0.05`$、自由度 38を用いて探し、境界値は 2.024 となる.
（境界値は「0.975」とラベル付けされた列から取得する。
これは両側検定であり、$`1-0.05/2=0.975`$ である）。
検定統計量の両方が絶対値で 2.024 の境界値よりも大きいことから、勾配と切片の両方が 95% 有意水準においてゼロから有意に異なると適切に結論づける。
