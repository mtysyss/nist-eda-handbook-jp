# 4.4.2.2. データを用いた適切な関数の選択

#### データのプロット
初期モデルを選択する最良の方法は、データをプロットすることである。
回帰関数の形について明確な見当がついていても、プロットを行うことで、モデルの当てはめを成功させるために必要な[基本的前提条件](../section2/pmd21.md)の予備的な確認ができる。
また、データを視覚的に確認することで、データの数値的要約だけでは得られ難い、データ収集の過程や方法に関する他の洞察が得られることもよくある。

#### 例
[圧力・温度の例](../section1/pmd11.md#pt.r1)のデータを以下にプロットした。
このプロットから、直線モデルがデータによく適合するように見える。
これはシャルルの法則に基づく予想通りである。
このケースでは、工程やデータ収集に問題の兆候は見られない。

#### 最も単純な関数から着手
モデルを選択するときの重要な点は、データの構造を説明できそうな最も単純な関数から始めることである。
必要であれば複雑なモデルでも良いが、不必要に使用すべきではない。
必要以上に複雑なモデルを適合させると、データに含まれる無作為なノイズが決定論的な構造としてモデル化されてしまう。
これにより、残差標準偏差の推定に利用できるデータ量が不必要に減少してしまい、モデルを用いて工学や科学上の疑問に答えるために得られる結果の不確かさが増大する可能性がある。
幸いなことに、多くの物理系は直線、多項式、または単純な非線形関数で十分にモデル化できる。
以下に示す[熱電対校正の例](../section1/pmd133.md#tc.r1)のデータは、2次モデルが適切のようである。

#### 高次元におけるモデルの構築
応答変数の決定論的変動を記述する関数が複数の予測変数（入力）に依存している場合、各変数が互いにどう関連しているかを把握するのは困難なことがある。
この問題に対処する、しばしば有用であることが証明される方法の一つは、データの断面図をプロットし、一次元ずつ関数を構築していくことである。
このやり方は、複数の予測変数の異なる水準をまとめて、応答変数に対してもう一つの予測変数のプロット上に表示するよりも、異なる予測変数と応答変数との関係をより明確に明らかにしてくれることが多い。

#### 高分子緩和の例
例えば、材料科学者は、一定量ねじれている螺旋状ポリマー標本の時間経過の緩和について興味を持っている。
また、温度がこの過程にどのような影響を与えるかを解明することにも関心を持っている。
その結果、時間と温度の両方が、以下にプロットした緩和データに見られる体系的な変動を記述する上で重要な要因であると考えられている。
（読者は、この高分子緩和データを[テキストファイル](https://www.itl.nist.gov/div898/handbook/datasets/PR1.DAT)としてダウンロードできる。） 

しかし、トルクを時間に対してプロットしても、その関係の性質は明確に示されない。
同様に、トルクを温度に対してプロットしても、温度の影響は明らかではない。
これらプロットの解釈が難しいのは、トルク対時間プロットには複数の異なる温度でのデータが含まれ、トルク対温度プロットには異なる時刻に観測されたデータが含まれているためである。
もし温度と時間の両方がデータを記述する関数の不可欠な要素であるならば、これらのプロットは、本来は三次元の曲面として表示されるべきものを二次元のプロットに押し込めていることになり、データの実像を曖昧にしてしまっている。

#### 構造を明らかにする多重プロット
データの断面データを異なる説明変数の値をまとめて表示するのではなく、複数のグラフにプロットすると、変数間の関係がはるかに明確になる。
以下の各断面グラフは、特定の温度におけるトルクと時間の関係を示している。
これで、各温度におけるトルクと時間の関係が明確である。
また、温度によってその関係が異なることも容易に確認できる。
25度の温度では、0分から20分の間にトルクが急激に低下し、その後、緩和の速度が緩やかになる。
一方、75度の温度では、実験期間全体を通して緩和の減少率はほぼ一定である。
トルク対時間のプロファイルが温度によって異なるという事実は、ポリマーの緩和過程を関数で記述するには温度を考慮に入れる必要性を裏付けている。

#### データの断面

#### さらなる知見をもたらす断面モデル
使用する適切な関数について、データの各断面を個別にモデル化し、そして、それらの個々のモデルを互いに関連づけることで、さらに深い洞察を得られる。
トルク（$`y`$）と時間（$`x_1`$）の間に広く受け入れられている伸長指数関係、

$$y = \beta_0 + \beta_1\exp\left[-\left(\frac{x_1}{\beta_2}\right)^{\beta_3}\right] + \varepsilon $$

をポリマー・データの各断面に当てはめ、推定された母数と温度の関係を示すプロットを検証すると、温度をポリマー緩和データのモデルにどのように組み込むべきかが大まかに示される。
データの各断面に当てはめられた個々の伸長指数は、上のプロットにおいてデータを通る実線として示されている。
伸長指数における母数4つそれぞれの推定値と温度の関係を示すプロットを以下に示す。

#### 断面の係数と温度の関係
![cross-section parameters vs. temperature](https://www.itl.nist.gov/div898/handbook/pmd/section4/plots/mspr4_f.gif)

伸張指数から得られる断面積パラメータの各プロット中心付近にある実線は、すべての温度 6水準における推定係数値の平均である。
基準実線の上下にある破線は、データの無作為なばらつきにより係数推定値がどれだけ変動し得るかの概算境界を示している。
これらの境界は、個々の伸張指数適合からの推定値標準偏差の典型的な値に基づいている。
これらのプロットから、$`\beta_2`$ 値だけが明らかで、温度範囲全体で互いに大きく異なる。
さらに、$`\beta_2`$ 係数推定値に明確な増加傾向が見られる。
他の係数すべてについて、各温度における推定値は不確かさの範囲内にあり、明確な構造は見当たらない。

上で推定された$`\beta_2`$ 値のプロットに基づき、標準伸長指数における $`\beta_2`$ 項を拡張することで、新しい分母が温度に関して2次になり（$`x_2`$ と表示) 、ポリマー緩和工程に適した良い開始モデルとなる。
温度を2次とする選択は、個別に推定された係数値のプロットにおけるわずかな曲率によって示唆される。
結果として得られるモデルは次式となる。

$$y = \beta_0 + \beta_1\exp \left[ -\left(\frac{x_1}{\beta_2+\beta_4x_2+\beta_5x_2^2)}\right)^{\beta_3}\right] + \varepsilon$$
