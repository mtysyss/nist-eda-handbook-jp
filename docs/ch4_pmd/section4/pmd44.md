# 4.4.4. モデルのデータ適合判断法

#### 不十分な $`R^2`$
モデルの検証は、モデル構築の工程において、おそらく最も重要なステップである。
一方で、最も見過ごされがちなステップの一つでもある。
多くの場合、モデルの検証は、フィッティングから得られた $`R^2`$統計量（これは、応答変数の総変動のうち、モデルによって説明される割合を測るもの）を引用するだけのように見受けられる。
残念ながら、$`R^2`$の値が高いからといって、そのモデルがデータにうまく適合しているとは限りません。
データにうまく適合していないモデルを使用しても、調査対象となっている根本的な工学上または科学上の疑問に対して、適切な答えを得ることはできません。

#### 主要ツール：グラフ残差分析
モデルの妥当性評価には多くの統計的手法がありますが、ほとんどの工程のモデル化の応用において主要な手法は、グラフを用いた残差分析である。
推定モデル[（以下で定義する）](pmd44.md#resdef)からの残差[（定義は後述）](pmd44.md#resdef)をさまざまな形式でプロットすることで、モデルの各側面が適切であるかどうかの情報が得られます。
$`R^2`$統計量などのモデル検証のための数値的手法も有用ですが、通常はグラフィカルな手法ほどには役立ちません。
モデル検証において、グラフィカルな手法が数値的手法よりも優れている点は、モデルとデータの間の関係の幅広い複雑な側面を容易に可視化できることである。
モデル検証のための数値的手法は、モデルとデータの間の関係の特定の側面に狭く焦点を当てがちであり、しばしばその関係を簡略化しようとする傾向がある。
側面を容易に可視化できる点で、数値的手法よりも優れている。
モデル検証のための数値的手法は、モデルとデータの関係における特定の側面に狭く焦点を当てがちであり、その情報を単一の記述的な数値や検定結果に圧縮しようとする場合が多い。

#### 数値解析の強み
しかし、数値解法は、図形的手法の検証手法として重要な役割を果たしている。
例えば、モデルの関数部分の正しさを評価するための「[不適合度検定](pmd442.md)」は、境界線上の残差プロットの解釈に役立つことがある。
 また、グラフィカルな手法を容易に適用できないモデリングの状況もいくつか存在する。
 こうした場合、数値的手法はモデル検証のための代替手段となる。
 数値的検証法がグラフィカルな手法に優先される一般的な状況の一つは、推定される母数の数がデータ集合のサイズに比較的近い場合である。
この状況では、未知の母数の推定によって残差に課される制約のため、残差プロットの解釈が困難になることが多い。
 これが典型的に発生する分野の1つは、設計実験を用いた最適化アプリケーションである。
二値データを用いたロジスティック回帰も、グラフィカルな残差解析が困難になり得る分野の一つである。

#### 残差
推定モデルの残差とは、説明変数の各値の組み合わせにおいて観測された応答値と、回帰関数を用いて計算された対応する応答の予測値との差である。
数学的には、データ集合内の*第i番目の*観測値に対する残差の定義は次のように表される。
$$ e\_i = y\_i - f(\vec{x}\_i;\hat{\vec{\beta}}) $$ここで、$`y\_i`$はデータ集合内の*第i番目の*応答値を表し、$`\vec{x}\_i`$はデータ集合内の*第i*番目の観測値に見られる対応する値に設定された説明変数のリストを表す。

#### 例

](../section1/pmd11.md) 1列目は観測が行われた順序を示し、2列目は各観測が行われた日付を示し、3列目は各測定時に記録された周囲温度を示している。
 4列目には、ガス自体の温度（説明変数）が、5列目には、ガスの観測された圧力（応答変数）が記載されている。
最後に、6列目には、適合された直線回帰関数から得られた対応する値が示されている。
$$ \hat{P} = 7.749695 + 3.930123T $$そして最後の列には、5列目と6列目の差である残差が記載されている。

#### 残差を利用する根拠
データに適合したモデルが正しい場合、残差は、説明変数と応答変数の関係を[統計的な関係](../section1/pmd12.md#srlshp)たらしめる無作為な誤差に近似するはずである。
したがって、残差が無作為に振る舞っているように見える場合、それはモデルがデータにうまく適合していることを示唆している。
 一方、残差に非無作為な構造が認められる場合は、モデルがデータにうまく適合していないことを示す明確な兆候である。
 以下に挙げる各小節では、モデルのさまざまな側面を検証するために使用するプロットの種類について詳述し、各プロットで観察される可能性のある結果の正しい解釈に関する指針を示する。
