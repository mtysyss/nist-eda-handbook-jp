# 4.4.5. 現在モデルにおけるデータ不適合時の改善

#### 次にの手順
残差プロット、正式な仮説検定、および記述統計を用いてモデルの検証時に、問題が見つかったためにモデル化の過程を最初からやり直さなければならないとしたら、かなり苛立たしいことである。
しかし幸いなことに、残差分析によって明らかになった問題の多くを是正するための技法やツールも存在する。
場合によっては、モデルの妥当性確認方法そのものが、問題が発見されたと同時に、モデルに対する適切な変更を示唆することもある。
これは特に、モデルの妥当性確認のためのグラフ・ツールが当てはまりまるが、回帰関数の係数に対する検定もまた、モデルの改良に向けた洞察を与えてくれる。
[4.4.4節](pmd44.md)で診断された様々なモデルの不備に対する対処法については、以下の小見出しで実例を示し、考察する。
