# 4.4.5.3. 非正規分布の誤差への対応

#### 基本的な手法：変換
[偶然誤差の変動が一定でない場合の補正](pmd452.md)とは異なり、ほとんどの回帰手法において、非正規偶然誤差を含むデータを扱うための基本的な手法は、実際には1つしかない。
これは、ほとんどの手法が、[正規性の仮定](../section2/pmd214.md)と線形推定法（最小二乗法など）に依存し、科学的または工学的な疑問に答えるための確率的推論を行っているためである。
データの正規性を前提とする手法の場合、偶然誤差を近似的に正規分布にするためにデータを直接操作することが、通常、この仮定にデータを適合させるための最善の方法である。
変換に代わる主な方法は、未知係数を推定するときに、偶然誤差の分布を直接考慮に入れるような適合基準を用いることである。
[最大尤度法](../../ch8_apr/section4/apr412.md)などのこの種の適合基準を使用することで、非常に良好な結果が得られる。
しかし、それらはほとんどの工程のモデル化手法で使用される一般的な適合基準よりも、使用するのがはるかに難しい場合が多い。

#### 変換の使用
非正規分布の偶然誤差を含むデータを扱うために変換を用いる基本的な手順は、偶然誤差の変動が一定でない場合を処理する手順と本質的に同じである。

1. 応答変数を変換し、偶然誤差の分布が近似的に正規分布になるようにする
2. 必要に応じて説明変数を変換し、回帰関数の単純な関数形を得るか、あるいは元の形に戻す
3. 変換後の変数を用いてモデルを推定し、その妥当性を検証する
4. 応答変数に適用した変換の逆変換を用いて、予測値を元の単位に戻す

偶然誤差の非一定ばらつきと非正規性を考慮する変換を用いる主な違いは、変換が偶然誤差の分布に及ぼす影響を直接的に把握することが難しいという点にある。
しかし多くの場合、偶然誤差の非正規性と非一定標準偏差は密接に関連しており、同じ変換によって両方の問題が同時に修正されることがある。
したがって実際には、データのばらつきが一定でない問題を修正するために変換を選択すると、多くの場合、偶然誤差の正規性も改善されることになる。
もしデータが非正規分布の偶然誤差を持つように見えても、標準偏差が一定である場合は、常に、変換された複数のデータ集合にモデルを適合させ、どの変換が最も正規分布に近い残差を生成するかを確認する。

#### 分布の仮定を満たす代表的変換
当然のことながら、偶然誤差の分布を近似的に正規分布に近づけるために有効な3つの変換は次の通り。

1. $`\sqrt{y}`$
2. $`\ln{(y)}`$\（注：対数の底は実際には重要ではない）
3. $`\frac{1}{y}`$

これらは、データのばらつきを安定化させるためによく用いられる変換と同じものである。
偶然誤差の分布特性を改善するための他の適切な変換は、科学的知見に基づくか、あるいはデータに基づいて選択される場合がある。
しかし、これら3つの変換は、多くの状況で良好な結果が得られるため、まず試してみるのに適している。

#### 例
変換を用いて偶然誤差の分布を変える方法を説明するために、[圧力・温度の例](../section1/pmd11.md#pt.r1)の誤差が一様分布している修正版を見ていく。
データを元の単位のまま当てはめた場合と、さまざまな変換を施した場合の結果の比較から、変換が偶然誤差の分布に及ぼす影響を直接的に明らかにすることができる。

#### 未変換データに対するモデルの当てはめ
一様分布に従う偶然誤差を含む圧力・温度データに直線モデルを適合させた後に得られた残差の4-プロットを以下に示す。
この4-プロットの下段にあるヒストグラムと正規確率プロットは、残差の分布を評価する上で最も有用なプロットである。
この事例のヒストグラムは分布がベル型よりは長方形に近く、偶然誤差が正規分布に従う可能性は低いことを示している。
正規確率プロットの曲率もまた、偶然誤差が正規分布に従わないことを示唆している。
もし偶然誤差が正規分布に従うならば、正規確率プロットはほぼ直線になるはずである。
もちろん、完全に直線になるわけではないが、滑らかな曲率や、直線から大きく外れた点がいくつかある場合は、非正規性を示すかなり有力な指標となる。

#### 適切な変換の選択
[無作為なばらつきを安定化させるための変換を見つけるために用いられる手順と同様の手順](pmd452.md#ut)を踏み、応答変数と予測変数の変換のさまざまな組合せから、単純な関数形式を持ち、残差がより正規分布に近くなる可能性のあるものを選択する。
以下のマルチ・プロットでは、基本的な変換の可能な組合せすべてを温度と圧力に適用し、単純な関数形式を持つ組みを特定している。
この典型的な事例では、平方根-平方根、ln-ln、逆関数-逆関数の各変換を適用したデータはすべて、直線モデルに従っているように見える。
次の手順では、これらの各データ集合に直線を当てはめ、残差プロットを比較し、正規分布に従うように見える偶然誤差を含むものがあるかを確認する。

#### 変換変数に対するモデルの適合
以下の正規確率プロットおよびヒストグラムは、変換済みデータ集合3つに対して直線モデルを適合させた結果を示している。
比較のために、元単位でのデータに対するモデル適合の結果も併せて示している。
正規確率プロット4つを見ると、ln-ln変換を用いたモデル適合が最も正規分布に近い偶然誤差のように見える。
ln-lnデータの正規確率プロットが非常に直線的であることから、圧力にlnを適用することで、偶然誤差の分布が近似的に正規分布になる、と結論付けてもよいと思われる。
ln-ln変換されたデータのヒストグラムは適度にベル型になっているのに対し、他のヒストグラムは特にベル型ではないことから、ヒストグラムもこれを裏付けている。
したがって、他の残差プロットも同様に、変換されたデータに直線モデルが適合することを示唆していると仮定すれば、ln-ln変換を用いることはこのデータの分析に適していると考えられる。
