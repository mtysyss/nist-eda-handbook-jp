# 4.4.2. 工程を記述するための関数の選択法

#### 必要な工程情報の統合
一連のデータに適合する適切な形式のモデルを選択するには、通常、データに含まれる実証的証拠の活用、工程に関する知識、そしてある程度の試行錯誤が必要である。
前のページでも述べたように、モデル構築は常に反復的な過程である。
反復が必要となる理由の多くは、データを適切に記述する関数を初期段階で選択することが困難であることに起因している。
データの詳細は、当初観測されたデータからは容易に把握できないことがよくある。
データに含まれる微細な構造は、通常、残差プロットなどのモデル構築ツールを用いたり、モデル形式を繰り返し改良したりすることによってのみ、明らかにすることができる。
その結果、モデルの形式がどうあるべきかを示唆する情報源をどれ一つとして見落とさないことが重要である。

#### 統計データだけでは得られない答え
効果的なモデルを導き出すために統合する必要があるさまざまな情報源が、時に矛盾する場合がある。
柔軟な姿勢で、データが何を示唆しているかを考察する意欲が重要である。
バランスを保ち、データに見られる異常な影響について別の情報源を探ることも重要である。
例えば、[ロードセルの校正に関する事例研究](../section6/pmd61.md)では、統計分析の結果、当初適切と考えられていたモデルではデータの構造すべてを説明できていないことが指摘された。
改良されたモデルが開発されたが、予期せぬ結果が現れたことで、当初の問題に対する理解が不正確だったのか、あるいは代替モデルが必要だったのは実験の人工物によるものだったのかという疑問が生じた。
ロードセル問題では、改良されたモデルの方が真実に近いと容易に受け入れられたが、より複雑なケースでは、この問題を解決するために追加の実験が必要だったかもしれない。

#### 知っておくと役立つ関数の型
モデル選択において役立つもう一つの要素は、さまざまな数学関数が取り得る形状に関する幅広い知識である。
また、これまでさまざまな応用分野で良好な結果が得られたモデルについてある程度理解していることも役立つ。
次のページにあるさまざまな関数のメニュー、4.4.2.1節（リンクは以下に記載）は、関数の形状や柔軟性について学ぶための1つの方法を提供している。
4.4.2.2節では、一般的な関数の特徴と定性的な科学的情報をどのように組み合わせ、モデル選択に役立てることができるかについて論じている。
最後に、4.4.2.3節では、データに適合させるために特定の関数を指定する必要のない手法や、そうした種類のモデルの改良方法について説明している。
