# 4.4.3.2. 加重最小二乗法
[4.1節](../section1/pmd143.md)で述べたように、加重最小二乗法（WLS）回帰は、予測変数値の組合せに対して応答値が異なる程度のばらつきを持つモデル係数値を推定するのに有用である。
名前が示す通り、加重最小二乗法による係数推定は、「標準的」「通常」「非加重」または「等加重」最小二乗法による係数推定と密接に関連する。

#### 一般 WLS 基準
加重最小二乗法による母数推定では、通常の最小二乗法と同様に、回帰関数における未知係数値、$`\beta_0, \beta_1, \ldots`$ は、観測された応答値とモデルの関数部分との間の偏差平方和を最小化する係数推定値の数値を求めることによって推定される。
しかし、最小二乗法とは異なり、加重最小二乗基準の各項には、データ集合内の各観測値が最終的な係数推定値にどの程度影響を与えるかを決定する追加の重み $`w_i`$ が含まれている。
係数推定値を得るために最小化される加重最小二乗基準は次式である。

$$Q = \sum_{i=1}^{n} \ w_i[y_i - f(\vec{x}_i;\hat{\vec{\beta}})]^2 $$

#### （常にではないが）通常 LSとほぼ共通する点
通常の最小二乗推定量と同様に、

1. 加重最小二乗推定量は、$`\hat{\beta}_0, \hat{\beta}_1, \ldots`$ と表記され、これらの推定量が係数の真値とは異なるという事実を強調している。
2. $`\hat{\beta}_0, \hat{\beta}_1, \ldots`$ は、最適化における「変数」として扱われる一方、応答変数、予測変数、重みの値は定数として扱われる。
3. 係数推定量は、予測変数と応答変数の両方の関数となり、一般に互いに相関を持つことになる。
（WLS推定量は重み $`w_i`$ の関数でもある。）
4. 加重最小二乗法の最小化は、通常、線形モデルでは解析的に、非線形モデルでは数値的に行われる。
