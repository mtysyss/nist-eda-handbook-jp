# 4.4.4.1. モデル関数部の十分性評価

#### 主なツール：散布図
モデルの残差とモデルに含まれない予測変数候補に対する予測変数の[散布図](../../ch1_eda/section3/eda33q.md)は、モデルの関数部分の十分性を評価するために主に用いられるプロットである。
残差に系統的構造が見られないプロットは、モデルがデータにうまく適合していることを示している。
残差と他の予測変数や予測変数候補の関数形として系統的構造を成すプロットは、関数の形を何らかの方法で改善できることを示唆している。

#### 圧力・温度の例
以下の残差散布図は、[4.1.1節](../section1/pmd11.md#pt.r1)で紹介され、[前節](pmd44.md#pt.r2)でも議論した圧力・温度データに直線を適合させたときの残差を示したものであるが、モデルに何ら問題があるようには見えない。
0 を通る基準線は、残差が正と負に50-50で分けていることを示している。
このプロットには、明らかな系統的パターンは見られない。
もちろん、$`R^2`$ 統計量がそれ自体では特定モデルを正当化できないのと同様に、単一残差プロットだけでは特定モデルの採用を完全に正当化することはできない。
もし、これら残差と別の変数とのプロットに、系統的な構造が見られるならば、その変数に関するモデルの形式を変更するか、あるいはその変数がモデルに含まれていないときはモデルに追加する必要がある。
モデル候補が可能な限り最良のモデルであることを確認するために、利用可能なすべての変数に対して残差をプロットすることが重要である。

#### 環境変数の重要性
見過ごされがちな重要な予測変数の1つに環境変数がある。
環境変数には、測定が行われている場所の周囲温度や周囲湿度などが含まれる。
ほとんどの場合、環境変数が工程に顕著な影響を及ぼすことは想定されていないが、環境条件によって引き起こされる予期せぬ問題がないかを確認することは、常に良い慣行である。
また、包括的な環境変数を用いて、モデルの妥当性を評価することもある。
例えば、実験が数日に渡って行われる場合、残差を日ごとにプロットすることで、異なる時間帯における実験条件の違いを確認することができる。
観察された違いは、必ずしも特定の原因に起因するとは限らないが、モデルから欠落している要因や他の設定を特定するための実験を行う根拠となり得る。
以下の2つの残差プロットは、圧力・温度の残差を実験室の周囲温度および日数に対してプロットしたものである。
どちらの場合も、これらのプロットが直線モデルはデータを適切に説明しているというさらなる証拠を提供している。
残差対日のプロットは、日間にわずかな周期的なパターンが見られ、少し不審に思えるが、決定的な問題を示しているわけではない。
この日間に見える差異は、単にデータの無作為な変動によるものと考えられる。

#### 全ての方法で機能する残差散布図
上記で示した残差プロットの例は、最も単純なケース、最小二乗法による直線回帰のものであるが、残差プロットはモデル構築に用いられる他のほぼすべての統計手法においても、まったく同じように用いられる。
例えば、以下の残差プロットは、[4.1.3.3節](../section1/pmd133.md#tc.ex)で紹介した熱電対校正データに適合させた LOESSモデルに関するものである。
上記のプロットと同様に、このプロットからも、データに対する LOESSモデルの適合に問題があることを示唆するものは見られない。
残差はすべての温度において基準線の上下に散在している。
プロット上で互いに隣接する残差は、同じ符号を持つ傾向にはない。
このプロットには、いかなる種類の明らかな系統的なパターンも見られない。

#### LOESSモデルの代替案
熱電対の校正データにおける電圧（応答変数）と温度（予測変数）の関係を示す[プロット](../section1/pmd132.md#tc.ms.plt)に基づけば、2次モデルはこのデータに対する妥当な初期モデルであったと考えられる。
2次モデルはデータの曲率を説明できる最も単純なモデルである。
しかし、データに2次モデルを適合させた残差と温度の散布図は、その適合度が低いことをはっきりと示している。
この残差プロットは、残差に強い周期的な構造があることを示している。
もし、2次モデルがデータに適合していたならば、このような構造は残差に残されることはなかったはずである。
2次モデルと LOESSモデルの残差プロットの比較において注目すべき点は、各事例でデータに残っている構造の量に加え、2つのプロットの尺度の違いである。
2次モデルの残差の範囲は、LOESS残差の範囲の 約50倍である。
