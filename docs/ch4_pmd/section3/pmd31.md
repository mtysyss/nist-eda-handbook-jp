# 4.3.1. 実験計画法（DOE）とは

#### データ収集への体系的取組み
実験計画法（DOE）とは、工学上の問題解決に向けた体系的かつ厳密な取組みであり、データ収集の段階において原則や手法を適用することで、妥当性があり、論証可能かつ裏付け可能な工学的結論を導き出すことを目的としている。
さらに、これらすべては、実験回数、時間、費用を最小限に抑えるという制約の下で実施される。

#### DOEの対象とする問題領域
DOEが適用可能な一般的工学上の問題領域は以下の4つがある。

1. 比較
2. 特徴付けのスクリーニング
3. モデル化
4. 最適化

#### 比較
1つめの領域では、技術者は、単一要因の変化が実際に工程全体の変化や改善をもたらしたか、を評価することに関心がある。

#### 特徴付けのスクリーニング
2つめでは、技術者は、（設計と解析の後）その工程に影響を与える要因を重要なものから重要でないものへと順位付けした一覧を手元に用意したいという意味で、工程全体を「理解すること」に興味を持っている。

#### モデル化
3番目の領域では、技術者は、工程を機能面からモデル化し、その出力を適合度の高い（＝予測精度の高い）数学関数とし、その関数の係数について良好な（＝精度が最大）推定値を得ることに関心を持っている。

#### 最適化
4番目では、技術者は工程要因の最適設定を決定すること、すなわち、各要因について工程応答を最適化する要因の水準の決定に興味を持っている。

本節では、3番目の領域である「モデル化」に焦点を当てる。
