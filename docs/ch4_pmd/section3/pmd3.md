# 4.3. 工程モデル化のためのデータ収集

#### 質の高いデータの収集
本節では、工程モデル構築のためのデータ収集に関するいくつかの一般的な原則を説明する。
綿密に計画されたデータ収集手順の採用は、実験の成否を分ける重要な要素となることがよくある。
さらに、よく設計された実験は、全体的な成否にかかわらず、十分に検討されていない実験よりも費用が抑えられることが多い。

具体的には、本節で次の問いに答える。

データ収集に先立ち（すなわち、実験計画の段階において）、分析者が工程モデル化を最適に行うために何ができるか。
