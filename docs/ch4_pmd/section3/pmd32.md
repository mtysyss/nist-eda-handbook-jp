# 4.3.2. 工程モデル化において、実験計画法が重要な理由

#### 当てはめられた数学関数の工程モデル出力
工程モデル化の結果として得られるのは、推定された係数を持つ適合された数学関数である。
例えば、抵抗率 $`y`$ をドーパント濃度 $`x`$ の関数としてモデル化するとき、分析者は次の関数を提案するかもしれない。

$$y = \beta_{0} + \beta_{1}x + \beta_{11}x^{2} + \varepsilon $$

ここで、推定する係数は $`\beta_0`$、$`\beta_1`$、$`\beta_{11}`$ である。
与えられた関数形式であっても、使用可能な係数の値は無限に存在する。
これらの係数の値のそれぞれが予測値を導き出す。

#### 適切な係数の値とは
係数の値が不適切であると、結果として得られる予測値が観測された生データ $`y`$ と著しく異なる。
係数の良い値とは、結果として得られる予測値が観測された生データ $`y`$ に近いものである。
係数の最適な値とは、結果として得られる予測値が観測された生データ $`y`$ に近い上、各係数に関連する統計的不確かさが小さいものである。

「最適な」係数の導出に有益な以下の考慮事項2つが挙げられる。
1. 最小二乗基準
2. 実験計画法の原則

#### 最小二乗基準
与えられたデータ集合（例えば、 $`(x,y)`$ の10組）について、次式

$$y = f(x;\vec{\beta} + \varepsilon) $$

の係数を得るための最も一般的な手法は、[最小二乗法基準](../section4/pmd431.md)である。
この手法により得られる予測係数値は、生データ $`y`$ に最も近いものとなり、生データと予測値との差の平方和が可能な限り小さくなるように推定する。

今日の回帰分析プログラムの圧倒的多数は、モデル係数の推定に最小二乗基準を採用している。
最小二乗推定量が広く用いられているのは、以下の理由による。

1. 推定量が統計的に最適である（BLUE：最良線形不偏推定量）
2. 推定アルゴリズムが数学的に扱いやすく、閉形式で表せるため、プログラミングが容易

では、これをどのように改善できるか。
与えられた $`x`$ 値の集合については改善できないが、多くの場合、$`x`$ 値の選択は我々の制御下にある。
もし $`x`$ の値を選択できれば、係数のばらつきは、$`x`$ が制御されていない場合よりも小さくなる。 

#### 実験計画法の原則
$`x`$ の値としてどのような値を用いるべきかについては、確立された実験計画法の原則を指針とする。

#### 原則1：係数の推定変動を最小限に抑える
実験計画法の第一の原則は、$`y`$データを収集した後、得られるモデル係数の変動が可能な限り最良となるように $`x`$ ベクトル内の値を制御することである。

実験計画法と工程モデル化に関する根本的な点は、（例えば単純な $` (x,y) `$ 適合の場合であっても）最小二乗基準が、与えられた $`x`$ 値の分布に対して最適な（ばらつきが最小）推定量を与えることがあるとしても、$`x`$ ベクトル内のデータ分布によっては、他の $`x`$ ベクトルよりも優れた（ばらつきが小さい）係数推定量が得られる場合がある。
分析者が $`x`$ ベクトルの値を指定できれば、その後の最小二乗法による係数推定値のノイズを劇的に変化、低減させることができる可能性がある。 

#### 5つの計画
実験計画法が工程モデル化に及ぼす影響を理解するために、直線回帰という以下の最も単純な例を考える。

$$y = \beta_{0} + \beta_{1}x + \varepsilon $$

分析者が、$` \beta_0`$ および $`\beta_1`$ の最適（すなわち、ばらつきが最小）推定量を決定するために、観測値 10組（すなわち、$`(x,y) `$ の10組）を収集できると仮定する。
対応する 10個の $`y`$ 値を収集するために、どのような 10個の $`x`$ 値を用いるべきか。
平易に言えば、$`\beta_0`$ および $`\beta_1`$ に対する最小二乗法による推定係数のばらつきを最小化するためには、横軸上に 10個の $`x`$ 値をどこに配置すべきか。
10個の $`x`$値は、

1. 対象範囲全体にわたって等間隔に配置された10個の値であるべきか。
2. 対象範囲全体に渡る等間隔の値を5つずつか。
3. $`x`$ の範囲の最小値に5つの値、$`x`$ の範囲の最大値に5つの値を配置すべきか。
4. 最小値に1つ、範囲の中央に8つ、そして最大値に1つにすべきか。
5. 最小値で4つ、範囲中間で2つ、そして最大値で4つにするべきか。

あるいは（結果として得られる$`\beta_0`$ と $`\beta_1`$ の推定値の「精度」という観点から）、違いはないか。

上記の5つの実験計画のそれぞれについて、当然ながら $`y`$ データが収集され、続いて $`\beta_0`$ と $`\beta_1`$ の最小二乗推定値を計算し、各計画からそれぞれ1本の回帰直線が得られることになる。 

#### 計画によっては近似直線の方が良いか
しかし、推定直線、すなわち推定工程モデルは、ある計画では他の計画よりも優れているか。
また、係数推定量の分散は、ある計画では他の計画よりも小さいか。
与えられた推定値について、その結果得られる予測値は、他の計画に比べてより良い（すなわち、観測された $`y`$ 値により近い）ものとなるか。
これらすべての質問に対する答えは **はい** である。
**確か**に違いがある。

線形モデル化においてどの設計を用いるべきかという上記の問いに対する最も一般的な答えは、10個の等間隔の点からなる設計1 である。
しかし、推定された傾き母数の分散は、以下の関係式に従って、計画に依存することが示される。

$$\text{Var}(\hat{\beta}_1) \propto \frac{1}{\sum_{i=1}^{n}(x_i-\bar{x})}$$

したがって、最小分散推定量を得るためには、右辺の分母を最大化する必要がある。
分母を最大化するためには、（任意に固定された $`\bar{x}`$ に対して）$`x`$ の値を $`\bar{x}`$ からできるだけ遠くに配置するのが最善である。
これを行うには、$`x`$ の半数を下限に、残りの半数を上限に配置する。
これが上記の設計3 であり、この「ダンベル型」計画（半分を下限、半分を上限）は、実際には直線を当てはめるための最良の計画である。
よく考えてみると、これは「2つの点が直線を決定する」という格言から直感的に導き出されるものであり、したがって、それらの2つの点を可能な限り遠く（両極端に）かつ可能な限り均等に（各極端にデータの半分ずつを配置して）決定することが最も理にかなっている。
故に、モデルが直線である場合の処理をモデル化する実験計画法の解は、「ダンベル型」の計画、すなわち各極値に $`x`$ の半数を配置する計画となる。 

#### 最悪の計画とは
上記の事例において、最も悪い計画はどれか。
5つの設計のうち、最も悪い計画は変動が最大となるものである。
上記の数式において、分母を最小化するものがそれであり、したがって上記設計番号4 にあたる。
この計画では、データのほぼすべてが中間範囲に位置している。
明らかに、この場合の推定直線は両端にある孤立した点を追いかけることになり、その結果得られる線形近似は直感的に劣るものとなる。

#### 計画 1、2、5
他の3つの計画はどうか。
設計1、2、5は、モデルが線形である可能性を考えるが、確信がない場合にのみ有用であり、そのため、必要に応じて直線を当てはめることができるよう追加の点を許容しつつ、必要に応じて直線を超える（例えば、2次、3次など）モデルを適合させる「余地」を設計に組み込んでいる。
この観点で計画の順序は次のようになる。

* 設計5（最悪の場合のモデルが二次関数である場合）
* 設計2（最悪の場合のモデルが4次の場合）
* 設計1（最悪の場合のモデルが5次以上である場合）
