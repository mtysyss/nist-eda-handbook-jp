# 4.3.3. 工程モデル化における一般的な設計原則

#### 工程モデル化への実験計画法の原則の適用
工程モデル化に適用される実験計画法には以下の6つの原則がある。

1. 1次モデルの性能
2. 代替モデルの性能
3. 係数推定量の分散の最小化
4. 変動が存在する箇所での標本採取
5. 反復
6. 無作為化

以下、それぞれについて以下に詳しく論じる。

#### 1次モデルの性能
最善推定モデルについて、設計がモデルの係数を推定できる性能を備えるようにする。
簡単な例を挙げると、2次モデルを推定する場合は、横軸上に少なくとも3つの異なるデータ点が含まれるようにする。

#### 代替モデルの性能
もし、最善推測モデルが不適切である場合は、その設計が、最善の推測に基づく代替モデルの係数を推定できる性能を確実に持つようにする（これは、暗黙のうちに、そのようなモデルを予め特定しておくべきであることを意味する）。
簡単な例を挙げると、線形モデルが適切であると推測している（ただし確実ではない）場合、局所最適設計（例えば、両端に5点ずつ配置する設計）を採用するよりも、全域的に頑健な設計（例えば、10点設計であれば、両端に4点、中間に3点）を採用するのが最善である。
局所最適な設計は直線に対して最良の適合を示す、2次関数に適合する性能はない。
一方、全域的に頑健な設計は、直線に対して良好に（最適ではないものの）適合し、さらに2次関数に対しても良好に（最適ではないものの）適合する。

#### 係数推定量の最小分散
与えられたモデルについて、その設計が、最小二乗法によって推定された係数の変動を最小化する性質を確かに持つようにする。
これは常に有効である一般的な原則であるが、実際には、単純な1因子モデル

$$y = f(x;\vec{\beta} + \varepsilon) $$

を超える多くのモデルでは、実装が困難である。
より複雑な 1因子モデルや、ほとんどの多因子

$$y = f(\vec{x};\vec{\beta} + \varepsilon) $$

モデルの場合、最小二乗推定量の分散を表す式は存在するが、その式は複雑であり、分析者が通常知っている以上の仮定を必要とする。
その結果、この原則は重要ではあるものの、単純な事例以外では適用が難しくなる。

#### ばらつきが一定でない場合の例
モデルの単純さや複雑さにかかわらず、曲線の特定領域が他の領域よりもノイズが多い状況がある。
単純な例として、$`x`$ と $`y`$ の間に線形関係があるが、記録装置が絶対値ではなく比例値で測定するため、$`y`$ の値が大きいほど、本質的にノイズが多くなる場合が挙げられる。
このようなとき、ばらつきが大きい領域で標本採取を行うことは、ノイズの多い領域においてより多くの複製点を取得することになる。
そのような反復データ点をいくつ設けるべきかという実用的な答えは、

$$n_{i} = \frac{1} {\sigma_{i}^{2}} $$

であり、ここで $`\sigma_{i}`$ は曲線の特定領域における理論上の標準偏差を表す。
通常、$`\sigma_{i}`$ は、局所的な標準偏差がどの程度であるかについての事前の推定値によって推定する。

#### ばらつきが急勾配曲線の場合の例
非線形モデルでよくあることとして、曲線上の特定領域が他の領域よりも急勾配になることが挙げられる。
例えば、指数関数モデル（小さな $`x`$ に大きな $`y`$ が対応し、大きな $`y`$ に小さな $`x`$ が対応する）を当てはめる、急勾配の領域における $`y`$ データは、比較的緩やかな領域の $`y`$ データに比べて本質的にノイズが多いことがよくある。
その理由は、一般的に $`x`$ 値自体に多少のノイズが含まれており、この $`x`$ ノイズが、緩やかな区間に比べて急勾配の区間ではより大きな $`y`$ ノイズとして現れるためである。
この場合、応答曲線の形状を十分に把握し、急勾配領域と緩勾配領域を区別できるのであれば、緩勾配領域よりも急勾配領域でより多くの標本を採取するのが良い場合が多い。
この状況で $`x`$ 値をどこに配置すべきかについての実用的な目安は、

1. 結果として得られる曲線がどのようなものになるか、最善の推測を描き
2. 縦（すなわち $`y`$）軸を等間隔の $`n`$ 個の点に分割する（ここで $`n`$ は利用可能なデータ点の総数を表す）
3. 各縦軸の点から、描いた曲線と交わる点まで水平線を引く。
4. 曲線との交点から横軸に向けて垂直な投影線を引く。

これらが、設計に用いるべき推奨される $`x`$ 値となる。

指数関数的に減少する曲線に対する上記の大まかな手順では、曲線の急勾配な領域に点が対数的に多く分布し、曲線の緩やかな部分には比較的少ない点となる結果が得られることになる。 

#### 反復
費用的に可能であれば、すべての設計に反復実験を取り入れるべきである。
反復実験を行うことで、工程標準偏差のモデルに依存しない推定値を計算することができる。
この推定値は、客観的な[不適合度検定](../section4/pmd446.md)における基準として用いられ、与えられたモデルが適切であるかを評価することができる。
このような客観的な不適合の F検定は、設計に反復が組み込まれている場合にのみ適用できる。
ある程度の反復は不可欠であり、すべての測定点で反復を行うことが理想的である。

#### 無作為化
$`x`$ に何らかの自然な順序があるからといって、データが $`x`$ と同じ順序で収集されるべきというわけではない。
あらゆる実験には何らかの無作為化の要素が組み込まれるべきであり、工程モデル化のための実験も例外ではない。
したがって、曲線上の 10点を採取する場合、10個の $`y`$ 値は、$`x`$ 値を最小から最大へと順次進めながら収集すべきではない。
この場合、機械、作業者、環境、測定装置などに何らかの外部要因による偏位や摩耗が生じると、その偏位が知らず知らずのうちに $`y`$ 値を汚染し、ひいては最終的な近似結果を汚染することになる。
このような潜在的な偏位の影響を最小限に抑えるには、$`x`$ 値の順序を無作為化（乱数表を使用）するのが最善である。
これにより、偏位がなくなるわけではないが、偏位の影響が曲線全体に均等に分散され、適合値のばらつきが現実的に拡大されるため、事後（残差分析やモデル検証の段階）にそのような偏位を明らかにしたり発見したりするための仕組みが組み込まれる。
実行順序を無作為化しない場合、仮に偏位が発生しても、それを検出する特性を失うことになる。
