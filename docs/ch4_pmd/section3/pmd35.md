# 4.3.5. 自分の用途に適した特定の実験計画採用判断

#### 6つの設計原則に基づく評価
どのような方法で作成されたにせよ、手元に計画がある場合、その計画の事後的な妥当性をどのように評価すればよいか。
こうした確認は、[6つの一般的な設計原則](pmd33.md)の一覧と並行して行う。
計画をこれら原則6つのそれぞれに対して評価する。
例えば、主なモデルに対応する性能があるか、代替モデルに対応する性能があるか、などである。

これらの確認のうち、一部は定量的で複雑である一方、他の確認方法は簡単でグラフで行う。
グラフを用いた確認は最も簡単に行えるが、最も有益なものの一つである。
当該グラフによる確認を2件、定量的確認を1件について述べる。

#### 一変量均衡のグラフでの確認
もし、$`k`$ 個の因子において大域的に良好であると主張される計画があるならば、一般にその計画は個々の $`k`$ つの因子それぞれにおいて局所的にも良好なはずである。
高次元における大域的な良好性を確認することは困難だが、低次元における局所的な良好性を確認することは容易である。
$`k`$ 個のプロットを作成し、各プロットの横軸に因子 $`x_i`$ の水準を、縦軸に因子 $`x_i`$ の各水準における設計点の数をプロットする。
ほとんどの良好な設計において、これらの個数は、因子のすべての水準でほぼ同じ（均衡）であるべきである。
例外は存在するが、このような均衡は、ほとんどの良好な設計に見られる基本的な特性である。

#### 2変量の均衡のグラフでの確認
もし、$`k`$ 個の要因において大域的に良好であるとされる計画ならば、一般に、その計画は $`k`$ 個の個々の要因すべての組合せにおいても局所的に良好であるはずである。
要因の全ての対に関してプロットを作成することでこのような二元均衡をグラフで確認するには、各プロットの横軸は $`x_i`$、縦軸は $`x_j`$ とする。
これらのプロットでは、応答変数 $`y`$ は考慮しない。
我々が関心を持っているのは計画の特性のみであるため、関係するのは $`x`$ 変数のみである。
優れた計画の2要因プロットのほとんどは、ある種の対称性と均衡した外観を示す――すべての組合せ点が網羅されており、各組合せ点にはほぼ同数のデータ点が存在すべきである。

#### 変動が最小限であるかの確認
最適な計画については、計画の質を反映し、計算可能な指標（D効率、A効率など）がある。
さらに、このような計画については、係数推定量の標準偏差の相対比や予測値の相対比を計算し、比較することが可能である。
こうした計算は、通常、最適計画の出力に特化したコンピュータ・パッケージを用いて行う。
