# 4.2.1.5. データは工程から無作為に抽出される

#### 工程を反映していなければならないデータ
[工程に内在する無作為な変動は、ほとんどのモデル化手法において満足のいく結果を得るために重要である](pmd211.md#rrv)ため、データがその無作為な変動を代表する形で反映していることが重要である。
しかし、代表的でない採取方法はほぼ無限にあるため、データに及ぼす影響を補正できる統計的手法は、例えあったとしてもごくわずかである。
その代わりにこれらの手法は、データが工程を代表しているという仮定に基づいている。
つまり、データのばらつきが工程を代表していない場合、関数 $`f(\vec{x};\vec{\beta})`$ で記述されるモデルの決定論的部分の性質は不正確なものとなる。
その結果、工程に関する科学的や工学的な疑問に答えるためにモデルが用いられたとき、誤った結論が導き出される可能性が高くなる。

#### 偏りのない標本抽出が最もよく工程を反映するデータ
特定のデータ集合における実際の偶然誤差が何であるかを決して特定できないことを踏まえると、データを工程から無作為に抽出することで最も代表的な標本を得ることができる。
単純無作為抽出では、標本抽出の対象となる母集団からの各観測値が、等しい確率で観測されることになる。
その結果、各標本が工程の代表として保証することはできないが、無作為抽出は、データ収集の過程において、平均的に見てデータに偏りが生じないことを確実にする。
これは、ほとんどの場合、繰り返し標本のデータが工程を代表していることを意味する。
さらに、無作為抽出の下では、確率論を用いて、特定のモデル化手順がデータの比較的極端な変動によってどの程度の頻度で影響を受けるかを定量化することができ、それによって、その工程に関する疑問に答えるときに生じる誤差率を制御することが可能になる。

#### この仮定は比較的制御可能
データの取得は、もちろん工程自体の特徴というよりは、実際には分析者が行う作業である。
これにより、分析者はこの仮定が有効であることをある程度保証することができる。
データ収集手順に細心の注意を払い、実行順序の無作為化といった実験計画法の原則を採用することで、工程から可能な限り完全に無作為に抽出されたものに近いデータ標本が得られる。
[4.3.3節](../section3/pmd33.md)では、適切な実験計画法の原則についてさらに詳しく論じている。
