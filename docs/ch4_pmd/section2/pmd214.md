# 4.2.1.4. 偶然誤差は正規分布に従う

#### 分布情報の主なニーズは推論
データにモデルを適合させ、妥当性を検証した後、工程に関する科学的または工学的疑問は、通常、そのモデルを用いて関連する工程量の統計的区間を計算することで解決される。
これらの区間は、データおよび工程に関する基礎的な前提条件に基づいて、工程母数の妥当な値の範囲を示す。
しかし、[工程の統計的な性質](pmd211.md#sp)上、これらの区間が常に真の工程母数を含み、実用的なほど十分に狭い範囲であることを保証できるとは限らない。
その代わりに、これらの区間には確率論的な解釈があり、指定された割合の時間で真の工程母数を網羅することが保証される。
これらの区間が真に指定された確率的解釈を持つためには、偶然誤差の分布形状が既知でなければならない。
確率分布の形状が既知でなければならないが、その分布の母数はデータから推定することができる。

もちろん、さまざまな種類の工程の偶然誤差は、一様、三角、二重指数、二項、Poisson 分布など、広範な範囲のさまざまな確率分布のいずれかで記述することができる。
しかしながら、ほとんどの工程モデル化手法では、工程に関する推論は、偶然誤差が正規分布から抽出されるという考えに基づいている。
これが行われる理由の一つは、正規分布が実際の工程における偶然誤差の実際の分布を比較的適切に記述することが多いためである。
正規分布は、その背後にある数学的理論が十分に開発され、工程に関するさまざまな質問に関連したデータの関数の広範な推論を支持していることから使用される。

#### 誤った推論につながる非正規偶然誤差
もちろん、もしその工程における偶然誤差が正規分布に従わないことが判明した場合、その工程について行われた推論はすべて誤りとなる可能性がある。
もし、偶然誤差の真の分布が、データのばらつきが正規分布の場合よりも小さいものである場合、工程母数の値を捉えるために用いられる信頼区間が、単に必要以上に少し長くなってしまう可能性がある。
その場合、区間が真の工程母数を含む頻度は予想よりも高くなる。
しかし、むしろ、区間が短すぎたり、推定対象の工程母数の真の平均値からずれてしまったりする可能性が高い。
その結果、真の工程母数を含む区間は、予想よりも頻度が低くなる。
このような場合、正規分布の仮定の下で計算された区間によって、工程に関する誤った結論が導き出される可能性が高くなる。

#### ガウス誤差が必要になる母数推定法
母数推定に用いられる手法によっては、正規分布に従う偶然誤差という仮定が暗黙的に含まれる場合もある。
[最尤法](../../ch8_apr/section4/apr412.md)のような一部の手法は、母数推定値を得るために偶然誤差の分布を直接利用する。
最小二乗法のように、母数推定に分布に基づく手法を直接用いない手法であっても、極端な無作為な変動がないデータに対しては、多くの場合、最良の結果が得られる。
正規分布は、極端な偶然誤差が稀な確率分布の一つである。
もし他の分布が、正規分布よりも偶然誤差をより適切に記述している場合、モデル内の未知母数値の良好な推定値を得るために、異なる母数推定手法を用いる必要があるかもしれない。
