# 4.2.1.3. 偶然誤差の標準偏差は一定である

#### データすべてを平等に扱うほとんどの工程モデル化手法
無作為なばらつきが存在するため、データ集合内のデータすべての品質が均一であるかを判断するのは困難な場合がある。
その結果、ほとんどの工程モデル化手法では、モデル内の未知母数を推定するときに、すべてのデータを同等に扱う。
また、ほとんどの手法では、予測や校正の不確かさを計算するときに、データに含まれる無作為な変動量の単一推定値として用いる。
すべてのデータを同じように扱うことで、より単純で使いやすいモデルが得られる。
しかし、当然のことながら、もしデータの質がすべて均一ではないことが判明した場合、データをこのように扱うという決定は、結果として得られるモデル品質に悪影響を及ぼす可能性もある。

#### 標準偏差によるデータ品質の測定
もちろん、データの各点ごとに誤差の大きさが異なることはデータを直接観察すれば明らかであるため、データの品質を点ごとに測定することはできない。
その代わりに、根本的な平均平方誤差、すなわち<u>分散</u>が同じであるデータ点は、同等の品質であるとみなせる。
この基準を満たすデータ点で観測された具体的な工程応答値の誤差はそれぞれ異なるが、そのようなデータ点で収集されたデータは、繰り返しデータ収集を行っても同等の品質を保つ。
各説明変数値の組合せにおけるデータの標準偏差は単にその分散の平方根であるため、説明変数の異なる組み合わせごとのデータの標準偏差もデータ品質を測定するために使用できる。
実際、標準偏差が好まれるのは、応答変数と同じ単位で測定されるという利点があり、この統計量との関連付けが容易になるためである。

#### 前提条件が不要な加重最小二乗法
偶然誤差の標準偏差が一定であるという仮定は、[加重最小二乗回帰](../section1/pmd143.md)には暗黙的に含まれていない。
その代わりに、分析で与えられた重みが、応答変数に存在する変動性の違いを正しく反映していると仮定される。
そして、これらの重みを用いて、各データ点がモデル母数の推定値に及ぼす影響の度合いを適切な水準に調整する。
また、データ集合の異なる領域おいて、予測および校正の不確かさを正しい水準に調整するためにも用いられる。

#### LOESSにも当てはまる前提条件
モデル母数の推定に加重最小二乗法を用いてはいるが、[LOESS](../section1/pmd144.md)は依然として標準偏差が一定であるという仮定に依存している。
LOESSで使用される重みは、実際には、各説明変数値の集合における応答の精度水準ではなく、説明変数空間内の近接する点における平均応答値間の相対的な類似度を反映している。
実際、LOESSはデータの各局所的な部分集合において個別の母数推定値を用いるため、母数推定においてデータの標準偏差が一定であるという仮定を必要としない。
LOESSで使用されるデータの部分集合は通常十分に小さいため、各部分集合内でのデータの精度はほぼ一定である。
ただし、LOESSは通常、データ集合全体に渡る精度の差異に応じて不確かさの計算を調整する仕組みは備えていない。
