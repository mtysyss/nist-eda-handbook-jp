# 4.2.1. 工程モデル化において想定される一般的な前提条件

#### 4.2.1節の概要
この節では、ほとんどの工程モデル化方法の基礎にある典型的な前提条件を列挙する。
以下の各ページでは、主要な前提条件 6つのうち1つを個別に説明し、その重要性の理由についても簡潔に論じるとともに、特定の前提条件に当てはまらない手法があればそれを指摘する。
[前のページ](pmd2.md)で述べたように、工程モデル化方法そのものに内在する特性に基づく、暗黙の前提条件である。
特定の応用分野においてこれらの方法を成功裏に活用できるかは、その存在が認識されているか否かにかかわらず、基礎となる前提条件の妥当性にかかっている。
[4.4.4節](../section4/pmd44.md)では、これら前提条件の妥当性を検証する方法について論じている。

#### 工程のモデル化における一般的な前提条件
1. [工程は<u>統計的</u>過程である](pmd211.md)  
2. [偶然誤差の平均はゼロである](pmd212.md)  
3. [偶然誤差の標準偏差は一定である](pmd213.md)  
4. [偶然誤差は正規分布に従う](pmd214.md)  
5. [データは工程から無作為に抽出される](pmd215.md)  
6. [説明変数は誤差なく観測される](pmd216.md)
