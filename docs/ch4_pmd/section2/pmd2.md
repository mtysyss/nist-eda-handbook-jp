# 4.2. 工程モデル化の基礎にある前提条件

#### ほとんどの行動の根底にある暗黙の前提
人々がとる思慮深い行動のほとんどは、すべてとは言わないまでも、その行動が達成したい目標にどのような影響を与えるかという考えや仮定に基づいている。
しかし、特定の行動方針を決定する際に実際に用いられる仮定が、明示的に示されることはめったにない。
その代わりに、行動そのものの性質によってのみ暗示されるに過ぎない。
暗黙の前提は、他のほとんどの種類の行動と同様に、工程モデル化活動にも内在している。
どの工程のモデル化手法においても、その暗黙の前提が何であるかを理解することは、前提の妥当性が分析の目標達成に影響するため重要である。

#### 行動のフィードバックを得るための仮定の確認
特定の行動の基礎にある暗黙の前提が正しくない場合、その行動も期待を満たすことはまずない。
目標が達成されたかは、時には一目瞭然の場合もあるが、残念ながら常にそうであるとは限らない。
特に、ほとんどの工程モデル化の応用事例において、目標の達成状況に関する即時のフィードバックを得ることは通常不可能である。
科学的または工学的な疑問への回答といった工程モデル化の目標は、工程モデルの正確性に依存しているが、その正確性は多くの場合、時間の経過とともに初めて直接的かつ絶対的に判断できるものである。
しかし、即時的かつ直接的なフィードバックの代わりに、工程モデル化分析の有効性に関する間接的な情報は、基礎となる仮定の妥当性を確認することで得ることができる。
基礎となる仮定が妥当であるかを確認することは、分析手法が適切であったこと、結果が目標と整合していることを保証するのに役立つ。

#### 第4.2節の概要
この節では、ほとんどのモデルの当てはめ方法に関連する具体的な基礎的な仮定について論じる。
基礎的な仮定を議論するにあたり、モデル化工程を完了前に打ち切り、分析結果が基礎的な仮定と矛盾したままにしてしまうことによる影響についても、背景情報を併せて提供する。
特定の事例においてこれらの仮定が成り立つかを確認するために使用できる具体的なデータ分析手法については、[4.4.4節](../section4/pmd44.md)に記載している。
