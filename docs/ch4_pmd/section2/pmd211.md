# 4.2.1.1. 工程は <u>統計的</u> 過程である

#### 無作為なばらつきを意味する「統計的」
工程モデル化のあらゆる統計的手法に内在する最も基本的な前提条件は、記述対象の工程が実際に統計的過程であるいうことである。
この前提条件はあまりにも自明であるため、工程の詳細に没頭している分析者や、興味深い新しいデータ集合から有用な情報を急いで引き出そうとしている分析者に見過ごされることがある。
しかし、統計的手法を用いて工程をうまくモデル化するためには、その工程に無作為なばらつきが含まれていなければならない。
無作為なばらつきこそが、その工程を純粋に決定論的なものではなく、統計的なものにする要素である。

#### 無作為ばらつきの役割
工程モデル化のために設計されたものを含め、あらゆる統計的手法の全体的な目的は、ノイズの多いデータから妥当な結論を導き出せるようにすることにある。
その結果、統計的手法は、データ集合に見られる表向きの影響をデータ内のノイズと比較し、その影響が何らかの繰り返し性のある根本的現象によって引き起こされている可能性が高いのか、それとも偶然に生じたデータのばらつきによるものなのかを判断するように設計されている。
したがって、工程における無作為なばらつきは、工程の決定論的部分の性質について結論を導き出すための基準となる。
もし工程に無作為なノイズが存在しなければ、統計的手法に基づいた結論はもはや意味をなさず、適切でもなくなる。

#### 妥当な前提条件
幸いなことに、この前提条件はほとんどの物理的過程において成り立つ。
何かを測定する必要がある場合、ほぼ常に測定には偶然誤差が生じる。
実際、複雑で現実的な過程においては、測定誤差に加えて、他の偶然誤差の要因が存在することがよくある。
しかし、非統計的過程の例として以下が含まれる。

1. 偶然誤差が系統誤差に比べて無視できるほど小さい物理的過程
2. 決定論的なコンピュータ・シミュレーションに基づく過程
3. 理論計算に基づく過程

これら種類の工程モデルが必要な場合は、統計的過程のモデル化ツールではなく、数学的なモデル化ツールの使用がより適切である。

#### 工程種類の区別
ある工程が統計的である確実な指標の一つは、特定の固定された条件下でその工程の応答を繰り返し観測したときに、異なる結果が得られるかである。
しかしながら、逆に、工程の応答を繰り返し観測しても常に同じ値が得られるという場合は、必ずしもその工程が非統計的であることを示す確実な指標とはならない。
例えば、理論方程式の解を近似するために複雑な数値手法が用いられるある種の計算では、丸め誤差、多段階の近似、収束判定基準、その他の誤差要因が相互に作用するため、計算結果が真の解から本質的に無作為な形で逸脱することがある。
それでもなお、計算の初期条件が毎回同じ値にリセットされるため、計算を繰り返すたびに結果が同じになる可能性がある。
その結果、特定の工程が統計的であるかを判断するためには、その工程に関する科学的または工学的な知見も常に活用しなければならない。
