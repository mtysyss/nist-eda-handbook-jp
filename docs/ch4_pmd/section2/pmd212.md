# 4.2.1.2. 偶然誤差の平均はゼロである

#### 母数推定に必要なデータと回帰関数との間の既知の関係
回帰関数における未知母数を推定するためには、説明変数空間の各点におけるデータが、回帰関数の対応する値とどのように関連しているかを理解する必要がある。
例えば、応答変数値を観測するために使用される測定システムが時間の経過とともに偏位する場合、データにおける決定論的な変動は偏位関数と真の回帰関数の和となる。
その結果、回帰関数を導出するために、モデルの適合前にデータを調整するか、適合後のモデルを事後的に調整する必要がある。
いずれの場合も、偏位関数の形状に関する情報が必要である。
偏位補正のような処理を一般的過程に一般化することは困難であり、また多くの工程では不必要であるため、ほとんどの工程モデル化手法は、観測された応答が平均的に回帰関数値と直接等しいデータに依存している。
この考え方を別の表現で言えば、説明変数値の各組合せにおける偶然誤差の平均がゼロであるということになる。

#### 実験計画法による前提条件の妥当性向上
この前提条件の妥当性は、過程の性質と、ある程度は、用いられるデータ収集手法の両方によって決まる。
工程によっては、データの測定が容易であり、データが回帰関数と直接的な関係にあることが明らかな場合もある。
この場合、最適なデータ収集手法を用いても、モデル化の成否に対して重要な要素とはならない。
もちろん、確実にそうなるかはめったに分からないため、通常は、可能な限り最善の方法でデータを収集する努力を払う価値がある。

他の工程では、測定の偏位やその他の系統的誤差により、扱いにくい可能性がある。
これら工程においては、[測定順序の無作為化](../section3/pmd33.md)などの優れた実験計画法を用いることで、系統的誤差の影響の排除や、少なくとも、削減できる可能性がある。
無作為化は、系統的測定誤差を追加される無作為な工程誤差に効果的に変換する。
工程に偶然誤差を加えることは望ましくないが、これにより回帰関数に関するデータから可能な限り最良の情報が得られ、これが現在の目標となる。

最も難解な工程では、優れた実験計画でさえ、系統的誤差が高いデータ集合を救い出せないことがある。
このような状況において、期待できる最善は、真の回帰関数が分析によって特定されていないという事実を認識することである。
その結果、追加情報を用いて系統的誤差を補正したり、測定システムを再設計して系統的誤差を排除したり、問題を再定式化して必要な情報を得る別の方法で、問題解決のより良い方法を見つける努力を注ぐことができる。


#### 観測 $`\vec{x}`$ の誤差によって破られる前提条件
この前提条件に対するもう1つのより軽微な違反は、説明変数が偶然誤差を伴って観測される場合に生じる。
直感的には、説明変数の偶然誤差は、応答変数の観測における偶然誤差と同様に、平均的には相殺されるように思えますが、残念ながらそうはならない。
モデルの関数部分における未知母数と説明変数との直接的な関連性により、この状況は、応答変数の偶然誤差の場合よりもはるかに複雑になる。
なぜこのようなことが起こるのかについての詳細は、[4.2.1.6節](pmd216.md)を参照のこと。
