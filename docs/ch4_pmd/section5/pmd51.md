# 4.5.1. モデルを用いた予測の種類

#### 予測に関する詳細情報
この節では、[4.1節](../section1/pmd1.md)から[4.4節](../section4/pmd4.md)までで開発について議論された様々な工程モデルを用いて行うことができる、異なる種類いくつかの予測について詳述する。
各種類の推定や予測に関した計算式やアルゴリズムを示すとともに、その確率論的解釈を示すシミュレーション例も併せて示す。
推定と予測のさまざまな種類に関する概要は、[4.1.3.1節](../section1/pmd131.md)に記載している。
工程モデルのその他の用途に対する推定と予測に関する簡単な説明は、[4.1.3節](../section1/pmd13.md)に示している。
