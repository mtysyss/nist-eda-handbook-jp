# 4.5.2. 校正のための工程モデルの活用

#### 詳細な校正情報
この節では、前節での開発について述べたさまざまな工程モデルを用いて行うことのできる、いくつかの異なる種類の校正について詳述する。
各校正の種類ごとに計算式やアルゴリズムを示し、その確率論的解釈を示すシミュレーション例も併せて提示する。
校正の概要については、[4.1.3.2節](../section1/pmd132.md)を参照のこと。
校正と工程モデルのその他の用途との簡単な比較については、[4.1.3節](../section1/pmd13.md)に記載している。
校正に関する追加情報は、[2章: 測定工程の特徴付け](../../ch2_mpc/mpc.md)の[3節](../../ch2_mpc/section3/mpc3.md)に記載している。
