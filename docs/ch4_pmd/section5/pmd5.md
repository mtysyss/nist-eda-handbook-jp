# 4.5. 工程モデルの活用と解釈

#### 第4.5節の概要
この節では、[4.3節](../section3/pmd3.md)および[4.4節](pmd4.md)4節で説明した手順を用いてデータを収集し、分析し、そこから策定されたモデルの解釈と活用について解説する。
こうしたモデルの主な用途である推定、予測、校正の3つについて詳細に説明する。
この種のモデルのもう一つの重要な用途である最適化については、主に[5章：工程の改善](../../ch5_pri/pri.md)で議論している。
