# 4.5.3. 工程モデルを使用した工程の最適化

#### 工程最適化に関する詳細情報
[応答曲面計画](../../ch5_pri/section3/pri336.md)を用いて収集したデータに適合させたモデルを用いた工程の最適化については、主に[5章：工程の改善」](../../ch5_pri/pri.md)の[5.5.3節](../../ch5_pri/section5/pri53.md)で扱っている。
同節では、目標出力値を達成するため、あるいは工程出力を最大化または最小化するために、適切な工程入力値を決定する方法について詳細な情報を示している。
ただし、最適化のための工程モデルの利用に関する背景情報は、本章の[4.1.3.3節](../section1/pmd133.md)にあり、最適化実験から得られたデータの基本的分析に関する情報は、他の種類のモデルに関する情報とともに、本章の[4.1節](../section1/pmd1.md)から[4.4節](../section4/pmd4.md)にかけて解説している。
