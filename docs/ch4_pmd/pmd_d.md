# 4. 工程のモデル化 - 詳細目次 [4.]

本章の目的は、特定の科学的もしくは工学的工程を記述する統計モデルの構築に必要な背景と具体的分析技法を示すことである。
本章で議論されるモデルの種類は明示的な数学関数に基づいたものに限られる。
この種のモデルは、工程出力の予測、校正、工程最適化に用いられる。
