# 4.8.1.2.2. 1次関数／1次有理関数

![Linear / Linear Rational Function](https://www.itl.nist.gov/div898/handbook/pmd/section8/plots/r11p1.r.gif)

| **関数：** | $`\displaystyle f(x) = \frac{\beta_0 + \beta_1x}{1 + \beta_2x}, \beta_1 \neq 0, \beta_2 \neq 0`$ |  
| **関数族:** | 有理 |  
| **統計の種類** | 非線形 |  
| **定義域** | $`\displaystyle \left(-\infty, -\frac{1}{\beta_2}\right) \cup \left(-\frac{1}{\beta_2}, \infty\right)`$ |  
| **値域** |  $`\displaystyle \left(-\infty, \frac{\beta_1}{\beta_2}\right) \cup \left(\frac{\beta_1}{\beta_2}, \ \infty\right)`$  |  
| **特別な特徴** | 水平漸近線:<br>$`\displaystyle y = \frac{\beta_1}{\beta_2}`$<br>垂直漸近線:<br>$`\displaystyle  x = -\frac{1}{\beta_2}`$ |  
| **追加例** | |
