# 4.8.1.2.6. 3次／1次有理関数

![examples of cubic/linear rational functions](https://www.itl.nist.gov/div898/handbook/pmd/section8/plots/r31p1.r.gif)

|||  
| :--- | :--------- |  
| **関数：** | $`\displaystyle f(x) = \frac{\beta_0 + \beta_1x + \beta_2x^2 + \beta_3x^3}{1 + \beta_4x}, \ \ \beta_3 \neq 0, \ \beta_4 \neq 0`$ |  
| **関数族:** | 有理 |  
| **統計の種類** | 非線形 |  
| **定義域** | $`\displaystyle \left( -\infty, \ -\frac{1}{\beta_4} \right) \ \cup \ \left( -\frac{1}{\beta_4}, \ \infty \right)`$ |  
| **値域** |  $`\displaystyle (-\infty, \infty)`$  |  
| **特別な特徴** | 垂直漸近線: <br>$`\displaystyle x = -\frac{1}{\beta_4}`$ |  
| **追加例** | |
