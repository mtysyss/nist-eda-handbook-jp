# 4.8.1.2.3. 1次／2次有理関数

![examples of linear/quadratic rational functions](https://www.itl.nist.gov/div898/handbook/pmd/section8/plots/r12p1.r.gif)

|||  
| :--- | :--------- |  
| **関数：** | $`\displaystyle f(x) = \frac{\beta_0 + \beta_1x}{1 + \beta_2x + \beta_3x^2}, \beta_1 \neq 0, \beta_3 \neq 0`$ |  
| **関数族:** | 有理 |  
| **統計の種類** | 非線形 |  
| **定義域** | $`\displaystyle (-\infty, \infty)`$<br>未定義点: <br>$`\displaystyle x = \frac{-\beta_2 \pm \sqrt{\beta_2^2 - 4\beta_3}} {2\beta_3}`$<br>$`\displaystyle \beta_2^2 - 4\beta_3`$<br> が負、ゼロ、正のいずれかに応じて<br>本式に 0もしくは、1、2の実数解が存在する。 |  
| **値域** |  $`\displaystyle (-\infty, \infty)`$  |  
| **特別な特徴** | 水平漸近線: <br>$`\displaystyle y = 0`$<br>水平漸近線: <br>$`\displaystyle x = \frac{-\beta_2 \pm \sqrt{\beta_2^2 - 4\beta_3}} {2\beta_3}`$<br>$`\displaystyle \beta_2^2 - 4\beta_3`$<br> が負、ゼロ、正のいずれかに応じて<br>本式に 0もしくは、1、2の実数解が存在する。 |  
| **追加例** | |
