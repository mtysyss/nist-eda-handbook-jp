# 4.8. 工程のモデル化に役立ついくつかの関数

#### 4.8節の概要
本節では、工程モデル化で一般的に使用される関数いくつかのを列挙している。
もちろん、有用な関数の網羅的な一覧を作成することは不可能であるが、特定の工程を記述するために経験的モデルを開発する必要がある場合、ここで紹介する関数は、多くの場合、良い出発点となる。

ここに列挙された各関数は、可能であれば関連する関数族に分類している。
その統計の種類（係数が線形か非線形か）も示している。
各関数の特別な特徴（漸近点など）は、関数の定義域（許容入力値の集合）および範囲（可能な出力値の集合）とともに列挙している。
各関数が取り得るさまざまな形状のいくつかのプロットも含んでいる。
