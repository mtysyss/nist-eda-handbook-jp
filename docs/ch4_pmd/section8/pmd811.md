# 4.8.1.1. 多項式関数

#### 多項式関数
多項式関数とは次の形をもつ関数のことである。

$$f(x) = a_{n}x^{n} + a_{n-1}x^{n-1} + ... + a_{2}x^{2} + a_{1}x + a_{0}$$

ここで、$`n`$ は多項式の<u>次数</u>を決める非負の整数を表す。
次数が 0 の多項式は単に定数であり、次数が 1 のものは直線、次数が 2 のものは2次関数、次数が 3 のものは3次関数というように続く。

#### 多項式モデル：利点
歴史的には、多項式モデルは関数の適合に最も頻繁に用いられてきた経験的モデルの一つである。
これらのモデルが広く用いられているのは以下の理由に拠る。

1. 多項式モデルは形式が単純である。
2. 多項式モデルは、性質がよく知られ、理解されている。
3. 多項式モデルは、形状の柔軟性が適度にある。
4. 多項式モデルは閉じた族である。
生データの位置や広がりの変化がある場合、ある多項式モデルから別の多項式モデルに写像される。
つまり、多項式モデルは基礎となる計量に依存しない。
5. 多項式モデルは計算処理が容易である。

#### 多項式モデル：制約
1. 多項式モデルは補間特性に乏しい。
高次多項式は、正確に適合した値の間で振動が生じやすいことで悪名高い。
2. 多項式モデルは外挿特性に乏しい。
多項式はデータの範囲内では良好な適合を示す場合があるが、データの範囲外では適合度が急速に低下することが多い。
3. 多項式モデルは、漸近的な性質が劣る。
その性質上、多項式は有限の $`x`$ 値に対しては有限の応答を示し、$`x`$ 値が無限大である場合にのみ無限の応答を示す。
したがって、多項式では 漸近的な現象を十分にモデル化できない場合がある。
4. 多項式モデルには、形状と次数の妥協点がある。
複雑な構造を持つデータをモデル化するためには、モデルの次数を高くする必要があり、推定すべき係数の数も多くなる。
その結果、非常に不安定なモデルに繋がることがある。

#### 例
[ロードセルの校正](../section6/pmd61.md)事例研究には、2次多項式モデルの適合例を含んでいる。
