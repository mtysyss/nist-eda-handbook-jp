# 4.8.1.2.4. 2次／1次有理関数

![Quadratic / Linear Rational Function](https://www.itl.nist.gov/div898/handbook/pmd/section8/plots/r21p1.r.gif)

|||  
| :--- | :--------- |  
| **関数：** | $`\displaystyle f(x) = \frac{\beta_0 + \beta_1x + \beta_2x^2}{1 + \beta_3x}, \ \ \beta_2 \neq 0, \ \beta_3 \neq 0`$ |  
| **関数族:** | 有理 |  
| **統計の種類** | 非線形 |  
| **定義域** | $`\displaystyle \left(-\infty, \ -\frac{1}{\beta_3}\right) \ \cup \ \left(-\frac{1}{\beta_3}, \ \infty\right)`$ |  
| **値域** |  $`\displaystyle \left\{\begin{array}{lll}(-\infty, \infty) & \text{for} & \beta_2^2-(\beta_1-\beta_0\beta_3)\beta_2\beta_3 \leq 0 \\ (-\infty, f_{max}] \cup [f_{min}, \infty) & \text{for} & \beta_2^2-(\beta_1-\beta_0\beta_3)\beta_2\beta_3 > 0 \end{array} \right.`$<br>このとき<br>$`\displaystyle f_{min} = \max \left[f \left( \frac{-\beta_2-\sqrt{\beta_2^2-\beta_0\beta_3}}{\beta_2\beta_3} \right), \ f \left( \frac{-\beta_2+\sqrt{\beta_2^2-\beta_0\beta_3}}{\beta_2\beta_3} \right) \right]`$<br>および<br>$`\displaystyle f_{max} = \min \left[f \left( \frac{-\beta_2-\sqrt{\beta_2^2-\beta_0\beta_3}}{\beta_2\beta_3} \right), \ f \left( \frac{-\beta_2+\sqrt{\beta_2^2-\beta_0\beta_3}}{\beta_2\beta_3} \right)\right]`$  |  
| **特別な特徴** | 垂直漸近線: <br>$`\displaystyle x = -\frac{1}{\beta_3}`$ |  
| **追加例** | |
