# 4.8.1.2.1. 定数関数／1次有理関数

![Constant / Linear Rational Function](https://www.itl.nist.gov/div898/handbook/pmd/section8/plots/r01p1.r.gif)

|||  
| :--- | :--------- |  
| **関数：** | $`\displaystyle f(x) = \frac{\beta_0}{1 + \beta_1x}, \beta_0 \neq 0, \beta_1 \neq 0`$ |  
| **関数族:** | 有理 |  
| **統計の種類** | 非線形 |  
| **定義域** | $`\displaystyle  (-\infty, \ -\frac{1}{\beta_1}) \ \cup \ (-\frac{1}{\beta_1}, \infty)`$ |  
| **値域** | $`\displaystyle (-\infty, 0) \cup (0,\infty)`$ |  
| **特別な特徴** | 水平漸近線:<br>$`\displaystyle y=0`$<br>垂直漸近線:<br>$`\displaystyle x = -\frac{1}{\beta_1}`$ |
