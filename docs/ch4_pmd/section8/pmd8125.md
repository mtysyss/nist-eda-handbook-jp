# 4.8.1.2.5. 2次／2次有理関数

![examples of quadratic/quadratic rational functions](https://www.itl.nist.gov/div898/handbook/pmd/section8/plots/r22p1.r.gif)

|||  
| :--- | :--------- |  
| **関数：** | $`\displaystyle f(x) = \frac{\beta_0 + \beta_1x + \beta_2x^2}{1 + \beta_3x + \beta_4x^2}, \beta_2 \neq 0, \beta_4 \neq 0`$ |  
| **関数族:** | 有理 |  
| **統計の種類** | 非線形 |  
| **定義域** | $`\displaystyle (-\infty, \infty)`$<br>未定義点: <br>$`\displaystyle x = \frac{-\beta_3 \pm \sqrt{\beta_3^2 - 4\beta_4}} {2\beta_4}`$<br>$`\displaystyle \beta_3^2 - 4\beta_4`$<br> が負、ゼロ、正のいずれかに応じて<br>本式に 0もしくは、1、2の実数解が存在する。 |  
| **値域** | 値域は複雑で、次式の特定値に依存する。<br>$`\beta_1, \ldots , \beta_5`$ |  
| **特別な特徴** | 水平漸近線: <br>$`\displaystyle y = \frac{\beta_2}{\beta_4}`$<br>水平漸近線: <br>$`\displaystyle x = \frac{-\beta_3 \pm \sqrt{\beta_3^2 - 4\beta_4}} {2\beta_4}`$<br>$`\displaystyle \beta_3^2 - 4\beta_4`$<br> が負、ゼロ、正のいずれかに応じて<br>本式に 0もしくは、1、2の実数解が存在する。 |  
| **追加例** | |
