# 4.8.1.2.7. 3次／2次有理関数

![examples of cubic/quadratic rational functions](https://www.itl.nist.gov/div898/handbook/pmd/section8/plots/r32p1.r.gif)

|||  
| :--- | :--------- |  
| **関数：** | $`\displaystyle f(x) = \frac{\beta_0 + \beta_1x + \beta_2x^2 + \beta_3x^3}{1 + \beta_4x + \beta_5x^2}, \ \ \beta_3 \neq 0, \ \beta_5 \neq 0`$ |  
| **関数族:** | 有理 |  
| **統計の種類** | 非線形 |  
| **定義域** | $`\displaystyle (-\infty, \infty)`$<br>未定義点: <br>$`\displaystyle x = \frac{-\beta_4 \pm \sqrt{\beta_4^2 - 4\beta_5}} {2\beta_5}`$<br>$`\displaystyle \beta_4^2 - 4\beta_5`$<br> が負、ゼロ、正のいずれかに応じて<br>本式に 0もしくは、1、2の実数解が存在する。|  
| **値域** |  $`\displaystyle (-\infty, \infty)`$  |  
| **特別な特徴** | $`\displaystyle (-\infty, \infty)`$<br>未定義点: <br>$`\displaystyle x = \frac{-\beta_4 \pm \sqrt{\beta_4^2 - 4\beta_5}} {2\beta_5}`$<br>$`\displaystyle \beta_4^2 - 4\beta_5`$<br> が負、ゼロ、正のいずれかに応じて<br>本式に 0もしくは、1、2の実数解が存在する。 |  
| **追加例** | |
