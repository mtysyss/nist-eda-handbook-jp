# 4.8.1. 単変数関数

#### 8.1節の概要
本節では単変数関数を列挙している。
これらはそれ自体でモデル化に有用であるだけでなく、高次元関数の基本的な構成要素としても機能する。
[4.4.2.1節](../section4/pmd421.md)では、単変数関数から高次元工程の経験的モデルを構築するための指針をいくつか提示している。
