# 8.3.1.4. 加速寿命試験

#### 加速試験は、使用負荷下で大規模な標本数を試験しても、妥当な時間内に破損がほとんど発生しないか、まったく発生しない場合に必要である
加速寿命試験とは、部品を高い負荷下で動作させ、その故障データを観測する部品寿命試験のことである。
高負荷試験は、単にどこでどのように破損が発生するかを確認し、その情報を用いて部品の設計を改善したり、より適切な部品を選定したりすることを唯一の目的として実施することも可能であるが、本節では、以下の2つの目的のための加速寿命試験に焦点を当てる。

1. 負荷によって故障がどのように加速されるかを調査し、複数の負荷試験セルからのデータに加速モデルを適合させる。
2. 高負荷条件下で十分な故障データを取得し、使用時のCDFを正確に予測（外挿）する。

もし加速モデル（あるいは高負荷試験条件から通常の使用条件への加速係数）がすでに分かっている場合は、[2ページ前](apr312.md)に説明した手法を使用する。
したがって、ここでは、加速モデルが事前に分かっていないことを前提とする。

#### 試験計画とは、モデルを適合させ、予測を行うのに十分なデータを取得できるように負荷水準、標本規模、および試験時間を決定することを意味する
（複数の）負荷セル寿命試験の実験における試験計画および実施は以下の内容で構成される。

* 対象となる負荷（ <u>調査対象の破損機構</u>を促進する負荷）の組み合わせをいくつか選ぶ。
各組み合わせが「負荷セル」である。
なお、計画では一度に1つの破損機構のみを対象とする。
試験中に他の機構によって生じた破損は、[打切られた実行時間](../section1/apr131.md#Separating%20out%20Failure)  として扱われる。
* 使用する負荷水準が高すぎないよう注意する。
使用負荷下では決して発生しないような新たな破損機構が導入されるような水準になってはならない。
許容可能な最大負荷水準の選定には、経験および／または適切な技術的判断が必要である。
* 各負荷セルに部品の無作為抽出標本を配置し、各セル内の部品を一定（ただし異なる場合もある）時間運転する。
* 各セルからの故障データを収集し、そのデータを用いて加速モデルおよび寿命分布モデルを推定し、これらのモデルを用いて使用負荷条件における信頼性を予測する。

試験計画は、モデル化や実験計画法について論じた章で既に扱った内容と、1つの重要な点を除いて類似している。
負荷セル内で部品を一定期間試験する場合、通常、一部の（あるいは多くの）部品が破損することなく試験を終了することがある。
これが打切り問題であり、これにより実験計画法は極めて複雑になり、統計科学というよりも（工学的な判断に基づく）芸術に近いものとなってしまう。

計画の課題の説明に例を挙げる。
金属マイグレーション故障モードが次式によって与えられる[2負荷温度電圧モデル](../section1/apr153.md#Two%20Temperature/Voltage)に従うと考えることを仮定する。

$$t_f = A V^\beta \text{exp } \left( \frac{\Delta H}{kT} \right) .$$

通常使用条件は、4V、25℃とし、検討すべき高負荷水準は、6、8、12V、85、105、125℃である。
典型的試験時間内での妥当な故障数を得るための十分な負荷加速ではないセル条件であるため、（6V、85℃）での試験は、同様に（8V、85℃）、（6V、105℃）も資源の無駄の可能性がある。

電圧が行ごとに、温度が列ごとに増加する3×3行列に、全ての9つの可能な負荷せるの組合せを書き込むと、以下の結果行列が得られる。

**「逆向き L 設計」のための行列**

||||  
| :---: | :---: | :---: |  
| 6v, 85℃ | 6v, 105℃ | **6v, 125℃** |  
| 8v, 85℃ | 8v,105℃ | **8v,125℃** |  
| **12v,85℃** | **12v,105℃** | **12v,125℃** |  
{: .no-header-table}


#### 「逆L字型」の配置は、加速寿命試験でよく見られ、負荷の低い試験セルにはより多くの試験片を配置する
太字で示された組合せは、両方の負荷の全範囲を網羅しつつ、なおかつ破壊を引き起こすのに十分な加速度が得られる可能性が最も高い設計選択肢である。
これは、加速度モデル化実験で一般的に用いられる、いわゆる**「逆向き L」設計**である。

**注**：試験体の多くを低負荷セルに配置することは、これらのセルでは破損する試験体の割合が小さくなるという事実を補うため、設計上の良い慣行である。 

#### 試験計画がうまくいく可能性があるかどうかを見極めるには、シミュレーションが最善の方法となる場合もある

**シミュレーションによる設計：** 

試験行列を選択する上で、時間は掛かるがより優れた方法は以下の通り。

* （通常通り）[加速度モデル](../section2/apr24.md)と[寿命分布モデル](../section2/apr21.md)を選択する。
* 文献調査や過去の実験結果に基づいて、寿命分布モデルの形状母数の値を推定する。
[形状母数](../section1/apr14.md)は、すべての負荷セルで[同一であるべきである](../section1/apr14.md) 。
使用時の尺度母数の値を使用負荷CDFが要件を正確に満たすように選択する（すなわち、対数正規分布の場合は、所望の使用信頼性を得る使用寿命 $`T_{50}`$ を選択し、Weibull モデルを選択する場合は、特性寿命母数についても同様に扱う）。
* 加速モデルの母数値（上記の2負荷モデルの場合、 $`\Delta H`$ および $`\beta`$ ）を推定する。
ここでも、類似の破壊機構に関する文献や、以前の実験データに基づいて値を設定する。
* 提案された試験セルから使用負荷を得るための加速係数を計算し、使用尺度母数をこれらの加速係数で割ることで、「試行」セルスケール母数を導出する。
* 導出したセル尺度母数と推定した形状母数を用いて、案された各負荷セルについてセル・データをシミュレーションする。
* 提案されたすべてのセルが、良好な推定値を得るのに十分な破壊事例を含むことを確認する。
* すべての条件が予想通りに進んだ場合、実験からモデル母数の良好な推定値を得るのに十分なデータが得られると確信できるまで、負荷セルの選択と標本規模の配分を調整する。 

#### 事前の推定を行った後、場合によっては最適な実験計画法を構築できることもあるが、そのためのソフトウェアはほとんどない

**最適設計：** 

加速寿命試験の設計に関する最近の研究により、特定のモデルと未知母数の仮定値が与えられた場合、最適設計（モデル母数の良好な標本推定値を得る可能性が最も高い設計）を構築することが可能であることが示されている。
これらの最適設計では、通常、負荷水準を可能な限り広く間隔を空けて設定し、低負荷セルへの標本単位の割り当てに大きな重み付けを行う。
しかし、実験者が自身の特定のモデル選択に対応したこれらの最適手法を組み込んだソフトウェアを見つけられなければ、上記で説明した手法が加速実験を設計する上で最も実用的な方法である。
