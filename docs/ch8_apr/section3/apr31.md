# 8.3.1. 信頼性評価試験の計画方法

#### 信頼性試験の計画書は、試験の実施方法に関する詳細な説明で締めくくられ、その冒頭では、前提条件と明らかにしたいことや証明したいことを明記することから始める

信頼性試験の計画とは、

* 試験期間はどのくらいにするべきか。
* 試験対象とする部品数は。
    * 修理系の場合、これは多くの場合1台に限定される。
* 実験計画に[加速モデル化](../section1/apr14.md)が含まれる場合
    * どのような応力の組み合わせで、実験セルをいくつ用意すべきか。
    * 各セルには何台の部品を入れるべきか。
    
これらの質問に対する答えは以下の要因によって異なる。

* どのようなモデルを想定しているか。
* 試験を実施し、データを分析した後、どのような決定や結論を導き出したいか。
* 誤った決定や結論を下すリスクをどの程度許容できるか。

使用を検討しているすべてのモデルについて、これらの問いに完全に答えることが常に可能であるとは限らず、現実的でもない場合がある。
本節では、以下のモデルに対する回答あるいは指針について検討する。

* [指数分布モデルまたは HPPモデル](apr311.md)
* [Weibull モデルまたは対数正規モデル](apr312.md)
* [Duane または NHPP冪乗則モデル](apr313.md)
* [加速モデル](apr314.md)
* [ベイズ・ガンマ事前分布モデル](apr315.md)
