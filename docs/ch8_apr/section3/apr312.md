# 8.3.1.2. 対数正規分布または Weibull 分布検定

#### 計画指数分布以外の分布に対する信頼性試験の計画は難しく、多くの推測を要する
信頼性試験の計画は、想定されるモデルが対数正規分布や Weibull 分布である場合、信頼性試験の計画は単純明快なものではない。
これらのモデルには2母数があるため、少なくとも2件の試験故障がなければ推定は不可能であり、適切な推定を行うにはそれよりもはるかに多くのデータが必要である。
打切りの影響により、未知母数について事前に適切な推測をしておかない限り、どのような試験計画も失敗する。

しかし、多くの場合、未知母数のうち少なくとも1つ（通常は「形状」係数、対数正規分布では *σ*、 Weibull 分布では *γ*）については、事前に適切な推測を立てることができる。
1母数が既知であると仮定すれば、被試験製品の信頼性または故障率が許容範囲内であることを保証する試験計画を策定できる。

**対数正規分布の場合（形状母数が既知）**：対数正規分布モデルは、エレクトロマイグレーションなど、多くのマイクロエレクトロニクスの摩耗による故障機構に用いられる。
生産監視の一環として、生産ロットから無作為に採取されたマイクロエレクトロニクスチップの標本を、エレクトロマイグレーション故障の発生を著しく加速させるのに十分な高電圧および高温の条件下で試験することがある。
加速係数は過去の試験から既知であり、その範囲は数百から数千である。 

#### 対数正規分布の検定計画、シグマおよび加速係数が既知

目標は、試験計画を策定することである（*n* 個の部品を *T* 時間負荷試験にかけ、故障が *r* 件以下であればそのロットを合格とする）。
以下の仮定を置く。

* 寿命分布モデルは対数正規分布である。
* $`\text{シグマ} = \sigma_0`$ は過去の試験から既知であり、ロット間で著しい変動はない。
* ロット間の信頼性は、$`T_{50}`$ 値（対数正規分布の中央値または 50百分位数）がロットごとに異なるため変動する。
* 高応力から使用応力への加速係数は既知の値である「*A*」
* *T* 時間の応力時間は、ラインモニターとして実用的である
* 公称使用 $`T_{50}`$ を $`T_u`$（$`\sigma_0`$ と組み合わせて）とすると、許容可能な使用CDF（または使用信頼性関数）が得られる。
これは、例えば 100,000時間における許容可能な使用CDFを所定の値 $`p_0`$ と指定し、以下の式を用いて $`T_u`$  を計算することに相当する。
<br>$` T_u = 100,000 \text{exp }\left[-\sigma \Phi^{-1}(p_0)\right] `$
ここで、$`\Phi^{-1}`$ は標準正規分布の逆関数である。
* 許容できない使用の累積分布関数 $`p_1`$ については、上記の式で $`p_0`$ を $`p_1`$ に置き換えることで、$`T_b`$ の「不良」使用 $`T_{50}`$ が導かれる。

加速因子 *A* を用いて、負荷における「良好」または許容可能な故障率 $`p_a`$ および「不良」または許容できない故障率 $`p_b`$ を計算する。

$$ p_a = \Phi \left( \frac{\text{ln } (AT / T_u)}{\sigma_0} \right) , \quad p_b = \Phi \left( \frac{\text{ln } (AT / T_b)}{\sigma_0} \right) , $$

ここで、$`\Phi`$ は標準正規CDFである。
これにより、信頼性の問題は、6章で扱ったよく知られた[ロット抜取検査計画（LASP）](../../ch6_pmc/section2/pmc22.md)の問題に帰着される。

もし $`p_a`$ と $`p_b`$ を区別するために必要な標本規模が大きすぎる場合は、*T* を増やすか、より高い負荷下で試験を行う必要があるかもしれない。
重要な点は、上記の仮定と式によって、対数正規モデルを仮定した下での継続的な信頼性試験を計画するための方法論が得られるということである。 

#### ガンマおよび加速係数が既知であると仮定した Weibull 試験計画

** Weibull 分布の場合（形状母数が既知）：** 仮定および計算方法は、対数正規分布の場合と同様である。

* 寿命分布モデルは Weibull 分布である。
* $` \text{ガンマ} = \gamma_0`$ は過去試験から既知であり、ロット間で顕著な変動はない。
* ロットごとに *α* 値  （ Weibull の特性寿命、または 62.3百分位数）が異なるため、ロット間の信頼性にばらつきがある。
* 高応力から使用応力への加速係数は既知の値「*A*」である。
* *T* 時間の応力時間は、ラインモニターとして実用的である。
* 公称使用値 $`\alpha_u`$ （$`\gamma_0`$ と組み合わせて）を用いると、許容可能な使用CDF（または使用信頼性関数）が得られる。
これは、例えば 100,000時間における許容可能な使用CDFを所定の値 $`p_0`$ と指定し、$`\alpha_u`$ を計算することに相当する。
<br>$` \alpha_u = \frac{AT}{\left[ -\text{ln } (1-p_0) \right]^{1/\gamma_0} } `$
* 許容できない使用CDFが $`p_1`$ の場合、上記の式で $`p_0`$ を $`p_1`$ に置き換えることで、$`\alpha_b`$ という「不良」な使用率 $`\alpha`$ が導かれる。

次に、加速因子 *A* を用いて、負荷下での「良好」または許容可能な故障率 $`p_a`$ および「不良」または許容できない故障率 $`p_b`$ を計算する。

$$ p_a = 1 - \text{exp } \left[ -\left( \frac{AT}{\alpha_u} \right)^{\gamma_0} \right] , \quad p_b = 1 - \text{exp } \left[ -\left( \frac{AT}{\alpha_b} \right)^{\gamma_0} \right] . $$

これにより、信頼性の問題は、第6章で扱った[ロット受入サンプリング計画（LASP）](../../ch6_pmc/section2/pmc222.md)の問題に帰着される。

もし $`p_a`$ と $`p_b`$ を区別するために必要な標本規模が大きすぎる場合、*T* を増加させるか、あるいはより高い負荷下で試験を行うことが必要になるかもしれない。
重要な点は、上記の仮定と式が、 Weibull モデルを仮定した下での継続的な信頼性試験を計画するための方法論を提供していることである。

 ** Weibull 母数と対数正規母数の両方を推定するための試験****計画** 

#### 一般的な対数正規分布または Weibull 分布を用いた寿命試験の計画に関する経験則
ここで言えるのは、いくつかの一般的な経験則だけである。

1. 少なくとも10件の正確な故障時刻を観察できれば、推定値は通常妥当なものとなる。
故障件数が 10件未満の場合、臨界形状母数を正確に推定するのは困難になる可能性がある。
故障件数が 5件未満の場合、推定値はしばしば非常に不正確になる。
2. 読出しデータの場合、総故障数が 10件を超えていても、正確な推定を行うには　3つ以上の読出し間隔で故障が発生している必要がある。
3. 試験に投入する部品数や試験期間を推測するときは、分布母数の妥当な組み合わせをいくつか試してみて、それに対応する試験中に予想される故障率の計算値に標本規模を乗じた結果が、妥当な故障数になるかどうかを確認する。
4. 最後の規則に代わる方法として、分布母数の妥当な組合せから試験データをシミュレーションし、そのシミュレーションデータから得られた推定値がシミュレーションで使用した母数に近い値になるかどうかを確認する。
もし試験計画がシミュレーション・データに対してうまく機能しない場合、実際のデータに対してもうまく機能する可能性は低い。
