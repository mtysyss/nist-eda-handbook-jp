# 8.3.1.3. 信頼性の向上（Duane モデル）

#### 信頼性向上試験実施期間の計画指針
信頼性向上試験は通常、多大な資源を要するため、試験にどれくらいの期間が必要かを推定する方法を確立しておくことが重要である。
以下の手順は、試験期間を決定するための出発点である。

1. 成長勾配である *β* の初期値を推測する。
これについては、以前いくつかの[指針](../section1/apr192.md#reliability%20improvement%20slope)を議論している。
保守的な見積もり（例えば、新しい部門横断チームが改善試験に取り組む場合や、改善対象のシステムに未知の故障機構を持つ新しい部品が多数含まれている場合など）には 0.3に近い値、より楽観的な見積もりには 0.5に近い値を選択する。
2. 現在のデータと技術的な推定値を用いて、システムの初期MTBFについて合意を得る。
これを $`M_1`$ とする。
3. $`M_T`$ を目標MTBF（顧客要件）とする。
すると、試験に必要な改善度は次式で与えられる。<br>
<br>$` IM = \frac{M_T}{M_1} .`$<br>
4. 必要な試験時間の初期推定値は、
$` T = IM^{1/\beta} . `$
この推定値は、初期のMTBFである $`M_1`$ を試験開始1時間後のMTBFとして扱い、1時間から *T* 時間までの改善度が単に$`T^\beta`$ となるという事実を用いたものである。

#### 試験時間が技術的に妥当であることを確認する
上記があくまで一次的な概算に過ぎない理由は、高い *β* を仮定すると、非現実的な（短すぎる）試験時間が計算されてしまうためである。
信頼性向上のための試験期間が極めて短いと、改善チームが信頼性を「高める」ための設計や部品の変更を決定するには、最低限の故障件数を観察する必要があるため、ほとんど意味がない。
また、これらの変更を実施し、修理率の改善が確認されるまでには時間が掛かる。

#### 反復シミュレーションは、試験計画の策定を支援する
[シミュレーション手法](../section1/apr191.md#Simulating%20NHPP%20Power%20Law%20Data)を用いることで、計画されている試験から、想定された成長率を実証するデータが得られるかを確認することも可能である。
