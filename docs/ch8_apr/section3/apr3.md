# 8.3. 信頼性データの収集

信頼性の評価や改善のために、故障データが通常必要である。
故障データは、システム実績の現場研究からもしくは、時に<u>寿命試験</u>と呼ばれる計画された信頼性試験から得られる。
本節は信頼性試験の計画方法に焦点を当てる。
目的は、試験すべきな期間、必要な標本規模、実行に求められる試験条件や負荷の程度といった問いに答えることである。
