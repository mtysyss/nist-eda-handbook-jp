# 8.2.3.1. 視覚による検定

#### モデルの視覚的検証は、そのモデルのデータとの整合を一目で把握できる、簡単なプロットのことである

これまでに、モデルの視覚的検証の例を数多く見てきた。
それらは、確率プロット、累積ハザードプロット、Duane プロット、傾向プロットである。
傾向プロットを除くすべてのケースにおいて、モデルは、データ点が直線にどれだけよく沿っているかによって「検証」された。
傾向プロットの場合、直線からの湾曲（累積修復プロット）や、規模の増減傾向（到着間隔および逆到着間隔）を確認した。

これらの単純なプロットは、人間の目がグラフを観察することでデータ内のパターンや異常をしばしば検出できるため、強力な診断ツールである。
分析者がモデルの適合度を確認するために定量的な統計的検定のみを使用していた場合、そのような貴重な情報は失われてしまう。
あらゆる分析には、適用可能な限り多くの視覚的検定を含めるべきである。

**視覚による検定の利点**

1. 理解しやすく、説明も容易である。
2. データ内のパターンや異常を明らかにできる。
3. モデルが視覚による検定に「合格」した場合、定量的統計検定によってそのモデルが「棄却」される可能性は比較的低くなる（人間の目はより厳格であり、偽の傾向を検出する可能性が高い）。 

#### 視覚的な検定と形式的な定量的検定を組み合わせ、「両方の長所を活かした」手法を採用する

**視覚検査の欠点**

1. 視覚的検証は主観的である。
2. モデルがデータにどの程度適合しているか、あるいは適合していないかを定量的に評価することはできない。
3. データに適合しているように見える2つ以上の競合するモデルの中から適切なものを選択する場合にはほとんど役に立たない。
4. シミュレーション研究によれば、正しいモデルであっても、単なる偶然によって適合が不十分にしばしば見えることが示されている。
視覚的証拠が、それまで正しいと信じられていたモデルを棄却するのに十分なほど強いかを判断するのは難しい。

データ・プロットを[適合度](apr232.md)や[傾向](apr234.md)に関する正式な統計的検定と組み合わせることで、視覚的検定の長所を維持しつつ、その短所を解消することができる。
