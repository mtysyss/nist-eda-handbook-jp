# 8.2.3.3. 尤度比検定

#### 尤度比検定は、モデルの仮定を検証するための強力かつ非常に汎用性の高い手法である。しかし、この検定を行うには特別なソフトウェアが必要であり、必ずしも容易に入手できるとは限らない。
信頼性データの尤度関数については、[4節](../section4/apr412.md#Likelihood%20Function%20Examples%20for%20Reliability%20Data%3A)で説明している。
尤度関数を用いてモデルを選択したり、仮定を検証・妥当性確認したりする2つの方法は以下である。

1. 仮定した分布モデルに基づいて、標本データの最尤値を計算する（未知母数をその[最尤推定値](../section4/apr412.md)で置き換えたときに最大値が得られる）。
（確率プロットに基づいて）データに適合していると思われる他の候補となる分布モデルについても、この計算を繰り返す。
すべてのモデルが同じ数の未知母数を持ち、かつ故障機構や過去の成功した分析に基づいて特定のモデルを他よりも優先して選択すべき説得力のある理由がない場合は、尤度値が最大のモデルを選択する。

2. 多くのモデル仮定は、尤度式における母数に制約を課すものと見なすことができ、それによって実質的に未知母数の総数を減らすことになる。
一般的な例としては、次がある。 

#### 尤度比検定によって仮定を検証できる例 

i) 通常、Weibull 分布でモデル化されるある種のデータが、指数分布モデルによって適切に近似できるのではないかと考えられている。
指数分布は、形状母数 *γ* を 1に設定した Weibull 分布の特例である。
このデータに対する Weibull 尤度関数を表すと、*γ* を 1に設定することで指数分布モデルの尤度関数が得られ、未知母数の数は2つから1つに減少する。

ii) 加速試験から得られた *n* 個のセルからなるデータがあり、各セルが異なる動作温度を持つとする。
各セルにおいて対数正規母集団モデルが適用されるとする。
加速モデルの仮定がない場合、実験データの尤度は各セルからの尤度の積となり、未知の母数は $`2n`$ 個（各セルごとに異なる $`T_{50}`$ および *σ*）となる。
[Arrhenius モデル](../section1/apr151.md)適用されると仮定すると、母数の総数は $`2n`$ からわずか 3つ（共通の *σ* 1つと、アレニウス定数 *A* および $`\Delta H`$）に減少する。
この加速の仮定により、$`(2n-3)`$ 個の母数を「削減」できる。

iii) 2社の供給業者から供給された製品サンプルについて寿命試験を行う。
この製品は、Weibull 分布によってモデル化される故障機構を持つことが知られており、供給業者間での信頼性の違いを知りたい。
データの無制限尤度は、2つの尤度の積であり、4つの未知母数（各供給業者集団の形状母数と特性寿命）を持つ。
しかし、供給業者間に差異がないと仮定すると、尤度は未知母数が 2つだけ（共通の形状母数と共通の特性寿命）になる。
「差異がない」という仮定によって、2つの母数が「失われる」ことになる。

明らかに、これら 3つの例以外にも、重要な仮定が、データの尤度関数を定式化する際に用いられる母数数の削減や制限として再定式化できる例は数多く挙げられる。
これらすべての事例において、その仮定がデータと整合しているかを検定する、単純かつ非常に有用な方法がある。

**尤度比検定の手順** 

#### 尤度比検定の手順の詳細　一般的に、計算は複雑であるため、使用するソフトウェアに組み込む必要がある

$`L_1`$ を追加の仮定を置かない場合のデータの尤度の最大値とする。
言い換えれば、$`L_1`$ は、すべての母数を無制限とし、これらの母数の代わりに最尤推定量を代入した場合のデータの尤度である。

$`L_0`$ を仮定に基づいて母数が制約され（かつ数が減少した）場合の尤度の最大値とする。
*k* 個の母数が失われた（すなわち、$`L_0`$ の母数数が $`L_1`$より *k* 個少ない）と仮定する。

比 $`\lambda = L_0 / L_1`$ を定義する。
この比は常に 0から 1の間で、仮定の妥当性が低いほど、*λ* は小さくなる。
これは、所定の信頼水準において次のように定量化できる。

1. $`\chi^2 = -2 \text{ ln } \lambda`$ を計算する。
*λ* が小さいほど、$`\chi^2`$ は大きくなる。

2. $`\chi^2`$ が統計的に有意に大きいかは、これを自由度を持つカイ二乗分布の $`100(1-\alpha)`$ 百分位数点と比較することで判断できる。
$`\chi^2`$ は、自由度 *k* を持つカイ二乗分布に近似され、標本規模が小さくても、この近似は通常有効である。

3. 尤度比検定では、$`\chi^2`$ を計算し、その値が自由度 *k* のカイ二乗分布の百分位数値よりも大きい場合、仮定を棄却する。
ここで、その百分位数値は、分析者が選択した信頼水準に対応するものである。

**注**：尤度比検定の手法は非常に有用で広く適用可能であるが、計算は手作業で行うのが困難であり、特に打ち切りデータの場合は、適切なソフトウェアが必要である。
