# 8.2.2.1. 確率のプロット

#### 確率プロットを使用してデータを把握し、モデルの仮定を視覚的に確認する 

確率プロットとは、対数-対数スケールを用いて[CDF](../section1/apr121.md)の推定値を時間に対してプロットし、信頼性データを視覚的に要約する簡単な手法である。

*x* 軸には「時間」と表記し、軸には「累積％」または「百分位数」と表記する。
信頼性データからプロット位置（点）を計算する規則は、モデルに依存しない。
これらは、データにおける[打切り](../section1/apr131.md)の種類と、正確な故障時刻が記録されているか、それとも測定時刻のみが記録されているかによってのみ決まる。

#### 各故障モードを個別にプロットする
異なる故障モードは、区別して個別に分析することが可能であり、またそうすべきであることを覚えておく。
例えば、故障モードA を分析するときには、故障モードB、Cなどによる故障発生時刻を[打ち切りされた稼働時間](../section1/apr131.md#Separating out Failure)として扱う。
その後、故障モードB 以降についても同様に繰り返し、。

#### 選択したモデルが妥当であれば、データ点はおおむね一直線上に並ぶ
データをプロットすると、分析担当者はそのデータに直線を当てはめる（目視で、あるいは最小二乗法による近似プログラムを用いて）。
例えば、Weibull 確率プロット上のすべての直線は、特定の[Weibull寿命分布](../section1/apr162.md)モデルに一意に対応し、[対数正規](../section1/apr164.md)や[指数](../section1/apr161.md)プロットについても同様である。
もしデータ点がその直線にかなりよく沿っているならば、そのモデルはデータと整合していることになる。
もしそれが以前に選択したモデルであるならば、その選択を疑う理由はない。
さらに、回帰直線に対応する母数推定値を求める簡単な方法がある。

#### *x* 軸上の位置のプロットは、データ欠損の種類によって異なる

**位置のプロット**：[打切りデータ（タイプ1 または タイプ2）](../section1/apr131.md) 

*i* 番目の故障が発生した時刻 $`t_i`$ におけるCDF（または母集団の累積故障率）の推定値が必要である。
最も単純かつ直感的な推定値は、単に $`100(i/n)`$ である（試験対象の総数が *n* 個の場合）。
しかし、これは一般的に過大評価となる（すなわち、偏りを含む）。
様々な文献では、$`100(i-0.5)/n`$ や $`100i/(n+1)`$ といった補正が推奨されている。
ここでは、いわゆる（近似）**中央位数**推定量が推奨される。

*i* 番目の故障が発生した時刻 $`t_i`$ ごとに、$`100(i-0.3)/(n+0.4)`$ を用いてCDFまたは百分位数推定値を計算する。

**プロット位置**：[読出しデータ](../section1/apr131.md) 
 
読出時刻を $`T_1, T_2, \ldots, T_k`$ とし、各読出し時に記録された対応する新たな故障数を $`r_1, r_2, \ldots, r_k`$ とする。
ここでも、試験対象のユニットは *n* 個ある。

各読取時刻 $`T_j`$ について、以下の式を用いてCDFまたは百分位数推定値を計算する。

$$ \frac{100 \sum_{i=1}^j r_i}{n} .$$

**プロット位置**：[多重打切りデータ](../section1/apr131.md) 

多重打切りデータの場合、計算はより複雑になる。
（前の節で説明した）[K-M推定量](apr215.md)を用いて、各故障時刻におけるプロット位置を求める。
より精度の高い[修正K-M推定量](apr215.md#Modified%20K%20-%20M)の使用が推奨される。
これらは、データが故障のみで構成され、試験終了時を除いて除去がない場合、打切りタイプ1 または 打切りタイプ2 の中央値順位推定量に帰着する。

**信頼性モデル** 

#### *y*軸上の位置の描画は、信頼性モデルによって異なる
大まかな考え方は、モデルとなるCDFの方程式を取り上げ、$`F(t)`$ の関数が *t* の関数の線形方程式となるような形で記述することである。
これは、いくつかの例を見れば明らかである。
以下の式において、「ln」は常に「自然対数」を意味し、「log」は常に「底10の対数」を意味する。

a) **指数モデル：**[指数CDF](../section1/apr161.md#Formula's%20and%20Plots)を次のように書き換える。
 
$$ \text{ln} \left( \frac{1}{1-F(t)} \right) = \lambda t , $$

あるいは、同値的に、

$$ \text{log} \left( \frac{1}{1 - F(t)} \right) = \frac{\lambda}{\text{ln } 10} t . $$

$`y = 1/[1-F(t)]`$ および $`x = t`$ と置くと、$`\text{log } y`$ は *x* に関して直線となり、その傾きは $`\lambda / \text{ln } 10`$ となる。
したがって、対数軸の *y*軸を用いることで、指数確率プロットを作成することができる。
前述の $`F(t_i)`$に関するプロット位置の推定値（100 倍の係数を除いたもの）を用いて、$`(x_i,\, y_i)`$ の点の組を計算する。

データが指数分布モデルと一致する場合、結果として得られるプロット上の点は、原点を通る傾きが $`\lambda / \text{ln } 10`$ の直線上にほぼ一直線に並ぶことになる。

b) **Weibull モデル：**[Weibull CDF](../section1/apr162.md#Formula's%20and)を次のように書き換える。

$$ \text{ln ln } \left( \frac{1}{1-F(t)} \right) = \gamma \text{ ln } t - \gamma \text{ ln } \alpha $$

または

$$ \text{log ln } \left( \frac{1}{1-F(t)} \right) = \gamma \text{ log } t - \gamma \text{ log } \alpha . $$

$`y = \text{ ln }(1/[1-F(t)])`$ および $`x = t`$ と置くと、$`\text{log } y`$は $`\text{log } x`$に対して傾きが *γ* の直線となる。
したがって、対数-対数尺度を用いて Weibull 確率プロットを作成することができる。
$`F(t_i)`$の推定値（100倍の係数を除いたもの）を用いて、点 $`(x_i, y_i)`$の組を計算する。

データが Weibull モデルと一致する場合、得られたプロットには傾きが $`\gamma`$ の直線上にほぼ並ぶ点が現れる。
この直線は、時刻 $`t = \alpha`$ で $`\text{log } x`$ 軸と交わり、$`-\gamma \text{ log } \alpha`$ で $`\text{log } y`$ 軸（すなわち、切片）と交わる。

c) **対数正規モデル**：[対数正規 CDF](../section1/apr164.md#Formula's%20and)を次のように書き換える。
 
$$ \text{ln } t = \sigma \Phi^{-1} \left[ F(t) \right] + \text { ln } T_{50} $$

あるいは、

$$ \text{log } t = \frac{\sigma}{\text{ln } 10} \Phi^{-1} \left[ F(t) \right] + \text{ log } T_{50} , $$

ここで、$`\Phi^{-1}`$ は標準正規分布の逆関数を表す（引数として確率を取り、対応する「*z*」値を返す）。

$`y = t`$ および $`x = \Phi^{-1}[F(t)]`$ と置くと、$`\text{log } y`$ は *x* に関して線形であり、その傾きは $`\sigma / \text{ln } 10`$ 、切片（$`F(t)`$ = 0.5 の場合）は $`\text{log } T_{50}`$ となる。
対数軸の *y*軸を用いて、対数正規確率プロットを作成する。
$`F(t_i)`$ のプロット位置の推定値（100 倍の係数を除いたもの）を用いて、点 ($`x_i, y_i`$) の組を計算する。

データが対数正規モデルと一致する場合、得られたプロット上の点は、傾きが $`\sigma / \text{ln } 10`$、切片が $`\text{log } y`$ 軸上の $`T_{50}`$ となる直線上にほぼ一直線に並ぶ。

d) **極値分布（タイプ 1 - 最小値）：**[極値分布 CDF](../apr/section1/apr163.md#Explanation%20and%20Formulas)を次のように書き換える。

$$ \text{ln } \left\\{ -\text{ ln } [1 - F(x)]\right\\} = (x - \mu)/\beta . $$

$`y = -\text{ ln }[1 - F(x)]`$ と置くと、$`\text{ln } y`$ は *x* に関して線形であり、傾きは 1/$`\beta`$、切片は $`-\mu / \beta`$ となる。
$`y`$ 軸を10進対数軸として、*y* 対 *x* のグラフを描く。
点群は、傾きが $`(1/\beta) \cdot \text{ln } 10`$、切片が ($`-\mu/\beta) \cdot \text{ln } 10`$ となる直線に沿うはずである。
プロットに10進対数軸が使用されているため、傾きと切片に $`\text{ln } 10`$ が因数として含まれている必要がある。

 **例** 

#### 確率プロットに関する Weibull 分布の例
形状母数が $`\gamma = 1.5`$ および $`\alpha = 500`$ である[Weibull 故障時間](../section1/apr162.md#DATAPLOT%20and%20EXCEL%20Functions%20for%20the)を 20個生成した。
試験時間を $`T = 500`$ 時間と仮定すると、これらの故障時間のうち観測されたのは 10個のみであった。
それらは、1時間単位で四捨五入すると、54、187、216、240、244、335、361、373、375、および386となる。
これらの故障時刻に基づいてCDF推定値の位置を計算し、確率プロットを作成する。

| :---: | :---: | :---: | :---: |  
| 1 | 54 | 0.034 | 0.035 |  
| 2 | 187 | 0.083 | 0.087 |  
| 3 | 216 | 0.132 | 0.142 |  
| 4 | 240 | 0.181 | 0.200 |  
| 5 | 244 | 0.230 | 0.262 |  
| 6 | 335 | 0.279 | 0.328 |  
| 7 | 361 | 0.328 | 0.398 |  
| 8 | 373 | 0.377 | 0.474 |  
| 9 | 375 | 0.426 | 0.556 |  
| 10 | 386 | 0.475 | 0.645 |  


列 (4) 対列 (2) を用いて、対数-対数尺度軸で確率プロットを作成する。

![Weibull plot of Weibull random number](https://www.itl.nist.gov/div898/handbook/apr/section2/apr221_r01.gif)

点の位置関係にはある程度の曲率が見られることに注意する。
これは主に、プロット上の最初の点（最も早い故障時刻）に起因している。
確率プロット上の最初の数点は、中央範囲の点よりも変動が大きく、「直線性」を視覚的に確認する際には、これらの点にはあまり注意を払うべきではない。

#### 確率プロット上の点を通る直線を適合するために、最小二乗法（回帰）を用いる
データは対数対数尺度でプロットされているため、独立変数として $`\text{log } x`$、従属変数として $`\text{log } y`$ を用いて直線適合した。

回帰分析の結果、傾きの推定値は 1.46 となり、これはシミュレーションで使用された値 1.5に近い。
切片は -4.114 であり、これを $`-\gamma \text{ log } \alpha`$ に等しく設定することで、$`\alpha = 657`$ と推定される（シミュレーションで使用された「真の」値は 500 であった）。

この節の分析は、[Dataplotコード](https://www.itl.nist.gov/div898/handbook/apr/section2/apr221.dp)および[Rコード](https://www.itl.nist.gov/div898/handbook/apr/section2/apr221.r)の両方を使用して実装できる。
どちらのパッケージにも、多種多様な分布に対する確率プロットを自動的に生成するための特別な関数が用意されている。
