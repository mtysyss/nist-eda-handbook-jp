# 8.2.1. 適切な寿命分布モデルの選択方法

#### 理にかなり、データに適合し、できれば説得力のある理論的根拠を持つモデルの選択
寿命分布モデルは、以下の3つの理由のうち1つ以上に基づいて選択する。

1. 故障機構と寿命分布モデルを理論的に結びつける物理的・統計的な根拠がある
2. 特定のモデルが、同一または類似の故障機構に対して過去に成功裏に使用された実績がある
3. 利用しやすいモデルが、すべての故障データに対して良好な経験的適合性を示す

どのような方法でモデルを選定する場合でも、そのモデルは、

* 「理にかなっている」ものでなければならない。
例えば、「摩耗」という故障メカニズムをモデル化する際に、故障率が一定である指数分布モデルを使用してはならない。
* データへの適合性について、[視覚的および統計的な検定](apr23.md)に合格すること。

対数正規分布や Weibull 分布のようなモデルは非常に柔軟であるため、少数の故障データ集合に対して両モデルが同等に良く適合することは珍しくない。
しかし、特に[加速モデル](../section1/apr14.md)を用いて試験データとはかけ離れた使用条件を予測する場合、これら2つのモデルが予測する故障率は桁違いに異なることがある。
それゆえ、特定の分布を使用するための理論的根拠を見出そうとする試みは、単なる学術的な演習以上の意義を持つのである。

#### モデルの選択を導く上で役立つ理論的な論拠がいくつかある
この種のよく知られた3つの議論について検討する。

* [極値論法](apr212.md)
* [乗法劣化論](apr213.md)
* [疲労寿命（Birnbaum-Saunders）モデル](apr214.md)

なお、寿命分布モデルを選択するための物理的・統計的論拠は、通常、個々の[故障モード](apr211.md)に基づいていることに留意されたい。

#### 問題によっては、「経験的」な分布に依存しない手法を用いることができる
Kaplan-Meier 法は、モデルに関する仮定を一切設けずに、単に「データそのものが物語る」ようにするのが適切な場合に利用できる。
しかし、この手法が有用であるには、一般的に多量のデータが必要であり、加速モデル化は著しく困難である。
