# 8.2.2. 信頼性データのプロットの仕方

#### 確率プロットを作成し、点がほぼ一直線上に並ぶ場合、想定したモデルは妥当な近似である
信頼性データのグラフ化は、特定のモデルが観測データと整合しているかどうかを素早く、かつ有用に視覚的に検証する方法である。
事実上すべてのグラフ化手法の背後にある基本的な考え方は以下の通り。

*データから計算された点を対数対数尺度でプロットし、それらがほぼ一直線上に並ぶ限り、分析者はデータが仮定されたモデルと整合していると結論づけることができる。

信頼性データが、[非修理系母集団](../section1/apr121.md)（あるいは、最初の故障までの時間のみが考慮される修理系母集団）からの（場合によっては[多重打切り](../section1/apr131.md)）故障データから構成される場合、モデルは[指数](../section1/apr161.md)、[Weibull](../section1/apr162.md)、もしくは[対数正規](../section1/apr164.md)などの寿命分布モデルである。
データが[修理可系](../section1/apr17.md)の修理時間から構成されている場合、モデルは[NHPP冪乗則](../section1/apr172.md)となる可能性があり、プロットは[Duane プロット](apr223.md)である。

非修理系母集団からの故障データについて検討するプロットの種類には以下がある。

* [確率（CDF）プロット](apr221.md)
* [ハザードおよび累積ハザード・プロット](apr222.md)

修理系母集団は以下がある。

* [傾向プロット](apr223.md)（[HPP](../apr171.md)モデルまたは指数分布モデルが適用可能かを確認する）
* [Duane プロット](apr223.md)（[NHPP冪乗則が](../apr172.md)適用されるかを確認する）

後の（[8.4.2.1節](../section4/apr421.md)）で加速モデルの仮定を検証するために使用できるプロットについても検討する。

**注**：この節で取り上げるプロットの多くは、モデル係数の概算値を素早く求めるのにも利用できる。
これについては後節で取り上げる。
係数を推定するより正確な方法は他にもあるかもしれないが、特に他の手法では入手が容易でないソフトウェア・プログラムを必要とする場合、このような単純なグラフによる推定は非常に便利である。
