# 8.2.1.4. 疲労寿命（Birnbaum-Saunders）モデル

#### 多くの独立した応力サイクル中に生じる無作為な亀裂進展から導かれたモデル

[疲労寿命モデルの導出](../section1/apr166.md#Derivation%20and%20Use%20of%20the%20Birnbaum-Saunders%20Model:)は、劣化を引き起こし、最終的に破損に至る応力の反復サイクルに基づいている。
典型的な例としては、き裂の進展が挙げられる。
重要な仮定の一つは、いずれのサイクルにおける劣化の程度も、他のサイクルの劣化とは独立しており、かつ同じ確率分布に従うというものである。

この仮定が、劣化過程を記述する仮説上の物理モデルとよく一致する場合、Birnbaum-Saunders モデルが妥当な分布モデルの候補となることが期待される。
（対数正規モデルの導出と疲労寿命モデルの仮定との違いに関するコメントについては、[導出](../section1/apr166.md#Derivation%20and%20Use%20of%20the%20Birnbaum-Saunders%20Model:)部分の注記を参照のこと。
また、Miner 則に関するコメントも参照のこと）。
