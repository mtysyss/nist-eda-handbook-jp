# 8.2.1.1. 故障モードに基づく

#### 寿命分布モデルや物理的加速度モデルは、通常、個々の故障モードレベルでのみ適用される

**故障モード**データとは、故障の種類ごとに分類された故障データである。
故障モードごとに故障を特徴づけるためには、個々の故障事例について根本原因分析を行う必要がある。
これは困難でコストもかかるかもしれないが、部品やシステムの信頼性を理解し、モデル化し、予測し、改善しようとする真剣な取組みにおいて、極めて重要な要素である。

[寿命分布モデル](../section1/apr121.md)と[物理的加速モデル](../section1/apr14.md)の両方を適用する適した場所は、故障モードの階層である。
各構成要素の故障モードには、通常、固有の寿命分布モデルがある。
加速モデルについても同様である。
ほとんどの場合、これらのモデルは故障モード階層でのみ意味をなし、構成部品やシステム階層では意味をなさない。
各モード（または機構）のモデル化が完了すれば、[ボトムアップ手法](../section1/apr18.md)を用いて、構成部品全体やシステム全体を構築することができる。

特に、次の3節で説明する寿命分布モデルの選択に関する論拠は、破損モード階層にのみ適用される。
これらは、[極値論](apr212.md)、[乗法劣化論](apr213.md)、および[疲労寿命（Birnbaum-Saunders）モデル](apr214.md)である。

[分布を制限しない（Kaplan-Meier）](apr215.md)手法は、どの階層（モード、構成部品、システムなど）でも適用可能である。
