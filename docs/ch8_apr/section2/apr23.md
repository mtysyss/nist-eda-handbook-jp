# 8.2.3. 信頼性モデルの仮定の検定方法

#### モデルは頻繁に必要となるが、常に確認を行う必要がある
信頼性モデルは、多くの場合、そのモデルの推定に用いられた信頼性データの範囲をはるかに超える故障率やMTBFを予測（外挿）するために使用されることから、選択したモデルが利用可能なデータとの整合を「検定」することが極めて重要である。
この節では、検討中モデルの受入れ可能性を判断するためのいくつかの方法について説明する。
それらは以下の通り。

1. [目視による検定](apr231.md)
2. [適合度検定](apr232.md)
3. [尤度比検定](apr233.md)
4. [傾向検定](apr234.md)
