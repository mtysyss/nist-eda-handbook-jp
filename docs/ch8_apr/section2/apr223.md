# 8.2.2.3. 傾向と成長のプロット（Duane プロット）

#### 修理率は通常、時間の経過とともにほぼ一定であるか、あるいは一貫して上昇傾向または下降傾向を示す
[修復系に関するモデル](../section1/apr17.md)は前の節で説明している。
これらのモデルは、時間の経過に伴う故障のない期間の累積数（あるいは[修復率](../section1/apr125.md)）を表す。
産業界全体で最も成功を収めている2つのモデルは、[HPP](../section1/apr171.md)（定修復率、または「指数」系モデル）と、[NHPP 冪乗則](../section1/apr172.md)過程（修復率は多項式 $`m(t) = \alpha t^{-\beta}`$）である。

[Duane プロット](../section1/apr192.md)を作成する前に、時間の経過に伴う修復率に傾向があるか否かを示す有力な証拠となることが多い、いくつかの単純な傾向プロットがある。
もし傾向がなければ、HPPモデルを採用するのが妥当である。
明らかな改善や劣化の傾向が見られる場合、Duane プロットを用い、NHPP冪乗則モデルがデータと整合しているかを視覚的に確認する。 

#### いくつかの簡単なグラフを見れば、傾向があるかどうかを判断するのに役立つ
傾向を把握するためのこうした単純な視覚的グラフによる検証は、

1. システムの稼働期間に対する累積故障数をプロットする（新しい故障が発生するたびに上昇するステップ関数である）。
このプロットが直線的であれば、明らかな改善（または劣化）の傾向は見られない。
下向きに曲がる場合は改善を示し、上向きに曲がる場合は劣化を示す。

2. 新たな故障間の到達間隔（言い換えれば、故障間の待機時間で、最初の故障までの時間を最初の「到達間隔」として用いる）をプロットする。
これらが上昇傾向を示せば改善しており、下降傾向を示せば劣化している。

3. 到達間隔の逆数をプロットする。
各逆数は、前回の故障からの待機時間のみに基づいて計算された、新たな故障率の推定値である。
これらが下降傾向を示せば改善、上昇傾向を示せば劣化を示す。

#### 実際の信頼性向上試験データに基づく傾向プロットおよび Duane プロット

 **事例研究 1：信頼性改善試験データを用いた傾向プロットおよび Duane プロットの活用** 
 
新しく開発された複雑な機器のプロトタイプに対し、1500稼働時間の[信頼性向上試験](../section1/apr19.md)が実施された。
試験中に 10件の故障が発生した。
改善過程の一環として、部門横断的な故障検討委員会が、すべての故障について根本原因まで徹底的に分析し、設計および部品選定の修正がプロトタイプに実施された。
観測された故障発生時間は、5、40、43、175、389、712、747、795、1299、1478時間で、試験は1500時間で終了した。
故障検討委員会の信頼性技術者は、まず前述のように傾向図を作成し、次に Duane プロットを作成した。

**コメント：** 3つの傾向プロットはいずれも改善傾向を示している。
3つの傾向プロットすべてを試してみるのが有用である理由は、あるプロットでは他のプロットよりも傾向がより明確に現れる可能性があるためである。
この傾向を示す視覚的証拠の有意性に関する正式な統計的検定は、[傾向検定](section2/apr234.md#Case%20Study%201%3a Reliability%20Test%20Improvement%20Data)の節に示している。

Duane プロット上のデータ点は、おおむね直線状に並んでおり、これはNHPP冪乗則モデルがデータと一致していることを示している。

この事例研究における、[信頼性成長勾配および本試験終了時点でのMTBF](../section4/apr452.md#Case%20Study%201:%20Reliability%20Improvement%20Test%20Data%20:)推定値は、後節で記載している。
