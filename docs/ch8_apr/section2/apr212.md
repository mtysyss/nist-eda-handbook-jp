# 8.2.1.2. 極値論

#### もし、競合する多数の故障過程のうち最初のものが臨界点に達した時に、構成部品またはシステムの故障が発生する場合、極値理論によれば、Weibull 分布が適切なモデルとなるとされる 

**中心極限定理**によれば、観測された測定値が（測定誤差などの）多くの小さな無作為な要因の総和から生じている場合、正規分布はほとんどの工学データを適切にモデル化できることが広く知られている。
実務上の経験もこの理論を裏付けており、多くの工学データ集合において正規分布が「機能する」。

あまり知られていないのは、[極値理論](../section1/apr163.md)によれば、多くの競合する類似の故障過程が故障に向けて「競い合い」、最初に故障に達したもの（すなわち、おおむね同等の無作為な故障時間の大きな集合における最小値）が観測される故障時間を生み出す故障時間を Weibull 分布がうまくモデル化する。
同様に、多数のほぼ同等のランナーが競い合い、多くの類似したレースで優勝時間が記録される場合、これらの時間は Weibull 分布に従う可能性が高い。

これは、部品やシステムの故障を引き起こすために複数の故障機構が競合している場合、常に Weibull モデルが適用されるという意味ではないことに注意が必要である。
これらの機構のうち1つまたはいくつかが他を圧倒し、ほぼすべての故障を引き起こしている可能性がある。
その場合、無作為な故障時間の「多数のおよそ同等の最小値」という概念は当てはまらず、適切なモデルは、[競合リスク・モデル](../section1/apr181.md)を用いて、支配的な少数の機構に対する分布モデルから導出されるべきである。

一方、多数の類似した劣化過程や欠陥の「最も弱い部分」で故障が発生する事例も数多くある。
その一例として、誘電体材料の絶縁破壊によって引き起こされるコンデンサの壊滅的故障をモデル化する場合が挙げられる。
典型的な誘電体材料には、最終的に絶縁破壊が発生する「欠陥」や微視的な箇所が多数存在する。
これらの箇所は、どこが最初に故障に至るかを**競い合っている**と捉えることができる。
極値理論が示唆するように、Weibull モデルは、この故障機構の寿命分布モデルとして非常に成功を収めてきた。
