# 8.2.1.3. 乗法劣化論
#### 対数正規モデルは、劣化が無作為な衝撃によって引き起こされ、その衝撃によって既に存在する総量に比例する割合で劣化が進行する場合に適用できる
[対数正規分布モデルの用途](../section1/apr164.md#Uses%20of%20the%20Lognormal%20Distribution%20Model)において、乗法劣化論（対数正規モデルの導出につながる）について、概略を説明した。
ここでは、劣化過程に基づく多くの故障機構において、対数正規分布がなぜ有効なモデルとして機能してきたのかという洞察が得られるため、その形式的な導出の概要を説明する。

$`y_1, y_2, \ldots, y_n`$ を特定の故障過程において、その過程が故障に向かって進行するにつれて、連続する離散的な時刻に測定された劣化量の値とする。
*y* 同士の間に以下の関係が存在すると仮定する。

$$ y_i = (1 + \epsilon_i)y_{i-1} , $$

ここで、$`\epsilon_i`$ は、システムに対する小さく、互いに独立した無作為な摂動、すなわち「衝撃」であり、これらが故障過程を進行させる。
言い換えれば、ある時点から次の時点への劣化量の増加は、既に存在する総劣化量の小さな無作為な倍数である。
これが**乗法劣化**の意味するところである。
この状況は、雪に覆われた坂を転がり落ちる雪玉に例えることができる。
雪玉は大きくなればなるほど、さらに多くの雪を巻き込むことができるため、その成長速度は速くなる。

*n* 番目の時点における劣化の総量は、次式で表現することができる。

$$ x_n = \left( \prod_{i=1}^n (1 + \epsilon_i) \right) x_0 , $$

ここで、$`x_0`$ は定数であり、$`\epsilon_i`$ は小さな無作為な衝撃である。
次に、両辺の自然対数をとると次式が得られる。

$$ \text{ln } x_n = \sum_{i=1}^n \text{ln }(1 + \epsilon_i) + \text{ln } x_0\approx \sum_{i=1}^n \epsilon_i + \text{ln } x_0 . $$

中心極限定理の議論を用いると、$` \text{ln}x_n`$ は近似的に正規分布に従うと結論づけられる。
しかし、[対数正規分布の性質](../section1/apr164.md#Formula's%20and)により、これは $`x_n`$（すなわち劣化量）は、任意の *n*（あるいは任意の時刻 *t*）において、対数正規モデルに近似的に従うことを意味する。
劣化量が臨界点に達したときに故障が発生するため、この種の過程においては、故障時刻は対数正規分布によって適切にモデル化される。 

#### 乗法劣化モデルに基づく対数正規分布によってうまくモデル化できるだろう破壊機構
乗法劣化モデルに従うと、どのような故障機構が予想されるだろうか。
以下に挙げるプロセスが有力な候補である。

1. 新しい化合物の生成につながる化学反応
2. イオンの拡散または移動
3. 亀裂の成長または伝播

半導体の故障モードの多くは、これら3つの劣化過程のいずれかによって引き起こされる。
したがって、対数正規モデルが以下の半導体の摩耗による故障機構に対して非常に有効であったことは驚くことではない。

1. 腐食
2. 金属移動
3. 電子移動
4. 拡散
5. 亀裂の進展
