# 8.2.3.2. 適合度検定

#### 適合度検定は、仮定された分布モデルに基づいて、データが妥当であるか、あるいは極めてあり得ないものであるかを検証する。
データが特定のモデルと一致しているという仮説を検証するための一般的な検定については、[7章](../ch7_prc/section2/prc21.md)で解説している。
[カイ二乗適合度検定](../../ch1_eda/section3/eda35f.md)および[Kolmolgorov=Smirnov（K-S）検定](../../ch1_eda/section3/eda35g.md)の詳細および例は1章に記載している。
カイ二乗検定は、[タイプ1 またはタイプ2の打切りデータ、および測定値データ](../section1/apr131.md)に対して、十分な数の故障数と測定時間があれば使用できる。
K-S検定は一般的に完全な標本が必要であり、これが信頼性解析におけるその有用性が限定される。
これらの検定では、有効なモデルを誤って棄却する確率を次のように制御する。

* 分析者は、$`100(1-\alpha)`$ で指定される信頼水準を選択する。
* データから検定統計量を計算し、モデルが正しいと仮定した場合の統計量の期待値と比較する。
* 検定統計量が極めて発生し難い値、あるいは発生確率が  *α* 以下である場合（ここで *α* は 0.1、0.05、あるいは 0.01のような小さな値である）、そのモデルは棄却される。

したがって、正しいモデルを棄却するリスクは *α* 以下に抑えられ、*α* の選択にあたっては通常、モデルが棄却された場合に生じうる潜在的な損失や困難が考慮される。
