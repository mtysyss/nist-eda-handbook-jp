# 8.1.7.3. 指数則

#### 指数則は、もう一つの柔軟なNHPPモデルである

[ROCOF](apr125.md)または強度関数が

$$ m(t) = \text{exp} \left(\alpha + \beta t \right) , $$

を持つNHPPは、**指数法則**に従うと言われる。
これは**対数線形モデル**または**Cox-Lewisモデル**とも呼ばれる。

修復率がこの柔軟なモデルに従うシステムは、$`\beta < 0`$ の場合は改善し、$`\beta > 0`$ の場合は劣化する。
$`\beta = 0`$ の場合、指数法則は [HPP](apr171.md)の定数修復率モデルに帰着する
