# 8.1.8.6. 複雑系

#### 多くの場合、複雑なシステムの信頼性は、直列および／または並列モデルの式を順次適用することで評価することができる 
多くの複雑なシステムは、[直列](apr182.md)構成要素、[並列](apr183.md)構成要素、[*R*-out-of-*N*](apr184.md)構成要素、および[待機](apr185.md)構成要素の組合せとして図式化することができる。
これらのモデルの式を用いることで、元のシステムのサブシステムや区画を、既知のCDFまたは信頼性関数を持つ「等価な」単一構成要素に置き換えることができる。
このように進めることで、最終的にはシステム全体を既知のCDFを持つ単一の構成要素に集約できる可能性がある。

以下は、並列接続された構成要素と直列接続された構成要素の両方から成る複雑なシステムをまず直列システムに、そして最終的に単一構成要素のシステムに集約した例である。

![Diagram of complex system reduced to equivalent one component system](https://www.itl.nist.gov/div898/handbook/apr/section1/gifs/complex.gif)

**注:** 上記の簡略化手法は、多くのシステムで有効だが、すべてのシステムに適用できるわけではない。
動作論理構造が複雑な一部のシステムについては、より形式的な構造解析手法が必要である。
この手法では、イベントツリー、ブール表現、コヒーレント構造、カットセット、分解などの主題を扱うが、これらは本ハンドブックの範囲を超えている。
