# 8.1.8.4. R-out-of-N モデル

#### *r*-out-of-*n* モデルとは、その構成要素のうち少なくとも *r* 個が正常に動作しているときにシステムが機能し続けるシステムのことである（*r*値は任意）
「*r*-out-of-*n*」システムには、[直列](apr182.md)システム・モデルと[並列](apr183.md)システム・モデルの両方が特例として含まれる。
このシステムは *n* 個の構成要素から成り、それらは互いに独立して動作または故障し、これらの構成要素のうち少なくとも *r* 個（任意の *r*）が正常に動作している限り、システムは正常に動作し続ける。
システムの故障は、$`(n - r + 1`$ 番目の構成要素が故障したときに発生する。

$`r = n`$ の場合、*n* 個のうち *r* 個のモデルは直列モデルに帰着する。
$`r = 1`$ の場合、*n* 個のうち *r* 個のモデルは並列モデルである。

ここでは、すべての構成要素が同一であるという単純なケースを扱う。

*n* 個のうち *r* 個のモデル（同一の構成要素）に関する式と仮定：

1. すべての構成要素は同一の信頼性関数 $`R(t)`$ を持つ。
2. すべての構成要素は（故障に関しては）互いに独立して動作する。
3. システムは、任意の（$`n - r`$）個の構成要素が故障しても動作し続けることができる。
システムは、（$`n - r + 1`$）番目の構成要素が故障した瞬間に故障する。 

#### 構成要素がすべて同一である *r*-out-of-*n* システムに関する式
システムの信頼性は、時刻 *t* まで正確に *r* 個の構成要素が生存する確率に、正確に ($`r + 1`$)個の構成要素が生存する確率を加算することで求められ、これを繰り返して、すべての構成要素が時刻 *t* まで生存する確率に至るまで続ける。
これらは二項分布の確率（$`p = R(t)`$）であるため、システムの信頼性は次式で与えられる。

$$ R_S(t) = \sum_{i=r}^n \left( \begin{array}{c} n \\
i 
\end{array} \right)\left[ R(t) \right]^i \left[ 1 - R(t) \right] ^{n-i} . $$

**注**：すべての構成要素が同一であるという仮定を緩和すると、$`R_S(t)`$ は、少なくとも *r* 個の生存部品とそれに対応する故障部品を選ぶことによって形成されるすべての可能な項について評価された確率の和となる。
各項の確率は、$`R(t)`$ と $`F(t)`$ の積として評価される。
例えば、$`n = 4`$ および $`r = 2`$ の場合、システムの信頼性は（$`R(t)`$ および $`F(t)`$ の表記を $`R`$ および $`F`$ のみに省略）

$$ \begin{equation}
\begin{split}
R_S & = R_1 R_2 F_3 F_4 + R_1 R_3 F_2 F_4 + R_1 R_4 F_2 F_3 + R_2 R_3 F_1 F_4 \\
        &+ R_2 R_4 F_1 F_3 + R_3 R_4 F_1 F_2 + R_1 R_2 R_3 F_4 + R_1 R_3 R_4 F_2 \\
        &+ R_1 R_2 R_4 F_3 + R_2 R_3 R_4 F_1 + R_1 R_2 R_3 R_4 .
  \end{split}
\end{equation} $$
