# 8.1.2.5. 修復率もしくは ROCOF

#### 時間経過に伴う故障累積件数に基づく修理率モデル
修理系の故障発生率をモデル化するには、別の手法が用いられる。
本章では、これらの発生率を<u>修理率</u>と呼ぶ（修理にかかる時間とは混同しないこと。
修理にかかる時間については、本章では扱わない）。
時間は、時刻ゼロでの最初の起動からシステムの寿命終了までの、システムの稼働時間（稼働時間）によって測定される。
システムが経年劣化するにつれて故障が発生し、システムは修理によって新品と同等、あるいはそれ以上、あるいはそれ以下の状態になる。
修理の頻度は、増加したり、減少したり、あるいはほぼ一定の率で推移したりする可能性がある。

$`N(t)`$ を時刻0 から時刻 $`t`$ までの間に特定システムで発生した累積故障数を記録する計数関数とする。
$`N(t)`$ は、故障が発生するたびに 1ずつ跳ね上がり、次の故障が発生するまでその新しい水準にとどまる階段関数である。

どのシステムにも、時間の経過に伴う固有の観測された $`N(t)`$ 関数がある。
多数の類似したシステムの $`N(t)`$ 曲線を観測し、これらの曲線を「平均化」すれば、$`M(t)`$、すなわちこれらのシステムにおける時刻 *t* までの累積故障数の期待値（平均値）の推定値が得られる。 

#### 単位時間あたりの平均故障率：修理率（またはROCOF）
$`M(t)`$ の導関数（$`m(t)`$ と表記される）は、**修復率**あるいは**時刻 *t* における****故障発生率（ROCOF**）として定義される。

$`N(t)`$、$`M(t)`$、および $`m(t)`$ に関するモデルについては、[修理率モデル](apr17.md)の節で説明する。
