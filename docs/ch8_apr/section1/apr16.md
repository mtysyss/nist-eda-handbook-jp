# 8.1.6. 非修理系母集団に一般的に用いられる基本的な寿命分布モデル
#### ごく一部の生涯分布モデルが、実用面で大きな成功を収めている 
幅広い製品や故障機構に起因する故障時間について、母集団モデルとして有効に機能してきたパラメトリックモデルがいくつかある。
場合によっては、故障モードの物理的特性に基づいた確率論的議論が、モデルの選択を正当化する傾向にある。
また、実際の故障データへの適合において経験的に成功を収めているという理由だけで、そのモデルが採用される場合もある。
本節では、以下の7つのモデルについて説明する。

1. [指数分布](apr161.md)
2. [Weibull](apr162.md)
3. [極値分布](apr163.md)
4. [対数正規分布](apr164.md)
5. [ガンマ](apr165.md)
6. [Birnbaum-Saunders](apr166.md)
7. [比例ハザード](apr167.md)
