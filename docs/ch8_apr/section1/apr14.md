# 8.1.4. 「物理的加速度」とは何であり、それをどのようにモデル化すればよいのでしょうか？

#### 変化する際、応力が「破損までの時間」に定数を乗じたものに等しい場合、真の（物理的な）加速度が得られる 
**物理的加速**（**「真の加速」**または単に**「加速」**と呼ばれることもある**）**とは、装置を高い負荷条件下（すなわち、高温、高電圧、高湿度、高デューティサイクルなど）で運転することにより、通常の使用条件下で発生するのと同じ故障が生じるが、その発生がはるかに速いことを指す。

故障の原因としては、機械的疲労、腐食、化学反応、拡散、マイグレーションなどが挙げられます。
これらは通常の使用条件下での故障原因と同じですが、その発生までの時間が異なるだけである。 

#### 加速係数とは2つの応力水準間の一定の乗数である
真の加速度が存在する場合、応力の変化は、破壊が発生するタイミングを記録するために用いられる時間スケールを変換することと同等である。
一般的に用いられる変換は線形であり、これは、高応力下での故障までの時間を、ある定数（**加速度係数**）で乗算するだけで、使用応力下での同等の故障までの時間を求めることができることを意味する。

以下の表記を用いる。

|||  
| :--- | :--- |  
| $`t_s`$= 応力 | $`t_u`$= 使用応力下での対応する故障までの時間 |  
| $`F_s(t)`$= 応力下での累積分布関数（CDF） | $`F_u(t)`$= 使用応力における累積分布関数（CDF） |  
| $`f_s(t)`$= 応力下での確率密度関数（PDF） | $`f_u(t)`$= 使用時の確率密度関数 |  
| $`h_s(t)`$= 応力状態における故障率 | $`h_u(t)`$= 使用時の故障率 |  
{: .no-border-table}

したがって、応力と使用との間の加速度係数 *AF* は以下の関係の成立を意味する。  

|||  
| :--- | :--- |  
| **線形加速度関係** | |  
| --- | --- |  
| **故障までの時間** | $`t_u = AF \times t_s`$ |  
| **故障確率** | $`F_u(t) = F_s(t/AF)`$ |  
| **信頼性** | $`R_u(t) = R_s(t/AF)`$ |  
| **PDF/確率密度関数** | $`f_u(t) = (1/AF) f_s(t/AF)`$|  
| **故障率** | $`h_u(t) = (1/AF) h_s(t/AF)`$ |  
{: .no-border-table} 

#### 各故障モードには固有の加速度係数がある。加速度が関係する場合、分析時に故障データを分けるすべきである。異なる応力セルからのデータの確率プロットは同じ傾きを示す（加速度が存在する場合）。

**注**：加速には、破損につながる変化や劣化を引き起こす、応力に依存する物理的過程の存在が必要である。
一般に、異なる破損モードは応力の影響を異なって受け、異なる加速係数を持つ。
したがって、単一加速係数が複数の破壊機構に適用されることはまずない。
一般的に、異なる破壊モードは応力の影響を異なって受け、それぞれ異なる加速係数を持つ。
破壊データを分析する際は、異なる種類の破壊を区別すること。

また、上記に示した線形加速関係（これは「真の加速」から直接導かれる）の結果として、以下のことが言える。
    
    主要な寿命分布モデル（ワイブル、対数正規）の形状母数は、異なる応力下で動作するユニット間でも変化しない。
    異なる応力セルからのデータの確率プロットは、おおむね平行に並ぶ。
    
これらの[分布](apr16.md)および[確率プロット](../section2/apr221.md)については、後の節で説明する。
