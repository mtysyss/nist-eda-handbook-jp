# 8.1.2.4. 「バスタブ」曲線

#### ほとんどの製品について、曲線が浴槽の絵のような形になる経時故障率プロット
ある母集団から十分な数の個体が、時間の経過とともに動作および故障する様子が観察されたとき、故障率 $`h(t)`$ の週ごと（または月ごと）の推定値を計算するのは比較的容易である。
例えば、使用開始から 13ヶ月目に $`N_{12}`$ 台の機器が稼働しており、そのうち $`r_{13}`$ 台が翌月（または720時間）の間に故障した場合、13ヶ月目（あるいは使用時間 8640時間から 9360時間の期間）にわたって平均化された $`h(t)`$ の経験的推定値は、$` (r_{13} / N_{12} \cdot 720) `$ となる。
同様の推定については、[経験的モデル適合](../section2/apr214.md)」の節で詳細に議論している。

長年にわたり、多種多様な機械・電子部品やシステムを対象に、人々は経時的な経年変化に伴う経験的な母集団故障率を計算してきており、その結果として、以下に示すようなグラフが繰り返し得られてきた。
この故障率曲線の形状から、それは広く「バスタブ曲線」として知られるようになった。

顧客が製品の使用を初めて開始する時点（時間ゼロ）から始まる初期の領域は、高いが急速に低下する故障率が特徴である。
この領域は**初期故障期**（最初のバスタブ曲線プロットの保険統計学的な起源に由来して**乳児死亡期**とも呼ばれる）として知られている。
この故障率の低下は、通常、数週間から数ヶ月間続く。

次に、故障率は横ばいとなり、（理想的には）製品の耐用年数の大部分にわたってほぼ一定に保たれる。
この故障率が横ばいになる長い期間は、**偶発故障期**（**安定故障期**とも呼ばれる）として知られており、この一定の故障率の水準は**固有故障率**と呼ばれる。
ほとんどのシステムは、その寿命の大部分を、このバスタブ曲線の平坦な部分で動作していることに留意されたい。

最後に、対象集団のユニットが十分に長く使用され続けると、材料の摩耗が進み、劣化による故障がますます高い頻度で発生するにつれて、故障率は上昇し始める。
これが「**摩耗故障期**」である。

注：バスタブ曲線は（多くの実証的証拠に基づき）、修理系にも適用されます。
この場合、縦軸は[修理率もしくは故障発生率（ROCOF）](apr125.md)である。
