# 8.1.3. 信頼性データに関する共通課題と克服方法
#### 信頼性解析のパラドックス：製品の信頼性が高ければ高いほど、その信頼性を「証明」するために必要な故障データを収集するのが難しくなる 
信頼性データには、他のほとんどの統計データではあまり見られない、密接に関連した2つの典型的な問題がある。
それらは以下の通り。

* [打切り](apr131.md)（観察期間が終了した時点で、すべての個体が故障したわけではなく、生存している個体も存在する）
* [故障の欠如](apr132.md)（打切りが多すぎると、観察対象となる単位数が多くても、実際の故障例が不足し、データに含まれる情報は限定的になる）

これらの問題は、信頼性評価試験の計画や故障データの分析を行う際に、実用上かなりの困難をもたらす。
いくつかの解決策については、次の2つの節で論じる。
通常、これらの解決策には、追加の仮定を立てたり、複雑なモデルを使用したりすることが伴う。
