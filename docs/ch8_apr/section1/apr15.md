# 8.1.5. 一般的な加速モデルにはどのようなものがあるか

#### 応力の関数として故障までの時間を予測する加速試験モデル 
加速係数は、特定の動作応力水準（ある故障モードまたは機構について）における故障までの時間を用いて、異なる動作応力水準における等価な故障までの時間を予測する方法を示す。

応力の関数として故障までの時間を予測するモデルは、単なる加速係数の集まりよりもさらに優れている。
もし $`t_f = G(S)`$ と表し、$`G(S)`$ を任意の応力水準 *S* に対するモデル方程式とすると、2つの応力レベル $`S_1`$ と $`S_2`$ 間の加速係数は、単に $`AF = G(S_1) / G(S_2)`$ とするだけで簡単に計算できる。
これで、より高い応力 $`S_2`$ の条件下で試験を行い、寿命分布モデルを適合させ、故障率を評価するのに十分な数の故障データを得た上で、[線形加速関係表](apr14.md#LARtable)を用いて、より低い使用応力 $`S_1`$ 条件下で何が起こるかを予測することができる。

使用応力の関数として故障までの時間を予測するモデルは**加速モデル**として知られている。 

#### 破壊機構に関連する物理モデルや動力学モデルから導き出される加速度モデル
加速劣化モデルは通常、特定の破壊機構の根底にある物理学や化学に基づいている。
破壊機構の理論がより深く理解されるようになると、成功した経験的モデルは、多くの場合、複雑な物理学モデルや反応速度論モデルの近似であることが判明する。
