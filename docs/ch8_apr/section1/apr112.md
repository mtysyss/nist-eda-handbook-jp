# 8.1.1.2. 競争上の推進要因

#### 信頼性は製品の成功を左右する主要な経済的要因である
信頼性の正確な予測と管理は、製品の収益性において重要な役割を果たす。
保証期間内またはサービス契約対象の製品に掛かるサービス・コストは、主要な経費であり、価格設定における重要な要素である。
適切な予備部品の在庫管理や、サポート要員の採用、研修も、信頼性に関する正確な予測に依存している。
一方、信頼性目標を達成できない場合は、契約上の違約金が発生したり、将来のビジネス機会を失うことにもなりかねない。

顧客の信頼性に対する期待に応える製品を経済的に設計、販売できる企業は、今日の市場において強力な競争優位性を有している。
