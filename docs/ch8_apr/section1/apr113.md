# 8.1.1.3. 安全と健康に関する考慮事項

#### 一部の故障は深刻な社会的影響を及ぼすため、信頼性調査を計画するときにはこの点を考慮に入れるべきである
機器の故障は、人々の安全や健康に重大な影響を及ぼすことがある。
自動車、航空機、生命維持装置、発電所などがその例である。

「製品の信頼性評価」という観点からは、こうした壊滅的な故障も、製造装置で測定された重要な母数が仕様範囲からわずかに逸脱し、予定外の保守措置が必要となる故障と何ら変わりなく扱われる。

信頼性調査において、何が故障に該当するかを定義するのは、信頼性技術者（および関係する顧客）の責任である。
誤った信頼性評価が安全や健康に悪影響を及ぼす可能性がある場合は、より多くの資源（試験時間および試験対象単位）を計画に組み込む必要がある。
