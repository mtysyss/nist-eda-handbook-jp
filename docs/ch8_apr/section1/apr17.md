# 8.1.7. 修復系に用いられる基本的修復率モデルにはどのようなものがあるか

#### 修復可能なシステムの修復率に関するモデル

$`N(t)`$、$`M(t)`$、および $`m(t)`$ は、[修復率](apr125.md)」の節で定義している。
修復率モデルは、まず時間 *t* までの累積故障数の期待値である $`M(t)`$ の関数形式を決定することで定義される。
これの微分を求めると、修復率モデル $`m(t)`$ が得られる。

次の3節では、$`M(t)`$ について、複雑さが徐々に増していくモデル3つについて説明する。
それらは、[均質 Poisson 過程](apr171.md)、[冪乗則に従う非均質 Poisson 過程](apr172.md)、および[指数則に従う非均質 Poisson 過程](apr173.md)である。
