# 8.1.1. 製品の信頼性の評価と管理が重要なのはなぜか。

#### 信頼性の高い製品に依存し、それを求め、期待している
今日の技術社会において、ほぼすべての人が、日々の健康、安全、移動の自由、そして経済的福祉のために、多種多様で複雑な機械や設備が継続的に機能することに依存している。
私たちは、自動車、コンピュータ、家電製品、照明、テレビなどが、必要なときにいつでも――毎日、毎年――正常に機能することを期待している。
それらが故障した場合、その結果は壊滅的になりかねない。
怪我や人命の損失、あるいは多額の損害賠償訴訟が発生する可能性がある。
さらに多くの場合、繰り返される故障は苛立ちや不便、そして長引く顧客の不満につながり、責任のある企業の市場での地位に甚大な悪影響を及ぼす恐れがある。

#### 信頼性の低い製品を出荷することは、企業の評判を台無しにする
企業が信頼性に関する評判を築き上げるには長い時間が掛かるが、欠陥のある製品を出荷してしまうと、「信頼できない」というレッテルを貼られるのはほんの一瞬のことである。
新製品の信頼性を継続的に評価し、出荷されるすべての製品の信頼性を絶えず管理することは、今日の競争の激しいビジネス環境において不可欠な要件である。
