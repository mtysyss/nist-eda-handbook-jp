# 8.1.6.3. 極値分布

#### 極値分布とは、通常、無制限の無作為な観測値の大量のうちの最小値の分布を指す
**説明、数式、およびプロット** 

[Weibull 分布の用途](apr162.md#Uses%20of%20the%20Weibull%20Distribution)を説明したときに、すでに**極値分布**について言及した。
極値分布とは、同じ任意の分布から得られる非常に大規模な無作為観測値の集合における最小値または最大値の極限分布である。
Gumbel (1958)は、任意の性質の良い初期分布（すなわち、$`F(x)`$ が連続であり、逆関数を持つもの）については、最大値と最小値のどちらに関心があるか、また観測値が上界または下界で制限されているかに応じて、必要なモデルはごくわずかであることを示した。

信頼性モデル化の文脈では、最小値に関する極値分布が頻繁に扱われる。
例えば、あるシステムが *n* 個の同一の構成要素を直列に接続したものであり、これらの構成要素のうち最初のものが故障した時点でシステムが故障する場合、システムの故障時刻は *n* 個の無作為な構成要素の故障時刻のうちの最小値となる。
極値理論によれば、構成要素のモデル選択にかかわらず、*n* が大きくなるにつれてシステム・モデルは Weibull 分布に近づく。
同様の理由で、多くの類似した競合する故障過程のうち最初のものが臨界水準に達したときに構成要素の故障が発生する場合、構成要素単位でも適用できる。

しばしば**極値分布（タイプ1）**と呼ばれる分布は、無制限で同一分布を持つ多数の確率変数の最小値の極限分布である。
PDFおよびCDFは次式で与えられる。 

#### 極値分布の公式とPDFの形状

$$ \begin{align}
f(x) & =  \frac{1}{\beta} \cdot e^{\frac{x-\mu}{\beta}} \cdot \text{exp} \left[ -e^{\frac{x-\mu}{\beta}} \right],& \quad & -\infty < x < \infty, \quad \beta > 0 \\
& & & \\
F(x) & =  1 - \text{exp} \left[ -e^{\frac{x-\mu}{\beta}} \right],& \quad & -\infty < x < \infty, \quad \beta > 0
\end{align} $$ 

もし *x* 値に下限がある場合（故障時間の場合のように）、その極限分布は Weibull 分布となる。
Weibull 分布の[式](apr162.md#Formula's%20and)およびその[用途](apr162.md#Uses%20of%20the%20Weibull%20Distribution)については、すでに説明した。

#### Weibull 分布データの自然対数は極値データである
**極値分布モデルの用途**

1. 関心のある変数が、いずれも正または負の値をとることができるある多数の無作為要因の最小値であるようなモデル化の応用においては、極値分布を有力な候補モデルとして検討する。
寿命分布のモデル化においては、故障時間が下限としてゼロを持つため、Weibull 分布の方が適している。

2. Weibull 分布と極値分布の間には、有用な数学的関係がある。
もし $`t_1, t_2, \ldots, t_n`$ が Weibull 分布から得られた故障時刻の標本であるならば、 $`\text{ln}(t_1), \text{ln}(t_2), \ldots, \text{ln}(t_n)`$ は極値分布からの無作為な観測値となる。
言い換えれば、Weibull 分布の無作為な故障時間の自然対数は、極値分布の無作為な観測値である。  
<br>
Weibull 分布の形状母数が *γ*、特性寿命が *α* である場合、極値分布（自然対数をとった後）の母数は 
<br> 
$`\mu`$ = ln($`\alpha`$)、$`\beta = \frac{1}{\gamma}`$ 
<br> 
となる。
この関係により、極値分布用に設計されたコンピュータ・プログラムを用いて、Weibull 分布のデータを分析する。
これは、データ点の自然対数を先に取った上で、正規分布用のプログラムを用いて対数正規分布のデータを分析する場合と全く同様である。 

#### 極値分布の確率プロット
$`\mu = \text{ln}(200,000) = 12.206`$ および $`\beta = 1/2 = 0.5`$ とする。
これらの母数に関連する極値分布は、特性寿命 $`\alpha = 200,000`$、形状母数 $`\gamma= 2`$ を持つ Weibull 分布の母集団からのデータに自然対数を用いることで得られる。

この極値分布から 100個の乱数を生成し、以下の[確率プロット](../../ch1_eda/section3/eda33n.md)を作成する。

![Extreme value type I probability plot for 100 extreme value type I random numbers](https://www.itl.nist.gov/div898/handbook/apr/section1/apr163_r01.gif)

この種のプロットを作成すると、極値分布からのデータはほぼ直線上に並ぶ。
この直線の傾きは *β* の推定値であり、直線上の「*y* 軸」の値で「*x* 軸」の 0点に対応する点は *μ* の推定値となる。
上のグラフの場合、これらは *β* および *μ* の実際の値に非常に近いことが判る。

$`\mu = \text{ln}(200,000) = 12.206`$ および $`\beta = 1/2 = 0.5`$ である極端値分布の例では、点5, 8, 10, 12, 12.8 に対応するPDFの値は、それぞれ 0.110E-5, 0.444E-3, 0.024, 0.683, 0.247 である。
また、同じ点に対応する累積分布関数（CDF）の値は、0.551E-6、0.222E-3、0.012、0.484、0.962となる。

極値分布のPDF値やCDF値を計算し、確率プロットを作成するための関数は、[Dataplotコード](https://www.itl.nist.gov/div898/handbook/apr/section1/apr163.dp)および [Rコード](https://www.itl.nist.gov/div898/handbook/apr/section1/apr163.r)の両方に含まれている。
