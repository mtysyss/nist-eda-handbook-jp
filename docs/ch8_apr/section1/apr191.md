# 8.1.9.1. NHPPの冪乗則

#### 冪乗則が当てはまる場合、修理率は時間の経過とともに式 $`\alpha t^{-\beta}`$ に従って向上し、指数 $`\beta`$ は 0 から 1 の間で、信頼性成長勾配と呼ばれる
この修復系モデルについて、[8.1.7.2](apr172.md)節で説明した。
時刻 *t* までの予想故障回数は $`M(t) = a t^b`$ の形をとり、修復率は $`m(t) = a b t^{b-1}`$ の形をとる。
$` 0 < b < 1 `$ の場合、これは改善をモデル化し、*b* が小さいほど改善の度合いが大きくなる。
次の Duane プロット節で見るように、$`\beta = 1 - b`$ および $`\alpha = ab`$ と定義し、修復率を次のように表すと便利である。

$$ m(t) = \alpha t ^{-\beta} . $$

ここでも、$` 0 < \beta < 1`$ の場合に改善が見られ、*β* の値が大きいほど改善幅も大きくなる。
*β* は、[Duane プロット](apr192.md)の傾き、あるいは信頼性改善の**成長率*として知られている。

$`M(t)`$ の元の母数を用いて表すと、次式となる。

$$ a = \frac{\alpha}{1-\beta} \quad \text{および} \quad b = 1-\beta . $$

信頼性向上試験データに対する冪乗則モデルの適用では、一般的に以下の仮定が置かれる。

1. 試験の進行中に、システムの改良が導入され、それによってシステムの修理率が継続的に向上する。

2. 十分に長い期間に渡り、これらの改善による効果は、連続多項式修理率改善モデル $`\alpha t^{-\beta}`$ によって適切にモデル化できる。 

#### 改善テストが終了すると、MTBFは最後に達成された値で一定のままとなる

3. 改善試験が試験時間 *T* で終了し、それ以上の改善措置が進行中でない場合、修復率は $`\alpha T^{-\beta}`$ に低下している。
それ以降、修復率はこの新しい（改善された）水準で一定に保たれる。

仮定3は、試験が終了すると、HPP定数修理率モデルが適用され、それ以降のシステムのMTBFは最終的な修理率の逆数、すなわち $`(T^{\beta})/\alpha`$ になることを意味する。
時刻 *T* までの予想故障回数を実際に観測された回数から推定すると、（冪乗則に従う）信頼性試験終了時点での推定 MTBF は次式となる。

$$ \text{試験終了時の推定MTBF } = \frac{T}{r(1-\beta)} , $$

ここで、*T* は試験時間、*r* は試験中の総故障数、そして *β* は信頼性増加の傾きを表す。
システムの故障時間から *β* を推定するための式は、[冪乗則モデルの解析](../section4/apr452.md)節に記載している。 

#### シミュレーションデータの例

**NHPPの冪乗則データのシミュレーション** 

手順1：ユーザーが正の定数 $`a`$ および $`b`$ を入力する。

手順 2：*n* 個の一様分布（0,1）に従う乱数のベクトルをシミュレーションする。
これらを$`U_1, U_2, U_3, \ldots, U_n`$ と呼ぶ。

手順 3：$`Y_1 = \left\{ -\frac{1}{a} \text{ ln } U_1 \right\}^{1/b}`$ を計算する。

手順 *i*：$`Y_i = \left\{ Y_{i-1}^b - \frac{1}{a} \text{ ln } U_i \right\}^{1/b} \quad \\text{for} \ i = 2, \ldots, n`$ を計算する。

*n* 個の数値 $`Y_1, Y_2, \ldots, Y_n`$ は、母数 $`a`$、$`b`$（または $`\beta = 1-b`$ および $`\alpha = ab`$）を持つ NHPP冪乗からシミュレートされた、求める修復時間である。

**例** 

$`a = 0.2`$ および $`b = 0.4`$ の NHPP冪乗過程を用いて、$`n = 13`$ 個の無作為な修復時間を出力した。
