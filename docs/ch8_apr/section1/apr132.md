# 8.1.3.2. 故障の欠如

#### 故障信頼性を正確に評価し、向上させるためにはデータが必要 - 信頼性の高い部品を試験するときの問題 
信頼性データからモデルを適合させ、故障率を推定する場合、推定値の精度（信頼区間の幅によって測定される）は、観察された故障数の平方根に反比例して変化する傾向があり、試験対象の単位数や試験期間の長さとは関係ない。
言い換えれば、試験対象 10個のうち 5個が故障した試験は、1000個の試験対象のうちわずか 2個しか故障しなかった試験よりも、多くの情報を提供する。

故障数 *r* が重要であり、試験対象の標本規模 *n* ではないため、信頼性の高い部品の故障率を評価することはますます困難になる。
メモリ・チップのような部品は、通常の使用条件下では故障率が 1000時間あたり 100万分の1単位で測定され、妥当な期間、手頃な標本規模で試験を行っても、故障はほとんど、あるいは全く発生しない。
このことから信頼性試験の2つの主要な目的は以下である。すなわち、

* 母集団故障率の正確な評価
* 製品改善に活かすための故障モード情報の取得 

#### 通常応力よりも非常に高い応力で試験を行うと破損が生じる場合があるが、その場合には、使用応力に関連付けるためのモデルが必要
**予想される「故障の欠如」という問題を克服するための試験設計の方法** 

答えは、対象機器が本来の用途において通常受けるよりもはるかに高い応力下で試験を行い、故障を誘発することにある。
これにより、新たな問題が生じ、通常よりも高い応力下で発生したこれら故障を通常の使用応力下で長年にわたって予想される挙動と、どのように関連づけられるか。
高応力下での信頼性と通常の使用条件下での信頼性を関連付けるモデルは、[加速モデル](apr14.md)と呼ばれる。
