# 8.1.9. 信頼性向上のモデル化方法

#### 信頼性改善試験とは、システムの信頼性上の欠陥を発見し、修正することを目的とした正式な手順である
複雑なシステムの開発や試作の初期段階では、信頼性が顧客の要件を満たさないことがよくある。
信頼性の低下の原因を特定し、是正することを目的とした正式な試験手順は、「**信頼性改善試験**」として知られている。
この試験では、故障の原因となるシステム設計、システム組立、および部品選定上の弱点に焦点を当てる。

典型的な信頼性改善試験の手順としては、顧客が実際に使用する場合と同様に、プロトタイプ・システムを数週間にわたって稼働させ、その間、値術者や技術者（設計、品質、信頼性、製造など）からなる多分野横断的なチームが、発生したすべての故障を分析する。
このチームは故障の根本原因を特定し、その種の故障の将来的な発生を排除または低減できるよう、設計および／または組立の改善策を策定する。
試験が継続するにつれて、チームが考案した改善策が試作機に組み込まれ、試験の過程で信頼性が向上することが期待される。 

#### 信頼性向上試験の過程において、修理率は改善傾向を示すはずであり、これはNHPPモデルを用いてモデル化することができる
信頼性向上試験の別名は**TAAF**試験であり、これは**Test, Analyze And Fix（試験、分析、および 修正）**の略である。

修復系に改善や劣化の傾向が見られない場合には、適用できるモデルは1つだけ（[修復率が一定であるHPPモデル](apr171.md)）であるが、修復率が低下するシステムを記述するために使用できるモデルは無限にある（信頼性成長モデル）。

幸いなことに、比較的単純なモデルが1つか2つ、幅広い産業用途において非常に有効であることが判っている。
本節では、これまでに説明してきた2つのモデルを使用する。
それらは、[NHPP冪乗則モデル](apr191.md)と[NHPP指数則モデル](apr193.md)である。
冪乗則モデルは、[Duane プロット](apr193.md)として知られるに使用されるグラフ作成手法の基礎となっている。
