# 8.1.1.1. 品質 対 信頼性

#### 信頼性とは、「時間の経過に伴う品質の変化」である 
日常的に使われる「製品の品質」という言葉は、大まかに言えば、その製品が本来備えている優秀さの度合いを意味すると解釈されている。
産業界では、これをより正確に定義するために、品質を「使用開始時点における要件への適合性」と定めている。
製品仕様が顧客要件を適切に反映していると仮定すれば、出荷された製品のうち仕様を満たす製品の割合によって、品質水準を正確に測定することが可能となる。 

#### スナップ写真ではなく、動画
しかし、これらの単位のうち、1週間の稼働後も依然として仕様を満たしているものはどれほどあるだろうか？
あるいは1ヶ月後、あるいは1年間の保証期間が終了した時点では？
そこで重要になるのが「信頼性」である。
品質とは製品寿命の開始時点におけるスナップショットであり、信頼性とは日々の稼働を映し出す動画である。
タイムゼロ欠陥とは、最終検査で見逃された製造上のミスである。
時間の経過とともに現れる追加の欠陥は、「信頼性欠陥」、あるいは信頼性による不具合と呼ばれる。

#### 寿命分布モデルによる、時間経過に伴う割合の減少
品質水準は、欠陥の割合という単一の数値で表される場合がある。
信頼性の低下を記述するには、時間の経過に伴う信頼性の低下率を表す確率モデルが必要となる。
これは「[寿命分布モデル](apr121.md)」として知られている。
