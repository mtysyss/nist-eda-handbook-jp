# 8.1.3.1. 検閲

#### テスト対象のすべてのユニットが失敗するわけではない場合、そのデータは打ち切りデータとなります
 ある母集団から無作為に抽出した$`n`$個の（修理不可能な）ユニットの信頼性試験を行う状況を考えよう。
母集団の故障率が許容範囲内であるかどうかを判断するために調査を行っている。
典型的な試験シナリオでは、固定された時間 $`T`$ の間、ユニットを稼働させ、それらが正常に動作し続けるか、あるいは故障するかを観察する。
得られたデータは**「打ち切り型Iデータ」**と呼ばれます。
 **打ち切り第I種データ** $`T`$時間の試験期間中に、$`r`$件の故障が観測される（ここで、$`r`$は0から$`n`$までの任意の整数である）。
（正確な）故障時刻は $`t_1, \, t_2, \, \ldots, \, t_r`$ であり、故障することなく $`T`$ 時間の試験全体を耐え抜いたユニットは $`(n - r)`$個ある。
注：$`T`$は事前に固定されており、$`r`$は無作為である。
これは、試験が実施されるまで何件の故障が発生するかわからないためである。
また、故障が発生した場合にはその正確な時刻が記録されると仮定している点にも留意されたい。
この種の打ち切りは、右側（すなわち $`T`$ より大きい）の故障時刻が欠落しているため、「右打ち切り」データとも呼ばれる。
もう一つの（はるかに一般的ではない）試験方法は、正確に $`r`$件の故障時刻を確認したいと事前に決定し、それらが発生するまで試験を続けることである。
例えば、100個の試験対象を準備し、そのうちの少なくとも半数が故障することを確認したいと決定する場合がある。
この場合、$`r = 50`$ となりますが、50回目の故障が発生するまでは$`T`$ は不明である。
これは**「切断型IIデータ」**と呼ばれます。
 **II型打ち切りデータ** $`t_1, \, t_2, \, \ldots, \, t_r`$ を観測する。
ここで、$`r`$は事前に指定されている。
検定は時刻 $`T = t_r`$ で終了し、$`(n - r)`$個のユニットが生存している。
ここでも、故障した個体の正確な故障時刻を観測できると仮定する。
第II種打ち切りには、試験で得られる故障時刻の数が事前に分かっているという大きな利点がある。
これは、適切な試験を計画する際に非常に役立つ。
しかし、試験時間が不定である無作為試験は、管理上の観点からは一般的に非現実的であり、この種の試験はめったに見られない。

#### 欠測データに対処するために、
多くの特別な手法が開発されてきた**打ち切りデータにはどのように対処すればよいでしょうか？** 多くの統計的手法を用いれば、打ち切りデータであっても、モデルを推定し、故障率を推定することが可能である。
後のセクションでは、[カプラン・マイヤー](https://www.itl.nist.gov/div898/handbook/apr/section2/apr215.md)法、[確率プロット](https://www.itl.nist.gov/div898/handbook/apr/section2/apr221.md)、[ハザードプロット](https://www.itl.nist.gov/div898/handbook/apr/section2/apr222.md)、[グラフィカル推定](https://www.itl.nist.gov/div898/handbook/apr/section4/apr411.md)、[および最尤推定](https://www.itl.nist.gov/div898/handbook/apr/section4/apr412.md)について解説する。
 **故障モードの****分離** データ集合が、いくつかの異なる故障モードに分類できる故障時間で構成されている場合、各モードを個別に分析・モデル化することが可能であり（また多くの場合必要となる）、その点に留意してください。
分析対象以外のモードに起因するすべての故障を検閲時間とみなす。
この場合、検閲された実行時間は、別の（独立した）故障モードによって故障した時間と等しくなる。
これについては、[競合リスクのセ](https://www.itl.nist.gov/div898/handbook/apr/section1/apr181.md)クションおよび後の分析セクションでさらに詳しく説明する。
