# 8.1.2. 信頼性評価に用いられる基本的な用語やモデル

#### 19世紀の保険会社から始まった信頼性その手法や用語
信頼性理論は、確率論や統計学の主流とは別個に発展し、主に19世紀の海上保険会社や生命保険会社が、顧客に請求する収益性の高い保険料率を計算するためのツールとして用いられてた。
今日でも、「故障率」と「ハザード率」という用語は、しばしば同じ意味で使用されている。

以下の節では、信頼性を記述、推定、予測するために必要な概念、用語、およびモデルについていくつかを定義する。
