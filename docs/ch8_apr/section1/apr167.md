# 8.1.6.7. 比例ハザード・モデル

#### 比例ハザードモデルは、生存分析（医学的検査）の研究でよく用いられ、工学分野のデータではあまり用いられない。
Cox（1972）によって提唱された比例ハザードモデルは、主に医学的試験の分析において、生存率に対する二次変数の影響をモデル化するために用いられてきた。
これは、特定の生存分布モデルというよりはむしろ加速モデルに近く、その強みは、生存分布モデルの形状について特定の仮定を一切行わずに、生存に関する多くの推論をモデル化し、検定できる点にある。

この節では、比例ハザードモデルの工学的な応用は限られているため、その概要についてのみ簡単に説明する。

**比例ハザードモデルの仮定**

$`z = \{x, y, \ldots\}`$ を寿命に影響を与えると見なされる1つ以上の**説明**変数のベクトルとする。
これらの変数は、連続変数（工学研究における温度や、医学研究における特定の薬剤の投与量など）である場合もあれば、特定の要因や条件が存在する場合は値が 1、そうでない場合は 0となる指標変数である場合もある。

名目（またはベースライン）集合 $`z_0 = \{x_0, y_0, \ldots\}`$ に対するハザード率を $`h_0(t)`$ で表すものとし、$`h_0(t)`$ は、ある未指定の生存分布モデルに対する正当なハザード関数（生存率）を表すものとする。 

#### 比例ハザードモデルでは、負荷変数（または説明変数）の変化が、ハザード率に定数を乗じる効果をもたらすと仮定する
比例ハザードモデルでは、新しい *z* の値に対する変化したハザード関数を

$$ h_z(t) = g(z) h_0(t)  .$$

と表すことができると仮定している。
言い換えれば、説明変数ベクトル *z* を変化させることで、名目ハザード関数に比例する新しいハザード関数が得られ、その比例定数は、時間変数 *t* とは独立した *z* の関数 $`g(z)`$ である。

$`g(z)`$ の一般的かつ有用な形式として、**対数線形モデル**が挙げられ、その式は、変数が1つの場合は $`g(x) = e^{\alpha x}`$、変数が2つの場合は $`g(x,y) = e^{ax + by}`$ などとなる。

**比例ハザードモデルの性質と応用**

1. 比例ハザードモデルは、寿命分布モデルが Weibull 分布（その特殊な場合として指数分布を含む）である場合に限り、[加速因子](apr14.md)という概念と等価である。
形状母数 *γ* の Weibull 分布、公称使用故障時間 $`t_0`$ と高応力故障時間 $`t_s`$（$`t_0 = AF t_s`$） の間に加速因子 *AF* がある場合、$`g(s) = AF^\gamma`$ となる。
言い換えれば、$`h_s(0) = AF^\gamma h_0(t)`$ である。

2. $`g(z)`$ に対して対数線形モデルの仮定を置き、寿命分布モデルについてこれ以上の仮定を設けずに、実験データを解析し、[最尤推定量](../section4/apr412.md)を計算し、[尤度比検定](../section2/apr233.md)を用いて、どの説明変数が極めて有意であるかを決定することができる。
ただし、この種の分析を行うには、専用のソフトウェアが必要である。

比例ハザードモデルの理論と応用に関する詳細は、[Cox and Oakes (1984)](../section4/apr47.md#Cox,%20D.%20R.,%20and%20Oakes,%20D.%20%281984%29,%20Analysis%20of) に記載されている。
