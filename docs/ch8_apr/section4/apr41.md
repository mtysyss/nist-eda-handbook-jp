# 8.4.1. 打切りデータから、寿命分布母数の推定方法

#### グラフを用いた推定法（コンピューターによる直線近似を活用）は、簡単かつ迅速である。最尤法は通常、より正確だが、専用のソフトウェアが必要である。

本節では広く用いられている2つの一般的な手法について説明する。

* [グラフを用いた推定](apr411.md)
* [最尤推定（MLE）](apr412.md)

**どの手法を用いるべきかに関する推奨** 

最尤推定（故障データが非常にまばらな場合、すなわち故障数がごく少ない場合を除く）は、より正確で柔軟性の高い手法である。
ただし、打切りデータの場合、最尤推定法では、指数分布以外の分布に対して特別なコンピュータ・プログラムが必要となる。
近年、多くの統計ソフトウェア・パッケージに、MLEを計算する信頼性プラット・フォームが追加され、これらのパッケージのほとんどが加速モデルの母数を推定し、信頼区間も提示するため、これはもはや障害とはならない。

寿命試験データと加速モデル化に基づいて行われた信頼性予測を基に重要な経営判断を行うのであれば、最先端のMLE信頼性ソフトウェアを導入する価値がある。
そうでない場合、信頼性の監視や追跡には、コンピュータ支援のグラフィカルな手順に基づく推定手法で十分な場合が多い。
