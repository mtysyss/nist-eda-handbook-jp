# 8.4.2.3. 故障データではなく劣化データを用いてモデルを推定する

#### 劣化データを用いてモデルを推定できれば、実際の試験失敗データは必要ない

故障が、測定可能な製品母数の経時的な変化と直接関連付けられる場合、経時的な劣化を測定し、そのデータを用いて故障発生時期を推定することが可能になる。
これにより、実際に故障が発生するのを待つことなく、加速モデルや寿命分布モデルを適合させることができる。

この劣化モデル化の概要では、すでに[寿命分布](../section2/apr21.md)モデルと[加速モデル](../section2/apr24.md)が選択されていることを前提としており、前述の故障データに基づく[加速試験手法](../section3/apr314.md)に代わる選択肢を提示する。

**劣化データのモデル化における一般的な仮定** 

#### 臨界故障値まで直線的に変化（劣化）する、測定可能な係数が必要である

劣化データをモデル化するときに、一般的に行われる2つの仮定は以下がある。

1. 時間の経過とともに測定可能な母数 $`D`$ は、指定された臨界値 $`DF`$ に向かって単調に（上昇、または下降）偏位する。
$`DF`$ に達すると、故障が発生する。
2. $`D`$ を用いて測定されるこの偏位は、時間に対して線形であり、その傾き（**劣化率**）$`R`$ は、部品単位が   動作しているときに関連する負荷および、測定対象の部品単位の（無作為な）特性に依存する。
注：線形性を確保するために、$`D`$ を何らかの標準母数の変換として定義する必要がある場合がある。
対数や累乗を用いる必要がある場合もある。

下図は、試験中の部品単位5つの劣化プロットを示し、これらの仮定を説明している。
各部品単位の劣化値は、同じ4つの時点において測定され、これらの測定値部品単位トごとに直線を適合している。
その後、これらの直線は、臨界（故障）劣化値まで延長する。
これらの部品単位の予測故障時刻をプロットから読み取る。
それらは、$`t_1, t_2, \ldots, t_5`$ である。

#### 4つの時点において測定された部品単位5つの線形劣化傾向のプロット

多くの実用的な状況において、$`D`$ は時刻 0 で 0 から始まり、すべての線形理論的劣化曲線は原点から始める。
これは、$`D`$ が「変化率（%）」の母数である場合、あるいは故障が、その初期値にかかわらず、母数の所定の大きさの変化として定義される場合に当てはまる。
すべての線が原点から始まる場合、$`D`$ の母集団の初期値を特定する必要がなく、また、どの単位も故障に至るまでに「移動する」距離は常に定数 $`DF`$ となるため、解析が簡略化される。

また、$`D`$ 値を読み取る際の測定誤差の影響は、モデル推定の精度に比較的ほとんど影響を与えないと仮定することも一般的である。
 
**劣化データに基づくモデル化の利点** 

#### 測定データの完全な標本に基づいたモデル化は、たとえ負荷の低いセルであっても、多くの利点をもたらす

1. 各試験対象部品単位について、劣化に関する測定結果のそれぞれが1つのデータ点である。
これにより、たとえ故障がごくわずかであっても、大量の有用なデータが得られる。
2. 有意な数の故障を得るために、試験を長期間実施する必要はない。
3. 使用条件により近い低負荷のセルを試験し、有意義な劣化データを取得することができる。
もしモデル化に故障データが必要だった場合、同じセルを試験するのは時間の無駄になってしまう。
これらのセルは使用条件をより典型的に反映しているため、モデル母数に影響を与えるようにすることは理にかなっている。
4. 劣化と時間の関係を示す単純なグラフを用い、線形劣化の仮定を視覚的に検証する。

**劣化データに基づくモデル化の欠点**

#### 劣化は、顧客が「故障」と呼ぶ状態に向かって、滑らかで直線的な経過をたどるわけではないかもしれない

1. 多くの故障機構において、母数が臨界値まで低下し、その臨界値に達することが、顧客が故障と呼ぶ状態に相当するような場合は稀であるため、測定可能な母数を見つけ出すことは困難、あるいは不可能である。
2. 劣化傾向は個体ごとに不規則に変化し、それらを線形な傾向に変換する明確な方法が見当たらない場合がある。
3. 場合によっては、劣化傾向が可逆的であり、一部の部品単位が「自己修復」したり、状態が改善したりするように見えることもある。
この種の挙動は、一般的な仮定には当てはまらず、モデル化が難しい。
4. 測定誤差が顕著であり、特に低負荷下では、わずかな劣化傾向を覆い隠してしまうことがある。
5. たとえ劣化傾向が仮定通りに振る舞い、選択したモデルが良好に適合している場合でも、最終結果は実際の破損データに基づく解析と一致しないことがある。
これはおそらく、破損機構が単純な連続的な劣化プロセス以上の要因に依存していることを意味する。

最後に挙げた欠点のため、標準的な寿命分布モデル解析を行うのに十分な実際の破損が発生する、少なくとも1つの高負荷セルを用意しておくことが望ましい。
得られた母数推定値は、「現実」との照合として、劣化データ解析からの予測値と比較する。

**劣化データのモデル化に関する簡単な方法** 

#### 簡単な手法としては、各部品単位の劣化曲線を、予測される「故障時刻」が得られるまで延長する方法がある

1. 上の図に示すように、各部品単位の劣化測定値を通る直線を引く。
これは手作業で行うこともできるが、最小二乗回帰プログラムを使用する方が良い。
2. 回帰直線の式を求め、$`Y`$ の代わりに *DF* を代入し、 $`X`$ を求める。
この $`X`$ 値が、その部品単位の「予測故障時刻」となる。
3. 負荷セル内のすべての部品単位についてこの手順を繰り返し、そのセルに関する（予測）故障時間の完全な標本が得られるまで続ける。
4. これらの故障時間を用いて、セル全体の寿命分布母数の推定値を計算する。
比較的一般的な仮定である[対数正規モデル](../section1/apr164.md)の下では、これは非常に簡単である。
すべての故障時間の自然対数をとり、得られたデータを正規分布からの標本として扱う。
標本平均と標本標準偏差を計算する。
これらは、そのセルにおける $`\text{ln } T_{50}`$ および $`\sigma`$ の推定値である。
5. 負荷が異なる $`k`$ 個のセルが存在すると仮定し、[グラフを用いた推定](apr421.md)節で説明されているように、各セルの $`\text{ln } T_{50}`$ 値を用いて、適切な[加速モデル](../section2/apr24.md)を適合させる。
単一のシグマ推定値は、各セルの $`\sigma^2`$ 推定値の平均平方根をとることで得られる（各セルの部品単位数が同じであると仮定する）。
各セルで試験対象の単位数が $`n_j`$ 個あり、かつ $`n_j`$ の値がすべて等しくない場合は、以下の式で計算される、すべての $`k`$ 個のセルに亘って組み入れられた平方和推定値を使用する。

$$ \hat{\sigma}^2 = \frac{1}{\sum_{j=1}^k (n_j - 1)}\sum_{j=1}^k \sum_{i=1}^{n_j} \left( x_{ij} - \bar{x}_j \right)^2 . $$ 

**時刻 0 で $`D = 0`$ であり、すべての部品単位で「故障までの距離」*DF* が同じである場合の、より正確な回帰手法** 

#### すべての劣化測定値を用いて、線形回帰分析によりモデルを推定することができる

$`k`$ 番目の負荷セルにおける $`j`$ 番目の読出し時刻での $`i`$ 番目の部品単位の劣化測定値を $`D_{ijk}`$ とし、対応する読み出し時刻を $`t_{jk}`$ と表す。
その読出し結果から、劣化率（または傾き）の推定値 $`D_{ijk} / t_{jk}`$ が得られる。
これは線形性の仮定、すなわち以下の関係式から導かれる。

$$ (\text{劣化率}) × (\text{試験時間}) = (\text{劣化量}) $$ 
 
その読出値のみに基づいて、その部品単位の故障までの時間の自然対数の推定値は次式となる。
 
$$ y_{ijk} = \text{ln } DF - \left( \text{ln } D_{ijk} - \text{ln } t_{jk} \right) . $$
 
これは、線形劣化と故障時間を結びつける基本式
 
$$（\text{劣化率}）×（\text{故障時間}） = DF $$ 
 
から、(故障時刻)を解き、自然対数をとることで得られる。

[Arrhenius モデル](apr421.md)による解析では、
 
$$ t_f = A \cdot \text{exp}\left( \frac{\Delta H}{KT} \right) , $$
 
$$ y_{ijk} = a + b x_k , $$ 

$`x_k`$ 値は $`1/KT`$ に等しい。
ここで、$`T`$ は $`k`$ 番目のセルの温度（ケルビン単位、273.16 + 摂氏度）であり、$`K`$ はボルツマン定数（8.617 × 10⁻⁵ eV/ケルビン）である。
線形回帰プログラムを用いて、$`a = \text{ln } A`$ および $`b = \Delta H`$ を推定する。
さらに、$`t_f`$ が対数正規分布に従うと仮定すると、回帰適合による平均二乗残差は $`\sigma^2`$ の推定値となる（ここで $`\sigma`$は対数正規分布のシグマである）。

このモデルを次のように考えることもできる。
各部品単位には、無作為な劣化速度 $`R`$ がある。
$`t_f = DF/R`$ であるため、正規分布の特性から、が対数正規分布に従うならば、$`R`$ も対数正規分布に従わなければならない（$`DF`$ と $`R`$ が独立であると仮定する）。
対数をとると、$`\text{ln } R`$ は、平均が加速モデル母数によって決定される正規分布に従う。
$`R`$ の無作為性は、材料や加工の違いに起因する、部品単位ごとの物理的特性のばらつきに由来する。

注：この単純なグラフ的手法に基づくシグマの推定値は、劣化測定値の読取り時に生じる測定誤差による加算項が含まれるため、過大になりがちである。
ただし、これは一般的に影響は小さいと想定されている。

 **例：Arrhenius 型劣化解析** 

#### 回帰分析を用いて Arrhenius モデルを適合する例

ある部品には、研究により、動作温度に応じて変化する速度で時間の経過とともに線形に劣化する重要な母数がある。
この母数に基づく部品の故障は、母数値が30％以上変化したときに発生する。
15個の部品を 3つの異なる温度条件（65°Cで 5個、85°Cで 5個、残りの 5個を 105°C）下で試験した。
劣化率の値は、200時間、500時間、1000時間時点で読み取られた。

なお、85°Cのセルでは 1単位が、105°Cのセルでは 4単位が故障したことに留意されたい。
故障件数が極めて少なかったため、105°Cのセル以外では寿命分布モデルを適合させることは不可能であり、したがって、故障データを用いて加速モデルを適合させることはできない。
そこで、劣化データを用いて、Arrhenius／対数正規モデルを適合させる。

 **解：** 

#### 劣化データにモデルを適合させる
上記の表をもとに、まず、最初の表の1行目から最後の表の最終行までを順にたどって、45個の劣化値を持つ変数（$`DEG`$）を作成する。
次に、温度変数（$`TEMP`$）を作成する。
この変数には、65が15回、続いて85が15回、さらに105が15回繰り返されるように設定する。
最後に、読み取り時刻に対応する時間変数（$`TIME`$）を作成する。

Arrhenius／対数正規方程式 $`y_{ijk} = a + bx_{ijk}`$ を適合させる。
ここで、

$$ y_{ijk} = \text{ln } 30 - \left( \text{ln } DEG - \text{ln } TIME \right) $$

および

$$ x_{ijk} = \frac{100000}{8.617(TEMP + 273.16)} . $$ 

線形回帰の結果は以下の通り。

```
   Parameter     Estimate   Stan. Dev   t Value
   ---------     --------   ---------   -------
   a            -18.94337    1.83343     -10.33 
   b              0.81877    0.05641      14.52 
 
   Residual standard deviation = 0.5611 
   Residual degrees of freedom = 45
```

Arrhenius モデルの母数推定値は、$`\text{ln } A = -18.94`$、$`\Delta H = 0.82`$ である。
対数正規分布のシグマ（$`\sigma`$）の推定値は 0.56 である。
