# 8.4.1.2. 最尤推定

#### 最尤法には視覚的な要素は一切ないが、これは強力な手法であり、少なくとも標本数が大きい場合には非常に精度が高い

最尤推定は、標本データの<u>尤度関数</u>として知られる数式を記述することから始める。
大まかに言えば、あるデータ集合の尤度は、選択された確率分布モデルを前提とした場合、その特定のデータ集合が得られる確率である。
この式には、未知のモデル母数が含まれている。
標本尤度を最大化するこれらの母数の値は、<u>最尤推定量</u>、<u>MLE</u>と呼ばれる。

最尤推定は完全に解析的な最大化手順である。
これは、あらゆる形態の打切りデータや多重打切りデータに適用可能であり、複数の負荷セルにまたがってこの手法を用い、寿命分布の母数と同時に加速モデルの母数を推定することも可能である。
さらに、MLEおよび尤度関数は、一般的に非常に望ましい大標本特性を有している。

* 標本規模が増加するにつれて、それらは不偏かつ最小分散の推定量となる
* 近似的に正規分布に従い、近似的な標本分散が計算可能であり、これを用いて信頼境界を得ることができる
* 尤度関数は、モデルや母数に関する仮説の検定に使用できる。 

#### 標本数が少ない場合、MLEは精度があまり高くない可能性があり、データ点の上や下に位置する直線を得られることさえある

MLEには2つの欠点しかないが、それらは重要である。

* 故障数が少ない場合（5件未満、場合によっては 10件未満でも少ないとされる）、MLEには大きな偏りが生じやすく、大標本における最適性の性質は適用されない。
* MLEの計算には、多くの場合、複雑な非線形方程式を解くための専用ソフトウェアが必要である。
しかし、年を追うごとにより多くの統計パッケージがMLE解析機能を搭載するようになっているため、この問題は徐々に解消されつつある。

最尤推定に関する追加情報は、[1章](../../ch1_eda/section3/eda3652.md)に記載している。

#### 打ち切りデータに対する尤度式

**信頼性データの尤度関数の例：** 

選択された寿命分布モデルについて、$`f(t)`$ をPDF、$`F(t)`$ をCDFとする。
これらは *t* およびモデルの未知母数の関数であることに注意されたい。
[タイプ1 打切りデータ](../section1/apr131.md#Censored Type I)に対する尤度関数は次式となる。

$$ L = C \left( \prod_{i=1}^r f(t_i) \right) [1-F(T)]^{n - r} , $$

ここで *C* は、最尤推定量（MLE）を求める際には役割を果たさない定数を表す。
なお、打切りがない場合、尤度は単に各密度関数を故障時刻で評価した積に帰着される。
[タイプ2 打切りデータ](../section1/apr131.md#Censored%20Type%20II)については、上記の *T* を試験終了時刻の確率変数 $`t_r`$ に置き換えればよい。

[読出しデータ](../section1/apr131.md#Readout%20or%20Interval)の尤度関数は次式となる。

$$ L = C \left( \prod_{i=1}^k \left[ F(T_i) - F(T_{i-1}) \right]^{r_i} \right) [1-F(T)]^{n - \sum_{i=1}^k r_i} , $$

ここで、$`F(T_0)`$ は 0 と定義される。

一般に、任意の[多重検知データ](../section1/apr131.md#Multicensored)集合の尤度は、標本内の各単位に対して、項の定数積となり、$`f(t_i)`$、$`[F(T_i) - F(T_{i-1})]`$、あるいは $`[1-F(t_i)]`$ のいずれかの形をとり、その単位が時刻 $`t_i`$ で正確に故障したか、2つの観測時刻 $`T_{i-1}`$ と $`T_i`$ の間に故障したか、あるいは時刻 $`t_i`$ まで生存し、それ以降観測されなくなったかによって異なる。

MLEを求めるための一般的な数学的手法には、$`\text{ln } L`$ の偏微分（未知の母数に対する微分）をゼロに等しく設定し、その結果得られる（通常は非線形の）方程式を解くことが含まれる。
ただし、指数モデルの式は容易に解くことができる。 

#### 指数モデルのパラメータ *λ* に対する MLE は、単に（総故障数）を（単位部品試験の総時間）で割ったものになることがわかった

**指数分布モデル（タイプ1 打切り）の最尤推定量（MLE）：** 

$$ \begin{align}
L = C \lambda^r \text{ exp } \left( -\lambda \sum_{i=1}^r t_i \right) \left( e^{-\lambda(n-r)T} \right) \\
\\
\text{ln } L = \text{ln }C + r \text{ ln } \lambda - \lambda \sum_{i=1}^r t_i - \lambda(n-r)T \\
\\
\frac{\partial \text{ln } L}{\partial \lambda} = \frac{r}{\lambda} - \sum_{i=1}^r t_i - (n-r)T = 0 \\
\\
\hat{\lambda} = \frac{r}{\sum_{i=1}^r t_i + (n-r)T} 
\end{align} $$ 

**注：** 指数分布の場合、故障率（または修復率）の最大尤度推定量（MLE）は、観測された故障総数を部品単位試験の総時間で割った値となる。
MTBFの最大尤度推定量については、この値の逆数を取るか、部品単位試験の総時間を観測された故障総数で割った値を用いる。
