# 8.4. 信頼性データの分析

構成部品やシステムの信頼性データを取得した後、寿命分布モデル、信頼性成長モデル、加速モデルにどう適合させるか。
使用条件下での故障率やMTBF類と、プロジェクト構成部品やシステム信頼性をどう予測するか。
本節では、これら種類の問いに答える。
