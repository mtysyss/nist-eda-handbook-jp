# 8.4.5. システム修復率モデルの推定方法

#### 前述の適合モデル

この小節では、実際の故障データがある場合に、システム修復率モデルを推定する方法について説明する。
データは、システムの通常稼働時の観測結果や、信頼性向上試験などの試験結果から得られる場合がある。

ここで取り上げる3つのモデルは、定修復率[HPP／指数）モデル](apr451.md)[冪乗則（Duane）モデル](apr452.md)、および[指数則モデル](apr453.md)である。
