# 8.4.5.3. 指数関数モデル

#### 指数分布モデルの母数推定値は、グラフを用いた手法または最尤推定のいずれかによって求めることができる

[1節](../section1/apr173.md)で述べたように、指数法則とは、修復率

$$ M'(t) = m(t) = \text{ exp } (\alpha + \beta t) $$

を持つNHPPプロセスを指す。
このモデルは、産業用途において冪乗則モデルほど広く用いられておらず、解析もより難しい。
ここでは簡単な説明にとどめる。

期待故障数は  

$$ M(t) = (1/\beta) \cdot \text{ exp } (\alpha + \beta t) $$

であり、

$$ \text{ln } M(t) = -\alpha \text{ ln } \beta + \beta t , $$

対数線形尺度で累積故障数を故障時間に対してプロットすると、おおむね傾きが $`\beta`$ の直線に従うはずである。
$`y = \text{ ln (累積故障数)}`$ 対 $`x = \text{ 故障時刻}`$ について回帰分析を行うと、傾き $`\beta`$ および切片 $`-\alpha \text{ ln } \beta`$ の推定値が得られる。

あるいは、以下の2つの式から最尤推定値を求めることもできる。

$$ \sum_{i=1}^r t_i + \frac{r}{\beta} - \frac{rT}{1 - e^{-\beta T}} = 0 $$
$$ \alpha = \text { ln } \left( \frac{r\beta}{e^{-\beta T} -1} \right) \, . $$ 

最初の方程式は非線形であるため、$`\beta`$の最尤推定値を求めるには反復的に解く必要がある。
その後、この推定値を2番目の方程式に代入して、$`\alpha`$ の最尤推定値を求める。
