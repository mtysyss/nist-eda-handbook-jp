# 8.4.1.3. Weibull 分布の最尤推定の例

#### Weibull 分布データを用いた信頼性解析
以前の例（[8.2.2.1](../section2/apr221.md#Example)）のデータを用いて、Weibull 分布の打ち切りデータをプロットし、母数を推定する。

記録された故障時間は54、187、216、240、244、 335、361、373、375、および386時間で、故障しなかった10個の単位は500時間時点で試験から除外された。
データは次の表にまとめられている。

```
 Time   Censored  Frequency
  54       0          1
 187       0          1
 216       0          1
 240       0          1
 244       0          1
 335       0          1
 361       0          1
 373       0          1
 375       0          1
 386       0          1
 500       1         10
```

「Time」列には故障時刻および打切り時刻が、「Censored」列には、1列目の時刻が故障時刻か打ち切り時刻かを示す変数が、そして「Frequency」列にはその時点で故障した、または打切りとなった部品単位数が示されている。

まず、Kaplan-Meier 法を用いて生存曲線を生成し、Weibull 確率プロットを作成する。
**注**：一部のソフトウェアパッケージでは、同義語である「Kaplan-Meier」の代わりに、「積極限法」または「積極限生存予測」という名称が使用されている場合がある。

![Survival Curve](https://www.itl.nist.gov/div898/handbook/apr/section4/apr413_r01.gif)

![Weibull Probability Plot](https://www.itl.nist.gov/div898/handbook/apr/section4/apr413_r02.gif)

次に、故障時間が Weibull 分布に従うと仮定した生存モデルについて、回帰分析を行う。
Weibull 分布の特性寿命母数（$`\eta`$）推定値は 606.5280、形状母数（$`\beta`$）の推定値は1.7208である。
モデル適合による対数尤度および赤池情報基準（AIC）は、それぞれ -75.135 および 154.27 である。
比較のために、対数正規分布のAICを計算したところ、Weibull 分布のAICよりわずかに大きいだけであることが判った。

```
Lognormal AIC   Weibull AIC 
    154.39         154.27
```

AICの値を比較する場合、小さいほど良い。
推定された Weibull 分布の確率密度関数を以下に示す。

![Probability Density of Fitted Curve](https://www.itl.nist.gov/div898/handbook/apr/section4/apr413_r03.gif)

 $`\eta`$ および $`\beta`$ の推定値に基づき、寿命の期待値と標準偏差は以下となる。
 
$$ \begin{align}
\hat{\eta} &= 606.5280 \\
\\
\hat{\beta} &= 1.7208 \\
\\
\hat{\mu} &= \hat{\eta} \cdot \Gamma \left( 1 + 1/\hat{\beta} \right) = 540.737 \,\, \text{時間}\\
\\
\hat{\sigma} &= \hat{\eta} \, \sqrt{\Gamma \left( 1+2/\hat{\beta} \right) -\left( \Gamma \left(1+1/\hat{\beta} \right) \right)^{2}} = 323.806 \ \text{時間}
\end{align} $$

ギリシャ文字 $`\Gamma`$ はガンマ関数を表する。 

#### 考察
最尤推定（MLE）は、適切なソフトウェア解析パッケージが利用可能であれば、生存分布母数を推定するための正確かつ簡単な方法である。
また、そのパッケージは信頼区間や対数尤度値も計算できるものである必要がある。

本節の解析は、[Rコード](https://www.itl.nist.gov/div898/handbook/apr/section4/apr413.r)を用いて実施することができる。
