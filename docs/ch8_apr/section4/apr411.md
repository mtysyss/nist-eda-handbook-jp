# 8.4.1.1. グラフを用いた推定

#### 確率プロット上の直線は、分布母数を一意に特定する
故障データから[プロット位置](../section2/apr221.md#Plotting)を計算し、選択したモデルに対する[確率プロット](../section2/apr221.md#How%20Special%20Papers%20Work)を作成すれば、母数推定は容易に行える。
しかし、[グラフを用いた推定の仕組み](apr411.md#Graphical%20Estimation)に加え、グラフを用いた推定法の[長所](apr411.md#Advantages%20of%20Graphical%20Methods%20of)と[短所]の(apr411.md#Disadvantages%20of%20Graphical%20Methods of)両方を留意する必要がある。

#### ほとんどの確率プロットには、基礎となる分布の母数推定値を計算するための簡単な手順がある

**確率プロットを用いた推定の仕組み：** 

確率プロット上の点を通る直線を描くと、通常、傾き（または形状母数）および尺度母数の推定値を求めるための単純な規則がある。
*x* 軸に時間、*y* 軸に累積百分位数をプロットした対数正規確率プロット上で、34百分位数と50百分位数から推定直線に向かって水平線を引いた後、それらの交点から時間軸に向けて垂直線を降ろす。
50百分位数に対応する時間は $`T_{50}`$ の推定値である。
$`T_{50}`$ を 34百分位数に対応する時間（これは $`T_{34}`$ と呼ばれる）で割る。
その比の自然対数がシグマの推定値であり、すなわち直線の傾きである（$`\sigma = \text{ln } (T_{50} / T_{34})`$）。

Weibull 確率プロットでは、*y* 軸から 62.3百分位数点における回帰直線まで水平線を引く。
その推定直線は、各点を通る直線と、特性寿命母数 *α* の推定値となる時刻で交差する。
回帰直線の傾き（または形状母数 *γ*）を推定するには、回帰直線上の任意の2点を選び、*y* 変数の変化量を *x* 変数の変化量で割る。 

#### コンピュータによる直線近似処理を使用することで、主観的な要素が排除され、プロット位置に基づいたコンピュータによる母数推定値を直接導き出すことができる

点を通る直線を引くときの主観性を排除するために、[確率プロット](../section2/apr221.md#How%20Special%20Papers%20Work)の節で説明した式を用いて、最小二乗法（回帰）による近似を行う。
この[例](../section2/apr221.md#DATAPLOTExample)として、Weibull 分布に関するものも同節で示している。
同じデータを用いた Weibull 分布のプロットに関する別の[例](apr413.md)の後半で示している。

最後に、正確な時刻と完全な標本（打切りなし）がある場合、多くのソフトウェア・パッケージには[確率プロット](../../ch1_eda/section3/eda33n.md)機能が組み込まれている。
その例は、さまざまな[寿命分布モデル](../section1/apr16.md)について説明した節に示している。 

#### 最終的な推定値の算出に他の手法を用いる場合でも、確率プロットを作成する

**グラフを用いた推定手法の利点：**

* 図式的な推定法は、迅速かつ使いやすく、視覚的にも理解しやすい。
* 計算には、特別なソフトウェアをほとんど、あるいは全く必要とせずに実行できる。
* モデルの視覚的な検証（つまり、点がどの程度整列しているか）も、追加される利点である。

**グラフを持ちた推定法の欠点**

#### おそらく、グラフを用いた推定の最大の欠点は、推定値に対して妥当な信頼区間を得ることができないという点である

グラフによる推定値の統計的性質（すなわち、平均的にどれほど正確か）は芳しくない。

* 偏りを持ち、
* 標本規模が大きくても、最小分散（すなわち、最も正確な）推定量ではなく、
* グラフによる手法では母数の信頼区間が得られない（この種のデータに対して回帰分析プログラムによって得られる区間は不正確である）、そして
* モデル適合度や母数値に関する正式な統計的検定は、グラフを用いた手法では実施できない。

次の節で見るように、[最尤推定量](apr412.md)は、これらすべての欠点を克服している――少なくとも、故障数が十分に多い信頼性データ集合においては――その代償として、グラフを用いた推定に挙げられた上記の利点をすべて失うことになる。
