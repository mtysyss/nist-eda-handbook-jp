# 8.4.2. 加速度モデルの適合方法

#### 加速度モデルは、グラフを用いた手法または最尤法のいずれかによって推定することができる
寿命分布モデルの母数を推定する場合と同様に、加速度モデルの母数を推定するには、一般的に2つの手法がある。

* [グラフを用いた推定](apr421.md)（あるいは可視化手法に基づくコンピュータ手順）
* [最尤推定](apr422.md)（加速度モデルを組み込み、すべてのセルに渡る全データの尤度関数を記述することに基づく解析的手法）。

これらの手法に関するこれまでの指摘や[推奨事項](apr41.md)は、依然として当てはまる。
ただし、負荷セル全体にわたって最尤推定を行い、加速度モデルの適合と検定を行う有用なソフトウェア・プログラムを見つけることは、さらに困難であることに留意する。

#### 場合によっては、劣化データを用いてモデルを推定できる
加速モデルの適合に別の有望な方法は、最終的に破壊を引き起こす負荷に誘導される漸進的な劣化過程を特徴とする破壊機構の研究に適用可能な場合がある。
この手法は、[劣化データに基づいてモデルを適合](apr423.md)し、実際に破壊現象を必要としないという利点がある。
これにより、すべての負荷セル内の各部品単位について、連続した時間間隔での測定データが得られるため、打切りによる制限を克服できる。
