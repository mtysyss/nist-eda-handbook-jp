# 8.4.2.2. 最尤法

#### 最尤法を用いることで、分布および加速度モデルの母数を同時に推定することができる
マルチセル加速モデルの尤度方程式は、8.4.1.2節で説明されているように、各セルに対する[尤度関数](apr412.md)を利用する。
各セルには未知の寿命分布母数があり、これらは一般に異なる。
例えば、対数正規モデルを使用する場合、各セルは独自の $`T_{50}`$ およびシグマを持つことになる。

しかし、加速の仮定の下では、すべてのセルには、同じシグマの値を持つ母集団からの標本が含まれている（異なる応力セル間でも傾きは変化しない）。
また、$`T_{50}`$ 値は加速モデルによって互いに関連しており、これらはすべて、適切なセル応力を含む加速度モデル式を用いて表すことができる。

加速度モデルの仮定の下で尤度式を導出するには、各セルの $`T_{50}`$ を加速度モデルの方程式における等価な式に置き換え、各セルのシグマを同じ全体的なシグマに置き換えることで、各セルの尤度を書き直せばよい。
次に、これらすべての修正されたセルの尤度を掛け合わせることで、全体的な尤度式を得る。

全体的な尤度式が作成されると、シグマおよび加速度モデル母数の最尤推定量（MLE）は、この尤度を最大化する値となる。
ほとんどの場合、これらの値は、対数尤度の偏微分をゼロに設定し、その結果得られる（非線形の）連立方程式を解くことによって得られる。 

#### この方法は複雑で、専用のソフトウェアが必要である
ご覧の通り、この手順は複雑で計算負荷が高く、適切なソフトウェアが利用可能な場合にのみ実用的なものである。
MLEには多くの望ましい特徴がある。

* この手法は、少なくとも理論上は、あらゆる分布モデルや  加速モデル、およびあらゆる種類の打ち切りデータに適用可能である。
* 標本規模（すなわち、故障数）が大きくなるにつれて、推定値は「最適な」統計的性質を持つようになる。
* 近似的な信頼境界を計算することができる。
* [尤度比検定](../section2/apr233.md)を用いて、主な仮定に対する統計的検定を行うことができる。
一般的な検定例としては以下がある。
    * 寿命分布モデルと、母数数が少ない別のより単純なモデルとの比較（すなわち、3母数 Weibull 分布と 2母数 Weibull 分布、あるいは2母数 Weibull 分布と指数分布との比較）、
    * 典型的な加速モデルにおけるセル間の勾配が一定であるという要件、および  特定の加速モデルの適合度。
    * 特定の加速モデルの適合度。

一般に、寿命分布モデルの母数を推定する手法を比較する際に示される[推奨事項](apr41.md)は、ここにも適用される。
加速モデル解析機能を組み込んだソフトウェアは、ほんの数年前まではほとんど見られなかったが、現在では容易に入手可能であり、多くの企業や大学が独自のバージョンを開発している。
 
 **Arrhenius モデルの適合手順** 

#### MLEを用いて、例示データに Arrhenius モデルを適合させる

8.4.2.1節で示した[Arrhenius の例](apr421.md#Graphical%20Estimation%3A%20Arrhenius%20Model)のデータをMLEを用いて解析した。

本節の解析は、[Rコード](https://www.itl.nist.gov/div898/handbook/apr/section4/apr422.r)を用いて実装することができる。

1. 各セルについて生存曲線を作成する。
すべてのプロットおよび推定値は、Arrhenius モデルの仮定を適用せず、個々のセル・データに基づいて計算されている。

![Survival Curves](https://www.itl.nist.gov/div898/handbook/apr/section4/apr422_r01.gif)

2. 3つのデータ・セルに対する対数正規生存回帰モデル化の結果を以下に示す。

```
Cell 1 - 85 °C
  Parameter   Estimate   Stan. Dev     z Value  
  ---------   --------   ---------     -------  
  Intercept     8.891      0.890        9.991    
  ln(scale)     0.192      0.406        0.473    
 
  sigma = exp(ln(scale)) = 1.21 
  ln likelihood = -53.4```


Cell 2 - 105 °C
  Parameter   Estimate   Stan. Dev     z Value  
  ---------   --------   ---------     -------  
  Intercept     6.470      0.108        60.14        
  ln(scale)    -0.336      0.129        -2.60      
 
  sigma = exp(ln(scale)) = 0.715   
  ln likelihood = -265.2


Cell 3 - 125 °C
  Parameter   Estimate   Stan. Dev     z Value  
  ---------   --------   ---------     -------  
  Intercept      5.33      0.163        32.82     
  ln(scale)     -0.21      0.146        -1.44     
 
  sigma = exp(ln(scale)) = 0.81 
  ln likelihood = -156.5
```

各セルの ln 尤度値は、それぞれ -53.4、-265.2、-156.5 である。
これらを合計すると、各セルごとに個別の対数正規分布母数を用いて全データを適合した場合（Arrhenius モデルの仮定なし）、総対数尤度は -475.1となる。 

3. MLEを用いて、すべてのデータに Arrhenius モデルを適合させる。

```
  Parameter   Estimate   Stan. Dev     z Value  
  ---------   --------   ---------     -------  
  Intercept   -19.906      2.3204       -8.58   
  l/kT          0.863      0.0761       11.34   
  ln(scale)    -0.259      0.0928       -2.79 
 
  sigma = exp(ln(scale))Scale = 0.772   
  ln likelihood = -476.7
```

4. Arrhenius モデル適合（単一シグマ加速の仮定も組み込まれている）に対する尤度比検定統計量は $` -2 \text{ ln } \lambda`$ であり、ここで $`\lambda`$ は 0.772 であり、ここで $`\lambda`$ は、Arrhenius モデルの仮定を適用した場合 ($`L_0`$）と適用しない場合（$`L_1`$）の尤度値の比を表すため以下となる。

$$ -2 \text{ ln } \lambda = -2 \text{ ln } (L_0 / L_1) = -2(\text{ln } L_0 - \text{ln } L_1) . $$

手順2 および 3の結果を用いると、次式を得る。

$$ -2 \text{ ln } \lambda = -2[-476.7 - (-475.1)] = 3.2 . $$

カイ二乗検定統計量の自由度は、加速度モデルの仮定の下で、6母数が3つに削減され 6 - 3 = 3 である。
自由度3 のカイ二乗分布において、3.2以上の値が得られる確率は 36.3 %であり、これはモデルが許容範囲内（有意な適合不良がない）であることを示している。 

これで、データ・セル3つに対する Arrhenius モデルの解析は完了する。
異なるデータ・セル間で電圧が異なる場合は、逆冪乗則の逆数モデルに適合させるために、新しい変数「$`\text{ln } V`$」を効果として追加する。
実際、複数の応力がセル間で変動する場合は、一度に複数の効果を含めることができる。
また、これらの列をスプレッドシートに追加し、モデル内で追加の「効果」として含めることで、応力の外積項を含めることも可能である。

なお、故障数が多く、打切りが少なければ、この2つの手法の結果はかなり一致している。
また、Arrhenius モデルの結果についても、両手法はほぼ一致している。
しかし、使用条件下で信頼性値を予測する場合には、わずかな差異であっても重要になることがある。
この例では、25°Cおよび 100,000時間におけるCDFは、グラフによる推定値では 0.014となるのに対し、MLEを用いた場合はわずか 0.003となる。 

#### MLE法はモデルを検定し、信頼区間を計算する
最尤法を用いることで、平行線（単一のシグマ）が妥当であるか、また Arrhenius モデルが受け入れ可能であるかを検定することができる。
3つの例示データセルに対する[尤度比検定](../section2/apr233.md)の結果、単一のシグマおよび Arrhenius モデルが適切であることを示した。
さらに、MLEの結果に基づいて、推定されたすべてのパラメータの信頼区間を算出することができる。
