# 8.4.4. 2つ以上の母集団の信頼性の比較方法

#### 集団間の信頼性を比較するためのいくつかの手法が説明されている 
故障データの標本に基づいて母集団間の信頼性を比較するとは、通常、その標本が、同じ信頼性関数（またはCDF）を持つ母集団から得られたものかを問うことを意味する。
すでに説明した3つの手法を用いて、打切り信頼性データについてこの問いに答える。
それらは以下である。

* [標本故障率の比較](apr44.md#Comparing%20Sample%20Proportion%20Fails)
* [尤度比検定による比較](apr44.md#Likelihood%20Ratio%20Test)
* [寿命回帰分析による比較](apr44.md#Lifetime%20Regression)

**標本故障率の比較** 

各標本が、それぞれ異なるロット、供給業者、あるいは生産工場から採取された無作為標本であると仮定する。
すべての標本は同じ条件下で試験する。
各標本について、試験における欠陥の観測比率が与えられている。
これらの標本欠陥比率を $`p_1, p_2, p_3, \ldots, p_n`$ とする。
これらはすべて、同等の母集団から得られたものとなり得るか。

これは7章で扱われている問題であり、[2つの母集団](../../ch7_prc/section3/prc33.md)および[2つ以上の母集団](../../ch7_prc/section4/prc46.md)の場合について説明し、そこで述べられている手法はここでも同様に適用できる。

**尤度比検定による比較** 

[尤度比検定](../section2/apr233.md)については前述した。
この応用例において、尤度比 $`\lambda`$ の分母には、各母集団が独自の母数の集合を持つと仮定した場合の、すべての標本における尤度の積が用いられる。
分子は、各母集団の母数が完全に同一であると仮定した場合の尤度の積である。
この検定では、$`-2\text{ ln } \lambda`$ が異常に大きいかを調べ、その場合は、母集団が同じ母数（または信頼性関数）を持つ可能性は低いとされる。

この手順は、使用している解析ソフトウェア・パッケージに組み込まれており、かつそのソフトウェアが解析者が関心を持つモデルや状況を網羅している場合に限り、非常に有効である。

**寿命回帰の比較** 

寿命回帰は、[最尤法](apr422.md)や[尤度比検定の手法](../section2/apr233.md)と類似している。
各標本は、同じ形状母数を持つ母集団から得られたものと仮定され、尺度母数（これはしばしばロット間または供給業者間の品質の「尺度」であると仮定される）に関する幅広い仮説を立て、その有意性を検定することができる。

複雑ではあるが現実的な例として、ある企業がメモリ・チップを製造しており、多くの用途において、いくつかの既知の欠陥を持つチップ（「部分的に良品」）を使用できるとする。
しかし、「部分的に良品」のチップの信頼性が「完全に良品」のチップと同等であるかという疑問がある。
この疑問に答えるための顧客からの信頼性データは豊富に存在する。
しかし、データには、信頼性に既知の差異がある複数の異なる製造ロットや、多くの異なる製造拠点で製造されたチップが含まれているため、分析が困難である。
部分良品と完全良品の差異に関する疑問は、どのように解決できるか。

寿命回帰モデルを構築するときに、ロット、製造拠点、「部分的に良品」か「完全に良品」か、およびその他の関連変数に基づいて尺度母数を変更する変数を組み込む。
そうすれば、優れた寿命回帰プログラムは、これらの要因のうちどれが有意であるか（もしあれば）、そして特に、「部分的に良品」と「すべて良品」の間に有意な差があるかどうかを見極めることができる。
