# 7.4.1. 未知分布の複数母集団の比較方法（Kruskal-Wallis 検定）

#### Kruskal と Wallisの方法による母集団の中央値の比較のためのノンパラメトリック検定
KW検定は、異なる母集団から抽出された可能性のある *k* 個の標本が、少なくともその中心傾向や中央値に関して、実際には類似した母集団に由来するという帰無仮説を検定する。
この検定では、検討対象の変数が連続分布に従うことを仮定している。

以下では、*k* 個の標本があり、*i* 番目の標本の標本規模が $`n_i, i=1, 2, \ldots, k`$ であると仮定する。

#### 組合せデータの順位に基づく検定
KW統計量の計算においては、各観測値は、*k* 個の標本すべてからなる順序付き組合せにおけるその順位に置き換えられる。
これは、*k* 個の標本から得られたデータを組み合わせ、単一系列として順位付けすることを意味する。
最小の観測値は順位1 に、次に小さい観測値は順位2 に、そして最大値の観測値は順位 *N* に置き換えられる。
ここで、*N* はすべての標本における観測値の総数である（*N*は $`n_i`$ の和である）。

#### 各標本に対する順位和の計算
次の手順として、各元の標本について順位和を計算する。
KW検定は、これらの順位和が標本ごとに著しく異なり、それらがすべて同じ母集団に由来する可能性が低いかを判断する。

#### カイ二乗分布に従う検定統計量
*k* 個の標本が同じ母集団から得られた場合、すなわち帰無仮説が真である場合、KW法で使用される検定統計量 *H* は、自由度 $`df= k-1`$ のカイ二乗統計量に近似的に従うことを示すことができるが、*k* 標本の標本規模があまり小さくないこと（例えば、すべての *i* について $`n_i > 4`$ であること）が条件である。
*H* は次のように定義される。

$$ H = \frac{12}{N(N+1)} \sum_{i=1}^k \frac{R_i^2}{n_i} - 3(N+1) , $$

ここで

* $`k`$  = 標本（群）の数
* $`n_i`$ = $`i`$番目の標本もしくは群の観測値の数
* $`N`$ = 観測値の総数（すべての $`n_i`$ の和）
* $`R_i`$ = 群 $`i`$ の順位和

**例**

#### 例の解説
以下のデータは、4社の投資会社を比較したものである。
各データは、推奨ファンドの 3か月間の成長率を示している。

| A | B | C | D |  
| :---: | :---: | :---: | :---: |  
| --- | --- | --- | --- |  
| 4.2 | 3.3 | 1.9 | 3.5 |  
| 4.6 | 2.4 | 2.4 | 3.1 |  
| 3.9 | 2.6 | 2.1 | 3.7 |  
| 4.0 | 3.8 | 2.7 | 4.1 |  
|  | 2.8 | 1.8 | 4.4 |  
| --- | --- | --- | --- |  
{: .no=border-table}

手順 1: それぞれの順位でデータを示す。

|  | A | B | C | D |  
| :---: | :---: | :---: | :---: | :---: |  
|  | --- | --- | --- | --- |  
|  | 17 | 10 | 2 | 11 |  
|  | 19 | 4.5 | 4.5 | 9 |  
|  | 14 | 6 | 3 | 12 |  
|  | 15 | 13 | 7 | 16 |  
|  |  | 8 | 1 | 18 |  
|  | --- | --- | --- | --- |  
| 合計 | 65 | 41.5 | 17.5 | 66 |  
|  | --- | --- | --- | --- |  
{: .no=border-table}

#### 検定統計量の計算
これに対応する *H* の検定統計量は

$$ H = \frac{12}{19(20)} \left[ \frac{65^2}{4} + \frac{41.5^2}{5} + \frac{17.5^2}{5} + \frac{66^2}{5} \right]- 3(20) = 13.678  . $$

1章の[カイ二乗分布表](../../ch1_eda/section3/eda3674.md)から、$`1 - \alpha = 0.95`$、$`df = k - 1 = 3`$ の臨界値は 7.812 である。
$` 13.678 > 7.812 `$ であるため、帰無仮説を棄却する。

なお、KW法における棄却領域は片側であることに注意されたい。
これは、*H* 統計量が大きすぎる場合にのみ帰無仮説を棄却するためである。
