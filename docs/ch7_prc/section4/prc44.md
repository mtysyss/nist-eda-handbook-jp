# 7.4.4. 分散成分とは何ですか？

#### 要因または変数のレベルが固定されているとは、実験におけるその要因のレベルが、
我々が関心を持つ唯一のレベルであることを意味する[前の例では](https://www.itl.nist.gov/div898/handbook/prc/section4/prc433.md#Example)、温度因子の水準は*固定*されているとみなされました。
つまり、関心のある温度は3つだけでした。
固定水準に用いるモデルは、*固定効果モデル*と呼ばれます。
前の例では、固定効果モデルの妥当性に疑問の余地があるかもしれませんが、1990年国際温度尺度（ITS-90）の固定点を対象とする研究においては、温度の影響を固定効果として扱うことは有意義であり、極めて適切であると言えます。
要因のレベルが無作為抽出によって選ばれた場合、例えば操作者、日、ロット、バッチなど、あるいはより一般的には、それ自体が特に注目されるものではなく、すべての可能な状態の代表と見なされる場合には、固定効果モデルが適している。
因子の水準が、オペレーター、日、ロット、バッチなどのように無作為抽出によって選択された場合、あるいはより一般的には、それ自体が特に注目されるものではなく、その因子が取り得るすべての水準の代表と見なされる場合、適切なモデルは[*無作為効果*](https://www.itl.nist.gov/div898/handbook/prc/section4/prc432.md#random effects)モデルである。
このような状況では、データから導き出される推論は、その要因が理論上取り得るすべてのレベルの集合全体に適用されることを意図している。 

#### 分散成分
無作為効果モデルを推定することは、多くの場合、さまざまな実験要因がデータの全体的な変動（その分散によって表される）に与える寄与の推定値を得る手段となる。
これらの寄与は、*分散成分*と呼ばれる。

#### 例のデータ
ある企業が、顧客に対して多数のロットの原材料を供給している。
顧客は、入荷した原材料の品質を管理するために、無作為に選定した5つのロットそれぞれについて、3回のサンプリング検査を行う。
このモデルは以下の通りである。

#### ANOVA表の解釈
*SS*を計算するための計算は、固定効果モデルと無作為効果モデルの両方で同じである。
ただし、無作為効果モデルの場合、バッチの平方和である147.73は、$`\{\sigma_\epsilon^2 + 3 \sigma_\tau^2\}`$の推定値となる。
これは、ANOVA表のEMS列に示されている。
バッチ効果がないという仮説、すなわち$`\sigma_\tau^2`$ = 0 を検定するために用いられる検定統計量は*F* = 36.933 / 1.800 = 20.52 である。
p値とは、$`\sigma_\tau^2`$ = 0 の場合に、サンプリングのばらつきのみによって、これほど大きい、あるいはそれ以上のF統計量が観測される確率である。
 p値が非常に小さいため、$`\sigma_\tau^2`$ > 0 であると結論づけ、したがって有意なバッチ効果が存在すると判断する。
この結論の妥当性は、以下のいくつかの仮定に基づいている：(i) $`\{\tau_{i}\}`$ は、平均 0、標準偏差 $`\sigma_\tau`$ を持つガウス分布からの標本である；(ii) $`\{\epsilon_{ij}\}`$ は、平均 0、標準偏差 $`\sigma_{\epsilon}`$ を持つガウス分布からの標本である； (ii)$`\{\epsilon_{ij}\}`$ は、平均 0、標準偏差 $`\sigma_{\epsilon}`$ を持つガウス分布からの標本であること；および (iii)$`\{\tau_{i}\}`$ と $`\{\epsilon_{ij}\}`$ は互いに独立している。
実験結果の分散のうち、どの程度がロット間の差異に起因し、どの程度が無作為誤差に起因するかを明らかにするには、*分散成分*である$`\sigma_{\tau}^{2}`$ および $`\sigma_{\epsilon}^{2}`$ を推定する必要がある。 

#### 分散成分のモーメント法による推定
$`\sigma_{\tau}^{2}`$ および$`\sigma_{\epsilon}^{2}`$の古典的な推定値は、モーメント法を用いて、期待平均二乗値と観測された平均二乗値を等しく設定し、$`\sigma_{\tau}^{2}`$と$`\sigma_{\epsilon}^{2}`$ に関する2つの連立方程式を解くことで計算される： $$\begin{aligned}\sigma_{\epsilon}^{2} + 3 \sigma_{\tau}^{2} &= 36.933 \\\sigma_{\epsilon}^{2} &= 1.800 .\end{aligned}$$ 解は $`\widehat{\sigma}_{\epsilon}^{2}`$ = 1.800 であり、$`\widehat{\sigma}_{\tau}^{2}`$ = (36.933 - 1.800)/3 = 11.71 である。
後者は、総分散の 11.71/(1.800 + 11.71) = 86.7 % を占め、一方、バッチ固有の誤差が占める割合はわずか 13.3 % である。
特に、$`\sigma_{\tau}^{2}`$が$`\sigma_{\epsilon}^{2}`$に比べて小さい場合、バッチの*平均二乗誤差*は誤差の*平均二乗*誤差よりも小さくなる可能性があることに注意が必要である。
このような状況では、モーメント法による$`\sigma_{\tau}^{2}`$ の推定値が負になる可能性があり、これは意味をなさない。
この理由と、推定値の性能に関連する理由から、他の推定法が望ましい場合があり、これについては次に説明する。 

#### 分散成分の制限付き最尤推定量
分散成分の制限付き最尤法（REML）による推定値は、一般に、モーメント法による推定値よりも好ましい。
[Searle (2006)](https://www.itl.nist.gov/div898/handbook/prc/section5/prc5.md#Searle)は、この問題について詳細に論じている。
付属の[Rコード](https://www.itl.nist.gov/div898/handbook/prc/section4/prc44.r)は、これらの推定値をどのように計算できるかを示している。
この場合、$`\sigma_{\tau}^{2}`$および$`\sigma_{\epsilon}^{2}`$のREML推定値は、モーメント法を用いて得られるものと一致する。
しかし、REML法では、分散成分の信頼区間も得られます。
 $`\sigma_{\tau}^{2}`$の95％信頼区間は、約1から34の範囲にあり、これはバッチ効果の有意性を裏付ける一方で、この分散成分の真の値については大きな不確実性があることも示している。
