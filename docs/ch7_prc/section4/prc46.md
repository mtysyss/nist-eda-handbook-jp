# 7.4.6. すべての工程で、不良品の割合は同じですか？

#### 分割表を用いたカイ二乗
分布による割合の均一性の検定$`n`$個の母集団（すなわち、ロット、ベンダー、生産ロットなど）からの標本がある場合、連関表の手法を用いて、これらの母集団の不良率に有意な差があるかどうかを検定することができます。
作成する交絡表は、2行 $`n`$列で構成される。
 $`n`$つの母集団間の不良率に差がないという帰無仮説を検定するには$` \text{H}_0: \,\,\, p_1 = p_2 = \cdots = p_n `$に対し、$`n`$個の母集団の割合がすべて等しくないという対立仮説$` \text{H}_a: \,\,\, \text{すべての } p_i \text{ が等しいわけではない } (i = 1, \, 2, \, \ldots, \, n) \, , `$ 

#### カイ二乗検定の検定統計量
以下の検定統計量を用いる：$$ \chi^2 = \sum_{\text{すべてのセル}} \frac{(f_o - f_c)^2}{f_c} \, , $$ここで、$`f_o`$は $`2 \times n`$の交絡表の特定のセルにおける観測頻度であり、$`f_c`$は、帰無仮説が真である場合に、その特定のセルにおける理論的計数または期待頻度である。

#### 臨界値
臨界値は、所定の有意水準において、自由度 $`(2-1)(n-1) = n-1`$ の $`\chi^2`$分布表から求める。

#### 例のデータ
プリント基板に使用されるダイオードは、4000個単位のロットで製造されている。

#### 不適合ユニットの全体的な割合の算出
帰無仮説が真であると仮定すると、すべてのサンプルの結果を統合することで、不適合ダイオードの単一の全体割合を次のように推定できる。
$$ \bar{p} = \frac{36 + 46 + 42 + 63 + 38}{5(300)} = \frac{225}{1500} = 0.15 \, . $$
#### 基準を満たす住戸の全体的な割合の算出
規格に適合する（「良品」）ダイオードの割合は、1 - 0.15 = 0.85 として推定する。

#### 結論
有意水準を0.05とすると、自由度4の$`\chi^2`$の臨界値は9.488となる（第1章の[カイ二乗分布表](../section3/eda3674.md)を参照）。
検定統計量(12.131) はこの臨界値を超えているため、帰無仮説を棄却する。
