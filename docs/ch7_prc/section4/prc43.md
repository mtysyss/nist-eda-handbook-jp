# 7.4.3. 平均値は等しいか

#### 平均値の等しさの検定
<u>分散分析</u>（*ANOVA*）と知られる手法は、複数の母集団が存在する場合に、平均値に関する仮説を検定するために用いられる。

***分散分析（ANOVA）**

#### 最も強力な統計的技法 ANOVA手順
ANOVAは、標本抽出された母集団が正規分布に従うという仮定の下で、2つ以上の群間の平均が等しいという仮説を検定するために用いられる一般的な技法である。

そこで、すぐにいくつかの疑問が浮かぶ。
平均<u>とは</u>、そして、<u>平均</u>に関する結論を導き出すために、なぜ**分散**を分析する必要があるか。

このテーマをさらに掘り下げていく中で、これらの疑問の両方に対する答えが明らかになっていきます。 

#### 分散分析（ANOVA）入門
まず、抵抗器などの受動素子に対する温度の影響について調べてみる。
3つの異なる温度を選び、抵抗器に及ぼす影響を観察する。
この実験は、3つの異なるオーブンにそれぞれ *n* 個の抵抗器を入れる前に、対象となるすべての抵抗器の値を測定し実施する。

各オーブンを所定の温度まで加熱する。
その後、例えば 24時間後に抵抗値を再度測定し、温度にさらされる前後の差である応答を分析する。
この温度は<u>因子</u>と呼ばれる。
異なる温度設定は<u>水準</u>と呼ばれます。
この例では、温度因子に対して3つの水準、すなわち設定がある。 

#### 因子とは
**因子とは、その設定（値）が実験者によって制御・変化させられる独立した処理変数である**。
**因子の強度の設定を水準という**。

* **水準は定量的な数値である場合もあれば、多くの場合、単に「存在する」もしくは「存在しない」（「0」または「1」）*である**。

#### 一元配置分散分析
上記の実験では、温度という1つの要因しか存在せず、温度の影響を分析するために用いる分散分析は、<u>一元配置</u>や<u>一因子</u> ANOCAと呼ばれます。

#### 二元もしくは三元分散分析（ANOVA）
オーブン内の位置による影響についても調査することを選択できたかもしれない。
その場合、温度とオーブン内の位置という2つの要因があることになる。
ここでは、<u>二元</u>または<u>2因子</u>ANOVAと呼ぶ。
さらに、3つ目の要因である時間の影響についても関心があるかもしれない。
この場合、<u>三元</u>または <u>3因子</u>ANOVAを扱う。
これらANOVA手法のいずれにおいても、（要因が変化した場合の）平均値（または平均応答値）の等しさに関する様々な仮説を検定する。

#### ANOVAで検証可能な仮説
まず、一元配置分散分析（ANOVA）について考えてみる。
帰無仮説は、因子 *A*（唯一の因子）の各水準における母平均に差がない、である。

対立仮説は、平均値が等しくない、である。

二元分散分析（ANOVA）の場合、考えられる帰無仮説は以下となる。

1. 因子 *A* の平均値に差はない。
2. 因子 *B* の平均値に差がない。
3. 因子 *A* と *B* の間に交互作用がない条件1 および 2における対立仮説は、平均値は等しくない、である。

条件3 における対立仮説は、因子 *A* と *B* の間に交互作用が存在するというものである。

3因子分散分析において、主効果は要因 *A*、*B*、および *C* であり、2要因間の交互作用は *AB*、*AC*、および *BC* である。
また、3因子間の交互作用 *ABC* も存在する。

7つの条件のいずれにおいても、帰無仮説は同じであり、平均値に差はない、となる。
対立仮説は、平均値が等しくない、である。 

#### *n*元要因分散分析
一般に、主効果および交互作用の数は、次の式によって求める。

$$ N = \left( \begin{array}{c} n \\ 0 \end{array} \right) +\left( \begin{array}{c} n \\ 1 \end{array} \right) +\left( \begin{array}{c} n \\ 2 \end{array} \right) + \ldots +\left( \begin{array}{c} n \\ n \end{array} \right) \, . $$

最初の項は全体平均を表し、常に 1である。
2番目の項は主効果の数を表し、3番目の項は 2因子間交互作用数を表し、以下同様である。
最後の項は *n* 因子間交互作用を表し、常に1である。
