# 7.4.3.2. 一元配置ANOVAモデルと仮定

#### 応答と処置間の関係（従属変数と独立変数間の関係）を記述するモデル
一元配置分散分析における応答と処理の関係を記述する数学的モデルは、次式で与えられる。

$$ Y_{ij} = \mu + \tau_i + \epsilon_{ij} $$

ここで、$`Y_{ij}`$ は *j* 番目の観測値（$`j = 1, 2, \ldots, n_i`$）が *i* 番目の処理（$`i = 1, 2, \ldots, k`$ 水準）に割り当てられた観測値を表す。
したがって、$`Y_{23}`$ は、因子の水準2 での 3番目の観測値を表す。
*μ* は実験全体における共通効果、$`\tau_i`$ は*i* 番目の処理効果、そして $`\epsilon_{ij}`$ は*i* 番目の処理における *j* 番目の観測値に含まれる偶然誤差を表す。

#### 固定効果モデル
誤差 $`\epsilon_{ij}`$ は、平均が 0、分散が $`\sigma_\epsilon^2`$ である正規分布に従い、互いに独立（NID）であると仮定される。
*μ* は常に固定母数であり、$`\tau_1, \tau_2, \ldots, \tau_k`$ は、<u>処置水準が固定され</u>、、可能なレベルの母集団からの無作為抽出ではない場合に、固定母数と見做される。
また、*μ* は以下の条件

$$ \sum \tau_i = 0 ,\quad i = 1, \ldots, k $$

が成り立つように選ばれると仮定する。
これが<u>固定効果モデル</u>である。

#### 無作為効果モデル
*k* 水準の処置が無作為に選択された場合でも、モデル式は変わらない。
ただし、この $`\tau_i`$ の値が NID(0, $`\sigma_\tau`$)に従うと仮定される確率変数である。
これが<u>無作為効果モデル</u>である。

水準が固定か無作為かは、ある実験においてそれら水準がどの様に選択されるかに依存する。
