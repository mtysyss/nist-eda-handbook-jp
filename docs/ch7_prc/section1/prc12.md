# 7.1.2. 一般的な仮定の設定

#### 検定の妥当性
本章で説明する検定の妥当性は、以下の仮定に依存する。

1. データは、単一の統計的分布で表すことのできる単一工程から得られている。
2. 分布は正規分布である。
3. データは時間的に相関がない。

#### ![](https://www.itl.nist.gov/div898/handbook/eda/gif100/histogra.gif)

単正規分布の仮定を確認する簡単な方法は、データの[ヒストグラム](../../ch1_eda/section3/eda33e.md)を作成することである。

#### 説明
この章で解説する検定は、正規性の仮定に基づいており、検定を適用する前に、正規性からのデータの逸脱を確認する必要がある。
しかし、これらの検定は正規性からのわずかな逸脱に対しては頑健であり、すなわち、データが釣鐘型分布を示し、裾部が重くない限り、かなり良好に機能する。
[正規性の仮定を検証するための定量的手法](../section2/prc21.md)については次の節で論じる。

#### ![](https://www.itl.nist.gov/div898/handbook/eda/gif100/normprpl.gif)
正規性の過程を検定する他のグラフを用いた方法は、[正規確率プロット](../../ch1_eda/section3/eda33l.md)である。

#### ![](https://www.itl.nist.gov/div898/handbook/eda/gif100/lagplot.gif)
測定間の相関の検定に関するグラフ手法は、[時間遅延プロット](../../ch1_eda/section3/eda33f.md)である。
測定値が時間に対して適切に構造化されているならば、相関に問題はない。測定値が時間的に近い時点で行われる場合にしばしば発生する。
