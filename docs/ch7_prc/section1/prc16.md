# 7.1.6. データにおける外れ値とは

#### 外れ値の定義
<u>外れ値</u>とは、母集団から無作為に抽出した標本において、他の値から異常なほど離れた位置にある観測値のことである。
ある意味で、この定義では、何が「異常」と見なされるかを決定するのは、分析者（あるいは合意形成の工程）に委ねられている。
異常な観測値を特定するには、まず正常な観測値の特徴を明らかにしておく必要がある。

#### データを表現する方法
データ集合の特徴を把握するには、次の2つの活動が不可欠である。

1. グラフ化されたデータの全体的な形状を検証し、対称性や仮定からの逸脱など、重要な特徴を確認する。
[探索的データ分析（EDA）](../../ch1_eda/section3/eda3.md)の章では、仮定やデータの要約について詳しく解説している。

2. データの大部分から大きく外れた、異常な観測値の有無をデータから確認する。
こうした点は、しばしば外れ値と呼ばれる。
外れ値を特定するための2つのグラフ手法、すなわち[散布図](../../ch1_eda/section3/eda33qa.md)と[箱ひげ図](../../ch1_eda/section3/eda337.md)、および分布が正規分布である場合に外れ値を検出するための解析的手法（[Grubbs 検定](../../ch1_eda/section3/eda35h.md)）についても、EDAの章で詳細に解説されている。

#### 箱ひげ図の作成
箱ひげ図は、分布の中央部だけでなく両端部のデータの傾向を説明するのに役立つグラフである。
箱ひげ図では、[中央値](../../ch1_eda/section3/eda351.md)と下四分位数および上四分位数（それぞれ25と75[百分位数](../section2/prc252.md)と定義される）が用いられる。
下四分位数をQ1、上四分位数をQ3とすると、その差（Q3 - Q1）は四分位範囲（IQ）と呼ばれる。

#### 柵付き箱ひげ図
箱ひげ図は、上四分位数と下四分位数の間に箱を描き、その箱を横切る実線で中央値を位置づけ作成する。
分布の両端にある極端な値を特定するには、以下の量（<u>柵（fence）</u>と呼ばれる）が必要である。

1. 下側内柵：Q1 - 1.5×IQ
2. 下側内柵：Q1 - 1.5×IQ
3. 下側外柵：Q1 - 3\*IQ
4. 上側外柵：Q3 + 3\*IQ

#### 外れ値の検出基準
内側の柵両側を越えた点は、**軽度の外れ値**と見做す。
外側の柵を越えた点は、**極端な外れ値**と見做す。

#### 外れ値の箱ひげ図の例
以下に示すように、*N* = 90 の順序付き観測値からなるデータ集合について、外れ値の有無を調査する。

```
30, 171, 184, 201, 212, 250, 265, 270, 272, 289, 305, 306, 322, 322, 
336, 346, 351, 370, 390, 404, 409, 411, 436, 437, 439, 441, 444, 448, 
451, 453, 470, 480, 482, 487, 494, 495, 499, 503, 514, 521, 522, 527, 
548, 550, 559, 560, 570, 572, 574, 578, 585, 592, 592, 607, 616, 618, 
621, 629, 637, 638, 640, 656, 668, 707, 709, 719, 737, 739, 752, 758, 
766, 792, 792, 794, 802, 818, 830, 832, 843, 858, 860, 869, 918, 925, 
953, 991, 1000, 1005, 1068, 1441 
```

上記のデータは[テキストファイル](https://www.itl.nist.gov/div898/handbook/datasets/COMPARE-7_1_6.DAT)として入手可能である。

計算方法は以下の通り。

* 中央値 = (n+1)/2 最大値 = 45番目と46番目の順序付きデータの平均  = (559 + 560)/2 = 559.5
* [下四分位数](../section2/prc242.md) = 0.25(N+1)番目のデータ点 = 22.75番目のデータ点 = 411 + 0.75(436-411) = 429.75
* [第3四分位数](../section2/prc242.md) = 0.75(N+1)番目のデータ点 = 68.25番目のデータ点 = 739 + 0.25(752 - 739) = 742.25
* 四分位範囲 = 742.25 - 429.75 = 312.5
* 下側内柵 = 429.75 - 1.5 (312.5) = -39.0
* 上側内柵 = 742.25 + 1.5 (312.5) = 1211.0
* 下限外柵 = 429.75 - 3.0 (312.5) = -507.75
* 上部外柵 = 742.25 + 3.0 (312.5) = 1679.75 

柵位置とデータを検討した結果、1点（1441）が上側内柵を超え、軽度の外れ値として目立っているが、極端な外れ値は見当たらない。

#### 重要な情報が含まれている外れ値
外れ値は慎重に調査すべきである。
多くの場合、それらは調査対象の工程や、データの収集、記録工程に関する貴重な情報を含んでいる。
データからこれらの値を削除することを検討する前に、なぜそれらが現れたのか、また同様の値が今後も現れ続ける可能性が高いかどうかを理解するよう努めるべきである。
もちろん、外れ値は多くの場合、不良データ点である。
