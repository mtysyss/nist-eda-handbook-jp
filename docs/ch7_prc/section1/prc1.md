# 7.1. はじめに

#### 本節の目的
この節の主な目的は、工程および工程間の比較に関する意思決定に有用な統計検定や信頼区間を理解するための基礎を築くことである。
取り上げる内容は以下の通り。

* [適用範囲](prc11.md)
* [仮定](prc12.md)
* [仮説検定の概要](prc13.md)
* [信頼区間の概要](prc14.md)
* [仮説検定と信頼区間の関係](prc15.md)
* [外れ値の検出](prc16.md)
* [データや工程における連続的傾向の検出](prc17.md)

#### 仮説検定と信頼区間
この章では、データから行える比較の種類について検討し、仮説検定、信頼区間、およびそれぞれの解釈について解説する。
