# 7.1.7. 連続した工程データや製品データにおける傾向とは

#### 点に適合させた傾きが明らかにゼロではない傾きの直線を把握し、データ点のプロットによるトレンドの検出
もし傾向がなかった場合に一連の数値がどのような様相を呈するかと、予想される値とを比較することに相当する。
もし、次の観測値が上昇する確率と下降する確率が等しいというモデルから著しい逸脱が見られる場合、「傾向がない」という仮説を棄却することになる。

傾向を調べる一般的な方法として、データに直線を当てはめ、その直線の方向（または傾き）を観察する。
もし直線が水平に見える場合は、傾向の証拠はないが、そうでない場合は傾向があることになる。
形式的には、直線の傾きがゼロと有意に異なるかどうかを検定する。
この方法論については、[4章](../ch4_pmd/pmd.md)で解説している。
