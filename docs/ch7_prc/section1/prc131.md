# 7.1.3.1. 臨界値と *p* 値

#### 臨界値の決定
仮説検定における臨界値は、検定の種類に固有の検定統計量と、検定の感度を定義する有意水準 *α* に依存する。
$`\alpha = 0.05`$ という値は、帰無仮説が実際には真である場合に、5％の確率で棄却されることを意味する。
*α* の選択はある程度恣意的であるが、実際には 0.1、0.05、および 0.01といった値が一般的に用いられる。
臨界値は本質的に、検定統計量が含まれる可能性が低い領域を定義する閾値であり、例えば、帰無仮説が真である場合に、確率 *α* で臨界値を超える領域を指す。
検定統計量がこの領域（しばしば「棄却領域」と呼ばれる）内にある場合、帰無仮説は棄却される。
特定の仮説検定における[臨界値](../../ch1_eda/section3/eda367.md)は、1章の表にまとめられている。

#### 本章の内容
この章では、検定統計量の計算式を示し、平均、標準偏差、および不良率に関する仮説検定に適した臨界値表を紹介する。

#### *p* 値
仮説検定の結果を報告するためのもう一つの定量的指標が、*p* 値である。
*p* 値とは、帰無仮説が真であると仮定した場合に、検定統計量が観測された値と同程度かそれ以上に極端な値をとる確率のことである。
*p* 値が小さいことは、帰無仮説が偽であることを示唆している。

#### 良い慣行  
検定を行う前に、検定を棄却するためにどの程度の小さな *p/ 値が必要かをあらかじめ決めておくのが良い慣行である。
これはまさに、検定の有意水準 *α* を選択することと類似している。
例えば、検定統計量が（$`\alpha = 0.05`$ における）臨界値を超える場合に帰無仮説を棄却するか、あるいは同様に、*p* 値が 0.05より小さい場合に帰無仮説を棄却するかを決定する。
一部の統計ソフトウェア・パッケージは、臨界値ではなく *p* 値を出力するため、これら2つの概念の関係を理解することが重要である。
