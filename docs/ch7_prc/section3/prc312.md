# 7.3.1.2. 平均値の差に対する信頼区間

#### 母平均の差に対する信頼区間の定義
2つの母集団から2つの無作為標本、

$$ Y_1, \ldots, Y_N \quad \text{ および } \quad Z_1, \ldots, Z_N $$ 

が与えられたとき、未知の母平均 $`\mu_1`$ と $`\mu_2`$ の差に対する $`100(1-\alpha)`$ %の網羅率である両側信頼区間を以下の表に示す。
[対応のある観測値](prc311.md)および[対応のない観測値](prc31.md#unpaired)に関する関連する統計量は、別の箇所に示している。

$`\mu_1 - \mu_2`$ **に対する** $`100(1-\alpha)`$ % **網羅率を持つ両側信頼区間** 

**対応のある観測値**

| | |  
| :----: | :-----: |  
| $` \mu_1 - \mu_2 \,\,\, (\text{ここで } \sigma_1 = \sigma_2) `$ | $` \bar{d} \pm t_{1-\alpha/2, \, N-1} \frac{s_{d}}{\sqrt{N}} `$ |  
 

**対応のない観測値**

| | |  
| :----: | :-----: |  
| $` \mu_1 - \mu_2 \,\,\, (\text{ここで } \sigma_1 = \sigma_2) `$ | $` \bar{Y} - \bar{Z} \pm t_{1-\alpha/2, \, N_1 + N_2 - 2} \,\,s \sqrt{\frac{1}{N_1} + \frac{1}{N_2}} `$ |  
| $` \mu_1 - \mu_2 \,\,\, (\text{ここで } \sigma_1 \ne \sigma_2) `$ | $` \bar{Y} - \bar{Z} \pm t_{1-\alpha/2, \, N_1 + N_2 - 2} \,\sqrt{\frac{s_{1}^{2}}{N_1} + \frac{s_{2}^{2}}{N_2}} `$ |  


#### 信頼区間の解釈
平均の信頼区間に関する解釈の一つとして、信頼区間にゼロが含まれている場合、2つの母平均は等価である。
