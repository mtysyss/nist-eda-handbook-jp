# 7.3. 2工程からのデータに基づく比較

#### 本節の概要
多くの製造環境では、2つ以上の工程が同じ作業を行うか、類似した製品を生成することが一般的である。
以下のページでは、2工程における最も一般的で有用な事例のいくつかを取り上げた検定について説明する。

1. [2工程は同じ平均か](prc31.md)  
    1. [標準偏差が等しい場合の検定](prc31.md)
    2. [標準偏差が等しくない場合の検定](prc31.md)
    3. [対になったデータの検定](prc311.md)
2. [2工程は同じ標準偏差か](prc32.md)
3. [2工程は同じ割合の不良品を生産しているか](prc33.md)
4. [観測値が故障時間であるとき、故障率（または平均故障までの時間）は同じか](prc34.md)
5. [任意の2工程は同じ中心傾向を持っているか](prc35.md)

#### 同時並行工程の例
例えば、自動車製造工場では、同じ部品を生産する組立ラインが複数存在することがある。
何らかの理由で 1ラインが停止した場合でも、部品は引き続き製造でき、生産は停止しない。
例えば、部品が特定モデル車用のピストンリングである場合、いずれかのラインで製造されたリングは、指定された仕様に適合すべきである。

2工程が実際に類似したリングを生成していることをどのように確認すればよいか。
つまり、2工程が類似しているかをどのように判断するか。

#### 2つの工程が類似しているかを判断する目的
この疑問に答えるため、各工程ごとにピストンリングに関するデータを収集する。
例えば、ある特定の日に、各工程から 10個のピストンリングの直径に関するデータを 1時間に渡り測定する。

2工程が類似しているかを判断するために、以下の問いに答えることが重要である。

1. 2つの工程で生産されるピストンリングの直径は同じか。
2. 2つの工程で生産されるピストンリングの直径のばらつきは類似しているか。 

#### 標準偏差が不明
2番目の問いでは、いずれの工程の標準偏差が未知であると仮定しており、したがってデータから推定しなければならない。
これは通常であり、本節の検定では母集団の標準偏差が未知であることを前提としている。

#### 正規分布の仮定
これら2つの問いに答えるために用いられる統計的手法（すなわち、具体的にどの検定を用いるか）は、測定値の基礎となる分布によって異なる。
本節で取り上げる検定は、データが正規分布に従うことを前提としている。
