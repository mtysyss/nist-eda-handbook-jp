# 7.2.6.1. 母集団の値の大部分を含む近似区間

#### 経験的区間
経験則として、著しい偏りや集積の兆候が見られない場合、観測値3つのうち2つ（67％）は、平均値から 1標準偏差以内の範囲に収まり、観測値の 90％から 95％は平均値から 2標準偏差以内の範囲に、99％から 100％は 3標準偏差以内の範囲に収まる。
このルールは、データ内の外れ値を特定するのに役立つ。

#### 任意分布に適用される区間
**Bienayme-Chebyshev** の法則によれば、データの分布に拘らず、平均値から *k* 標準偏差以内の範囲に含まれる観測値の割合は、少なくとも $`100(1-1/k^2)`$ % となる。

#### 正規分布の正確な区間
Bienayme-Chebyshev の法則は、あらゆる分布に適用できるため、保守的な推定法である。
<u>正規</u>分布の場合、以下の表に示す通り、平均値から *k* 標準偏差の範囲内に含まれる観測値の割合はより高くなる。

**平均値と *k* 標準偏差の間に含まれる観測値の割合**
