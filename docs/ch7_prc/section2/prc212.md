# 7.2.1.2. Kolmogorov-Smirnov 検定

#### カイ二乗検定に代わる優れた手法 K-S検定
Kolmogorov-Smirnov（K-S）検定は、もともと1930年代に、[Kolmogorov（1933）](../section5/prc5.md) および [Smirnov（1936）](../section5/prc5.md)の論文で提唱された。
連続分布と離散分布の両方に対する検定に使用できる[カイ二乗検定](prc211.md)とは異なり、K-S 検定は、正規分布や Weibull 分布などの連続分布に対するデータの検定にのみ適している。
これは、[経験累積分布関数（ECDF）](../../ch1_eda/section3/eda35g.md)に基づく数ある検定の一つである。

#### K-S法
K-S 検定の統計量 *D* の構築と解釈に関する詳細、およびいくつかの分布に関する例については、[1章](../../ch1_eda/section3/eda35g.md)で概説している。

#### 検定統計量に関連する確率を計算するのは困難
検定統計量 *D* に関連する臨界値は、標本規模が有限の場合、計算は困難であり、多くの場合、モンテカルロ法によるシミュレーションが必要である。
しかし、一部の汎用統計ソフトウェアでは、少なくとも一般的な分布について、Kolmogorov-Smirov 検定が実装されている。
表形式の値は[Birnbaum (1952)](../section5/prc5.md#Birnbaum,%20Z.%20W.%20%281952%29.%20%20Numericaltabulation%20of)に掲載されている。
分布の母数が、検定対象となっているのと同じデータを用いて推定される場合には、補正係数を適用することができる。
詳細については、[D'Agostino and Stephens (1986)](../section5/prc5.md)を参照のこと。
