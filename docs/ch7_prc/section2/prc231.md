# 7.2.3.1. 信頼区間法

#### 標準偏差の信頼区間
真の標準偏差の信頼区間は、カイ二乗分布を用いて構築する。
[前ページの帰無仮説検定](prc23.md)に対応する $` 100(1-\alpha) \text{%} `$ 信頼区間は以下で与えられる。

1. *α* の両側信頼区間
<br><br>
$$\frac{s\sqrt{N-1}}{\sqrt{ \chi^2_{1-\alpha/2, N-1}  }} \le \sigma \le \frac{s\sqrt{N-1}}{\sqrt{ \chi^2_{\alpha/2, N-1}  }}  ,$$
<br><br>
2. *α* の下側信頼区間
<br><br>
$$\sigma \ge \frac{s\sqrt{N-1}}{\sqrt{ \chi^2_{1-\alpha, N-1}  }} ,$$
<br><br>
3. *α* の上側信頼区間
<br><br>
$$0 \le \sigma \le \frac{s\sqrt{N-1}}{\sqrt{ \chi^2_{\alpha, N-1}  }} \, .$$

条件（1）の場合、$`\chi^2_{\alpha/2, N-1}`$ は自由度$` N-1 `$ のカイ二乗分布の $` \alpha /2 `$ 臨界値であり、条件（2）および（3）も同様である。臨界値は、1章 [カイ二乗表](../ch1_eda/section3/eda3674.md)に掲載している。

### 結論を変化させるリスク水準 *α* の選択
信頼区間（1）は、標準偏差の両面検定に一致する。つまり、仮説や公称値 $` \sigma_0 `$ がこれら限界内にない場合、公称値に等しい標準偏差の仮説は棄却される。

#### 仮説検定におけるジレンマ
*α* の変更は、異なる結論を導く。
これはジレンマである。
では、*α* の設定はどうすべきか。
残念ながら、あらゆる状況で通用する明確な答えはない。
一般的な戦略は、*α* を小さく設定し、帰無仮説が<u>誤って</u>棄却される条件をごく少数に抑えるようにすることである。
帰無仮説が偽であるにもかかわらず、それを棄却できないリスク、すなわち *β* は、不一致の大きさに依存するほか、*α* にも依存する。
次のページでの議論では、特定の不一致に対してこのリスクを小さく保つための[標本規模の選択](prc232.md)方法を示す。
