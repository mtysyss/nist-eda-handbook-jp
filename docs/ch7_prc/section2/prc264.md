# 7.2.6.4. 最大値および最小値に基づく許容区間

#### どのような形状の分布であっても、信頼区間を構築可能
前ページで紹介した許容限界の計算方法は、測定値が正規分布に従うという仮定に基づいている。
もし分布が正規分布でない場合、この仮定に基づいた許容範囲は、母集団の意図した割合 *p* を網羅することができない。
ただし、分布形状が不明であっても意図した網羅率を達成するための手法があるが、これらの手法では、許容範囲が大幅に広くなる可能性がある。

#### 分布に関する仮定を立てることに伴うリスク
分布の正確な形状について根拠のない仮定を立てることは、特に危険な状況がある。
例えば、航空機のフロントガラス用のガラスの強度を試験する場合などがある。
この場合、母集団の非常に大きな割合が許容範囲内に収まることが不可欠である。

#### 最大値および最小値に基づく信頼区間
未知分布に対する両側信頼区間として、$`Y_1, \ldots, Y_N`$ の測定値からなる標本における最小値と最大値の間の区間が、明らかな選択肢の一つである。
標本規模 *N* および信頼度 *p* が与えられたとき、Hahn と Meeker（p. 91）の式、[HahnとMeeker（p. 91）](../section5/prc5.md#Hahn)に示された式

$$ \alpha = 1 - Np^{N-1} + (N-1)p^{N} , $$

を用いることで、許容区間の信頼度 *α* を計算することができる。
例えば、$`N= 25`$ の場合、0.5から 0.9999までの範囲で選択された信頼度に対応する信頼水準を以下に示す。

```
  Confidence Coverage       
       1.000   0.5000       
       0.993   0.7500       
       0.729   0.9000       
       0.358   0.9500       
       0.129   0.9750       
       0.026   0.9900       
       0.007   0.9950         
         0.0   0.9990         
         0.0   0.9995         
         0.0   0.9999
```

なお、99%の信頼度が要求される場合、標本データ集合全体を網羅する区間であっても、母集団値のわずか 75%しか網羅できないことが保証される。 

#### 最適な標本規模はどの程度か
もう1つ興味深い問題は、「許容区間に母集団の少なくとも割合 *p* が含まれることを確率 *α* で保証するためには、標本規模はどの程度必要か」というものである。

#### *N* の近似
必要な標本規模については、以下の式がかなり良い近似である。

$$ N \cong \frac{1}{4} \frac{(1+p)}{(1-p)} \, \chi^2_{\alpha, \, 4} +\frac{1}{2} , $$

ここで、$` \chi_{\alpha, 4}^2 `$ は、自由度4のカイ二乗分布の臨界値であり、確率 *α* でこれを超える値である。

#### *p* が標本規模に及ぼす影響の例
最小値と最大値の観測値の間の区間が、確率 $` \alpha = 0.95 `$ で母集団の *p* の割合を確実に網羅するためには、何回の測定を行う必要があるかを求めるとする。
[カイ二乗分布の上側臨界値](../../ch1_eda/section3/eda3674.md) の表から、自由度4の行にある「0.95」とラベル付けされた列を参照する。
その値は $` \chi_{0.95, 4}^2 = 9.488 `$ であり、*p* が 0.90および 0.99の場合の計算を以下に示す。 

$`p = 0.90`$、$`\alpha = 0.95`$ の場合、

$$ N \cong \frac{1}{4} \frac{(1+0.90)}{(1-0.90)} \chi^2_{0.95, 4} + \frac{1}{2} = 0.25(19)(9.488)+0.5 = 45.57 = 46 \, . $$

$`p = 0.99 `$、$`\alpha = 0.95`$ の場合、

$$ N \cong \frac{1}{4} \frac{(1+0.99)}{(1-0.99)}  \chi^2_{0.95, 4} +\frac{1}{2} = 0.25(199)(9.488)+0.5 = 472.5 = 473 . $$

これらの計算から、許容区間が母集団の非常に大きな割合う網羅することを要求すると、許容できないほど大きな標本規模が必要になる可能性があることが示されている。
