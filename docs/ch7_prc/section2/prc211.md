# 7.2.1.1. カイ二乗適合度検定

#### 「適合度」検定における群数の選択は重要だが、有用な経験則に限定
この検定では、まずデータを群分けする必要がある。
各群の実際観測値数を期待される観測値数と比較し、この差に基づいて検定統計量を計算する。
群数や、群への割付の定義方法は、検定の検出力（すなわち、帰無仮説からの逸脱を検出する感度）に影響を与える。
検出力は、群の数やその定義だけでなく、標本規模や、帰無分布および基礎となる（真の）分布の形状にも影響を受ける。
明確な「最良の方法」は存在しないが、いくつかの有用な経験則を挙げる。

#### 群への割付
データが離散的な場合、群への割付は明確である。
データの分類には、集計やクロス集計を用いる。
一方、連続データの場合はより難しい課題である。
群は、取り得る値の範囲を互いに重ならない区間に分割することで定義する。
これにより、区間の端点で群への割付を定義する。
一般に、検出力は、群への割付確率が等しくなるように端点を選択することで最大化される（すなわち、観測値が特定の群に属する確率が、各区間に可能な限り均等に分配されるようにする）。
多くの市販ソフトウェア・パッケージがこの手順に従っている。

#### 群数の目安
経験則の一つとして、群数の決定にあたっては、値 $`2 n^{2/5}`$ を良い出発点として用いることが挙げられる。
また、もう一つのよく知られた経験則では、各群に少なくとも5つのデータ点を含めることが求められている。
