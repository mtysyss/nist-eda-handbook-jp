# 7.2. 1工程からのデータに基づく比較

単一工程については、その工程の現在の状態を公称状態や仮説上の状態と比較する。

#### 検定の一般的な形式
これらの問いは仮説検定または信頼区間を用いて検討する。

#### パラメトリック検定対ノンパラメトリック検定
すべての仮説検定の手法は、大まかに分けてパラメトリック検定とノンパラメトリック（分布に基ない）検定のいずれかに分類される。
パラメトリック検定とは、以下の条件を満たすものである。

1. 特定の母数（例えば「母集団の平均＝50g」など）に関する仮説検定を伴うもの。

2. 基礎となる標本分布について、一連の厳格な仮定を必要とする。 

#### 非パラメトリック手法を用いる場合
非パラメトリック手法や分布に依存しない手法が必要となるのはどのような場合か。
以下に、その候補となり得るいくつかの状況を挙げる。

1. 測定値が質的型のみである場合、すなわち、名目尺度または順序尺度（順位）である場合。

2. パラメトリック手法の使用に前提となる仮定が満たされない場合。

3. その状況において、特定の母集団母数の具体的な値に関する仮説の検定ではなく、無作為性、独立性、対称性、あるいは適合度のような特徴の調査が必要とされる場合。 

#### ノンパラメトリックと分布非依存の違い
一部の著者は、非パラメトリック手法と分布に依存しない手法を区別している。

**分布フリーの検定手法は、**大まかに次のように定義される。

1. 検定統計量が、標本データが抽出された母集団分布の形状に依存しないもの。

2. データが名目尺度または順序尺度で表されているもの。

**非パラメトリック検定手法**とは、分布の母数を考慮しないものを指す。 

#### ノンパラメトリック手法の利点
分布非依存法、すなわちノンパラメトリック法には、いくつかの利点、あるいは便益がある。

1. これらは、あらゆる種類のデータ――名目尺度であるか、順位尺度と呼ばれる順位形式のデータであるか、あるいは間隔尺度や比率尺度のデータであるかを問わず――に適用可能である。

2. 標本規模が小さい場合でも適用しやすい。

3. パラメトリックな手法に比べ、仮定の数が少なく、その厳格度も低い。

4. 具体的な手法にもよるが、対応するパラメトリック手法の仮定が満たされている場合には、それらと<u>ほぼ</u>同等の検出力を持ち、仮定が満たされていない場合には、一般的により高い検出力を示する。 

#### ノンパラメトリック手法の欠点
もちろん、欠点もある。

1. パラメトリック手法の仮定が満たされるのであれば、一般的にそれらを使用する方が効率的である。

2. 標本規模が大きい場合、コンピュータ・ソフトウェアが利用できない限り、データの処理はより手間がかかる傾向がある。

3. 多くの場合、検定統計量には特別な臨界値表が必要であるが、これらの値は必ずしもコンピュータ・ソフトウェアで出力できるとは限らない。
一方、パラメトリック検定の臨界値は容易に入手可能であり、一般的にコンピュータ・プログラムへの組み込みも容易である。
