# 7.2.6. データの一定の割合を含む区間とは

#### 中央値や平均値の周辺に集中する傾向がある観測値
実証研究によれば、どのような研究においても、観測値の多くが中央値付近に集中するのが一般的であることが示されている。
右偏りのデータでは、この集中は中央値の左側（すなわち下側）に生じ、左偏りのデータでは、観測値は中央値の右側（すなわち上側）に集中する傾向がある。
中央値と平均値が等しい対称的なデータでは、観測値はこれらの中央傾向の尺度を中心に均等に分布する傾向がある。
