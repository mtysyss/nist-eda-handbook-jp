# 5.5.4. 混合計画とは

#### 混合計画を使用する調合割合の要因
混合実験において、独立因子は配合物を構成する各成分の割合である。
例えば、ステンレス鋼の引張強度を最適化したい場合、注目すべき因子は、合金中の鉄、銅、ニッケル、クロムの割合である。
各因子の割合の合計が 100％でなければならないという事実が、混合実験の計画および解析を複雑にしている。

#### 標準混合計画と制約付き混合計画
混合物の各成分の和が 1 でなければならないという制約が課される場合、標準モデルに適合させるための標準的な混合計画として、<u>単体格子</u>計画や<u>単体中心計画</u>など、標準モデルに適合させるための標準的な混合計画がある。
混合成分に、各成分の最大値および／または最小値といった追加の制約が課される場合、標準的な混合計画以外の制約付き混合計画または<u>極頂点計画</U>と呼ばれる計画が適切である。

#### 相対的割合のみに依存すると仮定される測定応答
混合物実験では、測定される応答は、混合物成分の相対的割合のみに依存し、混合物量には依存しないと仮定される。
混合物の量を実験における追加の要因として検討することも可能であるが、その場合は、混合物変数と工程変数が一緒に扱われる例となる。

#### 各変数の割合の合計は1
混合実験と独立変数実験の主な違いは、前者の場合、入力変数もしくは構成要素が混合物の非負の割合であり、混合物に対する割合として表す場合、それらの合計が 1にならなければならないという点である。
もし何らかの理由で、成分割合の合計が 1未満となる場合、変数としての割合を、合計が 1になるように正規化された割合として書き換える。

#### 混合計画の目的
混合問題において、実験の目的は、調合曲面を何らかの数学方程式でモデル化し、以下のことを可能にする。

1. 任意の混合物や原料の組合せに対する応答を経験的に予測
2. 各成分が単独、あるいは他成分と組み合わされ、応答に及ぼす影響指標の取得

#### 混合実験における仮定
要因実験において通常行われる仮定は、混合実験においても同様に適用される。
特に、誤差は独立かつ同一分布であり、平均がゼロで共通の分散を持つと仮定される。
もう一つの仮定は、要因計画と同様に、真の応答曲面が調査対象領域において連続的である。

#### 混合実験の計画手順
混合実験の計画には、通常、以下の手順が含まれる（Cornell and Piepel, 1994）。

1. 実験の目的を定義する。
2. 混合物成分および調査対象の他の要因を選択する。
他要因には、工程変数や混合物の総量などが含まれる。
3. 実験領域を特定するために、混合物成分や他要因に関する制約を特定する。
4. 測定する応答変数を特定する。
5. 応答データを混合物成分および実験のために選択された他要因の関数としてモデル化するための、適切なモデルを提案する。
6. 提案されたモデルに適合するだけでなく、モデルの妥当性を検証することも可能な実験計画法を選択する。
