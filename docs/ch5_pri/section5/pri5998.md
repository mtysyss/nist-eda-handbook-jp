# 5.5.9.9.8. 動機：データの範囲を超えたモデルの活用方法

#### 内挿と外挿
前の節では、計画に含まれる各点での予測値を計算する方法について説明した。
モデル化の利点の一つは、その結果として得られる予測式が、計画データ点に限定**されない**ことである。
予測式から、以下の条件であれば、どこでも、どのような点でも予測値を計算することができる。

1. データの定義域内（補間）
2. データの領域外（外挿）

熟練した科学者、技術者、解析担当者に拠る、他の地点での予測能力は極めて貴重である。
適合モデルに基づき、応答の予測値を内部および外部の多数の点について計算することが可能である。
したがって、分析者は手元にあるわずかな要因の組合せに留まらず、（通常はその後の[等高線図](pri59a.md)を通じて）応答曲面全体の性質がどのようなものであるか、感覚をつかむことができる。

応答の性質に関するこの追加される洞察は「無料で」得られるものであり、モデル構築作業全体における極めて重要な利点である。 

#### 予測は慎重に
このような数学的、計算的な演習によって、私たちはだまされたり、誤った方向に導かれたりしてしまうか。
結局のところ、「現実」なのはデータだけであり、それ以外はすべて人工的なものではないか。
答えは「はい」であり、したがって、このような補間・外挿は、慎重に扱わなければならない両刃の剣である。
特に外挿に関しては、導出された結論を極めて慎重に捉えることが最善の姿勢である。

その性質上、推奨される適合モデルは計画点において良好であるべきである。
完全なモデルが使用されれば、適合は完璧になるだろう。
完全なモデルをほんの少し簡略化したとしても、適合は通常、依然として良好である。
連続性の観点からすれば、計画点における完璧さ／適合性の良さは、計画点のすぐ近傍においても適合性が良好であることを期待できるだろう。
しかし、そのような局所的な適合性の良さは、導出されたモデルが計画点からある程度の距離を置いた場所でも良好であることを保証するもので**はない**。 

#### 確認実行の実施
モデル化と予測により、データ以上のさらなる洞察を得ることができるが、これらは細心の注意を払って行わなければならない。
一般に、内挿は外挿よりも安全だが、いずれの場合も、予測の誤り、誤差、および誤解が生じる可能性がある。

分析者は、モデル構築過程を確実に実行し、他の場面で予測能力を活用すべきだが、常に追加の実証データを集めることで、補間および外挿による予測を検証する準備を整えておく必要がある。
私たちが推奨する一般的な経験的モデルは、特定の測定問題を取り巻く工学、物理学、化学について「何も」知らない。
このモデルは利用可能な中で最良の汎用モデルではあるが、それでもなお、追加データによって検証が必要である。
このような追加データは、実験前または実験後に取得する。
実験前に実施する場合、適合モデルの妥当性を確認するための推奨手順として、通常の 2<sup>*k*</sup> または 2<sup>*k*-*p*</sup> 計画に、設計中心に追加測定点を加える。
これについては[次の節](pri5999.md)で説明する。 

#### 連続因子にのみ適用
もちろん、補間や外挿に関するこうした議論はすべて、温度、時間、圧力、規模などの連続的な順序因子という文脈においてのみ意味をなすものである。
一方、供給業者、作業者、計画の種類などの離散的で順序を持たない因子については、補間や外挿は意味をなさない。
