# 5.5.2.1. D-最適計画

#### [古典的計画が適用できない](pri51.md)場合にしばしば用いられるD-最適計画
D-最適計画法は、コンピュータ・アルゴリズムによって生成される計画法の一種である。
この種のコンピュータ支援計画法は、古典的計画法が適用できない場合に特に有用である。

要因計画法や一部実施要因計画といった標準的な古典的計画法とは異なり、D-最適計画法の計画行列は通常、直交しておらず、効果の推定値には相関がある。

この種の計画法は、実験者が適合させたいモデルの種類（例えば、1次、1次にいくつかの交互作用を加えたもの、完全2次、3次など）や、実験に指定された目的（例えば、スクリーニング、応答曲面など）にかかわらず、常に選択肢の一つである。
D-最適計画は、選択された最適基準と適合させるモデルに基づいた単純な最適化である。
D-最適計画の生成に使用される最適基準は、情報行列 X'X の行列式である |X'X| を最大化するものである。

この最適基準により、あらかじめ指定されたモデルにおける母数推定値の一般化分散が最小化される。
その結果、所与のD-最適計画の「最適性」はモデルに依存する。
つまり、コンピュータが具体的な処理組合せを生成するには、実験者が計画に用いるモデルを事前に指定しなければならない。
実験の処理実行総数と指定されたモデルが与えられると、コンピュータ・アルゴリズムは、可能な計画処理実行の<u>候補集合</u>から、最適計画実行集合を選択する。
この処理実行候補集合は、通常、実験で使用したいさまざまな因子水準すべての可能な組合せから構成される。

言い換えれば、候補集合とは、D-最適アルゴリズムが計画に含める処理組合せを選択するための集合である。
コンピュータ・アルゴリズムは一般的に、段階法と交換法を用いて、処理実行集合を選択する。

 **注**：コンピュータが生成する計画が実際にD-最適であるという保証はない。 

#### 資源が限られている場合、因子設定に制約がある場合に有用なD-最適計画
標準的な古典的計画法ではなく、D-最適計画法を用いる理由は、一般的に以下の2区分に分類される。

1. 標準的な因子計画法や一部実施要因計画では、実験に割り当てられた資源や時間の範囲内で実施するには実行数が多過ぎる。
2. 計画空間に制約がある（工程空間には、実行不可能、あるいは実施不可能な因子設定が含まれている）。

#### 例
ある工業工程に3つの計画変数（*k*= 3）があると仮定し、技術的判断により、以下のモデルが当該工程の適切な表現として指定されているとする。

$$Y = \beta_{0} + \beta_{1} X_{1} + \beta_{2} X_{2} + \beta_{3} X_{3} +\beta_{11} X_{1}^{2} + \epsilon$$

研究者が検討している水準（コード化）は以下の通りである。

| |  
| :--- |  
| *X*<sub>1</sub>：5水準（-1, -0.5, 0, 0.5, 1） |  
| *X*<sub>2</sub>：2水準（-1, 1） |  
| *X*<sub>2</sub>：2水準（-1, 1） |
{: .no-thead-table}

資源制約により、収集できるデータ点は *n* = 12 個のみである。 

#### 候補集合の作成
実験仕様を踏まえると、計画を生成する上での最初の手順は点候補集合を作成することである。
この候補集合は、計画の対象となる各点（実行）ごとに1行が設けられたデータ表であり、多くの場合、完全実施要因計画である。
本問題における候補集合は、すべての要因について完全実施要因計画であり、5×2×2＝20 通りの計画実行を含む。

#### D-最適計画の生成
D-最適計画法は、D-効率を最大化するものであり、これは母数推定値の一般化分散に関する体積基準である。
標準的な一部実施要因計画の D-効率は 100％であるが、$$X_1^2$$ のような純粋な2次項がモデルに含まれる場合、100％の D-効率を達成することはできない。

D-効率の値は、計画における測定点の数、モデルに含まれる独立変数の数、および計画点における予測の最大標準誤差の関数である。
最適計画では D-効率が最も高い。
報告されている他の効率指標（A、G、Iなど）は、さまざまなモデルから D-効率類似を生成する、最適計画を選択するのに役立つ。

#### ソフトウェアに関する注意事項
ソフトウェア・パッケージによって、D-最適計画を生成する手順が異なることがあり、使用するソフトウェア・パッケージに依存して最終計画が異なることがある。
