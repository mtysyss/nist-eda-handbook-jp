# 5.5.9.7.4. パターン有意性

#### L型パターンを探す
|効果|のプロットは、水平方向に伸びたL字型の特徴的なパターンを示す。
Lの垂直な部分は重因子子で構成されている。
水平な部分は重要でない因子で構成されている。
因子が重要であれば、棒の高さは高くなり、それに続く棒の高さは低くなる（おそらく 50％程度）――そのような因子がL字の左側の腕を構成する。
一方、因子が重要でない場合、その棒の高さは低くなる傾向がありゼロに近い傾向がある。
こうした因子がLの底辺を構成する。
注目すべきは、Lのどこに折れ曲りがあるかという点である。
その折れ曲りの左側にある因子は重要であると看做し、折れ曲り位置およびその右側にある因子は重要ではないと看做す。

#### 因子標示
この「折れ曲がり」の影響として、プロットの右端ラベルに注目する。
折れ曲り点より左側および上側にある因子は、右端ラベルが明確に表示され、他のラベルと区別されやすい傾向がある。
一方、折れ曲り点上、右側、および下側にある因子は、右端ラベルが他のラベルと重なり、判読しづらい傾向がある。
したがって、（大まかな）経験則として、右端のラベルが区別しやすい因子や交互作用を重要であると看做し、右端ラベルが上書きされて区別しにくい因子や交互作用を重要ではないと看做す。
