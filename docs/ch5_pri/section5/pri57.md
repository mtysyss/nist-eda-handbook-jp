# 5.5.7. Johnの3/4 一部実施要因計画とは

#### 完全 2<sup>n</sup> 要因の 3/4実行数である Johnの計画
3/4計画とは、「元の」計画に必要な実験数の4分の3だけで済む 2水準要因計画であものである。
例えば、2<sup>4</sup> 一部実施要因計画に求められる 16実行をすべて行う代わりに、12実行すればよい。
このような計画は、テキサス大学の Peter John 教授によって考案されたもので、「Johnの3/4計画」と呼ばれこともある。

3/4一部実施要因計画は、異なる2つの状況において資源を節約するために利用できる。
1つ目のシナリオでは、一部実施要因計画を完了した後に追加実験を行い、特定の交互作用パターンの解像度を高めたい場合が挙げられる。
2つ目は、最初から3/4計画を採用し、通常計画に必要な実験数の 25％を削減したい場合である。 

**半折り返しの例**

#### 4つの実験要因
調査対象の実験要因が4つ、具体的には*X*<sub>1</sub>、*X*<sub>2</sub>、*X*<sub>3</sub>、および*X*<sub>4</sub>あり 2<sup>4-1</sup> 一部実施要因計画を設定し、実験を実施した。
この計画では、中心点実行（もしくは反復）を除くと、8実行の行がある。

#### 分解能 Ⅳ 計画
分解能IV の 2<sup>4-1</sup>の計画は、主効果が最悪の場合でも3因子交互作用と交絡し、2因子交互作用が他の2因子交互作用と交絡することを意味する。

#### 2因子交互作用の交絡
また、12=34、13=24、14=23である点にも留意する。
これらは、生成関係 4=123 から導かれるもので、他の2因子別名とは無関係な2因子交互作用を推定することはできないことを示している。

#### 交絡の無い2因子交互作用の推定
因子 *X*<sub>1</sub> が関与する2因子交互作用の一部またはすべてを推定することに関心を持ったとする。
つまり、2因子交絡の影響を受けない交互作用12、13、14のうち1つ以上を推定したい。

これを行う一つの方法は、計画の「残り半分」、関係 4 = -123 に基づいて形成された追加8行を実行することである。
これら2つの「半分」、つまり元の半分と新しい半分を組み合わせ、16実行の 2<sup>4</sup> 計画を得る。
これらの実行の8回はすでに完了しているため、あとは残り半分を実行するだけで済む。 

#### 別のより少ない実行の方法
しかし、実行数をわずか 4回だけ増やして、目的の結果を得る方法がある。
これらの実行は次の方法で選択される。
表5.8 のうち、「*X*<sub>1</sub>」列に「-1」が含まれる 4行を取り出し、*X*<sub>1</sub>の「-」記号を「+」に置き換えることで、表5.9 の 4行の表を得る。
これは、*X*<sub>1</sub> の折り返しと呼ばれ、*X*<sub>1</sub>= -1 実行の部分集合を選択している。
なお、この4実行の選択は一意ではなく、もし当初の計画において *X*<sub>1</sub> = -1 が望ましい水準であると示唆されていたならば、当初の計画から除外されていた他の 4処理の組合せについて実験を行うことを選択する。

#### 分解能V 計画
2因子交互作用の列を調べ、どれ一つとして同じものがないことをご自身で確認する。
これは、*X*<sub>1</sub>を含む2因子交互作用が、他のどの2因子交互作用とも別名になっていないことを意味する。
したがって、この計画法は分解能V となりますが、この種の 3/4折り返し計画を構築するときには、必ずしもそうするとは限らない。

#### *X*<sub>1</sub> 2因子交互作用の推定
現時点で 12実行の計画であるが、これを用い *X*<sub>1</sub> を含むすべての 2因子交互作用について、他のいかなる 2因子交互作用とも別名関係が生じることなく推定を行う。
これは、次の通常の要因計画（2<sup>4</sup>）の行数の 3/4であることから、3/4計画と呼ばれる。

#### 効果推定値の標準誤差
切片、ブロック効果、4主効果、および6二因子交互作用を含むモデルを推定する場合、計画は直交していないため、各推定値は他の2つの推定値と相関しており、各係数の標準誤差は *σ*/12<sup>1/2</sup> ではなく *σ*/8<sup>1/2</sup> となる。
なお、*σ* を推定するための自由度はない。
その代わりに、正規（または半正規）効果プロットを用いて 10効果推定値をプロットし、どの効果を有意とみなすべきかを判断すべきである。

#### 詳細情報
元計画の半分規模の追加計画で得られる 3/4 要因に関する詳細については、[Mee and Peralta (2000)](../section8/pri8.md#Mee,%20R.%20W.,%20and)を参照のこと。

**48実行 3/4計画の例**

#### 8つの要因について、すべての主効果および2要因間の交互作用を推定する
*k*=8 因子について実験を行い、すべての主効果と2因子交互作用を推定したいとする。
[一部実施要因計画の要約表](../section3/pri3347.md)に記載されている $` 2_V^{8-2} `$ 計画を用いることも可能だが、この場合、1 + 8 + 28 = 37の目的の係数を推定するために 64実行が必要である。
このような状況、特により高い分解能V 計画において、計画点の 3/4で概ね十分である。

#### 48実行計画の構築
48実行計画は次のように構築する。
まず、生成元 7 = 1234 および 8 = 1256 を用いて完全な $` 2_{V}^{8-2} `$ 計画を作成する。
定義関係は I = 12347 = 12568 = 345678 である（この計画の[詳細](https://www.itl.nist.gov/div898/handbook/pri/section3/eqns/2to8m2.txt)については要約表を参照のこと）。

次に、これら 64処理組合せを、16個 4ブロックに配置し、交互作用 135 および 246 に基づいてブロック分けを行う（すなわち、ブロック1 には 135 = 246 = -1 の実行があり、ブロック2 には 135 = -1、246 = +1、ブロック3 には135 = +1、246 = -1、ブロック4 には 135 = 246 = +1 がある）。
135 = 246 = -1 となる最初のブロックを除外すると、以下に示す求めていた 3/4 計画が得られる（これらが要約表に記載されている実行結果であり、番号 1、6、11、16、18、21、28、31、35、40、41、46、52、55、58、61番の実行を除いたものが、これらが要約表に記載されている実行であることが読者自身で確認できる）。

#### 係数推定値の高い精度
この計画は、誤差に対して11自由度を確保するとともに、係数推定においても良好な精度を実現している（係数によっては標準誤差が $` \sigma/\sqrt{32} `$であるものもあれば、$` \sigma/\sqrt{42.55} `$ であるものもある）。
