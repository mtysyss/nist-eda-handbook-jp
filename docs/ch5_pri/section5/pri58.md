# 5.5.8. 小規模複合計画とは

#### 分解能Ⅲ計画に星型点を追加し、分解能V応答曲面計画と比較し、実行数削減可能な小規模複合計画
応答曲面計画法（RSD）は、[前述](../section3/pri336.md)している。
一般的なRSDは、2要因の場合は約13実行、3要因の場合は20実行、4要因の場合は31実行、5要因の場合は32実行が必要である。
RSDに含めたい因子が4つ以上では、基本計画で 1ロット（すなわちバッチ）以上の実験単位が必要になることは明らかである。
これは、現在のほとんどの統計ソフトウェアが提示する内容である。
しかし、1959年12月に『Biometrics』に掲載された H.O. Hartley の論文『2次応答曲面のための最小複合計画法（*Smallest Composite Designs for Quadratic Response Surfaces*）』で提案されているように、実行数を削減する方法がある。

この手法は、RSDを作成するための最小要因計画として分解能V 計画の使用は不要であるという理論に基づいている。
この手法では、分解能Ⅲ 計画に星型点を追加し、その星型点を用いて 2因子交互作用による別名の主効果を除去する。
その結果得られる計画では、高次交互作用の推定が可能となる。
ただし、交互作用係数の推定精度は低く、因子の系統的効果に比べて誤差変動が無視できる場合を除き、この方法を使用すべきではない。 

#### 4もしくは5要因時に有用
これは、4または5要因を含む計画があり、1ロット（すなわちバッチ）実験単位のみを使用したい場合に特に有用である。

**小規模複合計画での *α* の決定**

#### 要因部分の処理組合数に基づいて計算される *α*
通常の CCD において回転性を維持するに *α* 値は、中心複合計画の因数分解部分における処理組合数によって決定する。

$` \alpha = \left[ \text{要因実行数} \right] ^{1/4} `$

#### 非回転性小規模複合計画
ただし、小規模複合計画では、*α* 値にかかわらず、回転を行うことはできない。
小規模複合計画での *α* は [因子実行回数]<sup>1/4</sup> より小さくなく、かつ *k*<sup>1/2</sup> より大きくてもいけない。
