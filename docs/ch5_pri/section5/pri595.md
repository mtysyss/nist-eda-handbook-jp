# 5.5.9.5. ブロック・プロット

#### 目的
ブロック・プロットは、以下の2つの一般的な問いに答える。

1. 重要な要因（交互作用を含む）は何か。
2. これらの重要因子に対して最適設定は何か。

基本的な（単一の）ブロック・プロットは、ある因子が重要であるかを判断し、その重要性が系内の他の因子すべてのあらゆる設定において無条件（頑健）であるかを確かめるための多因子 EDA技法の一つである。
実験計画法の文脈において、ブロック・プロットは実際に、*k* 要因それぞれについて1つずつの一連の *k* 種のブロック・プロットである。

ブロック・プロットには、他の因子すべての設定すべてにおいて、ある因子が重要であるかを判断することができるため、ブロック・プロットは DOE頑健性プロットとも呼ばれます。 

#### 出力
ブロック・プロットは、以下に関する具体的な情報を提供する。

1. 重要因子（*k* 要因および $` \left( \begin{array}{c} k \\ 2 \end{array} \right) `$ 2因子交互作用）
2. 重要因子の最適設定

#### 定義
ブロック・プロットは、*k* 基本ブロック・プロットからなる一連のもので、各基本ブロック・プロットは主効果に対応している。
各基本ブロック・プロットは、その特定要因が重要かという問いを投げかける。

1. 1番目のブロック・プロットは、次の問いを投げかける：「因子 *X*<sub>1</sub> は重要か。
2. 2番目のブロック・プロットは、次の問いを投げかける：「因子 *X*<sub>2</sub> は重要か。
3. 残りの因子についても続ける。

因子 *i* を対象とし、因子  *X*<sub>*i*</sub>  が重要かどうかを問う *i* 番目の基本ブロック・プロットは以下で構成する。

* 縦軸：応答 
* 横軸：(*k*-1)個の非対象因子（すなわち「頑健性」因子）のすべての 2<sup>k-1</sup> 通りの組合せ
例えば、2<sup>3</sup> 完全実施要因実験において因子 *X*<sub>1</sub> に焦点を当てたブロック・プロットの場合、横軸は因子 *X*<sub>2</sub> および *X*<sub>3</sub> のすべての 2<sup>3-1</sup> = 4 通りの異なる組合せで構成される。
この頑健性因子軸を作成するのは、 *X*<sub>1</sub> が頑健性に重要であるかを判断することに興味があるからである。
つまり、 *X*<sub>1</sub> が一般的・総括的な意味でのみ重要でだけでなく、*X*<sub>1</sub> の重要性が因子 *X*<sub>2</sub> と *X*<sub>3</sub> の 2<sup>3-1</sup> = 4 組合せのそれぞれにおいて、普遍的かつ一貫して成立するかを知りたいのである。
これら組合せ4つは、(*X*<sub>2</sub> ,  *X*<sub>3</sub> ) = (+, +)、(+, -)、(-, +)、および (-, -) である。
横軸上の頑健性因子は、ブロック・プロットごとに変化する。
例えば、*k* = 3 の因子の場合： 
    1.  *X*<sub>1</sub> を対象とするブロック・プロットには、 *X*<sub>2</sub> および *X*<sub>3</sub> が頑健性因子として含まれる。
    2.  *X*<sub>2</sub> を対象とするブロック・プロットには、頑健性因子として *X*<sub>1</sub> と *X*<sub>3</sub> が含まれる。
    3.  *X*<sub>3</sub> を対象とするブロック・プロットには、頑健性因子として *X*<sub>1</sub> と* *X*<sub>2</sub> が含まれる。

* プロット特性：目標因子 *X*<sub>*i*</sub>  の設定（- または +）。
ブロック・プロットの各点には、目標因子 *X*<sub>*i*</sub>  に対する設定が関連付けられている。
*X*<sub>*i*</sub>  = "-" の場合、対応するプロット上の点は "-" となり、 *X*<sub>*i*</sub>  = "+" の場合、対応するプロット上の点は "+" となる。

頑健性因子設定の特定組合せ（横軸）に対して、その上（縦軸）には2点をプロットする。

1. *X*<sub>*i*</sub>  = "-" に対応するプロット点を1つ
2. *X*<sub>*i*</sub>  = "+" に対応するもう1つのプロット点

ブロック・プロットでは、これら2つのプロット点がボックス（ブロック）で囲まれ、外部のブロック間の差異による注意の散漫を避け、ブロック内の差異に視線を集中させるようにしている。
ブロック内の差異は、目標因子の重要性を反映している（意図通り）。
ブロック間の外部的差異は、さまざまな頑健性因子の重要性を反映しているが、これは主たる関心事ではない。

ブロック内差異が大きい（すなわち、ブロックの高さが高い）場合は、応答に対する局所的な影響が大きいことを示し、特定のブロックにおいてすべての頑健性因子が固定されていることから、対象因子にのみ起因すると考えられる。
これにより、「重要」対象因子が特定される。
ブロック内での差異が小さい（つまり、ブロックが小さい）場合は、対象因子 *X*<sub>*i*</sub> が重要ではないことを示している。

したがって、あるブロック・プロットについて、具体的に関心のある問いは以下になる。

対象因子 *X*<sub>*i*</sub>  は重要か。
すなわち、ブロック内で対象因子の設定を「-」から「+」へと変化させたとき応答変数の値は大きく変化するか。

ブロックの高さは、対象因子の設定変更による応答への「局所的」（すなわち、その特定の頑健性因子設定の組合せにおける）効果を反映している。
 *X*<sub>*i*</sub> の目標因子効果に対する「局所的」な推定値は、実際には、目標因子 *X*<sub>*i*</sub> の「+」設定時と「-」設定時における応答の差と同一である。
したがって、頑健性プロットの各ブロックの高さは、目標因子効果の局所的な推定値である。

要約すると、重要な因子には以下の両方を示す。

1. 一貫した高いブロック高さ
2. 一貫した「＋／－」符号の配列

ここで、「一貫性」とは、頑健性因子のすべての設定に渡る。
重要度の低い因子は、これら2つの性質のうち1つだけを持つ。
重要でない因子は、どちらの性質も持たない。

#### 解釈の方法
ブロック・プロットから以下の点を確認する。

1. 重要因子（2因子交互作用を含む）
2. これらの因子に対する最適設定

これらについて順に検討していく。

**重要因子（2因子交互作用を含む）：**

*k* ブロック・プロットをそれぞれ確認する。

特定のブロック・プロット内において、

プロット内の頑健性因子設定を順に確認していき、対応するブロックの高さが一貫して大きくなっているか――はい／いいえ、また、ブロック内の符号パターン（＋が－より上、または－が＋より上）は、すべての頑健性因子の設定において一貫しているか――はい／いいえ、相互比較を容易にするため、すべてのブロック・プロットは同じ縦軸尺度にする。

これらのブロック・プロット全体において、

1. どのプロットが、一貫して最大のブロック高さを示し、かつブロック内の「＋」と「－」の配置も一貫しているか。
これが「最重要因子」を定義する。
2. 次に一貫してブロックの高さが大きく、かつブロック内の「＋」と「－」の配置も一貫しているプロットはどれか。
これが「2番目の重要因子」を定義する。
3. 残りの因子についても続ける。

*k* ブロック・プロットをこのように精査・比較することで、最重要因子を容易に特定できる。
この特定方法は、これまでの手順に比べて、頑健性という利点もある。
特定の重要因子について、頑健性因子の設定にかかわらず、ブロックの高さと符号の配置に一貫性が見られることは、その因子の頑健な重要性をさらに裏付ける。
その因子は、頑健性因子設定がどうであれ、重要である（応答の変化が大きくなる）と言える。
このような情報を得ることは、重要であると同時に心強いものである。

**重要な特例：大きいが一貫性がない場合：**

ブロック高さが大きいが一貫性がない場合はどうなるか。
例えば、2<sup>3</sup> 要因実験を分析しているとき、因子 *X*<sub>1</sub> に焦点を当てたブロック・プロットを因子 *X*<sub>1</sub> が重要かという一般的問いに答えるために検討・解釈しているとする。

このようなブロック・プロットがどのように見えるかについて、少し詳しく検討する。
この *X*<sub>1</sub> のブロック・プロットでは、横軸上に、頑健性因子 *X*<sub>2</sub> および *X*<sub>3</sub> の2<sup>3-1</sup> = 4 組合せが、以下の順序で配置される。

(*X*<sub>2</sub>, *X*<sub>3</sub> ) = (+, +); (*X*<sub>2</sub>, *X*<sub>3</sub>) = (+, -);(*X*<sub>2</sub>, *X*<sub>3</sub>) = (-, +); (*X*<sub>2</sub>, *X*<sub>3</sub>) = (-, -)

*X*<sub>2</sub> および *X*<sub>3</sub> の 4つの設定組合せ全体において、各ブロックで「+」が「-」よりも上にあるなど、ブロックの高さが一貫して大きい場合、

| (*X*<sub>2</sub>, *X*<sub>3</sub>) | ブロックの高さ（＝局所的な *X*<sub>1</sub> の影響） |  
| :---: | :---: |  
| (+, +) | 30 |  
| (+, -) | 29 |  
| (-, +) | 29 |  
| (-, -) | 31 |  
{: .grid-table}

二項分布の考察から、2<sup>4-1</sup> = 1/8 $`\approx`$ 12.5% の確率で、4つの局所的な *X*<sub>1</sub> 効果が同じ符号（すなわち、すべて正またはすべて負）を持つことになる。
通常の統計的有意水準である 5% には達していないが、この 12.5%という値は示唆的である。
さらに、4つの *X*<sub>1</sub> 効果の一貫性（すべて 30 付近）は、他の 2つの因子設定を超えて *X* 効果が堅牢であることを示す証拠である。
要約すると、上記は以下のことを示唆する。

1. 因子1 はおそらく重要である（どの程度の大きさの効果であれば重要と見なされるかという問題については、後節でより詳細に議論する）。
2. 推定された因子1 の効果は約30単位である。

一方、因子1 の4つのブロック高さが次の周期的なパターンで変化するとする。 

| (*X*<sub>2</sub>, *X*<sub>3</sub>) | ブロック高さ（＝局所的な *X*<sub>1</sub> の効果） |  
| (+, +) | 30 |  
| (+, -) | 20 |  
| (-, +) | 30 |  
| (-, -) | 20 |  
{: .grid-table}

これはどのように解釈すればよいか。

ここでの解釈の鍵は、ブロック・プロットが推定された *X*<sub>1</sub> 効果は実際には少なくとも 20単位あるが、一貫性**がない**ことを示している点である。
その効果は変化しているが、構造的なパターンに従って変化している。
「コツ」は、*X*<sub>2</sub> と *X*<sub>3</sub> の設定を精査し、その部分構造がどのようなものかを推測することである。
上記表から、推定された *X*<sub>1</sub> 効果は 30 であり、

* 点1（*X*<sub>2</sub>, *X*<sub>3</sub> ）＝（+, +）
* 点3（*X*<sub>2</sub>, *X*<sub>3</sub> ）＝（-, +）

の場合であり、次に推定 *X*<sub>1</sub> 効果は 10単位減少し 20であり、

* 点2（*X*<sub>2</sub>, *X*<sub>3</sub>）＝（+, -）
* 点4（*X*<sub>2</sub>, *X*<sub>3</sub>）＝（-, -）

したがって、*X*<sub>1</sub> の推定効果は

1. *X*<sub>3</sub>  = "+"のときは 30
2. *X*<sub>3</sub>  = "-"のときは 20

因子 *X*<sub>1</sub> の効果が一貫せず、実際には因子 *X*<sub>3</sub> 設定に応じて変化する場合、定義上、それは「*X*<sub>1</sub> \* *X*<sub>3</sub>  の交互作用」と呼ばれる。
まさにそれが今回の状況であり、結論は次になる。

1. 因子 *X*<sub>1</sub> はおそらく重要である。
2. 推定された因子 *X*<sub>1</sub> 効果は 25（30、20、30、20の平均値）である。
3. *X*<sub>1</sub> \* *X*<sub>3</sub> の交互作用はおそらく重要である。
4. 推定された *X*<sub>1</sub> \* *X*<sub>3</sub> 交互作用は約10である（*X*<sub>3</sub> が変化したときの因子 *X*<sub>1</sub> の効果の変化量 = 30 - 20 = 10）。
5. したがって、*X*<sub>1</sub> \* *X*<sub>3</sub> の交互作用は *X*<sub>1</sub> の効果ほど重要ではない。

なお、ここでは「重要」という用語を定性的な意味で用いていることに留意されたい。
統計的または工学的有意性という観点からの重要性のより正確な判定については後節で論じる。

ブロック・プロットは、こうした結論を導き出し、理解するための構造と詳細情報を提供する。
これは、これまでの分析手順を補完する貴重な手段である。

**最適設定：**

重要因子を特定した後、これら因子の最適設定の決定も有用である。
通常通り、最適設定は主効果についてのみ決定する（主効果のみが技術者が制御できるため）。
交互作用の最適設定は、技術者がそれらを直接制御する手段を持たないため行われない。

ブロック・プロットの文脈では、この最適因子設定の決定は、各ブロック内でどの因子設定（＋または－）が、技術者が最終的に達成しようとしている値に最も近いかを確認するだけで行う。
欠陥ばねの事例では、応答変数が「合格率（％）」であることから、明らかに応答を最大化すること（最小化や目標値達成とは対照的に）を目指しており、理想的な最適点は 100％である。
これを踏まえて、特定の重要因子のブロック・プロットを調べ、各ブロック内でどの因子設定（＋または－）が 100％に最も近いデータ値を与えるかを確認し、その設定をその要因の最適設定として選択する。

欠陥ばねのブロック・プロットから、以下に結論づけられる。

1. 因子1 の最適設定は「＋」
2. 因子2 の最適設定は「-」
3. 因子3 の最適設定は容易には判断できない。 

#### 欠陥ばねに関するデータの結論
要約すると、欠陥ばねのデータ集合にブロック・プロットを適用した結果、以下の結論が導き出される。

1. 重要因子順位付けなしの一覧（交互作用を含む）： 
    * *X*<sub>1</sub> は重要である。
    * *X*<sub>2</sub> は重要である。
    * *X*<sub>1</sub>\* *X*<sub>3</sub> は重要である。
2. 最適な設定： 
(*X*<sub>1</sub>, *X*<sub>2</sub>, *X*<sub>3</sub>) = (+, -, ?) = (+1, -1, ?)
