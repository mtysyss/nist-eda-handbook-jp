# 5.5.9.10.1. 解釈方法：軸

#### 2軸配置される因子
この最初の項目では、実験において最も重要な2つの因子をプロットの軸として選択する。

これらは、前の手順で議論した、重要度の低い順に並べられた因子一覧から決定される。
特に、[|効果|プロット](pri597.md)には、重要度の低い順に並べられた因子表が含まれている。
欠陥ばねデータの場合、その重要度の低い順に並べられた一覧は以下の通りである。

| 因子／交互作用 | 効果推定値 |   
| :---: | :---: |  
| *X*<sub>1</sub> | 23 |  
| *X*<sub>1</sub>\* *X*<sub>3</sub> | 10 |  
| *X*<sub>2</sub> | -5 |  
| *X*<sub>3</sub> | 1.5 |  
| *X*<sub>1</sub>\* *X*<sub>2</sub> | 1.5 |  
| *X*<sub>1</sub>\* *X*<sub>2</sub>\* *X*<sub>3</sub> | 0.5 |  
| *X*<sub>2</sub>\* *X*<sub>3</sub> | 0 |  
{: .no-border-table}


#### 可能な選択肢
一般的に、等高線プロットの2つの軸は、以下の組合せとなる。 

* *X*<sub>1</sub> および *X*<sub>2</sub>
* *X*<sub>1</sub> および *X*<sub>3</sub>
* *X*<sub>2</sub> および *X*<sub>3</sub> 

この場合、*X*<sub>1</sub> は順位付け一覧の最上位項目であり、推定効果値が 23 であることから、*X*<sub>1</sub> が最も重要な因子であり、等高線図の横軸を占めることになる。
したがって、許容一覧としては次のいずれかに絞る。

 * *X*<sub>1</sub> および *X*<sub>2</sub>
 * *X*<sub>1</sub> および *X*<sub>3</sub>

これら2つの組合せのどちらを選ぶかを決定するために、順位付け一覧の2番目の項目を確認する。
これは交互作用項 **X*<sub>1</sub>\* *X*<sub>3</sub> で、推定効果は 10 である。
交互作用項は等高線プロットの軸として使用できないため、*X*<sub>1</sub>\**X*<sub>3</sub>は除外しなければならない。
一方で、この交互作用の構成要素（*X*<sub>1</sub>と*X*<sub>3</sub>）は除外する必要はない。
*X*<sub>1</sub> はすでに等高線プロットの軸の1つとして特定されているため、もう一方の構成要素（*X*<sub>3</sub>）を2番目の軸として使用するのが妥当である。
故に、そうする。
なお、*X*<sub>3</sub> 自体が重要である必要は**ない**（実際に記載された表では *X*<sub>3</sub> の値は 1.5 で 4番目に位置する）。
要約すると、この例における等高線図の軸は次の通り。

横軸：*X*<sub>1</sub> 
縦軸：*X*<sub>3</sub> 

#### 軸の推奨選択に関する4事例
その他の場合は、より複雑になることもある。
一般的に、2つのプロット軸を選択するときの推奨ルールとしては、因子の順位付け一覧の上位2項目から軸を設定する。
以下の4つの条件が、実務上のほとんどの状況を網羅している。 

* ケース1：  
    1. 項目1が主効果である場合（例：*X*<sub>3</sub>）  
    2. 項目2が別の主効果である（例：*X*<sub>5</sub>）  
   - 推奨される選択：
      1. 横軸：項目1（例：*X*<sub>3</sub>）  
      2. 縦軸：項目2（例：*X*<sub>5</sub>)
<br><br>
* ケース2：  
    1. 項目1が主効果である場合（例：*X*<sub>3</sub>）  
    2. 項目2は（共通要素の）交互作用（例：*X*<sub>3</sub>\**X*<sub>4</sub>）  
   - 推奨される選択：  
      1. 横軸：項目1（例：*X*<sub>3</sub>） 
      2. 縦軸：項目2の残りの構成要素（例：*X*<sub>4</sub>）
<br><br>
* ケース3：  
    1. 項目1は主効果である（例：*X*<sub>3</sub>）  
    2. 項目2は（共通要素を持たない）交互作用（例：*X*<sub>2</sub>\**X*<sub>4</sub>）  
   - 推奨される選択：  
      1. 横軸：項目1（例：*X*<sub>3</sub>）  
      2. 縦軸：項目2のいずれかの構成要素（例：*X*<sub>2</sub>、または*X*<sub>4</sub>）、ただし、個別の効果が最も大きい方を選択することが望ましい（したがって、           ランク付けされた残りの因子を調べ、*X*<sub>2</sub>の|効果| > *X*<sub>4</sub>の |効果| であれば*X*<sub>2</sub>を選択し、そうでない場合は*X*<sub>4</sub>を選択する）。  
<br><br>
* ケース4：    
    1. 項目1が（2因子）交互作用（例：*X*<sub>2</sub>\**X*<sub>4</sub>）である場合  
    2. 項目2は任意のもの  
   - 推奨される選択：  
      1. 横軸：項目1の交互作用から得られる成分1（例：*X*<sub>2</sub>）  
      2. 横軸：項目1の交互作用（例：*X*<sub>4</sub>）から得られた成分2
