# 5.5.3.1.5. 単応答：標本抽出誤差が最適解に及ぼす影響

#### 導出されたすべての最適運転条件があくまで推定値に過ぎないことを意味する実験誤差
工程技術者は、推定された最適運転条件 ***x\**** が、系における真の（未知の）最適点の推定値のひとつであることを認識しておくべきである。
すなわち、標本抽出（実験）誤差により実験を繰り返すと、異なる2次関数が適合された結果、異なる定常点 ***x\**** が得られることになる。
一部の著者（[Box と Hunter](../section8/pri8.md#BoxHun), 1954;[Myers と Montgomery](../section8/pri8.md#MyMo), 1995）は、指定された確率で系の定常点を含む因子空間領域を計算できる手順を提示している。
この領域は、点推定値 ***x\**** がどれほど「良好」であるかを示す尺度となる点で、工程技術者にとって有用な情報である。
一般に、この領域が広ければ広いほど、点推定値 ****x\**** の信頼性は低くなる。
因子数 **k** が 3より大きい場合、これらの信頼領域を視覚化することは困難である。

#### 非常に重要な確認実行
工程技術者は、推定された最適運転条件である ***x\**** で確認試験を行うことの重要性を実験誤差の認識と共に理解すべきである。
