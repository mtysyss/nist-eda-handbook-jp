# 5.5.9.7. |効果| プロット

#### 目的
|効果|プロットは以下の問いに答える。

重要な因子（交互作用を含む）は何か。

定量的には、特定の因子や交互作用の推定効果はなにか、また他因子や交互作用に対する相対的順位はという問いは、[最小二乗推定](../../ch1_eda/section3/eda35i.md)基準（すなわち、生データとその推定値から得られる適合値との差の二乗和を最小化する効果推定値を計算すること）によって答えられる。
このような推定基準に基づき効果の大きさ順に並べた因子および交互作用の表を作成することができる。

|効果|プロットは、これらの順序づけられた推定値を最大から最小へとパレート式に可視化表現したものである。

ここで示す|効果|プロットは上記の両方を提供し、プロット自体と、順位付け一覧表である。
さらに、このプロットは交絡情報も提示するが、これは一部実施因子計画について妥当な結論を導き出す上で不可欠なものである。 

#### 出力
|効果| プロットの出力は次の通り。

1. 主: 重要効果（および交互作用）の順位付け一覧
完全実施因子計画の場合、交互作用には全順序における交互作用のすべてを含む。
一部実施因子計画の場合、交互作用には実際の交互作用の一部のみが含まれ、場合によっては全く含まれないこともある。
2. 副：因子（および交互作用）を重要と非重要の 2つに分類した群

#### 定義
|効果|プロットは、以下の要素で構成する。

* 縦軸：主因子および（利用可能な）交互作用の推定された順序付き（最大から最小）効果の絶対値
 *n* データ点（反復なし）の場合、一般的に (*n*-1) 効果が推定され、(*n*-1)の|効果|をプロットする。<br><br>
 
* 横軸：因子／交互作用の識別子：  
    1は因子 *X*<sub>1</sub> を示し、  
    2は因子 *X*<sub>2</sub> を示し、   
    …   
    12は 2因子 *X*<sub>1</sub>\* *X*<sub>2</sub> 交互作用 を示し、  
    123は 3因子 *X*<sub>1</sub>\* *X*<sub>2</sub>\* *X*<sub>3</sub> 交互作用を示す、  
    など。  <br>
    
* 右端の余白：因子／交互作用の識別（組み込みの冗長性）：  
    1は因子 *X*<sub>1</sub> を示し、  
    2は因子 *X*<sub>2</sub> を示し、  
    …  
    12は 2因子 *X*<sub>1</sub>\* *X*<sub>2</sub> の交互作用を示し、  
    123は 3因子 *X*<sub>1</sub>\* *X*<sub>2</sub>\* *X*<sub>3</sub> の交互作用を示す、  
    など。  
    設計が一部実施因子計画である場合、主因子および2因子交互作用について交絡構造が示される。<br><br>

* 右上の表：主効果および（利用可能な）交互作用に対する最小二乗推定値の（絶対値の大きい順に並べられた）一覧  
    前述と同様に、設計が一部実施因子計画法の場合、主因子および2因子交互作用について交絡構造が示される。

縦軸の基礎である推定効果は、最小二乗法の意味において最適である。
これらの推定値に基づいて、生データと推定値との間の偏差二乗和をこれより小さくする他の推定量はない。

2<sup>k</sup> 完全因子計画および 2<sup>k-p</sup> 一部実施因子計画のいずれにおいても、因子 *i* 効果、2因子交互作用効果、および多因子交互作用効果の最小二乗推定値は以下の単純な形式をとる。

**因子*i*の効果$` = \bar{Y}(+) - \bar{Y}(-) `$**  
**2因子交互作用効果$` = \bar{Y} (+) - \bar{Y} (-) `$**  
**多因子交互作用効果$` = \bar{Y} (+) - \bar{Y} (-) `$**  

ここで、$` \bar{Y}(+) `$ は、因子 *i*（または2因子交互作用、多因子交互作用）が「+」値をとる応答値すべての平均を表し、$` \bar{Y}(-) `$ は、因子 *i*（または 2因子もしくは多因子交互作用）が「-」値をとる応答値すべての平均を表す。

上記簡略化の本質は、2水準の完全実施因子計画および一部実施因子計画がいずれも本質的に直交しており、したがって、最小二乗法による *X'X* 行列の対角線以外の項はすべてゼロになるという点にある。 

#### 動機
最小二乗推定値は平均値の差によって定義されること、すべての因子（および交互作用）が -1 と +1（簡略化して - と +）の値をとるように標準化されていることから、結果として得られる推定値はすべて同じ尺度である。
したがって、大きさに基づいて推定値の比較や順位付けを行うことは、極めて理にかなっている。

さらに、各推定の符号は完全に恣意的であり、初期の割当て方法によって逆転する（例えば、処置A に「-」を処置B に「-」を割り当てることも、同様に簡単に処置A に「+」を処置Bに「-」を割り当てることも可能である）ため、符号付きの効果ではなく、大きさに基づいて順位付けを行うことが望ましい。

それを踏まえ、因子および交互作用効果の最終的かつ決定的な順位付けは、そのような最小二乗推定値の順位付け（大きさ）一覧に基づいて行う。
このような順位付けは、パレート式でプロット内に図示され、定量的にプロットの右上領域にある表によって示される。
一部実施（完全実施ではない）因子計画の場合、右上の表には使用された計画にかかわらず、交絡構造も示される。

ある因子が重要である場合、「+」の平均は「-」の平均とは異なり、その差の絶対値は大きくなる。
逆に、重要でない因子の場合は平均の差が小さいため、その絶対値も小さくなる。

このような |効果| のパレート図を作成する。
パレート図では、最も大きな効果（最も重要な因子）が最初に（左側に）表示され、そして最も小さな効果（最も重要度の低い因子）へと右側に向かって並ぶ。

#### 解釈の方法
|効果| プロットから以下の点を確認する。

1. 因子（交互作用を含む）の順位付け一覧は、スパイクの左から右への順序によって示される。
これらのスパイクの高さは、左から右へ進むにつれて低くなるはずである。
各バーに関連付けられた因子識別子に注目する。<br><br>
2. 重要な因子を特定する。
因子順位付け一覧を作成することは重要であるが、それは分析の半分に過ぎない。
分析の第二段階では、この順位一覧を用いて、一覧およびグラフ上に「（水平な）線を引き」、その線より上の因子を「重要」とみなす一方、線より下の因子を「重要でない」とみなす。<br><br>
因子効果は、非常に大きいものから中程度、さらに非常に小さいものに至るまで連続的に分布していることが多く、これら因子のすべてを「重要」と「重要でない」の2つのグループに分類することは、恣意的かつ厳しすぎるように思えるかもしれない。
しかし、実際には、研究資金の配分やモデル化の観点から、このような二分法は一般的であると同時に必要不可欠なものである。<br><br>
工学研究資金配分の観点から、将来の研究、注目度、および資金を特定因子の部分集合に集中させる必要が頻繁にあり、それによって必然的に他の因子はそれ以上の検討対象から除外されることになる。
モデル構築の観点からは、最終モデルにはある項が含まれているか、含まれていないかのいずれかであり、中間的な立場は存在しない。
簡潔なモデルには、含めるか、含まないかという決定が求められる。
言うまでもなく、重要因子を特定した時点で、それらが（簡潔な）優れたモデルを構成する因子となり、重要でないと判断された因子はモデルに含まれないことになる。<br><br>
そうだとすれば、その二分線の境界はどこに引くべきだろうか。<br><br>
そのような線を引き方には4つの方法があり、それぞれについて順に説明する。 <br><br>
    1. [統計的有意性](pri5971.md)
    2. [工学的意義](pri5972.md)
    3. [数値的有意性](pri5973.md)
    4. [パターンの有意性](pri5974.md)

|効果|プロットから導出された因子順位一覧と分類は、前手順で得られた因子順位一覧と比較する。
必ずと言っていいほど、すべての技法において考えられる程度の一貫性が示されるはずである。

#### 欠陥ばねデータの結論
欠陥ばねデータ集合に「|効果|プロット」を適用した結果から以下の結論が得られる。

1. 因子（交互作用を含む）の順位一覧：
    1. *X*<sub>1</sub>（最も重要）
    2. *X*<sub>1</sub>\* *X*<sub>3</sub>（次に重要）
    3. *X*<sub>2</sub>
    4. その他の因子は重要度が低い 
* 因子の「重要／重要でない」という分類：
    * 重要：*X*<sub>1</sub>、*X*<sub>1</sub>\* *X*<sub>3</sub>、および *X*<sub>2</sub>
    * 重要でない：それ以外
