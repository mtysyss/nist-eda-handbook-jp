# 5.5.9.4. 交互作用効果行列プロット

#### 目的
交互作用効果行列プロットは、主効果と2因子交互作用の両方（DOE平均プロットは主効果のみに焦点を当てている）を含むように拡張された[DOE平均プロット](pri593.md)である。
この交互作用効果行列プロットは以下の2つの問いに答える。

1. 因子（2因子交互作用を含む）の重要度順の順位付け一覧は、最も重要なものから最も重要度の低いものへどう並んでいるか。
2. *k* 因子それぞれの最適設定は何か。

*k* 因子実験において、応答への影響は、主効果や *k* 項交互作用に至るさまざまな交互作用によるものである可能性がある。
因子数 *k* が増加するに従い交互作用の総数は指数関数的に増加する。
次数すべての交互作用の総数 = 2<sup>*k*</sup> - 1 - *k* となる。
したがって、*k* = 3 では交互作用の総数 = 4 であるが、*k* = 7 では交互作用の総数 = 120 となる。

実際では、最重要交互作用は 2因子交互作用であことが多い。
可能な 2因子交互作用の総数は次式となる。

$$ \left( \begin{array}{c}k \\ 2 \end{array} \right)= \frac{k!} {2!(k-2)!} = \frac{k(k-1)}{2}$$  

したがって、*k*= 3 であれば 2因子交互作用数 = 3 であり、*k*= 7 の場合は 2因子交互作用数 = 21 となる。

与えられた実験において有効な交互作用数と、分析者が決定的な結論を導き出すことができる交互作用数とを区別することが重要である。
前者は、問題の物理的・工学的側面のみに依存する。
後者は、因子数 *k*、*k* 因子の選択、実行回数 *n* に対する制約、そして最終的には分析者が採用することを選択した実験計画に依存する。
要するに、可能な交互作用数は必ずしも検出できる交互作用数と一致する**わけではない**。

なお、

1. 完全実施要因計画では、あらゆる次数の交互作用を一意に推定できる。
2. 一部実施要因計画では、一部の（あるいは場合によっては全くない）交互作用のみを一意に推定できる。
計画がより細分化されるほど、推定可能な交互作用数は少なくなる。 

#### 出力
交互作用効果の行列プロットの結果は以下の通り。

1. 主：重要から非重要に順序付けされた、因子（2因子交互作用を含む）の重要度順順位付け一覧
2. 副：*k* 因子それぞれに対する最適設定

#### 定義
交互作用効果の行列プロットは、右上三角行列の形をした[平均プロット](../../ch1_eda/section3/eda33k.md)の集合であり、対角線上に *k* 種の主効果プロット、対角線外に *k*\*(*k*-1)/2 種の 2因子交互作用効果プロットが配置されている。

一般に、交互作用は通常の（乗法的な）交差積とは同一ではない。
しかし、（-, +）＝（-1, +1）と符号付けられた 2水準計画の特殊な場合においては、交互作用は交差積と同一**である**。
対照的に、2水準計画が別の方法で符号化されている場合（例えば、田口らによって提唱された (1, 2) 表記法など）、この等価性は成り立たない。
数学的には、

$${-1, +1} × {-1, +1} ≠ {-1, +1}$$

となるが、

$${1, 2} × {1, 2} ⇒ {1, 2, 4}$$

したがって、符号付けの仕方により結果が異なる。
（-、+）による符号付けの使用を推奨する。

注目すべきは、- および + の符号化を用いると、2因子交互作用が、*k* の主効果と同じ方法で扱われ、解釈され、比較される点にある。
したがって、比較を容易にするために、2因子交互作用と主効果の両方を同じ行列プロットに含めるのが自然である。

対角線以外の項については、最初の構築手順として、横軸の値を作る。
これは、交差積の導出値（これも- および +）である。
例えば、*X*<sub>1</sub>\* *X*<sub>2</sub> の交互作用の設定は、以下に示すように、データから単純な乗算によって導出する。

| *X*<sub>1</sub> | *X*<sub>2</sub> | *X*<sub>1</sub>\* *X*<sub>2</sub> |  
| :---: | :---: | :---: |  
| - | - | + |  
| + | - | - |  
| - | + | - |  
| + | + | + |  
{: .no-border-table}

したがって、*X*<sub>1</sub>、*X*<sub>2</sub>、および *X*<sub>1</sub>\* *X*<sub>2</sub> はすべて、閉じた（-、+）系を形成する。
この閉じた系の利点は、グラフ上で交互作用を、*k* 種の主効果とまったく同じ方法で解釈できることである。

このようにして *X*<sub>1</sub>\* *X*<sub>2</sub> の設定ベクトル全体を作成した後、*X*<sub>1</sub>\* *X*<sub>2</sub> 交互作用プロットの縦軸を作成する。

1. *X*<sub>1</sub>\* *X*<sub>2</sub> = "-" より上のプロット点は、単に *X*<sub>1</sub>\* *X*<sub>2</sub> = "-" のすべての応答値の平均値である
2. *X*<sub>1</sub>\* *X*<sub>2</sub> = "+" の上にあるプロット点は、単に *X*<sub>1</sub>\* *X*<sub>2</sub> = "+" のすべての応答値の平均値である。

残りの2因子交互作用についても同様の方法でプロットを作成する。

主効果および 2因子交互作用のすべての平均プロットは比較を容易にするために共通の目盛りが用いられる。
各平均プロットには

1. 縦軸：所与の因子もしくは所与の 2因子交互作用における特定の設定（- または +）における応答平均値
2. 横軸：各因子内もしくは各2因子交互作用内の2設定（- および +）
3. 凡例： 
    1. タグ（1、2、...、*k*、12、13など）。
    1 = *X*<sub>1</sub>、2 = *X*<sub>2</sub>、...、*k* = *X*<sub>*k*</sub>、12 = *X*<sub>1</sub>\* *X*<sub>2</sub>、 13 = *X*<sub>1</sub>\* *X*<sub>3</sub>、35 = *X*<sub>3</sub>\* *X*<sub>5</sub>、 123 = *X*<sub>1</sub>\* *X*<sub>2</sub>\* *X*<sub>3</sub>、などで、 特定の平均プロットを識別する。
    2. 因子（もしくは2因子交互作用）効果の最小二乗推定値。
    これらの効果推定値は、重要因子は絶対値が大きく、重要でない因子は絶対値がほぼゼロとなる。

[後節](pri5995.md)では、完全実施要因計画および一部実施要因計画の2水準計画に関連するモデルについて詳細に論じる。
そのようなモデル表現の一つは次の通り。

$` Y = \mu + \beta_1 X_1 + \beta_2 X_2 + \beta_{12} X_1 X_2 +\cdots + \epsilon `$。

+ および - 設定で符号化された因子変数については、*β*<sub>i</sub> 係数は因子 *X*<sub>i</sub> に起因する効果推定値の半分となる。
したがって、最小二乗係数に 2 を掛けると、直交性により、+ 設定と - 設定における平均値の単純な差が得られる。
これは *k* 主因子について成立する。
また、すべての 2因子および多因子交互作用についても同様である。

したがって、視覚的にプロット上の平均値の差はその効果の最小二乗推定値と完全に一致する。
差が大きい場合（急勾配の線）は重要因子であることを示し、差が小さい場合（緩やかな線）は非重要因子であることを示す。 

#### 動機
前述の通り、主効果の次に検討すべき論理的手順は 2因子交互作用を表示することであり、このプロット行列は主効果と2因子交互作用の相対的な重要性を一体として検討するための便利な可視化ツールである。
そのために、2水準計画の文脈において、2因子交互作用が交差積と同一であり、2因子交互作用の効果は主効果と同様に解釈、比較できるという注目すべき特徴を活用する。

#### 解釈の方法
交互作用効果行列から、3つの重要な結論を導き出すことができる。

1. 重要因子（2因子交互作用を含む）
2. 最適設定
3. 交絡構造（一部実施要因計画の場合）

これらについて順に検討する。

1. **重要な因子（2因子間の交互作用を含む）：**  
 *k* 主因子と、*k*\* (*k*-1)/2 の2因子交互作用を組み合わせて比較する。
これらの各副プロットについて、副プロット内で「-」設定から「+」設定へと変化するに従い、平均データ位置にずれが生じているか（はい／いいえ）。
すべての副プロットは（-1, +1）という共通の横軸を持ち、位置のずれに関する問いは、平均線の傾きに関する問いへと置き換わる（大きなずれは急勾配の平均線を意味し、ずれがない場合は平な平均線を意味する）。<br><br>
    1. （平均値に基づいて）最も大きな位置のずれを示す因子や 2因子交互作用を特定する。
    これが「最重要因子」となる。
    最大の位置のずれは、最も急勾配の直線によって決定する。
    2. （平均値に基づいて）次に大きなずれ示す因子や 2因子交互作用を特定する。
    これが「2番目の重要因子」となる。
    このずれは、次に急勾配な直線によって決定する。
    3. 残りの因子についても続ける。<br><br>
局所平均に基づく因子と2因子交互作用の順位付けは、スクリーニング実験に必要な順位付けされた因子の確定一覧を作成する重要な手順である。<br><br>

2. **最適な設定：**  
各因子（対角線上にある *k* 主因子のうち）について、どの設定（- または +）が「最適」（最高／最低）な平均応答を与えるか。
<br><br>
実験者は、*k* 主因子の設定のみを変更でき、2因子交互作用については変更できないことに注意する。
ある 2因子交互作用の設定が、その同じ 2因子交互作用に対する別の設定よりも優れた平均応答であっても、実験者は実際に は2因子交互作用の設定を行うことはできない。
つまり、装置には 2因子交互作用を制御する「ノブ」は存在せず、「ノブ」は *k* 主因子の設定のみを制御する。
<br><br>
副プロット行列は、 [DOE平均プロット](pri593.md)から得られる *k* の最適設定に比べ、どのような点で優れているか。
一般的な可能性として2つ挙げられる。 <br><br>
    1. 急勾配の線：<br><br>
    対角線上にある主因子のうち、勾配の急な線（つまり重要因子）については、副プロットから直接最適設定を選択する。
    これは、DOE平均プロットから導き出された最適な設定と同じものになる。<br><br>
    2. 平らな線：<br><br>
    対角線上にある主因子のうち、直線が平なもの（つまり重要でないもの）については、どちらの設定でもよいという単純な結論、例えばより安価な設定や実施が容易な設定を優先するという判断は、間違いの可能性がある。
    そのような場合、交互作用効果行列から得られる対角線外の2因子交互作用情報を活用し、名目上「重要でない」因子について、より適切な設定を導き出すために極めて重要である。<br><br>
    これを説明するために、次の例を考える。<br><br>
        * 因子 *X*<sub>1</sub> の副プロットが急勾配（重要）であり、*X*<sub>1</sub> の最適な設定が「+」であるとする。
        * 因子 *X*<sub>2</sub> の副プロットが平坦（重要でない）であり、どちらの設定でもほぼ同じ平均応答が得られるとする。<br><br>
    では、*X*<sub>2</sub> にはどのような設定を用いるべきか。
    これに応えるために、以下の2つのケースを検討する。<br><br>
        1. 事例1. *X*<sub>1</sub>\* *X*<sub>2</sub> 交互作用プロットがたまたま平坦（重要でない）である場合、コストや容易さを基準に *X*<sub>2</sub> の設定を選択する。
        2. 事例2. 一方、*X*<sub>1</sub>\* *X*<sub>2</sub> 交互作用プロットが急勾配（重要）である場合は、コストや容易さではなく、*X*<sub>2</sub>の推奨設定として決定される。<br><br>
    事例2 について具体的に言えば、*X*<sub>1</sub>\* *X*<sub>2</sub> が重要であり、*X*<sub>1</sub>\* *X*<sub>2</sub> = "+" がより良い設定である場合、かつ *X*<sub>1</sub> が重要であり、*X*<sub>1</sub> = "+" がより良い設定である場合、これは、*X*<sub>2</sub> の最適設定が「+」でなければならないことを意味する（*X*<sub>1</sub>\* *X*<sub>2</sub> (= +\*+) も「+」になることを保証するため）。
    理由は、既に *X*<sub>1</sub> = "+" に固定されており、かつ *X*<sub>1</sub>\* *X*<sub>2</sub> = "+" の方が優れているため、*X*<sub>1</sub> = "+" の状態で *X*<sub>1</sub>\* *X*<sub>2</sub> = "+" を得る唯一の方法は、 *X*<sub>2</sub> が「+」である場合に限られる（もし *X*<sub>2</sub> が「-」であれば、*X*<sub>1</sub> = 「+」の状態で *X*<sub>1</sub>\* *X*<sub>2</sub> を計算すると、*X*<sub>1</sub>\* *X*<sub>2</sub> = 「-」となる）。<br><br>
    一般に、*X*<sub>1</sub> が重要で、*X*<sub>1</sub>\* *X*<sub>2</sub> が重要であり、*X*<sub>2</sub> が重要でない場合、*X*<sub>2</sub> の最適な設定を決定する 4つの異なる条件が考えられる。<br><br>   
    | *X*<sub>1</sub> | *X*<sub>1</sub>\* *X*<sub>2</sub> | => *X*<sub>2</sub> |  
    | :---: | :---: | :---: |  
    | +	| +	| + |  
    | +	| -	| - |  
    | -	| +	| - |  
    | -	| -	| + |  
    {: .no-border-table}
<br><br>
    同様の理由により、各因子と因子対を検討し、*k* 最適設定結果のベクトルが得られる。 

   (*X*<sub>1</sub>best, *X*<sub>2</sub>best, ..., xkbest)
<br><br>
    この平均に基づく *k*-ベクトルを先に実施した手順（特に、最適設定が最適データ値から導出された手順1）から得られた最適設定の *k*-ベクトルと比較するべきである。
<br><br>
    平均に基づく最適設定とデータに基づく最適設定が一致する場合、結論に対する信頼性が高まるという利点がある。
<br><br>
    平均に基づく最適設定とデータに基づく最適設定が一致しない場合、分析者は最終的にどの設定を選択すべきか。
    一般的に、平均に基づく設定とデータに基づく設定は、「重要な」因子すべてについて常に同一であることに留意する。
    設定が異なる因子は、事実上常に「非重要」である。
    このような不一致が生じた場合、分析者には3つの選択肢がある。<br><br>
        1. 重要度の低い因子は、平均に基づく設定を使用する。
        これには、より広範な（平均的な）支持基盤が得られるという利点がある。
        2. 重要度の低い因子には、データに基づく設定を使用する。
        これには、局所的な最適性が実証されているという利点がある。
        3. 局所的な因子には、より安価もしくは便利な設定を用いる。
        これには、実用性という利点がある。<br><br>
    したがって、交互作用効果行列は、因子順位一覧だけでなく、*k* 主因子それぞれに対する最適設定についても、重要な情報を提供する。
    副プロット行列は、2水準スクリーニング計画の解析において、実験者にとって最も重要なツールの1つである。<br><br>

3. **交絡構造（一部実施要因計画について）** <br><br>
交互作用効果行列を用いて 2水準の一部（完全ではない）実施要因計画を分析する場合、交絡構造に関する重要な追加情報をその行列から抽出することができる。<br><br>
すべての一部実施要因計画には交絡が存在することはよく知られており、これは、推定されたすべての主効果が、何らかの高次交互作用によって交絡・汚染・偏りを帯びるという性質である。
これによる実用上の影響として、分析者は、推定された主効果のどの程度が主因子そのものに起因し、どの程度が何らかの交絡交互作用に起因するものか確信が持てない。
このような混入は、*k* 因子を完全実施要因計画の *n* = 2<sup>*k*</sup> 実行数よりも少ない標本規模 *n* で検討することで支払われる代償である。<br><br>
実験計画法の分野における「基本定理」として、与えられた因子数 *k* および実行数 *n* に対し、一部の一部実施要因計画は他よりも優れていることが挙げられる。
この場合の「優れている」とは、すべての一部実施要因計画法に必ず存在する内在的な交絡が、計画法の選択によって最小化されていることを意味する。
この最小化は、主効果による交絡を可能な限り高次の交互作用へと押し上げるように計画法を構築することで行われる。<br><br>
その背景にある理屈は、物理科学や工学系において、高次交互作用が有意となる「尤度」は（主効果や2因子交互作用が有意となる尤度に比べ）小さいことが分かっている点にある。
このことを踏まえると、避けられない主効果の交絡は、可能な限り高次の交互作用と共存させ、それによって推定される主効果への偏りを可能な限り小さくしたい。<br><br>
最悪の計画は、主効果の交絡が2因子交互作用と結びついていることである。
物理・工学システムにおいては、自然界に実際の（かつ大きな）2因子交互作用が存在することが極めて一般的であることから、これは危険な可能性がある。
そのような場合、2因子交互作用の効果は、推定された主効果のいずれかと不可分に絡み合ってしまうため、実験は次のような欠陥を抱えることになる。<br><br>
    1. 曖昧な主効果の推定値
    2. 順位付けされた因子の曖昧な一覧
<br><br>
因子数 *k* が大きく、実験数 *n* が少なく制限されている場合、主効果と2因子交互作用が交絡することは避けられない。
例えば、*k* = 7 因子があり、 *n* = 8 実験しか行えない場合、対応する 2水準の一部実施要因計画は 2<sup>7-4</sup> となり、必然的に主効果が (3) 2因子交互作用と交絡することになる。
これは避けられない。<br><br>
一方、 *k* や *n* の制約ではなく、計画の構築が不適切なために、2因子交互作用と主効果の交絡が生じる状況もある。
例えば、*k* = 7 因子があり、*n* = 16 実験が可能である場合、不適切に構築された計画では主効果が2因子交互作用と交絡してしまう可能性があるが、同じ *k* = 7、*n* = 16 の条件で適切に構築された計画では、主効果が 3因子交互作用と交絡するものの、2因子交互作用は**ない**。
明らかに、主効果の交絡・混入・偏りを最小限に抑えるという点では、後者の計画が望ましい。
主効果が 2因子交互作用と交絡している場合、重要な疑問が生じる。<br><br>
    関心のある特定の主効果について、どの2因子交互作用が主効果に交絡／汚染／偏りを生じさせているかを知ることができるのか。<br><br>
この問いに対する一般的な答えは、生成元理論、交絡表、または別名表を用いることである。
これとは別の補完的な手法として、交互作用効果行列が挙げられる。
特に、2水準一部実施要因計画を検討しているならば、<br><br> 
    1. 計画において主効果が2因子交互作用と交絡しているか確信が持てない場合
    2. そのような2因子交互作用による交絡が存在することは確実であるが、どの効果が交絡しているか不明な場合<br><br>
その場合、交互作用効果行列はどのように役立つか。
この問いに対する答えは、交絡構造が交互作用効果行列から**直接**読み取れるということである。<br><br>
例えば、7因子実験において、因子 *X*<sub>3</sub> が2因子交互作用 *X*<sub>2</sub>\* *X*<sub>5</sub> と交絡している場合、 <br><br>
    1. 因子 *X*<sub>3</sub> の副プロットと2因子交互作用 *X*<sub>2</sub>\* *X*<sub>5</sub> の副プロットの外観は必然的に一致し
    2. *X*<sub>3</sub> の推定主効果の値（主効果副プロットの凡例に示されているもの）と *X*<sub>2</sub>\* *X*<sub>5</sub> の推定2因子交互作用効果の値（2因子交互作用副プロットの凡例に示されているもの）も、必然的に一致する。<br><br>
上記の条件は、効果が交絡しているために必要ではあるが、十分条件ではない。<br><br>
したがって、（使用している統計ソフトウェアによる）交絡構造に関する表形式の記述がない場合、交互作用効果行列は一部実施要因計画における交絡構造を推定するために次の図による代替手段を提供する。<br><br> 
    1. 対角線上の副プロットに沿って主因子を調べ、「重要」因子の部分集合を選択する。
    2. 各「重要」因子について、すべての2因子交互作用を精査し、主因子の副プロットおよび推定効果を各2因子交互作用の副プロットおよび推定効果と比較する。
    3. 一致が見られない場合、これは主効果がどの2因子交互作用とも交絡していないことを意味する。
    4. 一致する場合、これは主効果がその2因子交互作用と交絡している**可能性がある**ことを示唆する。
    5. いずれの主効果もどの2因子交互作用とも交絡していない場合、推定された主効果の完全性（非交絡性）に対して高い信頼を持つことができる。
    6. 実際には、高度に分割された計画の場合、各主効果は複数の2因子交互作用と交絡している可能性がある。
    例えば、2<sup>7-4</sup> の一部実施要因計画では、各主効果は2因子交互作用3つと交絡することになる。
    これらの 1 + 3 = 4 の同一副プロットは、交互作用効果行列において極めて明白に現れる。<br><br>
最後に、計画において主効果が2因子交互作用と交絡して**いない**場合（対角上の副プロットが対角外の副プロットと一致しない場合）はどうなるか。
そのような場合、交互作用効果行列は有用なさらなる洞察や情報を提供してくれるか<br><br>
この質問に対する答えは、そのような計画では主効果が2因子間の交互作用と交絡していないとはいえ、 2因子交互作用が互いに交絡していることはかなり一般的であり、場合によっては、その交絡関係を理解することが分析者にとって興味深いこととなる可能性があるため、「はい」である。
そのような計画の具体的な例として、*X*<sub>4</sub> の設定が *X*<sub>1</sub>\* *X*<sub>2</sub>\* *X*<sub>3</sub> で構成される 2<sup>4-1</sup> 計画が挙げられる。
この場合、2因子交互作用の交絡構造は、すべての 2因子交互作用の副プロット（および効果推定値）を互いに比較することで推定できる。
一致する副プロットおよび効果推定値は、2つの 2因子交互作用が交絡していることを強く示唆している。
前述の通り、このような比較は交絡の必要条件（ただし十分条件ではない）を提供する。
一部実施要因実験を分析するためのほとんどの統計ソフトウェアは交絡構造を明示的に一覧表示する。
