# 5.5.9.10.7. 解釈方法：最適設定

#### 最適設定
「近接点」の最適設定は[最大勾配線](pri59a5.md)と[最適設定曲線](pri59a6.md)の交点である。

理論的には、最適曲線上の任意の(*X*<sub>1</sub>, *X*<sub>3</sub>)設定が、*Y* = 100 という望ましい応答を与える。
しかし実務上は、これは推定された等高面が「自然界の」応答面と完全に一致する場合にのみ成り立つ。
実際には、プロットされた等高線は、入手可能な（かつ「ノイズの多い」）*n* = 8 のデータ値に基づいた真の推定値に過ぎない。
データ点（グラフ上の4つの角点）の近傍における等高線曲線については信頼性が高いが、角点から離れるにつれて、等高線曲線に対する信頼度は低下する。
したがって、*Y* = 100 の最適応答曲線上で「最も可能性が高い」と見なされる点は角点に最も近い点である。
したがって、我々の目的はその「近傍点」を特定することである。 

#### 欠陥ばねの例
欠陥ばねの等高線図については、最良の角（+, +）から外側へ、*Y* = 90、*Y* = 95、および *Y* = 100の等高線に対して垂直な線を引く。
 *Y* = 100 との交点が最適応答曲線上の「最も近い点」となる。
 
これを行い、最適設定の座標に注目することが重要である。
この場合、[グラフから](pri59a.md#plot)設定は（符号化単位で）凡そ

$$ X_1 = 1.5, X_3 = 1.3) $$

付近にあることが判る。 

#### 符号化済みおよび未符号化因子の一覧表
設定が決定されたことで、理論上は当初の課題を形式的に完了したことになる。
しかし実際には、さらにやるべきことがある。
「この最適設定が、符号化された単位だけでなく、元の（符号化されていない）単位においてもどうなっているか」を知る必要がある。
つまり、（*X*<sub>1</sub> =1 .5, *X*<sub>3</sub> = 1.3）は、元のデータの単位では何に相当するか。

これを導き出すには、この問題における元の（符号化されていない）因子に立ち返る必要がある。
それらは以下の通り。

| 符号化因子 | 非符号化因子 |    
| :--: | :--- |  
| *X*<sub>1</sub> | OT：オーブン温度 |  
| *X*<sub>2</sub> | CC: 炭素濃度 |  
| *X*<sub>3</sub> | QT：急冷温度 |  
{: .no-border-table}

#### 非符号化因子設定と符号化因子設定
これらの因子には設定値があった――符号化因子と非符号化因子の設定値はどのようなものだったか。
問題の当初の記述によれば、非符号化因子の設定値は以下であった。

1. 炉内温度（1450 および 1600℃）
2. 炭素濃度（0.5 および 0.7％）
3. 急冷温度（70 および 120℃）

これに対応する符号化因子の通常設定は以下の通りであった。

1. *X*<sub>1</sub> (-1, +1)
2. *X*<sub>2</sub> (-1, +1)
3. *X*<sub>3</sub> (-1, +1)

（*X*<sub>1</sub> = 1.5、*X*<sub>3</sub> = 1.3）に対応する設定を決定するために以下の図を参照する。
この図は、平均応答の散布図を模したもので、横軸に炉内温度（OT）、縦軸に急冷温度（QT）が示されている。

グラフ上の「X」は、最近接点」設定を表している。 

#### X1（オーブン温度）の最適設定
「X」が非符号化単位で何であるかを求めるには、（グラフから）OT と *X*<sub>1</sub> 間の線形変換が以下に定義されていることに注目する。

$$ \begin{align}
OT = 1450 => & X_1 = -1 \\  
OT = 1600 => & X_1 = +1
\end{align} $$

により、

$$ X_1 = 0 \quad \text{となるのは} \quad OT = (1450 + 1600) / 2 = 1525 $$

したがって、

```
           |-------------|-------------|
X1:       -1             0            +1
OT:      1450          1525          1600
```

となる。
さらに、例えば *X*<sub>1</sub> = +2 の場合は、オーブン温度 OT = 1675 に対応する。

```
           |-------------|-------------|-------------|
X1:       -1             0            +1            +2
OT:      1450          1525          1600          1675
```

故に、最適な *X*<sub>1</sub> 設定値 1.5 は以下となる。

$$ OT = 1600 + 0.5 * (1675-1600) = 1637.5 $$

#### X3（急冷温度）の最適設定
同様に、グラフから焼入れ温度 QT と符号化因子 *X*<sub>3</sub>との間の線形変換は、次のように指定されることがわかる。

$$ \begin{align}
QT & = 70 => X_3 = -1 \\  
QT & = 120 => X_3 = +1
\end{align} $$

から、

$$ X_3 = 0 \quad \text{となるのは} \quad QT = (70 + 120) / 2 = 95 $$

のときであり

```
        |-------------|-------------|
X3:    -1             0            +1
QT:    70            95           120
```

したがって、例えば *X*<sub>3</sub> = +2 の場合、焼入れ温度は 145 となる。

```
        |-------------|-------------|-------------|
X3:    -1             0            +1            +2
QT:    70            95           120           145
```

故に、最適な *X*<sub>3</sub> の設定値 1.3 は以下となる。

$$ \begin{align}
QT & = 120 + 0.3 * (145-120) \\
QT & = 127.5
\end{align} $$

#### 最適設定の概要
まとめると、最適な設定は次の通り。

符号化：(X1= +1.5, *X*<sub>3</sub>= +1.3)  
非符号化：(OT = 1637.5 ℃, QT = 127.5 ℃)  

そして最後に、固定因子 *X*<sub>2</sub>（炭素濃度 CC）の最適設定値である *X*<sub>2</sub> = -1（CC = 0.5%）を含めると、3因子すべてに対する最終的な完全な推奨最適設定は以下となる。

符号化：(*X*<sub>1</sub> = +1.5, *X*<sub>2</sub>= -1.0, *X*<sub>3</sub>= +1.3)  
非符号化：(OT = 1637.5, CC = 0.7 %, QT = 127.5)  

もし別の実験を行う場合、これは（データに基づいて）100％のばねが合格基準を満たすことを期待、目標として、オーブン温度、炭素濃度、および焼入れ温度を設定すべき点となる。

#### 次手順の選択肢
実際には、次のいずれかの方法をとることができる。

1. （予算や時間が限られている場合は）この推奨設定で単一データ点を収集し、100％にどれだけ近づけるかを確認する。 
2. （費用や時間がそれほど問題にならない場合は）中心点（推奨設定）で2回、できれば3回の反復測定を行う。
3. 資金や時間に余裕がある場合は、中心点を伴う 2<sup>2</sup> の完全実施要因計画を実行する。
この計画は、最適設定（*X*<sub>1</sub> = +1, 5, *X*<sub>3</sub> = +1.3）を中心とし、(*X*<sub>1</sub> = +1, *X*<sub>3</sub> = +1) に1つの重複する新しい隅点と、(*X*<sub>1</sub> , *X*<sub>3</sub>) = (+1, +1)、(+2, +1)、(+1, +1.6)、(+2, +1.6) に配置される。
これら4つの新しい角点のうち、点(+1, +1) には、元計画の角点と重なるという利点がある。
