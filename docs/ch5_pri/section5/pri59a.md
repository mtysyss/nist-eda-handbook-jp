# 5.5.9.10. DOE等高線図

#### 目的
DOE等値線図は、次の問いに答える。

応答を最適化するために、他にどこで実験を行えたか。

この解析においてここまでの手順では、*k* の DOE等高線図それぞれについて最適な設定が示唆されている。
これらの最適設定は、以下のいずれかから導出された。

1. データ：*n* 計画点のうち、どの点が最良の応答を与え、計画点の設定はどのようなものであったか。
2. 平均値：各因子のどの設定が「平均的に」最良の応答を与えたか。

分析手順のこの 10番目（そして最後の）手順は、計画で既に選択された *n* データ点という制限を超え、データに制限された次の問い

「*n* データ点のうち、どの設定が最良だったか。」

を領域に関連した問いへと置き換える。

「一般的に、応答を最適化するためには、どの設定にすべきだったか。」

#### 出力
DOE等高線図からの出力は以下の通り。

1. 主：*k* DOE等高線図それぞれに対する最適な設定（*X*<sub>10</sub>、*X*<sub>20</sub>、…、*X*<sub>*k*0</sub>）この導出された設定は、最適応答を与えるはずである。
2. 副：応答曲面の性質や交互作用の重要／非重要に関する洞察。

#### 定義
DOE等高線図は以下の要素によって構成される。

* 縦軸：実験において 2番目に重要な因子
* 横軸：実験において最も重要な因子

より具体的には、DOE等高線図は以下の 7手順を経て作成、利用される。

1. 軸
2. 等高線
3. 最適応答値
4. 最良の端点
5. 最急上昇／下降
6. 最適曲線
7. 最適設定

に関して

1. 軸：実験において最も重要な 2因子をプロット上の 2軸として選択する。
2. 等高線曲線：[適合モデル](pri599.md)と残りすべての因子に対する最適データ設定に基づいて、2つの主なDOE等高線図を含む等高線曲線を描画する。
これにより、応答曲面のグラフ表現を得る。
線形等高線曲線の作成に関する詳細は、[後節](pri59a2.md#construction)で説明する。
3. 最適値：応答の理論上の値のうち、「最良」となるものを特定する。
具体的には、応答としてどのような値が得られればよいか。 
4. 最良の「角点」：等高線図には、最も重要な 2因子 *X*<sub>*i*</sub> および *X*<sub>*j*</sub> について、4つの「角点」(*X*<sub>*i*</sub>, *X*<sub>*j*</sub>) = (-, -), (-, +), (+, -), および (+, +) が存在する。
データから、これら4つの「角」のうち、どの点が最も高い平均応答値 $` \bar{Y} `$ を与えるかを特定する。
5. 最急上昇／下降方向：最適角点から、その角付近の等高線の性質に基づいて、最大化の場合は最急上昇方向へ、最小化の場合は最急下降方向へと進む。
6. 最適曲線：等高線図上で、理想的な最適値に対応する曲線を特定する。
7. 最適設定：最急上昇／下降線が最適等高線曲線と交差する点を特定する。
この点は、望ましい最適応答を得るために実験を実施すべきだった場所に関する「最善の推測」を表す。

#### 動機
洞察を深めることに加え、ほとんどの実験には応答を最適化するという目標がある。
つまり、応答が最適化される設定(*X*<sub>10</sub>, *X*<sub>20</sub>, ...,*X*<sub>*k*0</sub>) を特定することである。

この目標を達成するために最適な道具がDOE等高線図である。
因子 *X*<sub>*i*</sub> と *X*<sub>*j*</sub> の対について、DOE等高線図は3次元応答曲面 *Y* = *f*(*X*<sub>*i*</sub>, *X*<sub>*j*</sub>) を 2次元で表現したものである。
DOE等高線図上の等曲線の位置や間隔は、その曲面の性質を容易に解釈できる形で反映している。

DOE等高線図の作成に関して、以下の3点に留意する必要がある。


1. 因子対：DOE等高線図には必然的に 2軸（のみ）であるため、*k* 因子のうち2つだけがこの図に表すことができる。
他のすべてのDOE等高線図は、固定値に設定されなければならない（その最適設定は、[順序付きデータ・プロット](pri591.md)、[DOE平均プロット](pri593.md)、および[交互作用効果行列プロット](pri594.md)によって決定する）。
2. 最も重要な因子対：作成可能なDOE等高線図は多数ある。
*k* 因子を有する実験の場合、$` \left( \begin{array}{c}　k \\ 2　\end{array} \right)　\frac{k!} {2!(k-2)!} = \frac{k(k-1)}{2} `$　種類の等高線プロットが考えられる。
例えば、*k* = 4 のDOE等高線図の場合、 6種類の等高線プロットが考えられる：　*X*<sub>1</sub> と *X*<sub>2</sub>、 *X*<sub>1</sub> と *X*<sub>3</sub>、*X*<sub>1</sub> と *X*<sub>4</sub>、 *X*<sub>2</sub> と *X*<sub>3</sub>、*X*<sub>2</sub> と *X*<sub>4</sub>、 *X*<sub>3</sub> と *X*<sub>4</sub>。
実際には、通常、最も重要な 2つのDOE等高線図を含む 1つの等高線図のみを作成する。
3. 主効果のみ：等高線図の軸は主効果のみであり、交互作用は適用されない。
理由は、この手順の「成果物」が　*k* 設定、すなわち *k* のDOE等高線図それぞれに対する最適な設定であるためである。
これらの *k* のDOE等高線図は実際であり、制御可能であるため、最適な設定を生産に活用することができる。
交互作用は性質が異なり、交互作用を「－」または「＋」に設定できるような「機械のつまみ」は存在しない。
したがって、等高線図の軸候補となるのは主効果のみで、交互作用は含まれない。

要約すると、DOE等高線図が有用とされる理由は、応答曲面の性質に関する洞察を与え、「応答を最適化するためには、（他に）どこでデータを収集すべきだったか」という問いに対して具体的な答えを提供するために使いやすいグラフであるという点にある。

#### 欠陥ばねに関するデータの結論
欠陥ばねデータ集合にDOE等高線図を適用した結果、以下の結論が得られた。

1. 「次の」の実行における最適設定：  
符号化：(*X*<sub>1</sub>, *X*<sub>2</sub>, *X*<sub>3</sub>) = (+1.5, +1.0, +1.3)

2. 応答曲面の性質：  
*X*<sub>1</sub> \* *X*<sub>3</sub> 交互作用が重要であることから、因子 *X*<sub>1</sub> 効果は、因子 *X*<sub>3</sub> 設定によって変化する。
