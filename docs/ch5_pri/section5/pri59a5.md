# 5.5.9.10.5. 解釈方法：最急上昇／下降

#### 最適な角点から開始
[最適な角点](pri59a4.md)から、その角における等高線面の性質に基づいて、最大化の場合は最急上昇方向へ、最小化の場合は最急下降方向へと進む。

#### 欠陥ばねの例
欠陥ばねの問題における目標は応答を最大化することであるため、最急上昇経路を探す。
出発点は、平均応答値が 88.5 である最良の角（右上隅 (+, +)）である。
この等高線図の[等高線間隔](pri59a.md#plot)は5単位である。
等高線図上で左から右へ移動するにつれ、等高線は応答値の低い方から高い方へと変化する。
図中では、最大応答値である 105 の等高線を太線で示している。
識別しやすくするため、90 の等高線も太い線で描いている。
この 90 の等高線は、最適な角のすぐ右側に位置している。

#### 欠陥ばねの例に関する「最急上昇法」の結論
(+, +)付近の等高線の形状は、最急上昇経路を示す。

1. 「北東」方向
2. 水平面から約30度上
