# 5.5.3.1.3. 単応答：ステップ長の選択

#### 次の試行での最大勾配方向長さを選択するための手順
探索方向が決定したら、第1フェーズにおいて必要な2つ目の決定事項は、その方向へ「移動」させる過程の程度に関するものである。
ステップ長を選択する最も一般的な手順は、ある因子についてステップ長を選択し、その後、他の因子について、係数推定値に比例したステップ長を計算する。
これにより、改善が最大となる方向上の点が得られる。
この手順を以下に示する。
同様の手法は、以下の式において *ρ* の値を増加させていくことで得られる。

$$x_i^* = \rho \frac{b_i}{\sqrt{\sum_{j=1}^k {b_j^2}}} \qquad i = 1, 2, \ldots , k$$

ただし、以下の手順では符号化された「距離」である *ρ* よりも扱いやすい元の測定単位を考慮している。

**手順：ステップ長の選択**

#### ステップ長の選定手順
ステップ長の選定手順は以下の通りである。

1. ある因子 *j* に対し、ステップ長 Δ*X*<sub>*j*</sub>（自然単位系）を選択する。
通常、因子 *j* は、技術者が変更しやすいと感じるもの、または |*bj*| が最大となるものとして選択する。
Δ*X*<sub>*j*</sub> の値は、最急上昇／下降方向を取り囲む信頼錐の幅に基づいて決定する。
円錐が非常に広い場合は、推定された最急上昇／下降方向が信頼できないことを示し、したがって、Δ*X*<sub>*j*</sub> を小さくすべきである。
これは通常、*R*<sup>2</sup> 値が低い場合に発生する。
そのような場合、より良いモデル適合とより適切な探索方向を得るために、現在の実験領域内で追加の実験を行うこと。
2. 符号化単位への変換
$$\Delta x_j = \frac{\Delta X_j}{s_j}$$
<br><br>
ここで、*s*<sub>*j*</sub> は因子 *j* (例： *s*<sub>*j*</sub>= range<sub>*j*</sub>/2) に用いられる尺度係数を表す。
3. 他の因子 *i* すべてに $`\Delta x_i = \frac{b_i}{b_j} \Delta x_j`$ を設定する。
4. すべての *x*<sub>*i*</sub> を自然単位に変換する。

$$\Delta X_i = (\Delta x_i)(s_i)$$ 

**例：ステップ長選択**

#### ステップ長の選択例
以下に、ステップ長の選定手順の例を示す。

* [前述](pri5311.md#Example.-Optimization-of-a-Chemical)の化学工程実験について、工程技術者は、$`\Delta X_2 = 50`$ 分を選択した。
これは、工程工学上の考慮に基づいたものである。
また、$`\Delta X_2 = 50`$ とすれば、工程が現在の実験領域から過度に逸脱することはないと見なされた。
これは、適合モデルの *R*<sub>*2*</sub> 値が 0.6580 とかなり低いため、信頼性の低い最急上昇方向（および広範な信頼錐、[技術的付録 5B](pri5312.md#技術付録-5B)を参照）しか得られないことから、望ましいことだった。

* $`\Delta x_2 = \frac{50}{50} = 1.0`$ 
* $`\Delta x_1 = \frac{-1.2925}{11.14} = -0.1160`$ 
* $`\Delta X_2 = (-0.1160)(30) = -3.48^{\circ}C`$ 

したがって、ステップ長は $`\Delta X'= (-3.48 \text{℃, 50分})`$ となる。

**手順：最大改善方向に沿った実験の実施**

#### 最大改善方向に沿った実験を行う手順
以下は最大改善方向に沿って実験を行う手順である。

1. 既存運転条件 $`X_0^' = (X_1, X_2, \ldots , X_k)`$ およびステップ長 $`\Delta X' = (\Delta X_1, \Delta X_2, \ldots , \Delta X_k)`$ が与えられたとき、次の因子水準 $`X_0 + \Delta X, X_0 + 2 \Delta X, X_0 + 3 \Delta X, \ldots`$  で応答変数 $`Y`$ の改善（目的に応じて減少または増加）が観察される限り実験を継続する。
2. 更なる改善が見られなくなった時点で、不適合性を評価するために中心実行を繰り返しながら、新しい1次実験（例：2<sup>k-p</sup> 一部実施要因計画）を実施すべきである。
不適合の有意な証拠がない場合、新しい 1次モデルが新たな探索方向を示し、図5.3 に示すように、次の反復を実行する。
そうでない場合（不適合の証拠がある場合）、実験計画法を拡充し、2次モデルを適合させる。
すなわち、実験者は「第2フェーズ」に進む。 

**例：最大改善方向に沿った実験**

#### 手順 1：因子水準を *δ* だけ増加
**手順 1：** 

*X*<sub>0</sub> = (200℃, 200分) および Δ*X* = (-3.48℃, 50分) であるとき、次の実験を以下の条件で実施した（実用上の理由から、温度のステップ長は -3.5℃ に丸めた）。

|  | *X*<sub>1</sub>| *X*<sub>2</sub>| *x*<sub>1</sub>| *x*<sub>2</sub>| *Y* (= 収率) |  
| :--- | :---: | ---: | :---: | :--: | :---: |  
| *X*<sub>0</sub>| 200 | 200 | 0 | 0 |  |  
| *X*<sub>0</sub>+ Δ*X* | 196.5 | 250 | -0.1160 | 1 | 56.2 |  
| *X*<sub>0</sub>+ 2Δ*X* | 193.0 | 300 | -0.2320 | 2 | 71.49 |  
| *X*<sub>0</sub>+ 3Δ*X* | 189.5 | 350 | -0.3480 | 3 | 75.63 |  
| *X*<sub>0</sub>+ 4Δ*X* | 186.0 | 400 | -0.4640 | 4 | 72.31 |  
| *X*<sub>0</sub>+ 5Δ*X* | 182.5 | 450 | -0.5800 | 5 | 72.10 |  
{: .text-center}
  
目的は *Y* を最大化することであるため、観測された応答が最大となる点は、*X*<sub>1</sub> = 189.5℃、*X*<sub>2</sub> = 350分である。
なお、探索は応答値が 2回連続で低下した後に停止した。
これは、「丘」の「頂点」を確実に通過したことを確認するためである。 

#### 手順2：新しい要因実験
**手順 2：** 

新たな 2<sup>2</sup> 要因実験を *X'* = (189.5, 350) を原点として実施した。
以前と同じ尺度係数を使用すると、新しい尺度調整後の制御可能因子は以下となる。

$$x_1 = \frac{X_1 - 189.5} {30} \qquad \text{および} \qquad x_2 = \frac{X_2 - 350} {50}$$

不適合性を評価するために、5回の中心実行（*X*<sub>1</sub> = 189.5、*X*<sub>2</sub> = 350）を繰り返した。
実験結果は以下の通りであった。

| +1 | -1 | 219.5 | 300 | 51.78 |
