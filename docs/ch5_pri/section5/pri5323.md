# 5.5.3.2.3. 多重応答：数理計画法

#### 他の応答すべてに対して適切な制約の下で主応答を最大化または最小化する数理計画法
多重応答系の解析には、通常、何らかの最適化問題が含まれる。
ある応答を「主」、もしくは最重要応答として選択でき、且つ他の応答すべてに対して上限や目標値を定義する場合には、数理計画法による手法を採用する。
これが不可能な場合は、代わりに望ましさ手法を用いるべきである。

数理計画法では、他の応答すべてに対する適切な制約の下で、主応答を望まれる最大化または最小化する。
2応答（「二重」応答）の場合は、一部の著者によって詳細に研究されており、まずこれについて述べる。
そして、2応答以上の場合について説明する。

* [二重応答系](pri5323.md#二重応答系)
* [2応答以上](pri5323.md#2応答以上) 

**二重応答系**

#### 二重応答系の最適化
二重応答系（DRS）の最適化とは、以下の条件を満たす動作条件 ***x*** を求めることである。

$$\begin{align}
&\text{optimize} \qquad && \hat{Y}_p(x) \\
&\text{subject to} \qquad && \hat{Y}_s(x) = T \\
& && x'x \le \rho^{2}
\end{align}$$ 

ここで、**T** は2次応答の目標値、***p*** は1次応答数（すなわち、最適化対象となる応答）、***s*** は2次応答（すなわち、制約対象となる応答）数を表し、***ρ*** は、探索を行う制御可能因子空間領域を制限する球面制約の半径である。
***ρ*** 値は、実験データが得られた領域から過度に外れた解を回避することを目的として選択すべきである。
例えば、実験計画法が中心複合計画法である場合、***ρ* = *α***（軸間距離）を選択するのが妥当である。
立方体の実験領域を使用する場合（例えば、因子実験を使用する場合など）、代わりに ***L* ≤ *x*<sub>*i*</sub> ≤ *U***という形式の境界を使用することもできる。
なお、2次制約が存在しない場合、リッジ解析問題はDRS問題と関連する。
したがって、DRS用のアルゴリズムやソルバーは、単応答系リッジ解析にも適用できる。

#### DRSに必要な非線形計画法ソフトウェア
DRSでは、応答モデル $` \hat{Y}_p `$ および $` \hat{Y}_s `$ は、線形、2 次、あるいは 3 次の多項式であってもよい。
DRSの最適化には非線形計画法アルゴリズムを使用する必要がある。
特に2次応答の場合、2次応答に対する等式制約、および球面実験領域については大域最適解を保証する専用の最適化アルゴリズムがある。
このような場合、アルゴリズム DRSALG を使用できる（ダウンロード先：http://www.stat.cmu.edu/jqt/29-3）が、Fortran コンパイラが必要である。

#### より一般的な事例
不等式制約や立方体の実験領域といったより一般的なケースでは、汎用非線形ソルバーを使用する必要があり、局所最適解を避けるために複数の初期点を試すべきである。
これについては、次の節で説明する。

**二重応答以上の例**

#### 例：問題設定
推進剤の3成分 **（*x*<sub>1</sub>、*x*<sub>2</sub>、*x*<sub>3</sub>）** の値は、2つの2次応答、燃焼速度の分散 **（*Y*<sub>2</sub>）** およびコスト **（*Y*<sub>3</sub>）** が満足できる水準に保たれることを条件として、1次応答の燃焼速度**（*Y*<sub>1</sub>）** を最大化するよう選択する必要がある。
3成分の合計は混合物の 100％でなければならない。
適合されたモデルは以下の通り。

$$\begin{aligned}
\hat{Y}_1 &= 35.4 x_1 + 42.77 x_2 + 70.36 x_3 + 16.02 x_1 x_2 \\
          &\quad + 36.33 x_1 x_3 + 136.8 x_2 x_3 + 854.9 x_1 x_2 x_3 \\[1.5em]  
\hat{Y}_2 &= 3.88 x_1 + 9.03 x_2 + 13.63 x_3 - 0.1904 x_1 x_2 \\
          &\quad - 16.61 x_1 x_3 - 27.67 x_2 x_3 \\[1.5em]  
\hat{Y}_3 &= 23.13 x_1 + 19.73 x_2 + 14.73 x_3
\end{aligned}$$

#### 最適化問題
したがって、最適化問題は以下となる。

$$\begin{aligned}
& \text{maximize} \qquad && \hat{Y}_1(x) \\
& \text{subject to} \qquad && \hat{Y}_2(x) \le 4.5 \\
& && \hat{Y}_3(x) \le 20 \\
& && x_1 + x_2 + x_3 = 1 \\
& && 0 \le x_1 \le 1 \\
& && 0 \le x_2 \le 1 \\
& && 0 \le x_3 \le 1
\end{aligned}$$ 

#### 解
解は **(*x\**)' = (0.212, 0.343, 0.443)** であり、これにより $` \hat{Y}_1 = 106.62 `$、$` \hat{Y}_2 = 4.17 `$、および$` \hat{Y}_3 = 18.23 `$ となる。
したがって、2つの2次応答はいずれも指定された上限値を下回っている。
局所最適解を避けるため、最適化は様々な初期値を用いて実施すべきである。
また、推定された最適運転条件において、検証実験を行う必要がある。

最適化問題の解は、[Rコード](https://www.itl.nist.gov/div898/handbook/pri/section5/pri5323.r)を用いて求めることができる。
