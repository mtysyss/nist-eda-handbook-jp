# 5.5.9.9.4. 動機：項の追加を止めるタイミングの判断方法
#### ホッケー・スティック形状を示す累積残差標準偏差のプロット
左から右へと進むに従いモデルに項を追加していくと、累積残差標準偏差の「曲線」は通常、減少していく。
最初（左側）は、効果の大きい項を追加していくに従い、ある残差標準偏差から次の残差標準偏差への減少幅は大きくなる。
その後、改善の度合い（減少）は徐々に鈍化する傾向にある。
ある時点で、改善の度合いは通常、緩やかになる。
そして、外観上、このような曲線が「ホッケー・スティック」形状を示すのは非常に典型的である。

1. 最初は、連続する残差標準偏差の間で一連の大きな減少が見られ、
2. その後 エルボに達し、 
3. そして、一連の緩やかな減少となる。

#### 停止規則
累積残差標準偏差プロットは、次の問い視覚的な答えを示し、

　　どのようなモデルが適切か。

には、関連する次の問いへの答えを通じて示す。

　　累積モデルへの項の追加は、いつ停止すべきか。

グラフからの項の追加を停止する最も一般的な規則は、「エルボ」に到達した時点で直ちに停止することである。
エルボ点まで（その点を含む）のすべての項を含めるのは、これらの各項が残差標準偏差を大幅に減少させたためである。
しかし、それ以降の項は、残差標準偏差をモデルに含める価値があるほど十分に速く減少させないため、除外する。
