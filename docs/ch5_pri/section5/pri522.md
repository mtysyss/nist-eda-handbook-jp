# 5.5.2.2. 計画の修正

#### 古典的計画の修復や拡張
コンピュータ支援計画は、既存実験計画を修正したり、拡張したりするのに役立つ。
また、これを利用して、「機能しない」標準的古典的計画を修正することもできる。

#### 喪失や達成不可能な実行が含まれる元の計画行列
不適切な計画や他の問題により、元の計画行列に、禁止、あるいは到達不可能な因子設定の組合せが含まれている場合がある。
コンピュータ支援計画（例えば、[D-最適計画](pri521.md)）を利用し、元の計画のうち達成不可能な実行を「置き換える」ことができる。
元計画の実現可能な実行は「包含」実行として標記され、最終的なコンピュータ支援計画に含まれることになる。

#### コンピュータ支援計画（CAD）での実現可能な追加実行案の生成
あらかじめ指定されたモデルが与えられれば、コンピュータ支援計画（CAD）は、対象モデルを推定するために必要な、追加の達成可能な実行を生成することができる。
その結果、コンピュータ支援計画は、元計画においては実施不可能であった実験を実施可能な新しい実験集合に置き換えるだけであり、それによって実験者は依然として、実験から各要因に関する情報を得られる。

#### 当初計画の特性には及ばないことがある最終計画特性
この最終的な計画の特性は、おそらく元の計画の特性とは比較にならないものであり、推定値の間に何らかの相関関係が存在する可能性がある。
しかし、分析にどのデータも利用できないという事態を避けるために、コンピュータ支援計画（例えばD最適計画）を用いて代替実験を生成することで、データの分析を可能にする。
さらに、コンピュータ支援計画を用い、古典的計画に、モデル内項間の別名連鎖を解消したり、曲線効果の推定を可能にしたりする処理組合せを追加することができる。
