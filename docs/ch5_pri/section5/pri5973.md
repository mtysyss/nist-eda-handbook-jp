# 5.5.9.7.3. 数値的有意性

#### 最大効果の10％
最も高い棒グラフの高さ（＝最大効果の大きさ）に注目する。
**最大**効果の 10％を超える効果はすべて「有意」とみなす。
この 10％という数値は恣意的であり、統計的（あるいは工学的）根拠はないが、最大効果とその 90％以内の効果をすべて含める結果という点で、「数値的」な根拠はある。

#### 適用時の注意
他の経験則と同様、この基準を適用するときは、ある程度の注意を払う必要がある。
具体的には、最大の効果が実際にはそれほど大きくない場合、この経験則は役に立たないことがある。
