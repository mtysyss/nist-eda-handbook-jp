# 5.5.3.2. 複数回答の事例

#### 複数の解決策がある場合、それらをすべて
同時に最適化することは多くの場合不可能であり、何らかのトレードオフが必要となる複数の応答がある場合、すべての応答を同時に最大化（あるいは必要に応じて最小化）する工程運転条件を見つけることは非常に困難であり、多くの場合不可能である。
ほぼ必然的に、工程エンジニアは、ほとんどの（できればすべての）応答変数にとって満足のいく工程運転条件を見つけるために、何らかのトレードオフを行わなければならない。
この小節では、こうしたトレードオフを行うための効果的な方法をいくつか検討する。
