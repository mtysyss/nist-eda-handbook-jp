# 5.5.3.2. 多重応答の事例

#### すべて同時の最適化はほぼ不可能であり、トレードオフが必要となる多重応答
多重応答の場合、すべての応答を同時に最大化（あるいは必要に応じて最小化）する工程運転条件を見つけることは非常に困難であり、多くの場合不可能である。
ほぼ必然的に、工程技術者は、ほとんどの（できればすべての）応答変数が満たされる工程運転条件を見つけるために、何らかの妥協を行わなければならない。
この小節では、こうした妥協を行うための効果的な方法をいくつか検討する。
