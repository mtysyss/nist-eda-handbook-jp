# 5.5.9. 実験計画法に対するEDA手法

#### はじめに
この節では、計画された実験から得られたデータを分析するための、[探索的データ解析（EDA）](../../ch1_eda/eda.md)手法について解説する。
この内容は、[本章の4節](../section4/pri4.md)で示されている、よりモデルに基づいた実験計画法の分析手法を補完するものであり、それに取って代わるものではない。
適切な計画の選択については、[本章の3節](../section3/pri3.md)で詳細に記述している。 

#### 問題の分類
ここで取り上げる問題の分類は、「スクリーニング問題」である。
スクリーニング問題には、次の2つの特徴がある。

1. 考慮すべき要因は多数ある。
2. これらの要因それぞれは連続型もしくは離散型のいずれかである。

#### 期待される出力
スクリーニング問題の分析から得られる望ましい結果は、以下の通り。

* 因子の重要度順にランク付けされた一覧
* 各因子に対する最適な設定
* 優れたモデル
* 洞察

#### 問題の基礎
スクリーニング問題の基礎は以下の通り。

* *k* 因子があり、*n* 観測値がある。
* 一般的なモデルは以下の通り。

$$Y = f(X_1,X_2,\ldots,X_k) + \epsilon$$

#### 計画の種類
特に、EDA手法は、2<sup>*k*</sup> の[完全実施](../section3/pri333.md)および 2<sup>*k*-*p*</sup> [一部実施](../section3/pri334.md)要因計画に適用される。

EDA手法は、スクリーニング計画に特に適している。
これは、我々がまだ工程を理解する初期段階にあるためである。 

#### EDAの哲学
EDAは単一の技法ではない。
これは、データを分析するための手法である。

* EDAはデータ駆動型である。
つまり、初期モデルを前提とせず、むしろ、データそのものが語るままに任せるよう努める。
* EDAは問いに基づく。
つまり、1つ以上の問いに答えるために、適切な技法を選択する。
* EDAは、単一技法に依存するのではなく、複数の技法を活用する。
プロットごとに基礎となる考え方、焦点、感度が異なり、データの異なる側面を浮き彫りにする。
複数の技法により結論が重複する場合、その結論が妥当であるという確信が深まる。
一方、結論が矛盾する場合には、それがデータの性質に関する手がかりとなる。
* EDAツールの多くは図表現である。
主な目的は、データに対する洞察を提供することであり、可視化技法は定量的技法よりも容易にその洞察をもたらすことが多い。

これらのプロットはそれぞれ、以下の様式で示す。

* プロットの目的
* プロットの出力

* プロットの解釈方法に関する考察
* スプリング欠陥のデータからプロットを通じて導き出せる結論

**データ集合**

#### 欠陥のあるばねのデータ
この節で示すグラフは、[Box and Bisgaard (1987)](../section8/pri8.md#BoxBis)のデータ集合を用いて作成されている。
このデータは、2<sup>3</sup> の完全実施要因データ集合に由来するもので、以下の変数を含んでいる。

1. 応答変数 *Y* = ひび割れのないばねの百分率
2. 因子1 = 炉内温度（2水準：1450および1600 F）
3. 因子2 = 炭素濃度（2水準：0.5% および 0.7%）
4. 因子3 = 急冷温度（2水準：70および120 F）
