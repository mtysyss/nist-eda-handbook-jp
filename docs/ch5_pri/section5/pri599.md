# 5.5.9.9. 累積残差標準偏差プロット

#### 目的
累積残差 sd（標準偏差）プロットは、次の問いに答える。

このデータに適したモデルとは何か。

これまでの分析流れの 8手順では、次の重要な目標2つに取り組んできた。

1. 因子：応答に影響を与える最重要因子の特定
2. 設定：これらの因子に対する最適設定の特定

上記に加えて、3つ目の目標も注目に値する。

3. モデル：観測された応答 *Y* と、さまざまな主効果および交互作用を関数で関連付けるモデル（すなわち予測式）の特定

このような関数は、個々の因子がすべて連続型かつ順序（温度、圧力、湿度、濃度など）である場合に特に有意義であり、一方、因子のいずれかが離散型かつ非順序（プラント、作業者、触媒、供給業者など）である場合には当てはまらない。

連続型因子の場合では、分析者は次の目的でこの関数を利用する。

1. 再現性／平滑化：観測された計画点における応答の予測
2. 補間：計画点間（観測されていない）領域における応答の予測
3. 外挿：計画点を超えた（観測されていない）領域における応答の予測

離散因子の場合も、以下で説明する関数を導出するために開発された手法は依然として適用可能であり、その結果得られるモデルは再現性に利用できる。
ただし、補間および外挿の観点は適用されない。

モデル化において、*k* の因子 *X*<sub>1</sub>, *X*<sub>2</sub>, ..., *X*<sub>*k*</sub> における予測値

$$ \hat{Y} = f(X_1, X_2, \ldots , X_k) $$

が観測された生データ値 *Y* に「近く」なる関数 $` f `$ を求める。
この目的のために、2つの課題がある。

1. 適切な関数形式 $` f `$ を決定する。
2. 関数 $` f `$ の係数に対する適切な推定値を決定する。

例えば、*X*<sub>1</sub> と *X*<sub>2</sub> という2つの因子があるとき、目標は以下である。

1. ある関数 $` f(X_1, X_2) `$ を決定する。
2. $` f `$ の係数を推定する。

その結果得られるモデルが、観測された応答値 *Y* に可能な限り近い予測値 $` \hat{Y} `$ を与える。
もし形式 $` f `$ が適切に選択されていれば、良好なモデルが得られ、そのモデルは、差分（$` \text{「残差」} = Y - \hat{Y} `$) が均一にゼロ付近に分布するという特徴を持つ。
一方、不適切なモデル（関数形 $` f `$ の選択が不適切な場合）は、一部あるいはすべての残差が「大きい」という特徴を持つ。

与えられたモデルにおいて、*n* 残差の典型的な大きさを用いて適合の質を要約する統計量は以下の残差標準偏差である。

$$ s_{res} = \sqrt{\frac{\sum_{i=1}^n{r_i^2}}{n-p}} $$

ここで、*p* はモデル内の項数（定数項を含む）を *r* は *i* 番目の残差を表す。
また、残差平均がゼロであることを仮定しているが、これは定数項を含むモデルを最小二乗法で推定する場合に当てはまる。

モデルの適合度が良ければ、*s*<sub>*res*</sub> は小さくなる。
モデルの適合度が低ければ、*s*<sub>*res*</sub> は大きくなる。

特定のデータ集合に対して、提案された各モデルにはそれぞれ独自の適合度があり、したがって独自の残差標準偏差を持つ。
明らかに、残差標準偏差は、データを記述するよりもむしろモデルを記述する指標である。
「性質」がデータを作り出すのに対し、モデルを作り出すのは分析者である。
理論的には、同じデータ集合に対して、分析者が無限に多くのモデルを提案することも可能である。

しかし実際には、分析者は一般的に検討対象として妥当性のある少数の有限なモデルのみを提示する。
各モデルにはそれぞれ固有の残差標準偏差がある。
累積残差標準偏差プロットとは、単に、さまざまなモデルにおけるこれらの残差標準偏差の集合をグラフ化したものである。
このプロットの利点は以下の通り。

1. 優れたモデルと劣ったモデルを区別できる。
2. 単純な優れたモデルと複雑な優れたモデルを区別できる。

要約すると、累積残差標準偏差プロットは、どのモデルが不適切（最も望ましくない）かを評価するのに役立つ。

1. どのモデルが劣っているか（最も望ましくないか）。
2. どのモデルが優れているが複雑であるか（より望ましいか）。
3. どのモデルが良好かつ単純（最も望ましい）か。

#### 出力
累積残差標準偏差プロットから得られる結果は以下の通り。

1. 主：付加的定数に加え、最重要主効果および交互作用から構成される、適合の良い予測式
2. 副：この適合の良いモデルの残差標準偏差。

#### 定義
累積残差標準偏差プロットは以下の条件で作成される。

1. 縦軸：一連の漸進的に複雑化する適合モデルの（最大から最小）順序付き残差標準偏差。
2. 横軸：線形モデルに最後に組み込まれた項の因子／交互作用識別： 
    1 は因子 *X*<sub>1</sub> を示し、  
    2 は因子 *X*<sub>2</sub> を示し、  
    …  
    12 は 2因子交互作用 *X*<sub>1</sub>\* *X*<sub>2</sub> を示し、  
    123 は 3因子交互作用 *X*<sub>1</sub>\* *X*<sub>2</sub>\* *X*<sub>3</sub> を示す、  
    など。  
3. 右端の余白：因子／交互作用の識別（組み込みの冗長性）：   
    1 は因子 *X*<sub>1</sub> を表し、  
    2 は因子 *X*<sub>2</sub> を表し、  
    …  
    12 は 2因子交互作用 *X*<sub>1</sub>\* *X*<sub>2</sub> を表し、  
    123 は 3因子交互作用 *X*<sub>1</sub>\* *X*<sub>2</sub>\* *X*<sub>3</sub> を表す、  
    など。  
    計画が一部実施因子計画である場合、主効果および 2因子交互作用について交絡構造が示される。

したがって、累積残差標準偏差プロットは、選択された一連の漸進的に複雑な線形モデルに対する残差標準偏差を最大から最小へと並べた、パレート式のグラフでの要約である。

このプロットは、左から右へと、定数項のみを含むモデルから、残りの因子および交互作用を1つずつ順次追加して拡張したモデルを示している。
各因子および交互作用は、加法的（乗法、対数、または累乗などの形式ではなく）方法でモデルに組み込まれる。
どの段階においても、モデルに次に追加される項の順序は、結果として生じる残差標準偏差が最大となるように決定される。

#### 解釈の方法
[動機節の質問4](pri5994.md)で詳述した通り、累積残差標準偏差の「曲線」は、モデルに項を追加していくに従い、左から右へと減少していく特徴がある。
この漸進的な改善（減少）は、重要因子が追加される初期段階では大きくなる傾向があり、その後、重要度の低い因子が追加される終盤では減少幅はごくわずかになる傾向がある。

すべての項を含めれば、完全適合（残差標準偏差＝0）が得られるが、モデルが扱いにくくなる。
一方、最初の項（平均）のみ含めれば、単純なモデル（項が1つだけ！）が得られるが、通常は適合度が低くなる。
統計理論に基づいて形式的な定量的停止規則を策定することも可能であるが、それほど厳密ではない（しかし有効な）代替の停止規則として、グラフで、使いやすく、実務上も非常に効果的なものが以下である。

* 曲線の「L型」に遭遇するまで、モデルに項を追加し続ける。
「L型点」とは、曲線の傾き（減少率）が一貫して、明らかに緩やかになる値のことである。
L型点まで（その点を含む）のすべての項を含める（結局のところ、これらを含めた各項は残差標準偏差を大幅に減少させている）。
L型点**以降の**項は、いずれも、残差標準偏差を非常に緩やかにしか減少させないため、「維持する手間をかける価値がない」ものであり、すべて除外する。

欠陥ばねデータの残差標準偏差プロットから以下を確認する。

1. 「基準」モデルの残差標準偏差（rsd）

$` \hat{Y} = \bar{Y} = 71.25 `$ 

は *s*<sub>*res*</sub> = 13.7 である。
2. 次項の *X*<sub>1</sub> を追加すると、rsd は約 7単位（13.7 から 6.6 へ）低下する。
3. 項 *X*<sub>1</sub>\* *X*<sub>3</sub> を加えると、 rsd はさらに 3単位低下する（6.6 から 3.4 へ）。
4. 項 *X*<sub>2</sub> を追加すると、rsd はさらに 2単位（3.4 から 1.5 へ）低下する。
5. 項 *X*<sub>3</sub> を追加した場合、 rsd の減少幅（約 1.5 から 1.3 へ）はごくわずかである。
6. その後、最後では rsd の総減少幅は わずか 1.3 から 0 となる。

手順5 において、効果の大きさが等しい場合（*X*<sub>3</sub> 効果が *X*<sub>1</sub>\* *X*<sub>2</sub> 交互作用効果と等しい場合）、交互作用効果よりも主効果をまた高次交互作用効果よりも低次交互作用効果を先に含めることを優先することに留意する。

この場合、残差標準偏差曲線の「折れ目」は *X*<sub>2</sub> 項の位置にある。
それ以前に追加されたすべての項（*X*<sub>2</sub>を含む）が rsd を大幅に低減させていた（7、次に 3、次に 2）。
*X*<sub>2</sub> を追加後は、残差標準偏差の減少幅は小さく（すべて1未満）：0.2、次に0.8、次に0.5、そして0。

したがって、この事例で最終的に推奨されるモデルは *p* = 4項からなる：

1. 平均
2. 因子 *X*<sub>1</sub>
3. *X*<sub>1</sub>\* *X*<sub>3</sub> 交互作用
4. 因子 *X*<sub>2</sub>

したがって、推定されたモデルは以下の形をとる。

$` \hat{Y} = \bar{Y} + B_1X_1 + B_{13}X_1X_3 + B_2X_2 `$

このモデルの係数に対する最小二乗推定値は次の通り。

$` \hat{Y} `$ = 71.25  
*B*<sub>1</sub>= 11.5  
*B*<sub>13</sub> = 5  
*B*<sub>2</sub> = -2.5  

*B*<sub>1</sub>= 11.5、*B*<sub>13</sub>= 5、および*B*<sub>2</sub>= -2.5 という最小二乗推定値は、当然ながら、推定された効果 *E*<sub>1</sub>= 23、*E*<sub>13</sub> = 10、および *E*<sub>2</sub>= -5 の半分である。
効果量は、$` \hat{Y}(+1) - \hat{Y}(-1) `$ として計算され、推奨される 10段階の DOE 解析手順の[手順7](pri597.md)で既に導出されている。

したがって、最終的に適合されたモデルは

$` \hat{Y} = 71.25 + 11.5 X_1 + 5 X_1X_3 - 2.5 X_2 `$

この予測式を計画点8つに適用すると、予測値 $` \hat{Y} `$ はデータ *Y* に近くなり、残差($` Res = Y - \hat{Y} `$)はゼロに近い値となる。

| *X*<sub>1</sub> | *X*<sub>2</sub> | *X*<sub>3</sub> | *Y* | $` \hat{Y} `$ | *Res* |  
| :---: | :---: | :---: | :---: | :---: | :---: |  
| - | - | - | 67 | 67.25 | -0.25 |  
| + | - | - | 79 | 80.25 | -1.25 |  
| - | + | - | 61 | 62.25 | -1.25 |  
| + | + | - | 75 | 75.25 | -0.25 |  
| - | - | + | 59 | 57.25 | +1.75 |  
| + | - | + | 90 | 90.25 | -0.25 |  
| - | + | + | 52 | 52.25 | -0.25 |  
| + | + | + | 87 | 85.25 | +1.75 |  
{: .no-border-table}

残差標準偏差の計算：

$$ s_{res} = \sqrt{ \frac{\sum_{i=1}^n{r_i^2}} {n-p} } $$

ここで、*n* = 8 のデータ点、*p* = 4 の推定係数（平均値を含む）を代入すると、

$$ s_{res}= 1.54 \qquad \text{(小数点以下1桁に丸めると1.5)} $$

*s*<sub>*res*</sub> = 1.54 の詳細な計算過程をたどると元の点に戻り、1.54 は累積残差標準偏差プロットにおいて *X*<sub>3</sub> 項上に示される値である。 


#### 欠陥ばねに関するデータの結論
欠陥ばねのデータ集合に累積残差標準偏差プロットを適用した結果から以下の結論が得られる。

1. 適合度が高く、簡潔な（定数＋3項）モデル：   
$$ \hat{Y} = 71.25 + 11.5 X_1 + 5 X_1X_3 - 2.5 X_2 $$  
2. このモデルの残差標準偏差（モデルの適合度を測る指標として）：  
$$ s_{res} = 1.54 $$
