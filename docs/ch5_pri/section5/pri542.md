# 5.5.4.2. 単体格子計画

#### 単体格子点の定義
*q* 成分に対する {*q, m*} 単体格子計画は、以下の座標設定によって定義される点で構成される。
各成分がとる比率は、0 から 1 までの範囲で等間隔に配置された *m*+1 個の値を取り、

$$x_i= 0, 1/m,2/m, ..., 1 \quad \text{for} \quad i= 1, 2, ..., q$$

また、この式から得られる割合の可能なすべての組合せ（混合）が用いられる。

#### 中心点を除いた計画点すべては単体境界上
標準的な単体格子および単体中心計画（後述）は境界点計画であり、全体的な重心点を除き、すべての計画点は単体の境界上に配置される。
内部領域での予測に関心がある場合、単体型計画に内部の計画点を追加することが極めて望ましい。

この例では、*q* = 3、*m* = 3である。

単体格子における計画点の数は、(*q*+*m*-1)!/(*m*!(*q*-1)!) である。 

#### 混合実験で使用される標準多項式モデルの定義
ここで、混合実験のデータに適合させることができる多項式モデルの形式について考える。
制約条件 *x*<sub>1</sub>+ *x*<sub>2</sub>+ ... + *x*<sub>*q*</sub>= 1 があるため、混合実験のデータに適合させる回帰関数の形式は、従来の多項式適合とは多少異なり、しばしば正準多項式と呼ばれる。
その形式は、{*q*, *m*} 単体格子計画の各点で収集されたデータに適合させることができる回帰関数の一般形を用い、この関数に *x*<sub>*i*</sub> 項間の依存関係を代入することで導出される。
 {*q*, *m*}多項式の項の数は、前述の通り、(*q*+*m*-1)!/(*m*!(*q*-1)!) である。
これは、対応する {*q*, *m*} 単体格子計画を構成する点の数に等しい。

#### {*q*, *m*=1} の単体格子計画の例
例えば、{*q*,*m*=1} の単体格子計画によるデータ点に適合させることができる式は、

$` E(Y) = \beta_0 + \beta_1 x_1 + \cdots + \beta_q x_q `$

*β*<sub>0</sub> に (*x*<sub>1</sub> + *x*<sub>2</sub> + ・・・ + *x*<sub>*q*</sub> = 1) を掛け、得られる式は

$` E(Y) = \beta_1^{\star} x_1 + \cdots + \beta_q^{\star} x_q `$

ここで、すべての *i* = 1, ..., *q* について、$` \small \beta_i^{\star} = \beta_0 + \beta_i `$ である。  

#### 1階正準形
これは、一階混合モデルの正準形と呼ばれる。
一般に、混合モデル正準形（母数からアスタリスクを除いたもの）は以下の通りです：

#### 標準混合モデルのまとめ

$$
\begin{aligned}
\text{1次} & \quad E(Y) = \sum_{i=1}^q \beta_i x_i \\[1.5em]
\text{2次} &  \quad E(Y) = \sum_{i=1}^q \beta_i x_i +\sum_{i=1}^q \sum_{i < j}^q \beta_{ij} x_i x_j \\[1.5em]  
\text{3次} &  \quad \begin{aligned}
E(Y) = & \sum_{i=1}^q \beta_i x_i +\sum_{i=1}^q \sum_{i < j}^q \beta_{ij} x_i x_j + \\
& \sum_{i=1}^q \sum_{i < j}^q \delta{ij} x_i x_j (x_i - x_j) + \\
& \sum_{k=1}^q \sum_{j < k}^q \sum_{i < j}^q \beta_{ijk} x_i x_j x_k 
\end{aligned} \\[1.5em] 
\text{特殊3次} & \quad \begin{aligned} 
E(Y) = & \sum_{i=1}^q \beta_i x_i +\sum_{i=1}^q \sum_{i < j}^q \beta_{ij} x_i x_j + \\
& \sum_{k=1}^q \sum_{j < k}^q \sum_{i < j}^q \beta_{ijk} x_i x_j x_k
\end{aligned}  
\end{aligned}
$$

#### 線形調合部分
正準混合多項式の項には単純な解釈がある。
幾何学的には、上記式における母数 *β*<sub>*i*</sub>は、純粋な混合 *x*<sub>*i*</sub> = 1, *x*<sub>*j*</sub> = 0, *i* ≠ *j* に対する期待応答を表し、頂点 *x*<sub>*i*</sub> = 1 における混合曲面の高さである。
上記各多項式のうち、

$$ \sum_{i=1}^q \beta_i x_i $$  

で与えられる部分は、線形調合部と呼ばれる。
調合が厳密に加法的である場合、上記の線形モデル形式は適切なモデルである。

#### 3成分混合物の例
以下の例は Cornell[(1990)](../section8/pri8.md#Cornell)に掲載されているもので、3成分の混合問題から成る。
3成分は、ポリエチレン（*X*<sub>1</sub>）、ポリスチレン（*X*<sub>2</sub>）、およびポリプロピレン（*X*<sub>3</sub>）であり、これらが混合されて繊維が形成され、それが紡績されて糸になる。
製品開発担当者はこれら3材料の純物質と2成分調合物のみに関心を持っている。
対象とする応答変数は、加えた力のkg当たりの糸の伸びである。
調合工程を調査するために、{3,2}単体格子計画が用いらる。
単体領域と実験計画実行 6点が下図に示されている。
実験計画と観測された応答値は表5.4 にまとめられている。
各純物質調合品について、2回の反復測定が行われた。
2成分調合品については、3回の反復測定が行われた。
一意の計画実行6点に対して、計15件の観測データがある。

#### 結果の解釈
出力の係数推定部には、モデル内各係数に対する個別 t-検定結果が記載されている。
3交差項（*X*<sub>1</sub>\* *X*<sub>2</sub>、*X*<sub>3</sub>\*X*<sub>1</sub>、*X*<sub>3</sub>***\* *X*<sub>2</sub>）はいずれも有意であり、これは2次項の適合が有意であることを示している。

#### 適合2次モデル
適合された2次混合モデルは以下の通り。 

$$ \small \hat{y} = 11.7 x_1 + 9.4 x_2 + 16.4 x_3 + 19.0 x_1 x_2 + 11.4 x_1 x_3 - 9.6 x_2 x_3 $$ 

#### 適合2次モデルの結論
b<sub>3</sub> > b<sub>1</sub> > b<sub>2</sub> であることから、成分3（ポリプロピレン）が最も高い伸び率を持つ糸を生成すると結論づけられる。
さらに、b<sub>12</sub> および b<sub>13</sub> が正の値であるため、成分1 と 2、あるいは成分1 と 3 をブレンドすると単なる純ブレンドの伸び率を平均化した場合よりも高い伸び率を与える。
これは「相乗的」な調合効果の一例である。
一方、b<sub>23</sub> が負であるため、成分2 と 3 は拮抗的な調合効果を示す。
