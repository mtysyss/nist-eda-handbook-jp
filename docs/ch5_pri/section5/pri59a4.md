# 5.5.9.10.4. 解釈方法：最適角点

#### 2因子2水準を表す4つの角
等高線図には、最も重要な2因子 *X*<sub>*i*</sub> および *X*<sub>*j*</sub>について、4つの「角」（2因子に、各因子ごとの2設定を掛けたもの）が現れる：(*X*<sub>*i*</sub>, *X*<sub>*j*</sub>) = (-, -), (-, +), (+, -),または (+, +)。
この4つの「角」のうち、どれが最も高い平均応答値 $` \bar{Y} `$ を与えるか。
つまり、「最適な角」はどれか。

#### 生データの使用
これは、生データを用いて2つの「軸因子」を抽出し、4つの角点それぞれにおける平均応答値を計算した後、平均値が最も良い角点を選択する。

欠陥ばねデータの生データは 

| *X*<sub>1</sub> | *X*<sub>2</sub> | *X*<sub>3</sub> | *Y* |  
| :---: | :---: | :---: | :---: |  
| - | - | - | 67 |  
| + | - | - | 79 |  
| - | + | - | 61 |  
| + | + | - | 75 |  
| - | - | + | 59 |  
| + | - | + | 90 |  
| - | + | + | 52 |  
| + | + | + | 87 |  
{: .no-border-table}


プロット軸2本は *X*<sub>1</sub> と *X*<sub>3</sub> であることから、関連する生データは以下に集約される。

| *X*<sub>1</sub> | *X*<sub>3</sub> | *Y* |  
| :---: | :---: | :---: |  
| - | - | 67 |  
| + | - | 79 |  
| - | - | 61 |  
| + | - | 75 |  
| - | + | 59 |  
| + | + | 90 |  
| - | + | 52 |  
| + | + | 87 |  
{: .no-border-table}

#### 平均値
これにより、平均値が得られる

| *X*<sub>1</sub> | *X*<sub>3</sub> | *Y* |  
| :---: | :---: | :---: |  
| - | - | (67 + 61)/2 = 64 |  
| + | - | (79 + 75)/2 = 77 |  
| - | + | (59 + 52)/2 = 55.5 |  
| + | + | (90 + 87)/2 = 88.5 |  
{: .no-border-table}
 
これら角点4つの平均値は、[プロット上に](pri59a.md#plot)注記されている。
これらの中で最も良い（最大の）値は 88.5 である。
これは右上の（+, +）の角点から得られたものである。
したがって、欠陥ばねデータについては、最適な角点は（+, +）であると結論付ける。
