# 5.5.4.1. 混合物スクリーニング計画

#### 重要な混合要因を特定するためのスクリーニング実験
混合実験の一部の分野、例えば特定の化学産業などでは、実験において候補となり得る重要と思われる成分 *q* が多数存在することがよくある。
この種の実験目的は、成分をスクリーニングして最も重要なものを特定することである。
このような状況では、実験者は、候補となる成分数を減らすために、[スクリーニング実験](../section3/pri3346.md)を検討すべきである。

#### 1次混合モデル
スクリーニング計画とその対応するモデルの構築は、多くの場合、次式の1次（または1階）混合モデルから着手する。

$$ E(Y) = \beta_1 x_1 + \beta_2 x_2 + \cdots \beta_q x_q $$  

モデルではベータ係数は非負であり、その和は 1となる。 

#### 制約条件によって決まるスクリーニング計画の選択
実験領域が[単体](pri542.md)の場合、一般に、各成分範囲をできるだけ似せるようにするのが望ましい。
そうすることで、各成分の相対的な影響を母数推定値（すなわち、*β*<sub>*i*</sub> の推定値）の比率をその標準誤差を基準として順位付けすることで評価することができる。
単体スクリーニング計画法は、単体領域全体にわたって実験が可能である場合に推奨される。
一部の成分またはすべての成分の割合が上限と下限によって制限されている場合には、[制約付き混合計画](pri544.md)が推奨される。
これらの計画が実行不可能な場合、線形モデルの[D-最適](pri521.md)計画が常に選択肢となる。
