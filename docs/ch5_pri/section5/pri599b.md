# 5.5.9.9.11. 動機：モデルを用いた外挿方法

#### 外挿の図解
外挿は、[内挿](pri599b.md)と同様の方法で行われる。
例えば、温度 *T* = 375、時間 *t* = 28 における予測値は、「X」で示される。

![Graphical representation of the design with an extrapolated point](https://www.itl.nist.gov/div898/handbook/pri/section5/dpmacros/2x2des5.gif){: .text-center}

これは、*X*<sub>1</sub> = +2.0 (T=375) および *X*<sub>2</sub> = +0.8 (t=28) の値を予測式

$$ \hat{Y} = 5 + 2 X_2 + X_1 $$

により、予測値は 8.6 となる。
したがって、次のようになる。

#### 疑似データ
モデル化によって得られた予測値は、実験を行わずに得られたデータ、すなわち疑似データと見なすことができる。
このような「自由」なデータは、グラフ手法（特に[等高線図](pri59a.md)）を適用することで洞察を飛躍的に深め、*Y* と *X* の各値との関係を示す応答曲面の性質について、重要な知見と理解をもたらす。

しかし、ここでもう一度注意を喚起する。
モデル化過程から得られる「疑似データ」は、あくまで疑似データに過ぎない。
これは実際のデータ**ではない**ため、モデルおよびモデルの予測値は、追加検証用（実際の）データ点によって検証されなければならない。
よりバランスの取れた手法は以下の通り。

モデルは「実在」するものとして信頼してもよい[すなわち、予測値や等高線を作成するため]が、常に検証されなければならない[すなわち、確認用データポイントを追加する]。

したがって、経験則としては、これらの 2水準計画に対して利用可能かつ推奨されるモデル構築手法を活用しつつ、その結果として導出されたモデルに対しては、楽観と慎重さを等しく持ち合わせて扱うことが重要である。 

#### まとめ
要約すると、モデル構築を行う動機は、それが応答曲面の性質に関する洞察を与えてくれることに加え、補間や外挿を行うことができる点にある。
さらに、累積残差標準偏差プロットを用いる動機は、それが適切かつ簡潔なモデルを決定するための、解釈しやすいツールとして機能することにある。
