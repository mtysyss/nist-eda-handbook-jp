# 5.5.9.1. 順序付きデータプロット

#### 目的
この順序付きデータプロットは、以下2つの問いに答える。

1. （データに基づいて）*k* 要因それぞれについて、最適な設定は何か。
2. 最も重要な要因は何か。

上記の問い2つにおいて、「最適」および「重要」という用語にはより正確な定義が必要である。

設定が「最適」であると判断されるのは、以下の3つの異なる観点からである。

1. データに基づいて「最適」
2. 平均的に見て「最適」
3. 適切なモデルでの予測値に対する「最適」

最悪の場合、上記3つの基準のそれぞれが、異なる「最適設定」を導き出すことがある。
その場合は、10段階の過程の最後に、3つの答えを統合する必要がある。

順序付きデータ・プロットは、最初の基準（データ）に基づいて最適な設定を導き出す。
つまり、この手法は、最適な応答値に対応する設定を導き出すものであり、その最適値はプロジェクトの目標によって異なる。

1. 応答の最大化
2. 応答の最小化
3. 応答値の目標値を当てる

これにより、当然ながら最適な応答値が導き出される。

1. 最大化：観測された最大データ点
2. 最小化：観測された最小データ点
3. 目標値：指定された目標値に最も近い観測データ値

最も「重要な」因子に関しては、これは標準設定で因子の設定を「-」から「+」へと変更するに従い、応答変数値に最大の変化をもたらす単一因子を指す。
実際には、ある因子が最良と次善の応答値に対してある設定を持ち、最悪と次悪の応答値に対して反対の設定を持つ場合、その因子は通常、最も重要な因子である。 

#### 出力
順序付きデータ・プロットからの出力は次の通り。

1. 主：*k* 個の要因それぞれに対する最適な設定
2. 副：最も重要な因子名

#### 定義
順序付きデータ・プロットは、以下の要素によって構成される。

* 縦軸：実験における *n* 実行それぞれについて、順序付けられた（小さいものから大きいものへ）生応答値
* 横軸：対応するダミー実験番号（1 から *n*）と、（各実験回における）*k* 要因それぞれに対する設定（- または +）の指定

本質的に、順序付きデータ・プロットは、順序付きデータと単一 *n* 処理の統合因子との散布図と見なすことができる。

#### 動機
最適な設定を決定するには、まず「最適な応答値」から検討するのが当然である。
「最適」とは何を指すか。
応答を最大化すること、最小化すること、それとも特定の目標値に到達することか。
この統計的ではない問いは、分析者が検討し、答えを出さなければならない。
例えば、プロジェクトの目標が最終的に大きな応答値を達成することであるならば、望ましい実験目標は最大化となる。
そのような場合、分析担当者はプロットから最大の応答値と、最適応答をもたらした *k* 係数設定の組合せを特定する。

#### 解釈の方法
順序付けられたデータ・プロットから以下の点を確認する。

1. 最適な設定
2. 最も重要な要因

 **最適な設定（データに基づく）：** 
 
最適な（最高、最低、または目標）応答値において、*k* 要因それぞれに対応する設定はどのようなものか。
これにより、生データに基づいた最適な設定が定義される。
 
 **最も重要な要因：** 
 
最適応答点およびそれに近接する準最適応答点において、*k* 要因のうちどれ（もしあれば）が一貫した設定を示しているか。
つまり、最適や準最適な応答値の部分集合について、これらの値はすべてある要因の同一水準に起因しているか。
 
あるいは、データの最良の半分の値について、この半分がたまたま共通の設定を持つある要因に起因しているか。
もしそうであれば、そのような一貫性を示す要因は、「最も重要な要因」と宣言されるための優れた候補である。
均衡のとれた実験計画において、最良／ほぼ最良の応答値がすべて1つの設定から得られるならば、必然的に、最悪／ほぼ最悪の応答値はすべてその因子のもう一方の設定から得られることになる。
したがって、その因子が「最も重要な」因子となる。

プロットの下部で *k* 要因を一つずつ確認し、そのような挙動を示す要因があるかどうかを判断する。
これが「最も重要な」要因である。 

#### ばね欠陥データの結論
順序付きデータ・プロットを欠陥のあるばねのデータ集合に適用した結果、以下の結論が得られた。

1. （データに基づく）最適な設定<br><br>
(*X*<sub>1</sub>, *X*<sub>2</sub>, *X*<sub>3</sub>) = (+, -, +) = (+1, -1, +1)が以下の理由から最適な設定である。<br><br>
    1. プロジェクトの目標は、合格率の最大化であるため、
    2. *Y* = 90 が観測された応答値の中で最大である；および* *Y* = 90 のとき、
    3. (*X*<sub>1</sub>, *X*<sub>2</sub>, *X*<sub>3</sub>) = (+, -, +) となる。<br><br>
2. 最も重要な要因：<br><br>
*X*<sub>1</sub>が最も重要な因子である。
応答値の上位4つ（90、87、79、75）では因子*X*<sub>1</sub> が +1 であり、応答値の下位4つ（52、59、61、67）は因子*X*<sub>1</sub> が -1 の値をとっている。
