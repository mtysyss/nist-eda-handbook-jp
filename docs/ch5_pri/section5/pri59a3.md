# 5.5.9.10.3. 解釈方法：最適応答値

#### 「最適」を定義する必要性
「最適」となる応答の理論値を特定する必要がある。
応答としてどのような値が望ましいか。

例えば、化学実験における応答変数が反応率である場合、理想的な理論上の最適値は 100 ％である。
製造実験における応答変数が廃棄物量である場合、理想的な理論上の最適値はゼロである。
もし流動実験における応答変数がエンジンの燃料流量であるならば、理想的な理論上の最適値（エンジンの仕様によって定められる）は、特定の値（例：175 cc/秒）となる。
いずれにせよ、対象となる実験については、理想的な応答値を表す数値を選択する。 

#### この例の最適値
欠陥ばねデータについて、応答（合格ばねの割合）は *Y* = 52 から 90 の範囲であった。
理論上の最悪の値は 0（合格するばねが 1本もない状態）であり、理論上の最良の値は 100（ばねの 100％が合格）である。
ここでは応答の最大化を目指しているため、選択された最適値は 100 となる。
