# 5.5.3. 工程最適化方法

**工程稼働最適化領域の決め方**

#### 系の応答を最大化（または最小化）する運転条件を見つけるDOEの主な目的
工程稼働の最適領域は、通常、一連の実験が実施され、一連の経験的モデルが得られた後に決定される。
多くの工学および科学の応用分野において、対象とする応答の改善を目的として実験を実施し、経験的モデルを構築する。
数学的な観点から、目的は、*r* 個のシステム応答変数 *Y*<sub>1</sub>, *Y*<sub>2</sub>, ...,*Y*<sub>r</sub> を最大化または最小化する運転条件（または因子水準）*X*<sub>1</sub>, *X*<sub>2</sub>, ...,*X*<sub>*k*</sub> を見つけ、異なる最適化技法を<u>適合された</u>応答式 $`\hat{Y}_1, \hat{Y}_2, \ldots , \hat{Y}_r`$ に適用する。
適合した方程式が、真の（未知の）系の応答を適切に近似している限り、モデルの最適運転条件は真の系の最適運転条件に「近い」ものとなる。

#### 最適化に対するDOE手法
応答曲面モデルの実験最適化は、古典的最適化手法とは少なくとも以下の3つの点で異なる。

#### 近似的な（良好な）モデルの発見と（ほぼ）最適運転条件の反復探索
1. 実験最適化は反復的な工程である。
すなわち、一連の実験で得られた結果から適合したモデルに基づき、次の実験において、改善された運転条件を探す領域が示される。
したがって、最適化過程中に、適合した方程式の係数（あるいは適合した方程式の形式）が変化する可能性がある。
これは、最適化する関数が固定され所与と想定される古典的最適化とは対照的である。

#### 最終回答に影響を与える無作為性（標本ばらつき）考慮事項
2. 応答モデルは、通常、制御不能または未知要因に起因する無作為な変動を含む実験データから推定される。
これは、実験を繰り返すと異なる応答曲面モデルが推定され、その結果、異なる最適運転条件が導かれる可能性があることを意味する。
したがって、実験最適化においては、[標本抽出のばらつき](pri5315.md)を考慮すべきである。

対照的に、古典的最適化手法では、関数は決定論的でありあらかじめ与えられている。 

#### 実験者による入力が必要な最適化工程
3. 適合された応答は局所的な近似であり、最適化工程には実験者（その工程に精通した人物）の介入が必要であることを意味する。
これは、常に何らかのコンピュータ・アルゴリズムの形で自動化される古典的最適化とは対照的である。
