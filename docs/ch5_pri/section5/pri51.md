# 5.5.1. 古典的計画が機能しない場合

#### 計画が機能しない理由
ほとんどの実験状況では、多くの統計ソフトウェア・パッケージを用いて構築できる標準的な実験計画法が求められる。
標準的な実験計画法は、精度や直交性、および他の最適な特性を確実に備えており、これらはほとんどの実験における探索的な性質にとって重要である。
しかし、状況によっては、標準的な実験計画法が適切でない場合や、実用的でない場合もある。
これには、次のような状況が含まれる。

1. 実験状況において求められるブロック構造やブロックの規模が、標準的なブロック計画に適合しない。
2. 要因設定のすべての組合せが実行可能でない場合、あるいは他の理由により、実験領域が制約を受けているか、不規則な形状をしている。
3. 古典的計画法が「修正」を必要とする。
これは、計画段階での不適切な計画により、元の計画における処理組合せに、計画作成前に考慮されていなかった禁止されている組合せや到達不可能な組合せが含まれていたことが原因で発生する。
4. 非線形モデルが適切である。
5. 定性因子がある場合は、2次計画法または応答曲面法が必要である。
6. 実験因子に、混合物の各成分と他の工程変数の両方が含まれる。
7. 変動要因が複数あり、枝分かれまたは階層的なデータ構造が生じ、無作為化可能な項目に制約が生じる。
8. 標準的な一部実施要因計画では、与えられた時間および／または資源の範囲内で処理の組合せ数が多過ぎる。

#### コンピュータ支援計画
上記のような状況では、コンピュータ支援計画が有用な選択肢となる。
場合によっては、コンピュータ支援計画が実験者にとって唯一の選択肢である。
