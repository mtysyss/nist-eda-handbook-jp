# 5.5.9.9.1. 動機：モデルとは

#### 数学モデル：関数形式と係数
モデルとは、応答 *Y* と因子 *X*<sub>1</sub> から *X*<sub>*k*</sub> との関係を表す数学関数である。
モデルは以下を持つ。

1. 関数形式
2. 係数

特に有用で扱いやすい関数形式として、主効果と交互作用の線形結合が挙げられる（選択されたモデルは完全モデルの部分集合であり、ほとんどの場合、適切な部分集合である）。
この線形モデルの係数は、[最小二乗推定](../../ch1_eda/section3/eda35i.md)法[（回帰分析）](../../ch1_eda/section3/eda35i.md)を適用することで容易に求めることができる。
推定された係数を持つ特定の関数形式は、「推定モデル」または「予測式」と呼ばれる。

#### 予測値と残差
因子 *X*<sub>1</sub> から *X*<sub>*k*</sub> までの所定の設定において、推定モデルは予測値を与える。
*X*<sub>*i*</sub> の各（すべての）設定について、「完全適合」モデルとは、その *X*<sub>*i*</sub> における予測値が観測された応答値 *Y* と完全に一致するモデルを指す。
言い換えれば、完全適合モデルは、観測された応答値のベクトルと同一の予測値のベクトルを与える。
これらの同じ *X*<sub>*i*</sub> について、「良好な適合」モデルとは、観測応答 *Y* に「許容できる程度に近い」予測値を生成するモデルであり、必ずしも観測応答 *Y* と同一である必要はない。

モデルの残差（＝偏差＝誤差）とは、応答値とモデルから得られた予測値との差（$`Y - \hat{Y} `$）のベクトルである。
完全適合モデルの場合、残差ベクトルはすべてゼロとなる。
良い適合モデルの場合、残差ベクトルは（工学的観点から）許容できる範囲でゼロに近い値となる。
