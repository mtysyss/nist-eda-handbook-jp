# 5.5.9.9.9. 動機：補間を行う最適な確認点の決め方

#### 中心点を用いた拡張
通常の連続因子の場合、2<sup>*k*</sup> や 2<sup>*k*-*p*</sup> 計画に追加できる最も優れた（最も効率的で効果が最も高い）モデル検証点の追加は、中心点である。
この中心点の追加による「コスト」は、実験者にとって、たった 1 回の追加実験にすぎない。

#### 例
例えば、*k* = 2 因子（温度(300～350)、時間 (20～30)) について、前節で論じた実験では、通常の[4反復 2<sup>2</sup>完全実施要因計画](pri5998.md#designtable)に代わって、中心点を設けた以下の 5反復 2<sup>2</sup> 完全実施要因計画を用いることができる。

| *X*<sub>1</sub> | *X*<sub>2</sub> | *Y* |  
| --- | --- | --- |  
| - | - | 2 |  
| + | - | 4 |  
| - | + | 6 |  
| + | + | 8 |  
| 0 | 0 |  |  
{: .no-border-table }

#### 中心点の予測値
「-」は -1 を、「+」は +1 を表すため、中心点を(0,0)として符号化するのが自然である。
推奨される以下のモデルを用いれば、

$$ \hat{Y} = 5 + 2 X_2 + X_1 $$

*X*<sub>1</sub> と *X*<sub>2</sub> に 0 を代入することで、検証実行における予測値5 を計算できる。

#### 確認実行の重要性
確認実行の重要性はいくら強調してもしすぎることはない。
もし中心点での確認実行の結果、データ値が例えば *Y* = 5.1 となった場合、中心点での予測値は 5 であり、モデルが端点において完全であることがわかっているため、これにより解析担当者は、適合モデルの品質が内部（補間）領域全体に及ぶ可能性について、より強い確信を持つことができる。
一方、もし確認実行の結果、中心点でのデータ値が、中心点における予測値 5 とは異なる値（例えば、*Y* = 7.5）となった場合、分析者は補間目的であっても、その適合モデルを信頼すべき**ではない**と判断することになる。
したがって、因子が連続変数である場合、中心点での単一の確認実行は、モデルの信頼範囲を評価する上で極めて大きな助けである。

#### 中心点の反復
実際には、この中心点値には、2つ、あるいは3つ、さらにはそれ以上の反復値が存在することがよくある。
これは、中心点におけるモデルの補間能力を評価するための基準点となるだけでなく、データに含まれる固有の誤差について、モデルに依存しない推定値を計算することも可能にする。
これにより、モデル内の個々の係数の不確かさを計算したり、モデル全体の妥当性を評価するための適合度検定を厳密に実施したりするための、より厳密な手法が得られる。
