# 5.5.4.5. 混合変数と工程変数の同時処理

#### 標準工程変数と混合物変数の両方を持つ工程における実験設定の選択肢
*q* 混合成分と *k* 工程変数からなる混合実験を考える。
まず、調査対象の各工程変数が 2水準しか持たない場合を考える。
工程変数には直交尺度変換された因子設定を用いる（すなわち、-1は低レベル、1は高レベル、0は中心点とする）。
また、各成分 *x*<sub>*i*</sub> の値は 0から 1の範囲にあると仮定する。
このとき、工程変数に関する関心領域は *k* 次元の超立方体となる。

混合成分の関心領域は、(*q*-1) 次元の単体である。
工程変数と混合成分の両方を合わせた関心領域の次元は、*q*- 1 + *k* となる。 

#### 3混合成分と3工程変数の例
例えば、3混合成分(*x*<sub>*1*</sub>, *x*<sub>*2*</sub>, *x*<sub>*3*</sub>) と3つの工程変数 (*z*<sub>*1*</sub>, *z*<sub>*2*</sub>,*z*<sub>*3*</sub>) を考える。
この領域の次元は 5である。
混合成分3つと工程変数3つに関する対象領域の全体を以下の 2つの図に示す。
計画の完全な空間は、2つの方法のいずれかで捉えられる。
最初の図は、3成分単体領域の各頂点における完全実施要因計画の概念を示している。
2番目の図は、完全実施要因計画の各点における 3成分単体領域の概念を示している。
いずれの場合も、調査対象となるのは同じ全体工程空間である。

#### 利用可能な追加選択肢
上記の図から解るように、工程変数と混合成分における計画構成の設定には、工程変数の各設定点において混合計画を設定するか、あるいは同様に、混合成分の各組成点において工程変数の要因配置を作成する。
上記の図2つに示された例の場合、指定数の工程変数での混合成分のこの数に対して、これが唯一の計画というわけではない。
別の選択肢としては、混合計画の各頂点または各点で一部実施要因計画を実施し、各混合計画点で同じ割合の実行を行うことが考えられる。
さらに別の選択肢としては、混合計画の各頂点または各点で一部実施要因計画を実施し、各混合計画点で異なる割合で実験を行う方法も考えられる。
