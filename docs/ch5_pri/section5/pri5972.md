# 5.5.9.7.2. 工学的有意性

#### 工学的切捨値
技術者としてあらかじめ工学的切捨値と定めた値のグラフ上の位置に水平線を引く。
この切捨値より大きい効果は、工学的な観点から有意であると看做される。

#### 切捨値設定は統計的考え方を必要とせず、有用
この手法では、分析者があらかじめ技術者や科学者として「注意する」だろう、効果がどの程度大きく（どの程度の値か）なければならないかについて、データに依らない予備的な考察が分析者に求められる。
言い換えれば、分析者が「これは工学的観点から見て、十分に大きな変化だ」と応答変数の単位で判断するには、応答変数がどの程度一貫して変化しなければならないのか、工学的数値、すなわち閾値が必要である。
この値は統計的ではなく、技術者自身の頭の中から導き出されるものでなければならない。

もし熟考した結果、分析者がそのような値を思い浮かべることができ**ない**のであれば、この「工学的有意性」の手法は脇に置かれることになる。
経験上、そのような閾値を導き出すための技術者としての内省はしばしば有用であり、統計的考慮とは独立し、影響を重要と重要でないに分類する意思決定プロセスの一部となるべきであることが分かっている。 

#### 概略工学的切捨値
既知の工学的切捨値がない場合、大まかな切捨値は通常、系の**平均**（または現在の）生産応答の 5％もしくは 10％ とされる。
したがって、ある化学反応生産工程で反応速度が約70 である場合、その 5％は 70 = 3 である。
技術者は、応答に平均 3単位以上の変化をもたらす将来の効果（すなわち、その大きさが3を超えると推定される効果）を「工学的有意性」があると宣言することがある。
 |効果|プロットの文脈では、技術者はプロット上に高さ 3の線を引くことになり、その線より上のすべての効果は有意と宣言され、線より下のすべての効果は有意ではないと宣言される。
