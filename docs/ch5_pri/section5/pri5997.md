# 5.5.9.9.7. 動機：モデルを用いた予測値の計算方法
#### 2つの要因に対する応答値を含む計画行列
予測のためのモデルの活用に関する詳細を説明するために、単純な事例を検討し、一般化してみる。
*X*<sub>1</sub> および *X*<sub>2</sub> における単純な Yates 順序 2<sup>2</sup> の完全実施要因計画について、応答ベクトル *Y* を拡張したものを考える。

| *X*<sub>1</sub> | *X*<sub>2</sub> | *Y* |  
| :---: | :---: | :---: |  
| - | - | 2 |  
| + | - | 4 |  
| - | + | 6 |  
| + | + | 8 |  
{: .no-border-table}

#### 幾何学表現
これは幾何学的には次のように表すことができる。

![diagram of design with response points](https://www.itl.nist.gov/div898/handbook/pri/section5/dpmacros/2x2des.gif)
{: .text-center}

#### 予測式の決定
これは次のモデルが考えられる。

$$ Y = c + B_1 X_1  + B_2 X_2  + B_{12} X_1 X_2  + \epsilon $$

上の図から、推定された因子効果を以下の式で推測できる。

$$\begin{align}
c   &= \text{平均応答値} = \bar{Y} \\
    &= (2 + 4 + 6 + 8) / 4 = 5 \\
    &\quad \text{（平均）} \\
E_1 &= \text{$X_1$ が -1 から +1 に変化したときの $Y$ の平均変化量} \\
    &= ((4-2) + (8-6)) / 2 = (2 + 2) / 2 = 2 \\
    &\quad \text{注：}(4-2)\text{ は下軸上の $Y$ の変化量（$X_1$ による）、} \\
    &\quad \phantom{\text{注：}}(8-6)\text{ は上軸上の $Y$ の変化量（$X_1$ による）である。} \\
E_2 &= \text{$X_2$ が -1 から +1 に変化したときの $Y$ の平均変化量} \\
    &= ((6-2) + (8-4)) / 2 = (4 + 4) / 2 = 4 \\
E_{12} &= \text{交互作用} = \text{（あまり明らかではない）} \\
    &\quad \text{$X_1 * X_2$ が -1 から +1 に変化するときの $Y$ の平均変化量} \\
    &= ((2-4) + (8-6)) / 2 = (-2 + 2) / 2 = 0
\end{align}$$


+1 および -1 を用いて符号化された因子の場合、係数の最小二乗推定は効果推定の半分（*B*<sub>*i*</sub> = *E*<sub>*i*</sub>/ 2）となるため、推定モデル（すなわち、予測式）は以下となる。

$` \hat{Y} = 5 + 1 X_1 + 2 X_2  + 0 X_1 X_2 `$

あるいは、項を重要度の高い順に並べ替え、

$` \hat{Y} = 5 + 2 X_2 + X_1 `$

#### 適合値の表
この式に 4設計点の値を代入すると、以下の推定値が得られる。

| *X*<sub>1</sub> | *X*<sub>2</sub> | *Y* | $` \hat{Y} `$ |  
| :---: | :---: | :---: | :---: |  
| - | - | 2 | 2 |  
| + | - | 4 | 4 |  
| - | + | 6 | 6 |  
| + | + | 8 | 8 |  
{: .no-border-table}

#### 完全適合
これは完全適合モデルである。
このような完全適合モデルは、（この直交2水準計画の系列において）すべての主効果とすべての交互作用を含め、いつでも得られる。
注目すべきは、これが *k*= 2 因子の場合だけでなく、一般的な *k* の場合にも当てはまるということである。

#### 残差
あるモデル（どのようなモデルでも）において、応答値 *Y* と予測値 $` \hat{Y} `$ の差は「残差」と呼ばれる。

残差 = Y - $` \small \hat{Y} `$

完全適合した本格的なモデル（すべての主因子およびすべての次数の交互作用を含む）では、すべての残差が等しくゼロとなる。

完全適合とは、考えられるすべての項を含む線形モデルを用いる場合に得られる数学的性質である。 

#### 完全適合の対価
この完璧な適合には、どのような代償が伴うか。
その一つに $` \scriptsize \hat{Y} `$ の分散が不必要に増大してしまうことがある。
さらに、このモデルは簡潔さに欠けている。
すべての主効果および交互作用の平均値と係数を計算し、保持しなければならない。
平均値を含めると、一般に、*n*= 2<sup>k</sup> 点の適合を完全に記述するには 2<sup>k</sup> 個の係数が必要となる。
これは、*n* の異なる点に対する *Y*= *f*(*X*) という多項式適合と非常によく似ている。
よく知られているように、これは次数 n-1 の多項式を当てはめることで「完全に」行うことができる。
そのような完全性が数学的には達成可能であるというのは心強いが、実際には、これを常に、あるいはいつでも行いたいか。
その答えは、一般的に「いいえ」である。
その理由は2つある。

1. ノイズ：応答データ *Y* にノイズ（＝誤差）が含まれていることは非常に一般的である。
わざわざそのようなノイズまで適合する必要があるか。
それとも、モデルからノイズを除去させ、「信号」だけを当てはめたいか。
後者の場合、より少ない係数が適切となり、12個のデータ点に対して、完璧な（だがギザギザした）11次多項式の近似を見送り、代わりに不完全（だが滑らかな）3次多項式で 12点を近似するのと同じ考え方である。

2. 簡潔性：完全実施要因計画の場合、*n* = 2<sup>k</sup> のデータ点に適合させるには、2<sup>k</sup> の係数を計算する必要がある。
そのような係数のこれらの係数の絶対値と符号に注目することで情報を得るが、数値的には入力として *n* 個のデータ値 *Y* があり、出力として *n*　個の係数 *B* があるため、数値的な削減は達成されていない。
単に *n*　個の数値のセット（データ）を用いて、別の *n*　個の数値のセット（係数）を得たに過ぎない。
これらの係数のすべてが等しく重要であるとは限らない。
時には、その重要性が、*n* = 2kという膨大な係数の数によって見失われてしまうこともある。
簡潔性の原則によれば、結果としては、*n*個の初期点よりもより単純で、より焦点を絞ったものであるべきだ。
したがって、保持する係数の数を減らすことが求められる。

その結果、実際には、ほとんどの場合、完璧ではあるが扱いにくいモデルを捨て、不完全ではあるが簡潔なモデルを採用することになる。

#### 非完全適合
上記の計算は、完全モデルにおける予測値の計算方法を示したものである。
一方、前述したように、信号や簡潔性の観点から、重要でない要因を意図的に省略することが一般的に都合が良い場合がある。
解析者がそのようなモデルを選択する場合の予測値 $` \scriptsize \hat{Y} `$ を計算する手法はまったく同じであることに留意すべきである。
ただし、その場合、得られる予測値は一般に元の応答値 *Y* とは同一ではなくなる。
つまり、完全な適合は得られない。
したがって、一部の項を省略した線形モデルでは、残差のほぼすべてがゼロ以外となる。
