# 5.5.9.7.1. 統計的有意性

#### 正式な統計手法
統計的有意性という問いに答えるための正式な統計的手法には、一般的に以下を用いる。

* ANOVA（分散分析）
* 効果量に対する *t*-検定に基づく信頼区間

#### ANOVA
ANOVAの利点は、強力かつ柔軟なツールであり、幅広い用途があることである。
一方、ANOVAの欠点は以下を挙げられる。

* 極めて定量的であり、直感に反する
* 基礎となるモデルを仮定しなければならない
* その妥当性は、誤差の分散が一定であることおよび誤差の正規性という仮定に依存する

#### 信頼区間
[*t*-分布](../../ch1_eda/section3/eda3664.md)を用いた効果の *T* 信頼区間も、因子有意性を判断するために広く用いられている。
この *t* 法の一環として、まず効果の標準偏差である *sd*(効果) を決定する必要がある。
2水準の完全実施要因計画および一部実施要因計画において、この標準偏差は、固定条件下における観測値の標準偏差 *σ* と、以下の式で関連付けられる。

$` \text{sd(効果)} = \frac{2 \sigma}{\sqrt{n}} `$

これにより、適切な乗数 *c* (*t* 分布からの) を用いた次式から、効果に対する 95%信頼区間が導かれる。

*c*\* *sd*(*効果*)

したがって、|効果|プロットの文脈において、*c* \* *sd*(効果) の位置に「線を引く」ことは、意図したとおりに、効果一覧を以下の領域2つに分ける役割を果たす。

* 有意（すなわち重要）な効果
* 有意でない（すなわち、重要でない）

#### sd(効果)の推定
上記手法における鍵は、*sd*(効果) の推定値を決定することである。
以下の3つの統計手法が一般的に用いられる。

1. *σ* に関する事前知識：<br><br>
*σ* が既知の場合、上記の式から *sd*(*効果*)を計算し、以下の式の位置に線を引く、保守的（正規基準で）95% 信頼区間を用いる。<br><br>
$` \text{2 sd(効果)} = 2 \left( \frac{2 \sigma}{\sqrt{n}} \right) `$ <br><br>
*σ* が既知であることは稀であるため、この方法は実際にはほとんど用いられない。<br><br>
2. 実験計画における反復：<br><br>
反復を行うことで、決定論的モデルの正しさに依存することなく、データから *σ* を推定することが可能になる。
これは大きな利点である。
一方、このような反復の欠点は、実験の実行数、時間、および費用が増加することである。
反復の実施に余裕がある場合は、この手法を用いるべきである。
その場合、分析者は重要項と非重要項を区別するために、<br><br>
$` t* \text{sd(効果)} = t * \left( \frac{2\hat{\sigma}}{\sqrt{n}} \right) `$<br><br>
とし、*t* は適切な[スチューデントの*t*分布](../../ch1_eda/section3/eda3664.md) における 97.5百分率点を表す。<br><br>
3. 3因子交互作用および高次交互作用がゼロであると仮定する：<br><br>
この手法では、すべての3因子交互作用および高次交互作用を「仮定によって排除」し、これらの交互作用に関連するデータを用いて *σ* を推定する。
具体的には、<br><br>
$` \hat{\sigma} = \sqrt{\frac{\text{SSQ}}{h}} `$ <br><br>
ここで、*h* は 3因子交互作用および高次交互作用の数を表し、SSQ はこれらの高次効果の平方和である。
分析者は、以下の線を引くことで非重要効果から重要効果を分離する。 <br><br>
$` t * \text{sd(効果)} = t * \left( \frac{2 \hat{\sigma}}{\sqrt{n}} \right) `$<br><br>
ここで、*t* は適切な（自由度 *h* を持つ）[スチューデントの *t*-分布](../../ch1_eda/section3/eda3664.md) における97.5 百分率点である。<br><br>
この方法には注意が必要である。<br><br>
    * 検証不可能な仮定（すなわち、そのような交互作用＝0 であるという仮定）が含まれる。
    * *sd*(効果) 推定値がごく少数の項（場合によっては単一項）に基づいて計算される可能性がある。
    * 高度に分割された実験計画法では実質的に使用できない（高次交互作用は直接推定できない）。

#### 非統計的考慮事項
上記、統計手法は、活用することができ、また活用すべきである。
さらに、次の数節で論じる統計的ではない観点も、実務においてはしばしば有益な示唆を与えてくれるものであり、ここで推奨するEDA手法においても重要な位置を占めている。
