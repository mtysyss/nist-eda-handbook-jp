# 5.5.9.2. DOE散布図

#### 目的
DOE（実験計画法）の散布図は、以下3つの問いに答える。

1. 最も重要な要因は何か。
2. これら重要要因それぞれの最適設定は何か。
3. どのデータ点が外れ値か。

上記の問いにおいて、「重要」、「最適」、および「外れ値」という用語については、明確化と具体化が必要である。

**重要**

ある要因の「－」設定から「＋」設定へと変化するに従い、応答変数の位置もしくは変動の著しいずれに繋がるならば「重要」であると言える。
どちらの定義も適切であり受け入れられる。
工学・科学分野における「重要」の標準的定義は位置の移動である。
特に指定がない限り、ある要因が重要であるとされる場合、要因が応答における大きな位置の移動を引き起こしたことを意味する。

**最適**

因子設定が「最適」であるとは、その結果得られる典型的な応答値が、位置において、望ましいプロジェクト目標（最大化、最小化、目標値）に最も近い結果を与える。
この望ましいプロジェクト目標は統計的な問題ではなく工学的な問題であり、望ましい最適化目標は技術者によって特定されなければならない。

**外れ値**

データ点が、残りのデータとは異なる確率分布や異なる決定論モデルに従う場合、そのデータ点は「外れ値」である。
データ集合内の単一外れ値は、すべての効果推定値に影響を与える可能性があり、ひいては重要度に基づく要因の順位付けを無効にする可能性がある。

上記の定義を踏まえると、DOE散布図は、重要な要因、最適な設定、および外れ値を特定する初期段階における有用なツールである。
DOE散布図の別名は「主効果プロット」である。 

#### 出力
DOE散布図の出力は以下の通り。

1. 主：重要な要因の特定
2. 副：これら要因に対する最適設定と外れ値の特定

#### 定義
DOE散布図は以下の形式である。

* 縦軸：*k* 要因それぞれに対する要因の与えられた設定（- または +）に対する応答値（＝生データ）
* 横軸：*k* 因子と各因子内の2設定（- および +）

#### 動機
散布図は、応答変数が別の要因と関連しているか、またその関連性がどのようなものかを判断するための主なデータ分析ツールである。
そのような関連性の有無を判断することは、統計的な関連性を工学的な因果関係へと変換するための不可欠な第一歩である。
要因の異なる水準の関数として生データがどう変化するかを観察することは、あらゆるデータ分析において決して省略してはならないと主張されることもある基本的な手順である。

このような基礎的プロットから、分析者は必ず位置のずれ、変動のずれ、および外れ値に関する情報を抽出する。
こうした情報は、他の「より高度な」定量的もしくは図形的な手順（さらには平均値の計算やプロットさえも！）によって容易に埋もれてしまうことがある。
故に、DOE散布図を用いる意義がある。

単一要因の重要性を評価することに興味があり、かつ標準的に「重要」とは位置の移動を意味するならば、単純な散布図は理想的なツールである。
特定の因子の「－」設定から「＋」設定へと、データ本体に（データの重複がほとんどない）大きなずれが見られる場合、その因子は重要であると示唆される。
一方、小さなずれ（データの重複が多い）は、その因子が重要ではないことを示唆する。

DOE散布図は、実際に、各因子ごとに1つの散布図の *k* 個一連のそのような散布図である。

#### 解釈の方法
前述したように、DOEの散布図を以下の点を確認するために使用する。

1. 最も重要な要因
2. 最も重要な要因の最適設定
3. 外れ値

これらについて順に説明する。
 
**最重要要因：** 
 
*k* 個の要因それぞれについて、要因内で「-」設定から「+」設定へと移行するにつれて、データ本体に位置のずれが生じるか。
もし生じるのであれば、

1. どの因子が、そのようなデータの位置のずれが最も大きい（つまり、データの重複が最も少ない）か。
これが「最も重要な因子」を定義する。
2. 次に大きな位置のずれ（つまり、データの重複が次に少ない）を示す因子はどれか。
これが「2番目に重要な因子」である。
3. 残りの要因について、繰り返す。

実際には、DOE散布図では通常、最重要因子（最大の位置ずれ）と、場合によっては2番目の重要因子（次に大きな位置ずれ）しか判別できない。
残りの因子における重なり具合はしばしば大き過ぎ、他因子の順位を確実に特定することは困難である。

**最重要要因に対する最適設定：**

最重要な各要因について、どの設定（「-」または「+」）が「最適な」応答をもたらすか。

この問いに答えるためには、技術者はまず「最適」を定義しなければならない。
これは、プロジェクト全体の目標と、調査対象となっている特定の応答変数を併せて考慮して行う。
一部の実験（例：チップ速度の最大化）では、「最適」とは、応答（速度）を最大化しようとしていることを意味する。
一方、他の実験（例：半導体チップの不良率）では、「最良」とは、応答（不良率）を最小化しようとすることを意味する。
さらに別の実験（例：抵抗器設計）では、「最適」とは、特定の目標値（指定された抵抗値）を達成しようとすることを意味する。
したがって、「最適」の定義は、最適な設定を決定するための工学的な前提条件である。

分析者が応答を最大化しようとしているとする。
そのような場合、分析者は次のように進める。

1. 因子1 について、どの設定（- または +）でデータの大部分が高くなるか。
2. 因子2 については、どの設定（-または+）でデータの大部分がより高くなるか。
3. 残りの因子についても続ける。

その結果得られる最適設定の *k* ベクトル

(x1best, x2best, ..., xkbest)

は、DOE散布図において各要因を個別に検討し、データの大部分が所望の最適（最大、最小、目標）応答に最も近い設定（- または +）を選択することで、理論的に得られる。

前述の通り、DOE散布図では通常、最初の数個の重要要因についてのみ、最適設定を推定することができまる。
繰り返しになるが、データの重なり程度のために、残りの要因について最適な設定を特定することはできない。
DOE平均プロットなどの他のツールの方が、そのような設定を決定するには適している。

**外れ値：** 

データの大半から明らかに外れているデータ点はあるか。
もしある場合、そのような値は外れ値としてさらに調査すべき候補となる。
複数の外れ値がある場合、それらの異常なデータが、要因いずれかの同じ設定値に集中しているかを確認することが重要である。
もしそうであれば、その設定値は、外れ値の性質（不良か良好か）に応じて、回避すべきか、あるいは採用すべきかの候補となる。 

#### 欠陥のあるばねに関するデータの結論
欠陥のあるばねのデータ集合にDOE散布図を適用した結果、以下の結論が導き出された。

1. 最も重要な要因<br><br>
<ol>
<li>*X*<sub>1</sub> （最も重要）</li>
<li>*X*<sub>2</sub> （重要度は*X*<sub>1</sub>より低い）</li>
<li>*X*<sub>3</sub> （重要度が最も低い）</li>
</ol>
<br>つまり、<br><br>
<ul>
<li>因子1 は間違いなく重要に見える</li>
<li>因子2 はそれに大きく及ばない2番目である</li>
<li>因子3 は位置に関して重要であるには重複が多すぎるが、変動における潜在的な差異があるため、さらなる調査の対象としてマークする  </li>
</ul>

  
2. 最適な設定：  <br>
$$(X_1, X_2, X_3) = (+, -, -) = (+1, -1, -1)$$
<br><br>
3. 外れ値：検出なし。
