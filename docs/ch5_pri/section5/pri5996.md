# 5.5.9.9.6. 動機：線形組合せモデルの利点
#### 利点：完全な適合性と比較可能係数
主効果および交互作用すべてから構成される線形モデルには2つの利点がある。

1. 完全適合：モデルに主効果すべておよび交互作用（すべての次数）すべてを含めることを選択した場合、結果として得られる最小二乗法による適合モデルは、予測値が生の応答値 *Y* と**完全に**一致するという性質を持つ。
これについては[次](pri5997.md)節で説明する。

2. 比較可能係数：モデル適合が、元の因子単位（温度、時間、圧力、触媒濃度など）の単位ではなく、（-1, +1）の符号付き因子単位で行われるため、因子係数は即、互いに比較可能となり、これが因子の相対的な重要度を尺度に依存せずに順位付けするための直接的な機構として機能する。

#### 例
上記の後半を詳しく説明すると、係数 *X*<sub>1</sub> の (-1, +1) が実際には温度 *T* の符号化であり、元の温度範囲が 300 から 350 度、係数 *X*<sub>2</sub> (-1, +1) が実際には時間 *t* の符号化であり、元の時間は 20 から 30分の範囲にあるとする。
これを踏まえ、元の温度 *T* と時間 *t* を用いた線形モデルでは、係数の絶対値は *T*（300～350）および *t* (20～30) の大きさに依存し、*T*（例えば、華氏度から摂氏度へ）や *t*（例えば、分から秒へ）の単位を変更することにした場合、その値も変化してしまう。
これらすべてを回避するには、*T*（300、350）や *t*（20、30）の元の単位ではなく、*X*<sub>1</sub>（-1、+1）および *X*<sub>2</sub>（-1、+1）という符号化された単位を用いて回帰分析を行う。
その結果得られる係数は単位に依存せず、係数の絶対値は測定単位に関係なく、各因子および交互作用の真の寄与を反映することになる。

#### 一般性が失われない符号化
このような符号化は、符号化された因子が元の因子（*X*<sub>1</sub> から *T*へ、*X*<sub>2</sub> から *t* へ）の単純な線形関係として表せるため、一般性を損なうことはない。
また、単位不変の符号化係数は、必要に応じ、単位依存の元の係数に容易に変換することができる。
