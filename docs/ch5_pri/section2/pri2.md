# 5.2. 前提条件

#### DOEで採用されている工学上の仮定やモデル構築の前提
ほとんどのDOEで採用されている工学上の仮定やモデル構築の前提について、確認すべきである。

あらゆるモデル構築において我々は仮定を立てるが、推定の目的を概ね満たす特定の条件も必要である。
この節では、通常行われる工学上および数学上の前提のいくつかについて検討する。
それらは以下の通り。

* [測定システムはすべての応答に対応可能か](pri21.md)
* [工程は安定しているか](pri22.md)
* [応答変数は単純な多項式モデルによって十分に近似できるか](pri23.md)
* [残差（モデルの予測値と実際の観測値との差）は良好な挙動を示しているか](pri24.md)
