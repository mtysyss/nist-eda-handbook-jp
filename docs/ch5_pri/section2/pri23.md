# 5.2.3. 簡単なモデルがあるか

#### 滑らかに変化する出力に対してのみ有効な多項式近似モデル
この章では、応答変数が *Y* と表記される連続出力である場合に限定する。
実験範囲において、出力は連続であるだけでなく、適度に滑らかでなければならない。
Y値が急激に低下する場合、用いる近似多項式近似では、これら多項式は基礎となる応答曲面が滑らかに曲線を描いていることを前提とするため見逃してしまう可能性がある。

#### 区間ごとの滑らかさの確認には、個別の実験が必要
調査対象の表面が区間ごとにのみ滑らかであることが分かっている場合、実験を個別の実験に分割し、それぞれの区間の形状を個別に調査する必要がある。
非常にギザギザしている（すなわち、滑らかでない）ことが分かっている曲面は、滑らかな多項式によって適切に近似することはできない。
