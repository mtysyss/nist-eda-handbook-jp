# 5.2.4. モデルの残差は素性が良いか

#### 観測値と予測値間の差
残差とは、<u>予測応答から観測応答を差し引く</u>ことによって得られる実験誤差の推定値である。

予測応答は、実験データからすべての未知モデル係数を推定した後、選択したモデルから計算する。

残差の検討は、DOEを含むあらゆる統計的モデル化において重要な要素である。
残差を注意深く検討することで、仮定が妥当であるか、またモデルの選択が適切であるかを判断することができる。 

#### 適合モデルでは説明できない変動の要素
残差は、適合モデルでは説明できないばらつきの要素と考えることができる。
これは一種の誤差であるため、一般的に誤差に対して用いるのと同じ一般的な仮定を残差の群に適用する。
すなわち、<u>（概ね）正規、（近似的に）独立した分布に従い、平均が 0 の一定分散を持つと期待される</u>。

#### 残差の仮定
これらは、ANOVAや古典的な回帰分析の根底にある仮定である。
つまり、分析者は、回帰モデルが応答の予測において無作為な誤差を生じると想定すべきであり、モデルは実際値よりも高い値と低い値を等しい確率で予測するはずである。
さらに、誤差の水準は、研究において観測された時期や、予測される観測値の大きさ、さらには予測を行うときに用いられる要因設定条件とは無関係であるべきである。
残差の全体的なパターンは、正規分布のデータをヒストグラムにプロットしたときに観察される鐘型のパターンと類似しているべきである。
 
残差の検証は<u>グラフを用いた手法</u>の活用を重視する。 

#### モデルの不適切さを示す逸脱
これらの仮定からの逸脱は、通常、残差にはモデルで説明されていない<u>構造</u>が含まれていることを意味する。
構造を特定し、それを表す項を元のモデルに追加し、より優れたモデルにする。

**残差の正規性検定**

#### 残差検証のプロット
あるデータ集合の分布を表示すのに適したグラフであれば、どのようなものでも、一連の残差の分布が正規分布に従っているかを判断するのに適している。
最も一般的な3種類は次の通り。

1. [ヒストグラム](../../ch1_eda/section3/eda33e.md)
2. [正規確率プロット](../../ch1_eda/section3/eda33l.md)
3. 点図表である。

#### ヒストグラム
![Sample histogram of residuals from a semiconductor process ](https://www.itl.nist.gov/div898/handbook/pri/section2/gifs/reshist.gif)

ヒストグラムは、データを等間隔のセルに配置し、各セルの頻度をセルの中心に対してプロットして得られる頻度図である。
図2.2は、校正工程のモデルで作成した残差の近似的な正規分布を示している。
このヒストグラムには、正規密度関数を重ねて表示している。 

#### 小サンプルの大きさ
実験における処理の組合せには限りがあるため、残差の標本規模は一般的に小さく（＜50）、残差の分布を判断するにはヒストグラムは最適な選択肢とは言えない。
より感度の高いグラフとしては、正規確率プロットが挙げられる。

#### 正規確率プロット
正規確率プロットを作成する手順は次の通り。

* 残差を昇順に並べ替える。
* 次式を用い、各残差の累積確率を計算する。
<br><br>
$$P(i\text{番目の残差}) = i/(N+1)$$ 
<br><br>
ここで、$`P`$` は点の累積確率を表し、$`i`$ はリスト内の値の順序、$`N`$ はリスト内の要素数を表す。
* 計算された*p*-値を残差値に対して正規確率用紙上にプロットする。

点が正規分布に従っている場合、正規確率プロットはほぼ直線となるはずである。

#### 点図表を重ね合わせた正規確率プロットの例
以下の図2.3は、図2.2で使用したものと同じ残差の群から作成した正規確率グラフを示している。

![Sample normal probability plot](https://www.itl.nist.gov/div898/handbook/pri/section2/gifs/normprob.gif)

このグラフには、点図表を追加している。
点図表とは、左側のy軸に沿って配置された点の集合のことである。
これらは残差の値である。
点図表の目的は残差の分布を示すことにある。 

#### 双峰性分布を示す「S」字型曲線
正規確率プロットにおいて、直線からのわずかな逸脱はよくあることだが、このグラフ上で明らかに「S」字型の曲線が見られる場合は、残差の双峰性分布を示唆している。
また、グラフの中央付近に見られる折れ目も、残差分布の異常を示す兆候である。

注：スチューデント化残差とは、個々の残差が残差分布の中心からどの程度離れているかをおおよそ表す尺度に変換された残差である。
残差をこの形式に変換するために用いられる手法により、値のスチューデントのt分布が得られる。 

**時間に依存しない残差**

#### 実行シーケンス・プロット
データ表内の観測値の順序が、各処理組合せの実行順序を表している場合、それらの観測値の残差を観測値の場合順または時間順に対してプロットし、時間依存性の有無を検定する。
これは[実行シーケンス・プロット](../../ch1_eda/section3/eda33p.md)と呼ばれる。

#### 経時傾向を示す実行シーケンス・プロットの例
![Run sequence plot that exhibits a time trend](https://www.itl.nist.gov/div898/handbook/pri/section2/gifs/restime1.gif)

#### 経時傾向を示さない実行シーケンス・プロットの例
![Run sequence plot that exhibits no time trend](https://www.itl.nist.gov/div898/handbook/pri/section2/gifs/restime2.gif)

#### 実行シーケンス・プロット例の解釈
図2.4の残差は時間傾向を示唆しているのに対し、図2.5には見られない。
図2.4からは、調査が進むにつれてシステムが徐々に低い値へと偏位していたことが示唆される。
極端な場合、装置の偏位により、データの変動を説明する能力が極めて低いモデル（R²が低い）が作られることになる。

調査に中心点を含む場合、時間的傾向が存在すれば、時間順にプロットすることでより明確に把握できる。
また、生応答を時系列でプロットすると、残差プロットでは検出できない工程傾向の変化を検出できる場合もある。 

**残差と対応する予測値のプロット**

#### 推定値の大きさに伴う残差増加の確認
残差を適合応答値に対してプロットすると、適合値の大きさにかかわらず、0の周囲に無作為に散らばった点の分布が得られるはずである。
しかし、実際には、適合値が大きくなるにつれて残差値も増加することがよくある。
この場合、残差の雲は「漏斗状」となり、広い端が大きな適合値の方向を向く。
つまり、応答値が大きくなるにつれて、残差の散らばりもますます大きくなる。
符号付き値の代わりに残差の絶対値をプロットすると、「くさび形」の分布が得られ、各グラフには傾向を示すのに役立つ平滑化関数が追加されている。

#### 残差の増加を示す残差と値の散布図
![Residuals versus fitted values plot showing increasing residuals](https://www.itl.nist.gov/div898/handbook/pri/section2/gifs/respred1.gif)

#### 残差の増加を示さない残差と適合値の散布図
![Residuals versus fitted values plot that does not show increasing residuals](https://www.itl.nist.gov/div898/handbook/pri/section2/gifs/restime2.gif)

#### 残差対適合値プロットの解釈
図2.6のような応答値が大きくなるにつれて絶対残差が大きくなる傾向を示す残差分布は、応答を変換すべきであることを示唆し、対数や平方根などでモデル化する（収縮変換）。
このように応答を変換すると、予測変数との関係が単純化され、より単純なモデルが得られる。
後の節で、変換についてさらに詳しく説明する。
図2.7は、散らばりを抑えるために応答変数を変換した後の残差をプロットしたものである。
縦軸の目盛りの違いに注意する。

#### 2次項を追加した残差と因子設定のプロット
![Sample residuals versus factor setting plot after adding quadratic term](https://www.itl.nist.gov/div898/handbook/pri/section2/gifs/resx2.gif)

#### 残差と因子設定プロットの解釈
図2.8は、残差の大きさが予測の設定関数に応じて変化したことを示している。
このようなグラフは、モデルに予測子に関する高次項が必要であるか、あるいは例えば対数や平方根を用いて予測子を変換すべきであることを示唆している。
図2.9は、2次項を追加した後の同じ応答の残差を示している。
図2.9において、他の残差から大きく離れている1つの点に注目する。
この点は「外れ値」である。
つまり、その位置は調査でこの予測に使用された値の範囲内に十分に収まっているが、その結果はモデルが予測した値よりもやや低かったのである。
曲率の存在を示す兆候として、これらのグラフには「しかめっ面」や「笑顔」に似た痕跡が見られる。

#### 1つまたは複数の高次項を省いた、標本残差と因子設定の関係を示すプロット
![Sample residuals versus factor setting plot lacking one or more higher-order terms](https://www.itl.nist.gov/div898/handbook/pri/section2/gifs/resx3.gif)

#### プロットの解釈
図2.8および図2.9に示された例では、明らかに5水準の予測子が含まれている。
この実験では、応答曲面計画が採用された。
中心点を含む単純要因計画において、検討中の応答モデルに1つ以上の高次項が欠落している場合、残差と因子設定の関係を示すプロットは、図2.10のようになる。

#### 湾曲の存在を示すグラフ
このグラフには曲率が存在するという明確な兆候が示されているが、計画の構造上、その曲率の原因を特定することはできない。
そのような状況で他の予測子を用いて作成したグラフも、非常に似たような外観になる。
