# 5.2.1. 測定システムは対応可能か

#### ほとんどの実験において重要な要素である計測能力
すべての実験を終了した後に、手持ちの測定機器では期待していた変化を測定できないことが判明しても、何の役にも立たない。
実験自体に着手する前に、この点を確認しておく。
測定工程の特徴付けは、[2章](../../ch2_mpc/mpc.md)で解説している。

#### 測定機器のSPC検査
さらに、特に実験試料が長期間に渡る測定のために納品予定の場合は、実験プロジェクトの開始から終了に至るまで、すべての測定機器に対してSPC（すなわち品質管理）検査を継続して行うことが望ましい。
不可解な実験結果は、多くの場合、計測システムにおける「不具合」に起因していることがよくある。
