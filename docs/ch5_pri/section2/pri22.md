# 5.2.2. 工程は安定しているか

#### 実験の一環として、工程の安定性を検証する計画を立てる
実験実行には、「標準」の工程設定値、あるいは少なくとも何らかの標準的な操作処方に基づいて行われる対照実験を含めるべきである。
実験は、こうした対照実験で開始し、終了すべきである。
これら対照実験の結果をプロットすることで、実験中に基礎となる工程自体が偏位したりズレたりしたかが判る。

安定した工程で実験を行うことが望ましい。
しかし、それが難しい場合は、実験の解析において工程の不安定性を考慮に入れなければならない。
例えば、平均値が時間（または実験の試行）とともにズレている場合、実験モデルに傾向の項を含める必要がある（すなわち、時間変数または試行番号変数を組み込む必要がある）。
