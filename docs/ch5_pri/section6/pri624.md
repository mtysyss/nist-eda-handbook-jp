# 5.6.2.4. 主効果と交互作用：ブロック・プロット

#### ブロック・プロット
[ブロック・プロット](../section5/pri595.md)は、DOE平均プロットやDOE交互作用効果プロットを補完する有用な手法であり、因子の重要性を確認し、主効果に関する結論の頑健性を確立し、交互作用の存在を判断するために用いられる。

ブロック・プロットでは、各バーの相対的な位置ではなく、バーの高さが重要である。
したがって、ブロックが互いに「どこにあるか」ではなく、ブロックの大きさや内部の符号に注目する。

ちなみに、一部実施要因計画の場合、残りの 6因子すべての組合せを表示することはできない。
ここでは、2つの頑健性因子を恣意的に選択しており、その結果、比較対象となる 4ブロックが得られる。

![the block plot shows no significant interactions](https://www.itl.nist.gov/div898/handbook/pri/section6/inn/gifs/blockp_r.gif) {: .text-center}

#### ブロック・プロットからの結論
ブロック・プロットから以下の結論を導き出す。

1. 因子の相対的な重要度：2つの「外れ値」の影響で縦軸が拡大されているため、このブロック・プロットからは特に明確な傾向は読み取れない。
別の尺度（例：LOG(Y)）で変換したデータに基づくブロック・プロットの方が、より有益な情報を得られるだろう。
