# 5.6.2.9. 次の手順：DOE等高線図

#### 目的
[DOE等高線図](../section5/pri59a.md)は、次の実験反復において、最も重要な2因子について、最適設定値を決定するために用いられる。

これまでのプロットから、*X*<sub>2</sub>（溶質）と *X*<sub>7</sub>（ホーンの深さ）が最も重要な2因子であることが判明した。 

#### DOE等高線図の例

![the DOE contour plot identifies best settings for 2 most important factors X2 and X7](https://www.itl.nist.gov/div898/handbook/pri/section6/inn/gifs/dexcon_r.gif){: .text-center}

#### DOE等高線図からの結論
DOE等高線図から以下の結論を導き出すことができる。

1. *X*<sub>2</sub> の最適な（光強度が高い）設定は「-」であり、*X*<sub>7</sub>の最適な設定は「-」である。
この組合せでは、平均応答値は約224となる。
これら要因の他の組合せにおける2番目の平均応答値は、わずか 76 に過ぎない。

2. 等高線の非線形な性質は、*X*<sub>2</sub> \* *X*<sub>7</sub> 交互作用が重要であることを示唆している。

3. プロットの左側では、上から下に向かって、等高線は 0から始まり、50刻みで増加し、400で終わる。
また、プロットの下側では、右から左に向かって、等高線は 0から始まり、50刻みで増加し、400で終わる。
<br>
例えば光強度を 400にするためには、外挿による最適設定は (*X*<sub>2</sub>, *X*<sub>7</sub>) = (-2, -2) であることが示唆される。  

4. このような外挿は、*X*<sub>2</sub> と *X*<sub>7</sub> が連続的な因子である場合にのみ意味をなす。
しかし、この事例ではそうではない。
この例では、*X*<sub>2</sub> は溶質（-1＝砂糖、+1＝グリセロール）であり、*X*<sub>7</sub> はフラスコのクランプ状態（-1＝クランプなし、+1＝クランプあり）である。
両方の因子は離散的であるため、外挿による設定は不可能である。
