# 5.6.1.10. 適合モデルの活用

#### モデルからのさらなる知見
本研究の主目的は適合モデルの導出ではなかったが、さらなる知見を得るという点で2つの利点がある。

1. 大域予測
2. 最適設定の大域的決定

#### 大域的予測
実験で使用した点以外の点における応答をどのように予測すればよいか。
この予測式は、3因子について、-1 および +1 値で符号化された組合せ8つにおいて、良好な結果を与える。

1. *X*<sub>1</sub> = 巻数 = 90 および 180
2. *X*<sub>2</sub> = 巻線距離 = 0.38 および 1.14
3. *X*<sub>3</sub> = 線径 = 40 および 48

しかし、例えば次のような目標値設定の場合、検出器からはどのような結果が得られると予想されるか。

1. 巻数 = 150
2. 巻線距離 = 0.50
3. 線径 = 46

適合式に基づき、まず目標値を次のように符号化目標値に変換する。

$$ \text{符号化された目標値} = -1 + 2 * (\text{目標値}-\text{下限})/(\text{上限}-\text{下限}) $$

したがって、符号化された目標値は

1. $` X_1 = -1 + 2 * (150-90)/(180-90) = 0.333333 `$
2. $` X_2 = -1 + 2 * (0.50-0.38)/(1.14-0.38) = -0.684211 `$
3. $` X_3 = -1 + 2 * (46-40)/(48-40) = 0.5000 `$

したがって、生データ

$$（\text{巻数、巻線距離、線径}）＝（150、0.50、46）$$

は、符号化された

$$ (X_1, X_2, X_3) = (0.333333, -0.684211, 0.50000) $$

という -1 から +1 の尺度上の値に変換される。

これらの符号化された値を適合式に代入すると、期待どおり、予測値は 

$$ \hat{Y} = 2.65875 + 1.55125(0.333333) - 0.43375(-0.684211)= 3.47261 $$ 

上記の手順は、任意の巻数、距離、および線径に対して実行可能である。
ただし、データ点の頂点付近で良好な式であっても、因子空間のあらゆる場所で必ずしも良好であるとは限らないという、通常の注意が適用される。
補間は外挿よりも多少安全であるが、もちろん、良い結果が得られるとは保証されない。
（本例のように）中心点で追加データが収集され、中心点データが、適合モデルに基づいて予測された中心点値と良好に一致していることが判明していれば、補間に対してより安心感を持てるだろう。
今回の事例では、そのようなデータがなかったため、厳しい現実として、この方程式を使用する者は、与えられたデータ集合からはどちらとも断定できない仮定を置いていることになる。
その仮定を踏まえて、限られた元データ集合（8点）をはるかに超える予測値を慎重かつ洞察力豊かに与える方法を示した。 

#### 最適設定の大域的決定
各因子の最適設定を決定するために、[DOE等高線図](../section5/pri59a.md)を利用する。
DOE等高線図は、最も重要な2因子について作成し、頂点（すなわち、因子変数の -1 および +1 の設定）における応答変数の値を示し、応答変数を最大化（または最小化）する方向を示す。
重要因子が2つ以上ある場合は、重要因子をそれぞれ2つずつ用いた一連のDOE等高線図を作成する。

#### DOE等高線プロット
以下は、巻数および巻線距離のDOE等高線図である。

![The DOE contour plot identifies *X*<sub>1</sub>=-1 and *X*<sub>2</sub>=1 as the optimal settings](https://www.itl.nist.gov/div898/handbook/pri/section6/pri61a_r01.gif) 
{: .text-center}

応答変数（渦電流）の最大値は、*X*<sub>1</sub>（巻数）が -1、*X*<sub>2</sub>（巻線距離）が +1 の点に対応する。
等高線図の右下隅は応答変数を最大化する方向に対応している。
この情報は、実験の次の段階を計画するときに活用する。
