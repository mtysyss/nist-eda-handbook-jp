# 5.6.2.7. 重要因子：半正規確率プロット

#### 目的
[半正規確率プロット](../section5/pri598.md)は、重要な効果と重要でない効果を区別するために用いられる。

#### 半正規分布の確率プロットの例
![the half-normal probability plot identifies the important factors](https://www.itl.nist.gov/div898/handbook/pri/section6/inn/gifs/probpl_f.gif){: .text-center}

#### 半正規確率プロットからの結論
半正規確率プロットから以下の結論を導き出せる。

1. プロット上の点は、2つの明確な塊に分類される。  
    * 上側の群（|効果| > 60）。  
    * 下側の群（|効果| < 20）。  

2. 上側の群には、以下の効果が含まれている。  
*X*<sub>2</sub>、*X*<sub>7</sub>、*X*<sub>1</sub> \* *X*<sub>3</sub>（および交絡）、*X*<sub>1</sub>、*X*<sub>3</sub>、*X*<sub>2</sub> \* *X*<sub>3</sub>（および交絡）、*X*<sub>1</sub> \* *X*<sub>2</sub>（および交絡）  
これらの効果は間違いなく重要であると見なすべきである。  

3. 残りの効果は一直線上に並び、下側の塊を形成している。  
これらの効果は比較的重要ではないとみなされる。  

4. 効果IDおよび交絡構造は右端に記載されている（例 13:13+27+46）。
