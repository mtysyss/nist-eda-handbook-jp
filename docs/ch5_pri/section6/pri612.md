# 5.6.1.2. 初期プロット／主効果

#### データのプロット：順序付きデータ・プロット
分析の最初の手順は、[順序付きデータプロット](../section5/pri591.md)を作成することである。

![The ordered data plot shows factor 1 clearly important, factor 2somewhat important](https://www.itl.nist.gov/div898/handbook/pri/section6/splett3/gifs/order_f.gif) {: .text-center}

#### 順序付きデータ・プロットからの結論
並べ替えられたデータのプロットに基づいて、以下の結論を導き出す。

1. 重要な要因：応答値が最も高いデータ4つでは *X*<sub>1</sub> = + であり、応答値が最も低いデータ4つは *X*<sub>1</sub> = - である。
これは、*X*<sub>1</sub> が最も重要な要因であることを示唆している。
*X*<sub>1</sub> = - の場合、*X*<sub>2</sub> の - 値は *X*<sub>2</sub> の + 値よりも高い。
同様に、*X*<sub>1</sub> = + のときは、*X*<sub>2</sub> の - 値が *X*<sub>2</sub> の + 値よりも高くなる。
これは、*X*<sub>2</sub> が重要ではあるものの、*X*<sub>1</sub> ほどではないことを示唆している。
*X*<sub>3</sub> については明確な傾向は見られない。
2. 最適な設定：この実験では、デバイスを検出器として使用しているため、高い感度が望ましい。
これを踏まえ、最適な設定の最初の候補として (*X*<sub>1</sub> = +1, *X*<sub>2</sub> = -1, *X*<sub>3</sub> = どちらでもよい) が導き出された。

#### データのグラフ化：DOE散布図
分析の次の手順では、[DOE散布図](../../ch1_eda/section3/eda33b.md)を作成する。

![plot shows clear effect for factor 1, less clear for factors 2 and 3](https://www.itl.nist.gov/div898/handbook/pri/section6/splett3/gifs/dexsct_f.gif) {: .text-center}

#### DOE散布図からの結論
DOEの散布図に基づいて、以下の結論を導き出す。

1. 重要な要因：*X*<sub>1</sub>（巻数）は明らかに重要である。
*X*<sub>1</sub> = -1 のときは、4つの感度値すべてが低く、 *X*<sub>1</sub> = +1 のときは、4つの感度値すべてが高い。
 *X*<sub>2</sub> （巻線距離）はそれほど重要ではない。
 *X*<sub>2</sub> = -1 の場合の4つの感度は、全体として、*X*<sub>2</sub> = +1 の場合の4つの感度よりもわずかに高い。
*X*<sub>3</sub>（線径）はまったく重要ではないと考えられる。
感度は、 *X*<sub>3</sub> の設定にかかわらず（平均的には）ほぼ同じである。
2. 最適な設定：この実験では、本装置を検出器として使用しているため、高い感度が望ましい。
この点を踏まえると、最適な設定の第一候補として（*X*<sub>1</sub> = +1、*X*<sub>2</sub> = -1、*X*<sub>3</sub> = いずれでもよい）が導き出される。
3. 顕著な外れ値は見られない。

#### 主効果の確認：DOE平均プロット
主な問いの一つは、最も重要な要因は何か、である。
順序付きデータ・プロットとDOE散布図はデータを要約した有用なプロットである。
これらのプロットの両方から、*X*<sub>1</sub> は明らかに重要であり、*X*<sub>2</sub> は多少重要であり、*X*<sub>3</sub> はおそらく重要ではないことが示される。

[DOEの平均プロット](../section5/pri593.md)は主効果を示している。
これは、重要な要因を解釈する上で、おそらく最も分かりやすい指標である。

![plot shows factor 1 is most significant, factor 2 next most significant, factor 3 least significiant](https://www.itl.nist.gov/div898/handbook/pri/section6/splett3/gifs/dexmea_f.gif) {: .text-center}

#### DOE平均プロットからの結論
DOE平均プロット（または主効果プロット）は、DOE散布図の順序を裏付けるものであるが、平均値間の目視による距離が因子効果の最小二乗推定の近似値を示すことから、さらなる情報が得られる。
このDOE平均プロットから、以下の結論を導き出すことができる。

1. 重要な因子： 
    *X*<sub>1</sub> （効果＝大：約3Ω） 
    *X*<sub>2</sub> （効果＝中：約-1Ω）
    *X*<sub>3</sub> （効果＝小：約1/4Ω）
    
2. 最適な設定：前述と同様に、（平均的に）感度を最大化する因子設定を選択する。 

$$ (*X*<sub>1</sub>,*X*<sub>2</sub>,*X*<sub>3</sub>) = (+,-,+) $$ 

#### プロットの比較
これらのプロットはすべて、主に最も重要な要因を特定するために使用される。
DOE平均プロットは、生データではなく要約統計量をプロットすることから、主効果を最も明確に示す。
ただし、それでもなお、順序付きデータ・プロット や DOE散布図（あるいはその両方）を作成することが推奨される。
これらは生データをプロットするため、DOE平均プロットでは見落とされがちなデータの特徴を明らかにできる場合がある。
