# 5.6.1.5. 主効果および交互作用の効果の推定

#### 効果の推定
効果推定値は、前のページの[DOE交互作用プロット](pri613.md)に示されているが、表形式でも示す。
 
2<sup>3</sup> 要因計画に対する完全モデルは以下の通り。

$$ \begin{eqnarray\*}
Y &=& \mu + \beta_1 X_1 + \beta_2 X_2 + \beta_3 X_3 +\beta_{12} X_1 X_2 \\
&+& \beta_{13} X_1 X_3 + \beta_{23} X_2 X_3 +\beta_{123} X_1 X_2 X_3 + \epsilon
\end{eqnarray\*} $$

2水準要因計画によるデータは、最小二乗回帰を用いて分析することができる。
回帰係数は因子変数の 1単位あたりの変化を表しており、交互作用プロットに示される効果は、因子の高水準と低水準間の変化を表しているため、回帰係数の2倍の大きさとなる。 

#### 効果の推定値
完全モデルに対する最小二乗回帰分析による母数推定値は以下の通り。

```
     Effect    Estimate     
     ------    --------     
     Mean       2.65875     
     X1         1.55125     
     X2        -0.43375     
     X3         0.10625     
     X1*X2      0.06375     
     X1*X3      0.12375     
     X2*X3      0.14875     
     X1*X2*X3   0.07125
```
 

データに対して完全モデルを適合させたため、誤差の自由度はなく、有意性検定は利用できない。

効果を（平均値を除いて）大きい順に並べ替えると、最も重要な4つの要因は、*X*<sub>1</sub>（巻数）、*X*<sub>2</sub>（巻線距離）、*X*<sub>2</sub>\* *X*<sub>3</sub>（巻線距離と線径の交互作用）、および *X*<sub>1</sub> \* *X*<sub>3</sub>（巻数と線径の交互作用）である。
