# 5.6.2.5. 重要因子：Youden プロット

#### 目的
[DOE Youden プロット](../section5/pri596.md)は、重要因子と重要でない因子を区別するために用いられる。

#### Youden プロットの例

![the Youden plot identifies the important factors](https://www.itl.nist.gov/div898/handbook/pri/section6/inn/gifs/youden_f.gif){: .text-center}

#### Youden プロットからの結論
Youden プロットから以下の結論を導き出せる。

1. 左上隅には、交互作用項 *X*<sub>1</sub>\* *X*<sub>3</sub> と、主効果 *X*<sub>1</sub> と *X*<sub>3</sub> が示されている。
2. 右下隅には、主効果 *X*<sub>2</sub> と *X*<sub>7</sub>、および、交互作用項 *X*<sub>2</sub>\* *X*<sub>3</sub> と *X*<sub>1</sub>\* *X*<sub>2</sub> が位置している。
3. 残りの項は中央に集まっており、これはそれら効果の平均値が類似している（したがって効果はゼロに近い）ことを示し、したがって、それらの効果は比較的重要ではない。
4. プロットの右端には交絡構造が示され（例 13：13+27+46）、（プロット上の）*X*<sub>1</sub>\* *X*<sub>3</sub> に関する情報は、 *X*<sub>1</sub>\* *X*<sub>3</sub> が *X*<sub>2</sub>\* *X*<sub>7</sub> と *X*<sub>4</sub>\* *X*<sub>6</sub> と交絡しているという事実を考慮して解釈されなければならないことを示唆している。
