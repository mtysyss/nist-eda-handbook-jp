# 5.6.1.4. 主効果および交互作用：ブロック・プロット

#### ブロック・プロット
[ブロック・プロット](../section5/pri595.md)は、DOE平均プロットやDOE交互作用効果プロットを補完する有用な手法であり、因子の重要性を確認し、主効果に関する結論の頑健性を確立し、交互作用の有無を判断するために用いられる。
具体的には、

1. 以下の最初のプロットは、*X*<sub>1</sub> は重要か、という問いに答える。
*X*<sub>1</sub> が重要である場合、その重要性は *X*<sub>2</sub> と *X*<sub>3</sub> の4つの設定すべてにおいて頑健であるか。 

2. 以下の2番目のプロットは、*X*<sub>2</sub> は重要か、という問いに答える。
*X*<sub>2</sub> が重要である場合、その重要性は *X*<sub>1</sub> と *X*<sub>3</sub> の4つの設定すべてにおいて頑健であるか。 

3. 以下の 3番目のプロットは、*X*<sub>3</sub> は重要か、という問いに答えるものである。
もし *X*<sub>3</sub> が重要であるならば、その重要性は *X*<sub>1</sub> と *X*<sub>2</sub> の4つの設定すべてにおいて頑健であるか。

ブロック・プロットにおいて重要なのは棒の高さであり、各棒の相対的な位置ではない。
したがって、私たちはブロックが互いに「どこにあるか」ではなく、ブロックの大きさや内部構造に注目する。

#### ブロック・プロットからの結論
ブロック・プロットは、さまざまな条件における因子効果の一貫性（頑健性）の程度によって因子の重要度を評価するものであることを思い出す。
この観点から、ブロック・プロットからは以下の結論を導き出すことができる。

1. 因子の相対的重要性：プロット1 のすべての棒の高さ（回転数）は、プロット2 および 3 の棒の高さよりも大きい。
したがって、*X*<sub>1</sub> は *X*<sub>2</sub> および *X*<sub>3</sub> よりも重要である。
2. 統計的有意性：プロット1 において、各棒グラフ内の水準を見ると、4つの棒グラフすべてにおいて、水準2 の応答値が水準1 よりも高いことが確認できる。
偶然にこれが起こる確率は 1/(24) = 1/16 = 6.25% である。
したがって、*X*<sub>1</sub> は 5%水準で統計的に有意に近い。
同様に、図2 についても、4本の棒グラフすべてにおいて水準1 が水準2 よりも大きい。
したがって、*X*<sub>2</sub> は統計的にほぼ有意である。
*X*<sub>3</sub> については、4本の棒グラフすべてにおいて一貫した順序が見られないため、*X*<sub>3</sub> は統計的に有意ではない。
厳密に言えば、*X*<sub>1</sub> と *X*<sub>2</sub> は統計的に有意ではない（6.25％は 5％未満ではないため）。
一方、このような準有意性は、分析者に対して、これらの要因が実際には重要である可能性を示唆しており、したがってさらなる検討が必要である。
<br><br>
なお、統計的有意性を判定する一般的な方法は、分散分析（ANOVA）を行うことである。
ANOVAは正規性の仮定に基づいている。
これらの正規性の仮定が成り立つ場合、ANOVAは統計的有意性を判定する上で最も強力な手法である。
ブロック・プロット法の利点は、ANOVAよりも厳密でない仮定に基づいている点にある。
探索的な段階においては、重要な因子に関する結論が、幅広い仮定の下でも有効であることを知っておくことは有用である。
3. 交互作用：*X*<sub>1</sub> は、4本の棒の高さに体系的な変化は見られないため、*X*<sub>1</sub> が *X*<sub>2</sub> や *X*<sub>3</sub> のいずれかと交互作用している証拠はない。
同様に、 *X*<sub>2</sub> についても交互作用の証拠は見られない。
