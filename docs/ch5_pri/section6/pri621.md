# 5.6.2.1. 背景とデータ

#### 背景と動機
音響発光とは、音響エネルギーを光に変換する現象である。
超音波ホーンを用いて、媒質（通常は水）中の気泡を共振させる。
気泡は超音波によって圧縮され、その後崩壊し、発光するプラズマとなる。

物理学界全般において、音響発光に関する研究は、その特性を解明し、理解を深め、実用的な用途を見出すために進められている。
この分野における未解決の課題の一つは、音響発光が低温核融合に応用できるかどうかという点である。

NISTが音響発光の研究を行っている動機は、その現象が物理的試料の溶解に適しているかを評価することにある。
これは、均質な標準参照物質（SRM）の製造に必要とされている。
最大の溶解は、最大のエネルギーと最大の光強度と一致すると考えられている。
最大の溶解を目指す究極の動機は、それによって、試料中のアルファ線およびベータ線を放出する放射性核種の定量精度が向上するからである。

NIST実験の目的は、音響発光の光強度に影響を与える重要な要因を特定し、高強度を達成できる予測可能な要因の最適設定を明らかにすることであった。
当初 49項目あった要因リストは、物理的な理由に基づき、次の要因7つに絞り込まれた：モル濃度（溶質の量）、溶質の種類、pH、水中のガス種類、水深、ホーン深さ、およびフラスコの固定方法。

時間的制約により、実験期間は約 1ヶ月になり、その結果、実験回数は最大で 約20回に制限された。
7因子、2水準一部実施要因計画（分解能 Ⅳ）が構築され、実行された。
因子の水準設定は以下の通りである。

NIST物理学研究所の Eva Wilcox および Ken Inn が、1999年にこの実験を実施した。
NIST統計工学部門の Jim Filliben が、実験データの解析を行った。

#### 応答変数、因子変数、および、因子水準の設定
この実験では、以下の応答変数および要因変数を用いる。

1. 応答変数 (*Y*) = 音響発光光強度。

2. 因子1 (*X*<sub>1</sub>) = モル濃度（溶質の量）
符号化は、0.10molを -1、0.33molを +1。

3. 因子2 (*X*<sub>2</sub>) = 溶質の種類
符号化は、糖は -1、グリセロールは +1。

4. 因子3 (*X*<sub>3</sub>) = pH
符号化は、3を -1 、11を +1。

5. 因子4 (*X*<sub>4</sub>) = 水中のガスの種類
符号化は、ヘリウムは -1、空気は +1。

6. 因子5 (*X*<sub>5</sub>) = 水深
符号化は、半分は -1、満水は +1。

7. 係数6 (*X*<sub>6</sub>) = ホーンの深さ
符号化は、5mmは -1、10mmは +1。

8. 因子7 (*X*<sub>7</sub>) = フラスコの固定
符号化は、固定なしは -1、固定ありは +1。

このデータ集合には 16個の観測値が含まれている。
これは、中心点を含まない 2<sup>7-3</sup> の実験計画である。

#### 実験の目的
この事例研究では、2<sup>7-3</sup> の一部実施要因計画の分析について解説する。
この事例研究の目的は以下の通り。

1. 音響発光光輝度に影響を与える重要な要因を特定する。
   具体的にはこの輝度を最大化することを目指している。

2. 音響発光光強度を最大化するために、要因7つの最適設定を決定する。
