# 5.6.2.2. 初期プロット／主効果

#### データのプロット：順序付きデータ・プロット
分析の最初の手順として、[順序付きデータプロット](../section5/pri591.md)を作成する。

![The ordered data plot shows two points that clearly stand out](https://www.itl.nist.gov/div898/handbook/pri/section6/inn/gifs/order_f.gif){: .text-center} 

#### 順序付きデータ・プロットからの結論
並べ替えられたデータのプロットに基づいき、以下の結論を導き出す。

1. 2つの点がはっきりと際立っている。
最初の 13点は 50 から 100 の範囲にあり、次の 1点は 100 より大きく、最後の 2点は 300 より大きくなっている。
2. 重要な因子：これら 2つの最も高い値について、要因*X*<sub>1</sub>、*X*<sub>2</sub>、*X*<sub>3</sub>、および *X*<sub>7</sub> は同じ値（すなわち、それぞれ＋、－、＋、－）であるのに対し、*X*<sub>4</sub>、*X*<sub>5</sub>、および *X*<sub>6</sub> は異なる値をとっている。
したがって、*X*<sub>1</sub>、*X*<sub>2</sub>、*X*<sub>3</sub>、および *X*<sub>7</sub> は潜在的に重要な因子であるのに対し、*X*<sub>4</sub>、*X*5、および *X*<sub>6</sub> は重要ではないと結論づけられる。
3. 最適な設定：最初の試行では、観測された最大値（*Y* = 373.8）における設定を使用する。
この最大値に対する設定は（+, -, +, -, +, -, -）である。

#### データのグラフ化：DOE散布図
分析の次の手順では、[DOE散布図](../../ch1_eda/section3/eda33b.md)を作成する。

![plot shows 2 points clearly dominate](https://www.itl.nist.gov/div898/handbook/pri/section6/inn/gifs/dexsct_r.gif){: .text-center} 

#### DOE散布図からの結論
DOEの散布図に基づいて、以下の結論を導き出す。

1. 重要な要因：ここでも、2点がプロットを支配している。
*X*<sub>1</sub>、*X*<sub>2</sub>、*X*<sub>3</sub>、および *X*<sub>7</sub> については、これら2点は同じ設定（+, -, +, -）かであるのに対し、*X*<sub>4</sub>、*X*<sub>5</sub>、および *X*<sub>6</sub> については、異なる設定になっている。
したがって、*X*<sub>1</sub>、*X*<sub>2</sub>、*X*<sub>3</sub>、および *X*<sub>7</sub> は重要である可能性があり、*X*<sub>4</sub>、*X*<sub>5</sub>、および *X*<sub>6</sub> はおそらく重要ではないと結論づける。
2. 最適な設定：最適な設定に関する最初の検討の結果、(*X*<sub>1</sub> = +, *X*<sub>2</sub> = -, *X*<sub>3</sub> = +, *X*<sub>4</sub> =どちらでも, *X*<sub>5</sub> = どちらでも, *X*<sub>6</sub> = どちらでも, *X*<sub>7</sub> = -) となった。

#### 主効果の確認：DOE平均プロット
[DOE平均プロット](../section5/pri593.md)を主効果をより明確に示すために作成する。 

![plot shows X2 and X7 to have the largest effect with X1 and X3 only slightly behind](https://www.itl.nist.gov/div898/handbook/pri/section6/inn/gifs/dexmea_r.gif){: .text-center} 

#### DOE平均プロットからの結論
DOEの平均プロットから以下の結論を導き出す。

1. 重要な要因：  
　　*X*<sub>2</sub>（効果＝大：約－80）       
　　*X*<sub>7</sub>（効果＝大：約－80）  
　　*X*<sub>1</sub>（効果＝大：約70）  
　　*X*<sub>3</sub>（効果＝大：約65）  
　　*X*<sub>6</sub>（効果＝小：約－10）  
　　*X*<sub>5</sub>（効果＝小：5～10）  
　　*X*<sub>4</sub>（効果＝小：5未満）     
2. 最適な設定：ここでは、各因子を一つずつ順に検討し、音響発光光強度の平均値が最大となる設定を選択する。 

　　(*X*<sub>1</sub>, *X*<sub>2</sub>, *X*<sub>3</sub>, *X*<sub>4</sub>, *X*<sub>5</sub>, *X*<sub>6</sub>, *X*<sub>7</sub>) = (+,-,+,+,+,-,-)

#### プロットの比較
上記3つのプロットはすべて、主に最も重要な要因を特定するために使用する。
DOE平均プロットは生データではなく要約統計量を描画するため、主効果の順序を最も明確に示す。
ただし、順序付きデータ・プロットか DOE散布図（あるいはその両方）の作成を依然として推奨する。
これらは生データをプロットするため、DOE平均プロットでは見落とされがちなデータの特徴を明らかにできる場合がある。

この事例では、順序付きデータ・プロットと DOE散布図が2つの顕著な点をはっきりと示している。
もし DOE平均プロットのみを作成していた場合、この特徴は明らかにはならなかっただろう。

解釈の観点からは、最も重要な因子 *X*<sub>2</sub>（溶質）は、他の因子設定にかかわらず、平均して光強度を約 80 単位変化させる。
他の因子についても同様に解釈される。

最適な設定に関しては、最大応答値に基づいた順序付きデータ・プロットが以下の結果を示したことに留意する。

　　+, -, +, -, +, -, -

なお、3つのプロットで一致しない設定を「.」で示した合意に基づく最適値は次となる。

　　+, -, +, ., +, -, -

設定が一致しない因子*X*<sub>4</sub> は、常にそれ自体が「重要でない」因子として定義されることに留意する。
