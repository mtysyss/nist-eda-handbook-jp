# 5.6.1.7. 中間結論

#### 重要な因子
これまでの各節でのすべてのグラフ分析および定量分析を総合すると、感度に影響を与える最も重要な工学的要因は *X*<sub>1</sub>（巻数）であり、次いで *X*<sub>2</sub>（導線距離）が重要であり、その後に重要度の低い相互作用や *X*<sub>3</sub>（導線径）が続く、と結論づけられる。

#### 最適設定
また、さまざまな分析の結果、高感度検出器にとって（平均的に見て）最適な設計設定は以下の通りであると結論づけられる。

$$ (X_1,X_2,X_3) = (+,-,+) $$

すなわち  
　　巻数 = 180  
　　巻線距離 = 0.38  
　　線径 = 48  

#### データからさらに多くの情報を引き出すために
したがって、非常に現実的な意味でこの分析は完了したと言える。
この実験で掲げた2つの最も重要な目標を達成した。

1. 最も重要な要因についての知見を得る.
 
2. 最適な生産設定を特定する。

一方で、データからはさらに多くの情報を引き出すことが可能であり、それこそが本節および残りの節で取り上げる内容である。

1. まず、因子の順位付け一覧を用いて、どの要因が「重要」で、どの要因が「重要でない」かを客観的に特定するという問題に焦点を当てる。
2. これと並行し、上記で導出した重要因子の部分集合を用いて、「最終的な」予測式を構築する。
この式は、完全なモデル（残差標準偏差が 0、すなわち予測値が生データと一致する）と比較して、精度が高く（残差標準偏差が十分に小さい）、かつ簡潔（項の数が少ない）ものである必要がある。
（残差標準偏差 ＝ 0、すなわち 予測値 ＝ 生データ）ではあるが、過度に複雑（定数＋7項で構成されている）であるのに対し、簡潔（項数が少ない）な「最終的な」予測式を構築する。
