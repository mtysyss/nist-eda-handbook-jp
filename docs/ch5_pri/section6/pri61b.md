# 5.6.1.11. 結論と今後の展望

#### 結論
この事例研究の目的は以下の通りであった。

1. 最も重要な要因を特定する。
2. 各要因に対する最適な設定を特定する。
3. データに対する適切な予測式を導出する。

様々なプロットや分析の結果、巻数（*X*<sub>1</sub>）と巻線距離（*X*<sub>2</sub>）が最も重要な要因であることが示され、このデータに対する適切な予測式は以下の通りである。

$$ \hat{Y} = 2.65875 + 1.55125 X_1 - 0.43375 X_2 $$ 

DOEの等高線図から、各因子の最適な設定値（*X*<sub>1</sub> = -1、*X*<sub>2</sub> = 1）が得られた。 

#### 次の手順
通常、完全実施要因計画や一部実施要因計画は、最も重要な要因を特定するために用いられる。
用途によってはこれで十分であり、それ以上の実験は行われない。
一方、他の用途では、応答変数を最大化（または最小化）することが望まれる。
これには通常、[応答面計画](../section3/pri336.md)が用いられる。
DOEの等高線図は、実験の次の段階において因子変数にどのような設定を用いるべきかについて、指針を与えてくれる。

これは、工学や科学の分野における実験計画において一般的な手順である。
この手法の反復的な性質に注意する。
つまり、通常、すべての疑問に答えるために1つの大規模な実験を計画しない。
むしろ、一連の小規模な実験を実施する。
最初の実験（または一連の実験）は、重要な要因を特定するために使用される。
これらの要因が特定されたら、追加の実験を実施して、これらの最も重要な因子について、応答変数を最大化／最小化する観点から最適設定を微調整する。
この特定の事例研究では、応答曲面法は使用されなかった。
