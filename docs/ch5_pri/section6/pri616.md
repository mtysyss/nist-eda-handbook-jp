# 5.6.1.6. モデル化および予測式

#### 項を追加しても変わらない係数推定値
最小二乗法による推定では、ほとんどの場合、先に追加された項のモデル係数推定値は、その後順次追加された項の内容によって変化する。
例えば、*X*<sub>1</sub> 係数の推定値は、*X*<sub>2</sub> 項がモデルに含まれているかに応じて変化する可能性がある。
しかし、この 2<sup>3</sup> 完全要因計画のように、設計が直交である場合はそうではない。
このような場合、以前に含まれていた項の推定値は項が追加されても変化しない。
つまり、[5.6.1.5節](pri615.md#yatesの表)にある効果推定値一覧は、次第に複雑になるモデルに対する最小二乗法による係数推定値として機能する。

#### 初期モデル：総平均
どの要因も重要でない場合、予測式はすべての応答値の平均（全体平均）を初期値とする。
つまり、

$$ \hat{Y} = 2.65875 $$ 

この例の場合、初期モデルの全体平均は 2.65875 であり、残差標準偏差（適合度の指標）は 1.74106Ω となる。 

#### 考えられる予測式
初期モデルに、絶対値の大きい順に効果を追加し、各効果を追加した後の残差標準偏差を計算する。
予測式とその残差標準偏差を以下に示す。

```                                                         残差 
モデル項                                                     標準偏差
-----------------------------------------------------      ---------
平均 + X1                                                    0.57272
平均 + X1 + X2                                               0.30429
平均 + X1 + X2 + X2*X3                                       0.26737
平均 + X1 + X2 + X2*X3 + X1*X3                               0.23341
平均 + X1 + X2 + X2*X3 + X1*X3 + X3                          0.19121
平均 + X1 + X2 + X2*X3 + X1*X3 + X3 + X1*X2*X3               0.18031
平均 + X1 + X2 + X2*X3 + X1*X3 + X3 + X1*X2*X3 + X1*X2            NA
```

なお、完全モデルはデータに完全に適合していることに留意されたい。
