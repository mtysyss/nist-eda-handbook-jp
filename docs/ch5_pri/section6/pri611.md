# 5.6.1.1. 背景とデータ

#### 背景
本事例研究のデータは、[Capobianco, Splett, および Iyer](../section8/pri8.md#splett)によって実施された研究の一部である。
本研究当時、Capobianco は NIST電磁気学部門の所属であり、Splett と Iyer は NIST統計工学部門の所属であった。

本プロジェクトの目的は、金属の亀裂や破損を検出するための非破壊型の携帯型装置を開発することである。
主な用途としては、航空機の翼における欠陥の検出が挙げられる。
検出器の内部機構は、ひび割れに誘起される検出器の電磁場変化を感知するものであり、これにより、検出器のインピーダンス値に変化が生じる。
インピーダンスの変化は「感度」と呼ばれ、検出器を金属の欠陥のない領域から欠陥のある領域へと移動させるときの感度を最大化することが本実験の副次的な目標である。

#### 統計上の目標
この事例研究では、2<sup>3</sup> 完全要因計画実験の分析について解説している。
この実験における具体的な統計的目標は以下の通り。

1. 感度に影響を与える重要な要因を特定する。
2. 感度を最大化する設定を特定する。
3. 感度と様々な要因との間の関数関係を示す予測式を導出する。

#### ソフトウェア
本事例研究で使用された分析結果は、[Dataplotコード](https://www.itl.nist.gov/div898/handbook/pri/section6/pri611.dp) および [R コード](https://www.itl.nist.gov/div898/handbook/pri/section6/pri611.r)の両方を使用して出力できる。
読者は、データを[テキストファイル](https://www.itl.nist.gov/div898/handbook/datasets/SPLETT3.DAT)としてダウンロードできる。

#### 分析に使用したデータ
検討対象となった検出器の配線に関する要素は3つあった。

1. *X*<sub>1</sub> = 線の巻数
2. *X*<sub>2</sub> = 巻線距離
3. *X*<sub>3</sub> = 線径

本実験において、時間面および費用面から実施可能な最大実行回数は *n* = 10 であったため、2<sup>3</sup> 完全要因実験（*n* = 8 実行を含む）が採用された。
2水準因子設計における通常の単調性の仮定に鑑み、3因子について以下の設定が選択された。

1. *X*<sub>1</sub> = 線巻数：-1 = 90、+1 = 180
2. *X*<sub>2</sub> = 巻線距離：-1 = 0.38、+1 = 1.14
3. *X*<sub>3</sub> = 線径 : -1 = 40, +1 = 48

実験は、8設定を無作為な順序で実行した。
その結果、得られたデータは以下の通り。

```
     Y           X1        X2        X3
    探針        線巻数      巻線   　　線径    実行順  
インピーダンス               距離  
-------------------------------------------------
    1.70         -1        -1        -1         2
    4.57         +1        -1        -1         8
    0.55         -1        +1        -1         3
    3.39         +1        +1        -1         6
    1.51         -1        -1        +1         7
    4.59         +1        -1        +1         1
    0.67         -1        +1        +1         4
    4.29         +1        +1        +1         5

```

独立変数は +1 および -1 として符号化されていることに注意のこと。
これらは、各変数水準における低値および高値の設定を表している。
要因計画では、各因子（独立変数）ごとに2水準を持ち、それらの水準は -1 および +1 として符号化される。
これは、分析を簡略化できるデータの尺度調整手法である。
必要に応じて、これらの尺度調整された値を、提示のためにデータの元単位に換算し直すことも可能である。
