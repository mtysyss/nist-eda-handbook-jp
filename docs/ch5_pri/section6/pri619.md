# 5.6.1.9. 適合モデルの妥当性確認

#### モデルの妥当性確認
[重要因子と簡潔な予測](pri618.md#conclusions)節では、以下のモデルを選択した。

$$ \hat{Y} = 2.65875 + 1.55125 X_1 - 0.43375 X_2 $$

このモデルの残差標準偏差は 0.30429 である。

次の手順は、[モデルの妥当性確認](../../ch4_pmd/section4/pmd44.md)である。
モデル妥当性確認の主な方法は、残差グラフによる分析である。
つまり、観測データ *Y* とモデルから得られた予測値 $` \scriptsize \hat{Y} `$ との差をさまざまなグラフでプロットする。
例えば、設計点 (-1, -1, -1) については、（[背景とデータ](pri611.md#datatable)節にある）観測データが *Y* = 1.70 であるのに対し、この設計点に対する上記の適合モデルからの予測値は

$$ \hat{Y} = 2.65875 + 1.55125 (-1) - 0.43375 (-1) $$

となり、残差は 0.15875 となる。 

#### 残差表
モデルが適切に適合していれば、$` \scriptsize \hat{Y} `$ は8つの設計点すべてにおいて *Y* の近くにあるはずである。
したがって、残差8つはすべてゼロに近いはずである。
このデータを用いたモデルの8つの予測値と残差は次のとおり。

```
   X1   X2   X3   観測値    予測値     残差
----------------------------------------------
   -1   -1   -1    1.70    1.54125    0.15875
   +1   -1   -1    4.57    4.64375   -0.07375
   -1   +1   -1    0.55    0.67375   -0.12375
   +1   +1   -1    3.39    3.77625   -0.38625
   -1   -1   +1    1.51    1.54125   -0.03125
   +1   -1   +1    4.59    4.64375   -0.05375
   -1   +1   +1    0.67    0.67375   -0.00375
   +1   +1   +1    4.29    3.77625    0.51375
```

#### 残差の標準偏差
典型的な残差の大きさはどの程度か。
これを計算する方法はいくつかあるが、統計的に最適な指標は残差の標準偏差である。

$$ s_{res} = \sqrt{ \frac{\sum_{i=1}^N {r_i^2}} {N-P}} $$

ここで、*r*<sub>i</sub> は i 番目の残差を表し、*N* = 8 は観測数、*P* = 3 は適合係数数である。
[予測式の表](pri616.md#predeq)から、残差標準偏差は 0.30429 である。

#### 残差の振る舞い
予測式が適切であれば、その式から得られる残差は[無作為な抽出値](../../ch1_eda/section2/eda21.md)（通常は近似的に正規分布に従う）のように振る舞い、また、無作為であると想定されるため、いかなる因子とも構造的な関係を持たないはずである。
これには、あらゆる潜在的な項（*X*<sub>1</sub>、*X*<sub>2</sub>、*X*<sub>3</sub>、*X*<sub>1</sub>\* *X*<sub>2</sub>、*X*<sub>1</sub>\* *X*<sub>3</sub>、*X*<sub>2</sub>\* *X*<sub>3</sub>、*X*<sub>1</sub>\* *X*<sub>2</sub>\* *X*<sub>3</sub>）が含まれる。

さらに、モデルが適切かつ完全であるならば、残差は記録されている可能性のある他の**いかなる**変数とも構造的な関係を持たないはずである。
特に、これには実行順序（時間）が含まれるが、実際には、時間と相関するあらゆる物理的または環境的変数の代用変数として機能している。
理想的には、残差の散布図はすべて構造を持たない状態であるべきである。
何らかの構造を示す散布図は、因子が予測式の一部として正式に組み込まれるべきであったことを示唆している。

したがって、予測式の妥当性確認をするということは、時間とともに変動する変数を含め、他の変数が不注意により予測式から除外されていないかを最終的に確認することを意味する。

そして、グラフによる残差分析は、残差と3因子および4交互作用との散布図（これらすべてのプロットは構造を持たないはずである）、残差と実行順序との散布図（これも構造を持たないはずである）、および残差の正規確率プロット（これはほぼ直線的であるべきである）から構成される。
以下にこれらのプロットを示す。

#### 結論
上記のグラフに基づき、以下の結論を導き出す。

1. 主効果と交互作用：*X*<sub>1</sub>および*X*<sub>2</sub> の散布図は「平坦」である（*X*<sub>1</sub> および *X*<sub>2</sub> がモデルに明示的に含まれていたため、当然である）。
*X*<sub>3</sub> のプロットは、 *X*<sub>1</sub>\* *X*<sub>3</sub> 、*X*<sub>2</sub>\* *X*<sub>3</sub> 、および *X*<sub>1</sub>\* *X*<sub>2</sub>\* *X*<sub>3</sub> のプロットと同様に、ある程度の構造を示している。
*X*<sub>1</sub>\* *X*<sub>2</sub> のプロットにはほとんど構造が見られない。
結果として、これらの散布図の相対的な順序は、「非重要」因子の相対的な順序と（これもまた当然ながら）非常に一致している。
[効果の表](pri615.md#yatesの表)および *X*<sub>2</sub>\* *X*<sub>3</sub> の残差プロットから判断すると、モデルに追加すべき影響力の大きい項の第3位は *X*<sub>2</sub>\* *X*<sub>3</sub> となる。
事実上、これらのプロットは、効果順位付けについて、より高解像度で確認を提供している。
一方、これらの他因子はいずれも、前節で示した基準を「満たさなかった」ため、これらの要因が一見影響力があるように見えても、モデルに追加するには依然として影響力が不十分である。

2. 時間偏位：実行順序の散布図は無作為である。
したがって、時間による偏位も、また時間と相関している可能性のある因子（例：温度、湿度、気圧など）による偏位も認められない。

3. 正規性：残差正規確率プロット8つにはある程度の傾向が見られ、これは追加項を加える余地があることを示唆している。
一方、 8つの順序付き残差と、8つの理論上の正規分布 N(0,1) 順序統計量の中央値（これらがプロットの 2つの軸を定義する）との相関係数は 0.934 であり、正規性検定における[正規確率プロットの相関係数](../../ch1_eda/section3/eda3676.md)検定の許容範囲（5％）内に十分収まっている。
したがって、このプロットは、正規性を棄却するほど非線形ではない。

したがって、要約すると、以下の推定モデルを採用する。

$$ \hat{Y} = 2.65875 + 1.55125 X_1 - 0.43375 X_2 $$

を研究対象となっている感度現象を簡潔かつ適切に表すものとして採用する。
