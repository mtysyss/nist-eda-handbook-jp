# 5.4.2. DOEデータの見方

#### いくら強調してもしすぎることはないさまざまな種類のグラフや視覚的表現を用いたデータ分析の重要性
データ集合を適切にグラフ化、プロット、または視覚的表示すことで、異常値を明らかにしたり、ほとんどの定量的技法では発見できない洞察を得たりすることができる。
実際、多くの場合、定量的技法やモデルは、分析者がデータを注意深く「観察」した後に既に導き出した結論を裏付け、さらに発展させるための道具として用いられる。

ほとんどのソフトウェア・パッケージには、DOEデータを表示すためのさまざまな種類のプロットが用意されている。
以下では、データを分析する上で有用な方法のいくつかを挙げ、1章（探索的データ解析、EDA）における詳細な説明や、図解や解説が掲載されているページへのリンクを併せて紹介する。
さらに、視覚的（EDA）DOE技法の例や詳細な説明は、[5.5.9](../section5/pri59.md)節に記載されている。

注：これらのリンクは、プロットされた点が仮定された正規分布（または半正規分布）に従うときに点がほぼ直線上に並ぶことで、データが正規（または半正規）分布に従うかを検定するプロット作成方法を示している。
2水準完全実施要因実験および一部実施要因実験の場合、プロットされる点は交互作用を含むすべてのモデル効果の推定値である。
実際に無視できる程度の効果は、その推定値は平均がゼロで分散が一定である正規分布に従うノイズに類似したものとなるはずである。
有意な効果は直線に沿って並ばないことで特定できる。
正規効果プロットでは効果の推定値を直接使用するが、半正規プロットでは効果の推定値の絶対値を使用する。
