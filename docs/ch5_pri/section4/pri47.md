# 5.4.7. 計画実験の例

#### 詳細な例 3つ
計画実験から得られたデータの分析方法を説明する上で、最も効果的な方法の一つは、詳細例を実際に解き進めながら、分析の各手順を解説することである。

ここでは、3つの基本的種類の計画された実験について、詳細な分析例を示す。

1. [完全実施要因実験](pri471.md)
2. [一部実施要因実験](pri472.md)
3. [応答曲面実験](pri473.md) 

#### ソフトウェア
実験計画の分析のほとんどは、統計ソフトウェア・パッケージを用いて行われる。
優れた統計ソフトウェアを使えば、分析者はグラフ表示を確認したり、モデルを構築したり、仮定を検定したりすることができる。
場合によっては、実験の応答値の適切なグラフ表示を単に検討するだけで、実験目的を達成できることもある。
他の事例では、最も重要な要因や応答曲面の最適等高線を特定するために、適切なモデルを適合させる必要がある。
いずれの場合も、分析者が何を要求すべきか、またプログラムの出力をどのように解釈すべきかを理解していれば、ソフトウェアは適切な計算を実行してくれる。
