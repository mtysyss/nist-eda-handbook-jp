# 5.4.7.1. 完全実施要因の例

**元データ**

#### NISTの高性能セラミックス実験データを使用した例
このデータ集合は、数年前、NISTの材料科学・工学研究所（MSE）セラミックス部門に所属する Said Jahanmir によって行われた実験から得られたものである。
当初の分析は、主に統計工学部門の Lisa Gill 氏によって行われました。
ここに示す例は、元のデータ集合の一部を修正した部分に対する独立した分析結果である。

元データ集合は、高性能セラミックスに関する実験の一部であり、目的は、焼結反応結合窒化ケイ素、反応結合窒化ケイ素、および焼結窒化ケイ素に対して、粉砕母数が及ぼす影響を評価することである。

この完全実施要因計画データ解析の解説例では、3種類のセラミックスのうち最初のもの（焼結された反応結合型窒化ケイ素）から抽出された修正データのみについて説明する。

読者は、このデータを[テキストファイル](https://www.itl.nist.gov/div898/handbook/datasets/CERAMIC.DAT)としてダウンロードできる。 

**実験の説明：応答と要因**

#### 応答変数および因子変数
目的：セラミック強度に及ぼす加工要因の影響を明らかにすること 
応答変数＝セラミック強度の平均値（15回の反復実験の平均）
強度の平均値 観測数＝32（2<sup>5</sup> 因子完全計画）

| |  
| :---- |  
| 応答変数 Y = セラミック強度の平均値（15回の反復実験の平均） |  
| 因子1 = テーブル速度（2水準：低速（0.025 m/s）および高速（0.125 m/s）） |  
| 因子2 = 送り量（2水準：低速（0.05 mm）および高速（0.125 mm）） |

**実験の分析**

#### 5つの基本的な手順
実験データは前述の[5つの基本手順]section4/pri41.md#DOE分析)に従って解析する。
このページに示されている解析結果は、[Rコード](https://www.itl.nist.gov/div898/handbook/pri/section4/pri471.r)を用いて出力することができる。

**手順1：データの見直し**

#### 応答変数のプロット
応答データをいくつかの方法でプロットし、標準的な線形応答モデルでは説明できない傾向や異常があるかを確認することから着手する。

先ず、以下の4つのプロットを作成し、因子水準に関係なく、応答変数の分布を調べる。

1. 最初のプロットは、応答変数の[正規確率プロット](../../ch1_eda/section3/eda33l.md)である。
赤線は理論上の正規分布を示している。
2. 2番目のプロットは、応答変数の[箱ひげ図](../../ch1_eda//section3/eda337.md)である。。
3. 3番目のプロットは、応答変数の[ヒストグラム](../../ch1_eda//section3/eda33e.md)である。
4. 4番目のプロットは、応答変数と実行順序の関係を示している。

![4-plot: normal probability plot, box plot, histogram, run-order plot](https://www.itl.nist.gov/div898/handbook/pri/section4/pri471_r01.gif){: .text-center}
 
明らかに、応答モデルを推定するときに考慮したい「構造」が認められる。
例えば、ヒストグラムにおいて、応答変数はほぼ同じ大きさの2つの塊に分かれている。 
最初の集団は、およそ値が 450 を中心とし、2番目の集団は、およそ値が 650 中心にしている。
期待通り、実行順序プロットからは有意な時間効果は認められない。 

#### 因子変数ごとの応答値の箱ひげ図
次に、各要因に対する応答値の箱ひげ図を見ていく。 

![box plots of response for each factor](https://www.itl.nist.gov/div898/handbook/pri/section4/pri471_r02.gif){: .text-center}

いくつかの要因、とりわけ「方向」、次いで「バッチ」、そしておそらく「砥石の粒度」が、平均応答水準を変化させているように見える。 

**手順2：理論モデルの策定**

#### 理論モデル：4因子以上の交互作用項はすべて有意ではないとする仮定
2<sup>5</sup> 因子の完全実施要因実験について、平均項、主効果 5項、2因子間交互作用 10項、3因子間交互作用 10項、4因子間交互作用 5項、および 5因子間交互作用 1項を含むモデルを推定することができる（32係数）。 
しかし、ここではまず、すべての 4因子以上の交互作用項が存在しないと仮定する。
このような高次交互作用が有意となることは極めて稀であり、また、工学的な観点から解釈することも非常に困難である。 
この仮定により、これらの項の平方和を合算し、誤差項を推定することが可能になる。
まず、26個の未知定数を含む理論モデルから始め、データによって、最終モデルに必要な有意な主効果および交互作用がどれであるかが明らかになることを期待する。

#### 効果の正規確率プロット
有意でない効果は、実質的に、同じ位置と広がりを有する近似的な正規分布に従うはずである。 
有意な効果は、この正規分布から逸脱する。
したがって、有意な効果を判定する別の方法として、全 31 効果について正規確率プロットを作成する。
データに当てはめられた直線から著しく逸脱する効果は、有意であるとみなす。
これは多少主観的な基準ではあるが、実務上は概ね有効である。
モデルにどの項を残すかを決定するには、回帰分析による数値的な出力と、正規確率プロットなどのグラフ技法の併用が有用である。 

効果の正規確率プロットを以下に示す。
（y軸の尺度を縮小するため、最も値の大きい2つの効果項、X4: Direction および X5: Batch はプロットに表示していない。
また、これらの効果 2項は正規参照線の計算には使用されていない。） 
有意であると判断した効果には標識が付けられている。
この場合、段階的回帰分析と同様に、正規確率プロットを観察することで、まったく同じ 12項に至った。 

![Normal plot of the 31 effects](https://www.itl.nist.gov/div898/handbook/pri/section4/pri471_r03.gif)

ほとんどの要因は中心（ゼロ）線近くに集まっており、当てはめられた正規モデルの直線に沿っている。
線より少し上下に位置しているように見える要因は、X1を除き、段階的解析法を用いて特定されたものと同じである。
一部の分析者は、主効果項自体には有意性が認められなくとも、その主効果項に複数の有意な交互作用がある場合には、その主効果項を含めることを好む。 

#### 変動の大部分を説明しているモデル
現段階では、このモデルは応答ばらつきの大部分を説明しているようであり、調整済み R<sup>2</sup> は 0.982 である。
すべての主効果が有意であり、6つの2因子間交互作用および1つの3因子間交互作用も有意である。 
物理的にほとんど意味をなさない唯一の交互作用は、「*X4*：Direction × X5：Batch」の交互作用である。
なぜ、同じ配合の別バッチと比較し、あるバッチの材料を異なる方向に切断した場合に、応答が異なって現れるか。 

ただし、モデルを採択する前に、残差を検証する必要がある。

**手順4 続き：データの変換と再モデル当てはめ**

#### Box-Cox 変換
次に、応答変数の変換をモデル化し、想定された性質の残差が得られるかを検討する。
そこで、負の対数尤度を最大化する値 λ を求め、最適な Box-Cox 変換を計算する。 

![Box-Cox transformation graph, optimal value at lambda = 0.2](https://www.itl.nist.gov/div898/handbook/pri/section4/pri471_r06.gif){: .text-center}

最適値に λ = 0.2 が得られた。
新しい Y: Strength 変数は、以下の式を用いて計算する。

$$\frac{(y_i)^\lambda - 1}{\lambda \left[ \left(\prod_{i=1}^n y_i\right)^{\frac{1}{n}} \right]^{\lambda - 1}}$$

**手順5：実験目的の問いへの回答**

#### 重要な主効果と交互作用
効果推定値の大きさをみると、「方向」が断然、最も重要な要因であることが判る。
「バッチ」がそれに次いで重要な役割を果たし、その次に「砥石粒度」が続く。
さらに、いくつかの重要な交互作用があり、その後に「送り量」が続く。 
「テーブル速度」は、ほぼすべての有意な交互作用項に関与しているが、単独での主効果は最も重要度が低い。
なお、大きな交互作用があると、主効果が隠れてしまうことがある点に留意されたい。

#### 主効果と有意な2元交互作用のプロット
主効果および有意な2要因間の交互作用のプロットを以下に示す。

![Plots of significant 2-way interactions](https://www.itl.nist.gov/div898/handbook/pri/section4/pri471_r10.gif){: .text-center}
  
次に、要因 2つのすべての水準組合せにおける平均値を示す、2要因交互作用プロットを作成する。

![Plots of significant 2-way interactions](https://www.itl.nist.gov/div898/handbook/pri/section4/pri471_r11.gif){: .text-center}

プロット格子の対角線上にある表示には2つの目的がある。
第一に、同じ行にあるすべてのプロットにおいて、x軸に関連する要因を示す。
第二に、同じ列にあるプロットの2本の線を定義する要因を示す。

例えば、r\*s とラベル付けされたプロットには、速度の両方の水準における、送り量変数（x軸）の低水準と高水準の平均値を含む。 
青色の線は速度の低水準をピンク色の線は速度の高水準を表している。 
r\*s プロット上の 2本の線が交差していることは、送り量と速度の間に交互作用があることを示している。 
平行な線は、2要因間に交互作用がないことを示している。 

#### 最適設定
この分析結果に基づき、セラミックの強度を最大化する要因設定を選択することができる。
「-1」および「+1」を実際の要因設定に換算すると、次の通りとなる。テーブル速度は「1」または 0.125 m/s、送り量は「1」または 0.125 mm；砥石粒度は「-1」または 140/170；方向は「-1」または縦方向。 
残念ながら、「バッチ」も非常に重要な要因であり、最初のバッチは 2番目のバッチよりも高い強度が得られる。
このバッチで何がうまくいったのか、そしてそれを再現する方法を学べない限り、この要因についてはあまり打つ手はない。 

**注釈**

#### 横断面に対してのみ複雑なモデルが必要であることを示す固定方向の値分析
1. 「方向」を -1（すなわち縦断）に固定した状態で、2<sup>4</sup> 要因のみを分析すると、どのような結果が得られるのかと疑問に思う人もいるかもしれない。
この分析は、非常に単純なモデルとなることが判明した。
主要な主効果として「砥石粒度」と「バッチ」のみが有意であり、有意な交互作用はない。

一方、「方向」を +1（すなわち横方向）に固定した 2<sup>4</sup> 要因の分析を行うと、2<sup>5</sup> 要因分析で見られたすべての主効果および交互作用を含む 7係数モデルが得られる。
ただし、当然ながら、「方向」を含む項は除外される。 

したがって、全分析における複雑なモデルは、横切断面の物理的特性に起因しているようであり、縦切断面では、こうした複雑さは見られない。

#### 半要因計画
2. もし実験前に、3因子以上の交互作用が無視できると仮定していたならば、$$2_{V}^{5-1}$$ の半要因計画が選ばれていたかもしれない。 
今思えば、その半要因では、X<sub>3</sub> と X<sub>5</sub> を除くすべての主効果および 2因子交互作用について有効な推定値が得られていたはずである。
X<sub>3</sub> と X<sub>5</sub> については、その半要因法において X<sub>1</sub>\*X<sub>2</sub>\*X<sub>4</sub> と混同されてしまっていたであろう。

#### 自然対数変換
3. 最後に、多くの分析者は、指数が 0.2 の Box-Cox変換を使用する代わりに、自然対数変換（すなわち、ln *Y* を使用すること）を応答変数として採用することを好むかもしれないことに留意する。 
自然対数変換は、Box-Cox グラフにおいて、指数が λ = 0 に対応する。
