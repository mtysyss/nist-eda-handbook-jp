# 5.4.5. DOEの結果の解釈方法

#### 結論や意思決定を行うために用いる最終モデル
すべての関連する検定（視覚的および定量的）に合格した最終モデルが得られ、結論を導き出し、判断を下す準備が整ったと仮定する。
これらは、当初の実験目標によって定められた質問に対する回答や出力であるべきである。

**DOEの結論や実験目的や実験目標に対する出力に関連したチェックリスト**

#### 実験目標に対するDOE結果の比較方法のチェックリスト
* 要因の各水準間で応答に有意な違いはあるか（比較実験の目的）
* 最終モデルにおいて、有意な効果や項はどれか（スクリーニング実験の目的）
* 応答を推定するモデルはどれか
    * 完全実施要因計画の場合（主効果に加え、有意な交互作用）
    * 一部実施要因計画の場合（主効果に加え、他の潜在的な実効果と交絡していない有意な交互作用）
    * RSMの場合（必要に応じて、2次モデルや場合によっては3次モデルを許容する）
* 応答の予測はどうで、応答を最適化できる方法は（RSMの目的）
    * 等高線図
    * 検証実行の設定と結果の予測区間
