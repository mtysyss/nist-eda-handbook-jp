# 5.4.7.2. 一部実施要因計画の例

**「カタパルト」一部実施要因実験**

#### 「カタパルト」実験の一部実施要因計画実験の段階的分析
この実験は、学生チームによって、実験計画法や統計的工程管理を教えるために使用される卓上型の木製装置、<u>カタパルト</u>を用いて行われた。

このカタパルトには、制御可能な複数要因があり、教室という環境でも容易に測定できる応答がある。
これまでに、10年以上にわたり、数百の授業で活用されてきた。

![Catapult](https://www.itl.nist.gov/div898/handbook/pri/section4/gifs/catapul2.gif) 
{: .text-center}

[カタパルト](https://www.itl.nist.gov/div898/handbook/pri/section4/gifs/catapul2.gif)
{: .text-center}

**実験の概要：応答と要因**

#### ゴルフ・ボールの飛距離に影響を与える要因 5つがある実験
<u>目的</u>：カタパルトを用いてボールが投げられる距離に影響を与える有意な要因を特定し、異なる3つの距離（30、60、90インチ）に到達するために必要な設定を決定する。
<u>応答変数</u>：カタパルトの前面からボールが着地する地点までの距離（インチ）。
ボールはプラスチック製のゴルフ・ボールである。
<u>観測数</u>：20（中心点4つを伴う、2<sup>5-1</sup> 分解能 V 計画）。
<u>変数</u>：

1. 応答変数 *Y* = 飛距離 
2. 因子1 = ゴム・バンドの高さ（ゴム・バンドの支点の高さ、水準は 2.25インチおよび 4.75インチ、中心点は 3.5インチ） 
3. 因子2 = 始動角度（操作者が手を離し、アームの前方運動を開始する時点でのアームの位置。水準は 0度および 20度、中心点は 10度）） 
4. 因子3 = ゴム・バンド（カタパルトに使用されるゴム・バンドの数。水準は 1本および 2本） 
5. 因子4 = アームの長さ（アームが伸びる距離。水準は 0インチおよび 4インチ、中心点の水平位置は 2インチ） 
6. 因子5 = 停止角度（アームの前進運動が停止し、ボールが飛び始めるアームの位置。水準は 45度と 80度、中心点は 62度）

#### 1離散因子
なお、4つの要因は<u>連続</u>変数であり、1つ（ゴムバンドの数）は<u>離散変数</u>である。
この離散変数があるため、実際には異なる 2つの中心点があり、それぞれに実行2つがある。 実行7 と 19 は輪ゴム1本、他の要因は中央値であり、実行2 と 13 は輪ゴム2本、他の要因は中央値となっている。

#### 確認実行 5回
20回の実験を分析し、予測距離 30、60、90インチを達成するために必要な要因設定を決定した後、チームは、導き出された各設定について、確認実験を 5回ずつ実施するよう求められた。

実際、実行番号10 では実測距離は距離は 8インチであったが、モデルは -11インチと予測し、残差は 19インチである。

#### 理想的とは言えないがモデルは適合度検定に合格している残差グラフ
因子に対する残差グラフのほとんどは、グラフ上にわずかな「眉をひそめたような」形状（中央部で残差が大きくなる）が見られる。
これは、不適合、あるいは中心点値における曲率の兆候を示している可能性がある。 
しかし、不適合検定の結果から、この適合度の欠如は有意ではないことが示されている。

#### より良いモデルを検討するための応答変数変換
この時点で、適合とそれに伴う残差を持つモデルにいくつかの不満足な特徴があることから、応答変数（Y =「距離」）の単純な変換が状況を改善できるかどうか検討すべきである。

距離の対数を応答として使用することが、より良いモデルにつながる可能性がある少なくとも二つの妥当な理由がある。

1. 線形モデルを ln(*Y*) に適合させ、X 因子値の任意の組合せに対して元の尺度に再変換すると、常に正の距離を予測する。
2. 物理的な考慮から、距離の現実的なモデルは 2次項が必要になることが示唆される。
重力は重要な役割を果たし、対数を取ることで非線形項の影響を軽減することがしばしばある。

ln(*Y*) を応答として使用することが、より満足できるモデルにつながるかどうかを確認するために手順3 に戻る。

#### 最後のステップ：目的の距離を得るために使用すべき設定を予測する
分析結果とプロットに基づき、対数変換された距離を最大化する因子設定を選択する。 
「-1」、「0」、および「+1」を実際の因子設定に換算すると、バンドの高さは「0」または 3.5インチ、開始角度は「0」または 10度、 ゴム・バンドの数は「1」または 2本、アームの長さは「1」または 4インチ、そして停止角は「0」または 80度となる。

#### 「確認」実行は正常に完了
実験に続く検証実験において、研究チームは 3つの目標すべてを正確に捉えることに成功したが、それらすべてを 5回連続で捉えることはできなかった。
本分析で示されたように、モデル発見と適合のプロセスは、多くの場合、反復的なプロセスである。
