# 5.4.6. DOEの結果を確認する方法（確認実験）

#### 確認実行の定義
実験の解析が完了したら、予測が妥当であることを確認しなければならない。
これらを確認実験と呼ぶ。

実験の解釈や結論には、実験目的を達成するために用いるべき「最適な」設定が含まれる。
例えこの「最適な」設定が実験計画に含まれていたとしても、確認実験の一環として再度実行し、状況に変化がないこと、応答値が予測値に近いことを確認すべきである。

#### 計画すべき少なくとも3回の確認実行
現場の設定では、工程安定性が極めて重要視される。
従って、「最適な」設定で1回以上の試験を実施する必要がある。
少なくとも 3回の試験を実施する（その設定におけるばらつきを推定できるようにするため）。

実際の実験実施から確認試験実施までの時間が数時間以上空く場合は、実験者は、最初のデータ収集以降に他の条件に変化がないことを慎重に確認しなければならない。 

#### 元の環境を注意深く再現
確認試験は、元実験と可能な限り同様の環境下で実施すべきである。
例えば、実験が午後に実施され、装置に起動効果がある場合、確認試験は装置が暖機を終えた後の午後に実施すべきである。
確認試験の結果を変化させたり、影響を与えたりする可能性のあるその他外部要因としては、装置を操作する担当者、温度、湿度、装置設定値、原材料などが挙げられる。

#### 確認処理の実行時に予期せぬ結果が出るかの確認
期待した結果が得られなかったときはどうすればよいか。
もし確認実行で期待した結果が得られなかった場合は、

1. 当初のデータ収集以降、何か変更がないか確認する。
2. 確認実行の設定が正しいか検証する。
3. モデルを見直し、分析で得られた「最適な」設定を検証する
4. 確認実行において、正しい予測値が使用されていたかを検証する。

上記の4項目を確認しても答えが見つからない場合、そのモデルは「最適」と判断した領域では予測精度が低い可能性がある。
それでも実験から得られた知見は貴重であり、この実験で得られた情報を活用して、次の追跡実験を計画すべきである。

#### 実験の目標が達成されなかったとしてもその後の実験に活かせる知見は得られる
よく計画された実験は、そこから何かを学べるという点ですべて成功と言える。
しかし、すべての実験が必ずしも実験前に設定された目標を達成するとは限らない。
だからこそ、目標を達成するために、[実験を順番立て](../section1/pri14.md#The Sequential or Iterative Approach to)て行う計画を立てることが理にかなっているのである。
