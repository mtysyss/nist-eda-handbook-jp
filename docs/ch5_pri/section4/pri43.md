# 5.4.3. DOEデータのモデル化方法

#### 実験目的と整合性が取れていなければならないDOEモデル
一般的に、DOEデータに適合させる試行モデルは、実験目的と整合していなければならず、実験目的、実験計画、およびデータ収集方法によって予め決定されている。

#### 比較計画
比較計画は、（[完全無作為計画](../section3/pri331.md#Model for a)、[無作為ブロック計画](../section3/pri332.md#Model for a)、および[ラテン方格計画](../section3/pri3321.md#Latin square)）既出である。

#### 完全実施要因計画
*k* 個の因子の完全実施要因計画（中心点や反復実験を除いた2<sup>k</sup> 実験）の場合、完全モデルには主効果すべてと全次数の交互作用項が含まれる。
通常、高次（3因子以上）の交互作用項は、効果の正規（または半正規）プロットを作成するために当初は含めるが、より単純で適切なモデルを適合するときに後で除れる。
利用可能なソフトウェアや分析者の好みに応じて、正規確率プロットや半正規確率プロット、Youden プロット、*p*-値比較、段階的回帰法などの様々な手法が用いられ、モデルに必要な項を最小数に絞り込む。
モデル選択の例は、[この節の後半](pri471.md#手順2：-理論モデルの作成)で示し、Yete のアルゴリズム例を[事例研究](../section6/pri615.md)として紹介する。

#### 一部実施要因計画
一部実施要因スクリーニング計画は、実験の推定を意図した交互作用項のみを含む適切な初期モデルを記述するために、別名構造を把握しておく必要がある（これらの選択された項と交絡するすべての項が有意でないことを前提とする）。
これについては、[本節の後半](pri472.md#手順2：-理論モデルの作成)での一部実施要因計画の例で説明する。
そして、開始モデルを前述した完全実施要因計画モデルと同じ技法を用い、必要に応じて簡略化する。

#### 応答曲面計画
応答曲面の初期モデルには2次項が含まれ、場合によっては3次項も含まれる。
これらモデルは、[3節](../section3/pri336.md)で説明した。

#### モデルの検証
もちろん、あらゆるモデル適合の場合と同様に、必要に応じ[残差分析やその他のモデル適合度検定](section4/pri44.md)を用いて、モデルの確認と調整を行う。
