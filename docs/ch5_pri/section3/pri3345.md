# 5.3.3.4.5. 一部実施要因計画の活用

#### 分解能が違う計画の選択法[^1]
主効果のスクリーニングには低分解能の計画を用い、交互作用や応答曲面を調査する必要がある場合には、より高分解能の計画を用いる。
一部実施要因計画の基本的目的は、特定の実験設定において、重要な因果関係を経済的に調査することにある。
これは、本質的には他のいかなる実験計画の目的とも変わらない。
しかし、完全計画の一部を選択することによりより経済的に実施できる一方で、異なる要因計画にはそれぞれ異なる目的があることも認識しておく必要がある。

大まかに言えば、分解能が 3、場合によっては 4の計画では、多くの重要度の低い主効果の中から少数の重要な主効果を選別することを目指す。
このため、これらの計画はしばしば主効果計画、あるいはスクリーニング計画と呼ばれる。

一方、分解能 5以上の計画は、実験状況において主効果だけでなく、それ以上効果に焦点を当てるために用いる。
これらの計画により、交互作用効果を推定することが可能であり、また、こうした計画は容易に拡張して2次計画（完全な2次（quadratic）モデルを推定できる計画）を策定することができる。 

#### スクリーニング／RSM計画におけるさまざまな目的
スクリーニング／RSM計画戦略において、計画が用いられる機能的目的は数多くある。
例えば、ある実験は、製品をより良くする方法や、天候などの外部、且つ制御不可能な要因の影響に対して工程をより堅牢にする方法を特定するために計画される場合がある。
また、実験は、工程の不具合解決、ボトルネックの特定、あるいは製品のどの構成要素が最も改善を必要としているかを特定するために計画されることもある。
また、実験は、歩留まりを最適化したり、不良率を最小限に抑えたり、あるいは工程を不安定な動作領域から脱却させるために計画されることもある。
これらの目的や目標はすべて、一部実施要因計画およびそれに適した計画の改良手法を用いることで達成することができる。
