# 5.3.3.10. 3水準、混合水準、および一部実施要因計画

#### 2水準因子もあれば、3水準や4水準因子もある混合水準計画
2<sup>k</sup> および 3<sup>k</sup> 実験は要因計画の特殊な場合である。
要因計画では、各水準すべての組合せでデータを取得する。
要因計画、特に2水準要因計画の重要性については、Montgomery（1991）が次のように述べている。<u>我々は、2水準の要因計画および一部実施要因計画が、製品および工程の開発・改善における産業実験の礎となるべきであると確信している</u>。
彼はさらに次のように述べている。
<u>しかし、2水準を超える水準を持つ因子（または少数の因子）を含める必要がある状況もいくつか存在する</u>。
 
本節では、2水準計画から出発して3水準因子を追加し、いわゆる混合水準計画を得る方法について検討する。
また、2水準計画に4水準因子を追加する方法についても検討する。
この節の最後には、有用な直交3水準計画および混合水準計画（いわゆる田口「L」直交配列計画の一部）の一覧を掲載し、それらの長所と短所について簡単に解説する。 

**3水準および2水準混合計画の作成**

#### 混合計画を生成するための Montgomery 法
Montgomery（1991）は、かなり独創的な手法を用いて、2<sup>3</sup> 計画から3水準変数を導出する方法を提案している。
その目的は、変数A を 2水準、変数X を 3水準とする計画を作成することである。
これは、因子B および C の -1 と 1 のパターンを組み合わせて、3水準の因子X の水準を作成することで構成される。

| --- | | |

| --- | | |  
| -1 | -1 | x<sub>1</sub> |  
| +1 | -1 | x<sub>2</sub> |  
| -1 | +1 | x<sub>2</sub> |  
| +1 | +1 | x<sub>3</sub> |

#### 2次効果が無視できる場合の2水準因子2つの組込み
2次効果が無視できるならば、D = ABC とする第2の 2水準因子 D を含めることができる。
実際、この計画を 4つの 2水準因子と 1つの 3水準因子からなる、主効果のみ（分解能Ⅲ）に変換することができる。
これは、2番目の 2水準因子を AB に、3番目を AC に、4番目を ABC に等しくすることで実現される。
列BC は、3水準因子X の2次効果を含んでいるため、この方法は使用できない。

**1つ以上の3水準因子**

#### 2<sup>4</sup> および 2<sup>5</sup> 計画における3水準因子
これまで見てきたように、3水準1因子を作成するには、初期の計画を2<sup>3</sup> 要因とする。
証明は省略するが、2<sup>4</sup> は 1つ、2つ、または3つの 3水準因子を分離することができ、2<sup>5</sup> は 3水準因子3つを作成しつつも、完全実施要因計画の構造を維持することができる。
これに関する詳細は、Montgomery (1991)を参照のこと。

**2 および 4水準混合計画の作成**

#### 4水準因子1つと2水準因子2つの計画の構築
4水準因子を作成するには、3水準因子例と同じ原則を適用する。
ここでは、目標として、1つの 4水準要因と 2つの 2水準要因からなる実験計画を構築することを想定する。
まず、すべての主効果と交互作用を推定したい。
これについては（Montgomery, 1991を参照）、2<sup>4</sup>（16実行）の計画を用いることで達成できることが示されており、列A と列B を用いて 4水準因子X を作成する。

#### 3水準の混合水準計画の長所と短所
これらの計画の優れた点は以下の通り。

* これらは直交配列である。
一部の分析者は、これが結果の分析と解釈を簡素化すると考えている一方で、他の分析者はそうではないと考えている。
* 比較的少ない実験回数で、主効果に関する多くの情報を得ることができる。
* モデルに非線形項が必要かどうかを少なくとも 3水準の因子に関しては、検証することができる。

一方、これらの計画には考慮すべきいくつかの望ましくない特徴がある。

* 交互作用に関する情報は限られている。
* 同等の 2<sup>k-p</sup> 計画よりも多くの実行数を必要とし、因子が連続かつ単調である場合には、2水準計画で十分な場合が多い（2水準計画で十分だったはずの場面でも、多くの 3水準計画が用いられている）。
