# 5.3.3.2.3. 超グレコ・ラテン方格計画

#### 4つの妨害因子に対処する計画
[前述](pri3321.md)のように、超グレコ・ラテン方格は、4つの妨害因子が存在する処理因子1つの影響を検討する効率的な実験計画である。
ただし、この計画は、すべての因子の水準数が同じである場合に限定される。

#### 計画が許す限り無作為化
このページでは、4水準および5水準の要因に対する実験計画を示す。
これら計画では、各実行における処理の組合せがどうすべきかを示している。
**これら計画のいずれかを用いるときは、計画が許す限り、処理単位と試行順序を無作為化する**。

例えば、利用可能な超グレコ・ラテン方格計画の中から1つを無作為に選択し、その後、実行順序を無作為化することが推奨される。
