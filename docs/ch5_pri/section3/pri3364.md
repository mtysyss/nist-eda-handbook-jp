# 5.3.3.6.4. 応答曲面計画のブロック化

**応答計画のブロック方法**

#### 分解能 V 計画に星型点を追加し CCC計画に拡張するときの 計画のブロック化
研究者が、少なくとも分解能 V の 2<sup>k</sup> 完全要因または 2<sup>k-p</sup> 一部実施要因計画を実施した場合、その計画を中心複合計画（ CCC または CCF のいずれか）に拡張するには、星型点と中心点の実行の追加組（ブロック）を加えるだけで容易に実現できる。
もし要因実験で（ *t* 検定から）曲率が示された場合、この複合拡張が最良の次の手段となる（他の状況における次の手段については後述する）。

#### 直交ブロック応答面計画の利点
応答曲面計画を選択するときに考慮すべき重要な点は、その計画をブロック単位で実行可能かである。
ブロック計画は、ブロック効果とは独立して、個々の要因効果および因子交互作用効果を推定できる場合に、より優れた計画である。
この条件は「直交ブロック」と呼ばれる。
ブロックは応答曲面の性質や形状に影響を与えないと仮定される。

#### 直交ブロック化できないCCFの計画
CCF計画では直交ブロック化は許可されておらず、Box-Behnken 計画では限られた状況でのみブロック化が可能であるのに対し、CCCでは直交ブロック化が許可されている。

#### 軸ブロックと因子ブロック
一般的に、2ブロックが必要な場合は、軸方向のブロックと要因計画ブロックを設けるべきである。
3ブロックの場合は、要因ブロックを2ブロックに分割し、軸ブロックは分割しない。
要因計画の各点に対するブロック化は、ブロック間および個々の因子間、ならびにブロックと2因子交互作用との間で直交する必要がある。

以下の2因子中心複合計画は、2ブロックに分割されている。
