# 5.3.3.2.2. グレコ・ラテン方格計画

#### 3つの妨害因子に対処する計画
[前ページ](pri3321.md)ページで説明した通り、グレコ・ラテン方格は、3つの妨害因子が存在する処理因子1つの影響を検討する効率的な実験計画である。
ただし、すべての因子の水準数が同じである場合に限定される。

#### 計画が許す限り無作為化
このページでは、3水準、4水準、および5水準の因子に対する実験計画を示す。
これら計画では、各実行における処理の組合せがどうなるかを示している。
**これら計画のいずれかを用いるときは、計画が許す限り、処理単位と試行順序を無作為化する**。

例えば、利用可能なグレコ・ラテン方格計画から1つを無作為に選択し、その後、実行順序を無作為化することが推奨される。 

**3、4、5水準因子のグレコ・ラテン方格計画**

#### 3水準要因計画

**3水準因子**

| *X*1 | *X*2 | *X*3 | *X*4 |
| 行  ブロック  因子 | 列  ブロック  因子 | ブロック  因子 | 処理  因子 |
| --- | | | |
| 1 | 1 | 1 | 1 |
| 1 | 2 | 2 | 2 |
| 1 | 3 | 3 | 3 |
| 2 | 1 | 2 | 3 |
| 2 | 2 | 3 | 1 |
| 2 | 3 | 1 | 2 |
| 3 | 1 | 3 | 2 |
| 3 | 2 | 1 | 3 |
| 3 | 3 | 2 | 1 |


ここで、

<div class="formula-list">
   <i>k</i> = 4因子 (3ブロック因子および 1主因子)
   <br>
   <i>L</i><sub>1</sub> = <i>X</i><sub>1</sub>（ブロック）因子の3水準
   <br>
   <i>L</i><sub>2</sub> = <i>X</i><sub>2</sub>（ブロック）因子の3水準
   <br>
   <i>L</i><sub>3</sub> = <i>X</i><sub>3</sub>（主因子）因子の3水準
   <br>
   <i>L</i><sub>4</sub> = <i>X</i><sub>4</sub>（主因子）因子の3水準
   <br>
   <i>N</i> = <i>L</i>1 * <i>L</i>2 = 9実行
</div>  
<br>

これは次に様にも表示できる(A, B, C は、処理因子、および 1, 2, 3 はブロック因子を示す):


| A1 | B2 | C3 |
| --- | --- | --- |
| C2 | A3 | B1 |
| B3 | C1 | A2 |
