# 5.3.3.5. Plackett-Burman 計画

#### Plackett-Burman 計画
1946年、R.L. Plackett と J.P. Burman は、現在では著名な論文『最適多因子実験の計画法（The Design of Optimal Multifactorial Experiments）』を『Biometrika』（第33巻）に発表した。
この論文では、反復数が 2の冪ではなく 4の倍数となる、非常に経済的な実験計画法の構築について述べられている。
Plackett-Burman 計画は、主効果のみが関心事である場合に非常に効率的なスクリーニング計画である。

#### 4の倍数が使用されてる計画　
Plackett-Burman（PB）計画がスクリーニング実験に用いられるのは、PB計画では、主効果が一般的に 2因子交互作用と強く交絡しているためである。
例えば、12回の実行からなる PB計画は、最大 11個の要因を含む実験に適用することができる。

#### 飽和主効果計画
PB計画には、20実行、24実行、28実行（およびそれ以上）の計画もある。
 20実行の計画では最大19個の因子、24実行の計画では最大23個の因子、28実行の計画では最大27個の因子についてスクリーニング実験を行うことができる。
 これらのResolution III計画は、すべての自由度が主効果の推定に利用されるため、<u>飽和主効果</u>計画として知られている。

#### 定義関係がない
これらの計画法では、交互作用が主効果と完全に等しいわけではないため、定義関係は存在しない。
$`2_{III}^{k=p}`$ 計画では、主効果の列 <i>X<sub>i</sub></i> は、<i>X<sub>i</sub></i><i>X<sub>j</sub></i> と直交するか、またはプラスまたはマイナスの <i>X<sub>i</sub></i><i>X<sub>j</sub></i> と等しい。
Plackett-Burman 計画の場合、2因子交互作用の列 <i>X<sub>i</sub></i><i>X<sub>j</sub></i> は、すべての <i>X<sub>k</sub></i>（*k*が*i*または*j*と等しくないもの）と相関している。

#### 大きな主効果を検出するのに経済的である
しかし、これらの計画は、少数の重要な主効果と比較し、すべての交互作用が無視できると仮定すれば、大きな主効果を経済的に検出する上で非常に有用である。
