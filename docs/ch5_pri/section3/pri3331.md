# 5.3.3.3.1. 2水準完全実施要因計画

**解説**

#### 3因子2水準計画の図解
3因子2水準の完全実施要因計画、すなわち 2<sup>3</sup> 計画について考える。
これは、8回の実行（反復や中心点の実行は含まない）を意味する。
図示すると、2<sup>3</sup> 計画は図3.1 に示す立方体で表すことができる。
矢印は各因子の増加方向を示している。
計画箱の角にある数字「1」から「8」までは、実行の「標準順序」を表している（図3.1を参照）。

<b>2<sup>k</sup>水準要因計画の標準順序</b>

#### 2<sup>k</sup> 完全実施要因を「標準表記」で書くための規則
2<sup>3</sup> の標準順序行列は、因子 *k*個を持つ 2水準の完全実施要因計画に容易に一般化できる。
最初の(<i>X<sub>1</sub></i>)列は -1から始まり、2<sup>k</sup> 回の実行すべてにおいて符号を交互に変える。
2番目の (<i>X<sub>2</sub></i>) 列は、-1を 2回繰り返して始まり、その後、2<sup>k</sup> 箇所すべてが埋まるまで、符号が逆の 2 を交互に並べていく。
3番目の(<i>X<sub>2</sub></i>)列は、-1を 4回繰り返して始まり、その後 +1を 4回繰り返す、というように続きます。
一般に、*i* 番目の列(<i>X<sub>i</sub></i>)は、初めに -1を 2<sup><i>i</i>-1</sup> 回繰り返した後、+1を2<sup><i>i</i>-1</sup> 回繰り返す。

<b>2<sup>k</sup>実験</b>

#### 3因子完全実施要因の解析行列
3因子実験と呼ばれる工学実験で、圧力（要因<i>X<sub>1</sub></i>）、テーブル速度（要因<i>X<sub>2</sub></i>）、下方向力（要因<i>X<sub>3</sub></i>）をそれぞれ「高」と「低」の設定で実行し、製品の均一性に最も大きな影響を与える要因を特定することとなった。
各設定について 2回の反復実験が実施された。
2回の反復を含む（完全実施要因計画）2<sup>3</sup> の計画では、8×2＝16回の実験が行われる。

**2因子実験解析行列の直交特性**

#### 主効果と交互作用推定値間の相関の除去
すべての要因の高い値を「1」、低い値を「-1」に符号化すると、任意の完全（または適切に選択された部分）実施要因実験の計画行列列はすべて対の[直交](../section7/pri7.md#Orthogonality)であり、すべての列（「I」列を除く）の和は 0 となる。

この直交性の性質は、主効果および交互作用の推定値間の相関を排除するために重要である。
