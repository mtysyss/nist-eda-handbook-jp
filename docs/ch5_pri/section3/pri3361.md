# 5.3.3.6.1. 中心複合計画（CCD）

**Box-Wilson 中心複合計画**

#### 完全実施要因計画または一部実施要因計画計画（中心点を含む）を基に、「星型」点を追加して曲率を推定する CCD計画
一般に「中心複合計画」と呼ばれる Box-Wilson 中心複合計画は、中心点を持つ埋込み要因計画または一部実施要因計画を含み、曲率の推定を可能にする一連の「星型点」によって拡張されたものである。
各因子について、計画空間の中心から因子点までの距離が ±1 単位である場合、計画空間の中心から星型点までの距離は |*α*| > 1 となる。
*α* の正確な値は、計画に求められる特定の特性や、関与する因子数によって決まる。

同様に、計画に含まれる中心点の実行数も、その計画に求められる特定の特性に依存する。

#### 中心複合計画3つの比較
図3.21 の図は、因子2つに対する 3種類の中心複合計画を示している。
なお、CCCは最も広い工程空間を調査し、CCIは最も狭い工程空間を調査することに注意する。
CCC と CCI はいずれも[回転可能](../section7/pri7.md#回転可能性)な計画であるが、CCF はそうではない。
CCC計画では、計画点は要因表の正方形を<u>外接</u>する円を描く。
3因子の場合、CCC計画点は要因表の立方体を囲む球を描く。

**中心複合計画での *α* 設定**

#### 回転性を維持できるように選ぶ *α* 値
回転性を維持するために *α* 値は、中心複合計画の指数部分における実験実行回数に依存する。

$$\alpha = [ \text{要因実験の回数} ]^{1/4}$$ 

要因が完全実施要因である場合、 

$$\alpha = \left[ 2^{k} \right] ^{1/4}$$ 

ただし、因子部分は分解能 V の一部実施要因計画である場合もある。

表3.23は、因子数に対する *α* の典型的な値を示している。

#### 直交ブロック化
*α* の値は実験計画が直交ブロック化されているかにも依存する。
すなわち、ブロック効果が2次モデルの係数の推定値に影響を与えないようにブロックに分割されている計画かが、論点となる。
