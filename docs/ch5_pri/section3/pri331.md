# 5.3.3.1. 完全無作為化計画

#### 他の妨害因子を考慮に入れない 1主因子の影響を調査するための計画
ここでは、主因子1つの完全無作為化計画について検討する。
この実験では、主因子の異なる水準に基づいて応答変数の値を比較する。

完全無作為化計画では、主因子の水準が実験単位に無作為に割り当てられる。
ここでいう[無作為化](../section7/pri7.md#無作為化)とは、[実験](../section7/pri7.md#実験)単位の実行順序が無作為に決定されることを意味する。
例えば、各水準を2回ずつ実行する主因子の水準が3つある場合、6の階乗通りの実行順序（すなわち、実験試行を並べ替える6!通りの方法）が存在する。
反復があるため、一意な順序の数は 90 となる（$`90 = 6!(2!*2!*2!)`$ ）。
無作為化されていない計画の例としては、常に最初の水準で2回の反復実験を行い、次に2番目の水準で2回、最後に3番目の水準で2回行うといったものが挙げられる。
実験の実行を無作為化する方法の一つとして、2枚の紙に水準1、2枚に水準2、2枚に水準3と記入し箱に 6枚の紙片を入れる。
各実行前に、箱から1枚の紙片を盲検で取り出し、選ばれた水準を次の実験の実施に適用する。 

#### コンピュータ・ソフトウェアによって行われる無作為化
実際には、無作為化は通常、コンピュータ・プログラムによって行われる。
しかし、無作為化は、乱数表や何らかの物理的な仕組み（例えば、紙片を引くことなど）によってもすることができる。

#### 重要な3つの数値
主因子1つのすべての完全無作為化計画は、次の3つの数値によって定義される。

$$\begin{array}{ccl}
k & = & \text{因子数（これらの計画では 1）} \\
L & = & \text{水準数} \\
n & = & \text{反復回数}
\end{array}$$

また、全標本規模（実験回数）は $`N = k × L × n`$ となる。

#### 均衡
均衡を考慮すると、各要因水準ごとに反復回数を同じにする必要がある（これにより、その後の統計 *t*検定（または*F*検定）の感度が最大化される）。

#### 完全無作為化計画の典型例
完全無作為化計画の典型的な例は以下の通り。

$$\begin{array}{ccl}
k & = & 1 \text{ 因子 (X1)} \\
L & = & 4 \text{ 水準、1因子（「1」、「2」、「3」、および「4」と呼ばれる）} \\
n & = & 3 \text{ 反復、各水準当たり} \\
N & = & \text{4水準 × 各水準につき 3反復 = 12実験}
\end{array}$$

#### 試行無作為化順序の例
試験の無作為化順序は次のようなものになる。

| X1 |  
| :--: |  
| 3 |  
| 1 |  
| 4 |  
| 2 |  
| 2 |  
| 1 |  
| 3 |  
| 4 |  
| 1 |  
| 2 |  
| 4 |  
| 3 |  

この例では、実験を行う方法は $`12!/(3!×3!×3!×3!) = 369,600`$ 通りあり、それらはすべて、無作為化手順によって選ばれる確率が等しい。 

#### 完全無作為化計画のモデル
応答のモデルは次の通り。

$$Y_{ij} = \mu + T_{i} + \text{無作為誤差}$$

ここで、
$`Y_{ij}`$ は、$`X_1= i`$（*i*および *j*は、それぞれ因子の水準およびその水準内の反復を表す）
$`\mu`$（またはmu）は一般位置母数
$`T_{i}`$ は処理水準 $`i`$ を持つ効果

**推定と統計検定**

#### モデル因子水準の推定と検定

| | |  
| :---- | :------- |  
| $`\mu`$ の推定値： | $`\bar{Y}`$ = 全データの平均 |  
| $`T_i`$ の推定値： | $`\bar{Y}_{i} - \bar{Y}`$<br>$`\bar{Y}_i = X_1=i \text{となるすべての}`$<br>$`Y \text{の平均値}`$ 。 |
  
X1水準に対する統計検定は、[7章の一元配置分散分析](../../ch7_prc/section4/prc42.md)」の節で説明している。
