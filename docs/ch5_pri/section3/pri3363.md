#### 古典的応答曲面計画の特性

表3.27 は、古典的2次計画の特性をまとめたものである。
利用可能な計画の中から選択を行うときに大まかな指針としてこの表を活用する。


**表3.27：古典的応答面計画法の特性概要**

| 計画の種類 | 概要 |
| CCC | CCC計画は、計画空間全体に渡り高品質な予測を提供するが、要因設定が要因配置計画部分の因子範囲外が必要がある。 **注：**要因実験を始める前に CCC計画を実行できる可能性があると認められるときは、各符号化因子の±α が実行可能（妥当）な水準に対応するように因子空間を狭める。  各因子につき 5水準が必要である。 |
| CCI | CCIの計画では、初期に指定された要因範囲内の点のみを使用するが、CCCと比較して空間全体に渡り同等の高品質な予測はできない。  各因子につき 5水準が必要である。 |
| CCF | CCF計画は、計画空間全体に渡り比較的精度の高い予測を与え、元の因子範囲外の点を使用する必要がない。 しかし、純粋な 2次係数の推定においては精度が低くなる。  各因子につき 3水準が必要である。 |
| Box-Behnken | これらの計画は、3 または 4要因を含む場合に、中心複合計画よりも必要な処理組合せ数が少なくて済む。  Box-Behnken 計画は回転可能（あるいはほぼ回転可能）であるが、CCIと同様に予測精度の低い領域を含む。 その「欠落した角」は、実験者が因子の極端な組合せを避けるべき場合に有用である。 この特性により、そのような場合にデータ損失の可能性を防ぐことができる。  各因子につき 3水準が必要である。 |

**応答曲面計画に望まれる特性**


#### 応答曲面計画における望ましい特性の概要

G. E. P. Box および N. R. Draper は、『Empirical Model Building and ResponseSurfaces』（John Wiley and Sons, New York, 1987, page 477）において、応答曲面計画に求められる望ましい特性を次のように挙げている。

* 実験領域全体に渡る情報の適切な分布  
    - [回転可能性](../section7/pri7.md#回転可能性)  
* 推定値が観測値に可能な限り近い  
    - <u>残差や予測誤差の最小化</u>  
* 適合不良の検出精度が高い  
* 誤差の内部推定  
* 分散が一定かの確認  
* 変換の推定が可能  
* ブロック化への適応性  
* より単純な計画から高次計画への順次構築  
* 処理組合せの最小数  
* 単純なデータ・パターンによる良好なグラフ分析  
* 入力変数設定に誤りがあった場合でも、良好な挙動
