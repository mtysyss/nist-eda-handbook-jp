# 5.3.3.6.3. 応答曲面計画の比較

**応答曲面計画の選択**

#### さまざまな CCD計画法および Box-Behnken 計画法を比較し、それらの特性について考察する
表3.24 は、3要因の調査に用いることができる 4つの一般的な 2次計画構造を比較したものである。
この表では、CCC計画法と CCI計画法を構造的に同一であるため、まとめて記載している。

3要因の場合、Box-Behnken 計画は実行回数が少なくて済むという点で一定の利点がある。
4要因以上の場合、この利点はなくなる。
