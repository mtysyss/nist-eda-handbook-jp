# 5.3.3.6.2. Box-Behnken 計画

#### 各因子 3水準を必要とし、かつ回転可能（あるいは「ほぼ」回転可能）な 2次モデルを推定するための別の選択肢
Box-Behnken 計画は、埋込み要因計画や一部実施要因計画を含まないという点で、独立2次計画である。
この計画では、処理の組合せは、工程空間の辺の中点および中心に配置される。
これら計画は回転可能（またはほぼ回転可能）であり、各因子について3水準を必要とする。
計画は、中心複合計画と比較し、直交ブロック化の適用可能に限りがある。

#### 計画の幾何学
この計画の幾何学的構造は、工程空間内に球体が存在することを示唆しており、球体表面は各面を突き抜け、球体表面は空間各辺の中点に接している。
