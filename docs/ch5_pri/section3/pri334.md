# 5.3.3.4. 一部実施要因計画

#### 多くの実験回数を要する完全実施要因計画実験
ASQC（1983）『統計的品質管理用語集および表』では、一部実施要因計画について次のように定義している。
「<u>完全実施要因実験に必要な処置の組合せのうち、適切に選択された一部のみを選定して実施する要因実験のこと</u>。」

#### 実行から慎重に選定された一部で十分
たとえ計画の因子数 *k* が小さくても、完全実施要因計画で指定される 2<sup>k</sup> の実験回数は、あっという間に非常に多くなってしまう。
例えば、2<sup>6 </sup> = 64 実験は、因子 6つを持つ 2水準の完全実施要因計画に対応する。
この計画には相当数の中心点実験を追加する必要があり、その結果、因子数が 然程多くない場合でも、実験に必要な資源がすぐに膨大なものとなってしまう。

#### 2水準計画での均衡が取れ、かつ直交している「適切な」分割の選択方法
この問題の解決策は、完全実施要因計画で指定された実験の内、一部のみを利用することである。
どの実験を実施し、どの実験を省くかが、ここでの焦点となる。
一般的には、完全実施要因計画で要求される実験の ½、¼ などの割合を選択する。
実験の適切な選択を保証するために、さまざまな戦略を用いる。
以下の節では、そのときの目的に合わせて完全実施要因計画から適切な割合を選択する方法について説明する。
<u>2水準の実験に対して適切に選択された一部実施要因計画は、[均衡](../pri/section7/pri7.md#均衡化)が取れており、かつ[直交性](../section7/pri7.md#直交性)という望ましい特性を備えている</u>。

#### 2水準一部実施要因計画に重点
**注：**ここでは2水準一部実施要因計画にのみ焦点を当てる。
その理由は、少なくとも工学の分野においては、2水準一部実施要因計画が断然最も一般的な要因計画であるためである。
一部の要因が 3水準を持つ一部実施要因計画については、[5.3.3.10節](pri33a.md)で簡潔に取り上げる。
