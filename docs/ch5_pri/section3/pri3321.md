# 5.3.3.2.1. ラテン方格と関連計画

#### 妨害因子2～4をブロックする効率的なラテン方格（および関連）計画
ラテン方格計画および関連するグレコ・ラテン方格計画や超グレコ・ラテン方格計画は比較計画の一種である。

主に関心がある、一般的に処理因子と呼ばれる単因子といくつかの妨害因子がある。
ラテン方格計画では妨害因子が2つ、グレコ・ラテン方格計画では3つの妨害因子、超グレコ・ラテン方格計画では4つの妨害因子がある。 

#### ブロック変数として用いられる妨害因子
妨害因子はブロック変数として用いられる。

1. ラテン方格計画では、2つの妨害因子が表形式の格子に分割され、各行および各列が各処理を正確に1回ずつ受けるという性質を持つ。  
<br>
2. ラテン方格計画と同様に、グレコ・ラテン方格計画も $k×k$ の表形式の格子であり、*k*は処理因子の水準数を表す。
ただし、標準的なラテン方格計画で使用される2つのブロック変数の代わりに、3つのブロック変数が使用される。  
<br>
3. 超グレコ・ラテン方格計画もまた、$k×k$ の表形式の格子であり、*k* は処理因子の水準数を表する。
ただし、標準的なラテン方格計画で用いられる2つのブロック変数の代わりに、4つのブロック変数を使用する。

#### ラテン方格計画の長所と短所
ラテン方格計画の利点は以下の通り。

1. いくつかの妨害因子が存在し、それらを単一因子に統合できない場合や個別に扱いたい場合にも対応できる。
2. 比較的少ない実験回数で実験を行うことができる。

欠点は以下の通り。

1. 各ブロック変数の水準数は、処理因子の水準数と等しくなければならない。
2. ラテン方格モデルは、ブロック変数間、あるいは処理変数とブロック変数との間に交互作用がないことが前提である。

なお、ラテン方格計画は特定の一部実施要因計画と同等であることに注意する（例えば、4×4 のラテン方格計画は $4^{3-1}$ [一部実施要因](pri334.md)計画と同等である）。

**ラテン方格と関連計画のモデル**

#### ラテン方格計画モデルと効果水準の推定値
ラテン方格計画における応答のモデルは次式である。

$$Y_{ijk} = \mu + R_{i} + C_{j} + T_{k} + \text{偶然偶然}$$

ここで、

| | |  
| :--- | :--- |  
| *Y**ijk* | 以下の全ての観測を示す。<br>  *X*1 = *i*, *X*2 = *j*, *X*3 = *k*<br>  *X*1 および *X*2 はブロック因子   <br>  *X*3 は主因子 |  
| $\mu$ | 全体平均 |  
| *Ri* | ブロック *i* の効果 |  
| *Cj* | ブロック *j* の効果 |  
| *Tk* | 処理 *k* の効果 |  
{: .no-thead-table}

グレコ・ラテン方格および超グレコ・ラテン方格のモデルは、ラテン方格モデルの明らかな拡張であり、ブロック変数が追加されている。

**ラテン方格計画の推定値**

#### 推計値  

| | |  
| :--- | :--- |  
| $\mu$ の推定値: | $\bar{Y}$ = 全データ平均値 |  
| *Ri* の推定値: | $\bar{Y}\_{i} - \bar{Y}$   $\bar{Y}\_{i}$ = （*X*1 = *i* の全 *Y* の平均値） |  
| *Cj* の推定値: | $\bar{Y}\_{j} - \bar{Y}$   $\bar{Y}\_{j}$ = （*X*2 = *j* の全 *Y* の平均値） |  
| *Tk* の推定値: | $\bar{Y}\_{k} - \bar{Y}$   $\bar{Y}\_{k}$ = （*X*3 = *k* の全 *Y* の平均値） |  
{: .no-thead-table}

#### 計画が許す限り無作為化  
3水準、4水準、および5水準の要因を持つラテン方格の計画を以下に示す。
これらの計画は、各実行の処理の組合せをどうすべきかを示している。
**これらの計画のいずれかを用いるときは、計画が許す限り、処理単位と実行順序を確実に無作為化する**。

例えば、ひとつの推奨としては、利用可能なラテン方格計画から無作為に選択し、実行順序を無作為化する。
