# 5.3.3.4.3. 交絡（別名とも呼ばれる）

#### ある効果や交互作用を推定する能力を失ったことを意味する交絡
計画表の列 <i>X</i><sub>1</sub>×<i>X</i><sub>2</sub> を用いて[表3.14](pri3342.md#表3.14) の列 <i>X</i><sub>3</sub> を求めるときに生じる代償の一つは、明らかに、<i>X</i><sub>1</sub>×<i>X</i><sub>2</sub> の交互作用効果（すなわち <i>c</i><sub>12</sub>）の推定値を <i>X</i><sub>3</sub> の主効果の推定値とは区別して得ることができないという点にある。
言い換えれば、因子 <i>X</i><sub>3</sub> の主効果の推定値（すなわち <i>c</i><sub>3</sub> ）と、<i>X</i><sub>1</sub>と<i>X</i><sub>2</sub> の交互作用効果の推定値（すなわち <i>c</i><sub>12</sub> ）とが[交絡](../section7/pri7.md#交絡)している。
この交絡の問題は、一部実施要因計画の構築において極めて重要であり、以下で詳しく検討していく。

#### 効果の希薄性という仮定
2<sup>3-1</sup> 計画を用いるとき、<i>c</i><sub>12</sub> は <i>c</i><sub>3</sub> に比べて小さいと仮定する。
これは「<u>効果の希薄性</u>」仮定と呼ばれる。
<i>c</i><sub>3</sub> の計算は実際には <i>c</i><sub>3</sub> + <i>c</i><sub>12</sub> の計算である。
目的の効果が有意でない交互作用とのみ交絡している場合は問題はない。

** 交絡もしくは別名を作成するための表記法と方法**

#### 因子列の掛け算を簡潔に書く方法
「 <i>X</i><sub>3</sub> = <i>X</i><sub>1</sub>×<i>X</i><sub>2</sub> 」を簡潔に表す方法（ここで、計画表の列同士を掛け合わせてることを前提とする）は、「3 = 12」となる（同様に、3 = -12 は  <i>X</i><sub>3</sub> = -<i>X</i><sub>1</sub>×<i>X</i><sub>2</sub> を指す）。
なお、「12」は、一部実施要因計画を構築するために使用している種類の列積を指しており、どの列もそれ自体と乗算すると、すべて「1」からなる単位列になる。

#### 「生成元」もしくは「生成関係」および「定義関係」の定義
I=123 は、この 2<sup>3-1</sup> 計画（図3.4 の濃い影で示された角）の「<u>計画生成元</u>」または「<u>生成関係</u>」と呼ばれる。
この計画には計画生成元が 1つしか存在しないため、それは同時にこの計画の定義関係でもある。
同様に、I=-123 は図3.4 の薄い陰影の隅の部分に対する計画生成元（および定義関係）となる。
<u>I=123を 2<sup>3-1</sup> 計画の定義関係と呼ぶのは、これによって（「乗算」によって）その計画の完全な交絡パターンを作成できるからである</u>。
つまり、I=123 が与えられれば、{1=23, 2=13, 3=12, I=123} という集合を作成できる。
これは、この 2<sup>3-1</sup> 一部実施要因計画における、いわゆる「<u>別名</u>」の完全な集合である。
I=123 とすれば、半実施要因計画 2<sup>3-1</sup> のすべての列を容易に作成することができる。

#### 基本実施
**注**：どの計画生成元も、その負の対応物と置き換えることができ、同値ではあるが異なる一部実施要因計画が得られる。
正の計画生成元によって作成される一部実施要因は、「<u>基本実施</u>」と呼ばれることがある。

#### すべての主効果が2因子交互作用と交絡している 2<sup>3-1</sup> 計画
1=23、2=13、3=12 で表される交絡パターンから、2<sup>3-1</sup> 計画のすべての主効果が 2要因交互作用と交絡していることが判る。
これが、この一部実施要因計画を使用するときに支払う代償である。
他の一部実施要因計画では、異なる交絡パターンが見られる。
例えば、典型的な 2<sup>6</sup> 計画の 4分の1 計画、すなわち 2<sup>6-2</sup> 計画では、主効果が 3因子間交互作用（例：5=123）と交絡するなどである。
5=123 の場合、15=23（など）であることも容易に確認でき、これにより、2<sup>6-2</sup> 計画の特定の 2因子交互作用が、他の 2因子交互作用と交絡しているという事実が明らかになる。
