# 5.3.3.8. 一部実施要因計画の分解能の向上

#### 分解能を改善する折り返し計画
[前述](pri3324.md#計画分解能)に、一部実施要因計画では、主効果と特定の交互作用が交絡する別名構造が生じることを見た。
多くの場合、有意な効果や交互作用を覆い隠している別名構造を取り除くために、いくつかの追加処理の組合せをどのように実行すればよいかを知っておくことは有用である。

#### 特定の別名パターンを解消する部分的折り返し計画
これら追加の処置組合せを選択するための2つの方法について説明する.
* [鏡像折り返し計画](pri3381.md)（分解能 Ⅲ　の計画から分解能 Ⅳ の計画を構築する）
* [代替折り返し計画](pri3382.md)（特定の別名パターンを解消する）
