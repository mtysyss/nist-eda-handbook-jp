# 5.3.3.3. 完全実施要因計画

#### 因子、設定すべてが、他因子、設定すべてと現れる完全実施要因計画
一般的な実験計画は、入力要因すべてに2水準を設定する。
これら水準は、それぞれ「高」と「低」、あるいは「+1」と「-1」と呼ばれる。
入力要因すべてについて、可能なすべての「高／低」の組合せを含む計画は、2水準完全実施要因計画と呼ばれる。

<u>k個の因子がそれぞれ2水準であるならば、完全実施要因計画の実行回数は 2<sup>k</sup> 回となる。</u>
<br>


**表 3.2  2k 完全実施の実行数**

| **因子数** | **実行数** |
| 2 | 4 |
| 3 | 8 |
| 4 | 16 |
| 5 | 32 |
| 6 | 64 |
| 7 | 128 |


#### 完全実施要因計画の非推奨条件
上記表が示す通り、要因数が 5以上の場合、完全実施要因計画では実験回数が非常に多くなり、効率的とは言えない。
 [計画指針表](pri33.md#計画の選定)で推奨されているように、因子が5つ以上の場合は一部実施要因計画または Blacket-Burman 計画の方が適している。
