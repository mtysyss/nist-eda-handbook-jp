# 5.3.3.4.6. スクリーニング計画

#### 有意な主効果を特定する効果的な方法としてのスクリーニング計画
用語「スクリーニング計画」は、多くの要因候補の一覧からごく少数の重要要因を見つけ出すことを目的とした実験的計画を指す。
あるいは、主な目的が交互作用効果ではなく有意な主効果を特定することである場合、その計画をスクリーニング計画と呼ぶが、後者は重要度が低いと想定される。

#### 考慮因子多数のときのスクリーニング計画の利用
<u>たとえ実験目的が最終的に応答曲面モデルへの適合（RSM解析）である場合でも、考慮すべき要因が多数あるときの最初の実験はスクリーニング計画とすべきである</u>。

#### 分解能 Ⅲ もしくは Ⅳ であるスクリーニング計画
スクリーニング計画は、通常、[分解能](pri3344.md) Ⅲ が採用される。
その理由は、分解能 Ⅲ の計画であれば、効率的な実験回数で多くの要因の効果を調査できるからである。
スクリーニング計画では、分解能 Ⅳ 計画が用いられることもある。
これらの計画では、主効果が最悪の場合でも 3因子交互作用と交絡する。
これは交絡の観点からは望ましいが、分解能 Ⅲ 計画に比べてより多くの実験回数が必要である。 

#### Plackett-Burman 法
スクリーニング計画のもう一つの一般的な族として、その考案者にちなんで名付けられた Plackett-Burman 計画群が挙げられる。
これらの計画は分解能 Ⅲ に属するが、[以降](pri335.md)で議論する。

#### 有意な主効果を特定するための経済的な手法
端的に言うと、スクリーニング計画とは、多くの主効果の相対的な有意差を明らかにすることに重点を置いた、経済的な実験計画である。
