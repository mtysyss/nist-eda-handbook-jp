# 5.3.3.4.2. 2<sup>3-1</sup> 半実施要因計画の構築

#### 2<sup>2</sup> 完全実施要因計画から初め、2<sup>3-1</sup> 半実施要因計画の構築
まず、数学的に 2<sup>3 - 1</sup> = 2<sup>2</sup> であることに留意する。
これにより、最初の手順として、正規の 2<sup>2</sup> 完全実施要因計画から始めることになる。
つまり、以下の計画表から始める。
 

**表 3.12：標準順序 22 完全実施要因計画表**

|  | *X*1 | *X*2 |
| 1 | -1 | -1 |
| 2 | +1 | -1 |
| 3 | -1 | +1 |
| 4 | +1 | +1 |


#### 2<sup>2</sup> 計画の交互作用列に割り当てる第3因子
この計画には 4実行があり、2<sup>3</sup> の要因半数として適切な数だが、因子X<sub>3</sub> に対応する列がない。
これを補うために 3つ目の列を追加する必要があり、X<sub>1</sub>×X<sub>2</sub> の交互作用列を追加する。 この列は、完全実施要因計画から、X<sub>1</sub> 行の値と X<sub>2</sub> 行の値を乗算し、X<sub>1</sub>×X<sub>2</sub> 行の値を計算することで構成される。
 

**表3.13：X1×X2 交互作用列を追加した 22 計画表  
'X1×X2'**

|  | *X*1 | *X*2 | *X*1×*X*2 |
| 1 | -1 | -1 | +1 |
| 2 | +1 | -1 | -1 |
| 3 | -1 | +1 | -1 |
| 4 | +1 | +1 | +1 |


#### X<sub>3</sub> を X<sub>1</sub>×X<sub>2</sub> に設定した計画表
この表において、「X<sub>1</sub>×X<sub>2</sub>」の代わりに「X<sub>3</sub>」を代入する。
 

**表 3.14：列X3 を X1×X2 に設定した 23-1 計画表**

|  | *X*1 | *X*2 | *X*3 |
| 1 | -1 | -1 | +1 |
| 2 | +1 | -1 | -1 |
| 3 | -1 | +1 | -1 |
| 4 | +1 | +1 | +1 |


#### X<sub>3</sub> を -X<sub>1</sub>×X<sub>2</sub> に設定した計画表
表3.14の各行は、[図3.4](pri3321.md#図 3.4)に示す計画の濃い陰影で示された角に対応していることに注意されたい。
もし、2<sup>3-1</sup> 計画の3列目を作成するルールとして X<sub>3</sub>= -X<sub>1</sub>×X<sub>2</sub> を設定していたならば、次のような結果が得られていたはずである。
 
****  


**表3.15：列X3 を -X1×X2 に設定した 23-1 計画表**

|  | *X*1 | *X*2 | *X*3 |
| 1 | -1 | -1 | -1 |
| 2 | +1 | -1 | +1 |
| 3 | -1 | +1 | +1 |
| 4 | +1 | +1 | -1 |


#### 完全実施要因計画ほど正確ではない 一部実施要因計画の主効果推定値
この計画により、[図3.4](pri3341.md#図3.4) 箱の薄い色で示された部分が得られる。
作成した 2<sup>3-1</sup> 計画はどちらも同等に優れており、どちらも元の 2<sup>3</sup> の完全実施要因計画に比べて実行回数を半分に削減できる。
<i>c</i><sub>1</sub>、<i>c</i><sub>2</sub>、<i>c</i><sub>3</sub> を因子<i>X</i><sub>1</sub>、<i>X</i><sub>2</sub>、<i>X</i><sub>3</sub> 主効果の推定値（すなわち、ある効果について「低」から「高」へ変化した際の応答値の差）とすると、これらの推定値の<i>c</i><sub>1</sub>、<i>c</i><sub>2</sub>、<i>c</i><sub>3</sub> の推定値の精度は、8回の実験からなる完全実施要因計画ほど高くない。
これは、平均値を計算するための観測値が 8つではなく 4つしかないためである。
これは、実験回数を減らすことで生じる代償の一つである。

#### 例
**例：**[前例](pri3341.md#例)で示した「圧力（P）、テーブル速度（T）、および下向き力（D）」の計画条件について、無作為な実行順序で反復した 2<sup>3-1</sup> のデータである。
実行間に 5つの中心点実行（「000」）が散りばめられている。
この計画表は、前述の手法を用いて、D = P*T として作成した。
