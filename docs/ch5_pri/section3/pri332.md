# 5.3.3.2. 無作為化ブロック計画

#### 妨害要因の影響を「取り除く」ためのブロック
無作為化ブロック計画では、主に関心がある要因または変数が1つある。
しかし、他にいくつかの妨害要因も存在する。

妨害要因とは、測定結果に影響を与えることがあるが、主たる関心事ではない要因のことである。
例えば、処置を適用する場合、妨害要因として処置を準備した特定の作業者、実験が行われた時間帯、室温などが挙げられる。
すべての実験には妨害要因が存在する。
実験者は通常、どの妨害要因を追跡し、可能であれば制御するほど重要であるかを判断するために、ある程度の時間を費やす必要がある。 

#### 制御可能な妨害要因に用いられるブロック
妨害要因を制御できる場合、ブロック化と呼ばれる重要な手法を用い、妨害要因が実験誤差に及ぼす影響を低減や排除する。
基本的な考え方は、妨害要因を一定に保ち、対象要因のみを変化させる均質なブロックを作成することである。
ブロック内では、分析において考慮されるブロック因子の変化による変動を気にすることなく、対象因子の異なる水準が及ぼす影響を評価することが可能である。

#### ブロック因子の定義
<u>主因子の各水準が、妨害因子の各水準と等しい回数で組み合わされる場合、その混在因子はブロック因子として扱われる</u>。
実験の解析では、実験の各ブロック内における主因子の水準を変化させた場合の影響に焦点を当てる。

#### 最も重要な阻害要因のいくつかをブロック
一般的なルールは次の通り。

<u>「ブロックできるものはブロックし、ブロックできないものは無作為化する。」</u>

ブロック化は最も重要な妨害変数のうち数個の影響を取り除くために用いられる。
その後、無作為化を用いて残りの妨害変数の混入効果を低減させる。

#### 無作為化ブロック計画の表
無作為化ブロック実験を捉える上で有用な方法の一つは、全実験の内のひとつのブロック内ででそれぞれ実施される完全無作為化実験の集合と見なすことである。

**無作為化ブロック計画（RBD）**

| 計画の<br>名称 | 要因数<br>*k* | 実施回数<br>*n*<br> |  
| :----- | :---: | :--------: |  
| 2因子RBD | 2 | $`L_1*L_2`$ |  
| 3因子RBD | 3 | $`L_1*L_2*L_3`$ |  
| 4因子RBD | 4 | $`L_1*L_2*L_3*L_4`$ |  
| . | . | . |  
| *k*因子RBD | *k* | $`L_1*L_2*\ldots*L_k`$ |  

ここで

$$\begin{array}{l}
L_1 = \text{因子1 の水準（設定）数} \\
L_2 = \text{因子2 の水準（設定）数} \\  
L_3 = \text{因子3 の水準（設定）数} \\ 
L_4 = \text{因子4 の水準（設定）数} \\
\vdots \\ 
L_k = \text{因子}k \text{ の水準（設定）数} 
\end{array}$$

**無作為化ブロック計画の例**

#### 無作為化ブロック計画の例
ある半導体製造施設の技術者達が、炉内の拡散工程後の抵抗率測定値に、ウェハへのイオン注入量の違いが有意な影響を与えるかを検証したい。
彼らは4種類の異なる注入量を試したいと考えており、同じロットから、各注入量ごとに3枚ずつ実験用ウェハを用意できるだけの数が確保されている。

#### 炉の稼働は妨害要因
彼らが懸念している要因は「炉のでの実行」であり、炉のでの実行ごとに前回とは異なることが知られており、多くのプロセス母数に影響を及ぼすためである。

#### 妨害要因の排除が理想
この実験を行う上で理想的な方法は、4×3＝12枚のウェハを炉のでのすべて同じ実行で処置することである。
そうすれば、厄介な炉の影響を完全に排除できる。
しかし、通常の生産用ウェハには炉の使用優先権があり、どの炉の稼働でも同時に投入できる実験用ウェハはごくわずかしか許可されていない。

#### 非ブロック法
この実験を非ブロック法で実施するため、12枚の実験用ウェハを無作為な順序で、炉の処理 1回につき 1枚ずつ処置する。
しかし、そうすると、炉の処理ごとのばらつきによって各抵抗率測定の実験誤差が増大し、異なる処理量による影響を調査することがより困難になる。
この実験をブロック法で実施する場合、製造部門に1回の炉処置で4枚の実験用ウェハを投入することを許可してもらえることを前提として、3回の炉処置のそれぞれに、異なる処理量のウェハを4枚ずつ投入することになる。
唯一の無作為化は、処理量1 の ウェハ3枚のうちどれを炉処置1 に入れるかを選択することであり、同様に、処理量2、3、4のウェハについても同様に行う。

#### 実験の概要
$`X_1`$ を処理量の「水準」、$`X_2`$ をブロック因子である炉の処理と定義する。
すると、実験は次のように記述できる。

$$\begin{array}{l}
k = 2 \text{因子（1つの主因子} X_1 \text{と 1つのブロック因子} X_2 \text{）} \\
L_1 = 4 \text{水準、因子 }X_1 \\
L_2 = 3 \text{水準、因子 }X_2 \\
n = 1 \text{反復 セルあたり} \\
N = L_1 * L_2 = 4 * 3 = 12 \text{実行}
\end{array}

#### 無作為割付前の計画試行
無作為化前の試行計画は、以下のようになる。

| $`X_1`$ | $`X_2`$ |    
| :----: | :----: |    
| 1 | 1 |  
| 1 | 2 |  
| 1 | 3 |  
| 2 | 1 |  
| 2 | 2 |  
| 2 | 3 |  
| 3 | 1 |  
| 3 | 2 |  
| 3 | 3 |  
| 4 | 1 |  
| 4 | 2 |  
| 4 | 3 |   

#### 行列表現
この計画試行をまとめる別の方法では、4行3列の行列を用いる。
この行列の4つの行は処置 $`X_1`$ の水準を表し、列はブロック変数 $`X_2`$ の3水準を表す。
行列の各セルには、前述の $`X_1`$ と $`X_2`$ の組合せに対応するインデックスが割り当てられる。

さらに、任意の*K*-因子無作為化ブロック計画における試行は、単に *K* 次元行列のセルのインデックスに他ならないことに注意する。 
 
**無作為化ブロック計画のモデル**

#### 無作為化ブロック計画のモデル
妨害変数1つを含む無作為化ブロック計画のモデルは次のように表される。

$$Y_{i,j} = \mu + T_{i} + B_{j} + \text{無作為誤差} $$

ここで


$`Y_{i,j}`$ は、 $`X_1= i`$ かつ $`X_2= j`$  
$`X_1`$ は主因子  
$`X_2`$ はブロック因子
$`\mu`$ は一般位置母数（すなわち、平均）  
$`T_i`$ は、処置 *i* による効果（因子 $`X_1`$）
$`B_j`$ は、ブロック *j* による効果である（因子 $`X_2`$）

**無作為化ブロック計画の推定**

#### 無作為化ブロック計画における要因効果の推定

| | |  
| :---- | :------- |  
| $`\mu`$ の推定値： | $`\bar{Y} = \text{データすべての平均値} `$ |  
| $`T_i`$ の推定値： | $`\bar{Y}_{i} - \bar{Y}`$<br>ここで、$`\bar{Y}_{i} = (X_1 = i \text{となるすべての} Y \text{の平均値})`$ |  
| $`B_j`$ の推定値： | $`\bar{Y}_{j} - \bar{Y}`$<br>ここで、$`\bar{Y}_{j} = (X2 =j \text{となるすべての} Y \text{の平均値})`$ |

#### 訳註
* 「無作為化ブロック計画」は、「乱塊法」とも呼ばれます。
