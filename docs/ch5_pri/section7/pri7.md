# 5.7. DOE用語集

#### 主なDOE用語の定義
このページでは、DOEで使用される多くの基本用語の定義と情報を掲載している。

* <span id="Alias"></span>**(Alias) 別名**： ある[効果](pri7.md#Effect)の推定値に、1つ以上の他の効果（通常は高次の[交互作用](pri7.md#Interactions)）の影響も含まれている場合、それらの効果は<u>別名</u>と言われる（[交絡](pri7.md#Confounding)を参照)。
例えば、4因子実験における効果D の推定値が実際には (D + ABC) を推定している場合、主効果D は 3因子交互作用 ABCと別名状態にある。
**注**：高次交互作用が存在しないか、あるいは有意でない場合には、問題にならない。

* <span id="Analysis"></span>**(Analysis of Variance(ANOCA)) 分散分析（ANOVA）**： 一連の観測値の変動を帰属可能な要因に分解し、様々な有意差検定を設定するための数学的手法。

* <span id="Balanced"></span>**(Balanced Design) 釣合い計画**： すべてのセル（すなわち処理の組合せ）が同数の観測値を持つ実験計画法。

* <span id="Blocking"></span>**(Blocking) ブロック化**： 実験研究において[処理の組合せ](pri7.md#Treatment%20)を実施するための計画であり、原材料、作業者、機械などの既知の変化に起因する実験結果への影響が、ブロック化変数の各水準に集中するようにする。
**注**： ブロック化を行う理由は、系統的な影響を隔離し、主効果を覆い隠すのを防ぐためである。
ブロック化は、[無作為化](pri7.md#Randomization)を制限することで実現される。

* <span id="Center"></span>**(Center Points) 中心点**： すべての因子範囲の中心値にある点。

* <span id="Coding"></span>**(Coding Factor Levels) 符号化因子水準**： 因子の測定尺度を変換し、高い値を＋1、低い値を－1とする（<u>尺度調整</u>を参照）。
2水準完全要因実験においてすべての因子を符号化すると、計画行列のすべての列が[直交](pri7.md#Orthogonality)する。
<br><br>
符号化は、元の測定尺度の単純な線形変換である。
「高い」値が X<sub>h</sub> で、「低い」値が X<sub>L</sub>（元の尺度において）である場合、尺度変換は元の X の値をすべて (X - a)/b に変換する。
ここで 、a = (X<sub>h</sub> + X<sub>L</sub>)/2、b = (X<sub>h</sub> - X<sub>L</sub>)/2 である。
元の測定尺度に戻すには、符号化された値に「b」を掛け、「a」を加算すればよい。
つまり、X = b(符号化された値) + a となる。
<br><br>
例として、対象が温度で、上限設定が 65℃、下限設定が 55℃の場合、a = (65 + 55)/2 = 60、b = (65 - 55)/2 = 5 となる。
中心点（符号化された値が 0 となる点）の温度は、5(0) + 60 = 60°C となる。

* <span id="Comparative"></span>**(Comparative Designs) 比較計画**： 1事前重要因子について結論を導き出すことを目的とした計画であり、場合によっては 1つ以上の他の「妨害」因子が存在する。

* <span id="Confounding"></span>**(Confounding) 交絡**： 交絡計画とは、一部の[処理効果](pri7.md#Treatment)（主効果または交互作用）が、一部の[ブロック効果](pri7.md#Blocking)  と同様に、実験観測値の同じ線形結合によって推定される計画のことである。
この場合、処理効果とブロック効果は交絡していると言われる。
交絡はまた、[主効果](pri7.md#main)の推定値が主効果そのものだけでなく、高次[交互作用](pri7.md#Interactions)による混入や偏りからも生じていることを示す一般的な用語としても用いられる。  注：交絡設計は、[完全実施要因計画](../section3/pri331.md)がブロックごとに実施され、かつブロック規模が異なる処理の組合数よりも小さい場合に、自然に生じる。
また、完全要因計画の代わりに[一部実施要因計画](../section3/pri332.md)が選択された場合にも生じる。

* <span id="Crossed"></span>**(Crossed Factors) 交差因子**： 以下の[因子](pri7.md#Factors)を参照。

* <span id="Design"></span>**(Design) 計画**： 特定のモデルを適合させ、目的の効果を推定することを可能にする一連の実験実行。

* <span id="Design"></span>**(Design Matrix) 計画行列**：実 験を構築、分析するときに有用な、実験を[行列記述](../section3/pri32.md#The%20Design)もの。

* <span id="Effect"></span>**(Effect) 効果**： 因子の設定を変更することで応答がどのように変化するか。
単一の因子の効果は、主効果とも呼ばれる。
**注：**： 2水準を持つ因子Aについて、低 ＝ -1、高 ＝ ＋1 となるように[尺度調整](pri7.md#Scaling)された場合、因子A の効果は、A が －1 のときの平均応答値から A が ＋1 のときの平均応答値を差し引き、その結果を 2で割ることで推定される（－1 の水準は ＋1 の水準から 2尺度単位離れているため、2で割る必要がある）。

* <span id="Error"></span>**(Error) 誤差**： 一連の観測値に見られる説明のつかない変動。
**注**： DOEでは通常、偶然誤差と不適合誤差の両方についての理解が求められる。

* <span id="Experimental"></span>**(Experimental Unit) 実験単位**： 特定の処理組合せが適用される対象。
**注**： 実験単位は
    * PC基板
    * シリコン・ウェハ
    * 同時に処理された部品のトレイ
    * 個々の農作物
    * 農地の一区画
    * 自動車用トランスミッション
    * など

* <span id="Factors"></span>**(Factors) 要因、因子**： 出力に変化をもたらすために研究者が操作する工程の入力。
一部の要因は実験者によって制御できないが、応答に影響を与える可能性がある。
その影響が有意である場合、これらの<u>制御不能な要因</u>は測定され、データ解析に用いられるべきである。
**注**： 入力は離散的または連続的である。
    * <span id="Crossed"></span>**(Crossed Factors) 交差因子**： 実験において、一方の因子のすべての水準が、もう一方の因子の水準すべてと組み合わされる場合、これら2因子は<u>交差</u>している。
    * <span id="Nested"></span>**(Nested Factors) 枝分れ因子**： 要因「A」の水準または値が、要因「B」の水準すべてまたは値に対して異なる場合、要因「A」は要因「B」の中に「入れ子」されている。
    **注**：枝分れ因子または効果は、階層的な関係にある。

* <span id="Fixed"></span>**(Fixed Effect) 固定効果**： 水準数が限られている、あるいは実験者が関心を持つ水準が限られている入力変数に関連する効果。

* <span id="Interactions"></span>**(Interactions) 交互作用**： ある因子の応答に及ぼす影響が、別の因子（または複数の因子）の水準に依存する場合に生じる。

* <span id="Lack"></span>**(Lack of Fit Error) 不適合誤差**： 分析において、工程モデルから1つ以上の重要な項または因子が省略された場合に生じる誤差。
**注**： DOEに反復実験を含めることで、実験誤差を「不適合誤差」と「偶然（純粋）誤差」という構成要素に分解することができる。

* <span id="Model"></span>**(Model) モデル**： 特定の応答の変化を1つ以上の因子の変化と関連付ける数学的関係。

* <span id="Nested"></span>**(Nested Factors) 枝分れ因子**： 上記の[因子](pri7.md#Factors)を参照。

* <span id="Orthogonality"></span>**(Orthogonality) 直交性**： 長さが同じ2つのベクトルは、対応する因子の積の和が 0である場合に直交している。
**注**： 実験計画法は、いずれかの因子効果が他の因子効果に対して相殺され（和がゼロになる）、釣合いが取れている場合に直交している。

* <span id="Random"></span>**(Random Effect) 無作為効果**： 取り得る値の数が非常に多い、あるいは無限にある母集団から無作為に選択された入力変数に関連する効果。

* <span id="Random"></span>**(Random error) 偶然誤差**： 工程の自然な変動に起因して生じる誤差。
注：無作為誤差は通常、平均がゼロで分散が一定な正規分布に従うと[仮定](../section2/pri24.md)される。
**注**： 偶然誤差は実験誤差とも呼ばれる。

* <span id="Randomization"></span>**(Randomization) 無作為化**： 実験計画法（DOE）において、処理材料を割り当て、処理の組合せを実施するための計画であり、ある実行における条件が、前の実行の条件に依存せず、また、その後の実行の条件を予測できないようにするものである。
  **注**： 無作為化の重要性はいくら強調してもしすぎることはない。
無作為化は、実験から導き出される結論が正しく、曖昧さがなく、正当化可能なものであるために不可欠である。

* <span id="Replication"></span>**(Replication) 反復**： 同一の処理の組合せを複数回実施すること。
**注**： 反復を含めることで、不適合誤差とは独立した偶然誤差の推定が可能となる。

* <span id="Resolution"></span>**(Resolution) 分解能**： 推定された主効果が、推定された2水準[交互作用](pri7.md#Interactions) 、3水準交互作用などと、どの程度[別名](pri7.md#Alias:) （または[交絡](pri7.md#Confounding)）しているかを表す用語。
一般に、設計の分解能は、ある主効果が交絡している（同定される）ものより 1大きい。
ある主効果がいくつかの2水準交互作用と交絡している場合、分解能は 3となる。
**注**： [完全実施要因計画](../section3/pri331.md)には交絡がなく、分解能は 「無限大」であると言われる。
実用上のほとんどの場合、分解能5 計画は優れており、分解能4 計画でも十分である場合がある。
分解能3 計画は、経済的な[スクリーニング設計](pri7.md#Screening)として有用である。

* <span id="Responses"></span>**(Responses) 応答**：工程の出力。
従属変数と呼ばれることもある。

* <span id="Response"></span>**(Response Surface Designs) 応答曲面計画**： 工程のウィンドウを完全に探索し、応答をモデル化するDOE。
**注**： これらの計画は因子が5つ未満の場合に最も効果的である。
応答曲面計画には2次モデルが用いられ、計画には各因子につき少なくとも 3水準が必要となる。

* <span id="Rotatability"></span>**(Rotatability) 回転性**： 計画は、任意の点 **x** における予測応答の分散が、**x** から計画[中心点](pri7.md#Center)までの距離のみに依存する場合、<u>回転可能</u>である。
この性質を持つ計画は、 **x** における予測分散を変化させることなく、その中心点を中心に回転させることができる。
**注**： 回転性は、応答面計画（すなわち 2次モデル計画）において望ましい特性である。

* <span id="Scaling"></span>**(Scaling Factor Levels) 尺度調整係数水準**： 係数水準を[変換](../section3/pri32.md#Definition%25of)し、高い値を +1、低い値を  -1 にすること。

* <span id="Screening"></span>**(Screening Design) スクリーニング計画**： 多数の要因のうち、どの要因が応答に有意な影響を与えるかを特定する実験計画法（DOE）。
  **注**： 通常、スクリーニング計画には 5つ以上の要因が含まれる。

* <span id="Treatment"></span>**(Treatment) 処理**：処理とは、他の処理と比較される効果を持つ、因子水準の特定の組合せのことである。

* <span id="Treatment "></span>**(Treatment Conbination) 処理の組合せ**： 特定の実験試行における、複数の因子の設定の組合せ。
<u>実行</u>とも呼ばれる。

* <span id="Variance"></span>**(Variance Components) 分散成分**：全体的な変動を割り当て可能な成分に分割すること。
