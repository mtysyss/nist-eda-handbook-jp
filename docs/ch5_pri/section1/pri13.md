# 5.1.3. DOEの手順

#### DOEの重要な手順
DOEから良好な結果を得るには、以下の7つの手順が必要である。

1. [目標の設定](../section3/pri31.md)
2. [工程変数の選定](../section3/pri32.md)
3. [実験計画の選定](../section3/pri33.md)
4. 計画の実行
5. [データが実験の仮定と整合しているかの確認](../section2/pri2.md)
6. [結果の分析と解釈](../section4/pri4.md)
7. 結果の活用と提（さらなる実験やDOEにつながる場合もある）。

#### 実務上の考慮事項に関するチェックリスト
実験の計画および実施において重要な実務上の考慮事項は以下の通り。

* まず、計器や測定装置の性能を確認する。
* 実験はできるだけ単純にする。
* 計画したすべての実行が実行可能であることを確認する。
* 実行中に工程の偏位やズレに注意する。
* 予定外の変更（例：実験の途中で作業員を交代するなど）は避ける。
* 予期せぬ事態に備えて、ある程度の時間的余裕（および予備の材料）を確保する。
* 関係者全員の合意を得る。
* 実験計画の各手順に関する効果的な責任体制を維持する。
* 平均値の要約だけではなく、すべての生データを保存する。
* 発生したことはすべて記録する。
* 実験終了後は機器を元の状態に復旧する。

**DOEに対する逐次もしくは反復手法**

#### 一連の小規模実験計画
一連の小規模実験を行う計画を立てる方が、ひとつの大規模実験にすべての答えを期待するよりも、多くの場合、より良い結果が得られる。

「ひとつの大規模な実験で答えが得られる」と信じるのは、往々にして間違いである。

実験計画においてより有用な取組みは、1つの実験で有用な結果が得られることもあるが、完全な答えにたどり着くまでには、2つや3つ、あるいはそれ以上の実験を行うことが一般的であることを認識することである。
つまり、反復的手法が最善であり、最終的には最も経済的であると言える。
すべての卵を1つのカゴに入れることはお勧めできない。 

#### 次段階への示唆を与える各段階
反復的手法がしばしば最も効果的である理由は、実験の各段階を順を追って進めていくことが理にかなっており、各段階が次の実験をどのように実施すべきかについての示唆を与えてくれるからである。
