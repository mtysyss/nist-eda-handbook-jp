# 5.1.1. 実験計画法とは

#### 情報を経済的に最大化する実験計画法（DOE）
実験では、1つ以上の応答変数に及ぼす影響を観察するために、1つ以上の工程変数（または要因）を意図的に変化させる。
（統計的）実験計画法（*DOE*）は、得られたデータを分析し、妥当かつ客観的な結論を導き出す、実験を計画するための効率的な手順である。

DOEは、実験の[目的](../section3/pri31.md)を決定し、研究対象の[工程要因](../section3/pri32.md)を選択することから始める。
<u>実験計画法</u>とは、実験に先立ち詳細な実験計画を策定することである。
適切に選択された実験計画は、一定の実験労力に対して得られる「情報」の量を最大化する。

DOEの基礎となる統計理論は、一般的に<u>プロセス・モデル</u>の概念が起点である。 

**DOEのプロセス・モデル**

#### ブラックボックス・プロセス・モデル
「ブラックボックス」型のプロセス・[モデル](pri12.md#モデル:)から始めるのが一般的で、制御可能な、実験者が自由に変化させることができるいくつかの離散的もしくは連続的な入力[要因](pri12.md#要因:)と、1つ以上の測定された出力[応答](pri12.md#応答)が含まれる。
出力応答は連続変数であると仮定される。
実験データを用い、出力と入力を結びつける経験的（近似）モデルが導出される。
これら経験的モデルには、一般的に[1次と2次項](../section2/pri23.md)が含まれる。

多くの場合、実験では、制御不能な要因を数多く考慮に入れなければならないが、異なる機械や作業者といった離散的な要因、周囲温度や湿度といった連続的な要因である。

#### DOEのモデル
実験データに適合させる最も一般的な経験的モデルは、<u>線形</u>または<u>2次</u>のいずれかをとる。

#### 線形モデル
2因子 $`X_1`$ および $`X_2`$ の線形モデルは次式で表すことができる。

$$Y = \beta_{0} + \beta_{1}X_{1} + \beta_{2}X_{2} +\beta_{12}X_{1}X_{2} + \text{実験誤差}$$

ここで、$`Y`$ は[主効果](pri12.md#効果:) $`X_1`$ および $`X_2`$ の各水準における応答値であり、$`X_1 X_2`$ 項は $`X_1`$ と $`X_2`$ 間の[交互作用](pri12.md#交互作用:)効果を考慮するために含まれている。
定数 $`\beta_{0}`$ は、両方の主効果が 0 の場合の $`Y`$ の応答値である。

より複雑な例として、3因子 $`X_1`$、$`X_2`$、$`X_3`$と 1応答変数 $`Y`$ を持つ線形モデルは、次の形になる（すべての可能な項がモデルに含まれている場合） 
 
$$Y = \beta_{0} + \beta_{1}X_{1} + \beta_{2}X_{2} + \beta_{3}X_{3} +\beta_{12}X_{1}X_{2} + \beta_{13}X_{1}X_{3} + \beta_{23}X_{2}X_{3} +\beta_{123}X_{1}X_{2}X_{3} + \text{実験誤差}$$
 
「$`X`$」が1つだけある3つの項は<u>主</u>[<u>効果</u>](pri12.md#効果:)項である。
また、$`k(k-1)/2 = 3*2/2 = 3`$ 個の<u>2因子</u>[<u>交互作用</u>](pri12.md#交互作用:)項と、1個の<u>3因子</u>交互作用項がある（これは簡略化のため、しばしば省略される）。
実験データを分析するとき、すべての未知の "$`\beta`$" 係数が推定され、「$`X`$`」項の係数が検定され、どれが 0 と有意に異なるかを確認する。 

#### 2次モデル
2次（quadratic）モデル（通常、曲率が疑われる[応答曲面](pri12.md#応答曲面) DOEで使用される）は、3因子交互作用項を含まないが、線形モデルにさらに3つの項、具体的には次式を追加する。

$$\beta_{11}X_{1}^{2} + \beta_{22}X_{2}^{2} + \beta_{33}X_{3}^{2}$$

**注**：当然ながら、完全なモデルにはXの平方を含む多くの交差積（または交互作用）項が含まれることがある。
しかし、一般にこれらの項は必要とされず、ほとんどの DOEソフトウェアでは、初期値でこれらをモデルから除外している。
