# 2.6.1.2. 分析と解釈

#### [繰り返し性に関するプローブ効果のグラフ](mpc613.md)
グラフによる解析では、ウェハおよびプローブごとにプロットされた繰り返し性の標準偏差を示している。
プローブは番号で識別され、プローブ 2362は#5として表記されている。
このプロットから、両方の測定実行において、このプローブの精度が他のプローブよりも優れていることがわかる。

プローブ 2362番は、その優れた精度から、NISTにおいてすべての 100 Ω.cm 抵抗率のウェハを測定するための測定器として選定された。
したがって、本分析の残りの部分では、このプローブに焦点を当てる。

#### 日、ウェハ、実行に関する枝分かれ設計におけるプローブ 2362番の[繰り返し性標準偏差のプロット](mpc613.md)
プローブ 2362番の精度については、日、ウェハ、および実行ごと繰り返し性標準偏差をプロットすることで、まず一貫性を確認する。
日数は文字でコード化されている。
プロットから、両方の実行において、プローブの繰り返し性はウェハや日数に依存しないことが確認できるが、実行2 のD、E、F日の標準偏差は、他の日と比較して幾分大きくなっている。
ウェハ表面へのプローブを繰り返し押し当てることにより、わずかな劣化が生じる可能性があるため、これは驚くべきことではない。

次に、[繰入れ繰り返し性標準偏差](../section4/mpc441.md)は以下の範囲で行われた。

* *K = 6*日間 自由度 *K(J - 1) = 30*
* *L = 2*実行 自由度 *LK(J - 1) = 60*
* *Q = 5*枚のウェハ 自由度 *QLK(J - 1) = 300*

組み入れた結果は以下の通り。
中間段階は示されていないが、繰り返し性標準偏差は、[ウェハの組み入れ例](../section4/mpc441.md)に示されている。

**組入れ階層1 標準偏差（Ω.cm）**

```
 プローブ 実行 1   自由度   実行 2   自由度   組入れ   自由度

 2362.   0.0658  150     0.0758   150    0.0710  300
```

#### [プローブ 2362番の再現性および安定性のグラフ](mpc614.md)
各ウェハの中心部における6回の測定値の平均をウェハごとに1つのグラフにプロットした。
各グラフの左側にある点（線で結ばれている）は、5日間に渡って測定されたウェハ中心部の平均値であり、右側の点は、測定工程の安定性を確認するために1か月後に再度実施した同じ測定値である。
これらのプロットからは、日間変動に加え、実行ごとのわずかな変動を示している。

初期の研究では、これらの変化の原因としてゲージの長期的な偏位は考慮されていない。
妥当な結論として、日間や実行間は、測定工程における無作為な変動に起因すると考えられる。

#### プローブに起因する偏りへの対処法
プローブ 2362番は、その優れた精度から認証工程に採用されまたが、他のプローブとの比較において偏りが生じていることが問題となっている。
この問題に対処するには、以下の2つの方法がある。

1. プローブ 2362番で得られたすべての測定値を、プローブ群の平均値に補正する。
2. プローブ間の差に対する標準偏差を不確かさの予算に含める。

研究におけるプローブが、この種類のプローブの無作為抽出サンプルであると仮定できる場合は、(1)がより適切な選択である。
これは、単位（抵抗率）が試験方法によって定義されている場合に特に当てはまる。
