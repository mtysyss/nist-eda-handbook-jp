# 2.6.3.2. 分析と解釈

#### このページの目的
本ページでは、初期研究においてゲージを用いたシリコン・ウェハの抵抗率（Ω・cm）測定のタイプA 不確かさ要素を定量化するために、ゲージ研究において収集されたデータ分析を概説する。

#### 3階層の標準偏差の概要
以下の表は、不確かさ分析における[階層1](../section4/mpc441.md)、[階層2](../section4/mpc442.md#level2)、および[階層3](../section4/mpc443.md#level3) の標準偏差を[ゲージ事例研究](mpc61.md#level1)からまとめたものである

```
プローブ 2362番の標準偏差

 階層        記号      見積もり     自由度
 階層-1      s₁       0.0729     300
 階層-2      s₂       0.0362      50
 階層-3      s₃       0.0197       5
```

#### 日および実行の各要素の計算
[日効果](../section4/mpc442.md)を推定する標準偏差は、

$$\displaystyle \large{s_{days} = \sqrt{s_2^2 - \frac{1}{6} s_1^2} = 0.0217 \quad \text{Ω・cm}}$$

[日ごとの変動](https://www.itl.nist.gov/div898/handbook/mpc/section4/mpc443.md)を推定する標準偏差は、

$$\displaystyle \large{s_{runs} = \sqrt{s_3^2 - \frac{1}{6} s_2^2} = 0.0130 \quad \text{Ω・cm}}$$

#### 感度係数を示す認定値標準偏差の計算
各ウェハの認定値は、*M = 1* 日間、*P = 1* 回の実行において、ウェハの中心で実施された*N = 6* 回の繰り返し性測定の平均値である。
なお、*N*、*M*、および *P* は、ウェハごとのゲージ研究における測定回数、すなわち *J*、*K*、および *L* とは必ずしも一致しないことに注意されたい。
認定値の標準偏差（時間依存の誤差源について）は、

$$\displaystyle \large{s = \sqrt{s_{runs}^2 + s_{days}^2 - \frac{1}{6} s_1^2}}$$

この計算には、認定測定において日や実行に渡る反復測定が行われていなかったとしても、日間および実行間の標準偏差が含まれている。
これらの因子は、対象となる特定の測定では抽出されていなくとも、測定工程の全体的な不確かさに寄与する。

#### 自由度計算のために必須な式の書き換え
自由度は、個々の要素の計算には分散間の差が関与するため、上記の方程式からは計算できない。
[3階層設計の感度係数の表](../section5/mpc564.md#level3)から、

*N = J、M = 1、P = 1*の

場合、上記式は次の形で書き換える。

$$\displaystyle \large{s = \sqrt{\frac{5}{6} s_2^2 + s_3^2}}$$

この場合、自由度は Welch-Satterthwaite 法を用いて近似する。 

#### プローブの偏り - [プローブの偏りを示すグラフ](mpc615.md)
グラフによる分析から、5つのプローブ間の相対偏りが示されている。
各ウェハについて、プローブごとのウェハ平均値からの偏差をウェハ番号に対してプロットしている。
これらのグラフから、プローブ 2362番（コード5）が他のプローブに比べて低偏りであることが確認できる。
この偏りは、プローブが使用された後（実行2）により顕著に現れている。

#### プローブによる偏りへの対処法
プローブ 2362番は、その優れた精度から認証工程に採用されたが、他のプローブと比較して偏りがあるため、問題が生じている。
この問題に対処するには、次の2つの方法がある。

1. プローブ 2362番で得られたすべての測定値をプローブ群の平均値に補正する。
2. プローブ間の差に対する標準偏差を不確かさの予算に含める。

認証工程で採用された最善の戦略は、すべての測定値をプローブ 2362番の平均偏り分だけ補正し、その補正値の標準偏差を不確かさ タイプA成分として扱うことである。 

#### 偏りまたはプローブ 2362番および不確かさの補正
プローブおよびウェハごとの偏りは、[ゲージ事例研究](mpc61.md#probebias)に示されている。
プローブ 2362番における偏りは、2回の測定について以下の表にまとめられている。
補正値は平均偏りの負の値とみなす。
補正値の標準偏差は 10個の偏りの平均値の標準偏差となる。

```
  プローブ 2362番の推定偏り
 
ウェハ プローブ   実行 1    実行 2     All
```

#### 設定[データベース](mpc6312.md)と[差異のプロット](mpc6321.md)
検査ウェハの測定は、プローブを異なる構成 2つ（A、B）で配線して行われた。
構成A と構成B の差をプロットした結果、両構成間に偏りは認められなかった。

#### 構成間の差異の検定
この結果は、実行1 および実行2 を通じて一貫しており、以下の表に示す[t-統計量](../section4/mpc455.md#tstatistic)によって裏付けられ、ウェハ 5枚、6日間の測定データから平均差および標準偏差が計算されている。
t-統計量 < 2 から有意な差はないことを示している。
結論として、配線構成による偏りはなく、この要因による不確かさへの寄与もない。

```
  設定間の差異

状況    平均      標準偏差   自由度   t
 
前    -0.00858   0.0242    29    1.9  
後    -0.0110    0.0354    29    1.7
```

#### 感度係数、標準偏差、自由度を示す誤差予算
標準不確かさと自由度を計算するための[感度係数を示す誤差予算](../section5/mpc565.md)の概要を以下に示す。

**抵抗率（Ω・cm）の誤差予算**

| 源 | タイプ | 感度 | 標準偏差 | 自由度 |
| :--- | :---: | :--- | :--- | ---: |  
| 繰り返し性 | A | $`a_1 = 0 | 0.0729 | 300 |  
| 再現性 | A | $`a_2 = \sqrt{5/6}`$ | 0.0362 | 50 |  
| 実験間 | A | $`a_3 = 1`$ | 0.0197 | 5 |  
| プローブ 2362番 | A | $`a_4 = \sqrt{1/10}`$ | 0.0162 | 5 |  
| 配線構成 A | A | $`a_5 = 1`$ | 0 | -- |  

#### 繰り返し性、日、実行、およびプローブの要素を含む標準不確かさ
標準不確かさは、以下の誤差予算から計算する。

$$\displaystyle \large{u = \sqrt{ \sum_i a_i^2 \cdot s_i^2} = \sqrt{\frac{5}{6} s_2^2 + s_3^2 +\frac{1}{10} s_{probe}^2 } = 0.0388 \quad \text{Ω・cm}}$$

#### 自由度および拡張不確かさの近似
*u* の自由度は、Welch-Satterthwaite の式により次のように近似する。

$$\displaystyle \large{\nu = \frac{u^4}{ \sum_{i=1}^5 \frac{a_i^4 \cdot s_i^4}{\nu_i} } = 42}$$

ここで、$`\nu_i`$

は、表の右端の列に示されている自由度である。

[t 表](../section3/eda3672.md)から、自由度 42、有意水準 0.05 における境界値は 2.018 であり、拡張不確かさは以下となる。

$$U = 2.018 \cdot u = 0.078 \quad \text{Ω・cm}$$
