# 2.6.1.1. 背景とデータ

#### 測定方法の解説
100 Ω・cm ウェハの抵抗率測定は、測定システムの不確かさの要因を評価するために、ASTM標準試験方法[（ASTM F84）](../section7/mpc7.md#ASTMF84)に従って実施された。
抵抗率測定は長年にわたり研究が行われ、それらのデータから、ゲージの基本的な不確かさを超えて、工程に影響を与える変動源の存在が明らかである。
測定結果には数日単位および数ヶ月単位での変動が認められており、本研究のデータは、測定工程におけるこうした時間依存の変化を定量化する構成がされている。

#### ゲージ
本研究で使用したゲージは、シリコン・ウェハの抵抗率を測定するために用いられる5つのプローブである。
これら5つのゲージは、抵抗率測定を行うための典型的な4点式ゲージの無作為抽出標本であると仮定される。
問題となるのは、これらゲージが本質的に同等か、あるいはゲージ間で偏りが生じる可能性があるかという点である。

#### 検査標準
本研究における検査標準は、100 Ω・cm のウェハ 100枚から無作為に選定された5枚のウェハである。

#### 作業者
本研究では、作業者の影響は有意ではないと考えられた。

#### [測定値データベース](mpc6111.md)
この [3階層枝分かれ設計](../section4/mpc43.md)は、以下の構成である。

* *J = 6* 1日あたり各ウェハ中心部での測定
* *K = 6* 日
* *L = 2* 実行

プローブの特性およびウェハが測定に及ぼす影響を評価するため、この設計を以下の条件で繰り返した。

* *Q = 5* 枚のウェハ（検査標準 138、139、140、141、142）
* *I = 5* のプローブ（1、281、283、2062、2362）

実行は約1ヶ月の間隔を空けて実施された。
各ウェハの中心での *J = 6* 測定は、平均値および繰り返し性標準偏差に集約され、ウェハ、プローブ、および測定日の識別情報を付記してデータベースに記録された。
