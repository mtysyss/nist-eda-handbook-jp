# 2.6.2.1. 背景とデータ

#### 検査標準測定値の説明
この工程では、単結晶（51939番）から切り出された個々のシリコン・ウェハの抵抗率（Ω・cm）を測定する。
これらのウェハにはリンがドープされており、公称抵抗率は 100 Ω・cm である。
130枚のウェハ・バッチから無作為に選ばれた1枚のウェハ（137番）が、本工程の検査標準として指定された。

#### データ収集の設計と[データベース](mpc6211.md)
測定は、NISTプローブ 2362番を用いて、ASTM試験方法[（F84）](../section7/mpc7.md#ASTM F84)に従って実施された。
検査標準の測定は、同時期に結晶 51939番由来の個々のウェハに対して行われていた認証測定を複製したものである。
検査標準については、以下の条件が適用された。

* *J = 6* 繰り返し、各日ウェハの中心
* *K = 25* 日間 

*K = 25* 日間は、個々のウェハが米国国立標準技術研究所（NIST）にて認定されていた期間を網羅している。
