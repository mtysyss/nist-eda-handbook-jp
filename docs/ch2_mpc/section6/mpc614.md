# 2.6.1.4. 日間と長期安定性の効果

#### 測定に対する日間と長期安定性の効果
以下に示す5つのグラフにプロットされているデータ点は、ウェハ番号 138、139、140、141、142の各ウェハ中心部で測定された抵抗率の平均値である。
各グラフには、2回の測定実行それぞれのデータが示されている。
各実行における6日間の測定データは約1ヶ月間隔で取得されており、ウェハ 139番を除いて、実行1 と実行2 の間で非常にわずかな上昇傾向が見られる。
この影響の大きさは、データ解析において階層3 の標準偏差と推定される。
