# 2.6.1.5. プローブ 5つ間の差異

#### 実行1 - プローブ 5つの各ウェハ平均値との差のグラフ
プローブ 2062番および 2362番は、他のプローブに比べて低めに偏っていることが示されている。

![Plot of Run 1: Graph of differences from wafer averages for each of 5 probes](https://www.itl.nist.gov/div898/handbook/mpc/section6/mpc615a.gif)

**プローブの記号：1 = 1番；2 = 281番；3 = 283番；4 = 2062番；5 = 2362番** 

#### 実行2 - プローブ 5つの各ウェハ平均値との差のグラフ
プローブ 2362番は他のプローブに比べ、依然として低めに偏っていることが示されている。

![Plot of Run 2: Graph of differences from wafer averages for each of 5 probes](https://www.itl.nist.gov/div898/handbook/mpc/section6/mpc615b.gif)

**プローブの記号：1 = 1番；2 = 281番；3 = 283番；4 = 2062番；5 = 2362番**
