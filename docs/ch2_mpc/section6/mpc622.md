# 2.6.2.2. 分析と解釈

#### [繰り返し性標準偏差](../section4/mpc441.md)と[階層2 標準偏差](../section4/mpc442.md)の推定値
データベースからの階層1 標準偏差（自由度 *J - 1 = 5* をそれぞれ持つ）を *K = 25* 日間について組み入れし、繰り返し性の信頼できる推定値を得る。
この組入れ値は 

$$s_1= 0.06139 \text{Ω・cm}$$

となり、自由度は *K(J - 1) = 125* である。
階層2 標準偏差は日平均値から計算され、 

$$s_2= 0.02680 \text{Ω・cm}$$

となり、自由度は *K - 1 = 24* である。 

#### 不確かさの計算との関係
これらの標準偏差は、検査標準と同じ材料および構造を持つウェハ上で行われた6回の測定値平均値の不確かさを推定するのに適している。
計算方法は、[検査標準測定の感度係数](../section5/mpc562.md)の節で説明されている。
試験ウェハにおける測定回数が異なる場合、その計算方法は、[階層2 設計の感度係数](../section5/mpc563.md)の節で説明されている。

#### [繰り返し性と階層2 標準偏差計算を示す図解の表](mpc6221.md)
検査標準データの部分集合（*J = 6* 繰り返し、*K = 6* 日）を表形式で示し、計算例を説明する。
この限定されたデータベースから計算された *K(J - 1) = 30* の自由度を持つ組入れ繰り返し性標準偏差が、[表](mpc6221.md)の最後から2行目に示されている。
自由度 *K - 1 = 5* の[階層2 標準偏差](../section4/mpc442.md)は、中心値から計算され、表の最終行に示されている。

#### [プローブ 2362番の管理図](mpc623.md)
プローブ 2362番の精度を監視するための管理図は、[標準偏差の管理図](../section2/mpc231.md)の節で説明した通りに作成される。
プローブの劣化を検査するための上限管理限界（UCL）は、[F 表](../section3/eda3673.md)の境界値を用いて計算される。
分子の自由度は *J - 1 = 5*、分母の自由度は *K(J - 1) = 125* である。
有意水準 0.05 の場合、 

$$F_{0.05, 5, 125} = 2.29$$ 

$$UCL = s_1 \sqrt{F_{0.05, 5, 125}} = 0.09238 \quad \text{Ω・cm}$$

#### プローブ 2362番の管理図の解釈
管理図には、上管理限界を超えている点が2つ示されている。
管理下にある測定工程では、標準偏差の5％が上管理限界（UCL）を超えると予想される。
2つの外れ値があるからといって、プローブの繰り返し性に重大な問題があることを示すものではないが、今後、プローブを注意深く監視する必要がある。

#### [偏りと変動の管理図](mpc624.md)
[Shewhart 管理図](../section2/mpc221.md)を用いて抵抗率の偏りおよび長期変動を監視するための管理限界は、以下で与えられる。

$$UCL = \text{平均} + 2 \cdot s_2 = 97.1234 \quad \text{Ω・cm}$$ 

$$中心線 = 平均 = 97.0698 \quad \text{Ω・cm}$$ 

$$LCL = 平均 - 2 \cdot s_2 = 97.0162 \quad \text{Ω・cm}$$

#### 偏りの管理図の解釈
管理図から、データ点は中心線を中心に無作為に散らばっており、深刻な問題は見られないが、1点が上側管理限界を超え、もう1点が下側管理限界をわずかに超えている。
結論として、以下のことが言える。

* 測定工程に偏り、変化、または偏位の証拠はない。
* 長期的な管理不備の証拠はない。

今後、管理限界を超える測定値が得られた場合は、偏りや変動の長期変化について評価を行う必要がある。
