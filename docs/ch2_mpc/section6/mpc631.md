# 2.6.3.1. 背景とデータ

#### 測定の説明
課題となっている測定値は、シリコン・ウェハの抵抗率（Ω・cm）である。
目的は、この測定での定義された基準である [ASTM F84](../section7/mpc7.htm#ASTM%20F84) の方法に従って、配線構成 A のプローブ 2362番で認証されたシリコン・ウェハ約100枚の抵抗値に関する不確かさの計算である。
各ウェハの報告値は、1日のうちにウェハの中心で実施された6回の測定値の平均である。
プローブ 2362番は、測定が可能な米国国立標準技術研究所（NIST）が所有する 5つのプローブのうちの1つである。

#### NIST測定値における不確かさ源
不確かさ解析では、以下の変動源を考慮している。

* [ウェハ中心部での測定の繰り返し性](mpc632.md)  
* [日間変動](mpc632.md#day)
* [実行間変動](mpc632.md)  
* [プローブ 2362番による偏り](mpc632.md#probebias)
* [配線構成による偏り](mpc632.md#configbias)

#### 3階層枝分かれ設計の[データベース](mpc6311.md)--時間依存不確かさ源の推定
認証測定そのものは、日間変動や長期的効果に関する情報を得られないため、不確かさの要素を推定する主要な情報源ではない。
3つの時間依存性不確かさ源に対する標準偏差は、[3階層枝分かれ設計](../section4/mpc43.md)から推定する。
設計は、この目的のためにウェハのロットから無作為に選ばれた *Q = 5* 枚のウェハそれぞれに対して反復した。
工程の長期安定性を確認するために 2回の実行の間に認証測定を行った。
データは、ウェハ中心での測定による[繰り返し性標準偏差](../section4/mpc44.md)（それぞれの自由度 *J - 1 = 5* ）で構成される。
