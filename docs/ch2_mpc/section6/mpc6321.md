# 2.6.3.2.1. 2つの配線構成の違い

#### 2通りの方法で設定したプローブの測定
以下のグラフは、2つの異なる構成、A および B で配線したプローブ（2362番）での、ウェハ 5枚の抵抗率測定値（Ω・cm）から作成されたものである。
このプローブは 4点プローブであり、多くの配線構成が可能である。
本実験では、大きな不一致を特定する手段として、2つの構成のみを試験した。

#### 本研究の人工物
ウェハ 5枚、すなわち 138番、139番、140番、141番、および 142番は、グラフ内ではそれぞれ 1、2、3、4、5と番号が振られている。
これらのウェハは、抵抗率の認定を受けていた約100枚のウェハのバッチから無作為に選ばれたものである。

#### 解釈
同じ日に実施された構成A と構成B の測定値の差を各ウェハについて6日間にわたってプロットした。
2つのグラフは、約2ヶ月の間隔を空けて実施された2回の測定結果を示している。
中央の点線はゼロ線である。
データ点の分布は、ゼロ線の上下にかなり無作為に散らばっており、プローブ 2362番については構成間の差異がないことを示している。
この結論はプローブ 2362番に適用されるものであり、このタイプのすべてのプローブに一般化することはできない。
