# 2.2.3.1. 標準偏差の管理図

#### 機器の劣化や一度限りの異常挙動
計測器精度の変化、特に異常と劣化は、適切な対応が必要である。
精度の変化は、短期標準偏差を管理図上に打点した *F* 分布に基づく統計的管理手順によって検出することができる。

この種の管理図の基準線は、[データ収集と分析](mpc232.md)で定義している組み入れた標準偏差 $`s_1`$ である。 

#### [質量秤の管理図の例](../section3/mpc3511.md)  
計測器の劣化を検知する上で重要なのは、上側管理限界 *UCL* のみである。
短期標準偏差が過去のデータに基づいて設定された上側管理限界内に収まっている限り、計測器の精度が劣化していない（すなわち、共通要因によるばらつき）と確信する根拠がある。

#### F分布に基づく管理限界
管理限界は

$$UCL = {\large s}_1 \sqrt{F_{\alpha, J-1, K(J-1)}}$$  

であり、ここで根号内の値は、自由度 $`(J-1)`$ および $`K(J-1)`$ を持つ[*F* 分布表](../../ch1_eda/section3/eda3673.md)の上限 *α* 境界値である。
分子の自由度 $`v_1=(J-1)`$ は、現在の測定値から計算された標準偏差に関連し、分母の自由度 $`v_2=K(J-1)`$ は、過去のデータの組み入れられた標準偏差に対応する。
確率 *α* は、例えば 0.05 のように小さい値に設定される。

より一般的な標準偏差管理限界とは対照的に、この管理限界を採用する根拠は、本質的に以下の仮説検定を行っていることにある。

$$H_0: \quad \sigma_1 = \sigma_2$$
$$H_a: \quad \sigma_1 < \sigma_2$$

ここで、$`σ_1`$ は上記で定義された $`s_1`$ の母集団値であり、$`σ_2`$ は、現在の値の標準偏差が検定される値である。
一般に、$`s_1`$ は十分な過去のデータに基づいており、$`σ_1`$ が「既知」の値であると仮定することは合理的である。

上記の上側管理限界は、標準偏差が等しい場合の標準的な *F* 検定に基づいて導出される。
この導出の根拠と詳細は、[Cameron andHailes (1974)](..//section7/mpc7.md#CameronHailes)に報告されている。 

#### サンプル・コード
$`α=0.05`$、$`J=6`$、$`K=6`$ の場合における *F* 値の計算用サンプル・コードは、[Dataplot](https://www.itl.nist.gov/div898/handbook/mpc/section2/mpc231d.dp)と [R](https://www.itl.nist.gov/div898/handbook/mpc/section2/mpc231d.r)の両方で利用可能である。
