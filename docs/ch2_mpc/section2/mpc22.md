# 2.2.2. 偏りと変動の管理方法

#### 長期に渡る検査標準の監視による偏りと変動の管理
偏りおよび長期変動は、検査標準の測定値を長期に渡り監視し管理する。
数回の測定順に渡り一定水準で続く検査標準測定値の変化は、以下の可能性を示している。

1. 参照標準の変質または損傷  
2. 検査標準人工物の変質または損傷  
3. 測定工程の仮定を無効にする手順の変更  

検査標準における測定のばらつきの変化は、以下のような多くの原因のいずれかによる可能性がある。

1. 環境管理の不備
2. 取扱い方法の変更
3. 計測機器の著しい劣化  

管理手順では、経過時間での検査標準測定値の動きを監視し、著しい変化が発生したときに信号を発する。
この目的に適した2つの管理図の方法がある。

#### 導入が容易な Shewhart 管理図
[Shewhart 管理図](mpc221.md)は、直感的で導入しやすいという利点がある。
中心線、対称な上側と下側の管理限界が特徴である。
この管理図は、工程における大きな変化を検出するには適しているが、小さな変化（標準偏差の半分から1倍程度）を迅速に検出することには向いていない。

#### Shewhart 管理図の図解
以下に示す Shewhart 管理図の簡略図では、上側管理限界を超えた一つの測定値を除き、測定値は管理限界内にあることを示している。

![depiction of shewhart control chart](https://www.itl.nist.gov/div898/handbook/mpc/section2/mpc22a.gif)  

#### EWMAチャートは、わずかな変化を捉えるのに適しています
[EWMA管理図](../section3/mpc3522.md)（指数加重移動平均）は導入がやや難しいが、小さな変化を早期に検知することが目的であれば、検討すべきである。
Shewhart 管理図の判定手順は現在の測定値のみに基づいているのに対し、EWMA管理図の判定手順は、検査標準の過去測定値の（時間経過での）指数の減少関数に基づいている。

#### 安定し、利用可能出なければならない工程管理用の人工物
工程の偏りや長期変動を管理するための標準試験片は、測定対象となる作業負荷での測定対象物と同じ種類および形状でなければならない。
人工物は安定し、測定工程において継続的に利用可能でなければならない。
通常、1つの人工物で十分である。
これには以下が含まれる。

#### 事例研究：[比抵抗](../section6/mpc62.md)  
1. 作業負荷から無作為に抽出した個々の物  
2. 目的のために試験所が確保した特定の物
