# 2.2.2.4. 是正措置

#### 管理外れ信号の考えられる原因の検討と長期的是正措置の実施
管理外れ信号に対する多くの考えられる原因がある。

A. 工程に対する是正措置を必要とし<u>ない</u>（ただし、その時点の測定値は破棄する必要がある）原因としては、以下のものが挙げられる。

1. 工程が実際には管理下にあるときの、偶発的異常  
2. 測定工程の設定または操作時の不具合  
3. データ記録時の誤り  

B. 偏りの変化は、以下による可能性がある。

1. 人工物の損傷  
2. 人工物の劣化（摩耗、あるいは汚れや鉱物堆積物の蓄積）

C. 長期変動の変化は、以下による可能性がある。

1. 計測機器の劣化  
2. 環境条件の変化  
3. 新規または経験の浅い作業員による影響  

#### 短期に対する 4段階戦略
高精度測定工程が伴う管理外れ信号に対処するための即時戦略は、以下の通り。

#### 測定の繰返し
1. 測定手順を繰り返し、管理外れ信号が単なる偶然か、一時的な不具合か、それとも工程における恒久的な変化や傾向を示していたのかを確認する。

#### 試験対象物の測定値の破棄
2. 高精度な工程において、試験対象物とともに検査標準も測定している場合、新しい測定データに基づいて試験対象物に新しい値を割り当てる必要がある。

#### 偏位の確認
3. 最近のデータのパターンを検討する。
計測機器や人工物の劣化が原因で工程が徐々に偏位しているならば、  
    * 計測機器の修理が必要になる可能性がある  
    * 参照試料の再校正が必要になる可能性がある　　

#### 再評価
4. 測定工程を管理下に戻すことができない場合は、より新しいデータに基づいて工程値と管理限界を再設定する。
