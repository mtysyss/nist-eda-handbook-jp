# 2.2.3. 短期変動の管理方法

#### 計測器に重点
短期変動または測定器の精度は、対象の測定器を用いて繰り返し測定を行い、その標準偏差を監視することで管理する。
データベースは、単一の人工物、あるいは人工物の組の代表に対する測定結果から作成する。

#### 測定結果 - 事例研究：[比抵抗](../section6/mpc62.md)
人工物は、以下のように、作業負荷内で測定される対象物と同じ種類および形状でなければならない。

1. 作業負荷内の物  
2. この目的のために選定された単一の検査標準  
3. この特定の目的のために確保された人工物の集合
