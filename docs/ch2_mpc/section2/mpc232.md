# 2.2.3.2. データ収集

#### 事例研究：[抵抗率](../section6/mpc62.md)
測定を行うためのスケジュールは、1台の計測器を用いて設定する必要がある（1日1回、週2回、あるいはあらゆる測定条件を網羅するのに適切な頻度）。

#### 短期標準偏差
測定値は次式で表される。

$$Y_{kj}(k=1, \ldots, K, \quad j=1, \ldots, J)$$  

ここで、*K* 回の測定それぞれにおいて *J* 個の測定値がある。
*k* 番目の測定時の平均は次式である。

$$\overline{Y}_{k \small{\bullet}} = \frac{1}{J}\sum_{j=1}^{J} Y_{kj}$$  

*k* 番目の測定時の短期（繰り返し性）標準偏差は次式である。

$${\large s}_k = \sqrt{\frac{1}{J-1} \sum_{j=1}^{J} ( Y_{kj} - \overline{Y}_{k \small{\bullet}} ) ^2} . $$  

ここでの自由度は $`(J-1)`$ である。

#### 組み入れた標準偏差
繰り返し性の標準偏差は、*K* 回の測定結果について組み入れ、自由度 $`K(J-1)`$ を持つ水準1 の標準偏差の推定値として得る。

$${\large s}_1 = \sqrt{\frac{1}{K} \sum_{k=1}^{K} {\large s}_k^2}  . $$  

注記：繰り返し性標準偏差は、1つの測定組に基づく場合でも、複数の測定組を組み入れた場合でも、同じ表記が用いられる。

#### データベース
個々の短期標準偏差と、すべての有意な要因の識別情報をファイルに記録する。
この情報を記録する最良の方法は、各グループごとに固定されたフィールドに情報を1行（スプレッドシートでは行）ずつ記載した単一のファイルを使用することである。
以下に、典型的な記入例を示す。

1. 試験品または検査用標準品の識別情報  
2. 日付  
3. 短期標準偏差  
4. 自由度  
5. 計測器  
6. 作業者
