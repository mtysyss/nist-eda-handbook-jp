# 2.2.1. 測定工程管理の課題

#### 目的：測定結果の「良さ」の保証
統計的管理の目的は、予測可能な範囲内での測定結果の「良さ」の保証と、測定結果の不確かさの記述の妥当性を確認することである。

統計的管理手法を用い、測定工程の過去の水準と比較し、偏りや変動における変化を検定する。
しかし、測定工程の仕様や校正が不適切ならば、管理手順では測定値間の比較可能性のみしか保証できない。 

#### 厳密ではない正規性の仮定
[測定工程に関連する仮定](../section1/mpc121.md)は、統計的管理にも適用され、すなわち、測定誤差は時間的に無相関であり、単一分布の母集団に由来する。
制御の検定は、基礎となる分布が正規（ガウス）分布であるという仮定に依存するが、検定手順は正規性からのわずかな逸脱に対しては頑健である。
実用上、求められるのは測定値の分布が釣鐘型で対称であることのみである。

#### 工程を管理する仕組みの検査標準
[検査標準](../section1/mpc12.md)を用いた測定は、測定工程を管理するための手段を提供する。

検査標準の測定は、偶然誤差の影響を除き、同一の結果をもたらすべきであり、管理のための試験は、工程に起因する偶然誤差が継続的に検査標準の過去データと同一の統計的分布に従っているかを基本的に試験する。
 
検査標準データベースを用いて監視および試験する変化は、以下の通り。
