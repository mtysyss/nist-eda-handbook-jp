# 2.2.2.3. 偏りと長期変動の監視

#### 監視段階
管理図の基準線と管理限界を過去データから決定し、不良観測値を除去し、管理限界を再計算して、測定工程の監視段階に入る。
質量校正工程を監視するための[Shewhart 管理図](mpc221.md)と[EWMA管理図](mpc2211.md)を以下に示す。
これら2つの技法を比較する目的ために、2つの管理図は同じデータに基づき、基準線と管理限界は1985年以前に取得されたデータから計算している。
監視段階は1985年の初めから始まる。
同様に、両方の管理図の管理限界は3標準偏差限界になっている。
[検査標準データおよび分析](../section3/mpc3521.md)は、別の節でより詳しく解説する。

#### 1985年以降に発生した工程の外れ値と偏位を示す、[キログラム検査標準測定値の Shewhart 管理図](../section3/mpc3521.md)  
![shewart control chart for kilogram calibrations](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3521a.gif)  

#### EWMA 統計量の管理限界の多重逸脱を示す、[キログラム検査標準測定値のEWMA図](../section3/mpc3522.md)  
以下のEWMA管理図では、1985年以降の管理データが緑色で示され、EWMA統計量は生データの上に重ねられた黒い点として表示されている。
管理外れ信号を探すために、生データではなく、EWMA統計量に注目する。
EWMA統計量は加重平均であるため、単一の管理測定値よりも標準偏差が小さく、したがって、EWMAの管理限界は、上に示した Shewhart 管理図の限界よりも狭くなっている。

![EWMA control chart for mass calibrations](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3522c.gif)  

#### 対応が必要になる管理限界を超える測定値
管理戦略は、過去のデータから将来の測定値を予測できることに基づいている。
新しい各検査標準測定値は、即時に管理図に打点する。
工程状態に変化がなければ、これらの値は管理限界内に収まると予想される。
管理限界を超える測定値は、管理外れの可能性があり、是正措置が必要である。
外れ値に対処するための戦略を策定するときは、管理外れを示す信号の考えられる原因を理解しておく必要がある。

#### 有意な傾向や偏位の兆候
管理図は、工程の偏位や偏位を特定するために、定期的に全体像を確認する必要がある。
上記の Shewhart 管理図では、管理限界を超えているデータ点はごくわずかである。
1985年以降に生じた、わずかではあるが有意な工程偏位は、経時的な管理測定値のプロットを精査することによってのみ特定できる。
[キログラム検査標準データの再分析](../section3/mpc3521.md)に、Shewhart 管理図の管理限界は1985年以降のデータに基づいて更新すべきであることが示されている。
EWMA管理図では、1986年以降、管理限界の違反が複数回発生している。
校正環境において、このような違反が複数回発生していることは、管理技術者に対し、参照標準の損傷や値の変化などが原因で工程に偏位が生じており、工程の見直しが必要であることを警告するものである。
