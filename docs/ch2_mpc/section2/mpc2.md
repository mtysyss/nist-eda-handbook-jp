# 2.2. 測定工程の統計的管理
本節の目的は、測定工程において統計的管理を行うために取ることができる手順を概説し、不確かさの妥当性を示すことである。
測定工程は、偏りと変動の両方に関して変化し得る。
測定が記録されているならば、計測器の精度変化に容易に注意を払えるが、偏りや長期変動の変化は、工程における人工物の経時変化を調査しているときには把握するのが難しい。
