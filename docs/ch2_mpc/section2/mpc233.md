# 2.2.3.3. 短期精度の監視

#### 将来の精度の監視
過去のデータから管理図の基準線と管理限界を決定したら測定工程の監視段階に入る。
以下の管理図の管理限界は1985年以前に収集されたデータに基づいている。

#### 管理図上で逐次監視する新しい標準偏差
*J* 回の測定値に基づく新しい短期標準偏差それぞれを管理図に打点し、管理限界を超える点は統計的制御不足の可能性を示す。
時間経過に伴う偏位は計測器の劣化を示す。
管理外れにある点は是正措置が必要であり、[外れ値に対処する戦略](mpc234.md)を策定するときに、管理外れを示す要因を把握しておく必要がある。

#### 各自由度が3の天秤について、過去の標準偏差に基づく[質量秤の精度管理図](../section3/mpc3511.md)  
この管理図から、2つの外れ値と、時間経過に伴う天秤精度のわずかな低下が確認できる。

![Control chart for precision of balance](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3511a.gif)

#### Jと異なる測定数の監視
将来の標準偏差が、過去データベース内の測定数である *J* に基づく必要はない。
しかし、測定回数の変更は管理状態の検定に影響を及ぼし、新しい測定ごとに管理限界が変化する管理図の作成は、必ずしも適切ではない。

 *J'* 回の測定に基づく新しい標準偏差で、計測器の精度が管理下であるのは、
 
 $${\large s}_{\text{new}} < {\large s}_1 \sqrt{F_{\alpha, J'-1, K(J-1)}}$$
 
 分子の自由度 $`v_1=J'-1`$ は変化するが、分母の自由度 $`v_2=K(J-1)`$ は変わらないことに注意されたい。
