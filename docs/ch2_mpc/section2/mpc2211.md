# 2.2.2.1.1. EWMA管理図

#### 時間経過でのみ明らかになる小さな変化
データにパターンが現れるまでには時間が掛かるため、工程に恒久的な偏位が生じても、Shewhart 管理図の管理限界からの個々の逸脱が直ちに現れるとは限らない。
[Shewhart 管理図](mpc221.md)は、標準偏差の1〜1.5倍程度の微小な変化を検出するという点では、あまり有効ではない。
この目的には、EWMA（指数加重移動平均）管理図の方が適している。

#### 量産校正用の[EWMA管理図の例](../section3/mpc3522.md)
指数加重移動平均（EWMA）は、工程を監視するための統計量であり、現在の測定値から時間的に離れるほど、データへの重みを徐々に小さくする方法で平均化する。
データ

$$Y_1, Y_2,..., Y_t$$  

は、時間順に並べられた検査標準測定値である。
時刻 *t* における EWMA 統計量は、個々のデータ点から再帰的に計算し、最初の EWMA 統計量である $`EWMA_1`$ は、過去のデータの算術平均となる。

$$EWMA_{t+1} = \lambda Y_t + (1-\lambda)EWMA_{t}$$  

#### EWMAの管理の仕組み
EWMA管理図は、重み係数 $`\lambda`$ の選択によって、工程の小さな変化や漸進的な偏位に対して感度を高めることができる。
この目的では、通常、重み係数として0.2～0.3 が推奨されている（[Hunter](../section7/mpc7.md#Hunter)）が、0.15 がもよく用いられる値である。

#### 管理図の限界値
管理図の目標値もしくは中心線は、過去データの平均値である。
上限（*UCL*）と下限（*LCL*）は、それぞれ以下の式で与えられる。

$$UCL = EWMA_{1} + k{\large s} \sqrt{\frac{\lambda}{(2-\lambda)}}$$  
$$LCL = EWMA_{1} - k{\large s} \sqrt{\frac{\lambda}{(2-\lambda)}}$$

ここで、*s* を掛けた平方根の式は EWMA統計量の標準偏差の近似値であり、係数 *k* は Shewhart 管理図の場合と同様に選択され、一般的には 2 もしくは 3 である。

#### EWMA管理図の実施手順
EWMA管理図の導入手順は、他のあらゆる種類の管理手順と同様である。
この手順は、「良い」過去データが管理下にある工程を代表しているという仮定に基づいており、同じ工程から得られる将来のデータが過去のデータと一致するかを検定する。
手順の始めに、過去の検査標準データから目標値（平均）と工程の標準偏差を計算する。
その後、手順は[監視段階](mpc223.md)に入り、EWMA統計量を計算し、管理限界に対して検定する。
EWMA統計量は加重平均であるため、その標準偏差は生データの標準偏差よりも小さく、対応する管理限界は、Shewhart の個々の観測値管理図の管理限界よりも狭い。
