# 2.2.3.4. 是正措置

#### 考えられる原因の検討
A. 是正措置を必要とし<u>ない</u>（ただし、その時点の測定値は破棄する必要がある）原因は、以下のものが挙げられる。

  1. 精度が実際に管理下にある場合の偶発的な不具合  
  2. 測定工程の設定または操作における一時的な不具合  
  3. データ記録時の誤り 

B. 計測器性能の変化は、以下である可能性がある。

1. 電子部品または機械部品の劣化  
2. 環境条件の変化  
3. 新規または経験の浅い作業者による影響  

#### 測定の繰返し
測定手順を繰り返し、管理外れ信号が単なる偶然か、一時的な不具合か、それとも工程における恒久的な変化や傾向を示していたかを確認する。

#### 試験対象物への新しい値の割付け
不確かさが保証されなければならない高精度な工程においては、新しい測定データに基づいて、試験対象に新しい値を割り当てる必要がある。

#### 劣化の確認
直近の標準偏差のパターンを検討する。
もし、計測器や人工物の劣化が原因で工程が徐々に管理外れ偏位しているならば、計測器の修理や交換が必要である可能性がある。
