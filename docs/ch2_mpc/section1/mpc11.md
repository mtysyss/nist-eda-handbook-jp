# 2.1.1. 特徴付けにおける課題

#### 測定値の「良さ」
測定工程は、測定結果が出力である、適切に運営された生産工程と考えることができる。
測定値の「良さ」は課題であり、良さは測定に影響を与える誤差によって特徴付けられる。

#### 偏り、ばらつき、不確かさ
測定の良さは、以下の観点で定量化する。

* [偏り](section1/mpc113.md)  
* [短期変動あるいは計測器の精度](mpc114.md#短期)
* [日次あるいは長期変動](mpc114.md#長期)
* [不確かさ](../section5/mpc5.md)

#### 継続的な統計的管理施策の必要性
良さの維持は、以下の両方を制御する統計的管理施策によって保証される。
* [短期変動あるいは計測器の精度](../section2/mpc23.md)
* 工程の偏りと日々の変動を制御する[長期変動](../section2/mpc22.md)

#### 継続的工程に対する適用範囲
本章で取り上げる技法は、主に継続的な工程を意図している。
単発の試験や特殊な試験、あるいは破壊試験については、その特性を評価することが困難である。
継続的工程の例として、以下が挙げられる。

* 類似試験対象を定期的に測定する校正  
* 材料を定期的に特性評価する認証
* 計測（道具）誤差が顕著になり得る生産工程
* 調査期間を通してデータを収集できる特別研究

#### 製造工程への適用
本章の内容は、計測（工具）誤差の大きさが重要な考慮事項となり得る製造工程の研究に関連している。
計測誤差の評価に関するより具体的な指針は、[ゲージ研究](../section4/mpc4.md)の節で取り上げる。
