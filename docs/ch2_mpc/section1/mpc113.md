# 2.1.1.3. 偏りと精度

#### 精度と偏りの定義
精度とは、ある対象物に対して行われた測定値とその真の（目標または参照）値との間に一致があるかを示す定性的な用語である。
偏りとは、同じ対象物に対して行われた測定値の平均とその真の値との差を表す定量的な用語である。
特に、測定機関において、偏りとは、ある試験対象物に対する当該機関の（経時的な）平均値と、参照機関が同じ試験対象物に対して同じ測定を行い得られるであろう平均値との間の差（一般的には未知）を指す。

#### 偏りの特定
測定工程における偏りは、以下の方法によって特定する。

1. 標準物質および／または測定器の[校正](../section3/mpc3.md)は標準試験所が行い、標準試験所の標準物質との比較に基づき、依頼者の標準物質に値が割り当てられる。
2. [検査標準](mpc12.md)において、検査標準の管理図における管理限界の逸脱が、標準または測定器の再校正が必要であることを示唆する。
3. 測定保証施策の場合は、標準試験所または他の適格機関から人工物が依頼者に送付され、依頼者の環境下で「盲検」サンプルとして測定される。
4. 機関間比較では、複数の試験所間で参照標準または材料が巡回される。

#### 偏りの低減
標準物質や測定器の校正を行うことで、偏りを除去または低減することができる。
コストや時間の制約があるため、校正の大部分は二次または三次機関によって行われ、基準機関を起点とする相互比較の連鎖を通じて基準系に関連付けられる。

また、その目的のために巡回された人工物や計測器（標準物質）との比較に基づき、内部測定値に補正を加え偏りを低減する。 

#### **注意**
すべての機器や標準器が適切に校正され、管理されている場合でも、偏りの原因となる誤差が生じる可能性がある。
温度が、測定にこの種の偏りを生じさせる可能性が最も高い。
例えば、一定の熱源は、金属製品の寸法測定に重大な誤差をもたらす。
温度は、化学的および電気的な測定にも影響を及ぼす。

一般的に言えば、この種の誤差は、測定技術に精通した者でなければ特定できない。
読者は、技術文献や当該分野の専門家に相談し、指針を得ることを推奨する。
