# 2.1.1.1. 目的

#### 目的：報告された値に対する誤差の影響を理解し、定量化する
特徴付けの目的は、測定工程における誤差の原因と、それらが特定の測定結果与える影響の状況を理解することにある。
本節では、以下に関する背景を記述する。

* 測定工程における誤差の原因の特定
* 測定工程における誤差の理解と定量化
* 不確かさの記述におけるこれら誤差が特定の報告値に及ぼす影響の定式化

#### 重要な概念
特徴付けは、測定システムの基礎になる、以下の特定の概念に依存する。

* [測定の基準（権威）](mpc112.md)  
* [偏り](mpc113.md)  
* [変動](mpc114.md)  
* [検査標準](mpc12.md)

#### 報告値：顧客に送信される結果を指す総称
報告された値は、特定の試験項目の測定結果である。
これには以下が含まれる。

* 単一の測定値
* 複数の測定値の平均
* モデルによる最小二乗法による予測
* 物理モデルによって関連付けられた複数の測定結果の組合せ
