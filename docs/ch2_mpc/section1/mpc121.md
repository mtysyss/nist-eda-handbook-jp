# 2.1.2.1. 仮定

#### 事例研究：[比抵抗測定用標準試料](../section6/mpc62.md)
本章で推奨されている品質管理手順を適用して検査標準データを確認する前に、基本的な前提条件を検討する必要がある。
品質管理手順の基礎にある基本的な仮定は以下の通り。

1. データは単一の統計的分布に従う。  
2. 分布は正規分布である。  
3. 誤差は時間的に相関がない。  

#### ![](https://www.itl.nist.gov/div898/handbook/eda/gif100/histogra.gif)
単一正規分布の仮定を確認する簡単な方法は、検査標準データのヒストグラムを作成することである。
[ヒストグラム](../../ch1_eda/section3/eda33e.md)は、一つのこぶがある釣鐘形のパターンに従わなければならない。
測定システムに問題があることを示す異常の種類は次のとおり。

1. 誤差に二つ以上の分布があることを示す二重のこぶ  
2. 工程における外れ値を示す長い裾  
3. 測定工程が制御されていない、または適切に指定されていないことを示す平坦なパターンまたは両端のこぶ  

#### ![](https://www.itl.nist.gov/div898/handbook/eda/gif100/normprpl.gif)  
正規性の仮定を検定するための別のグラフ手法は、[確率プロット](../../ch1_eda/section3/eda33l.md)である。
データが正規分布から得られている場合、点は近似的に直線上に配置されることが期待される。
外れ値や他の分布からのデータは、S字曲線を描く。

#### ![](https://www.itl.nist.gov/div898/handbook/eda/gif100/lagplot.gif)  
測定間の相関を検定するためのグラフ手法は、[遅延プロット](../../ch1_eda/section3/eda33f.md)である。
測定が時間経過に対して適切に構築されていれば、相関は頻繁に問題にはならない。
相関問題は、測定が時間的に非常に近く測定され、装置が測定から次の測定までに適切に復旧できない場合に一般的に発生する。
時間経過による相関は通常あるが、しばしば無視できる程度である。
