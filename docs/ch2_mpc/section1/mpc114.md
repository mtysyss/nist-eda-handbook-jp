# 2.1.1.4. 変動

#### 時間依存変動の原因
変動性とは、測定条件が安定している場合でも、あるいは時間、温度、作業者などの変化に伴って変動する場合でも、同一の試験対象に対して測定値にわずかな違いが生じる傾向を指する。
本章では、時間依存性の変動要因として以下の2つを取り上げます：

* 計測器の精度に起因する短期変動
* 環境や取り扱い方法の変化に関連する長期変動

#### 6日間にわたる短期変動が同じである2つの測定工程の図示。
工程1は日ごとの変動が大きく、工程2は日ごとの変動がごくわずかである。

#### 短期変動
短期的な誤差は、計測器の精度に影響を及ぼす。
非常に高精度な計測器であっても、偶然誤差によって生じるわずかな変動が見られる。
単一の計測器を用いて数分間または数時間に渡って行われる測定という観点から考えることが有用で、これは通常、一連の測定を完了するのに要する時間として理解されるべきものである。

#### 用語
短期的な現象を表す4つの用語が一般的に用いられる。
これらは互換性がある。

1. 精度  
2. 繰り返し性  
3. 時間内変動  
4. 短期変動  

#### 精度は標準偏差により定量化
精度の尺度として標準偏差が用いられる。
精度が高いということは、標準偏差が小さいことを意味する。
この標準偏差は、工程の短期標準偏差、あるいは併行精度標準偏差と呼ばれる。

#### 注意――長期変動が支配的である可能性
非常に高精度な計測機器では、測定工程が示す日次変動が測定工程で制御や補正ができない環境条件や取扱技術の小さな変化により、機器の精度を上回ることは珍しくない。
この変動要因が定量化されるまでは、測定工程の特性が完全に把握されたとは言えない。

#### 用語
長期的な現象を表す3つの用語が一般的に用いられる。
これらは互換性がある。

1. 日々の変動  
2. 長期変動  
3. 再現性  

#### 注意――「再現性」という用語について
「再現性」という用語は、一部の国内および国際規格において非常に具体的な定義が定められている。
しかし、それらの定義は必ずしも一致しているわけではない。
したがって、ここでは、日ごとの変動を示すための一般的な意味で使っている。

#### 本ハンドブックにおける用語の定義
本稿では、正確な定義を採用し、以下の推定を行うために、[検査基準](mpc12.md)および[測定管理](../section2/mpc2.md)の節において、データ収集および分析手法を提示している。

* [水準1 標準偏差：短期変動](mpc123.md)  
* [水準2 標準偏差：日次変動](mpc123.md)  

[ゲージ研究](../section4/mpc4.md)の節では、変動の概念を拡張し、極めて長期的な測定変動を含めている。

* [水準1 標準偏差](../section4/mpc441.md)：短期変動
* [水準2 標準偏差](../section4/mpc442.md)：日次変動
* [水準3 標準偏差](../section4/mpc443.md)：超長期変動

これら3種類の不確かさに関連する標準偏差を、それぞれ「レベル1、2、3の標準偏差」と呼ぶ。 

#### 長期変動は標準偏差で定量化
長期変動の尺度は、数日、数週間、あるいは数ヶ月に渡って行われた測定値の標準偏差で表す。

この評価を行う最も簡単な方法は、[校正標準](mpc12.md)のデータベースを分析することである。
校正標準の測定データは、長い時間間隔を網羅し、測定工程におけるすべての変動要因を捉えるように構成されている。
