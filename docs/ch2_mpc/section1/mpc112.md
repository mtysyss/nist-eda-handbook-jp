# 2.1.1.2. 参照基準

#### 究極の権威
あらゆる測定工程において最も重要な要素は、個々の測定値と測定単位の参照基準との関係である。
この参照基準こそが、測定単位の究極の権威の源泉である。

#### 基本単位について
基本単位（長さ、質量、温度、電圧、時間）および一部の組立単位（圧力、力、流量など）の参照基準は、各国および各地域の標準研究所によって維持管理されている。
機関間の比較試験による合意値や、特定環境下で維持管理されている計測器・標準器は、他の測定単位の参照基準として用いられる。

#### 比較目的のために
比較が目的のための参照基準は、参加試験所もしくは機関間の合意に基づき、以下の値に繋がる。

* 標準試験法を用いて行われた測定値
* 機関間比較試験から導かれた測定値
