# 2.1.2. 検査標準とは

#### 工程のデータ収集に役立つ検査標準
検査標準法は、時間の経過とともに工程で生じる誤差を明らかにするための測定工程のデータを収集するツールである。
検査標準の測定データベースから、時間依存の誤差要因を評価し定量化する。
これは、検査標準の過去データからこれらの数量の基準値が確立された後、工程の偏りや長期変動を管理するための手段である。

#### データの観点で考える；人工物もしくは定義された量である検査標準
検査標準は、測定値のデータベースとして捉えるべきである。
これは、その値が工程の全期間に渡って取得された測定値から再現可能な、人工物または測定工程の特徴として定義することができる。
例としては、以下が挙げられる。

* 安定した人工物に対する測定値
* 校正実験から推定された2つの参照標準値間の差
* 基準標準および／または試験対象物の測定から推定される偏り項などの工程特性の値

人工物の検査標準は、作業負荷の測定対象である試験対象物と、材質および形状が近い必要がある。
可能であれば、作業負荷に含まれる試験対象物の一つであるべきである。
当然ながら、それは安定した人工物であり、測定工程において常に利用可能でなければならない。 

#### 工程の標本抽出における課題の解決
測定工程は、生産工程と同様に、継続的であり、時間、測定機器、作業者、および環境条件が異なっても、（許容範囲内で）同一の結果が得られることが期待される。
しかし、通常、測定対象は測定順ごとに変化するため、測定工程の出力を抽出することは難しい。

#### 未観測測定値の代用
一定間隔で行われる検査標準の測定は、十分な時間と資源が確保できれば試験対象に対して行われるはずの測定の代用として機能する。
