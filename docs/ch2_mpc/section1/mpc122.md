# 2.1.2.2. データ収集

#### 測定実施のスケジュール
検査標準測定を定期的に実施するスケジュール（1日1回、週2回、あるいは標本抽出測定条件すべてを網羅するのに適切な頻度）を策定し、遵守すべきである。
検査標準測定は、試験対象について報告される値と同様の方法で構成されるべきである。
例えば、報告される値が5分以内に実施された2回の反復測定の平均値である場合、検査標準値も同様に、同じ方法で行われた2回の測定の平均値とするべきである。

#### 例外
この規則には1つの例外があり、1日あたり少なくとも $`J = 2`$ 回の測定を繰り返す必要がある。
この冗長性がなければ、測定システムの短期的な精度を確認する手段がない。

#### 事例研究：シリコン・ウェハ測定の[比抵抗検査標準](../section6/mpc62.md)
検査標準の値は、関連する環境測定値と他の重要な要因すべての識別情報とは、ともに記録する必要がある。
この情報を記録する最良の方法は、検査標準の測定ごとに、固定フィールドに情報を1行（スプレッドシートの場合は1行）ずつ記載したひとつのファイルにまとめることである。
以下に、典型的な記入例を示す。

1. 検査標準の識別情報  
2. 日付  
3. 測定設計の識別情報（該当する場合）  
4. 測定機器の識別情報  
5. 検査標準の値  
6. *J* 回の反復による短期標準偏差  
7. 自由度  
8. 作業者識別  
9. 環境測定値（該当する場合）
