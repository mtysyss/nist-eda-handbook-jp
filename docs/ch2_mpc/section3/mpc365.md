# 2.3.6.5. データ分析とモデルの妥当性確認

#### 最初の手順 - 校正データのプロット
理論的検討や経験から検量線のモデルが判明しない場合は、検量線のモデルを特定し、その妥当性を確認する必要がある。
この工程を始めるには、校正データを参照標準の既知値の関数としてプロットする。
データを描画するこの[プロットはモデルの候補を示唆する](../..//pmd/section4/pmd421.md)。
線形モデルは常に検討すべきである。
応答値とその既知値が同じ単位である場合、データの構造を明らかにするために応答値と既知値の差をプロットする方が、データそのものをプロットするよりも有益である。

#### 警告 - 統計ソフトウェアについて
初期モデルを選定したら、統計ソフトウェア・パッケージを用いて、データからモデルの係数を推定する。
この分析に、信頼性が高く、十分な実績のあるソフトウェアを使用する重要性をいくら強調してもし過ぎることはない。

#### ソフトウェア・パッケージに求められる出力
ソフトウェア・パッケージは、係数の推定に[最小二乗法](../../ch4_pmd/section4/pmd431.md)を用いる。
また、ソフトウェア・パッケージが校正範囲内で[測定誤差が一定でない](../../ch4_pmd/section2/pmd213.md)場合にも、「重み付け」された近似を実行できる必要がある。
[重みの選択](../../ch4_pmd/section4/pmd454.md)は、通常、利用者の責任である。
ソフトウェア・パッケージは、少なくとも以下の情報を提供しなければならない。

* 校正曲線の係数  
* 係数の標準偏差  
* 適合の残差標準偏差  
* [適合度のF比](mpc365.md#データへの適合度を検定するために用いる-F比)（各参照値において *y* 軸上に反復測定がある場合）  

#### 二次近似の一般的な解析
[ロードセルの測定値](mpc3651.md)は、以下に示すように、既知の荷重に対する2次関数としてモデル化される。
各荷重水準で 3回ずつ測定を行い、合計 33回の測定が行われた。

```
モデル y = a + b*x + c*x*x + e の係数推定:

係数      　　推定     標準誤差        t-値  Pr(>|t|)    
a     -1.840e-05   2.451e-05      -0.751     0.459    
b      1.001e-01   4.839e-06   20687.891    <2e-16 
c      7.032e-06   2.014e-07      34.922    <2e-16 

残渣標準誤差 = 3.764e-05 (30 自由度)
決定係数 = 1
自由度調整済み決定係数 = 1 


分散分析表:
分散の要素     自由度   　 　平方話      平均平方　 　　　 F-比        Pr(>F)

モデル          2         12.695       6.3475       4.48e+09    <2.2e-16
残差           30       4.2504e-08    1.4170e-09

(適合不足)       8       4.7700e-09    5.9625e-10    0.3477       0.9368
(純粋誤差)      22       3.7733e-08    1.7151e-09

合計           32         12.695
```

上記の解析は、[Dataplotコード](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc365.dp)および[Rコード](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc365.r)を使用して再現可能である。
読者はデータを[テキストファイルとして](https://www.itl.nist.gov/div898/handbook/datasets/LOADCELL.DAT)ダウンロードできる。 

注：Dataplot は F比に関する確率を出力し（例えば、不適合度検定では6.334％）、95％を超える確率は、5％水準で有意な F比であることを示す。
R は、F値よりも高い確率に対応する *p* 値を報告し、0.05未満の値は 5％水準での有意性を示す。
他のソフトウェアでは異なる方法で報告されることがあり、各パッケージごとの解釈を確認する必要がある。

#### データへの適合度を検定するために用いる *F*比 
F比は、モデルがデータを適切に記述しているかの情報を提供する。
F比は[F表](../../eda/section3/eda3673.md)の境界値と比較する。
F比が境界値より小さい場合、重要な構造のすべてがモデルによって捕捉されていることを示す。

#### 常に良好な適合を示す *F*-比 < 1
ロードセル解析において、[データのプロット](mpc36.md#plot)からは線形近似が示唆される。
しかし、線形近似では非常に大きなF比が得られる。
二次近似の場合、F比は 0.3477 で、自由度は $`v_1=8`$、$`v_2=22`$ である。 
境界値 $`F(0.05, 8, 20)=2.45`$ は、データを記述するには二次関数で十分であることを示している。
留意すべき点として、*F*-比 < 1 の場合は境界値との比較を行う必要がなく、常にデータへの適合が良好であることを示す。

#### 個々の係数の有意性を検定するために用いる *t*-値
*t*-値は[$`t`$-表](../../eda/section3/eda3672.md)の境界値と比較する。
ただし、5% 有意水準での検定では、*t*値 < 2 であれば、有意差がないことを示す良い指標である。 
切片項 *a* の *t*-値は < 2 であり、切片項が 0 と有意に異なるわけではないことを示している。
一次項および二次項の *t*-値は有意であり、これらの係数がモデルに必要であることを示している。
モデルから切片項を除外した場合、分析を繰り返し、係数 *b* および *c* の新しい推定値を求める。

#### 残差標準偏差
残留標準偏差は、ロードセルでの単一測定値の標準偏差を推定するものである。

#### さらなる検討と仮定の検定
また、近似から得られる残差（測定値と推定値の差）についても、[外れ値](../../ch4_pmd/section2/pmd213.md)と、検量線の有効性を損なう可能性のある[構造](../../ch4_pmd/section4/pmd441.md)がないかを確認する必要がある。
これらは、すべての測定値について正規性および同一精度という[基本的な仮定](../../ch4_pmd/section2/pmd21.md)が成立しているかの良い指標でもある。
 
初期モデルがデータに対して不適切であることが判明したときは、[モデルを改善するための戦略](../../ch4_pmd/section4/pmd45.md)を行う。
