# 2.3.4. 校正設計目録

#### 重要な概念 - 拘束
これらの設計は、参照標準と試験対象間の差を単独もしくは組み合わせて測定するために構築されている。
個々の標準および試験対象の値は、1つ以上の参照標準の値（ $`拘束値＝R\**`$ と呼ばれる）が既知である場合にのみ、設計から計算することができる。
校正設計の構築および解法に関する方法論は、[解行列](mpc3321.md)に簡潔に、またNISTの刊行物に詳細に記載されている。
（[Cameron et al.](../section7/mpc7.md#Cameronetal)）。

#### 本目録に掲載されている設計
設計は従来からの分野別に分類されているが、その多くは一般的に、人工物標準の相互比較に適している。

* [質量分銅設計](mpc341.md)  
* [ブロックゲージの偏位除去設計](mpc342.md)  
* [電気標準左右バランス設計](mpc343.md)  
* [真円度標準設計](mpc344.md)  
* [角度ブロック設計](mpc345.md)  
* [水浴での温度計偏位除去設計](mpc346.md)  
* [湿度缶偏位除去設計](mpc347.md)  

#### 本目録に掲載されている設計の特性
基本的な要求事項は以下の通り。

1. 差分は名目上ゼロでなければならない。  
2. 拘束が与えられた個々の項目に対して設計が解けるものでなければならない。  

その他の望ましい特性は以下の通り。

1. 測定回数は少ないこと。  
2. 自由度はゼロより大きいこと。  
3. 試験対象の推定値の標準偏差は、その目的に見合った十分に小さいものであるべきである。   

#### 情報：設計：解：標準偏差計算の因子
以下の条件のもと

* $`n = \text{差異測定の数}`$  
* $`m = \text{人工物の数（参照標準＋試験対象）}`$ を校正 

各設計について、以下の情報を示す。

* 設計行列 -- $`(n×m)`$  
* 拘束の標準を特定するベクトル -- $`(1xm)`$  
* 自由度 = $`(n-m+1)`$  
* 所定の拘束に対する解行列 -- $`(n×m)`$  
* 標準偏差計算用因子表 

#### 測定手順を示すための規約
標準および試験対象の公称サイズは、測定計画の上部に示されている。
「＋」は、同時に測定される項目を示し、「－」は、同時に測定しない項目を示す。
差分測定値は、これらの「＋」と「－」の組合せによって構成される。
例えば、同じ公称サイズを持つ1つの参照標準と2つの試験対象について、3回の測定を行う「1,1,1」の測定計画は、以下の通り。

```
                 1     1     1
          Y(1) = +     -
          Y(2) = +           -
          Y(3) = +     -
```

#### 解の行列：例と解釈
差分測定値の列と*R\**の列と解行列の列との外積を指定された除数で割り、個々の値を得る。
例えば、

```
                    解行列
                   除数 = 3 
                  
                 1       1      1                 
          Y(1)   0      -2     -1
          Y(2)   0      -1     -2
          Y(3)   0      +1     -1
          R*    +3      +3     +3
```

は、拘束および2つの試験対象の推定値が以下であることを示している。

$$\begin{array}{cl} 
\widehat{R^\*} &= \frac{1}{3} \left\\{ 0 Y_1 + 0 Y_2 + 0 Y_3 + 3 R^\* \right\\} = R^\* \\
\widehat{Test}_1 &= \frac{1}{3} \left\\{ -2 Y_1 - Y_2 + Y_3 + 3 R^\* \right\\} \\
\widehat{Test}_2 &= \frac{1}{3} \left\\{ -Y_1 - 2 Y_2 - Y_3 + 3 R^\* \right\\}
\end{array} 

#### 因子表の解釈
この表の係数は、精度に関する情報を提供している。
繰り返し性標準偏差、$` {\large s}_1 `$ に適切な係数を掛け、個々の項目または項目の組合せの標準偏差を求める。
例えば、

```
        Sum    係数        1      1      1             
        1      0.0000     +           
        1      0.8166            +       
        1      0.8166                   +   
        2      1.4142            +      +
```

は、推定値の標準偏差が以下であることを示している。

$$\begin{array}
{\large s}_{R^\*} = 0 \\{\large s}_{{test}_{ \, 1}} = 0.8661 \cdot {\large s}_1 \\
{\large s}_{{test}_{ \, 2}} = 0.8661 \cdot {\large s}_1 \\
{\large s}_{{test}_{\, 1+2}} = 1.4142 \cdot {\large s}_1
\end{array}
