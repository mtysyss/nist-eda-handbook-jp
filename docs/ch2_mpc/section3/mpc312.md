# 2.3.1.2. 参照標準

#### 一次参照標準
測定単位の参照標準は、その値を参照基準に紐づける方法で、対象である量を具現化した人工物である。

最上位階層において、一次参照標準に参照基準との直接比較によって値が割り当てられる。
質量は、人工物によって定義される唯一の測定単位である。
キログラムは、フランス・セーヴルにある国際度量衡局によって保管されている白金イリジウム製のキログラム原器の質量として定義されている。

他の単位の一次参照標準は、人工物標準に具現化された単位の実現化に由来する。
例えば、長さの参照基準はメートルであり、1秒の299,792,458分の1の時間間隔における真空中の光の進路の長さとして定義されている。 

#### 二次参照標準
二次参照標準は、高精度の比較器を用いて一次標準と比較し、測定時の理想条件からのズレの補正を行い校正される。

質量の二次参照標準はステンレス製のキログラム分銅で、高精度天秤を用いて一次標準と比較し、空気の浮力を補正し校正される。
そして、これらの分銅は、試験用分銅に値を割り当てるための基準となる。

長さの二次参照標準はブロックゲージで、機械式比較器を用いて一次ブロックゲージ標準と比較し、温度の補正を行い校正される。
そして、これらのブロックゲージは、試験用ブロックゲージセットに値を割り当てるための基準となる。
