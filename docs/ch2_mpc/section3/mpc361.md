# 2.3.6.1. 計測器校正のモデル

#### 表記法
本章では、校正曲線のモデルについて述べる際に、以下の記号を用いる。

* $`Y`$ は、参照標準の測定値を表す  
* $`X`$は、参照標準の既知の値を表す  
* $`\epsilon`$は測定誤差を表す  
* $`a`$、$`b`$、$`c`$ は決定すべき係数を表す  

#### 検量線が取り得る形状
計測器の校正において検討される校正曲線のモデルはいくつかある。
それらは以下の区分に分類される。

* 線形： 

$$Y = a + bX + \epsilon$$

* 2次：    

$$Y = a + bX + cX^2 + \epsilon$$  

* 冪乗：  

$$Y = aX^b\epsilon$$  

* 非線形：        

$$Y = g(X) + \epsilon$$  

#### 線形モデルの特殊な事例 - 校正不要
以下の条件を満たす場合、計測器は校正を必要としない。

$$a = 0 \mbox{ かつ } b = 1$$  

すなわち、測定誤差の許容範囲内で、参照標準の測定値が既知の値と一致する場合、その計測器はすでに校正済みである。
[データの収集](mpc362.md)、[係数の推定および検定](mpc365.md)に関する指針は、他のページに記載している。

#### 線形モデルの利点
線形モデル [ISO 11095](../section7/mpc7.md#ISO11095) は、より複雑なモデルに比べていくつかの利点があるため、機器の校正に広く用いられている。

* 係数および標準偏差の計算が容易である。  
* 偏りの補正が容易である。  
* モデルに多くの場合、理論的根拠がある。  
* 不確かさの解析が容易である。

#### モデルから切片項を除外することに関する警告
*x* 軸上の応答がゼロであれば、*y* 軸上の応答もゼロになるはずであるため、モデルから切片 $`a`$ を除外したくなることはよくある。
しかし、正しい手順は、完全なモデルを推定し、切片項の有意性を検定することである。

#### 2次モデルと高次多項式
線形化できず、かつ、理論的なモデルが存在しない計測器や計測システムの応答は、場合によっては二次モデル（もしくは高次多項式）で記述できることがある。
その一例として、セルに加えられる力は荷重の非線形関数であるロードセルが挙げられる。

#### 二次モデルの欠点
2次および高次多項式の欠点は以下の通り。

* 曲率の領域を捉えるために、より多くの参照標準が必要になる場合がある。
* 理論的な正当化はほとんど存在しないが、モデルの妥当性は統計的に検定可能である。
* 偏りの補正は、線形モデルの場合よりも複雑である。
* 不確かさの解析が困難である。

#### 警告
データのプロットは常に推奨されるが、それだけでは検量線の適切なモデルを特定するには不十分である。
計測器の応答は、広い範囲では非線形に見えない場合がある。
応答値と既知値が同じ単位である場合は、既知値との差分を既知値に対してプロットする必要がある。

#### 線形モデルとして扱う冪乗モデル
冪乗モデルは、測定誤差が加法的ではなく、応答に比例する場合に適している。
これは、放射性物質の線量水準を測定する計測器の校正によく用いられる。

冪乗モデルは、自然対数変換によって線形化することができる非線形モデルの特殊な事例で次式とすることができ
 
$$Y = \log_e(a) + b \log_e(X) + \log_e(\epsilon)$$
 
これによりデータに適合させるモデルはよく知られた線形形式
 
$$W = a' + bZ + e$$
 
となる。
ここで、$`W`$、$`Z`$、および $`e`$ は、それぞれ変数 $`Y`$、$`X`$、および測定誤差の変換値であり、$`a'`$ は $`a`$ の自然対数である。

#### 非線形モデルと制限
係数に対して応答が線形でない計測器は、非線形モデルによって記述できる場合がある。
モデルに理論的根拠がある場合もあれば、試行錯誤によってモデルが構築される場合もある。
校正関数として実用的な価値があることが示されている非線形関数には以下の2つの種類がある。

1. 指数関数  
2. 有理関数  

非線形モデルは校正モデルの重要な分類であるが、いくつかの大きな制限がある。

* モデルそのものの特定や検証が困難な場合がある。
* 係数の推定において、深刻な計算上の困難が生じる可能性がある。
* 偏りの補正は代数的に適用できず、補間によって近似するしかない。
* 不確かさの解析は非常に困難である。 

#### 指数関数の例
以下の式は指数関数を表している。
この関数は、流体に浸漬された、さまざまな水準の欠陥（穴）を持つ参照標準の超音波応答を測定する計測器を記述している。

$$Y = \frac{e^{-aX}}{b + cX} + \epsilon$$

#### 有理関数の例
[有理関数](../../ch4_pmd/section8/pmd812.md)は以下の式で表される。
半導体上の線幅に関する走査型電子顕微鏡による測定結果は、この関数によって記述される[（Kirby）](../../mpc/section7/mpc7.md#Kirby)。

$$Y = \frac{a + bX + cX^2}{a_1 + b_1X + c_1X^2} + \epsilon$$
