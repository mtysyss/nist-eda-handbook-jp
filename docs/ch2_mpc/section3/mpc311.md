# 2.3.1.1. 参照基準

#### 究極の権威
あらゆる測定工程において最も重要な要素は、個々の測定値と測定単位の参照基準との関係である。
この参照基準こそが、測定単位の究極の権威の源泉である。

#### 基本単位と組立単位
国際単位系（SI）の基本単位は（[Taylor](../section7/mpc7.md#Taylor)）以下である。

* キログラム - 質量
* メートル - 長さ
* 秒 - 時間
* アンペア - 電流
* ケルビン - 熱力学的温度
* モル - 物質量
* カンデラ - 光度 

これらの単位は、パリにある国際度量衡局によって管理されている。
これらの単位および次のようなSI組立単位の地域の参照基準は、

* パスカル - 圧力
* ニュートン - 力
* ヘルツ - 周波数
* オーム - 抵抗
* 摂氏度 - 摂氏温度、など

は、各国および各地域の標準機関によって維持されている。 

#### 他の情報源
特定環境下で維持されている機関間比較試験や計測機器・標準による合意値は、他の測定単位の基準である。
