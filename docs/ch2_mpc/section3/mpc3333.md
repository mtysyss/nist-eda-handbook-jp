# 2.3.3.3.3. 繰り返し性と段階2の標準偏差の合成

#### いくつかの要因に依存する試験対象の標準偏差
最後の問題は、試験対象の標準偏差を推定するための、繰り返し性標準偏差と検査標準の標準偏差の合成方法である。
この計算は、以下の要素に依存する。

* 設計の構成  
* 設計における検査標準の取扱い  
* 設計における参照標準の取扱い  
* 設計における試験対象の取扱い  

#### 行列代数が必要な導出
[目録](mpc34.md)には、すべての試験対象の標準偏差を推定するための表が、すべての設計の解とともに掲載されている。
試験対象の標準偏差を推定するための[表の使用](mpc3334.md)方法は、1,1,1,1 設計を例に説明している。
目録に掲載されていない設計については、[行列方程式](mpc3321.md#stddev)を用いて推定値を導出する。

各設計における検査標準は、校正のために使用される試験対象以外の設計に含まれる追加の試験対象であるか、設計によって推定される2つの参照標準間の差といった構成値である。
