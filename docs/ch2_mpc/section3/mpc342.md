# 2.3.4.2. ブロックゲージの偏位除去設計

#### 定義された長さ単位への紐づけ
多くの産業において、長さの単位はブロックゲージによって維持され配布されている。
ブロックゲージの最高精度の校正は、長さの単位をブロックゲージに移することを可能にする、光波干渉法によって行われている。
一次標準機関では、この方法で校正された英尺法およびメートル法のブロックゲージの基準ブロック一式を管理している。
米国における産業工程を支えるためには、0.1インチから20インチまでのサイズのブロックゲージが必要とされる。

#### ブロックゲージの機械的比較
しかし、ブロックゲージの大半は、同じ公称長を持つ2つのブロック間のわずかな差を測定するために特別に設計された機械式比較器を用いて、基準ゲージと比較することで校正される。
測定値は、ブロックの表面で直接読み取った値から温度補正される。
2～20インチのブロックでの測定には、熱の影響を最小限に抑えるための特別な取り扱い技術が必要である。
一般的な校正では、81個のブロックゲージ一式を使用し、それらを同じ公称サイズの標準ゲージと1つずつ比較する。

#### ブロックゲージの校正設計
校正設計により、作業の効率化を図り、標準ゲージの摩耗を最小限に抑える方法で、同じ公称サイズの複数のブロックゲージを1つの標準ゲージと比較することが可能となる。
この校正設計は、試験一式に含まれるすべてのブロックの測定が完了するまで、各サイズごとに繰り返す。

#### 熱偏位の問題
ブロックゲージを用いた測定では、比較器内の温度上昇による偏位が生じる可能性がある。
この偏位は校正実験において適切に考慮されなければならない。
そうしなければ、ブロックに割り当てられた長さが偏位項の影響を受けて正確でなくなる。

#### 直線偏位の除去
本目録に掲載されている設計は、測定値が時間軸上で等間隔に設定されているならば、解が線形偏位の影響を受けないよう構成されている。
偏位の大きさは、*n* 回の差分測定値の平均値である。
通常の値の範囲から著しい変化が見られる場合は、測定システムに問題があることを示している可能性があるため、設計ごとに偏位を把握しておくことは有用である。

#### Doiron 設計における仮定
ブロックゲージに対する機械的測定は、1つのブロックを比較器に挿入し、続いて2つ目のブロックを挿入するというように、順次行う。
この状況では、個々の測定値には偏位が生じると想定される（[Doiron](../section7/mpc7.md#Doiron)）。
Doiron は、この基準を満たす設計として、以下を挙げている。

* 2つの基準ブロック $`R_1`$ および $`R_2`$  
* 1つの検査標準 = $`R_1`$ と $`R_2`$ の差  
* 1～9個の試験ブロック  

#### 1基準ブロックを用いる偏位除去設計の特性
これらの設計は、以下の目的で構築されている。

* 線形偏位の影響を受けない  
* 試験ブロックの標準偏差を最小限に抑える（可能な限り最小限に）  
* 各ブロックにおける測定値を設計全体に分散させる  
* 5～10分で完了し、偏位を5 nm 水準に抑える

#### 注意
相互比較されるブロックゲージの数が非常に多く、偏位を除去する必要があるため、Doiron の設計では、試験ブロックに対して完全に平衡が取られているわけではない。
そのため、すべてのブロックで標準偏差が等しいくはない。
もしすべてのブロックが同一施設での使用を目的として校正されるのであれば、ブロックごとに個別の記録を維持しようとするよりも、すべてのブロックの中で最も大きい標準偏差を提示する方が最も簡便である。

#### 基準ブロックの定義および検査標準
米国国立標準技術研究所（NIST）では、この設計における最初の2つのブロックは、それぞれ $`R_1`$ および $`R_2`$ に指定されたNIST 基準ブロックである。
$`R_1`$ ブロックは鋼製ブロックであり、$`R_2`$ ブロックはクロムカーバイド製ブロックである。
試験ブロックが鋼製の場合、基準は $`R_1`$ となり、試験ブロックがクロムカーバイド製の場合、基準は $`R_2`$ となる。
検査標準は常に、設計から推定される $`R_1`$ と $`R_2`$ の差であり、$`R_1`$ および $`R_2`$ とは独立している。

#### 2基準ブロックを用いる設計の特性
ブロックゲージの従来の設計（[Cameron and Hailes](../section7/mpc7.md#CameronHailes)）は、差分測定値が直線偏位の影響を受けているという仮定に基づく。
この仮定はより制約が厳しく、連続した測定における偏位がある場合を網羅するが、設計の数は少なくなる。
この基準を満たす Cameron/Hailes 設計では、以下のことが可能である。

* 2つの参照（基準）ブロック、$`R_1`$ および $`R_2`$  
* 検査標準 = 2つの基準ブロックの差  

すべての試験ブロックの値に等しい不確かさを割り当てる。

#### 重要な概念 - 検査標準
本節の設計における[検査標準](../section1/mpc12.md)は、人工物基準ではなく、設計に基づいて構築されたものである。
1つの基準ブロックの値、もしくは、2つの基準ブロックの平均値が設計の拘束となり、基準 $`R_1`$ および $`R_2`$ の値は、設計に従って実施された一連の測定結果から推定される。
検査標準値は、推定値 $`R_1`$ と $`R_2`$ の差である。
[測定管理](mpc35.md)は、検査標準の現在値と過去の平均値を比較することで行われる。
