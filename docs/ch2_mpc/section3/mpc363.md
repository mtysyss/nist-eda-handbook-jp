# 2.3.6.3. 計測器校正の仮定

#### 参照準値に関する仮定
校正実験において測定される人工物の参照値に関して、それらが誤差なく既知であるという基本的仮定が置かれる。
しかし実際には、通常、測定工程からそれらの値自体が得られているため、この条件が満たされることはほとんどない。
参照値に含まれる系統誤差は常に結果に偏りを生じさせ、[参照値に含まれる偶然誤差](../../pmd/section2/pmd216.md)もまた、結果に偏りを生じさせる可能性がある。

#### 経験則
Bruce Hoadly はNISTの内部刊行物において、参照値における無作為な変動の影響を軽減する最善の方法は、計測器の精度に対して、*x* 軸上の値の分布を広く設定することであると示している。

#### 測定誤差に関する仮定
この計測器に伴う測定誤差に関する[基本的仮定](../../pmd/section2/pmd21.md)は、以下の通り。
すなわち、

* [外れ値がない](../../pmd/section4/pmd442.md)  
* [独立している](../../pmd/section4/pmd443.md)  
* [等精度](../../pmd/section4/pmd444.md)  
* [正規分布に従う](../../pmd/section4/pmd445.md)
