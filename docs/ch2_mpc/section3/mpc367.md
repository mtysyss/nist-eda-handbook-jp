# 2.3.6.7. 校正値の不確かさ

#### 目的
その目的は、検量線によって補正された「将来」の結果の不確かさを定量化することである。
原則として、この不確かさは、補正値とその参照基準（通常は参照標準に依存する）との間に生じうるあらゆる差異を定量化する。

#### 参照人工物を用いた説明
対象である測定値は未知の人工物に関する将来測定値であるが、この問題を捉える一つの方法は、次のように問うことである。
もし、参照標準の一つに対して測定を行い、その測定値に県稜線を適用して補正値を求めた場合、その値は参照標準の「既知」値とどの程度一致するか。

#### 問題点
以下の関連する2点の不確かさが重なるため、答えは簡単ではない。

1. データが限られていることによる検量線自体  
2. 「将来の」測定値  

校正実験を繰り返し行ったとき、統計的管理されたシステムであっても、わずかに異なる検量線が得られる。
環状力計の校正に関する、これら2つの不確かさの交差に関する解説が（[Hockersmith and Ku](../section7/mpc7.md#HockersmithKu)）によってなされている。 

#### [検査標準](../section1/mpc12.md)もしくは[誤差の伝播](../section5/mpc55.md)に基づく不確かさのISO手法
