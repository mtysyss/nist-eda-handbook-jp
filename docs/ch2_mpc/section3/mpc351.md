# 2.3.5.1. 精度の管理

#### 過去データに基づく管理係数
計測器の精度管理には、改良された管理図の手順が用いられる。
この手順は、対象となる計測器の基準線および管理限界が、短期標準偏差のデータベースから設定された後、即時に実施されるように設計されている。
計測器ごとに個別の管理図が必要であるが、種類が同じで基本精度が同じ計測器では、それらを1つとして扱うことができる。

基準線は、データベース内の $`k = 1, \ldots,K `$ 個の個別の繰り返し性標準偏差 $`{\large s}_k`$ から繰り入れられた工程標準偏差であり、各繰り返し性標準偏差は $`\nu_k`$ 自由度を持つ。
繰入れ繰り返し性標準偏差は、

$${\large s}_1 = \sqrt{ \frac{1}{\nu} \sum_{k=1}^K \nu_k {\large s}_k^2 }$$

であり、自由度は次式である。

$$\nu = \sum_{k=1}^K \nu_k \quad.$$ 

#### 各校正実行ごとに即時実行する管理手順
管理手順では、記録された計測器の各新しい繰り返し性標準偏差を管理上限 *UCL* と比較する。
主な関心は計測器の精度の劣化を検出することであるため、通常、関心事は管理上限のみである。
問題となり得るのは、管理限界が新しい標準偏差の自由度に依存していることであり、次式で計算される。

$$UCL = s_1 \sqrt{F_{\alpha, \nu_{new}, \nu}}$$

根号内の量は、[*F* 表](../../eda/section3/eda3673.md)における *α* 百分位値であり、ここで *α* は、例えば 0.05 のように小さく設定される。
他の2つの項は、新しい標準偏差の自由度と、工程標準偏差の自由度を指す。

#### 図解法の限界
繰り返し性の新しい推定値をすべて管理図に作図するというグラフによる方法は、自由度に依存して各校正設計ごとに *UCL* が変化する場合、うまく機能しない。
これと代数的に同等の方法は、新しい標準偏差が管理限界を超えているかどうかを検定することである。
この場合、短期精度は管理外れであると判断され、現在の校正実行は不適合とされる。
詳細については、[管理外れ信号への対処と戦略](../section2/mpc234.md)を参照のこと。

繰り返し性の標準偏差が管理下にある限り、その計測器の精度が低下していないと確信する根拠となる。 

#### [事例研究：物質収支の精度](mpc3511.md)  
計測器が徐々に劣化していないかを確認するために繰り返し性標準偏差を時間軸に対して定期的にグラフ化することが推奨される。
個別の測定結果の異常だけでは、計測器の調整やチューニングが必要であるとは気づかない場合がある。
