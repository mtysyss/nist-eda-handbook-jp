# 2.3.6.4. 校正手順の潜在的問題

#### 校正手順で除去できないは偏り
校正曲線が意図したとおりに偏りを低減または除去できない状況がいくつかある。
その一部については、このページで説明している。
校正データに対して綿密な探索的解析を行うことで、こうした問題を明らかにできるはずである。

#### 正確さの欠如
計測器の精度が不十分もしくは予期せぬ日間効果に因り標準偏差が大きくなり過ぎ、校正の信頼性を損なう恐れがある。
校正手順そのものに精度を向上させる要素は存在せず、特定の計測器を採用する前に取るべき最善の策は、対象となる環境下でその計測器の精度を推定し、要求される精度水準を満たしているかを判断することである。

#### 校正データにおける外れ値
[校正データの外れ値](../../pmd/section4/pmd442.md)は、特に校正範囲の端点付近にある場合、校正曲線を著しく歪める可能性がある。

* 孤立した外れ値（単一のデータ点）は、校正データから削除するべきである。
* 他のデータと整合しない1日分の結果は、分析を進める前にその内容を精査し、修正すべきである。

#### 作業者間の系統的差異
作業者によって、符号や大きさが異なる偏りを伴う測定結果が得られる可能性がある。
これは通常、自動測定装置では問題にならないが、目視に依存する測定装置の場合、作業者によって結果が大きく異なることがある。
この問題を特定するために、異なる作業者による同一人工物の測定値を作図し、比較する。
作業者間のわずかな差異は測定工程の不確かさの一部として受け入れ可能であるが、作業者間での大きな系統的差異は解決が必要である。
考えられる解決策としては、作業者の再教育や作業者ごとに個別の校正曲線を維持することが挙げられる。

#### システム制御の欠如
校正手順は、一度確立されると、計測器が長期にわたり同じように応答し続けることを前提としている。
システムに偏位が生じたり、予測不能な逸脱が見られたりすると、校正値の偏りが適切に補正されない可能性があり、変化の方向によっては、校正によって測定精度がさらに低下する恐れがある。
将来の測定において偏りが適切に補正されることを保証するために、校正手順に[計測器の統計的管理手順](../../mpc/section3/mpc37.md)を組み合わせるべきである。

#### [校正データにおける反復測定間差異](mpc3641.md)の例
重要な点でありながらほとんど考慮されないのが、解析結果を無効にしてしまう、測定の反復ごとの応答の差異の可能性である。
[校正データの集計値のプロット](../../mpc/section3/mpc3641.md#plot1)をしただけでは、計測器応答の日間変化を特定できない場合がある。
必要なことは、校正データに含まれる日間差異を明らかにする、[データの微細な構造のプロット](../../mpc/section3/mpc3641.md#plot2)である。

#### 警告：日間の変化による校正の失敗
集計データに直線を当てはめると、「校正曲線」が得られる。
しかし、[各日の測定値に個別に直線を当てはめ](mpc3641.md#plot3)、応答に著しいばらつきが見られる場合、その計測器は、良くて毎日校正が必要であり、最悪の場合、管理が不十分で使用に耐えない可能性がある。
