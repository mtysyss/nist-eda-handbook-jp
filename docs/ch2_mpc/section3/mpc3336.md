# 2.3.3.3.6. 拡張不確かさ

#### 標準不確かさ
試験対象の[標準不確かさ](../section5/mpc52.md#standard)は、

$$ u = \sqrt{ {\large s}_{test}^2 + \left( \frac{公称試験値}{公称拘束値} \right)^2 \left( {\large s}_{R^\*} \right)^2 } \,\, .$$

#### 拡張不確かさ
[拡張不確かさ](../section5/mpc57.md)は、次式で計算する。

$$U = k u$$

ここで、*k* は自由度 *v* の[t 表](../section3/eda3672.md) の境界値、あるいは 2 に等しく設定される。

#### 自由度の問題
自由度 *v* の計算は、問題となることがある。
場合によっては、[Welch-Satterthwaite 近似](../section5/mpc571.md)と、試験対象の不確かさの構造を用いて計算する。
制約の標準偏差の自由度は、無限大であると仮定する。
この近似が信頼できるものとするためには、Welch-Satterthwaite の式における係数はすべて正でなければならない。

#### 1,1,1,1 設計における試験対象の標準偏差
[1,1,1,1 設計](mpc3334.md#equation)の場合、試験対象の標準偏差は、次式に代入し書き換える。

$${\large s}_{X_1} = {\large s}_{X_2} =\sqrt{\frac{3}{8}s_1^2 + \frac{3}{2} {\large s}_{days}^2 } =\sqrt{\frac{3}{8} {\large s}_1^2 + \frac{3}{2} \left\\{ \frac{1}{2} {\large s}_2^2 - \frac{1}{4} {\large s}_1^2 \right\\} } =\frac{\sqrt{3}}{2} {\large s}_2 $$

したがって、自由度は参照標準の標準偏差の自由度のみに依存する。
この手法は、すべての設計において満足のいく結果が得られるとは限らない。

#### 1,1,1,1 設計に基づく標準不確かさ
ページ最上部の式に示されている計算を実行するために、試験対象の公称値（1に等しい）を拘束の公称値（これも1に等しい）で割り、その結果を二乗する。
故に、標準不確かさは以下となる。

$$u = \sqrt{\frac{3}{4} s_2^2 + s_{R^\*}^2} \quad .$$

#### Welch-Satterthwaite 近似を用いた自由度
したがって、自由度は次式で近似される。

$$\nu = \frac{u^4}{\frac{1}{n-1} \left( \frac{9}{16} s_2^4 \right)} $$

ここで、$`n-1`$ は検査標準不確かさに関連する自由度である。
自由度が無限大となるため、拘束の標準偏差は計算から消去されることに注意されたい。
