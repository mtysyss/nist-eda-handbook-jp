# 2.3.6.6. 将来測定値の校正

#### 目的
検量線作成の目的は、同じ計測器を用いて行われる今後の測定値を正しい単位に補正することである。
計測器が[統計的管理](mpc37.md)下にある限り、検量線は廃棄または再作成されるまで、何度も繰り返し使用することができる。
ただし、化学測定の場合は例外であり、多くの場合、検量線は単一の測定バッチにのみ使用し、次のバッチでは新しい検量線を作成する。

#### 表記法
本節における表記は以下の通り。

* $`Y'`$ は将来の測定値を表す。
* $`X'`$ は対応する校正済み値を表す。
* $`\hat{a}, \hat{b}, \hat{c}`$ は、係数 $`a, b, c`$ の推定値である。
* $`{\large s}_a, {\large s}_b, {\large s}_c`$ は、係数 $`a, b, c`$ の標準偏差である。

#### 手順
将来測定値 $`Y^\*`$ に補正を適用し、校正値 $`X^\*`$ を求めるには、[校正曲線の逆](mpc36.md#plot)関数が必要である。

#### 線形校正線
[線形モデル](mpc361.md)

$$Y = a + bX + \epsilon$$

の校正直線の逆関数をとると、校正値は

$$X' = \frac{Y' - \hat{a}}{\hat{b}}$$

となる。

#### 検定曲線の切片および傾きの検定[^1]
― 両方の条件が満たされる場合、検定は不要 ―

上記の式を用いて校正直線の補正を行う前に、$` a=0 `$ および $` b=1 `$ の条件で、切片と傾きを検定すべきである。
もし両方が

$$\left|\frac{\hat{a}}{s_a}\right| < t_{1-\alpha/2, \nu} \quad \mbox{ かつ } \quad \left|\frac{\hat{b}-1}{s_b}\right| < t_{1-\alpha/2, \nu}$$

を満たす場合、校正の必要はない。
一方、もし $`a=0`$ に対する検定のみが <u>失敗</u> した場合、誤差は定数である。
もし $`b=1`$ に対する検定のみが <u>失敗</u> した場合、誤差は参照標準の規模に関連する。

#### *t*-係数の表検索
係数 $`t_{1-\alpha/2, \nu}`$ は、[*t*-表](mpc3652.md)から求め、$`\nu`$ は検定線からの残差標準偏差の自由度であり、$`\alpha`$ は、例えば 0.05 のように、小さい値に設定する。

#### 2次校正曲線
[二次モデル](mpc361.md)

$$ Y = a + bX + cX^2 + \epsilon $$

の検定線の逆関数には、根

$$X' = \frac{-\hat{b} \pm \sqrt{\hat{b}^2 - 4 \hat{c} \left( \hat{a} - Y'\right)}}{2 \widehat{c}}$$

が必要である。
正しい解（+ または -）は、通常、実用的な観点から特定する。

#### 出力特性曲線
[冪乗モデル]mpc361.md)

$$Y = aX^b\epsilon$$

の検量線の逆関数は、校正値

$$X' = \mbox{exp} \left( \frac{\mbox{log}_e(Y') - \mbox{log}_e(\hat{a})}{\hat{b}} \right)$$

であり、ここで、$`b`$ および $`a`$ の自然対数は、[線形関数に変換した冪乗モデル](mpc361.md#power)から推定する。

#### 非線形および他の検量線
より複雑なモデルの場合、検量線の逆関数は、関数のグラフもしくは関数の予測値から補間によって求める。
