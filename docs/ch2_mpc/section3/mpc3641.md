# 2.3.6.4.1. 校正における日間変化の例

#### 4日間の校正データ
10個のNIST参照標準について、4日間にわたり光学撮像システムを用いて線幅測定を行った。
各参照値に対するデータ点 4つは、精度に比べて参照値のばらつきが大きいため、プロット上では重なり合っているように見える。
このプロットから、画像システムの校正には線形の検量線が適切であることが示唆される。

#### 校正結果の解釈
この測定工程には制御手段がないため、校正データの平均値に基づいて構築された校正手順では、特定の日にはシステムを適切に補正できず、その結果得られる測定値が無効になってしまう。
この問題に対する有効な解決策は、毎日の校正を行う以外にない。
