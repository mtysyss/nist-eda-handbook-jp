# 2.3.3.2. 校正設計の対応策

#### [目録掲載設計](mpc34.md)の対応策
本ハンドブックに掲載している設計すべての対応策は、各設計に含まれている。
[他の設計の対応策](mpc3321.md)、行列に関する基礎知識があれば、以降のページに記載されている手順に従って計算することができる。

#### 1,1,1 設計の測定値
目録に掲載されている表の使用例として、3つの人工物、すなわち、既知の *R\** 値を持つ参照標準、および未知の値を持つ検査標準と試験対象について説明する。
すべての人工物は同じ公称サイズである。
設計は、 [1.1.1 設計](mpc3411.md)として、以下の条件で参照される。
* $`n=3`$ の差分測定値  
* $`m=3`$ 個の人工物  

#### 測定手順の表示および参照および確認標準の特定に関する規定
測定順序の表記規則は以下の通りである。
1行目の公称値には下線が引かれており、この表記は 3つの 1キログラム分銅など、同じ公称サイズの 3品の比較に適していることを示している。
参照標準は 1番目、検査標準は2番目、試験対象は3番目である。

|        | <u>1</u> | <u>1</u> | <u>1</u> |
| ------ | :--: | :--: | :--: |
| Y(1) = | + | - |   |
| Y(2) = | + |   | - |
| Y(3) = |   | + | - |
| 拘束    | + |  |  |
| 確認標準 |  | + |  |

#### この設計の制限事項
この設計には自由度がある$$ \nu = n - m + 1 = 1 $$
#### 個々の項目に対する最小二乗推定値を表示するための規約
以下の表は、個々の項目の推定値を計算するための係数をまとめたものである。
推定値は、対象となる項目の該当する列と測定データの列との外積を求め、それを表の上部に示された除数で割ることで計算されます。

```
                        SOLUTION MATRIX
                          DIVISOR = 3

     OBSERVATIONS      1      1      1

        Y(1)           0     -2     -1
        Y(2)           0     -1     -2
        Y(3)           0      1     -1
        R*             3      3      3
```

#### 上記の表にある各項目に対する解答
例えば、参照標準物質の推定値は第1列に、検査標準物質の推定値は第2列に、そして試験対象物質の推定値は第3列に示されている。
設計上の制約により、測定結果にかかわらず、参照標準物質の推定値は必ず *R\**となることが保証されている点に注意してください。
推定値は以下の通りです：$$ \widehat{R^\*} = \frac{1}{3}(0 Y_1 + 0 Y_2 + 0 Y_3) + R^\* $$$$ \widehat{Chk} = \frac{1}{3}(-2 Y_1 - 1 Y_2 + 1 Y_3) + R^\* $$$$ \widehat{Test} = \frac{1}{3}(-1 Y_1 - 2 Y_2 - 1 Y_3) + R^\* $$
#### 個々の項目および項目の組み合わせに対する標準偏差の表示に関する規約
標準偏差は、以下に示す2つの因子表から計算される。
項目の組み合わせに対する標準偏差には、適切な共分散項が含まれている。
 ```     FACTORS FOR REPEATABILITY STANDARD DEVIATIONS
     WT  FACTOR           K1      1   1   1      1  0.0000    +      1  0.8165        +      1  0.8165            +      2  1.4142        +   +      1  0.8165        +
     FACTORS FOR BETWEEN-DAY STANDARD DEVIATIONS
     WT  FACTOR
           K2      1   1   1      1  0.0000    +      1  1.4142        +      1  1.4142            +      2  2.4495        +   +      1  1.4142        +``` 

#### 統一方程式
各項目の標準偏差は、
以下の統一式を用いて計算される：
$$ {\large s}_{test} = \sqrt{K_1^2 {\large s}_1^2 + K_2^2 {\large s}_{days}^2} $$

#### 因子表に基づく1,1,1設計の標準偏差
1,1,1の設計における標準偏差は以下の通りです：
$$ {\large s}_{R^\*} = 0 $$
$$ {\large s}_{chk} = \sqrt{(0.8165 \cdot {\large s}_1)^2 + (1.4142 \cdot {\large s}_{days})^2)} =
\sqrt{\frac{2}{3} {\large s}_1^2 + 2 {\large s}_{days}^2} $$
$$ {\large s}_{test} = \sqrt{(0.8165 \cdot {\large s}_1)^2 + (1.4142 \cdot {\large s}_{days})^2} =
\sqrt{\frac{2}{3} {\large s}_1^2 + 2 {\large s}_{days}^2} $$
$$ {\large s}_{chk+test} = \sqrt{(1.4142 \cdot {\large s}_1)^2 + (2.4495 \cdot {\large s}_{days})^2)} =
\sqrt{2 {\large s}_1^2 + 6 {\large s}_{days}^2} $$

#### 過去のデータから、工程の標準偏差を把握しておく必要があります
これらの方程式を適用するには、測定工程における日々の変動を表す
標準偏差 \( {\large s}_{days} \) の推定値が必要となる。
この標準偏差は、
検査用標準物質の[レベル2標準偏差](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3332.md)
\( {\large s}_2 \) から導かれる。
この標準偏差は
チェック標準に関する過去のデータから推定される。これは
無視できるほど小さい場合があり、その場合は計算が簡略化される。 [再現性標準偏差](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3332.md)、
\( {\large s}_1 \) は、
過去のデータ、通常は複数の試験計画のデータから推定される。 

#### 標準偏差の計算手順
テスト項目の標準偏差を算出する手順は以下の通りです： * 設計データまたは過去のデータから[再現性の標準偏差](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3332.md#inst)を算出する。 * 過去のデータから[チェック標準の標準偏差](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3332.md#chkstd)を算出する。 * **チェック標準**試料の係数 \( K_1 \) および
      \( K_2 \) を求める。1,1,1 設計の場合、係数は
      それぞれ 0.8165 および 1.4142 であり、ここでチェック標準試料の
      データは表の最後にある。 * 統一式をチェック標準値に適用して、
        日ごとの標準偏差を推定する。なお、チェック標準値の
        標準偏差は、一部のページで言及されている
        [レベル2の標準偏差](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3332.md)
        、
        \( {\large s}_2 \) と同じであることに注意されたい。
        統一式から得られる
        日間標準偏差の式は
        以下の通りである。
        $$ {\large s}_{days} = \frac{1}{K_2} \sqrt{{\large s}_2^2 - K_1^2 {\large s}_1^2} $$
        したがって、上記の例では
        $$ {\large s}_{days} = \frac{1}{\sqrt{2}} \sqrt{{\large s}_2^2 - \frac{2}{3} {\large s}_1^2} $$
        * これが、
          [NIST質量校正
          ソフトウェア](https://www.itl.nist.gov/div898/handbook/mpc/section7/mpc7.md#Varner)に「測定間標準偏差」として入力される数値である。この
          ソフトウェアを使用する場合、試験対象の標準偏差は
          ソフトウェアによって自動的に計算されるため、これを行う必要が
          ある計算はこれだけである。 * もし、平方根の記号内の計算結果が負の
            数値となった場合は、\( {\large s}_{days} =0 \) と設定してください。
            （これは起こり得ることであり、
            日ごとの変動による不確かさへの寄与がないことを
            示しています。） * 完全を期すために、適切な係数を用いた
              試験項目の標準偏差および試験項目と
              チェック項目の標準偏差の和の
              計算式を以下に示します。
              $$ {\large s}_{test} = \sqrt{\frac{2}{3} {\large s}_1^2 + 2 {\large s}_{days}^2}
              = \sqrt{\frac{2}{3} {\large s}_1^2 + \frac{5}{2} \left( {\large s}_2^2 - \frac{2}{3} {\large s}_1^2 \right) }
              = {\large s}_2 $$
              $$ {\large s}_{test+chk} = \sqrt{2 {\large s}_1^2 + 6 {\large s}_{days}^2}
              = \sqrt{2 {\large s}_1^2 + \frac{13}{2} \left( {\large s}_2^2 - \frac{2}{3} {\large s}_1^2 \right)}
              = \sqrt{3} \, {\large s}_2 $$
