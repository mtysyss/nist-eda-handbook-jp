# 2.3.6.2. データ収集

#### データ収集
検量線の作成のためのデータ収集の工程は、校正計画の成否を左右するため重要である。
[検量実験の設計](../../pmd/section3/pmd3.md)には一般的な原則が適用され、本章での[検量モデル](mpc361.md)に適した指針を以下に示す。

#### 参照標準の選定
[線形校正曲線](mpc361.md#線形モデルの特殊な事例--校正不要)の作成には、少なくとも<u>5つ</u>の参照標準が必要であり、より複雑な校正モデルでは<u>10個</u>の参照標準があれば十分である。

参照標準を選択する際の最適な戦略は、計測器の測定範囲を網羅するように、*y* 軸上で等間隔となる点に参照標準を配置することである。
しかし、多くの場合、参照標準を作成する担当者と検量線を作成する担当者が異なるため、この戦略は現実的ではない。
*x* 軸上で等間隔に参照標準を配置することが有効な代替策である。 

#### 上記規則の例外 - 挟み込み法
計測器を全測定範囲にわたって校正するのではなく、特定用途のためにごく狭い範囲のみを校正するならば、完全な校正曲線を作成する必要はなく、挟み込み法[（ISO11095）](../section7/mpc7.md#ISO11095)）を用いることで満足のいく結果が得られる。
挟み込み法は、対象範囲において計測器が直線的であることを前提としており、この場合、参照標準物質は範囲の両端に1つずつ、計2つだけで済む。

#### 各参照標準の測定回数
各参照標準において、少なくとも<u>2</u>回の測定が必要であり、4回行うことが推奨される。
反復は数日もしくは数週間の間隔を空けて実施すべきである。
これらの反復により、候補となるモデルが当該計測器の校正に適しているかを判断するためのデータが得られる。
