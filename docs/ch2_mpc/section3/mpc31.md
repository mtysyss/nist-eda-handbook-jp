# 2.3.1. 校正における課題

#### 偏りを低減する校正
校正は、人工物の特性や参照標準に紐づけられた機器の応答、あるいは設計された測定工程に値を割り当てる測定工程である。
校正の目的は、参照基準に紐づけられた利用者の測定システムにおける偏りを排除、低減することである。

#### 計測器および機器の校正
校正手順は、特定の処理手順にしたがって、「未知」や試験対象、計測器を基準標準と比較する。
本ハンドブックでは、以下の2つの一般的な校正の種類について取り上げる。

* [人工物の1点校正](mpc32.md)  
* [測定範囲にわたる計測器校正](mpc36.md)

#### 取り上げなかった校正の種類
本ハンドブックに記載されている手順は、トレーサビリティ連鎖の二次階層以下において、当該単位の参照標準が既にある場合の校正に適している。
物理学の第一原理に基づく校正や相互校正については扱わない。
