# 2.3.3.3. 校正値の不確かさ

#### [ISOの原則](../section5/mpc5.md)の不確かさ解析
校正計画における校正値の不確かさに関する計算について示す。
この議論は、[不確かさ要素の分類と合成](../section5/mpc52.md#ISO)」の節に記載された指針に従う。
ここでは、2種類の評価について取り上げる。

1. [タイプAの評価](../section5/mpc53.md)：偶然誤差の時間依存要因
2. [タイプBの評価](../section5/mpc54.md)：他の誤差要因

後者には、参照標準に割り当てられる不確かさの値といった校正設計における再現されない要因の不確かさが含まれるが、これに限定されるものではない。

#### 試験対象の不確かさ
設計に基づく試験対象の校正値に関連する不確かさには、個々の設計に応じた計算が必要である。
その手順を以下に概説する。
