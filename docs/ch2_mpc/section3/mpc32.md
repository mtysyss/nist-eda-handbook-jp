# 2.3.2. 人工物の（1点）校正

#### 目的
人工物の校正とは、参照標準に紐づけられる人工物の特性に値を割り当てる測定工程である。
校正の目的は、参照基準に紐づけられた利用者の測定システムにおける偏りを排除、低減することである。

校正手順では、校正設計と呼ばれる特定の処理手順に従って、「未知」または試験対象物と同じ公称値を持つ参照標準（したがって、「1点校正」）と比較する。 

#### 仮定
校正手順は、試験対象物と参照標準個々の測定値が以下の要因の影響を受ける仮定に基づく。

* 測定システムまたは計測器に起因する偏り  
* 制御できない偶然誤差    

#### 偏りとは
偏りの運用上の定義とは、依頼先機関と参照標準を維持管理する機関で人工物に割り当てられる値の間に生じる差異を指す。
この文脈における「値」とは、両機関において得られるであろう長期的平均値と解釈される。

#### 試験対象物と値が非常に近い基準試料が必要である、偏りを除去するための校正モデル
偏りを除去する一つの方法として、試験対象物とほぼ同一の参照標準を選択し、比較器型の計測器を用いてこれら2つの試料を測定し、2つの測定値の差分を求め、偏りを相殺する。
計測器に求められる唯一の要件は、これら2つの人工物の測定に必要な狭い範囲において直線性を保つことである。

試験対象はまだ割り当てられていない値 $`X^\*`$ 、参照標準には割り当てられた値 $`R^\*`$ がある。
試験対象の測定値 *X* と参照標準の測定値 *R* が与えられたとき、

$$
\begin{aligned}
X &= \text{偏り} + X^\* + \text{誤差}_1 \\
R &= \text{偏り} + R^\* + \text{誤差}_2
\end{aligned}
$$

試験対象と参照標準の差は、

$$D = X - R$$  

により推定され、試験対象の値は以下となる。

$$\widehat{Test} = X^\* = D + R^\*$$  

#### 校正設計につながる冗長性の必要性
1点差分値のみに基づく *D* を推定する欠点は、偶然誤差の影響を評価する方法がない点である。
明らかな解決策は以下が挙げられる。

* 校正測定を *J* 回繰り返す  
* 結果を平均する  
* *J* つの結果から標準偏差を計算する  

複数の参照標準および試験対象物の測定を連続した順序で行う冗長な相互比較の計画は、[校正設計](mpc33.md)と呼ばれ、後の節で論じる。
