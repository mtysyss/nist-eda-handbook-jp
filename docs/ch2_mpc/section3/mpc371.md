# 2.3.7.1. 線形検量線の管理図

#### 目的
3つのフォトマスク参照標準（検量線の低、中、高端）の線幅を参照人工物 10個を用いた同様の測定値に基づいて校正した光学撮像システムを用い、6日間にわたり測定した。
管理図の[管理値](mpc37.md#管理値の定義)および[管理限界](mpc37.md#管理限界の計算)は、線形検量直線の切片と傾きに基づいており、光学撮像システムの校正状態と線形性を監視するものである。

#### 初期校正実験
初期の校正実験は、10個の人工物に対する 40回の測定（ここでは示していない）からなり、以下の線形検量線が得られた。

* 切片 = 0.2357  
* 傾き = 0.9870  
* 残差標準偏差 = 0.06203 マイクロメートル  
* 自由度 = 38  

#### 光学撮像システムを用いた線幅測定
検量線の上、中、下端（U、M、L）の人工物の3つについて、管理測定値 *Y* および既知値 *X* を以下の表に示す。

#### 管理図の解釈
管理測定値には偏位の兆候は見られず、4日目の管理値3つすべてが限界値を超えているのを除き、管理限界の範囲内にある。
問題のその日の原因は、手元のデータからは特定できないが、その日に実施されたすべての測定値（作業対象品を含む）は無効とし、再測定を行うべきである。
