# 2.3.5.1.1. 精度の管理図例

#### 物質収支の精度に関する管理図の例
質量校正は通常、高精度天秤を比較器として用い、キログラム標準を比較することから始める。
1975年から1989年にかけてNISTで行われたキログラム水準の測定の多くは、12番天秤を用いて、[1,1,1,1 校正設計](mpc3412.md)に基づいて実施された。
この校正設計における冗長性により、個々のキログラム値の推定値と、各校正実行ごとに自由度 3 を持つ繰り返し性標準偏差が得られる。
これらの標準偏差で天秤の精度を推定する。

#### 精度監視の必要性
天秤の精度を監視し、以下の点を確認する。

1. 天びんの緩やかな劣化  
2. 特定の時間帯における異常な動作  

#### 標準偏差の監視技法
経時および多数の校正における標準偏差は、[標準偏差の管理図](mpc351.md)を用いて追跡・監視する。
データベースと管理限界は年次または隔年ごとに更新し、次の期間で行われる各校正の標準偏差を管理限界と比較する。
本事例では、1975年から1985年の間に実施された117回の校正からの標準偏差を組み入れ、自由度 $`v=3×117=351`$ を持つ繰り返し性標準偏差を求め、[管理限界](mpc351.md#各校正実行ごとに即時実行する管理手順)は 1%の有意水準で計算された。

#### 管理図の解釈
管理図によると、1988年の最初の5か月間、天秤の精度は管理範囲内にあり、管理限界値を超えたのはわずか2回であった。
その事例では、校正結果を無効とし再校正を行った。
明らかに、2回目の逸脱については、校正結果を無効にするような重大な事象が発生したと考えられる。

#### 管理図のさらなる解釈
しかし、経時の標準偏差推移からも、天秤の精度が徐々に低下し、管理限界に近づく測定値がますます増えていることが明らかになった。
この結果を受け、高精度な校正にはこの天秤を交換することが決定された。
