# 2.3.5.2.2. 量産校正用のEWMA管理図の例

#### 時間が経つことで明らかになる小さな変化
残念ながら、管理限界を個別に逸脱したからといって必ずしも工程の恒久的な変化を示しているとは限らないため、データにパターンが現れるまでには時間が掛かる。
Shewhart 管理図は、最大で1標準偏差程度のような微小な変化を検出するには不向きであり、前ページに示した[校正データ](mpc3521.md)の事例もそのように見える。
この目的には、EWMA（指数加重移動平均）管理図の方が適している。

#### キログラム水準におけるEWMA統計量の説明
指数加重移動平均（EWMA）は、現在の測定値から時間的に離れるほどデータの重みを徐々に小さくする方法でデータを平均化し、工程を監視するための統計である。
時刻 *t* における EWMA 統計量は、以下の時間順に並べられた個々のデータ点から再帰的に計算され

$$Y_1, Y_2, \ldots, Y_t$$

ここで、最初の EWMA 統計量は過去のデータの平均である。

$$EWMA_{t+1} = \lambda Y_t + (1-\lambda)EWMA_t$$

#### EWMAの管理の仕組み
EWMA管理図は、重み係数 $`\lambda`$ の選択によって、工程のわずかな変化や漸進的な偏位に対して感度を高めることができる。
この目的のために重み係数として 0.2～0.3 が提案されており、（[Hunter, 1986](../section7/mpc7.md#Hunter)）、0.15 がよく用いられる値である。

#### 管理図の限界値
管理図の目標値または中心線は、過去データの平均値である。
上限（*UCL*）と下限（*LCL*）は次式であり、

$$ UCL = EWMA_1 + {\large s} k \sqrt{\frac{\lambda}{2-\lambda}} $$
$$ LCL = EWMA_1 - {\large s} k \sqrt{\frac{\lambda}{2-\lambda}} $$

ここで、*s* は過去のデータの標準偏差である。
根号内の関数は、時間の関数である EWMA 統計量の標準偏差の成分に対する良好な近似である。
また、*k* は[乗数係数](../section2/mpc221.md)であり、Shewhart 管理図の場合と同様に定義され、通常は 3 が使われる。

#### EWMA統計量における管理限界の複数回の逸脱を示す、キログラム校正用の標準データを検証するためのEWMA管理図例
目標値（平均）および工程標準偏差は、1985年以前に取得された検査標準データから計算されている。
EWMA 統計量の計算は、1985年初頭に採取されたデータから始まっている。
以下の管理図では、1985年以降の管理データが緑色で示され、EWMA 統計量は生データの上に重ねられた黒点として表示されている。
管理限界は上記の式に従って計算され、ここで工程標準偏差 $`s=0.03065 \text{mg}`$、$`k=3`$ である。
管理外れ信号を探すときには、生データではなく EWMA 統計量が重要である。
EWMA 統計量は加重平均であるため、単一の管理測定値よりも標準偏差が小さく、したがって、EWMA 管理限界は Shewhart 管理図の限界よりも狭くなる。

![EWMA control chart for mass calibrations](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3522c_r.gif)

質量校正の EWMA 管理図は、[Dataplotコード](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3522a.dp)および[Rコード](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3522a.r)の両方を使用して作成できる。
読者は[データをテキストファイルとして](https://www.itl.nist.gov/div898/handbook/datasets/MASS.DAT)ダウンロードできる。 

#### 管理図の解釈
EWMA 管理図では、1986年の中頃頃から管理限界の逸脱が多数見られる。
このパターンは、実際の工程平均が約1標準偏差分ズレており、EWMA 管理図がわずかな変化にも敏感であることから生じている。
