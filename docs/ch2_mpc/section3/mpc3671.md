# 2.3.6.7.1. 誤差の伝播を用いた二次校正における不確かさ

#### ロードセルの校正値の不確かさに対する誤差伝播
このページの目的は、二次校正曲線に基づくロードセルの校正値について、誤差の伝播を次式の計測器応答モデルで示すことである。

$$Y = a + bX + cX^2 + \epsilon$$

[校正データ](mpc3651.md)は既知の荷重（psi）における計測器の応答であり、[二次係数の推定値](mpc365.md) $`a, b, c`$ およびそれに付随する標準偏差が解析結果と共に示されている。

正しい荷重（psi）である $`X'`$ に対して補正された測定値 $`Y'`$ を示す校正曲線のグラフを以下に示す。

![quadratic calibration curve for loadcell](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3671a.jpg)

#### 校正値 X' の不確かさ
評価すべき不確かさは、校正済みの計測器を用いて将来行われる任意の測定値 $`Y'`$ に対して次式で計算される校正値 $`X'`$ の不確かさである。

$$X' = \frac{-\hat{b} \pm \sqrt{\hat{b}^2 - 4 \hat{c} \left( \hat{a} - Y' \right)}}{2 \hat{c}}$$

#### 偏微分
不確実性を計算するには、偏微分が必要である。

$$\frac{\partial{X'}}{\partial{Y'}} =\frac{1}{\sqrt{\hat{b}^{2} - 4\hat{c}(\hat{a}-Y')}}$$

$$\frac{\partial{X'}}{\partial{\hat{a}}} =\frac{-1}{\sqrt{\hat{b}^{2} - 4\hat{c}(\hat{a}-Y')}}$$

$$\frac{\partial{X'}}{\partial{\hat{b}}} =\frac{-1 + \frac{\hat{b}}{\sqrt{\hat{b}^{2} - 4\hat{c}(\hat{a}-Y')}}}{2\hat{c}}$$

$$\frac{\partial{X'}}{\partial{\hat{c}}} =\frac{-\hat{a} + Y'}{\hat{c}\sqrt{\hat{b}^{2} - 4\hat{c}(\hat{a}-Y')}} -\frac{-\hat{b} + \sqrt{\hat{b}^{2} - 4\hat{c}(\hat{a}-Y')}}{2\hat{c}^{2}}$$

#### 誤差伝播による校正値の分散
$`X'`$ の分散は、[誤差伝播](../section5/mpc55.md)から次式で定義される。

$$u^{2} = \left( \frac{\partial{X'}}{\partial{Y'}}\right) ^{2} (s_{Y'})^{2} +\left( \frac{\partial{X'}}{\partial{\hat{a}}}\right) ^{2} (s_{\hat{a}})^{2} +\left( \frac{\partial{X'}}{\partial{\hat{b}}}\right) ^{2} (s_{\hat{b}})^{2} +\left( \frac{\partial{X'}}{\partial{\hat{c}}}\right )^{2} (s_{\hat{c}})^{2}$$

検量線への2次近似から得られる係数の値とそのそれぞれの標準偏差を式に代入する。
補正対象の測定が別の測定系で行われた場合、測定値 $`Y`$ の標準偏差は、校正データへの近似から得られる標準偏差とは一致しないことがある。
ここでは、校正対象の計測器の標準偏差が、校正データの収集に使用された計測器の標準偏差と実質的に同じであると仮定し、2次近似による残差の標準偏差が適切な推定値であるとみなす。

```
a  = -0.1850148e-04
sa =  0.2081e-04
b  =  0.100102
sb =  0.3681e-05
c  =  0.7030346e-05
sc =  0.1460e-06
sy =  0.0000340856
```

上記に示した標準偏差は、そのままでは解釈しにくいが、グラフ化するのは容易である。
校正値 $`X'`$ の標準偏差を計測器の応答 $`Y'`$ の関数として示したグラフを以下に示す。

![standard deviation of calibrated value of X' for given instrument response Y'](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3671b.jpg)

#### 誤差の伝播に関する問題
上記の誤差の伝播は、係数 $`a, b, c`$ 間の共分散を無視しているため、完全なものではない。
残念ながら、一部の統計ソフトウェア・パッケージでは、分析結果の他の出力とともに、これらの共分散項が表示されないことがある。

#### ロードセル・データの共分散項
ロードセルのデータ集合の分散・共分散項を以下に示す。

```
            a              b              c
a      4.330796e-10
b     -7.027501e-11  1.355352e-11
c      2.498281e-12 -5.244666e-13  2.133052e-14
```

対角要素は、それぞれ係数 $`a, b, c`$ の分散であり、非対角要素は共分散項である。 

#### X'の標準偏差の再計算
共分散項を考慮に入れるため、$`X'`$ の分散は共分散項を加え再定義する。
適切な置換を行い、標準偏差を再計算し、計測器の応答関数としてグラフ化する。

$$u^2 = u^2 + 2 \left( \frac{\partial X'}{\partial \hat{a}} \right) \left( \frac{\partial X'}{\partial \hat{b}} \right) s_{\hat{a}\hat{b}} + 2 \left( \frac{\partial X'}{\partial \hat{a}} \right) \left( \frac{\partial X'}{\partial \hat{c}} \right) s_{\hat{a}\hat{c}} + 2 \left( \frac{\partial X'}{\partial \hat{b}} \right) \left( \frac{\partial X'}{\partial \hat{c}} \right) s_{\hat{b}\hat{c}}
$$

```
sab = -7.027501e-11
sac =  2.498281e-12
sbc = -5.244666e-13
```

下のグラフは、$`X'`$ の標準偏差の正しい推定値を示し、共分散項を無視することで生じ得る精度の損失を評価する手段を提供する。
このじれいでは、共分散項を含めることで不確かさが低減されるが、そのうちのいくつかは負である。
