# 2.3.4.7. 湿度標準

#### 湿度標準
湿度標準の校正では通常、参照分銅と湿気を含んだシリンダーとの比較を行う。
本目録に掲載されている設計は偏位を排除するものであり、湿度シリンダー以外の標準にも適している。
