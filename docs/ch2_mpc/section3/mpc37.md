# 2.3.7. 線形校正の計測器管理

#### 目的
管理の目的は、計測器の校正精度が経時で低下しないことを保証することである。

#### 手法
これは、Shewhart 管理図を応用した手法を用い、工程の部品に対して行う品質管理とほぼ同様の方法で、計測器の出力に対して品質管理を行うことによって実現される。

#### 管理施策に必要な検査標準
線形校正においては、計測器が校正から外れないようにするために端点と校正区間の中心点を管理すれば十分である。
したがって、検査標準はすなわち以下の3か所が必要である。

* 測定範囲の下端
* 測定範囲の中間
* 測定範囲の上端

#### データ収集
各検査期間において、各検査標準につき1回の測定が必要である。
まずは、毎日開始時に、あるいは経験に基づいて適切な頻度で、管理測定を行うことを勧める。
計測器が管理状態であり続けている場合は、点検の間隔を長くすることができる。

#### 管理値の定義
計測器の補正の節での表記に合わせるため、$`X^\*`$ は標準の既知値を表し、$`X`$ は標準の測定値を表す。

管理値は、以下の差として定義される。

$$W = X^\* - X$$

校正が完璧であれば、管理値はゼロを中心として無作為に分布し、管理図上の適切な上限および下限の範囲内に収まる。

#### 管理限界の計算
上下側管理限界（[Croarkin and Varner）](../section7/mpc7.md#CroarkinVarner)は、それぞれ、

$$l_{upper} = +\frac{s}{\hat{b}}t_{\alpha/2}^{\*}(\nu)$$

$$l_{lower} = -\frac{s}{\hat{b}}t_{\alpha/2}^{\*}(\nu)$$

となり、ここで、$`{\large s}`$ は校正実験による近似の残差標準偏差、$`\hat{b}`$ は線形校正曲線の推定傾きである。

#### *t*\* の値
境界値、$`t_{\alpha/2}^{\*}`$ は、[*t*\* 表](../section3/eda3675.md)から求める。
$`\nu`$は、残差標準偏差の自由度であり、$`\alpha`$ は 0.05 に等しい。

#### t*の決定
$`\alpha = 0.05`$ かつ $`\nu = 38`$ の場合、$`t^\*`$ 統計量の臨界値は 2.497575 となる。

[Rコード](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc37.r)および[Dataplotコード](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc37.dp)を使用し、標準 $`t`$ -表を用いて $`t^\*`$ の臨界値を決定する。
ここで、$`\zeta`$ は

$$\zeta = \frac{1}{2} \left[ 1 - e^{\frac{\ln (1-\alpha)}{m}} \right]$$

で計算され、*m* は検査標準数である。 

#### 直線性からの逸脱に対する感度
もし

$$l_{lower} \le W \le l_{upper}$$

であれば、その計測器は統計的管理下にある。
この文脈における統計的管理とは、測定値がある特定範囲内で再現可能であるだけでなく、計測器の応答が線形性を維持していることも意味する。
この検定は、線形性からの逸脱に対して感度が高い。

#### 線形校正曲線によって補正されたシステムの[管理図](mpc371.md#管理図)
光学撮像システムを用いた[フォトマスク標準の線幅を測定](mpc371.md)での線形検量線によって補正した例を示す。
3つの管理測定は、校正区間の下端、中間、上限端の値を持つ参照標準に対して行われた。
