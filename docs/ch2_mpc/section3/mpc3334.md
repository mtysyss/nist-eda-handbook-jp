# 2.3.3.3.4. 1,1,1,1の設計における標準偏差の算出

#### 2つの参照標準と2つの試験対象を用いた設計
以下に、2つの参照標準 $`R_1`$ および $`R_2`$ 、2つの試験対象 $`X_1`$ および $`X_2`$、そして6つの差分測定値を用いた[1,1,1,1設計](mpc3412.md)の例を示す。
拘束条件 *R\** は2つの参照標準の値の和であり、拘束条件とは独立した確認標準は、参照標準の値の差である。
この設計と解を以下に示す。

#### 2つの参照標準の差である確認標準

```
        観測値       1   1   1   1

         Y(1)       +   -
         Y(2)       +       -
         Y(3)       +           -
         Y(4)           +   -
         Y(5)           +       -
         Y(6)               +   -


         拘束        +   +

     
        確認標準      +   -
     
     
     　　自由度  =  3


                         　解行列
                           除数  =  8

       観測値           1      1      1      1

        Y(1)           2     -2      0      0
        Y(2)           1     -1     -3     -1
        Y(3)           1     -1     -1     -3
        Y(4)          -1      1     -3     -1
        Y(5)          -1      1     -1     -3
        Y(6)           0      0      2     -2
        R*             4      4      4      4
```

#### [解行列の説明](mpc332.md)
解行列は、試験対象に対して以下の値を与える。

$$
\begin{array}
 X_1^\* &= \frac{1}{8} \left( -3Y_2 - Y_3 - 3Y_4 - Y_5 + 2Y_6 \right) + \frac{1}{2} R^\* \\
 X_2^\* &= \frac{1}{8} \left( -Y_2 - 3Y_3 - Y_4 - 3Y_5 - 2Y_6 \right) + \frac{1}{2} R^\*
\end{array}
$$

#### 不確かさに対する繰り返し性と段階2標準偏差の寄与を算出するための因子

```
     繰り返し性標準偏差因子
     WT   因子
            K1     1   1   1   1
      1  0.3536    +
      1  0.3536        +
      1  0.6124            +
      1  0.6124                +
      0  0.7071    +   -

         
     段階2標準偏差因子
     WT   因子
            K2     1   1   1   1
      1  0.7071    +
      1  0.7071        +
      1  1.2247            +
      1  1.2247                +
      0  1.4141    +   -
```

最初の表は、繰り返し性標準偏差が不確かさの総和への寄与を計算するための係数を示している。
2番目の表は、日間標準偏差の不確かさへの寄与を計算するための係数を示している。
なお、各表の最後の項目が検査標準であることに留意する。 

#### 統一方程式
統一式は次の通り。

$${\large s}_{test} = \sqrt{K_1^2 {\large s}_1^2 + K_2^2 {\large s}_{days}^2 } \quad .$$

#### 表の係数と統一式を用いて計算する標準偏差
試験対象の標準偏差を計算する手順は以下の通り。

* 過去のデータから[繰り返し性標準偏差](mpc3332.md#inst)を計算する。  
* 過去のデータから[検査標準の標準偏差](mpc3332.md#chkstd)を計算する。  
* 検査標準の係数 $`K_1`$ および $`K_2`$ を求める。
* 日間分散を計算する（検査標準の統一式を使用）。
この例では、

$$
s_2^2 &= { ( \sqrt{0.5} s_1 )^2 + ( \sqrt{2} s_{\text{days}} \right)^2 } = { \frac{1}{2} s_1^2 + 2 s_days}^2 } 
$$

$$
\begin{aligned}
s_2^2 &= \left\{ \left( \sqrt{0.5} s_1 \right)^2 + \left( \sqrt{2} s_{\text{days}} \right)^2 \right\} = \left\{ \frac{1}{2} s_1^2 + 2 s_days}^2 \right\} \\
&\text{より} \\
&\Longrightarrow \\
s_{days}^2 &= \frac{1}{2} \left\{ s_2^2 - \frac{1}{2}s_1^2 \right\} \quad .
\end{aligned}
$$

* この分散の推定値が負の場合、$` {\large s}_{days} = 0 `$ と設定する。
（これはあり得ることであり、日ごとの影響による不確かさへの寄与がないことを示す。） 
* 試験体調に対する因子 $`K_1`$ および $`K_2`$ を求め、統一式を用いて標準偏差を計算する。
この例では、

$$
s_{X_1} = \sqrt{\frac{3}{8} s_1^2 + \frac{3}{2} s_{days}^2} = \sqrt{\frac{3}{8} s_1^2 + \frac{3}{2} \cdot \frac{1}{2} \left\{ s_2^2 - \frac{1}{2}s_1^2 \right\} } = \sqrt{\frac{3}{4} s_2^2}
$$  

および

$$s_{X_2} = s_{X_1} \quad .$$
