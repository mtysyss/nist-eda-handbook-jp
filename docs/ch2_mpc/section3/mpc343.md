# 2.3.4.3. 電気量の設計

#### 標準セル
公称1ボルトの飽和標準セル群は、多くの試験所において電圧単位を維持するための基礎となっている。

#### 偏りの問題
2つの飽和標準電池を直列対向接続した電位差をポテンショメータで測定すると、回路の極性を逆にしても変化しない熱起電力によって測定値が影響を受けることが観察されている。

#### 偏り除去設計
標準セルを比較するための校正設計は、以下の条件を満たすように左右対称に構成する。

* 一定偏り *P* が個々のセル推定値に影響を与えない。
* *P* は測定差の平均として推定される。

#### 電気量の設計
以下の区分けによる電気的人工物の設計を示す。
これらの設計は左右対称であり、電気標準以外の人工物にも適している。

* [飽和標準参照セル](mpc343.md#referencecells)
* [飽和標準試験セル](mpc343.md#testcells)
* [ツェナーダイオード](mpc343.md#zeners)
* [抵抗器](mpc343.md#resistors)

#### 1箱あたりの標準セル数
すべての参照セルに拘束が課され、標準セル同士を比較するための[左右対称な設計](mpc331.md)を以下に示す。
これらの設計は、試験セルに値を割り当てる用途には適して **いない**。

個々の標準セルおよび偏り *P* の推定値は、「解行列」という見出しの下に示されている。
また、これらの設計は、一度に 1 つのセルのみの接続変更で済むという利点もある。

本目録の設計は左右対称である。
