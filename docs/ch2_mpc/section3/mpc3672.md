# 2.3.6.7.2. 検査標準を用いた線形校正の不確かさ

#### 不確かさを計算する仕組みを提供する検査標準
検量線から得られた校正値のタイプA 不確かさを計算する最も簡単な方法は、検査標準を定期的に測定することである。
この場合の検査標準とは、検量線の下限と、中間点、上限に位置する人工物のことである。
検査標準の測定は、校正手順の結果を無作為に抽出する方法で行う。

#### 検査標準値の計算
検査標準値とは、検量線を用いて補正した人工物の生データである。
これらの値の標準偏差は、校正値に伴う不確かさを推定すべきである。
この不確かさ推定手法の有効性は、測定工程の適切な標本抽出に依存している。

#### [線形検量線による測定値の補正](mpc371.md#controlchart)
例として、光学撮像システムを用いて測定し線形校正曲線によって補正された[フォトマスク標準の線幅測定](mpc371.md)考える。
3つの対照測定は、校正範囲の下限と、中点、上限に位置する値を持つ参照標準で行われた。

#### 校正の標準偏差の計算
線幅データについて、校正実験から得られた回帰式は

$$Y = a + bX + \epsilon$$

であり、推定された回帰係数は以下の通り。

$$\hat{a} = 0.2357 $$
$$ \hat{b} = 0.9870$$

次に、回帰式から求めた「予測」$`X`$ と観測された $`X`$ の差を計算する。

$$W_i = \frac{(Y_i - \hat{a})}{\hat{b}} - X_i$$

最後に、計算された差の標準偏差を求め、校正標準偏差を求める。

$$S = \sqrt{\frac{\sum \left( W_i - \overline{W} \right)^2}{n-1}}$$

線幅データの校正標準偏差は 0.119 *μ*m である。

本節の計算は、[Dataplotコード](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3672.dp)および[Rコード](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3672.r)を使用して行うことができる。
読者はデータを[テキストファイルとして](https://www.itl.nist.gov/div898/handbook/datasets/LINEWID.DAT)ダウンロード可能である。 

#### 誤差の伝播との比較
標準偏差 0.119 *μ*m は、[誤差の伝播解析](mpc3673.md)と比較する。

#### 他の不確かさの要因
タイプA の不確かさに加え、県稜線を作成した参照標準の値の不確かさなど、不確かさに寄与する他の要因が存在する可能性がある。
