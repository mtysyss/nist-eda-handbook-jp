# 2.3.3.3.5. タイプB不確かさ

#### 拘束に関連するタイプB不確かさ
校正設計を解く目的では、参照標準に既知の値 *R\** が仮定される。
標準不確かさを計算する目的では、試験対象の不確かさに寄与する[タイプBの不確かさ](../section5/mpc54.md)を持つ。

*R\** の値は、上位の校正機関または工程から得られ、その値は通常、不確かさ *U* と共に報告される。
もしその機関が *U* を計算するための *k* 係数も報告している場合*、制約の標準偏差は以下となる。

$$s_{R^\*} = \frac{U}{k} \quad .$$

*k* が報告されていない場合、保守的な対処として $`k = 2`$ と仮定する。 

#### 試験対象と参照標準のサイズが異なる場合
通常、参照標準と試験対象は同じ公称サイズであり、校正はこれら2つの間のわずかな差を測定することに依拠し、例えば、参照キログラムと試験キログラムとの相互比較がそれにあたる。
また、校正は、参照と、参照と同じ公称サイズを持つ人工物の合計との相互比較からなることもあり、例えば、参照キログラムと500g + 300g + 200g の試験対象分銅との比較などである。

#### 試験人工物に関するタイプBの不確かさ
参照標準の不確かさから試験対象に生じるタイプBの不確かさは、それらの公称規模に比例する。
すなわち、

$$s_B = \frac{\text{公称試験対象}}{\text{公称拘束}} {\large s}_{R^\*} \quad .$$
