# 2.3.3.2.1. 校正設計に対する一般行列解

#### 要求事項
本ハンドブックに掲載している設計すべての解は、各設計に含まれている。
他の設計の解は、行列に関する基礎知識があれば、以降のページに記載されている手順に従って計算することができる。
計算に必要な行列操作は以下の通り。

* 転置（ ' で表す）
* 乗算
* 逆行列

#### 表記
* $`n = \text{差異測定の数}`$  
* $`m = \text{人工物の数}`$  
* $`(n - m + 1) = \text{自由度}`$  
* $`X = (n×m)`$ 設計行列  
* $`r' = (m×1)`$ ベクトル、拘束条件を特定する  
* $`v'_i= (m×1)`$ ベクトル、対象の *i* 番目の項目を特定する *i*番目の位置に1、それ以外の位置に0を持つ  
* $`R^\* = \text{参照標準の値}`$  
* $`Y = (mx1)`$ 観測された差分値のベクトル

#### 測定手順を示すための規約
測定順序を示す規約として、1つの基準標準、1つの検査標準、1つの試験対象からなる[1,1,1](mpc3411.md)設計の3つの測定例を用いて説明する。
1行目の公称値には下線が引かれている。[^1]

```
                 1     1     1
          Y(1) = +     -

          Y(2) = +           -

          Y(3) =       +     -
```

#### 設計問題を解くための行列代数
$`(m×n)`$ の設計行列 *X*は、プラス記号(+)、マイナス記号(-)、および空白をそれぞれ1、-1、0に置き換えることで構成される。

$`(m×m)`$ の正規方程式行列 $`X'X`$ を作り、拘束ベクトルで拡張し、$`(m+1)×(m+1)`$ の行列 *A* がを作る。

$$
A = \begin{bmatrix}
X'X & r' \\
r & 0
\end{bmatrix}
$$

#### 設計行列の逆行列
行列 *A* は逆行列が求められ、以下の形で表される：

 A = [Q  h'; h 0]ここで、*Qは**m*×*m*の行列であり、*s²*と乗算すると、通常の分散共分散行列が得られる。

#### 個々の遺物の価値の推定
個々の人工物の値に対する最小二乗推定値は、(*m*×1) 行列*B*に格納されており、ここで B = QX'Y + h'R* ここで、*Qは*上記に示した*A*-1行列の左上要素である。
個々の推定値の構造は行列*QX*'に含まれている。
すなわち、*i*番目の項の推定値は、*XQ*および*Y*を用いて* *XQ*  の*i*  番目の列と  *Y*  を  クロス乗算し* そして    *、R\*(公称試験)/(公称拘束)*    を加算する 

#### 具体例を挙げて説明してください
上記の議論を、NISTにおける質量校正工程の例を用いて説明する。
この例では、2つのNISTキログラム分銅を、顧客が持ち込んだ未知のキログラム分銅と比較する。
 設計行列 *X* は以下の通りである。

X = [1  -1 0; 1  0  -1; 0  1  -1]最初の2つの列は2つのNISTキログラムを表し、3番目の列は顧客のキログラム（すなわち、校正対象のキログラム）を表する。
 得られた測定値、すなわち*Y*行列は以下の通りである。

Y = [-0.3800  -1.59 -1.2150]測定値は、設計行列で指定されている通り、2つの測定値の差であり、単位はグラムである。
つまり、*Y*(1)はNISTキログラム1とNISTキログラム2の測定値の差、*Y*(2)はNISTキログラム1と顧客のキログラムの測定値の差、そして*Y*(3)はNISTキログラム2と顧客のキログラムの測定値の差である。
 基準標準の値*R*\*は0.82329 である。
 するとX'X = [2  -1 -1; -1  2  -1; -1  -1  2]重量1および重量2の値が既知の3つの分銅がある場合、r = [ 1 1 0 ]


*r*= [ 1 1 0 ]

したがってA = [2  -1  -1 1; -1  2  -1  1; -1  -1  2  0; 1  1  0  0]したがってA^(-1) =(1/6)*[1  -1  0  3; -1  1  0  3; 0  0  3  3; 3  3  3  0]*A*-1より、次のことが得られるQ = (1/6)*[1  -1  0; -1  1  0; 0  0  3]次に *QX'*を計算するQX' = (1/6)*[ 2 1 -1; -2 -1 1; 0 -3 -3]次に*、B* = *QX'Y* + *h'R*\*を計算する B = (1/6)*[1  -1  0; 1  1  0; 0  0  3]*[1  1  0; -1  0  1;0  -1  -1]*[-0.3800  -1.5900  -1.2150] +0.82329*[0.5  0.5  0.5] これにより、以下の最小二乗法による係数の推定値が得られる：

B = [0.2225  0.6008  1.8141] 

#### 推定値の標準偏差
*i*番目の項目の標準偏差は次の通りである： s(itemi) = SQRT(vi'*Q*vi*s1**2 + vi'*D*vi*s(days)**2) ここで D = (Q*X'*X)*(Q*X'*X)' （NIST）質量校正工程の全体的な精度の尺度である工程標準偏差は、 S1 = SQRT((1/(n-m+1))*Y'(I - X*Q*X')*Y) は設計値からの残差標準偏差であり、*sdaysは*日数に関する標準偏差であり、これは[校正用標準物質の測定値](https://www.itl.nist.gov/div898/handbook/mpc/section3/mpc3332.md)からのみ推定可能である。

#### 例
先ほど始めた例を続けます。
*n* = 3 かつ*m* = 3 であるため、式は次のように簡略化されます：

s(1) = SQRT(Y'(I - X*Q*X')*Y)上記で示した値を *X*、*Y*、*Q* に代入すると、次のようになる。

(I - XQX') = [0.3333  -0.3333  0.3333; -0.3333  0.3333  -0.3333; 0.3333  -0.3333  0.3333]となり、

*Y*'(*I* - *XQX*')*Y* =0.0000083333最後に、平方根をとると*s*1 = 0.002887次のステップは、項目3（顧客のキログラム）の標準偏差、すなわち*sitem3を*計算することである。
まず、*X*および*Q*の値を代入し、*Dを*計算しますD = (QX'X)(QX'X)' = [0.5  -0.5  0.0; -0.5  0.5  0.0; 0.0  0.0  1.5]次に、v'(i) = [0 0 1] とし、s(days)^2 =0.021112（この値は検査標準から取得したものであり、この例で与えられた値から計算されたものではありません）を代入する。
 以下の計算結果が得られますv(i)Qv(i)' = [0 0 1] * (1/6)*[1  -1  0; -1  1  0; 0  0  3] * [0 0 1]' = 0.5およびv(i)Dv(i)' = [0 0 1] * [0.5  -0.5  0; -0.5  0.5  0.0; 0  0  1.5] * [0 0 1]' = 1.5およびs(item(i)) = SQRT(vi'*Q*vi*s1**2 + vi'*D*vi*s(days)**2) s(item(i)) = SQRT(0.5*(0.002887)^2 + 1.5*(0.0211)^2) = 0.02593
