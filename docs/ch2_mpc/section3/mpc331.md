# 2.3.3.1. 特定種類の偏りの排除

#### 反証される可能性のある仮定
校正測定に関する一般的仮定のうち、2つは常に成り立つとは限らず、偏りを生じさせる。
これらの仮定は以下である。

* 試験対象物の測定値と参照標準の測定値の差を計算し、偏りを相殺する。  
* 参照標準および試験対象は、一連の測定過程を通じて安定している。  

#### 理想的な状況
理想的な状況では、試験対象の測定値 *X* と参照標準の測定値 *R* の差を採り、偏りを除去する。
しかし、理想的な条件が満たされない状況もある。
