# 2.5.5.1. 単変数関数の式

#### 事例：*Y=f(X,Z)*
単変数の関数である報告値の標準偏差は、H. Ku（[Ku](../section7/mpc7.md#Ku)）の論文から転載したものである。
報告値 *Y* は、単変数に対する *N* 測定値の平均値の関数である。 

| 注記 | $`\bar{X}`$ の関数 $`Y`$<br> $`\bar{X}`$ は $`N`$ 回の測定値の平均 | $`Y`$ の標準偏差<br>$`s_x = X \text{の標準偏差}`$ |
| :--- | :----: | :----: |
|  | $`\Large{ Y = \bar{X} }`$ | $`\Large{ \frac{1}{\sqrt{N}} s_x }`$ |
|  | $`\Large{ Y = \frac{\bar{X}}{1+\bar{X}} }`$ | $`\Large{\frac{s_x}{\sqrt{N} \left( 1 + \bar{X} \right)^2 } }`$ |
|  | $`\Large{ Y = (\bar{X})^2 }`$ | $`\Large{ \frac{2 \bar{X}}{\sqrt{N}} s_x }`$ |
|  | $`\Large{ Y = \sqrt{\bar{X}} }`$ | $`\Large{ \frac{s_x}{2\sqrt{N \bar{X}}} }`$ |
|  | $`\Large{ Y = \mbox{ln} \bar{X} }`$ | $`\Large{ \frac{s_x}{\bar{X} \sqrt{N}} }`$ |
| N が小さい場合<br>近似は大きな<br>誤差になる | $`\Large{ Y = e^{\bar{X}} }`$ | $`\Large{ \frac{e^{\bar{X}}}{\sqrt{N}} s_x }`$ |
| 式から直接導かれ<br>るものではない | $`\Large{ Y = \frac{100}{\bar{X}} s_x }`$ | $`\Large{ \frac{Y}{\sqrt{2(N-1)}} }`$<br>注：元のデータが概ね<br>正規分布に従うと仮定<br>する必要がある。 |
