# 2.5.3.1.1. 時間依存影響のタイプA 評価

#### 偶然誤差の主な源である時間依存変化
偶然誤差の最も重要な指標の一つは時間である。
環境変化など、特に研究対象とされていない影響は、時間の経過とともに現れる。
本節では、時間依存誤差の3つの階層について記載する。
これらは、以下の分類ができる。

1. [階層1](../section4/mpc431.md)または短期誤差（繰り返し性、精度の欠落）
2. [階層2](../section4/mpc432.md)または日間誤差（再現性）
3. [階層3](../section4/mpc433.md)または長期誤差（安定性 - すべての工程において問題となるわけではない）

#### 不確かさの支配的源である日間誤差
短期間では極めて高精度な計測器であっても、多くの場合、微小な環境の影響によって引き起こされる経時的な変化が、測定工程における不確かさの主な源となることが頻繁にある。
不確かさ声明は、時間経過とともに再現できない状況を説明している場合、その目的において「真」とは言えない。
不確かさの利用者は、測定が行われた日や時期にかかわらず、測定結果として得られうる結果の範囲を知る権利を有している。

#### 十分な2階層
測定工程の大部分を記述するには、おそらく2階層の時間依存誤差で十分である。
しかし、新しい測定工程や、特性が十分に理解されていない工程については、3段階が必要である。

#### 他のデータがない場合の不確かさ評価に用いられる試験対象の測定値
試験対象の反復測定では、一般的に、測定工程における日間の変化を捉えるのに十分な時間が確保されない。
これら測定値の標準偏差は、評価に利用できる他のデータがない場合に限り、不確かさの推定値として引用される。
 *J* 回の短期測定の場合、この標準偏差は $`v = J - 1`$ の自由度を持つ。

#### 全ての偶然誤差源を補足する最良機器としての検査標準
不確かさの時間依存源に関する情報を把握する最良の方法は、工程の全期間に渡り所定の間隔で[検査標準](../section1/mpc12.md)の測定を作業負荷の中に適宜組み込むことである。
検査標準の測定値の標準偏差は、不確かさの全体的な時間的成分を直接推定し、それによって個々の成分の推定が不要となる。

#### タイプA 不確かさを推定するための枝分かれ設計　事例研究：3階層枝分かれ設計の時間不確かさ
不確かさの時間依存源を推定する効率の低い方法としては、実験計画が挙げられる。
2つまたは3つの誤差階層を推定するために、測定を特別に行う。
これを行う方法は数多くあるが、最も簡単な方法は、*J* 回の短期測定を *K* 日間繰り返し、その一連の操作を *L* 回（数ヶ月など）に渡り繰り返す「[枝分かれ設計](../section4/mpc43.md)」である。
これらのデータの解析から次式が得られる。

* $`s_1`$ = 短期誤差の自由度 *(J - 1)* の標準偏差
* $`s_2`$ = 日間誤差の自由度 *(K - 1)* の標準偏差
* $`s_3`$ = 超長期誤差の自由度 *(L - 1)* の標準偏差
