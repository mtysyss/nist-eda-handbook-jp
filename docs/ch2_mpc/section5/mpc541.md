# 2.5.4.1. 仮定された分布からの標準偏差

#### 信頼できる不確かさ推定値を得る難しさ
このページで説明する方法は、信頼できる不確かさ推定値が存在しない誤差源を許容することによる困難を回避しようとするものである。
これらの方法は、妥当である場合もあればそうでない場合もある仮定に基づいており、実験者はそれらの仮定が最終的な不確かさに及ぼす影響を考慮する必要がある。

#### 信頼できる不確かさ推定値を得る難しさ
ISOガイドラインでは、偏りに関して最悪状況の推定値をその他の成分に加算することが認められておらず、何らかの方法でそれらを同等の標準偏差に変換することが求められている。
その手法は、その状況におけるあらゆる誤差や偏りを既知の統計分布からの無作為な抽出と見なすものである。
そして、その分布の既知（もしくは仮定した）の特性から標準偏差を計算する。
検討し得る分布は以下である。

* 一様
* 三角
* 正規（ガウス）

#### 一様分布の標準偏差
一様分布は、不確かさの最も保守的な推定値、すなわち最大の標準偏差を与える。
標準偏差の計算は、分布の端点である ±a が既知であるという仮定に基づいている。
また、この計算には、特定の不確かさ源について、報告値に対する全ての影響が -a から +a までの範囲で等しいという仮定も含まれている。

 ![Diagram showing uniform distribution between -a and +a ](https://www.itl.nist.gov/div898/handbook/mpc/section5/mpc541d.gif)
 
$$\displaystyle \large{s_{source} = \frac{1}{\sqrt{3}} a}$$
 
#### 三角分布の標準偏差
三角分布を用いると、不確かさの推定値は保守的が少なくなり、すなわち、一様分布よりも小さな標準偏差を与える。
標準偏差の計算は、分布の端点である ±a が既知であり、三角分布の最頻値が 0 にあるという仮定に基づいている。
 
 ![Diagram showing triangular distribution between -a and +a](https://www.itl.nist.gov/div898/handbook/mpc/section5/mpc541e.gif)
 
$$\displaystyle \large{s_{source} = \frac{1}{\sqrt{6}} a}$$
 
#### 正規分布の標準偏差
正規分布は、不確かさの最も保守的な推定値、すなわち最小の標準偏差を与える。
標準偏差の計算は、端点である ±a が分布の 99.7% を網羅するという仮定に基づいている。

![ Diagram showing normal distribution between -a and +a](https://www.itl.nist.gov/div898/handbook/mpc/section5/mpc541f.gif)
 
$$\displaystyle \large{s_{source} = \frac{1}{3} a}$$
 
#### 自由度
上記の分布に [Welch-Saitterthwaite の式](mpc571.md)を適用する場合、自由度は無限大と仮定される。
