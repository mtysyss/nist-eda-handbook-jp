# 2.5.6.5. 不確かさ予算の例

#### 時間に関する不確かさ3成分の不確かさ予算の例
不確かさ分析のいくつかの原則を示す不確かさ予算を以下に示す。
試験対象の報告値は、$`N`$ 短期測定の平均値であり、不確かさの時間成分は、$`K`$ 日間に渡る $`J`$ 回の短期反復を含む [3階層枝分かれ設計](../section4/mpc43.md)から推定されたものである。

試験対象に対して行われた測定回数は、設計における短期測定の回数と同じで、すなわち、$`N = J`$ である。
試験対象に対して、日や実行での反復がなかったため、$`M = 1; \, P = 1`$ である。
[この設計の感度係数](mpc564.md#level3)は前頁に示されている。 

#### 計測器の偏り例
この例は、試験所内の他の計測器に対して偏りを有している計測器の場合を示しており、それに応じて[偏り補正](mpc5332.md)が適用されている。
偏り補正が人工物 $`Q`$ 個の測定値に基づく、感度係数は $`a_4=1`$ と定義され、標準偏差 $`s_4`$ は[補正値の標準偏差](mpc5332.md)である。

**タイプA および タイプB 不確かさの誤差予算の例**

| タイプA 成分 | 感度係数 | 標準偏差 | 自由度 |  
| :---: | :---: | :---: | :---: |  
| 1. 繰り返し性 | $`a_1 = 0`$ | $`s_1`$ | $`J-1`$ |  
| 2. 再現性 | $`a_2=\sqrt{(k-1)/K}`$ | $`s_2`$ | $`K-1`$ |  
| 3. 安定性 | $`a_3=1`$ | $`s_3=1`$ | $`s_3`$ | $`L-1`$ |  
| 4. 計測器の偏り | $`a_4 = 1`$ | $`s_4`$ | $`Q-1`$ |
