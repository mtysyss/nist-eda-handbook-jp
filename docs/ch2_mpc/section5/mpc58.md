# 2.5.8. 補正されていない偏りの処理

#### 背景
測定不確かさの表現に関するISOガイド（[ISO](../section7/mpc7.md#ISO)）は、すべての偏りが補正されており、不確かさがその補正後の結果に適用されることを前提としている。
工場現場での測定において、この手法にはいくつかの欠点がある。
製品の商業的価値に影響を及ぼさない偏りを補正することは、現実的でなく、コストが掛かり、経済的にも合理的ではないことがある（[Turgel andVecchia](../section7/mpc7.md#TurgelVecchia)）。

#### 偏りを補正しない理由
修正に既存のソフトウェアの変更が必要な場合、実施には多額の費用がかかる可能性があり、また「紙と鉛筆」による修正は時間が掛かり、間違いも生じやすい。
科学または計量の研究所では、特定の状況下で偏りが文書化される場合があるが、その偏りを引き起こすメカニズムが完全には解明されていない、あるいは繰り返し性がない場合があり、補正の必要性を主張することが難しい。
このような場合の最善の対処法は、測定値をそのまま報告し、その「偏り」を考慮して不確かさを調整することである。

#### 不確かさの調整方法に関する論点
結果として得られる不確かさが以下の性質を持つことを保証する手法を開発する必要がある（[Phillips and Eberhardt](../section7/mpc7.md#Phillips)）。

1. 最終的な不確かさは、偏りが補正された場合に示されるであろう不確かさ以上でなければならない。
2. 最終的な不確かさは、偏り補正が適用された場合に得られる不確かさと同じ不確かさに収束しなければならない。
3. 最終的な不確かさ声明によって達成される網羅性の程度は、偏りが補正された場合に得られる程度以上でなければならない。
4. この方法は転用可能であり、不確かさと偏りの両方が別の不確かさ声明における不確かさ成分として使用できるものでなければならない。
5. この方法は、容易に実施可能であるべきである。
