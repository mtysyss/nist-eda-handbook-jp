# 疎なデータの偏り

#### 限定されたデータの対処戦略
本議論では、実際に存在する可能性があるがデータの希薄さのために信頼性をもって推定できない偏りに対処する方法を概説する。
例えば、測定工程の多くの可能な構成のうちの2つを比較する検定では、補正をするに十分に信頼できる偏り推定値は得られないが、測定工程における問題点を明らかにすることはできる。
有意な偏りに対する戦略は、「ゼロ」補正を適用することである。
タイプA 不確かさの成分は補正値の標準偏差であり、その計算は次の偏りに依存する。

* [一貫性の欠如](mpc5331.md#consistent)
* [一貫性](mpc5332.md#inconsistent)

#### 配線設定間の差異の例
ここでは、単一ゲージにおける配線設定に関する研究の例を示す。
ゲージは、シリコン・ウェハの抵抗率を測定するための4点プローブで、いくつかの方法で配線することができる。
ゲージ研究中にすべての配線構成を検定することは不可能であったため、潜在的な問題を特定する方法として、2つの構成でのみ測定が行われた。

#### 配線構成に関するデータ
6日間に渡り、ウェハ 6枚について、プローブ 2062番を2つの構成で配線し測定を行った（ウェハ 39の 5回分の測定を除く）。
この一連の測定は約1か月後に繰り返され、結果として2回行われた。
同日に行われた[2つの構成における測定値の差異のデータベース](../section4/mpc455.md#wiringdata)の有意性を分析した。

#### 2つの構成間の差異に関する統計検定
t 統計量は、差が近似的に正規分布に従うと仮定する近似検定として用いられる。
この検定には、差の平均値と差の標準偏差が必要である。
もし 

$$\displaystyle \large{t = \left| \frac{\sqrt{N}}{s_{diff}} Avg_{diff} \right| > 2} $$ 

を満たす場合、2つの構成間の差は統計的に有意である。
上記の表にある各実行における *N = 29* の差から計算された、両方の実行において差が有意であるが、その方向が逆であることが確認される平均と標準偏差を対応する t 値と共に示す。

```
配線構成間の平均差異

 実行 プローブ      平均       標準偏差    N    t
  1    2062    - 0.00383    0.00514    29   - 4.0
  2    2062    + 0.00489    0.00400    29   + 6.6 
```

#### [t-検定を行うためのソフトウェアマクロの実行](https://www.itl.nist.gov/div898/handbook/mpc/section5/mpc536b.dp)

```

let avgrun1 = average d1

let sdrun2 = standard deviation d2

print avgrun1 sdrun1 t1
```

#### 一貫性のない偏りの事例
データからは、両方の実行において、実行間で方向が変化する有意な配線偏りを明らかにしている。
この一貫性の欠如から、結果には「ゼロ」補正が適用され、タイプA 不確かさは 

$$\displaystyle \large{s_{correction} = \frac{1}{\sqrt{3}} 最大偏り}$$

本研究において、配線偏りのタイプA 不確かさは以下となる。 

$$\displaystyle \large{s_{correction} = \frac{1}{\sqrt{3}} 0.00489 \,\, \mbox{Ω.cm} = 0.0028 \,\, \mbox{ohm.cm}} $$

#### 一貫した偏りの事例
偏りが経時的に一貫性があっても、結果には「ゼロ」の補正が適用され、1回の実行について補正の推定標準偏差は 

$$\displaystyle \large{s_{correction} = \frac{1}{\sqrt{N}} s_{diff}}$$ 

2回の実行（1と2）について、補正の推定標準偏差は 

$$\displaystyle \large{s_{correction} = \frac{1}{\sqrt{2N}} \sqrt{ s_{{diff}_1}^2 + s_{{diff}_2}^2 }}$$

となる。
