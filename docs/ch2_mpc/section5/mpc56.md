# 2.5.6. 不確かさ予算と感度係数

#### [不確かさ予算を示す事例研究](../section6/mpc63.md)
不確かさ成分は、対応する感度係数、標準偏差、および自由度とともに表にまとめられている。
代表的な項目を記載した表がこの概念を説明している。

***不確かさ成分のタイプA および タイプB の典型的な予算***

| タイプA 成分 | 感度係数 | 標準偏差 | 自由度 |
| :---: | :---: | :---: | :---: 
| 1. 時間（繰り返し性） | $`a_1`$ | $`s_1`$ | $`\nu_1`$ |
| 2. 時間（再現性） | $`a_2`$ | $`s_2`$ | $`\nu_2`$ |
| 3. 時間（長期） | $`a_3`$ | $`s_3`$ | $`\nu_3`$ |
| タイプB 成分 | | | |
| 4. 参照標準 | (定格試験 / 定格参照)  | $`s_4`$ | $`\nu_4`$ |

#### 各成分が結果とどのように関連しているかを示す感度係数
感度係数は、試験項目報告値の標準偏差に対する個々の不確かさ成分の関係を示している。
感度係数は、報告される結果に関連するもので、不確かさを $`u`$ とした次式の不確かさ成分を推定する方法には関連しない。

$$u = \sqrt{\sum_{i=1}^R a_i^2 s_i^2}$$ 

#### 不確かさのタイプA に対する感度係数
この節では、反復測定から推定されたタイプA 成分に適した感度係数を定義する。
このページを読み進める前に、[タイプA 評価](mpc531.md)、特に[繰り返し性と再現性の成分の推定](mpc5311.md)に関連するページを確認しておくべきである。
本節における感度係数の表記法は以下の通り。

1. $`a_1`$ は繰り返し性標準偏差 $`s_1`$ の感度係数を指す
2. $`a_2`$ は再現性標準偏差 $`s_2`$ の感度係数を指す
3. $`a_3`$ は安定性標準偏差 $`s_3`$ の感度係数を指す

ここで、係数の一部はゼロとなることがある。

#### 長期誤差に関する注意事項
報告された値の決定に、日ごとの測定や実行ごとの測定が行われていなかったとしても、その標準偏差がデータの分析において有意と判明した場合は、感度係数はゼロではない。

#### 偶然誤差の他のタイプA 成分に対する感度係数
試験所において不確かさの無作為成分として扱われる[計測器間、作業者間などの差異を推定する手順](mpc5312.md)では、感度係数が 1 となるように補正の標準偏差を推定する方法を示している。

#### 偏りに対するタイプA 成分の感度係数
本ハンドブックは、ISO ガイドラインに従い、偏りを補正する（補正値はゼロの場合もある）ものとし、不確かさ成分は補正値の標準偏差とする。
[偏りに対処する手順](mpc533.md)では、感度係数が 1 となるように、補正値の標準偏差を推定する方法を示している。

#### タイプB 評価の感度係数
タイプB 評価における感度係数の大部分は、ごく一部の例外を除き、1 である。
参照標準の不確かさに対する感度係数は、試験対象の公称値を参照標準の公称値で割った値である。
