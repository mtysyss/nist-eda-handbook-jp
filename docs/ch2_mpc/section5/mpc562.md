# 2.5.6.2. 校正用標準試料を用いた測定における感度係数

#### 検査標準の測定値から
測定工程の時間に関する成分が[検査標準での測定値](../section1/mpc123.md)から評価され、**検査標準の測定値と同じ方法で構成された**試験対象物の $`M`$ 日（$`M = 1`$ も許容される）測定データの場合、報告値の標準偏差は

$$s_{reported \ value} = \frac{1}{\sqrt{M}} s_2$$

となり、検査標準データベース内の $`K`$ 個のデータから自由度は、$`\nu\_2 = K - 1`$ である。

#### 検査標準測定値からの標準偏差
検査標準値からの標準偏差の計算方法、および、計測器精度の成分や工程の日間変動との関連については、[検査標準値を用いた2階層枝分かれ設計](../section4/mpc432.md)の節で説明されている。

#### 感度係数
感度係数は、$`a\_1 = 0 ; \, a\_2 = \sqrt{\frac{1}{M}}`$ である。
