# 2.5.3. タイプA 評価

#### 誤差と偏りの両方に適用されるタイプA 評価
タイプA 評価は、偶然誤差と偏りの両方に適用できる。
唯一の要求事項は、不確かさ成分の計算をデータの統計的解析に基づくことである。
偶然誤差と偏りに関して留意すべき違いは、以下の通り。

* 偶然誤差は補正できない
* 偏りは、少なくとも理論上は、結果から補正または除去することができる。

#### 偏りに関する注意点
ISOガイドラインは、すべての偏りが補正され、この源に起因する不確かさは補正の不確かさのみであるという前提に基づいている。
[偏りのタイプA 評価](mpc533.md)に関する節では、偏りに関連する不確かさの評価、補正、および計算方法について指針を示している。

#### 異なる種類の分析が必要な偶然誤差と偏り
誤差源の報告値と不確かさの文脈に与える影響の仕方によって、偶然誤差の分析が適切か、あるいは偏りの分析が適切かが決まる。

ある試験所に類似するすべての計測器を代表すると合理的に想定できる複数の計測器があると仮定する。
その場合、不確かさ声明が、このバッチから無作為に選ばれた任意の計測器の結果に適用されることを意図しているならば、これらの計測器間の差異は無作為効果と見なすことができる。

一方、不確かさ声明が特定の1つの計測器に適用されることを意図している場合、その計測器が群全体に対して示す偏りが、注目すべき成分となる。
