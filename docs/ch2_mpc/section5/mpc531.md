# 2.5.3.1. 無作為成分のタイプA 評価

#### 無作為成分のタイプA 評価
不確かさのタイプA成分は、以下の3つの主な区分に分類される。

1. [時間の経過とともに明らかになる不確かさ](mpc5311.md)  
2. [特定の測定条件に起因する不確かさ](mpc5312.md)  
3. [材料の不均一性に起因する不確かさ](mpc532.md)

#### 偶然誤差の主な源である時間依存の変化
偶然誤差の最も重要な指標の一つは時間であり、その根本的な原因はおそらく時間の経過に伴う環境の変化にある。
本節では、[時間依存の影響の3階層](mpc5311.md)を検討する。

#### 試験所で測定を行うために考え得る様々な構成
不確かさの他の源は、試験所ないにおける測定の構成に関係している。
試験対象の測定は、通常、1日に、1人の担当者により、1台の計測器を用いて行われる。
不確かさの意図が、試験所内で行われる全ての測定を特徴づけることであるならば、不確かさは、以下の項目による差異を考慮に入れるべきである。

1. 測定器
2. 作業者
3. 幾何学上
4. その他

#### 研究室内における差異の原因の例
管理の行き届いた試験所内で生じる差異の原因の例としては、次のものがある。

1. 参照基準に対して直接的に構成できない計測器を用いるシリコンのシート抵抗など、派生単位での測定を行う計測器間の差異
2. 自動化されておらず、作業者の目視に強く依存する光学測定での作業者間の差異
3. 計測機器の幾何学的もしくは電気的構成における差異

#### この分類には含まれない校正済み計測器
計測器の校正に伴う不確かさはタイプB 評価として報告され、試験所内の計測器は校正不確かさの範囲内で一致しているはずであるため、通常、校正済みの計測器はこの分類には含まれない。
その応答が定義単位に対して直接校正されていない計測器は、タイプA 評価の対象である。
これは、測定が特定の計測器の種類を用いた試験手順や標準的な慣行によって定義されている状況を含む。

#### 不確かさの文脈によって異なる評価
これらの差異の扱い方は、主に不確かさ声明の文脈によって決まる。
文脈に応じこれらの差異は、[無作為な差異](mpc5312.md)として扱うか、あるいは[偏りによる差異](mpc533.md)として扱うことになる。

#### 不均一性による不確かさ
人工物、電気機器、化学物質などは、測定工程によって評価される量に関して不均一な場合がある。
この事実が事前に分かっているならば、特定の箇所で人工物を非常に慎重に測定し、その後、利用者に対してもその箇所で測定するよう指示することが可能である。
この場合では不均一性による測定不確かさへの寄与は生じない。

しかし、これが常に可能であるとは限らず、測定が破壊的である場合もある。
例えば、化学化合物の組成は容器ごとに異なることがある。
ロットの報告値が、そのロットから無作為に抽出した数本の容器に対する測定から決定される場合、このばらつきは不確かさ声明において考慮しなければならない。

[不均一性](mpc532.md)の検査方法および適切な不確かさの評価については、別のページで解説する。
