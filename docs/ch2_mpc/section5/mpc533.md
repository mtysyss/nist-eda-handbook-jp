# 2.5.3.3. 偏りのタイプA 評価

#### 具体的な測定環境に関連している偏り源
このページで論じている偏り源は、特定の測定構成に関するものである。
試験対象の測定は通常、1日で、1人の作業者が、1台の計測器を用いて行われる。
不確かさの意図が、特定の1つの構成下で行われた測定のみを特徴づけることであれ、不確かさには以下の要因による有意な差異を必ず考慮しなければならない。

1. 測定器
2. 作業者
3. 幾何学的条件
4. その他

#### この分類には含まれない校正済み計測器
測定器の校正に伴う不確かさはタイプB 評価として報告され、試験所内の計測器は校正不確かさの範囲内で一致しているべきであることから、通常、校正済みの測定器はこの分類には含まれない。
応答が定義された単位に対して直接校正されていない計測器は、タイプA 評価の対象となる。
これは、測定が計測器の特定種類を用いた試験手順または標準的な慣行によって定義される場合を含む。

#### 偏りを補正し、補正による不確かさを計算する最善の戦略
この問題は、不確かさがすべての構成におけるすべての測定に適用される場合における[偶然誤差の解析](mpc531.md)としてここ以前のページで扱われている。
特定の測定器を用いて行われた測定などの<u>ある特定の構成</u>での測定のみが対象となる場合、あるいは、より小さな不確かさが求められる場合、例えば計測器間の差異は、偏りとして扱われる。
この状況における<u>最善の戦略</u>は、特定の計測器で行われたすべての測定値を試験所内の計測器の平均値に対して補正し、その補正値に対してタイプA 不確かさを計算することである。
もちろん、この戦略は、試験所内の計測器が特定種類の計測器全てからの無作為標本であることを前提としている。

#### 潜在的偏り源間の限定的な比較
しかし、例えば、2つの計測器のみを比較することが可能であり、いずれも「不偏」であることが確認されていない場合を想定する。
このシナリオでは、平均値が必ずしも不偏な結果になるとは限らないため、異なる戦略が必要である。
計測器間に有意な差があり、これを検定する必要がある場合の最善の戦略は、「ゼロ」補正を適用し、その補正に対するタイプA 不確かさを評価することである。

#### 偏りの対処に関するガイドライン
以上の議論は、偏りには多くの考えられるシナリオがあり、それらをケースバイケースで扱うべきであることを指摘するものである。
以下について計画を立てる必要がある。

* データの収集
* 偏りの検定（グラフや統計的に）
* 偏りの推定
* 有意な偏りに伴う不確かさの評価

以下に因る場合。

* 計測器
* 作業者
* 構成、形状など
* 不均一性

#### 偏りを評価するための試験計画
例えば、計測器間の偏りを評価するために必要な測定では、利用可能な計測器の中から *I（I > 1）* を無作為に抽出し、各計測器を用いて *Q （Q > 2）* の試料を測定する必要がある。
他の偏り源についても、同様のことが言える。
有意な偏りに対処するための一般的な戦略を以下の表に示す。

#### 有意な偏りがないときの戦略
時間経過に伴う有意な偏りがなければ、補正は行われず、不確かさへの寄与も生じない。
