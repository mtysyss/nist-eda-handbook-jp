# 2.5. 不確かさ分析

#### 検査結果の「良さ」を示す不確かさ
この節では、測定結果の不確かさについて議論する。
不確かさは、結果の「良さ」を測る尺度である。
このような尺度がなければ、健康、安全、商業、あるいは科学的な卓越性に関する意思決定の根拠として、その値が適切かどうかを判断することは不可能である。
