# 2.5.3.1.2. 試験所内の測定構成

#### 本ページの目的
このページでは、試験対象を測定するための特定の測定構成に関連した不確かさを推定するための、他の考えられうる測定構成を考慮した選択肢を概説す。
これらの要因の中には制御可能なものもあれば、制御不可能なものもあり、次のようなものである。

* 計測器
* 作業者
* 温度
* 湿度

試験所における制御不能な環境条件の影響は、一定期間に渡り取得された校正標準のデータから推定できることが多く、他のページで[不確かさ成分の計算方法](mpc5311.md)を解説する。
特定の測定のために選択された作業者や計測器などの制御可能な要因に起因する不確かさについては、このページで解説する。

#### 最初の取組み：不確かさの背景の明確化
この手法は、主に不確かさ声明の文脈によって決まる。
例えば、計測器の影響に疑問があるとき、一つの対応として、試験所にある計測器を同じ種類の計測器器の無作為抽出として、特定の測定が行われた特定の機器に関係なく、すべての結果に適用される不確かさを計算する。
その他の対応としては、[特定の計測器を使用した結果](mpc533.md)に適用される不確かさを計算することである。

#### 次の取組み：差異の有無の評価
計測器を不確かさの無作為源として扱うには、まず、計測器に起因する差異が有意であるかを判断する必要がある。
これは、作業者などについても同様である。

#### データ収集計画
計測器に対する測定工程を評価するために、利用可能な計測器から、*I（I > 4）* の標本を無作為に選択する。
各計測器を用いて、*Q（Q > 2）* の人工物を測定する。

#### [計測器間の差異を示すグラフ](../section6/mpc615.md)
グラフによる分析では、各人工物における平均値からの偏差を人工物ごとにプロットし、各計測器を専用の標示記号で個別に識別する。
このグラフを検証し、一部の計測器が他の計測器に比べて常に高いもしくは低い値を示すか、またこの傾向が人工物間で一貫しているかを判断する。
計測器間で系統的かつ有意な差異が認められる場合、計測器に関するタイプA 不確かさを計算する。
[抵抗率プローブのグラフ](../section6/mpc615.md)では、例えばプローブ 4番と 5番の間で差異が見られ、他のプローブに比べて一貫して低い値を示している。
プローブ間の差異を表す標準偏差が、不確かさの構成要素として含まれる。

#### 計測機器の標準偏差
測定値が与えられたとき、 

$$\large{ Y_{11}, Y_{12}, \cdots, Y_{1I}, \cdots, Y_{Q1}, Y_{Q2}, \cdots, Y_{QI} }$$

*Q* 個の人工物と *I* 個の計測器それぞれについて、計測器間の差異を表す組み入れられた標準偏差は次式となる。

$$\large{ s_{inst} = \sqrt{\frac{1}{Q} \left( \frac{1}{I-1} \right)\displaystyle \sum_{q=1}^Q \sum_{i=1}^I(Y_{qi} - \overline{Y}_{q \scriptsize{\bullet}})^2} }$$

ここで 

$$\displaystyle \large{ \overline{Y}_{q \scriptsize{\bullet}}= \frac{1}{I} \sum_{i=1}^I Y_{qi} }$$

#### シリコン・ウェハの抵抗率測定例
5枚のウェハ（識別番号：138、139、140、141、142）上の5つのプローブによる[抵抗率測定値（Ω・cm）の2元表](https://www.itl.nist.gov/div898/handbook/datasets/MPC5312.DAT)を以下に示す。
