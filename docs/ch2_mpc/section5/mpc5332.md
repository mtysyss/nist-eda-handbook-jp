# 2.5.3.3.2. 一貫した偏り

#### 一貫した偏り
特定の計測器、作業者、または設定において、有意かつ長期に渡り一貫して持続する偏りは、反復測定から確実に推定できるのであれば、補正すべきである。
そして、対象の測定器による測定結果は、次式で補正する。

*補正後の結果 = 測定値 - 偏りの推定値* 

以下の例は、計測器 5台を用い、試験片 5片を測定した結果から、グラフ上でどのように特定し、各計測器間の差分を用いて偏りを推定するを示している。 

#### [プローブ 5番における一貫した偏りを示すグラフ](../section6/mpc615.md)
5つの測定器について、5つの試料の測定値に基づく偏りの分析では、具体的なプロット記号で識別された計測器ごとの人工物に対して、各人工物の平均値からの差異が示されている。
このプロットを検証し、ある計測器が他の計測器に比べて常に高い値または低い値を示すか、またこの挙動がすべての人工物で一貫しているかを判断する。
[抵抗率プローブのグラフ](../section6/mpc615.md)において、この測定工程での対象計測器であるプローブ 2362番（グラフ上の5番）が、他のプローブに比べて一貫して低い値を示していることに注目する。
この挙動は、2ヶ月間隔を空けて実施された2回の測定において一貫して見られる。

#### 戦略 - 偏りの補正
対象計測器には有意で一貫した偏りがあることから、その計測器による測定値は、他の計測器との比較での平均偏りを考慮して補正すべきである。

#### 偏りの計算
測定値が与えられたとき、

$$\large{ Y_{qi}(q = 1, \cdots, Q, \,\, I = 1, \cdots, I)$$

 *I* 台の測定器を用いて *Q* 個の人工物を測定した場合、例えば測定器 *I* の平均偏りは 
 
$#\displaystyle \large{\overline{B}_{I'} = \frac{1}{Q} \sum_{q=1}^Q \left(Y_{qI'} - \overline{Y}_{q \, \scriptsize{\bullet}} \right)$$

ここで、 

$$\displaystyle \large{ \overline{Y}_{q \, \scriptsize{\bullet}} = \frac{1}{I} \sum_{i=1}^I Y_{qi} \,\, . $$

#### 補正の計算
測定器 *I'* を用いて行われた測定値に対して行うべき補正は次式となる。

$$\large{Y_{corrected} = Y_{measured} - \overline{B}_{I'}}$$

#### 補正のタイプA 不確かさ
補正のタイプA 不確かさは、平均偏りの標準偏差、もしくは次式となる。

$$\displaystyle \large{s_{correction} = \frac{1}{\sqrt{Q}} s_{bias} =\frac{1}{\sqrt{Q}} \sqrt{ \frac{1}{Q-1} \sum_{q=1}^Q \left(Y_{qI'} - \overline{Y}_{q \, \scriptsize{\bullet}} - \overline{B}_{I'} \right)^2 }}$$

#### 計測器の偏りに対するさまざまな扱いに関する注記
このページの分析では、認定測定に1つの計測器器のみ、すなわちプローブ 2362番 を使用する場合を想定しており、認定値はこのプローブに起因する偏りについて補正されている。
[無作為効果のタイプA 分析](mpc5312.md)の節における分析では、認定測定にどのプローブでも使用できる場合を想定している。
