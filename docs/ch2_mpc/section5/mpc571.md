# 2.5.7.1. 自由度

#### 不確かさの各成分の自由度
タイプA 不確かさの自由度は、それぞれの標準偏差の自由度である。
タイプB 評価の自由度は、公表された報告書や校正証明書から得られる場合がある。
断片的なデータや科学的判断から標準偏差を推定しなければならない特殊な場合は、自由度が無限大であると仮定する。
例えば、

* 頑健度研究や他の証拠に基づく最悪状況の推定値
* 考えられる誤差分布に基づく推定
* 自由度が記載されていないタイプB 不確かさ成分

#### 標準不確かさの自由度
多くの標準偏差の組み合わせである標準不確かさ $`u`$ の自由度は、一般的に知られていない。
これは、自由度が小さい大きな不確かさの成分が存在する場合、特に問題にある。
この場合には、自由度を以下の Welch-Satterthwaite 式によって近似する（[Brownlee](../section7/mpc7.md#Brownlee)）。

$${\large \nu = \frac{u^4}{\sum_{i=1}^R \frac{a_i^4 s_i^4}{\nu_i}}}$$

#### 事例研究：[不確かさと自由度](../section6/mpc632.md#errorbudget)
[タイプA 不確かさ分析の事例研究](../section6/mpc63.md)では、不確かさの時間成分、計測器の偏り、幾何学的偏り、標準不確かさ、自由度、および拡張不確かさに関する計算を示している。
