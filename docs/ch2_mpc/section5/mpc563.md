# 2.5.6.3. 2階層設計の測定値に対する感度係数

#### 2階層設計の感度係数
時間に関する成分が [2階層枝分かれ設計](../section4/mpc43.md)から推定され、かつ試験対象の報告値がその測定値の以下の項目の平均である時、

* $`N`$ 回の短期反復
* $`M`$ 日（$`M = 1`$ も許容）

報告値の標準偏差は次式となる。

$$s_{reported \, value} = \sqrt{\frac{1}{M}s_{days}^2 + \frac{1}{MN} s_1^2}$$

標準偏差の定義およびそれぞれの自由度については、[2階層枝分かれ設計](../section4/mpc432.md)節の関係を参照のこと。

#### 自由度の推定に関する問題
報告値の不確かさに自由度が求められる場合、上記式をそのまま使用することはできず、標準偏差 $`s_1`$ および $`s_2`$ を用いて書き換えなければならない。

$$s_{reported \, value} = \sqrt{\frac{1}{M}s_2^2 + \frac{J-N}{MNJ} s_1^2}$$

#### 感度係数
感度係数は、$`a_1 = \sqrt{\frac{(J-N)}{MNJ}} ; \, a_2 = \sqrt{\frac{1}{M}}`$ である。

特定の $`N, \, M`$ に対する感度係数は、以下の表に示す。 

**不確かさの2成分に対する感度係数**

| 数値<br>短期<br>$`N`$ | 数<br>日間<br>$`M`$ | 短期<br>感度係数<br>$`a_1`$ | 日間<br>感度係数<br>$`a_2`$ | 
| :---: | :---: | :---: | :---: |
| 1 | 1 | $`\sqrt{(J-1)/J}`$ | 1 |
| $`N`$ | 1 | $`\sqrt{(J-N)/(NJ)}`$ | 1 |
| $`N`$ | $`M`$ | $`\sqrt{(J-N)/(MNJ)}`$ | $`\sqrt{1/M}}`$ |
