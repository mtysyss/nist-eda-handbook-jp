# 2.5.6.1. 試験対象の測定における感度係数

#### 試験対象自体のデータから
時間成分が、試験対象自体の *N* 個の短期測定値

$$Y_1, Y_2, \ldots , Y_N$$

から次式で推定され、

$$s_1 = \frac{1}{\sqrt{N-1}} \sqrt{\sum_{i=1}^N (Y_i - \bar{Y})^2}$$

報告値が平均値である場合、その報告値の標準偏差は以下となる。

$$ s_{reported \, value} = \frac{1}{\sqrt{N}} s_1 $$

ここで自由度は $`\nu_1 = N-1`$ である。

#### 感度係数
感度係数は $`a_1 = \sqrt{\frac{1}{N}}`$ である。
この方法を用いたリスクは、不確かさを著しく過小見積もりの可能性があることである。

#### 不確かさ計算の信頼性の改善
可能であれば、試験対象の測定値を *M* 日間に渡り繰り返し、その平均値を計算して報告値を推定すべきである。
報告値の標準偏差は日々の平均値から計算され、時間成分の標準偏差は次式となる。

$$s_{reported value} = \frac{1}{\sqrt{M}}\sqrt{ \frac{1}{M-1} \sum_{m=1}^M \left( \bar{Y}_{m \, \scriptsize{\bullet}} - \bar{Y}_{\scriptsize{\bullet \bullet}} \right)^2}$$

自由度は $`\nu_2 = M-1`$ であり、$`\bar{Y}_{m \, \scriptsize{\bullet}}`$ は日ごとの平均値、$`\bar{Y}_{\scriptsize{\bullet \bullet}}`$ は全期間の平均値である。

感度係数は $`a_1 = 0 ; a_2 = \sqrt{\frac{1}{M}}`$ である。 

#### 長期的誤差に関する注意事項
報告された値の決定に、日ごとの測定や実行ごとの測定が行われていなかったとしても、その標準偏差がデータの分析において有意と判明した場合は、感度係数はゼロではない。
