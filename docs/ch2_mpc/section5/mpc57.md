# 2.5.7. 標準不確かさと拡張不確かさ

#### 標準不確かさの定義
感度係数と標準偏差を二乗和の平方根を用いて組み合わせ、「標準不確かさ」を得る。
**R** 個の成分が与えられたとき、標準不確かさは次式となる。

$$u = \sqrt{\sum_{i=1}^R a_i^2 s_i^2}$$

#### 高い信頼性が確保された拡張不確かさ
不確かさ声明の目的が高い信頼度で網羅することである場合、拡張不確かさは次式で計算される。

$$U = k \cdot u$$

ここで、*k* は、[t-表](../../eda/section3/eda3672.md)から[自由度](mpc571.md) *ν* の $`t_{1-\alpha/2, \nu}`$ の境界値が選択される
自由度が大きい場合、$`k = 2`$ は 95% を網羅する。

#### 不確かさ声明の解釈
上記で定義された拡張不確かさは、対象となる測定値の未知の真値に対して高い網羅水準を提供すると仮定され、いかなる測定結果 *Y* に関して次式を満たす。

$$Y - U \le \mbox{真値} \le Y + U$$
