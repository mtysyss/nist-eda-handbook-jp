# 2.5.2.1. 手順

#### 不確かさ分析の手順 - 報告すべき結果を定義する
不確かさの評価における最初の手順は、不確かさの必要な試験対象に関する報告すべき結果を定義することである。
標準偏差の計算は、試験対象の反復数や、反復測定が行われた環境および操作条件の範囲に加え、最終結果に影響を与える参照標準の校正不確かさなどの他の誤差源にも依存する。
試験対象の値を直接測定できず、二次量の測定値を用いて計算しなければならない場合、各種の量を組み合わせるための式を定義する必要がある。
不確かさ分析において実施すべき手順は、以下2つの状況について概説している。

#### 単一量に関する不確かさ評価において実施すべき手順の概要
**A. 報告値が 1つの量に関する測定値を含む**
1. 以下の偶然誤差源について、タイプA 標準偏差を計算する。
    * [試験対象の反復測定結果](mpc561.md)  
    * [校正標準の測定値](mpc562.md)  
    * [2階層実験計画に従った測定値](mpc563.md)  
    * [3階層実験計画に従った測定値](mpc564.md) 
2. 収集したデータと解析が、以下のようなすべての偶然誤差源を網羅していることを確認する。
    * [計測器の精密さ欠如](mpc531.md)  
    * [日間変動](mpc531.md)  
    * [長期変動](mpc531.md)   
および以下の様な偏り  
    * [計測器間の差異](mpc533.md)  
    * [作業者による差異](mpc533.md) 
3. 不確かさの各[タイプB 成分](mpc54.md)について、標準偏差を計算する。
4. [感度係数](mpc56.md)を用いて、タイプA およびタイプB の標準偏差を組み合わせ、報告される結果の[標準不確かさ](mpc57.md)を計算する。
5. [拡張不確かさを計算する](mpc56.md)。

#### 複数の二次量を含む不確かさの評価における手順の概要
** B. 報告値が 1つ以上の量を含む**
1. 各量の関係を示す式を書く。
    * [誤差伝播](mpc55.md)式を書き出し、可能であれば、誤差伝播に基づいて予備評価を行う。
2. 測定結果が**直接反復可能な**場合は、個々の反復における二次量の数にかかわらず、不確かさの評価を上記の(A.1)から(A.5)と同様に扱い、その過程におけるすべての偶然誤差源を確実に評価する。
3. 測定結果を**直接反復できない**場合は、各測定量を(A.1)および(A.2)と同様に扱い、 
    * 各測定量について標準偏差を計算する。
    * 各測定量の標準偏差を[誤差伝播](mpc55.md)を用いて、報告される結果の標準偏差に統合する。
4. 各[不確かさタイプB 成分](mpc54.md)について、標準偏差を計算する。
5. タイプA およびタイプB の標準偏差を報告される結果の[標準不確かさ](mpc57.md)に統合する。
6. [拡張不確かさ](mpc57.md)を計算する。
7. 誤差伝播から導出された不確かさとデータ解析技法から導出された不確かさと比較する。
