# 2.5.4. タイプB 評価

#### 誤差と偏りの両方に適用されるタイプB 評価
タイプBの評価は、偶然誤差と偏りの両方に適用できる。
顕著な特徴は、不確かさ成分の計算がデータの統計的解析に基づかない点にある。
偶然誤差と偏りに関して留意すべき違いは以下の通り。

* 偶然誤差は補正できない
* 少なくとも理論上は、偏りを結果から補正または除去できる

#### タイプB 評価の源
タイプB 評価につながる不確かさの要因の例として以下がある。

* その他の試験所によって校正された参照標準
* 報告値の計算に使用された物理定数
* 標本抽出できない環境の影響
* 計測器の構成／幾何学的配置のずれの可能性
* 計測器の分解能不足

#### 他の工程に起因する不確かさの文書化された源
参照標準の校正報告書や物理定数の不確かさに関する公表報告書など、文書化された不確かさの情報源は、分析において何ら問題はない。
不確かさは通常、拡張不確かさ *U* として報告され、これは次式の標準不確かさである。

$$u = U/k$$

*k* 係数が不明または記載されていない場合、*k = 2* と仮定するのが保守的であると考えられる。 

#### 測定工程に固有の不確かさ源
測定工程に固有であるが、統計解析が可能なほど十分に標本を得ることができない不確かさの要因については、タイプB 評価が必要である。
広く用いられている技法の一つは、対象の源に対して、最悪の場合の影響量 *a* を次から推定する。

* 経験
* 科学的判断
* 不十分なデータ

影響が両側であると仮定した上で、標準偏差から考えられる影響の[一様分布](mpc541.md)、[三角分布](mpc541.md#triangular)、もしくは[正規分布](mpc541.md#normal)に基づいて計算する。

[測定の不確かさの表現に関する指針（GUM）](../section7/mpc7.md#GUM) に従い、この方法で導出された標準偏差には、**無限の自由度**を割り当てるのが慣例である。
