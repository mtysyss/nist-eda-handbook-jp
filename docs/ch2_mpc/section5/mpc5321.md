# データ収集と分析

#### このページの目的
このページでは以下の方法について概要する。

* データの収集
* 不均一性の検定
* 不確かさ成分の定量化

#### 2階層での釣合い型測定
測定結果の不均一性の影響を特定し、定量化する最も単純な手法は、釣合い型（各セルあたりの測定回数が等しい）の[2階層枝分かれ設計](../section4/mpc432.md)である。
例えば、あるロットから化合物の瓶 *K* 本を無作為に抽出し、瓶ごとに $`J(J > 1)`$ 回の測定を行う。
測定値は次式で表される。

$$\large{ Y_{11}, Y_{12}, \cdots, Y_{1j}; \, \cdots; \, Y_{k1}, Y_{k2}, \cdots, Y_{kj} }$$ 
 
ここで、添字 *k* は瓶、添字 *j* は瓶での反復である。 

#### 測定結果の分析
（瓶間の）分散は以下に示す[分散分析法](../section4/mpc432.md)を用いて計算され、手順を改めて以下に示す。

$$\large{ \displaystyle s_{inh}^2 = \frac{1}{K-1} \sum_{k=1}^K ( \overline{Y}_{k \scriptsize{\bullet}} - \overline{Y}_{\scriptsize{\bullet \bullet}} )^2 - \frac{1}{KJ(J-1)} \sum_{k=1}^K \sum_{j=1}^J ( Y_{kj}           - \overline{Y}_{k \scriptsize{\bullet}} )^2}$$

ここで

$$\large{ \displaystyle\\overline{Y}_{k \scriptsize{\bullet}} = \frac{1}{J} \sum_{j=1}^J Y_{kj} \}$$

また

$$\large{ \displaystyle\\overline{Y}_{\scriptsize{\bullet \bullet}}} = \frac{1}{K} \sum_{k=1}^K\overline{Y}_{k  \scriptsize{\bullet}} $$
 
#### 瓶間ばらつきが負の値の場合
分散が負の場合、不確かさへの寄与はなく、化学組成の関してこれらの瓶は同等である。
分散が正であっても、不均一性は依然として[統計的有意](../section3/eda354.md)ではない可能性があり、その場合は不確かさ成分として含める必要はない。

瓶間の分散が統計的に有意である場合（すなわち、ゼロより大きいと判断される場合）、不均一性は報告された値の不確かさに寄与する。 

#### 認証および報告値、関連する不確かさ
不均一性を評価する目的は数本の瓶の平均値に基づいてバッチ全体に値を割り当てられるようにすることであり、不均一性の判定は通常、認証法よりも精度の低い方法によって行われる。
バッチの報告値は、認定法を用いて***Q*本の瓶に対して*N*回繰り返した平均値**である。

不確かさの計算は、測定法自体からの不確かさへの寄与が、認定法に関連する繰り返し性標準偏差 ***s*1**のみである場合について、以下にまとめる。
より複雑なシナリオについては、[不確かさ予算](mpc56.md)に関するページを参照のこと。

もし $`\large{s_{inh}^2 \le 0 \Rightarrow s_{reported \, value} = \frac{1}{\sqrt{QN}} s_1}`$ 

もし $`\large{ s_{inh}^2 > 0 }`$ である場合、以下の2つの場合とその解釈を区別する必要がある。

1. 標準偏差<br><br>$$\displaystyle \large{ s_{reported value} =   \sqrt{ \frac{Q+1}{Q} s_{inh}^2 + \frac{1}{QN} s_1^2} }$$<br><br>は、報告値とバッチから無作為に選ばれた1本の平均値との差を網羅する区間を与える。
2. 標準偏差<br><br>$$\displaystyle \large{ s_{reported value} =  \sqrt{ \frac{Q+1}{Q} s_{inh}^2 + \frac{QN+1}{QN} s_1^2} }$$ <br><br>を用いることで、単一測定値を用いて計測器を検定する。
報告値と単一測定間の差異に関する予測区間は、バッチから無作為に選択された瓶について認定測定と同等の精度で行う。
これは、試験のための計測器が認定計測器と類似の場合に適している。
もしその差が区間内に収まらない場合、利用者の計測器は校正が必要である。 

#### 予測区間との関係
上記の最後の2例のように、不均一性の標準偏差を計算に含めると、不確かさの区間は<u>予測区間</u>となり（[Hahn & Meeker](../section7/mpc7.md#HahnMeeker)）、ロットから無作為に抽出した1本の瓶について、将来行われる測定値を特徴付けるものとして解釈される。
