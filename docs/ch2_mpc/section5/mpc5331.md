# 2.5.3.3.1. 一貫性のない偏り

#### 一貫性のない偏りに対する戦略――ゼロ補正の適用
有意な偏りがあるが、方向が経時で変化する場合、ゼロ補正を仮定し、補正値の標準偏差をタイプA 不確かさとして報告する。
すなわち、 

$$\displaystyle \large{s_{correction} = \frac{1}{\sqrt{3}} 最大偏り}$$

#### 一様分布もしくは正規分布に基づく計算
補正の標準偏差を推定する式は、偏りが {-|bias|の最大値, +|bias|の最大値} の間で[一様分布](mpc541.md#uniform)と仮定している。
この仮定はかなり保守的である。
これは、偏りが[正規分布](mpc541.md#normal)に従うという仮定よりも、より大きな不確かさを与える。
もし正規性がより妥当な仮定であるならば、上記の式において「3の平方根」を「3」に置き換える。

#### 経時的偏りの変化の例
5枚のシリコン・ウェハ上で5つのプローブを用いて行った比抵抗測定の結果を以下にプローブ 283番について示す。
プローブ 283番は、この水準において注目すべきプローブであり、人工物として 1Ω・cmのウェハが用いられている。
プローブ 283番の偏りは、2ヶ月の間隔を空けて実施された実行1 では負、実行2 では正となっている。
補正値はゼロとみなす。

```
    プローブ 283 の偏り (Ω.cm) の表
   ウェハ プローブ   実行 1       実行 2
   -----------------------------------
     11   283    0.0000340  -0.0001841
     26   283   -0.0001000   0.0000861
     42   283    0.0000181   0.0000781
    131   283   -0.0000701   0.0001580
    208   283   -0.0000240   0.0001879
    平均   283   -0.0000284   0.0000652
```

保守的な仮定として、偏りは範囲 ± a のどこかに収まると考えられる。
ここで、a = 最大偏り、もしくは 0.0000652 Ω・cm である。
補正の標準偏差は、不確かさのタイプ A 系統的成分として含まれる。

$$\displaystyle \large{s\_{correction} = \frac{1}{\sqrt{3}} MaxBias = 0.000038 \, \mbox{Ω・cm}}$$
