# 2.4.3. 時間に関連するばらつき源のデータ収集

#### 時間に関する分析
このページは、測定工程における時間依存効果を推定するためのデータ収集方法に関する選択肢のいくつかを示している。

#### 時間間隔
本節では、多くの測定システムの特性に基づき、以下の階層の時間依存誤差について検討し、必要に応じて具体的な測定状況に合わせて調整すべきである。

1. 階層1  ゲージの精度を把握するために短期間で行われる測定 
2. 階層2  数日（または他の適切な時間間隔）に渡って行われる測定
3. 階層3  数ヶ月間隔で実施される測定

#### 時間間隔
* [2階層偶然誤差に対する単純設計](mpc431.md)  
* [2階層偶然誤差に対する枝分かれ設計](mpc432.md)  
* [3階層偶然誤差に対する枝分かれ設計](mpc433.md)

いずれの場合も、データの収集と分析は明快であり、時間依存の誤差を扱う際に交互作用項を推定する理由はない。
ほとんどの測定システムを特徴付けるには、[2階層](mpc432.md)で十分である。
誤差源が十分に解明されておらず、これまで研究されたことのない測定システムについては、[3階層](mpc433.md)が推奨される。
