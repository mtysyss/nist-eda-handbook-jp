# 2.4.5.5. 幾何学/構成上の差異

#### 設定の差異への対処法
計測器における幾何学的形状や構成の違いを特定や対処する仕組みは、基本的に、それら[ゲージ間の違い](mpc454.md)に対処する場合と同じである。

#### 配線構成の違いの例
ひとつのゲージにおける構成の違いに関する研究の例を挙げる。
ゲージは、シリコン・ウェハの抵抗率を測定するための4点プローブであり、いくつかの配線方法が存在する。
ゲージ研究の間、すべての配線構成を試験することは不可能であったため、潜在的な問題を特定する手段として、2つの構成でのみ測定が行われた。

#### 配線構成に関するデータと2つの配線構成の違いを示すプロット

#### 構成間差異の検定
構成は2つのみであることから、*t*-検定を用いて両者に差があるかを判断する。 
もし

$${\large t} = \left| \frac{\sqrt{N}}{{\large s}_{diff}} \text{Avg}_{diff} \right| > 2$$

ならば、2つの構成間の差は統計的に有意である。
 
各実行における 29の差異から計算された平均値と標準偏差は、以下の表に *t*-値と共に示されており、両方の実行において差が有意であることを確認できる。

```
配線構成間における平均差異

 実行  プローブ    平均          標準偏差    N      t 

  1    2062   - 0.00383       0.00514    29   -4.0
  2    2062   + 0.00489       0.00400    29   +6.6
```

#### 予期せぬ結果
データから、実行間で方向の変化が示され、実行の両方において配線偏りが認められる。
これは多少懸念される結果であり、ゲージに関するさらなる研究が必要である。
配線構成が優先されたり、「正しい」結果をもたらすことが既知でもないため、これら差異は[測定の不確かさ](../section5/mpc53.md#change)の構成要素として扱う。
