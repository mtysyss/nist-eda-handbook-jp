# 2.4.4.2. 再現性の分析

#### 事例研究：[抵抗率計](../section6/mpc61.md)
日間のばらつきは、各検査標準ごとに個別のグラフで、日に対する[検査標準のグラフ](../section6/mpc614.md)（*J* 反復の平均）を作成し評価する。
測定状況の全体像を把握するためにすべての検査標準のグラフを同一ページにプロットすべきである。

#### より信頼できる推定値を得るための組入れ
自由度 (*K*- 1) の[階層2 標準偏差](mpc44.md)は日の検査標準値から計算し、以下の表に示すように、各実行を組み入れる。
組入れ階層2 標準偏差は、以下によって行われ、自由度は*L*(*K*- 1)となる。

* *K* 日
* *L* 実行

#### 組入れの仕組み
以下の表は、各実行の階層2 標準偏差の組入れの仕組みを示している。
組み入れられた値は加重分散の平均であり、表の右端の列の最後の項目として示されている。
必要に応じて、この組入れに検査標準も含める。

この表は、1つの検査標準（140番）とプローブ（2362番）について、6日間に渡り枝分かれ設計で収集された[データの部分集合](mpc441.md)（前ページに示した）を使用して作成された。
データは日間効果について分析している。
実行1 および 2 における階層2 標準偏差および組み入られた階層2 標準偏差は以下の通り。

**実行を組み入れた1ゲージの階層2 標準偏差**

| ばらつき源 | 標準偏差 | 自由度 | 平方和<br>(SS) |  
| :-----: | :-----: | :-----: | :-----: |  
| 日 | $`{\large s}_{2i}`$ | $`\nu_i`$ | $`SS_i=\nu_i {\large s}_{2i}^2`$ | 
| 実行1<br>実行2<br><br>合計<br>組入済値<br>$`{\large s}_2=\sqrt{\sum{SS_i} / \sum{\nu_i}}`$ | 0.027280<br>0.027560<br><br><br><br> | 5<br>5<br>------<br>10<br><br> | 0.003721<br>0.003798<br>------<br>0.007519<br>0.02742 |

#### 日効果との関係
階層2 標準偏差は、日間の精度およびゲージの精度に関する標準偏差と以下の式で関係付けられる。

$${\large s}\_{days} = \sqrt{ {\large s}\_2^2 - \frac{1}{J} {\large s}\_1^2}$$

他の2つの標準偏差が確実に推定されれば、上式を用いて引き算を行うことで、日効果の大きさが計算できる。

#### 日に関する分散成分の計算
この例では、日間の分散成分は -0.00028072 である。
分散の値が負であることは、日間の分散成分がゼロであることを意味する。
しかし、階層2 標準偏差の自由度がわずか10であることから、この推定値は必ずしも信頼できるものではない。
データベース全体における[日間標準偏差](../section6/mpc63.md#day)は、日間の有意な成分を示している。
