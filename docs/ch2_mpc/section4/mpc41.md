# 2.4.1. 重要な課題

#### 基本的課題
研究における基本的な課題は、特定の環境下における以下に関するゲージの挙動である。

* [繰り返し性](mpc441.md)  
* [再現性](mpc442.md)  
* [安定性](mpc443.md)  
* [偏り](mpc45.md)  

#### 戦略
戦略は、類似したゲージの挙動を検証する研究を実施・分析し、以下の点を確認することである。

* 異なる精度水準を示すか。  
* 同一環境下で計測器が同等の結果を示すか。  
* 同一環境下で作業者が同等の結果を示すか。  
* 個々の測定器の応答が、構成や形状の変更、あるいは設定手順の変更の影響を受けるか。  

#### 他の目標
他の目標は以下の通り。

* [計測器の分解能の検定](mpc451.md)  
* [ゲージの直線性の検定](mpc452.md)  
* [各ゲージ間の差異の推定(偏り)](mpc454.md)  
* [形状、構成による差異の推定](mpc455.md)  
* [作業者偏りの推定](mpc456.md)  
* [不確かさ予算への知見の組込み](mpc46.md)
