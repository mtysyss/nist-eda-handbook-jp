# 2.4.5.3. 偏位

#### 定義
偏位とは、（[VIM](../section7/mpc7.md#VIM)）において、ゲージの応答が徐々に変化することと定義される。

#### 校正用比較器として使用される計測器
比較器測定では、短期偏位が問題となることがある。
その原因は、多くの場合、測定中に計測器内の発熱にある。
ゲージ研究を用いてこのような偏位の程度を特定しようとすることは困難であり、おそらく非生産的である。
最も簡単な解決策は、校正データの収集に[偏位のない設計](../section3/mpc3312.md)を採用することである。
この設計により、結果に対する線形偏位の影響を軽減できる。

偏位は校正設計間で一定であり差分測定において相殺されるため、比較器による測定において、長期偏位は問題にならないはずである。

#### 直線校正により補正された計測器
直線検量線によって測定値が補正される測定器おいて、[管理図技法](../section3/mpc37.md)と、3つ以上の検査標準を用いた測定により、偏位を検出することができる。

#### 直読式計測器における偏位と不確かさ解析
他の測定器では、あらかじめ設定された期間（例えば1か月）に渡り、2つ以上の検査標準を用いて毎日測定を行う。
これらの測定結果を時間軸上にプロットし、偏位の程度や性質を特定するために用いる。
偏位が同じ速度・同じ方向で長期間にわたって止まることなく続くことはめったにない。

したがって、このような実験から期待されるのは、所定の期間中に発生しうる最大変化量を文書化し、計測器の調整計画を立てることである。
得られた知見のさらなる意義は、補正されていない偏位は不確かさ解析において[タイプA成分](../section5/mpc53.md)として扱うことである。
