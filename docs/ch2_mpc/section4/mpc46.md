# 2.4.6. ゲージ研究に基づく不確かさの定量化

#### 不確かさ評価の基礎として活用するゲージ研究
ゲージ研究を行う理由の一つは、実際の測定条件下では定量化が困難な測定工程における[不確かさ](../section5/mpc5.md)を定量化することにある。

この手法は、その結果が実作業環境における測定工程を真に代表する場合には妥当なものである。
すべての誤差源、特に短期間の実行では現れない誤差源に関して十分に考慮すべきである。 

#### この手法における潜在的な問題点
この手法の潜在的な問題は、不確かさの計算が完全にゲージ研究に依存している点にある。
もし測定工程の特性が時間の経過とともに変化した場合、ゲージ研究から得られた標準偏差は、不確かさ分析において正しい標準偏差とはならない。
このような問題を回避する一つの方法は、不確かさを直腸づけるための測定の前後でゲージ研究を実施することである。
「前」と「後」の結果から、その間に測定工程が変化したかを判断できるはずである。

#### 不確かさ分析に必要な具体的測定に関する情報
不確かさの計算方法は、対象となる特定の測定によって異なる。
ゲージ研究では、データを収集し、測定結果の不確かさに寄与する源それぞれの標準偏差を推定する。
しかし、これら標準偏差を測定結果の標準偏差と関連付けるには、特定の計算式が必要である。

#### 偏り - 経験則
偏りに対する手法は、ゲージ研究から最大偏りを推定し、[適切な分布の仮定](../section5/mpc541.md#normal)した最大偏りから標準不確かさを計算する。
以下の式では、各偏りについて一様分布を仮定している。

#### [分解能の決定](mpc451.md)
ゲージの分解能が $`\delta`$ とすると、分解能の標準不確かさは次式となる。

$${\large s}_{resolutioni} = \delta / \sqrt{3}$$

#### [非直線性の決定](mpc452.md)
もし、ゲージの直線性からの最大逸脱がゲージ研究により決定され、かつ、試験範囲内の任意の点においてゲージが作動する確率を等しいと仮定することが妥当であるならば、直線性の標準不確かさは次式となる。

$${\large s}_{linearity} = \mbox{Max} \left| Y_{observed} - Y_{fitted} \right| / \sqrt{3}$$

#### 履歴効果
性能仕様としての履歴効果は、（[NCSL RP-12](../section7/mpc7.md#NCSL)）において、同じ人工物を用いた双方向全範囲走査時の尺度上昇と下降における読み値の最大差異として定義される。
履歴効果の標準不確かさは次式となる。

$${\large s}_{hysteresis} = \mbox{Max} \left| Y_{upscale} - Y_{downscale} \right|  / \sqrt{3}$$

#### [偏位の決定](mpc453.md)
直読式計測器の偏位は、対象とする特定の時間間隔において定義される。
偏位の標準不確かさは

$${\large s}_{drift} = \mbox{Max} \left| Y_0 - Y_t \right| / \sqrt{3}$$

となり、ここで、$`Y_0`$ および $`Y_t`$は、それぞれ時刻 0 および時刻 $`t`$ における測定値である。
