# 2.4.5.4. ゲージ間の差異

#### 目的
ゲージ研究では、ゲージ同士が互いに一致しているか、またその一致（あるいは不一致）が、人工物や時間に渡り一貫しているかを取り扱うすべきである。

#### データ収集
本研究の対象となる各ゲージについて、分析には以下の測定値が必要である。

* *Q*（*Q* > 2）個の検査標準
* *K*（*K* > 2）日

測定は、1人の作業者によって行われるべきである。

#### データの集約
分析の手順は以下の通り。

1. 測定値は、人工物／ゲージ構成ごとに日単位で平均化する。
2. 各人工物について、ゲージごとの平均値を計算する。
3. その後、各ゲージについて、平均値からの偏差を計算する。
4. 設計が[3階層設計](mpc433.md) として実行した場合、統計量は各実行ごとに個別に計算する。

#### ゲージ研究のデータ
以下の表のデータは *K* = 6 日の間に *Q* = 5 の試料について行った抵抗率（Ω・cm）測定結果に基づくものである。
測定は約1ヶ月の間隔を空けて2回実施された。
人工物はシリコン・ウェハであり、ゲージはシリコン・ウェハーの抵抗率測定用に特別に設計された4点プローブである。
表には、ウェハの平均値からの偏差が示されている。

#### [各プローブ間差異のプロット](../section6/mpc615.md)
ゲージ間差異の検出には、差異を一覧表で示すよりも、グラフを用いた分析の方が効果的である。
差異を人工物の識別情報に対してプロットし、各計ゲージをそれぞれ異なるプロット記号で識別する。
解釈を容易にするために同一のゲージを表す記号同士を点線で結ぶ。

#### 解釈
プロットは各人工物ごとの平均値からの差異を示しているため、中心線はゼロの線となり、その差異は偏りの推定値である。
他のゲージよりも*一貫して*上下にあるゲージは、平均値に対するそれぞれ偏りは高いもしくは低いと言える。
特定ゲージの偏りに対する最良の推定値は、*Q* 個の人工物に対するその平均偏りである。
このデータ集合では、プローブ 2362番が他のプローブに比べて一貫して低偏りであることに注目されたい。

#### ゲージ間差異への対処戦略
ゲージが同種のゲージの無作為抽出であるならば、どのような状況においても、最良の推定値は全ゲージの平均値である。
しかし、通常の生産現場や計測の環境では、特定の部品に対して1つのゲージで測定を行うことしか現実的でない場合がある。
その場合、ゲージ間の差異に対処するには2つの方法がある。

1. 特定のゲージを用いて行った各測定値をそのゲージの偏り分だけ補正し、[タイプA不確かさとしての補正値の標準偏差](../section5/mpc5332.md)として報告する  
2. 各測定値をそのまま報告し、[ゲージ間差異に対するタイプA不確かさ](../section5/mpc5312.md)を評価する。
