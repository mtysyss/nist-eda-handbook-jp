# 2.4.3.1. 単純設計

#### 時間と資源の制約
ゲージ研究計画において、特に初めて計画を立てる場合は、まずは単純な設計から始め、データ収集や分析の経験をある程度積んでから、より複雑で手間のかかる設計へと進めることが望ましい。
ここで推奨する設計は、時間の経過に伴う測定工程のばらつきに関する予備的研究に適している。
これには、約1ヶ月間隔で 1日 2回、計 2日間の測定が必要である。

#### 2段階および3段階の枝分かれ設計との関係
この設計の欠点は、経時的なばらつきを推定するためのデータが極めて少ない点である。
経時的な測定を必要とする [2階層枝分かれ設計](mpc432.md)および [3階層枝分かれ設計](mpc433.md)は、他のページで解説する。

#### 行動計画
測定法に対する期待される応答が実質的に同一である、少なくとも $`Q = 1 `$ 個の被測定物または検査標準を選択する。
同じゲージを用いて各検査標準の2回測定を行うが、そのときに検査標準の測定順序を無作為にするよう注意する。

約1か月後、測定手順を繰り返し、検査標準の測定順序を改めて無作為に設定する。 

#### 表記
検査標準の測定値は、次のように表記する。

$$
\begin{array}
Y_{11}, & Y_{12} \\
Y_{21}, & Y_{22}
\end{array}
$$

ここで、最初の添字は測定月を、2番目の添字は測定回数を表す。

#### データの分析
ゲージの基本的な精度を表す階層1 の標準偏差は、次式で表される。

$$s_1 = \sqrt{\frac{1}{4Q}\sum_{i=1}^{Q}{\{(Y_{11} - Y_{12})^2 + (Y_{21} - Y_{22})^2\}}}$$

ここで、自由度は $`\nu_1 = 2Q`$ である。

階層2 の標準偏差は、測定工程の経時的なばらつきを表し、

$$s_2 = \sqrt{\frac{1}{Q}\sum_{i=1}^{Q}{\left\{ \frac{(Y_{11} + Y_{12}) - (Y_{21} + Y_{22})}{2} \right\}^2}}$$

ここで、自由度は $`\nu\_2 = Q`$ である。 

#### [試験対象の不確かさ](../section5/mpc56.md)との関係
試験対象の 1回測定における不確かさを定義する標準偏差は、しばしば再現性標準偏差（[ASTM](../section7/mpc7.md#ASTM)）と呼ばれ、次式で与えられる。

$${\large s}_R = \sqrt{{\large s}_{days}^2 + {\large s}_1^2} = \frac{{\large s}_2}{\sqrt{2}}$$

時間依存成分は次式となる。

$${\large s}_{days} = \sqrt{\frac{1}{2} {\large s}_2^2 - {\large s}_1^2}$$

測定工程には他にも不確かさ源が存在することがあり、これらは正式な、[不確かさの解析](../section5/mpc5.md)において考慮されなければならない。
