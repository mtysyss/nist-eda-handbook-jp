# 2.4.5. 偏りの分析

#### 偏りの定義
本ハンドブックにおいて、「偏り」と「系統誤差」は同じ意味で用いている。
偏りとは（[VIM](../section7/mpc7.md#VIM)）、測定結果とその未知の「真値」との差として定義される。
多くの場合、参照標準を用いた校正により、その値の推定や除去を行う。

#### 想定される問題
校正とは、理想的な環境下における出力と「真値」とを関係付けることである。
しかし、それだけでは、ゲージが実際の使用環境において適切に動作することを保証するものではない。
温度、湿度、作業者、摩耗、他の要因によって、測定値に偏りが生じることがある。
この問題に対処する唯一の方法はないが、ゲージ研究は測定工程における偏りを明らかにすることを目的としている。
