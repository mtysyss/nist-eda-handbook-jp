# 2.4.3.2. 2階層枝分かれ設計

#### 時間依存ばらつき源の推定のための検査標準の測定値
経時的に顕在化するばらつき源の影響を研究するには、[検査標準](../section1/mpc12.md)を用いた測定が推奨される。
データの収集と分析は明快であり、時間依存の誤差を扱う際に交互作用項を推定する理由はない。
測定は、以下の2つのレベルのうちいずれかで行えばよい。
ほとんどの測定システムを特徴付けるには、2階層で十分である。
誤差源が十分に解明されておらず、これまで研究されたことのない測定システムについては、[3階層](mpc433.md)が推奨される。

#### 枝分かれ設計における時間間隔
以下の階層は、多くの測定システムの特性に基づき、必要に応じて具体的な測定状況に合わせて調整すべきである。

* 階層1  ゲージの精度を推定するために短期間で行われる測定
* 階層2  数日（他の適切な時間間隔）に渡り行われる測定

#### 各水準における測定回数の定義
本章では、以下の記号を定義する。

* 階層1  *J (J > 1)* の反復
* 階層2  *K (K > 2)* 日

#### 測定スケジュール
検査標準測定を一定期間（1日1回、週2回、あるいはあらゆる測定条件を網羅するのに適切な頻度）に渡って実施するスケジュールを策定し、これを遵守すべきである。
検査標準測定は、試験対象の報告値と同様の方法で構成されるべきである。
例えば、報告値が5分以内に実施された2回の反復測定の平均値である場合、検査標準値も同様に、同じ方法で実施された2回の測定の平均値とするべきである。

#### 例外
この規則の例外として、1日あたり少なくとも $`J = 2`$ 回の繰り返し測定を行う必要がある、といった点が挙げられる。
この冗長性がなければ、測定システムの短期的精度を確認する手段がない。

#### 作業者に関する注意事項
測定は、**1人** の作業者が行うべきである。
自動化システムの場合、通常、作業者の要因は考慮されない。
ただし、線状の境界やその他の特徴の境界に関する判断を必要とするシステムでは、作業者によって結果が左右されることがある。

#### 事例：[抵抗率測定](../section6/mpc62.md)
関連する環境測定値や重要な要因の識別情報とともに、[結果を記録すべきである](../section1/mpc122.md#file)。
この情報を記録する最善の方法は、各検査標準測定について、固定された列に1行（表では行）の情報を記載した単一のファイルに記録することである。

#### ゲージ精度のデータ解析
検査標準測定値は、

$$Y_{kj}(k=1, \ldots, K, \quad j=1, \ldots, J)$$

で表され、これは *k* 日目、*j* 回目の測定値である。
*k* 日目の平均は

$$\overline{Y}_{k \small{\bullet}} = \frac{1}{J}\sum_{j=1}^{J} Y_{kj}$$

であり、自由度 $`\nu = J -1`$ を持つ測定精度の（階層1）標準偏差は次式となる。

$${\large s}_k = \sqrt{\frac{1}{J-1} \sum_{j=1}^{J} ( Y_{kj} - \overline{Y}_{k \small{\bullet}} ) ^2} \quad .$$

#### 標準偏差推定値の信頼性向上のための組入れ
自由度 $`\nu = K(J-1)`$ の組み入れられた階層1 標準偏差は次式となる。

$${\large s}_1 = \sqrt{\frac{1}{K} \sum_{k=1}^{K} {\large s}_k^2}$$

#### 工程のデータ分析（階層2）の標準偏差
検査標準の階層2 標準偏差は、工程のばらつきを表す。
これは、自由度 $`\nu = K - 1`$を用いて次式で計算する。

$${\large s}_{chkstd} = {\large s}_2 =\sqrt{\frac{1}{K-1} \sum_{k=1}^{K} \left(\overline{Y}_{k \small{\bullet}} - \overline{Y}_{\small{\bullet} \small{\bullet}} \right) ^2}$$

ここで

$$\overline{Y}_{\small{\bullet} \small{\bullet}} = \frac{1}{K} \sum_{k=1}^{K} \overline{Y}_{k \small{\bullet}}$$

#### [試験対象の不確かさ](../section5/mpc56.md)との関連性
試験対象の 1回測定での不確かさを定義する標準偏差は、しばしば再現性標準偏差（[ASTM](../section7/mpc7.md#ASTM)）と呼ばれ、次式で与えられる。

$${\large s}_R = \sqrt{{\large s}_{days}^2 + {\large s}_1^2} = \sqrt{{\large s}_2^2 + \frac{J-1}{J} {\large s}_1^2}$$

測定工程には他の不確かさ源が存在することがあり、それらを正式な[不確かさの解析](../section5/mpc5.md)において考慮しなければならない。
