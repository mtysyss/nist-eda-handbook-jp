# 3.2.4. 離散モデル

#### 説明
連続データよりもむしろ離散データの分析に直面する場面は数多くある。
その例として、歩留まり（良品／不良品）、速度区分（遅い／速い／さらに速い／最も速い）、調査結果（賛成／反対）などが挙げられる。
そこで、離散的や連続的な説明変数の組み合わせを用いて、これらの離散的な結果を説明しようとする。
このような状況では、これまで学んできたモデル化技法（CLMやANOVA）はもはや適切ではない。

#### 分割表分析と対数線形モデル
離散的な応答データの分析には、主に2つの方法がある。
1つ目は、説明変数と応答変数の両方が離散的な場面で分割表分析として知られている。
このモデルについては、本節で詳しく解説する。
2つ目のモデルは、説明変数が離散型と連続型の両方の場合に適用され、対数線形モデルと呼ばれる。
このモデルについては本ハンドブックの範囲外であるが、関心のある読者は本章の[参考文献節](../ppcref.md)を参照し、この話題に関する有用な書籍の一覧を確認のこと。

#### モデル
2つの基準A と B に基づいて分類する *n*人の個人がいると仮定する。
基準A の *r*水準と基準B の *s*水準を仮定する。
これらの応答は、$`r × s`$ 表で示すことができる。
例えば、良品か不良品かに分類する生産された部品の入った箱があり、それらが供給業社 1、2、3 のいずれから供給されたかを分類すると仮定する。

ここで、この表の各セルは区分水準の特定の組合せに区分される個人の計数である。この計数を $`N_{ij}`$ とする。これら全ての計数の合計は、個人の全数 N と等しくなる。
また、表の各行は $`N_{i \cdot}`$ の合計、各行は $`N_{\cdot j}`$ の合計である。

2つの分類変数間に相互作用がないという仮定（例えば、良品や不良品の数は供給元によって決まるわけではない）の下、各セルで期待される数を計算する。
任意のセル $`E_{ij}`$ を期待される計数と呼ぶことにする。
そして、セルの期待値は $`E_{ij} = N_{i \cdot} * N_{\cdot j}/N`$ となる。
次にすべきことは、期待される数と観測された数を比較する。
観測された数と期待値の間に大きな差がある場合、2つの変数は何らかの形で交互作用している。

#### 推定
推定の手順は非常に簡単である。
必要なのは、観測された数から表を作成し、前述のように期待数を計算する。

#### 検定の内容
この検定は、以下の式に従ってカイ二乗適合度検定を用いて行う。

$$\chi^2 = \sum{\sum{\frac{(\text{観測値} - \text{期待値})^2}{\text{期待値}}}}$$

ここで、表内のすべてのセルに渡り和を計算する。 

以下に記述される前提条件が与えられたとき、この統計量はほぼカイ二乗分布であり、したがって、以前に定義した *r* と *s* の自由度 $`(r-1)(s-1)`$ を持つカイ二乗表と比較する。
検定統計量の値が、ある信頼水準に対するカイ二乗値よりも小さいとき、分類変数は独立と宣言され、そうでなければ依存性があると判断する。

#### 前提条件
上記の推定および検定結果は、標本モデルがポアソン分布、多項分布、あるいは積多項分布のいずれであるかに拘わらず成り立つ。
いずれかのセルの計数が少ない場合、例えば ＜5、カイ二乗検定の結果は機能しない。

#### 用途
分割法は、実際には、離散的な応答変数に対する離散的な説明変数間の交互作用を検定する手法に過ぎない。
以下に示す例は2つの要因に関するものである。
この手法はより多くの要因に対しても同様に適用可能であるが、他の交互作用と同様に、要因が増えるにつれて結果の解釈は難しくなる。

#### 例
2つの生産工程の歩留まりの比較を想定する。
ある一つの工程の歩留まりがより高いかを知りたい。

#### カイ二乗統計量の計算と表の値との比較
カイ二乗統計量は 1.276 である。
これは、自由度 1、信頼水準 90% におけるカイ二乗値 2.71 より小さい。
したがって、工程の歩留まりに（有意な）差はないと結論付ける。

#### 結論
したがって、これら2つの工程間には統計的に有意な差はないと結論づける。
