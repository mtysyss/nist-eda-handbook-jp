# 3.2.1. 一般的な前提条件

#### 前提条件：工程は系統的成分と無作為成分の和である
本節で説明するモデル化技法を適用するためには、対象とする工程についていくつかの仮定を置く必要がある。
まず、その工程を系統的成分と無作為成分の和として適切にモデル化できると仮定しなければならない。
系統的成分は数学的モデルの部分であり、無作為成分は系に存在する誤差やノイズである。
また、系統的成分は運転条件の範囲に渡り一定であり、無作為成分の位置、広がり、分布の形が一定であると仮定する。

#### 前提条件：これらのモデルを近似するために用いられたデータはモデル化される工程を代表する
最後に、これらのモデルを近似するために用いられるデータは、モデル化の対象となる工程を代表すると仮定する。
その結果、データを収集するために使用される測定システムについて、調査が行われ、所望の精度と正確さで測定が可能であることが実証されていると、仮定しなければならない。 
そうでない場合は、本ハンドブックの[測定能力の節](../../ch2_mpc/mpc.md)を参照のこと。
