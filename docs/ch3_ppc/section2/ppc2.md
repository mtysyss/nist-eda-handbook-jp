# 3.2. 前提条件／必要条件

#### 主な目的：ばらつき源の特定と定量的把握
PPCの主な目的は、ばらつき源を特定し、定量化することである。
これを行って初めて、ばらつきの低減と工程改善に向けた効果的な計画を策定することができる。
場合によっては、この目標を達成するために、まず工程の数学的・統計的モデルを構築する必要がある。
これらのモデルにおいて、影響を与える要因と、それらが影響を及ぼす応答を特定する。
これらのモデルを用いて、ばらつき源が重要な要因によってどのように影響を受けるかを理解する。
この小節では、これらの課題を達成するために利用可能な多くのモデル化手法について概説する。
特に、この節で取り上げるモデルは、線形モデル、分散分析（ANOVA）モデル、および離散モデルである。
