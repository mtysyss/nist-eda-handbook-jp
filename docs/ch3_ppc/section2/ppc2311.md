# 3.2.3.1.1. 一元値分割

#### 例
加工例のデータを用いて、値分割という手法を用いて各データ値をその構成要素に分解する方法を説明する。
構成要素が分かれば、平方和を計算し、検定のF値を計算するのは極めて簡単な作業となる。 

| 機械 | | | | |   
| :--: | :--: | :--: | :--: | :--: |  
| 1 | 2 | 3 | 4 | 5 |  
| .125 | .118 | .123 | .126 | .118 |  
| .127 | .122 | .125 | .128 | .129 |  
| .125 | .120 | .125 | .126 | .127 |  
| .126 | .124 | .124 | .127 | .120 |  
| .128 | .119 | .126 | .129 | .121 |  

読者は、データを[テキストファイル](https://www.itl.nist.gov/div898/handbook/datasets/CHARACTERIZE-3_2_3_1.DAT)としてダウンロードできる。 

#### 水準平均の計算
モデル、$`y_{ij} = m + a_{i} + \epsilon_{ij}`$ からわかるように、各観測値は、共通値、水準効果、および残差の和である。
値分割とは、各観測値をその構成要素に分解するだけである。
値分割の最初の手順は、各機械内の平均値（千分の一の桁まで四捨五入）を計算し、水準ごとの平均値を求める。

| 機械 | | | | |   
| :--: | :--: | :--: | :--: | :--: |  
| 1 | 2 | 3 | 4 | 5 |  
| .1262 | .1206 | .1246 | .1272 | .123 |  

#### 水準平均での掃き出し
次に、元のデータ表に対して平均値を<u>掃き出す</u>（各関連データ値からその水準の平均値を引く）ことで、残差を求める。

| 機械 | | | | |   
| :--: | :--: | :--: | :--: | :--: |  
| 1 | 2 | 3 | 4 | 5 |  
| -.0012 | -.0026 | -.0016 | -.0012 | -.005 |  
| .0008 | .0014 | .0004 | .0008 | .006 |  
| -.0012 | -.0006 | .0004 | -.0012 | .004 |  
| -.0002 | .0034 | -.0006 | -.0002 | -.003 |  
| .0018 | -.0016 | .0014 | .0018 | -.002 |

次の手順は、各機械の平均値から総平均を次のように計算する。

| 全体平均 |  
| :---: |  
| .12432 |  

#### 水準平均から全体平均を掃き出し
最後に、全体平均を個々の水準平均から掃き出し、水準効果を求める。

| 機械 | | | | |   
| :--: | :--: | :--: | :--: | :--: |  
| 1 | 2 | 3 | 4 | 5 |  
| .00188 | -.00372 | .00028 | .00288 | -.00132 |  

総平均、機械効果、適切な残差を加算し元のデータ表の構築を簡単に検証する。

#### ANOVA値の計算
データ値の分割と重ね合せの作成が完了したところで、次の手順として、[一元配置分散分析](ppc231.md#anova)表の各種値を計算する。
各重ね合せについて計算する値は3つある。
それらは、平方和、自由度、平均平方である。

#### 平方和の合算
総平方和は、すべてのデータ値の平方を合計し、そこから全平均の平方にデータ値の総数を掛けた値を差し引き計算する。
通常、総平方和の平均平方はどの統計的検定においても使用されないため計算しない。

#### 残差平方和、自由度、平均平方
残差平方和は、残差値の平方の合計によって計算する。
その値は 0.000132 である。
自由度は、制約を受けていない値の数である。
因子の各水準における残差の合計はゼロでなければならないため、そのうちの4つが分かれば、残りの1つが決定される。
つまり、各水準につき 4つの制約のない値があり、自由度は 20 となる。
これにより、平均平方の値は 0.000007 となる。

#### 水準平方和、自由度、平均二乗
最後に、各水準の平方和を求めるために、水準効果の重ね合せに含まれる各値の平方を合計し、その合計値に各水準の観測値の数（この場合は5）を乗じると、値は 0.000137 となる。
水準平均からの偏差の合計はゼロにならなければならないため、制約のない値は 4つしかなく、したがって水準効果の自由度は 4 となる。
これにより、平均平方の値は 0.000034 となる。

#### F値の計算
最後の手順は、F値を計算し、等水準平均の検定を行う。
F値は、水準平均平方を残差平均平方で割ったものである。
この場合、F値は 4.86 となる。
信頼水準 95%での自由度 4 および 20 のF分布表を参照すると、境界値は 2.87 であることが判る。
これは、結果が有意であり、したがって、機械による強い効果の証拠があることを意味する。
水準と効果の重ね合わせ図を見ると、これが機械 2 と 4 によって引き起こされていることが判る。
