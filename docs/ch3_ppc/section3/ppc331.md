# 3.3.3.1. 母数、範囲、分解能の特定

目標とこれまでの手順で構築したモデルは、母数の選択、期待される範囲と求められる測定分解能の決定に必要な情報全てを提供すべきである。

#### 何をどのように測定すべきかを示す目標
最初の手順は、慎重な目標の検討である。
これにより、どの応答変数をどのように採取すべきかが明らかになる。
例えば、ウェハ上の酸化膜を目標値から 10Å 以内の誤差で、均一性 2％未満で成膜できるかを判断したいと目標に記述している場合、ウェハ上の膜厚をを少なくとも ±3Å の精度で測定する必要があり、均一性を計算するためにウェハ上の複数の箇所で測定を行わなければならないことが判る。

目標と構築するモデルが、標本採取すべき説明変数とその方法についても示さなければならない。
特性要因図で既知の重要な関係を定義し、それらがどの説明変数が測定の候補になるかの最もよい指針になる。

#### 外れ値の選別に役立つ範囲
想定される値の範囲を定義しておくことは、外れ値を選別するのに役立つ。
[加工の例](../section2/ppc231.md#例)では、公称値から ±0.005" 以上ずれる値が多数見られることは想定されていない。
したがって、この範囲を大幅に超える値は疑わしいとみなされ、再測定を行うべきであることが判る。

#### 測定機器の選定に役立つ分解能
最後に、測定に必要な分解能を指定する必要がある。
この仕様は、計測機器の選定の指針となり、測定手順の策定にも役立つ。
経験則として、測定分解能は公差の少なくとも 1/10 であることが望ましいとされている。
酸化膜成長の例の場合、これは 2Å の精度で測定する必要があることを意味する。
同様に、旋削加工の場合、直径を .001" 以内の精度で測定する必要がある。
つまり、この用途ではノギスが測定機器として適切であると言える。
