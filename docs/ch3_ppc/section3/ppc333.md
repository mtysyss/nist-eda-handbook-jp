# 3.3.3.3. 標本規模の決定

#### 標本規模を決定するときの考慮事項
標本規模の決定には、以下の課題を考慮しなければならない。

* 推定したい母集団の母数
* 標本採取のコスト（情報の重要性）
* どの程度既知か
* 母集団のひろがり（ばらつき）
* 実用性：データ収集の難易度
* 最終の推定値に求める精度の程度

#### 標本採取にかかる費用
標本採取のコストの課題は、推定の精度をどの程度にすべきかを判断する上で役立つ。
後述するように、標本規模を決定するときにリスク値を選択する必要がある。
標本採取活動に基づいて下す決定の価値が非常に高い場合は、リスク値を低く設定し、その結果、より大きな標本規模が必要になる。

#### 事前情報
もし対象の過程に関してこれまでに研究が行われているのであれば、その事前情報を活用し、標本規模を縮小することができる。
これには、事前の平均値および分散の推定値を用いることや、母集団を層別して群内の変動を低減させることなどがある。

#### 固有のばらつき
対象とする母集団の何らかの特性を推定するために標本を取得する。
その推定量の分散は、母集団固有のばらつきを標本規模で割った値に比例する。

$$\text{Var}(\hat{p}) \approx \frac{\sigma^2}{n}$$ 

ここで、$`\hat{p}`$ は推定しようとしている母数を表す。
これは、母集団のばらつきが大きい場合、多くの標本を取得しなければならないことを意味する。
逆に、母集団の分散が小さい場合は、それほど多くの標本を取得する必要がないことを意味する。 

#### 実用性
もちろん、選択する標本規模は妥当なものでなければなりません。
ここが、通常、トレードオフが生じる点である。
関心のある母数について適度に正確な推定値を得るために十分な観測値を収集したい一方で、実用的な資源の範囲内でこれを実現したいとも考える。
重要なのは、選択した標本規模に伴うリスクを定量的に評価することである。

#### 標本規模の決定
要約すると、標本規模の推定には以下の手順が必要である。

1. 標本に何を期待しているかについて、明確な記述が必要である。
何を推定しようとしているのか、推定値の精度をどの程度求めるか、推定値が得られた後にそれをどのように活用するかを決定しなければならない。
これらは目的から容易に導き出せるはずである。
2. 推定値に求める精度と標本規模を結びつける式を見つける必要がある。
これは確率論的な記述である。
以下にいくつかの例を示す。
もしこれらが状況に適さない場合は、統計学者に相談する。
3. この式には、母平均や分散など、母集団の未知の特性が含まれる場合がある。
ここで、事前情報が役立つことになる。
4. 変動を低減するために母集団を層別化する場合、各層ごとに標本規模の決定を行う必要がある。
5. 最終的な標本規模は、実用性の観点から精査する必要がある。
もしそれが受け入れがたいものである場合、それを減らす唯一の方法は、標本推定値の精度を多少下げることを受け入れることである。

#### 標本比率
標本比率を調べるときは、望まれる精度に関する確率の記述から始める。
これは次のように表す。

$$Pr(|\hat{p} - P| \ge \delta) = \alpha$$

ここで
* $`\hat{p}`$ は推定された割合
* **P** は未知の母集団母数
* *δ* は推定値の指定された精度
* *α* は確率値（通常は低い値）

この式は、単に、推定値の精度が所望値を下回る確率が *α* であることを示している。
当然ながら、*α* は低く設定するのが望ましく、通常は 0.1 以下とする。
割合がおおよそ正規分布に従うという仮定を用いると、必要な標本規模の推定値を次式で求めることができる。

$$n = z_{\alpha}^{2}(\frac{pq}{\delta^2})$$ 

ここで、*z* は *α* に対応する正規分布曲線上の縦軸上の値である。 

#### 例
試してみたい新しい工程があるとする。
この新しい工程を実行し、その出力を標本採取して歩留まり（良品／不良品）を測定する計画である。
現在の工程歩留まりは 65％（$`p=0.65`$、$`q=0.35`$）である。
そこで、新しい工程の歩留まりの推定値が、95%の信頼度（$`α= 0.05`$、$`z_α= -2`$）で $`δ= 0.10`$ 以内の精度を持つようにすることを決定した。
上記の式を用いると、標本規模の推定値は $`n=91`$ となる。
したがって、新しい工程の出力から 91 個の部品を無作為に抽出し、歩留まりを推定すれば、その推定値が真の工程歩留まりから 0.10 以内に収まる確率は 95% となる。

#### 位置の推定：相対誤差
連続的な正規分布に従う変数を標本抽出する場合、多くの場合、絶対誤差よりも推定値の相対誤差が関心事となる。
望ましい精度と標本規模を結びつける確率的記述は、次式で与えられる。

$$Pr\left( \left\|\frac{\hat{y} - \mu}{\mu}\right\| \ge \delta) \right) = \alpha$$ 

ここで、*μ* は（未知の）母平均、$`\bar{y}`$ は標本平均である。

ここでも、正規性の仮定を用いると、推定標本規模は次式で求められる。

$$n \approx \frac{z_{\alpha}^{2}\sigma^{2}}{\delta^{2}\mu^{2}}$$ 

ここで、$`\sigma^2`$ は母分散を表す。 

#### 位置の推定：絶対誤差
もし相対誤差の代わりに絶対誤差を用いたい場合、標本規模の式は割合の場合の式とよく似ている。

$$n \approx z_{\alpha}^{2}\left( \frac{\sigma^{2}}{\delta^{2}} \right)$$ 

ここで、*σ* は母標準偏差である（ただし実際には、通常は<u>工学的概算値</u>に置き換えられる）。 

#### 例
半導体ウェハ上に 500Å の薄膜を堆積させる安定した工程から標本採取し、工程平均値を求め、工程に対する管理図を作成したいとする。
真の平均値から 10Å 以内（$`δ=10`$）の精度で、95％ の信頼度（$`α= 0.05`$、$`z_α= -2`$）で平均値を推定したい。
この工程のばらつきに関する初期の推定値として、1標準偏差は約 20Å であると仮定する。
これにより、標本規模の推定値は $`n= 16`$ となる。
したがって、この工程から少なくとも 16個の標本を採取し、平均膜厚を推定すれば、その推定値が真の平均値から 10Å 以内の範囲にあると 95％の確信を持って言える。
