# 3.3.3.4. データの保存と抽出

#### 施設規模によって異なるデータ管理
小規模な生産施設や実験室であれば、標本採取計画を策定し、材料を処理して測定を行い、実施記録に記入した後、コンピュータに戻って結果を分析するだけで済む。
データの保存や検索に関しては、特に気にする必要はほとんどない。

#### 工程の理解
PPCの計画段階では、データ収集工程全体を確実に把握しておく必要がある。
注意すべき点としては、以下のようなものがある。

* 外れ値を排除してしまう自動測定装置
* 要約統計量（平均値と標準偏差）のみが保存される
* 説明変数（位置、作業者など）の値が保存されていない
* 欠損値の取り扱い方法

#### 早い段階でのサポートへの相談
PPCの計画段階の早い段階で、データ・システムの保守を担当する組織の関係者と相談することが重要である。
また、計画で定義された形式で実際にデータを取得できることを確認するために、データ収集の「リハーサル」を何回か行うことも有益である。
