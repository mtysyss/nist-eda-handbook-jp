# 3.3. PPCのためのデータ収集

#### 綿密な計画から着手
PPCのデータ収集過程は、綿密な計画立案から始める。
この計画立案には、明確かつ簡潔な目標の設定、工程モデルの構築、および標本採取計画の策定が含まれる。

#### データ収集で起きるさまざまな問題
この一連の活動は、実際にデータを収集せずに終了するが、データ収集は見た目ほど単純な作業ではない。
標本採取計画の実行においては、多くのことがうまく実行できないことがある。
こうした問題は、チェックリストを活用し、当初の標本採取計画からのすべての例外事項を綿密に記録することで、軽減することができる。
