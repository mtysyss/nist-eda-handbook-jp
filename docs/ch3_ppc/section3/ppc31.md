# 3.3.1. 目標の定義

#### 簡潔な目標の記述
目標記述書は、特徴付け計画において最も重要な部分の一つである。
目標が明確かつ簡潔に述べられていれば、その後の計画策定工程は自然と順調に進む。

#### 目標を主要な仕様に基づいて定義
目標は通常、主要な仕様や生産指標に基づいて定義する。
一般に、工程を特徴付け、その結果をこれらの仕様と比較したいと考える。
しかし、必ずしもそうとは限らない。
例えば、単に主要な工程母数を定量化し、それらの母数の推定値を制御設計や工程改善といった他の活動に活用したいだけの場合もある。
