# 3.3.3. 標本採取計画の定義

#### 実施すべき測定の詳細な概要である標本採取計画
標本採取計画とは、どの測定をいつ、どの材料に対して、どのような方法で、誰が行うかについて詳細に定めた概要である。
標本採取計画は、得られたデータが対象とする母数の代表的な標本を含み、且つ目標に明記されたすべての疑問に答えられる形で設計されるべきである。

#### 標本採取計画の手順
標本採取計画の策定には、以下の手順がある。

1. [測定対象の母数と、想定される値の範囲、求められる分解能の特定](ppc331.md)
2. [標本の採取方法および時期を詳細に定めた標本採取方法の設計](ppc332.md)
3. [標本規模の選定](ppc333.md)
4. [データ保存形式の設計](ppc334.md)
5. [役割と責任の割当て](ppc335.md)

#### 検証と実行
標本採取計画が策定されたら、その内容を検証した上で、実行担当に引き継ぐ。
