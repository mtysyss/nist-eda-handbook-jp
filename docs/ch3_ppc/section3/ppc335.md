# 3.3.3.5. 役割と責任の割当て

#### PPCはチーム作業、早い段階から全員を巻き込む
今日の生産環境において、調査研究がたった一人の個人によって行われることは珍しい。
PPC調査のほとんどはチームでの取り組みである。
調査に関与するすべての関係者が、開始時からチームの一員として関与することが重要である。
さまざまな付随業務の多くは、承認や署名が必要である。
計画にはその所要時間を必ず考慮に入れる。
