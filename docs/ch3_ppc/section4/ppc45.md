# 3.4.5. 工程安定性の評価

#### 時間が経過しても平均が一定、分散も一定ならば工程は安定
生産工程は、その安定性が証明されるまでは量産に投入することはできない。
また、工程の安定性が実証されるまでは、[工程能力](ppc46.md)について論じることはできない。
工程は、その測定に用いるすべての応答母数が、時間が経過しても平均値と分散の両方が一定であり、且つ分布も一定である場合に、安定していると言われる。
これは、前述の[管理されたばらつき](../section1/ppc132.md#control)の定義と同義である。

#### 散布図もしくは管理図：安定性を評価するために用いるグラフ
工程の安定性を評価するために使用するグラフは、[散布図](../../ch1_eda/section3/eda33q.md)である。
十分な期間（日数、処理時間、または処理された部品数で指定可能）に渡り、工程から独立した十分な標本数（100以上）を収集し、x軸に標本の順序、y軸に標本の値をプロットした散布図を作成する。
この図は、一定の平均値を中心に無作為なばらつきが一定であるように見えるはずである。
場合によっては、[管理限界](../../ch6_pmc/section3/pmc31.md)を計算し、データとともに散布図にプロットすると役立つことがある。
[管理されたばらつきの例](../section1/ppc1321.md)の例にある2つの図は、安定した工程と不安定な工程の良い例示である。

#### 自己相関関数を用いた数値的定常性の評価
数値的には、[定常性](../../ch6_pmc/section4/pmc44.md#stationary)として知られる時系列解析の概念を用いて、工程の安定性を評価する。
これは、工程の平均が一定で、分散も一定であることを別の表現で示したものに過ぎない。
定常性を評価するために用いられる数値的手法は、[自己共分散関数](../../ch6_pmc/section4/pmc44.md#covar)である。

#### グラフ化方法でたいてい十分
通常、工程の安定性を評価するには、グラフ化手法で十分である。
数値的手法は、一般的にモデル化目的でのみ用いられる。
