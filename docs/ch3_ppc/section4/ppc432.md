# 3.4.3.2. 物理モデルへの近似

#### 物理モデルを使いたいとき
場合によっては、応答挙動を[多項式モデル](ppc431.md)で近似するのではなく、工程の背景にある物理が既知であり、モデル化できることもある。
このような場合、データに<u>物理モデル</u>を当てはめることが望ましい。
この種のモデル化は、より正確な予測を可能にし、多項式モデルに比べて変動の影響を受けにくいという利点がある（背景にある工程が変化しない限り）。

#### CMP工程を例に挙げた解説
この概念を例を挙げて説明する。
特定の半導体生産工程における化学的機械的平坦化（CMP）工程に関するデータを収集した。
この工程では、研磨パッドを使用し、研磨スラリー中の化学物質を組合せてウェハを研磨する。
材料除去率を計算するために、複数のウェハを異なる時間で研磨した。

#### 非線形方程式を用いてモデル化するCMPの除去率
第一原理から、除去率は時間とともに変化することが判っている。
初期段階では除去率は高いが、ウェハがより平坦になるにつれて除去率は低下する。
これは、次の指数関数で簡単にモデル化できる。

$$ 除去率= p1 + p2 × exp^{p3 × 時間}$$

ここで、*p*1、*p*2、*p*3は、推定したい母数である。
