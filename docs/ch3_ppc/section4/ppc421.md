# 3.4.2.1. 応答の相関関係

#### 応答変数すべての散布図の作成
データの探索を行うこの最初の段階では、すべての応答変数を対の形式でプロットする。
個々の散布図は、行列の同一行にあるすべてのプロットの y軸尺度を同じにし、行列形式で表示する。

#### 散布図上のデータの傾きの確認
[散布図行列](../../ch1_eda/section3/eda33qb.md)は、応答変数同士がどのように関連しているかを示している。
もし正の傾きを持つ線形傾向が見られる場合、応答変数間に正の相関があることを示している。
負の傾きを持つ線形傾向が見られる場合は、変数間に負の相関を示す。
もしデータに傾きがなく無作為に見える場合、変数間にはおそらく相関がない。
これは、その後のモデル構築の段階において重要な情報となる。

#### 負の相関と正の相関の両方の変数の例を示す散布図行列
以下に、散布図行列の例を示す。
この半導体生産の例では、応答変数 3つ、留まり（Bin1）、Nチャネル有効Id（NIDEFF）、およびPチャネル有効Id（PIDEFF）が、互いに相関関係を示すように散布図行列上にプロットされている。
ここから、Bin1 は NIDEFF と正の相関があり、PIDEFF とは負の相関があることが判る。
また、予想通り、NIDEFF は PIDEFF と負の相関がある。
このような情報は、歩留まり向上のためのモデルを構築する際に役立つ。
