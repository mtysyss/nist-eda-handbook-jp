# 3.4.4. 分散構造の分析

#### PPCで重要な分散の研究
工程特徴付け作業において最も一般的な活動の一つは、工程に伴うばらつきを調査し、ばらつきの主な要因を特定しようとすることである。
これは<u>分散分析</u>と呼ばれる。
この種の分析の理論的背景の議論は、本章の[ANOVAモデル](../section2/ppc23.md)節を参照のこと。

#### 構造を理解することの重要性
分散分析を行う上での鍵は、データが表す<u>構造</u>の特定である。
「ANOVAモデル」の節では、要因が[交差した](../section2/ppc232.md)か、あるいは[枝分かれた](../section2/ppc233.md)[一元](../section2/ppc231.md)配置および二元配置について解説した。
ANOVAの構造的配置についてさらに詳しく知りたい場合は、これらの節を復習のこと。

分析の実行では、構造を特定し、各因子とそれぞれの水準のデータを統計分析プログラムに入力し、ANOVA表と他の出力を解釈する。
これら全てを以下の例で示す。

#### 例：一元配置における炉内酸化膜の厚さ
半導体生産における、ウェハ上に酸化膜を形成する炉の操作を例として挙げる。
各ロットのウェハは石英製の容器（ボート）に載せられ、長い管状炉内に投入される。
そして、ガスが流れる中で所定の温度まで加熱され、一定時間その温度を維持する。
この工程における重要な要因を把握したい。
炉は4つの区画（ゾーン）に分けられており、各ゾーンにおいて各ロットから2枚のウェハを抽出し、酸化膜の厚さを測定する。

#### ゾーンの位置が酸化膜の厚さに及ぼす影響の確認
まず検討することは、ゾーンの位置が酸化膜の厚さに及ぼす影響である。
これは典型的な一元配置である。
要因は炉のゾーンであり、4つの水準がある。

#### 枝分かれ配置を用いたロットの説明
グラフから、ゾーン効果はそれほど大きくなく観えるが、実際に、ANOVA表ではその効果は有意ではないことが示されている。
問題は、ロットに起因するばらつきが非常に大きいため、ゾーン効果が隠れてしまっている点である。
これを解決するために、ロット要因を追加すればよい。

#### 結論
「確率 > F」が0.05未満であることから、ロットおよびゾーンの両方について、これらの要因は 0.05 の有意水準において統計的に有意であることが解る。
