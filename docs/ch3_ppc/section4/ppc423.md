# 3.4.2.3. 一次交互作用の探索

#### 交互作用の特定が重要
探索フェーズにおける最後の手順（そしておそらく最も重要な手順）は、一次交互作用を見つけることである。
ある 1因子の水準間の応答の差が、別の因子のすべての水準において同じではない場合、その2つの因子の間に交互作用があると言える。
因子設定に基づいて応答を最適化しようとするとき、交互作用は妥協点を与える。

#### 注意ーあてにならない見た目
交互作用は、入れ子になった[箱ひげ図](../../ch1_eda/section3/eda337.md)を用い視覚的に確認する。
ただし、グラフのみを用いて交互作用を特定するときには注意が必要である。
グラフによって特定された交互作用すべてについて数値的方法も検証すべきである。

#### 前の例の続き
前の例に続き、以下に小粒子と大粒子の入れ子状の箱ひげ図を示す。
前室は 2つの温度値に入れ子になっている。
これら2つの因子間に何らかの交互作用がある証拠がいくつか見られる。
前室の影響は、高温時よりも低温時の方が強い。
この効果は、大きな粒子よりも小さな粒子の方が強い。
この例が示すように、有意な交互作用がある場合、主効果は条件付きで解釈しなければならない。
つまり、主効果だけでは全体像を把握することはできない。

#### 高温時よりも低温時の方が強い小粒子の前室効果
以下は、温度に入れ子になった前室内の小粒子の箱ひげ図である。

![ load lock effect within temperature for small particles; effectstronger for low temperatures](https://www.itl.nist.gov/div898/handbook/ppc/section4/gifs/int1.gif)

このプロットから小粒子について、高温時における前室の影響は、低温時ほど強くないと結論づける。 

#### 大粒子でも同様の可能性があるがそれほど強くはない
以下は、温度に入れ子になった前室の大粒子に関する箱ひげ図である。

![ load lock effect within temperature for large particles ](https://www.itl.nist.gov/div898/handbook/ppc/section4/gifs/int2.gif)
 
このプロットから、大きな粒子については、高温時における前室の影響は、低温時ほど強くない可能性があると結論づける。
ただし、この影響は、小さな粒子の場合ほど強くはない。
