# 3.4.3.1. 多項式モデルの推定

#### どの入力要因が応答を左右し、どの方向に影響を与えるかを特定するための優れたツールである多項式モデル
多項式モデルを用いて、入力母数値の範囲に渡る応答値の形状を推定し予測する。
多項式モデルは、どの入力要因が応答を駆動し、どの方向に影響を与えるかを特定するための優れたツールである。
また、これらは実験計画法の分析に最も一般的に使用されるモデルでもある。
2つの説明変数に対する二次多項式モデルは、以下の式の形を持つ。
単一 x項は、主効果と呼ばれる。
2乗項は 2次効果と呼ばれ、応答曲面の曲率をモデル化するために用いる。
交差積項は、説明変数間の交互作用をモデル化するために用いる。

$$Y = \alpha_0 + \alpha_1 x_1 + \alpha_2 x_2 + \alpha_{11} x_{1}^{2} +
\alpha_{22} x_{2}^{2} + \alpha_{12} x_{1}x_{2} + \epsilon$$

#### 2次方程式以上は不要
ほとんどの工学および生産分野の適用において扱うのは、高々 2次多項式モデルまでである。
多項方程式は、説明変数の数、ひいては交差項の数を増やすにつれ、明らかにより複雑になる可能性がある。
幸いなことに、2因子を超える有意な交互作用項が見られることはめったにない。
これにより、方程式を扱いやすい範囲に抑えることができる。

#### 多項式モデルを推定する多重回帰
因子数が少ない場合（5未満）、完全な多項式方程式をいわゆる多重回帰という技法を用いて推定する。
因子数が多い場合は、<u>段階的回帰</u>と知られる技法を用いるべきである。
ほとんどの統計解析プログラムには、段階的回帰機能が備わっている。
単に、多項式モデルのすべての項を入力し、ソフトウェアにデータを最もよく説明する項を選ばせるだけである。
この話題に関するより詳細な解説や具体例については、[工程改善](../../ch5_pri/pri.md)の章を参照のこと。
