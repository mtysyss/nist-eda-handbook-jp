# 3.4.2. 関係性の探索

#### データに対する最初の分析は探索
希望する形式でデータファイルを作成し、データの整合性を確認し、応答変数の要約統計量を推定したら、次の手順はデータの探索を開始し、背後にある構造を理解しようと試みる。
最も有用な道具となるのは、さまざまな基本的散布図や箱ひげ図である。

これら技法で、任意の応答変数の対、説明変数と応答変数の対、任意の2つの説明変数の関数としての応答変数間の関係を検証するための、対で探索が可能になる。
3次元を超える場合は、可視化に関する人の弱点により多くの場合、制限される。

#### 意味のあるものはすべてグラフ化
この探索フェーズでは、グラフ化に意味があるものはすべてグラフ化することが重要である。
これらの図は、データに潜むさらなる品質上の問題を明らかにするだけでなく、影響力の大きいデータ点を明らかにし、その後のモデル化活動の指針となる。

#### 応答、説明変数対応答、そして条件付きプロットのグラフ化
データ分析において一般的に最も効果的とされる手順は、まずすべての応答変数を互いに対でプロットすることである。
次に、応答変数を説明変数に対してプロットする。
これにより、応答変数に影響を及ぼす主な要因が示される。
最後に、説明変数の水準を条件として、応答変数をプロットする。
これにより、説明変数間の相互作用が明らかになる。
相互作用を可視化するために、枝分かれた[箱ひげ図](../../ch1_eda/section3/eda337.md)と[ブロック・プロット](../../ch1_eda/section3/eda333.md)を使用する。
