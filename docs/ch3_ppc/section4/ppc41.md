# 3.4.1. 最初の手順

#### すべてのデータを一か所に集約
特徴付け研究のデータ収集計画を実行した後、分析のためにデータを集めなければならない。
研究の範囲によっては、データが1か所にあることもあれば、さまざまな場所のこともある。
一般的な工場のデータベースや、個々のコンピュータ上の簡単なファイル、手書きの作業記録の場合もある。
いずれの場合でも最初の手順では、さまざまな情報源からすべてのデータを収集し、単一データ・ファイルに入力する。
ほとんどのデータ分析において最も便利な形式は、変数を列に配置する形式である。
この形式では、列見出しに変数名を、行に変数の値を記載する。

#### グラフと数値的技法を用いてデータの品質確認
次の手順は、データの品質を確認する。
ここでは通常、データ入力の誤り、異常なデータ値、欠損データなどを探す。
この手順で最も有用な2つのツールは、[散布図](../../ch1_eda/section3/eda33q.md)と[ヒストグラム](../../ch1_eda/section3/eda33e.md)である。
すべての応答変数の散布図を作成することで、データ入力の誤りを容易に特定することができる。
また、応答変数のヒストグラムも、データ入力の誤りを特定するのに非常に役立つ。
説明変数のヒストグラムも、標本採取計画の実行における問題を特定するのに役立つ。
説明変数の各水準における計数が標本採取計画で定められたものと一致しない場合、実行上の問題がある可能性があることが判る。
すべての変数（応答変数と説明変数の両方）に対して数値要約統計量を計算することも、データの問題を特定するのに役立つ。

#### データの位置、ばらつき、形状を推定しデータを要約
データの品質に関する問題が特定され、修正されたら、すべての応答変数について、位置、広がり、形状を推定すべきである。
これは、ヒストグラムと数値的要約統計量とを組み合わせ、容易に行える。
