# 3.4.3. モデルの構築

#### ブラックボックス・モデル
データ収集計画の策定時には、以下に示す調査対象の工程に関する<u>ブラックボックス</u>モデルを構築する。

![black box model](https://www.itl.nist.gov/div898/handbook/ppc/section1/gifs/img1351.gif)

#### 工程モデルの概念図を明示的に表現した数値モデル
[関係性の探索](ppc42.md)」の節では、グラフを用いた方法を通して、どのように入力と出力の関係を特定するかについて検討した。
しかし、その関係を定量化し、統計的有意性を検定したい場合は、数学的モデルを構築しなければならない。

#### 出力曲面を記述する一般的な多項式モデル
数学モデルの構築に関しては、2つの事例を取り上げる。
経験的な予測式の策定や、統計的に有意な説明変数を特定し、応答変数に及ぼす影響を定量化することが目的である場合、通常は[多項式モデル](ppc431.md)を構築する。
その名称が示す通り、これらは説明変数と応答変数との関係を記述する多項式関数（通常は線形または2次関数）である。

#### 工程の背景にある物理を記述する物理モデル
一方、既存の理論式に適合させることを目標とする場合は、[物理モデル](ppc432.md)を構築する。
これもまた、その名称が示す通り、その過程に関わる物理現象を表す方程式が既に存在し、特定の母数値を推定したい場合に関係する。
