# 3.1.2. PPC研究の使われ方

#### あらゆるCI[^1]施策の中核をなすPPC
工程の特徴付けは、あらゆる継続的改善プログラムにおいて不可欠な要素である。
その施策には、工程の特徴付けが求められる多くの段階がある。
その例としては、次のようなものが挙げられる。

#### 工程の特徴付けが必要な場合
* 新しい工程やツールを導入するとき
* 予定された／予定外のメンテナンス後に、道具や工程を復旧させるとき
* 道具や工程を比較したいとき
* 監視フェーズにおいて、工程の健全性を確認したいとき
* 不具合のある工程のトラブル解決を行うとき

本章で述べられている技法は、本ハンドブックで網羅している他の章に等しく適用可能である。
これらには以下が含まれる。

#### 他の分野にも適用可能な工程特徴付け技法
* 校正
* 工程監視
* 工程の改善
* 工程／製品の比較
* 信頼性
