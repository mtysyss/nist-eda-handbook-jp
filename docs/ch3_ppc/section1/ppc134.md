# 3.1.3.4. 母集団と標本抽出

#### 対象集団から標本の抽出と推論
調査の標本抽出において、ある特定の話題について全員がどう考えているかを知りたい場合、単に全員に尋ねてその回答を記録すればよい。
ただし、**全員**という用語の定義（ある町のすべての成人、米国のすべての男性など）によっては、全員を対象に調査を行うことが不可能だったり、現実的でない場合もある。
その他の選択肢は、関心のある意見を持つ人々（対象集団）の中から少人数のグループ（標本）を選び、意見を記録し、その情報をもとに全員の考えについて推論を行うことである。
世論調査機関は、まさにそれを行うための道具を開発しており、これらの多くの道具は製造業にも適用できる。
私たちはこれらの標本抽出技法を用いて、工程からいくつかの測定値を取得し、その工程の挙動について結論を導き出すことができる。

#### 必ずしも母集団に関する事実とは限らない、標本に関する事実
もし工程の変動がなければ、1つの標本を取るだけで、対象母集団に関するすべてのことを知ることができた。
残念ながら、そのようなことは決してない。
標本に関する事実を、母集団に関する事実として見なすことはできない。
私たちの仕事は、この変動があるにもかかわらず、母集団について適切な結論を導き出すことである。 
母集団からより多くの観測値を得れば得るほど、標本データは母集団に近づく。
標本に関する事実が、母集団に関する事実の妥当な近似となる地点に達したとき、その標本は適切であると言える。

#### 標本の4つの属性
標本の妥当性は、以下の4つの属性によって決まる。

* 標本の代表性（無作為か？）
* 標本規模
* 母集団の変動性
* 推定値に求められる精度

次に、[標本採取計画の定義](../section3/ppc33.md)の節で、適切な規模の代表的標本の選択に関して学ぶ。
