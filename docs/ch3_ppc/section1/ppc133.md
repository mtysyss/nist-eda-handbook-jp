# 3.1.3.3. 伝播する誤差

#### さまざまな源に起因する変動
特定の工程段階における分散を推定するとき、この分散は通常、その段階だけの結果ではなく、むしろそれ以前の段階からの変動や測定誤差が蓄積されたものである。
したがって、PPCにおいて答えが必要な重要な問いは、異なる源に起因する変動がどのように蓄積されるかということである。
これにより、総変動を分解し、その各部分をさまざまな源に割り当てることが可能になる。
それゆえ、最も大きく寄与する源に対処することができる。

#### 誤差の分類方法
通常、総誤差に対する各種誤差源の寄与は、単純な線形関係によってモデル化することができる。
もし、2つの変数間に単純な線形関係がある場合、例えば、 

$$y = \mu + \alpha y_{1} + \beta y_{2} + \epsilon$$

$`*y*`$ に関連する分散は次式で与えられる。

$$\text{Var}(y) = \alpha^{2}\text{Var}(y_{1}) +\beta^{2}\text{Var}(y_{2}) + 2 \alpha \beta \text{Cov}(y_{1},y_{2})$$

変数間に相関がない場合、共分散は存在せず、上記式における最後の項は消去される。
この良い例として、工程誤差と測定誤差の両方が存在する場合が挙げられる。
これらは通常互いに独立しているため、観測される総分散は、工程誤差と測定誤差の分散の和に他ならない。
標準偏差を足し合わせてはならないことに注意し、必ず分散を足し合わせなければならない。 

#### 個々の要素の計算方法
もちろん、個々の変動成分がわかっている上で、総分散を知りたいという場合はめったにない。
通常は、総分散の推定値があり、その分散を個々の成分に分解したいと考える。
これは<u>分散成分</u>の推定として知られており、この章の後半にある[分散分析](../section4/ppc44.md)のページで詳しく扱う。
