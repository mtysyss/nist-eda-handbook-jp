# 3.1.4. PPCの手順

#### 資源の効率的活用のための4つの手順
PPCの主な活動は、データを収集し分析し、それに基づいて結論を導き出し、最終的には生産工程を改善することである。
多くの産業分野での適用では、実験を行うための生産施設の利用が非常に制限されている。
したがって、費用対効果の高い方法で確実にこれらの活動を行うように、進め方には細心の注意を払わなければなりません。

#### 段階1：計画
圧倒的に最も重要な段階は、計画段階である。
この段階を忠実に実行することで、可能な限り最も効率的な方法でデータを収集し、なお且つ、PPCの目標を支援する。
計画では、以下の内容を作成すべきである。

* 目標の明文化
* 記述的な工程モデル（工程の入力および出力一覧）
* 標本採取計画の説明（研究期間における工程を実行するために使用される手順および設定の説明を含み、関与する各担当者への明確な役割分担を明記する）
* データ収集方法、業務と責任分担、書式、保存方法の説明
* データ分析の概要

特徴付けの実施方法に影響を与えるすべての決定は、計画段階でなされるべきである。
工程特徴付けは、この計画に従って実施され、例外事項はすべて明記されるべきである。

#### 段階2：収集
データ収集とは、本質的に前段階における標本採取計画の実行そのものである。
計画段階での作業が適切に行われていれば、この段階は比較的順調に進むはずである。
計画に可能な限り忠実に実行し、いかなる例外も記録しておくことが重要である。

#### 段階3：分析と解釈
これは、PPCの目標を達成するために、収集されたデータに対して適用される、定量的（回帰分析、分散分析、相関分析など）および図形的（ヒストグラム、散布図、箱ひげ図など）な分析技法の組合せである。

#### 段階4：報告
報告は、決して見過ごしてはならない重要な段階である。
有益な報告書を作成し、扱いやすい場所に保管することで、PPCによって作成された情報を他の関係者も確実に利用できるようになる。
多くの場合、類似した他の研究結果を活用することで、PPCに伴う作業を最小限に抑えることができる。
PPC報告書の例は、[事例研究](../section5/ppc5.md)の節で見ることができる。
