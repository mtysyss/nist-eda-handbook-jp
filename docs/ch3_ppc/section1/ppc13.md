# 3.1.3. 用語と概念
PPCに必要な基礎概念は僅かしかない。
本節ではそれら概念を簡潔に外観し、より詳細を網羅しているハンドブックの他の節へ繋げる。

#### [分布（位置、広がり、形）](ppc131.md)
基本的なデータ分析を行うには、データから位置、広がり、形状をどのように推定するかを理解する必要がある。
これら3つの指標は、いわゆるデータの**分布**として知られるものを構成している。
ここでは、グラフの技法と数値的な技法の両方について見ていく。

#### [工程のばらつき](ppc132.md)
工程変動という概念を徹底的に理解する必要がある。
これには、変動が予想されるデータ値の範囲をどのように説明するか、変動のさまざまな分類、そして変動が工程の安定性や能力において果たす役割などが含まれる。

#### [誤差伝播](ppc133.md)
また、ばらつきが製造工程を通じてどのように伝播するか、そして観測された総ばらつきを寄与源に起因する構成要素への分解方法を理解する必要がある。

#### [母集団と標本抽出](ppc134.md)
標本抽出に関連するさまざまな課題について理解しておくことが重要である。
ここでは、<u>母集団</u>を定義し、対象とする母集団から代表的な無作為標本を採取する方法について定義する。
また、特定の疑問に答えるために必要な、観測数を推定する有用な計算式についても解説する。

#### [モデル化](ppc135.md)
モデル化を行うには、重要な要因と応答を特定する方法を知っておく必要がある。
また、要因と応答間の関係について、図的および定量的にモデルを構築する方法も知っておく必要がある。

#### [実験](ppc136.md)
最後に、これらの関係を定量化するためには、スクリーニング計画や応答曲面計画など、実験計画の基礎について理解しておく必要がある。
この話題については、本章ではごく簡単に触れるにとどめる。
詳細については、[工程改善](../../pri/pri.md)の章で網羅している。
ただし、その活用例は事例研究に掲載している。
