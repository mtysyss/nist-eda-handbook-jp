# 3.1.3.2.1. 制御された／制御されていない変動

#### 2つの傾向グラフ
以下の2つの図は、2つの異なる酸化膜成膜工程における傾向グラフである。
各工程から30枚のウェハを30日に渡り一枚づつ標本抽出した。
各ウェハについて、中心部の膜厚を測定した。
各グラフの<u>x軸</u>はウェハ番号、<u>y軸</u>は Å単位の膜厚を示している。

#### 「管理下」と「管理外れ」工程の例
最初の工程は、工程位置が 約990 を中心に無作為な変動が見られる「管理下」工程の例である。
2番目の工程は、観測数 20 以降、工程位置が上昇傾向を示している「管理外れ」工程の例である。

#### 制御された変動を示す工程
一定の平均値を中心とした無作為な変動に注目する。
