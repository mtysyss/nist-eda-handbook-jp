# 3.1.3.2. 工程のばらつき

#### 至る所に存在するばらつき
あらゆる製造および測定工程にはばらつきが見られる。
例えば、工程の出力に関する重要な寸法、酸化膜の厚さ、抵抗率といった標本データを採取すると、すべての値が同一では<u>な</u>ことが解る。
観察値の集合における結果はあるいくつかの位置の値の周囲に分布する。
これを「広がり」もしくは「ばらつき」と呼ぶ。
ばらつきは、[分散の計算](../section3/eda356.md)と[ヒストグラム](../section3/eda33e.md)によってグラフに表される。

#### 標準偏差でのデータの広がりの表し方
標準偏差（分散の平方根）は、いわゆる<u>>経験則</u>>を用いることで、データの広がりの示唆を与えてくれる。
この経験則（下のグラフに示されている）は以下の通り。

データの約60～78％は、平均値から1標準偏差の範囲内にある $`(\bar{x} - s, \bar{x} + s) `$。

データの約90～98％は、平均値から2標準偏差の範囲内（$`(\bar{x} - 2s, \bar{x} + 2s) `$）にある。

データの99％以上が、平均値から3標準偏差の範囲内（$`(\bar{x} - 3s, \bar{x} + 3s) `$）にある。

#### さまざまな源から蓄積されるばらつき
この観測されたばらつきは、製造工程全体を通して生じたさまざまな分散源が積み重なったものである。
工程の特徴付けにおける重要な活動の一つは、これらさまざまな分散源を特定し定量化し、それらを最小限に抑えることである。

#### さまざまな種類
分散源はさまざまであるだけでなく、分散の<u>>種類</u>もさまざまである。
PPCの目的から分散の重要な分類として、<u>>制御された分散と制御されていない分散</u>の2つがある。

#### 例を見るにはここをクリック
##### 制御された分散
時間の経過とともに<u>安定的</u>かつ一貫した分散パターンを特徴とする分散。
この種の分散は本質的に<u>無作為</u>であり、一定水準での均一な変動を示す。
##### 制御不能な変動 
時間の経過とともに分散パターンが<u>変化</u>し、したがって予測不可能な分散。
この種の分散には、通常、何らかの構造が含まれる。 

#### 制御された変動のみを示す安定した工程
この制御されたまたは制御されていない分散という概念は、工程が<u>安定</u>>しているかを判断する上で重要である。
工程は、一貫性があり予測可能な方法で実行される場合、安定しているとみなされる。
これは、工程平均値が一定であり、ばらつきが制御されていることを意味する。
もし分散が制御されていない場合、工程平均値が変化しているか、工程の分散が変化しているか、あるいはその両方が変化していることになる。
上記の例における最初の工程は安定していますが、2番目の工程は安定していない。

工程の特性付けの過程において、制御されていない分散のすべての要因を排除するよう努めるべきである。
