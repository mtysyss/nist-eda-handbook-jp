# 3.1.3.5. 工程モデル

#### ブラック・ボックス・モデルと特性要因図
この章の第3節で見ていくように、PPCにおける最初の手順の一つは、調査対象の工程をモデル化することである。
この実行時に非常に役立つツールとして、**ブラック・ボックス**・モデルと***特製要因図***がある。

#### 工程を説明するためにブラック・ボックス・モデルの利用
以下に示すような単純な<u>ブラック・ボックス</u>・モデルを用いて、PPCで出くわすツールや工程のほとんどを説明することができる。
工程は入力によって駆動される。
これらの入力には、制御可能なもの（処方や機械の設定など）と、制御不可能なもの（湿度、作業者、電力の変動など）がある。
これらの入力は工程と相互作用し、出力を生み出す。
この出力は通常、測定可能な工程の特性である。
測定可能な入力と出力は、それらがどのように振る舞い、互いにどのように関連しているかを観察し理解するために、標本を採取することができる。

#### ブラック・ボックス・モデルの図
![black box model describing process](https://www.itl.nist.gov/div898/handbook/ppc/section1/gifs/img1351.gif)


これらの入力と出力は、それぞれ因子および応答としても知られる。

##### 因子
応答の挙動（説明変数とも呼ばれる）を説明するために用いられる観察された入力。
##### 応答
標本された工程出力。応答は、平均厚みや均一性といった標本された出力の関数でもある。

#### 変数の種類によってさらに分類される因子と応答
さらに因子と応答変数をそれらが含む情報の量を示す<u>変数型</u>に従って分類する。
名称が示す通り、この分類はデータのモデル化作業に有用であり、適切な分析技法を選択する上で極めて重要である。
以下の表に、この分類をまとめる。
各種類は、含まれる情報の量が多い順に並べており、<u>>測定型</u>>が最も多くの情報を含み、<u>>名義型</u>が最も少ない情報を含む。

#### さまざまな変数型を説明表

| 種類 | 説明 | 例 |  
| :--- | :------ | :------ |  
| 測定 | 離散／連続、順序が重要、無限の範囲 | 粒子数、酸化膜厚さ、圧力、温度 |  
| 順序 | 離散、順序が重要、有限範囲 | 実行番号、ウェハ番号、サイト、区間 |  
| 名義 | 離散的、順序は重要でない、取り得る値がごくわずか | 良品／不良品、区間、高／中／低、シフト、作業者 |  

#### 複雑さを分解するのに役立つ特性要因図
特性要因図を活用することで、モデル化工程をさらに精緻化することができる。
特性要因図は、製造工程の複雑さを分解する上で非常に有用である。
通常、ある工程特性（因子または応答変数のいずれか）を選び、その特性に影響を及ぼす可能性のある一般的な分類（材料、機械、方法、環境など）を列挙し、各分類内でより具体的な詳細を記載する。
その具体的な方法の例は、[事例研究](../section5/ppc5.md)」の節で紹介されている。
