#### 分散の要素
上記分散分析表から、分散の要素を計算する。
このデータ集合では、2枚のウェハについて4つの炉の位置で21回の実行が測定されたことを思い出す。
これにより、次の一連の方程式が導かれる。

$$3072.11 = (4×2)×\text{Var(Run)} + 2×\text{Var(Furnace Location)} + \text{Var(Within)}$$
$$571.659 = 2×\text{Var(Furnace Location)} + \text{Var(Within)}$$
$$120.893 = \text{Var(Within)}$$

これらの方程式を解くと、以下の分散の要素が得られる。
