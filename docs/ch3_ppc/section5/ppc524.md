# 3.5.2.4. スループット

#### スループットのまとめ
スループットを以下の表にまとめる（これは当初のデータ収集の一部であり、分析の結果ではない）。

| 機械 | 1日目 | 2日目 | 3日目 |  
| :--: | :---: | :---: | :---: |  
| 1 | 576 | 604 | 583 |  
| 2 | 657 | 604 | 586 |  
| 3 | 510 | 546 | 571 |  

この表から、機械3 のスループットが著しく低いことが判る。

#### スループットのグラフ表示
スループットをグラフで示す。

![scatter plot of throughput shows machine 3 has significantly lower throughput](https://www.itl.nist.gov/div898/handbook/ppc/section5/Machine/gifs/thrput_f.gif)

このグラフから、機械3 のスループットが低いと明確に判る。

分散分析を行い、機械3 のスループットが低い統計的有意差を確認する。
