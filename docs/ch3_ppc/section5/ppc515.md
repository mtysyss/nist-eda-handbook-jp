# 3.5.1.5. 最終結論

#### 最終結論
炉内酸化物成長工程に関するこの簡単な研究では、当該工程が実行可能であることが示され、また、実行間および同一実行内のゾーン間がいずれも有意なばらつき源であることが明らかになった。
この点を、本工程の制御戦略を設計する際には考慮に入れるべきである。
また、この結果は工程改善活動を行う際にどこに注目すべきかを示唆するものでもあった。
