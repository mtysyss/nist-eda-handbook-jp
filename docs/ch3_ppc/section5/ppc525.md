# 3.5.2.5. 最終結論

#### 最終結論
分析から、機械1 と機械2 のばらつきはほぼ同じであるが、位置には有意な違いが見られた。
また、機械2 のスループットは機械1 よりも高くばらつきも大きかった。
作業員への聞き取り調査によると、彼は2台目の機械の設定が正しくなかったことに気づいていたことが判明した。
しかし、彼は調査が行われていることを知っていたため、設定を変更すると結果に影響を与えるのではないかと懸念し、設定を変更したくなかった。
機械3 は、ばらつきが著しく大きく、スループットも低かった。
作業員によると、この機械は軽微な修理のために数回停止させなければならなかったとのことである。
前述の分析結果を踏まえ、チームは機械3 の交換を推奨した。
