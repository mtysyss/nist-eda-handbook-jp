# 3.5.1.3. ばらつき源の特定
分析の次の領域は、ばらつき源を分解することである。

#### 実行ごとの箱ひげ図
以下は、実行番号ごとの厚さを示した[箱ひげ図](../../ch1_eda/section3/eda337.md)である。

![box plot by run](https://www.itl.nist.gov/div898/handbook/ppc/section5/Furnace/gifs/bprun_f.gif) 

#### 箱ひげ図からの結論
この箱ひげ図から以下の結論が導かれる。

1. 実行ごとのばらつきが顕著である。
2. 各実行の平均値は異なるが、実行による明確な傾向は見られない。
3. 実行間のばらつきに加え、実行内のばらつきも顕著である。
このことから、炉の位置ごとの箱ひげ図も有用である。

#### 炉の位置別箱ひげ図
以下は、炉の位置ごとの厚さに関する[箱ひげ図](../../ch1_eda/section3/eda337.md)である。

![box plot by zone](https://www.itl.nist.gov/div898/handbook/ppc/section5/Furnace/gifs/bpzone_f.gif) 

#### 箱ひげ図からの結論
この箱ひげ図から以下の結論が導かれる。

1. 特定の炉の位置内にはかなりのばらつきが見られる。
2. 炉の位置間のばらつきは小さい。
つまり、4つの炉の位置それぞれにおける分布の位置や尺度はほぼ同程度である（ただし、炉の位置3 にはわずかな外れ値がいくつか見られる）。

#### ウェハごとの箱ひげ図
以下は、ウェハごとの厚さを示した[箱ひげ図](../../ch1_eda/section3/eda337.md)である。

![box plot by wafer](https://www.itl.nist.gov/div898/handbook/ppc/section5/Furnace/gifs/bpwafe_f.gif) 

#### 箱ひげ図からの結論
この箱ひげ図から、ウェハは有意な要因ではないと結論づける。

#### ブロック・プロット
実行、炉の位置、ウェハの複合的な影響を示すために、厚さの[ブロック・プロット](../../ch1_eda/section3/eda333.md)を作成した。
なお、見やすさを考慮して、囲みボックスではなく、接続線を使用していることに留意されたい。

![block plot of film thickness by run, zone,wafer](https://www.itl.nist.gov/div898/handbook/ppc/section5/Furnace/gifs/blockp_f.gif) 

#### ブロック・プロットからの結論
このブロックプロットから、以下の結論を導き出せる。

1. 各実行間および炉の位置間において、いずれも有意なばらつきが見られる。
実行間のばらつきはより大きく観える。
2. 実行3 は外れ値のようである。
