# 3. 生産工程の特徴付け
本章の目的は、製造工程に関する<u>生産工程の特性付け研究</u>（PPC）を計画し、実施する方法を学ぶことである。
製造工程のモモデル化方法を学び、これらのモデルを用いてデータ収集手順を設計し、データ分析活動を導く。
特徴付け研究で収集されたデータの分析方法と、結果の解釈および報告方法について詳細に検討する。
付随する[事例研究](section5/ppc5.md)では、いくつかの工程特徴付け研究の詳細な例を提供している。
